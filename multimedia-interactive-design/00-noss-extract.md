## 2. Occupational Prerequisites

- Minimum age 18 years old (Employment Act 1955 — Act 265)
- Medically fit (verified by licensed Medical Officer)
- Able to read and write in Bahasa Malaysia and/or English
- Basic computer literacy

## 3. Training Prerequisites

One of the following:
1. SKM Level 2 in any related ICT / Multimedia field
2. SPM or equivalent with credit in Mathematics / Science / Technical subject
3. Other equivalent qualification as recognised by JPK

### CU C01: Multimedia Production Preparation (Penyediaan Pengeluaran Multimedia)

**CU Description:** Perform pre-production activities including project brief analysis, concept development, storyboard creation, and resource preparation for multimedia projects.

#### Work Activities

| WA Code | Work Activity (EN) | Work Activity (BM) |
|---------|-------------------|-------------------|
| J582-001-3:2019-C01-W01 | Analyse Multimedia Project Brief | Menganalisis Taklimat Projek Multimedia |
| J582-001-3:2019-C01-W02 | Develop Multimedia Concept and Script | Membangunkan Konsep dan Skrip Multimedia |
| J582-001-3:2019-C01-W03 | Create Multimedia Storyboard | Mencipta Papan Cerita Multimedia |
| J582-001-3:2019-C01-W04 | Prepare Multimedia Production Resources | Menyediakan Sumber Pengeluaran Multimedia |

#### Related Knowledge (→ KP Topics)

| KP No. | Related Knowledge Topic |
|--------|------------------------|
| KP-01 | Multimedia concepts, types, and industry applications |
| KP-02 | Multimedia production pipeline and project management |
| KP-03 | Script writing and storyboard techniques |
| KP-04 | Software, hardware, and resource requirements for multimedia production |

#### Performance Criteria (Assessment Reference)

- Correctly identify project requirements from client brief
- Produce a complete and coherent multimedia concept document
- Create a storyboard aligned to the approved script
- Prepare production schedule, equipment list, and resource checklist

#### Related Knowledge (→ KP Topics)

| KP No. | Related Knowledge Topic |
|--------|------------------------|

#### Work Activities

| WA Code | Work Activity (EN) | Work Activity (BM) |
|---------|-------------------|-------------------|

| J582-001-3:2019-C03-W03 | Edit and Mix Audio Tracks | Menyunting dan Mencampurkan Trek Audio |
| J582-001-3:2019-C03-W04 | Export and Deliver Audio Files | Mengeksport dan Menyerahkan Fail Audio |

#### Related Knowledge (→ KP Topics)

| KP No. | Related Knowledge Topic |
|--------|------------------------|
| KP-01 | Audio fundamentals: frequency, amplitude, sampling rate, bit depth |

### CU C05: Interactive Multimedia Production (Pengeluaran Multimedia Interaktif)

**CU Description:** Design, develop, integrate, test, and publish interactive multimedia products that combine graphics, audio, video, and navigation elements.

#### Work Activities

| WA Code | Work Activity (EN) | Work Activity (BM) |
|---------|-------------------|-------------------|
| J582-001-3:2019-C05-W01 | Design Interactive Multimedia Structure | Merekabentuk Struktur Multimedia Interaktif |
| J582-001-3:2019-C05-W02 | Develop Interactive Multimedia Elements | Membangunkan Elemen Multimedia Interaktif |
| J582-001-3:2019-C05-W03 | Integrate Multimedia Components | Mengintegrasikan Komponen Multimedia |
| J582-001-3:2019-C05-W04 | Test and Debug Interactive Multimedia | Menguji dan Membetulkan Multimedia Interaktif |
| J582-001-3:2019-C05-W05 | Publish and Deliver Interactive Multimedia | Menerbitkan dan Menyerahkan Multimedia Interaktif |

#### Related Knowledge (→ KP Topics)

| KP No. | Related Knowledge Topic |
|--------|------------------------|
| KP-01 | Interactive multimedia concepts: interactivity, navigation, user experience (UX) |
| KP-02 | Authoring tools and platforms (e.g. Adobe Animate, HTML5, Articulate) |
| KP-03 | Multimedia integration: embedding audio, video, and graphics in interactive projects |
| KP-04 | User interface (UI) design principles for interactive media |
| KP-05 | Testing, debugging, and publishing interactive multimedia products |

#### Performance Criteria (Assessment Reference)

- Produce interactive structure map / navigation diagram
- Develop interactive elements using approved authoring tools
- Integrate all multimedia assets correctly
- Conduct user testing and resolve identified issues
- Publish final product to specified platform or delivery format
