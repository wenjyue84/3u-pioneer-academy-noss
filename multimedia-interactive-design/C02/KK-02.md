### Tujuan Aktiviti / Activity Purpose

Kertas kerja ini membimbing pelatih untuk mengaplikasikan prinsip-prinsip reka bentuk dan teori warna secara praktikal dalam penghasilan reka bentuk grafik digital. Pelatih akan mencipta sebuah poster promosi digital menggunakan Adobe Illustrator dengan menerapkan prinsip komposisi, hierarki visual, imbangan, kontras dan teori warna.

*(This work sheet guides trainees to practically apply design principles and colour theory in the production of digital graphic designs. Trainees will create a digital promotional poster using Adobe Illustrator by applying principles of composition, visual hierarchy, balance, contrast and colour theory.)*

### Brief Projek / Project Brief

**Tajuk Projek:** Poster Promosi Festival Muzik Digital

**Saiz:** A4 Landscape (297mm x 210mm)
**Resolusi:** 300 DPI
**Mod Warna:** RGB (untuk paparan digital) — Note: Dalam latihan ini, simpan sebagai RGB kerana output adalah digital
**Format Output:** PDF (untuk paparan), JPEG (untuk perkongsian)

**Kandungan yang diperlukan:**
- Nama festival: "NADA FEST 2026"
- Tarikh: 15 - 17 Ogos 2026
- Tempat: Stadium Putra, Kuala Lumpur
- Slogan: "Di mana muzik bertemu jiwa"
- Maklumat tiket: Tiket dari RM 80 | nada.fest/tiket

**Sasaran Audiens:** Belia berumur 18-35 tahun

---

### Prosedur Langkah Demi Langkah / Step-by-Step Procedure

**Langkah 1: Membuka Dokumen Baru**

1. Buka Adobe Illustrator.
2. Klik **File > New** (Ctrl+N).
3. Tetapkan:
   - Width: 297mm, Height: 210mm
   - Orientation: Landscape
   - Colour Mode: RGB
   - Raster Effects: 300 ppi
4. Klik **Create**.
5. Simpan fail segera: **File > Save As** ke folder `04-working/` dengan nama `NADAFEST2026_poster_v01.ai`.

**Langkah 2: Menetapkan Grid dan Garis Panduan Komposisi**

1. Aktifkan Rulers: **View > Rulers > Show Rulers** (Ctrl+R).
2. Aktifkan Grid: **View > Show Grid** (Ctrl+').
3. Edit tetapan grid: **Edit > Preferences > Guides & Grid**:
   - Gridline every: 10mm
   - Subdivisions: 5
4. Dari ruler, seret garis panduan menegak ke kedudukan 99mm dan 198mm (membahagikan kanvas kepada tiga bahagian sama — peraturan satu pertiga).
5. Seret garis panduan mendatar ke kedudukan 70mm dan 140mm.
6. Titik persilangan keempat-empat garisan adalah titik focal utama.

**Langkah 3: Mencipta Palet Warna Menggunakan Adobe Color**

1. Buka pelayar web dan lawati **color.adobe.com**.
2. Pilih mod warna "Complementary" pada roda warna.
3. Tetapkan warna asas kepada warna ungu gelap (sebagai warna latar belakang utama festival muzik): **#1A0533** atau setara.
4. Adobe Color akan mencadangkan warna komplementari — pilih atau sesuaikan mengikut keperluan.
5. Cipta palet yang mengandungi:
   - Warna Latar (Background): Ungu gelap #1A0533
   - Warna Utama (Primary): Kuning emas #FFD700
   - Warna Sokongan (Secondary): Magenta #E91E8C
   - Warna Aksen (Accent): Putih #FFFFFF
   - Warna Teks (Text): Putih gading #F5F5F5
6. Simpan palet ini ke Adobe Creative Cloud atau catat nilai hex dalam ruangan di bawah.

**Palet Warna Saya / My Colour Palette:**

| Peranan | Nama Warna | Kod Hex |
| --- | --- | --- |
| Latar / Background | | # |
| Utama / Primary | | # |
| Sokongan / Secondary | | # |
| Aksen / Accent | | # |
| Teks / Text | | # |

**Langkah 4: Mencipta Latar Belakang**

1. Pilih **Rectangle Tool** (M) dari panel alatan.
2. Klik pada kanvas dan seret untuk mencipta segi empat tepat yang menutupi seluruh kanvas (297mm x 210mm).
3. Tetapkan Fill kepada warna latar yang dipilih (ungu gelap #1A0533).
4. Tetapkan Stroke kepada None.
5. Dalam panel Layers, namakan layer ini "00-Background".
6. Kunci layer ini: klik ikon kunci di sebelah nama layer.

**Langkah 5: Mencipta Elemen Grid/Geometri (Elemen Visual)**

1. Cipta layer baru: klik ikon "+" di panel Layers, namakan "01-Geometric".
2. Gunakan **Ellipse Tool** (L) untuk mencipta bulatan-bulatan besar yang bertindih sebagai elemen latar dekoratif:
   - Bulatan besar (garis) berwarna ungu sederhana #3D0F6B, opacity 30%, stroke 1px
   - Letakkan elemen geometri di bahagian kiri kanvas
3. Gunakan **Polygon Tool** untuk menambah elemen grafik tambahan jika sesuai.
4. Pastikan elemen latar tidak bersaing dengan teks utama — kurangkan opacity.

**Langkah 6: Menambah Tajuk Utama (Hierarki Tahap Pertama)**

1. Cipta layer baru, namakan "02-Text-Primary".
2. Pilih **Type Tool** (T).
3. Klik pada kanvas dan taip: **NADA FEST**
4. Tetapkan:
   - Font: Pilih jenis taip display yang sesuai (contoh: Montserrat Black atau Impact)
   - Saiz: 80-100pt
   - Warna: Kuning emas #FFD700
5. Taip nombor tahun pada baris berasingan: **2026**
   - Font: Sama tetapi berat normal
   - Saiz: 50pt
   - Warna: Putih #FFFFFF
6. Letakkan teks tajuk pada titik focal atas mengikut peraturan satu pertiga.

**Langkah 7: Menambah Slogan (Hierarki Tahap Kedua)**

1. Gunakan Type Tool, taip: **"Di mana muzik bertemu jiwa"**
2. Tetapkan:
   - Font: Sans-serif ringan (contoh: Montserrat Light atau Raleway Thin)
   - Saiz: 20-24pt
   - Warna: Putih gading #F5F5F5
   - Style: Italic
3. Letakkan di bawah tajuk utama, sedikit lebih kecil untuk menunjukkan hierarki.

**Langkah 8: Menambah Maklumat Acara (Hierarki Tahap Ketiga)**

1. Cipta layer baru, namakan "03-Text-Secondary".
2. Tambah maklumat dengan saiz dan kontras berbeza:
   - **Tarikh:** "15 - 17 OGOS 2026" — Font bold, 18pt, warna kuning emas
   - **Tempat:** "Stadium Putra, Kuala Lumpur" — Font regular, 14pt, warna putih
   - **Tiket:** "Tiket dari RM 80 | nada.fest/tiket" — Font medium, 12pt, warna magenta #E91E8C
3. Gunakan pemisah garis mendatar (Rectangle tool, tinggi 1px) untuk mengasingkan blok maklumat.

**Langkah 9: Semakan Prinsip Reka Bentuk**

Sebelum menyimpan, semak semula reka bentuk anda:

1. **Komposisi:** Adakah elemen-elemen utama berada pada atau berhampiran titik focal grid satu pertiga?
2. **Hierarki:** Adakah tajuk utama paling menonjol? Adakah urutan pembacaan jelas (tajuk → slogan → maklumat)?
3. **Imbangan:** Adakah komposisi keseluruhan terasa seimbang (walaupun tidak semestinya simetri)?
4. **Kontras:** Adakah teks mudah dibaca atas latar belakang gelap? Adakah terdapat cukup variasi visual?

**Langkah 10: Menyimpan Versi Kerja**

1. Simpan versi kerja: **File > Save** (Ctrl+S) — format `.ai`
2. Cipta versi baru jika membuat perubahan ketara: **File > Save As** dengan nombor versi dinaikkan (`_v02.ai`)
3. Dokumen Illustrator mengekalkan semua layers dan data editabel untuk penyuntingan masa depan.

**Langkah 11: Semakan Rakan Sebaya (Peer Review)**

1. Tunjukkan reka bentuk anda kepada rakan di sebelah.
2. Minta rakan menilai menggunakan senarai semak berikut:

| Kriteria | Ya | Tidak | Cadangan |
| --- | --- | --- | --- |
| Tajuk mudah dibaca | | | |
| Hierarki visual jelas | | | |
| Kontras mencukupi | | | |
| Warna harmoni | | | |
| Maklumat acara lengkap | | | |
| Kesan keseluruhan menarik | | | |

3. Catat maklum balas dan buat penambahbaikan yang perlu.

**Langkah 12: Menyimpan Versi Akhir**

1. Setelah puas dengan reka bentuk, simpan versi akhir ke folder `04-working/`.
2. Beri nama `NADAFEST2026_poster_FINAL.ai`.

### Titik Semakan Kualiti / Quality Check Points

- [ ] Dokumen dicipta dengan tetapan yang betul (saiz, mod warna, resolusi)
- [ ] Grid dan garis panduan peraturan satu pertiga telah diaktifkan
- [ ] Palet warna 5 warna telah dipilih dan diselaraskan dengan psikologi warna sasaran audiens
- [ ] Semua elemen teks menggunakan hierarki saiz yang jelas (3 tahap berbeza)
- [ ] Kontras antara teks dan latar belakang adalah mencukupi dan mudah dibaca
- [ ] Reka bentuk mencapai imbangan visual yang harmoni
- [ ] Fail kerja telah disimpan dalam folder yang betul dengan penamaan yang betul
- [ ] Semakan rakan sebaya telah dilakukan dan maklum balas telah diambil kira
