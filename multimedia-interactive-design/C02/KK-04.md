### Tujuan Aktiviti / Activity Purpose

Kertas kerja ini membimbing pelatih untuk mengeksport dan menghasilkan output grafik digital dalam pelbagai format yang sesuai untuk cetakan profesional dan penggunaan digital. Pelatih akan menggunakan fail kerja dari KK-02 (poster festival) dan KK-03 (logo + foto produk) sebagai asas dan mengeksportnya dalam format yang betul untuk pelbagai penggunaan akhir.

*(This work sheet guides trainees to export and produce digital graphic outputs in various formats suitable for professional printing and digital use. Trainees will use working files from KK-02 (festival poster) and KK-03 (logo and product photo) as the basis and export them in the correct formats for various end uses.)*

---

### Peringatan Keselamatan dan Kesihatan / Safety and Health Reminders

1. Jangan menutup perisian semasa proses eksport sedang berjalan — tunggu sehingga selesai.
2. Pastikan terdapat ruang storan yang mencukupi dalam pemacu sebelum mengeksport fail bersaiz besar (TIFF, PDF resolusi tinggi boleh mencapai saiz 100MB+).
3. Simpan fail kerja asal (.ai, .psd) sebelum mengeksport untuk memastikan data editabel terpelihara.
4. Rehatkan mata setiap 20 minit.
5. Sahkan semua tetapan eksport sebelum menekan butang eksport untuk mengelakkan pembaziran masa memproses semula.

### Prosedur Langkah Demi Langkah / Step-by-Step Procedure

#### BAHAGIAN A: Eksport Poster Festival dari Adobe Illustrator

**Langkah 1: Membuka dan Menyemak Fail Poster**

1. Buka Adobe Illustrator.
2. Buka fail `NADAFEST2026_poster_FINAL.ai` dari folder `04-working/`.
3. Semak semula reka bentuk secara menyeluruh:
   - Adakah semua teks menggunakan ejaan yang betul?
   - Adakah semua maklumat acara (tarikh, tempat, tiket) tepat?
   - Adakah semua warna kelihatan seperti yang diingini?
4. Jika perlu penyesuaian terakhir, buat dan simpan terlebih dahulu.

**Langkah 2: Eksport sebagai PDF untuk Cetakan (PDF/X-1a)**

1. Klik **File > Save As** (bukan Export!).
2. Dalam kotak dialog Save As:
   - Format: Adobe PDF (.pdf)
   - Nama fail: `NADAFEST2026_poster_CETAK.pdf`
   - Lokasi: folder `05-output/`
3. Klik **Save**. Kotak dialog Adobe PDF Options akan terbuka.
4. Tetapkan seperti berikut:
   - **Adobe PDF Preset:** PDF/X-1a:2001 (atau "Press Quality")
   - **Standard:** PDF/X-1a:2001
   - **Compatibility:** Acrobat 4 (PDF 1.3) atau lebih tinggi
5. Klik tab **Marks and Bleeds:**
   - Aktifkan: Trim Marks, Registration Marks, Colour Bars, Page Information
   - Bleed: Top 3mm, Bottom 3mm, Left 3mm, Right 3mm
6. Klik tab **Output:**
   - Colour Conversion: Convert to Destination
   - Destination: ISO Coated v2 (atau profil yang ditetapkan pensyarah)
   - Profile Inclusion Policy: Include Destination Profile
7. Klik **Save PDF**.
8. Sahkan output dengan membuka fail PDF dalam Adobe Acrobat Reader.

**Rekod Eksport:**
- Nama fail: ___________________________
- Saiz fail: ___________________________ MB
- Tetapan bleed: _______________________

**Langkah 3: Eksport sebagai JPEG untuk Web/E-mel**

1. Klik **File > Export > Export As**.
2. Dalam kotak dialog Export:
   - Format: JPEG (.jpg)
   - Nama fail: `NADAFEST2026_poster_web.jpg`
   - Lokasi: folder `05-output/`
   - Aktifkan: Use Artboards
3. Klik **Export**.
4. Dalam kotak dialog JPEG Options:
   - Colour Model: RGB
   - Quality: 8 (High) — keseimbangan antara kualiti dan saiz fail
   - Resolution: 150 ppi (cukup untuk e-mel dan paparan skrin)
   - Anti-aliasing: Art Optimised (Supersampling)
5. Klik **OK**.

**Rekod Eksport:**
- Nama fail: ___________________________
- Saiz fail: ___________________________ KB
- Dimensi: ___________________________ px

**Langkah 4: Eksport sebagai PNG untuk Media Sosial**

1. Klik **File > Export > Export for Screens** (Ctrl+Alt+E).
2. Dalam kotak dialog Export for Screens:
   - Pilih tab **Artboards**
   - Format: PNG
   - Scale: Custom, Width: 1200px
3. Klik **Add Scale** jika perlu menambah saiz kedua (628px tinggi untuk Facebook/LinkedIn).
4. Lokasi: folder `05-output/`
5. Klik **Export Artboard**.

**Rekod Eksport:**
- Nama fail: ___________________________
- Saiz fail: ___________________________ KB
- Dimensi akhir: _______________________

---

#### BAHAGIAN B: Eksport Logo NovaTech dari Adobe Illustrator

**Langkah 5: Membuka Fail Logo**

1. Buka fail `NovaTech-Logo_v01.ai` dari folder `04-working/`.
2. Semak bahawa logo kelihatan bersih dan semua elemen teratur dengan baik.
3. Pastikan logo dikumpulkan (grouped): pilih semua elemen, Ctrl+G jika belum dikumpulkan.

**Langkah 6: Eksport Logo sebagai SVG (untuk Web)**

1. Klik **File > Export > Export As**.
2. Format: SVG (.svg)
3. Nama fail: `NovaTech-Logo.svg`
4. Lokasi: folder `05-output/`
5. Klik **Export**.
6. Dalam kotak dialog SVG Options:
   - Styling: Presentation Attributes
   - Font: Convert to Outlines (mengubah teks kepada paths — logo tidak akan berubah jika fon tidak dipasang)
   - Images: Embed
   - Decimal Places: 2
   - Minify: Ya (untuk saiz fail lebih kecil)
   - Responsive: Ya (untuk logo yang responsif pada web)
7. Klik **OK**.
8. Uji output SVG dalam pelayar web — buka fail .svg dalam Chrome atau Firefox untuk memastikan logo kelihatan dengan betul.

**Rekod Eksport:**
- Nama fail: ___________________________
- Saiz fail: ___________________________ KB

**Langkah 7: Eksport Logo sebagai PNG dengan Latar Telus**

1. Klik **File > Export > Export for Screens** (Ctrl+Alt+E).
2. Format: PNG
3. Scale 1x: 500px (saiz asal)
4. Tambah Scale 2x: 1000px (untuk Retina/HiDPI)
5. Aktifkan: **Transparent Background** (Latar Telus)
6. Nama fail: `NovaTech-Logo` (sistem akan auto menambah `@1x` dan `@2x`)
7. Lokasi: folder `05-output/`
8. Klik **Export Artboard**.

**Rekod Eksport:**
- Nama fail @1x: _____________________, Saiz: ___________ KB
- Nama fail @2x: _____________________, Saiz: ___________ KB

**Langkah 8: Eksport Logo sebagai EPS (untuk Pencetak/Vendor)**

1. Klik **File > Save As**.
2. Format: Illustrator EPS (.eps)
3. Nama fail: `NovaTech-Logo.eps`
4. Lokasi: folder `05-output/`
5. Klik **Save**.
6. Dalam kotak dialog EPS Options:
   - Version: Illustrator 8 EPS (keserasian meluas)
   - Preview: TIFF (8-bit Colour)
   - Fonts: Embed Fonts — atau Convert to Outlines terlebih dahulu sebelum eksport
7. Klik **OK**.

---

#### BAHAGIAN C: Eksport Foto Produk dari Adobe Photoshop

**Langkah 9: Membuka Fail Foto Produk**

1. Buka Adobe Photoshop.
2. Buka fail `foto-produk_v01.psd` dari folder `04-working/`.
3. Semak semua Adjustment Layers dan mask masih berfungsi dengan betul.

**Langkah 10: Eksport sebagai JPEG untuk Web**

1. Klik **File > Export > Export As** (Ctrl+Alt+Shift+W).
2. Dalam kotak dialog Export As:
   - Format: JPG
   - Quality: 80%
   - Resize Image: Width 1200px (kekalkan nisbah)
   - Resolution: 72 ppi
   - Colour Space: sRGB (Convert to sRGB jika dalam CMYK)
   - Metadata: None (untuk mengurangkan saiz fail)
3. Klik **Export All**.
4. Nama fail: `foto-produk_web.jpg`
5. Lokasi: folder `05-output/`

**Rekod Eksport:**
- Nama fail: ___________________________
- Saiz fail: ___________________________ KB
- Dimensi: ___________________________ px

**Langkah 11: Eksport sebagai TIFF untuk Cetakan**

1. Klik **File > Save As**.
2. Format: TIFF
3. Nama fail: `foto-produk_cetak.tiff`
4. Lokasi: folder `05-output/`
5. Klik **Save**.
6. Dalam kotak dialog TIFF Options:
   - Image Compression: LZW (lossless compression untuk mengurangkan saiz tanpa kehilangan kualiti)
   - Pixel Order: Interleaved (RGBRGB)
   - Byte Order: IBM PC (Windows)
   - Layer Compression: Discard Layers and Save a Copy
7. Klik **OK**.

**Rekod Eksport:**
- Nama fail: ___________________________
- Saiz fail: ___________________________ MB
- Resolusi: ___________________________ DPI

**Langkah 12: Semakan Kualiti Semua Output**

Semak setiap fail output menggunakan jadual berikut:

| Fail Output | Format | Saiz Fail | Resolusi | Semak Kualiti | OK? |
| --- | --- | --- | --- | --- | --- |
| Poster_CETAK.pdf | PDF/X-1a | | | Buka dalam Acrobat, semak bleed marks | |
| Poster_web.jpg | JPEG | | 150 ppi | Buka dalam pelayar, semak ketajaman | |
| Poster_sosmed.png | PNG | | 72 ppi | Saiz 1200x628px, semak visual | |
| Logo.svg | SVG | | Vektor | Buka dalam Chrome, uji resize | |
| Logo@1x.png | PNG | | 72 ppi | Latar telus, 500px | |
| Logo@2x.png | PNG | | 144 ppi | Latar telus, 1000px | |
| Logo.eps | EPS | | Vektor | Semak boleh dibuka | |
| Foto_web.jpg | JPEG | | 72 ppi | Semak kualiti warna | |
| Foto_cetak.tiff | TIFF | | 300 ppi | Semak resolusi tinggi | |

**Langkah 13: Mengorganisasi Folder Output**

1. Semak bahawa folder `05-output/` mengandungi semua fail output.
2. Cipta subfolder dalam `05-output/` untuk mengatur output mengikut tujuan:
   ```
   05-output/
   ├── cetak/       ← PDF, TIFF, EPS
   ├── web/         ← JPEG, PNG, SVG untuk web
   └── sosmed/      ← PNG untuk media sosial
   ```
3. Pindahkan fail output ke subfolder yang sesuai.

**Langkah 14: Mencipta Senarai Semak Penghantaran**

Cipta dokumen teks ringkas dalam folder `05-output/` bernama `README_output.txt` yang mengandungi:
- Nama projek dan tarikh
- Senarai fail yang dihantar
- Arahan penggunaan setiap fail
- Nama pelatih dan pensyarah

### Titik Semakan Kualiti / Quality Check Points

- [ ] Poster cetakan (PDF/X-1a) mengandungi crop marks dan bleed 3mm yang betul
- [ ] Poster web (JPEG) berukuran sesuai dan kualiti yang boleh diterima
- [ ] Poster media sosial (PNG) berukuran 1200x628px dengan kualiti tinggi
- [ ] Logo SVG boleh diskala tanpa pixelation dalam pelayar web
- [ ] Logo PNG mempunyai latar belakang telus (checkerboard pattern kelihatan dalam perisian)
- [ ] Logo EPS dapat dibuka dalam Illustrator tanpa ralat
- [ ] Foto web (JPEG 72 PPI) bersaiz sesuai untuk muat naik ke laman web
- [ ] Foto cetakan (TIFF 300 DPI) berkualiti tinggi untuk cetakan
- [ ] Semua fail output diatur dalam subfolder yang betul
- [ ] README_output.txt dicipta dan lengkap
