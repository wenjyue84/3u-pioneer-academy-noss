### Objektif Pembelajaran / Learning Objectives

Pada akhir sesi teori ini, pelatih akan dapat / By the end of this theory session, trainees will be able to:

1. Mengenal pasti dan menghuraikan prinsip-prinsip reka bentuk termasuk komposisi, hierarki, imbangan dan kontras. / Identify and describe design principles including composition, hierarchy, balance and contrast.
2. Menerangkan model warna, palet warna dan psikologi warna dalam rekabentuk grafik digital. / Explain colour models, colour palettes and colour psychology in digital graphic design.
3. Memilih jenis taip yang sesuai dan mengaplikasikan prinsip tipografi untuk keterbacaan. / Select appropriate typefaces and apply typography principles for readability.
4. Menghuraikan teknik ilustrasi digital, penyuntingan foto dan manipulasi imej. / Describe techniques for digital illustration, photo editing and image manipulation.
5. Menyediakan ruang kerja rekabentuk grafik digital mengikut keperluan projek. / Set up a digital graphic design workspace according to project requirements.
6. Mengenal pasti format fail dan tetapan eksport yang sesuai untuk pelbagai output. / Identify appropriate file formats and export settings for various outputs.

### Kandungan Pengajaran / Teaching Content

#### SESI 1: Prinsip Reka Bentuk / Design Principles (3 jam / 3 hours)

**Berkaitan Aktiviti Kerja / Related to Work Activity:** WA-02

| Masa | Topik | Kaedah Pengajaran |
| --- | --- | --- |
| 0:00 – 0:30 | Pengenalan kepada reka bentuk grafik digital / Introduction to digital graphic design | Kuliah, tayangan slaid |
| 0:30 – 1:15 | Komposisi: peraturan satu pertiga, garis panduan, grid / Composition: rule of thirds, guides, grid | Kuliah, demonstrasi |
| 1:15 – 2:00 | Hierarki visual: saiz, warna, kontras / Visual hierarchy: size, colour, contrast | Kuliah, analisis contoh |
| 2:00 – 2:45 | Imbangan: simetri, asimetri, radial / Balance: symmetry, asymmetry, radial | Kuliah, latihan analisis |
| 2:45 – 3:00 | Kontras: nilai, warna, tekstur, saiz / Contrast: value, colour, texture, size | Perbincangan kumpulan |

**Isi Kandungan Utama / Key Content:**

- **Komposisi (Composition):** Susunan elemen visual dalam ruang reka bentuk. Peraturan satu pertiga (rule of thirds) membahagikan kanvas kepada sembilan bahagian yang sama untuk penempatan elemen utama. Grid sistem membantu menyelaraskan elemen secara konsisten. White space (ruang kosong) memainkan peranan penting dalam keterbacaan.

- **Hierarki Visual (Visual Hierarchy):** Pengaturan elemen mengikut kepentingan untuk membimbing pandangan pengguna. Elemen paling penting diberi saiz, warna atau kedudukan yang menonjol. Kontras dan saiz digunakan untuk mewujudkan hierarki yang jelas.

- **Imbangan (Balance):** Taburan berat visual dalam komposisi. Imbangan simetri mencipta rasa formal dan stabil. Imbangan asimetri menghasilkan reka bentuk yang dinamik. Imbangan radial memancar dari titik pusat.

- **Kontras (Contrast):** Perbezaan antara elemen untuk mewujudkan minat visual dan mengarahkan perhatian. Kontras warna, saiz, bentuk dan tekstur digunakan secara strategik.

#### SESI 2: Teori Warna / Colour Theory (3 jam / 3 hours)

**Berkaitan Aktiviti Kerja / Related to Work Activity:** WA-02

| Masa | Topik | Kaedah Pengajaran |
| --- | --- | --- |
| 0:00 – 0:45 | Model warna: RGB, CMYK, HSB / Colour models: RGB, CMYK, HSB | Kuliah, demonstrasi perisian |
| 0:45 – 1:30 | Roda warna dan perhubungan warna / Colour wheel and colour relationships | Kuliah, latihan praktikal |
| 1:30 – 2:15 | Palet warna: monokromatik, analog, komplementari / Colour palettes: monochromatic, analogous, complementary | Demonstrasi, latihan |
| 2:15 – 3:00 | Psikologi warna dalam reka bentuk / Colour psychology in design | Kajian kes, perbincangan |

**Isi Kandungan Utama / Key Content:**

- **Model Warna (Colour Models):** RGB (Merah, Hijau, Biru) digunakan untuk media skrin digital. CMYK (Cyan, Magenta, Kuning, Hitam) digunakan untuk cetakan. HSB (Hue, Saturation, Brightness) memudahkan pemilihan warna secara intuitif.

- **Perhubungan Warna (Colour Relationships):** Skim warna komplementari menggunakan warna bertentangan pada roda warna. Skim analog menggunakan warna bersebelahan. Skim triadik menggunakan tiga warna yang sama jarak.

- **Psikologi Warna (Colour Psychology):** Warna merah membangkitkan semangat dan urgensi. Biru mewakili kepercayaan dan profesionalisme. Hijau dikaitkan dengan alam dan kesihatan. Pemahaman psikologi warna penting dalam komunikasi visual yang berkesan.

---

#### SESI 3: Tipografi / Typography (3 jam / 3 hours)

**Berkaitan Aktiviti Kerja / Related to Work Activity:** WA-02, WA-03

| Masa | Topik | Kaedah Pengajaran |
| --- | --- | --- |
| 0:00 – 0:45 | Klasifikasi jenis taip: serif, sans-serif, script, display / Typeface classification | Kuliah, analisis visual |
| 0:45 – 1:30 | Anatomi jenis taip dan istilah tipografi / Typeface anatomy and typography terms | Kuliah, latihan pengecaman |
| 1:30 – 2:15 | Keterbacaan: saiz, jarak baris, jarak huruf / Readability: size, line spacing, letter spacing | Demonstrasi, latihan |
| 2:15 – 3:00 | Padanan jenis taip dan hierarki tipografi / Typeface pairing and typographic hierarchy | Demonstrasi, kajian kes |

**Isi Kandungan Utama / Key Content:**

- **Klasifikasi Jenis Taip:** Serif (Times New Roman, Georgia) sesuai untuk teks panjang dalam cetakan. Sans-serif (Arial, Helvetica, Roboto) sesuai untuk paparan digital. Script meniru tulisan tangan, digunakan untuk aksen dekoratif. Display digunakan untuk tajuk besar.

- **Keterbacaan:** Saiz minimum 12pt untuk teks badan dalam cetakan, 14-16px untuk skrin. Jarak baris (line height) 1.4-1.6 kali saiz fon untuk keterbacaan optimum. Jarak huruf (kerning/tracking) disesuaikan untuk keselesaan bacaan.

- **Padanan Jenis Taip:** Padankan maksimum dua atau tiga jenis taip dalam satu reka bentuk. Gunakan satu jenis taip untuk tajuk dan satu untuk teks badan. Pastikan kontras yang jelas antara jenis taip yang dipilih.

---

#### SESI 4: Ilustrasi Digital dan Penyuntingan Imej / Digital Illustration and Image Editing (3 jam / 3 hours)

**Berkaitan Aktiviti Kerja / Related to Work Activity:** WA-01, WA-03, WA-04

| Masa | Topik | Kaedah Pengajaran |
| --- | --- | --- |
| 0:00 – 0:30 | Penyediaan ruang kerja: perisian, antara muka, tetapan / Workspace setup: software, interface, settings | Demonstrasi, panduan langkah demi langkah |
| 0:30 – 1:15 | Imej vektor vs imej raster / Vector vs raster images | Kuliah, demonstrasi perbandingan |
| 1:15 – 2:00 | Teknik ilustrasi digital: pen tool, bezier curves, layers / Digital illustration techniques | Demonstrasi, perbincangan |
| 2:00 – 2:45 | Penyuntingan foto: penyesuaian, penapisan, masking / Photo editing: adjustments, filters, masking | Demonstrasi, latihan |
| 2:45 – 3:00 | Format fail dan eksport: JPEG, PNG, SVG, PDF / File formats and export | Kuliah, demonstrasi |

**Isi Kandungan Utama / Key Content:**

- **Penyediaan Ruang Kerja:** Konfigurasi panel dan ruang kerja mengikut tugasan. Tetapan unit ukuran (px, mm, cm) mengikut keperluan output. Pengurusan fail projek menggunakan struktur folder yang sistematik.

- **Vektor vs Raster:** Imej vektor berasaskan persamaan matematik, boleh diskala tanpa kehilangan kualiti, sesuai untuk logo dan ilustrasi. Imej raster berasaskan piksel, resolusi bergantung pada saiz asal, sesuai untuk foto.

- **Teknik Illustrasi Digital:** Pen tool digunakan untuk mencipta laluan (paths) yang tepat. Layer digunakan untuk mengasingkan elemen reka bentuk bagi kemudahan penyuntingan. Blend mode dan opacity mengawal cara layer berinteraksi.

- **Penyuntingan Foto:** Penyesuaian asas: kecerahan, kontras, tepu warna, imbangan warna. Teknik masking untuk memisahkan objek dari latar belakang. Penapis (filters) untuk kesan artistik dan pembetulan imej.

- **Format Fail dan Eksport:** JPEG untuk foto dengan saiz fail kecil. PNG untuk imej dengan ketelusan. SVG untuk grafik vektor pada web. PDF untuk cetakan berkualiti tinggi.
