## Tajuk / Title: Interactive Multimedia Concepts: Interactivity, Navigation and User Experience (UX)

---

## 1. Objektif Pembelajaran / Learning Objectives

Selepas mempelajari Kertas Penerangan ini, pelatih akan dapat / After studying this Information Sheet, trainees will be able to:

1. Mendefinisikan multimedia interaktif dan membezakannya daripada multimedia linear / Define interactive multimedia and differentiate it from linear multimedia.
2. Mengenal pasti dan menerangkan jenis-jenis interaktiviti dalam produk multimedia / Identify and explain types of interactivity in multimedia products.
3. Menerangkan model-model navigasi yang digunakan dalam multimedia interaktif / Explain navigation models used in interactive multimedia.
4. Mengaplikasikan prinsip Pengalaman Pengguna (UX) dalam proses reka bentuk struktur multimedia interaktif / Apply User Experience (UX) principles in the interactive multimedia structure design process.
5. Menghasilkan peta struktur dan carta alir navigasi untuk projek multimedia interaktif / Produce structure maps and navigation flowcharts for interactive multimedia projects.

---

## 2. Definisi Multimedia Interaktif / Definition of Interactive Multimedia

### 2.1 Multimedia

**Multimedia** merujuk kepada gabungan dua atau lebih media dalam satu persembahan digital. Media tersebut termasuk:

| Jenis Media / Media Type | Contoh / Example |
|--------------------------|------------------|
| Teks / Text | Skrip, kapsyen, label / Scripts, captions, labels |
| Grafik / Graphics | Ilustrasi, foto, ikon / Illustrations, photos, icons |
| Audio | Muzik, kesan bunyi, suara latar / Music, sound effects, narration |
| Video | Klip video, animasi / Video clips, animation |
| Animasi / Animation | Animasi 2D/3D, motion graphics |

### 2.2 Multimedia Interaktif / Interactive Multimedia

**Multimedia interaktif** ialah sistem multimedia yang membenarkan pengguna mengawal urutan, kandungan, atau persembahan melalui tindakan atau input pengguna. Pengguna bukan sekadar penonton pasif — mereka boleh membuat pilihan, mengklik, menjawab soalan, atau menavigasi mengikut kehendak mereka sendiri.

**Definisi (JPK):** Multimedia interaktif ialah gabungan pelbagai media digital yang dikawal oleh pengguna melalui antara muka yang membolehkan input aktif, menjadikan pengalaman lebih bermakna dan berpusatkan pengguna.

### 2.3 Perbezaan Multimedia Linear dan Multimedia Interaktif / Differences Between Linear and Interactive Multimedia

| Aspek | Multimedia Linear | Multimedia Interaktif |
|-------|-------------------|----------------------|
| Kawalan pengguna / User control | Tiada / None | Ada / Present |
| Urutan / Sequence | Tetap / Fixed | Boleh dipilih / Selectable |
| Contoh / Example | Video siaran TV / Broadcast TV video | Laman web, e-pembelajaran / Website, e-learning |
| Maklum balas / Feedback | Tiada / None | Segera / Immediate |
| Penglibatan / Engagement | Pasif / Passive | Aktif / Active |

## 3. Jenis-Jenis Interaktiviti / Types of Interactivity

Interaktiviti dalam multimedia boleh dibahagikan kepada beberapa tahap dan jenis:

### 3.1 Tahap Interaktiviti / Levels of Interactivity

| Tahap / Level | Penerangan / Description | Contoh / Example |
|---------------|--------------------------|------------------|
| **Tahap 1 — Reaktif** | Pengguna hanya boleh memulakan dan menghentikan kandungan / User can only start and stop content | Butang main/berhenti video / Video play/stop button |
| **Tahap 2 — Kawalan Terbatas** | Pengguna boleh memilih kandungan dari senarai terhad / User can select content from limited list | Menu utama dengan 3-5 pilihan / Main menu with 3–5 options |
| **Tahap 3 — Kompleks** | Pengguna boleh memasukkan data, menjawab soalan, membuat keputusan / User can input data, answer questions, make decisions | Kuiz interaktif, simulasi / Interactive quiz, simulation |
| **Tahap 4 — Real-time** | Sistem bertindak balas kepada input pengguna secara masa nyata / System responds to user input in real time | Permainan video, aplikasi AR / Video games, AR applications |

### 3.2 Jenis Interaktiviti Berdasarkan Tindakan Pengguna / Types Based on User Action

1. **Interaktiviti Navigasi / Navigation Interactivity** — Pengguna bergerak antara skrin atau bahagian / User moves between screens or sections.
2. **Interaktiviti Maklum Balas / Feedback Interactivity** — Sistem memberikan respons kepada input pengguna (contoh: betul/salah dalam kuiz) / System responds to user input (e.g., correct/wrong in quiz).
3. **Interaktiviti Manipulasi / Manipulation Interactivity** — Pengguna boleh mengubah elemen dalam persekitaran digital / User can modify elements in the digital environment.
4. **Interaktiviti Pencarian / Search Interactivity** — Pengguna mencari dan mendapatkan semula maklumat / User searches and retrieves information.
5. **Interaktiviti Komunikasi / Communication Interactivity** — Pengguna berkomunikasi dengan sistem atau pengguna lain / User communicates with the system or other users.

## 4. Model Navigasi / Navigation Models

Navigasi dalam multimedia interaktif menentukan cara pengguna bergerak melalui kandungan. Pemilihan model navigasi yang sesuai adalah kritikal untuk UX yang baik.

### 4.1 Model Linear / Linear Model

Pengguna bergerak dari satu skrin ke skrin berikutnya dalam urutan yang ditetapkan.

```
[Skrin 1] → [Skrin 2] → [Skrin 3] → [Skrin 4]
```

- **Kelebihan:** Mudah dibangunkan; sesuai untuk tutorial langkah demi langkah.
- **Kelemahan:** Tiada fleksibiliti; pengguna tidak boleh melangkau kandungan.
- **Kegunaan:** Tutorial prosedur, demo produk.

### 4.2 Model Hierarki / Hierarchical Model

Kandungan disusun dalam struktur pepohon (tree structure) dengan menu utama dan sub-menu.

```
         [Menu Utama]
        /      |      \
  [Bab 1]  [Bab 2]  [Bab 3]
  /    \      |
[1.1] [1.2] [2.1]
```

- **Kelebihan:** Teratur dan mudah difahami; sesuai untuk kandungan berskala besar.
- **Kelemahan:** Pengguna mungkin tersesat dalam struktur yang terlalu dalam.
- **Kegunaan:** Ensiklopedia digital, kursus e-pembelajaran.

### 4.3 Model Bercabang / Branching Model

Pengguna membuat pilihan di titik tertentu yang menentukan laluan seterusnya.

```
[Permulaan] → [Soalan] → [Pilihan A] → [Hasil A]
                       → [Pilihan B] → [Hasil B]
```

- **Kelebihan:** Membolehkan pengalaman yang diperibadikan; sesuai untuk simulasi.
- **Kelemahan:** Pembangunan lebih kompleks; keperluan kandungan yang banyak.
- **Kegunaan:** Simulasi latihan, senario peranan (role-play scenarios).

### 4.4 Model Bukan Linear / Non-Linear (Free Navigation) Model

Pengguna boleh mengakses mana-mana kandungan pada bila-bila masa tanpa sebarang urutan yang ditetapkan.

- **Kelebihan:** Kebebasan penuh kepada pengguna.
- **Kelemahan:** Boleh menyebabkan kekeliruan; sukar untuk memastikan pengguna melengkapkan kandungan.
- **Kegunaan:** Ensiklopedia, laman web portal.

### 4.5 Model Komposit / Composite Model

Gabungan dua atau lebih model navigasi dalam satu produk multimedia.

- **Kegunaan:** Kebanyakan produk multimedia profesional menggunakan model ini.

## 5. Pengalaman Pengguna (UX) / User Experience (UX)

### 5.1 Definisi UX

**Pengalaman Pengguna (UX)** merujuk kepada keseluruhan pengalaman seseorang apabila berinteraksi dengan produk atau sistem digital, termasuk perasaan, emosi, persepsi, dan tindak balas mereka.

UX yang baik memastikan pengguna dapat mencapai matlamat mereka dengan mudah, cepat, dan menyeronokkan.

### 5.2 Komponen UX / UX Components

| Komponen | Penerangan / Description |
|----------|--------------------------|
| **Kebolehgunaan / Usability** | Kemudahan penggunaan sistem / Ease of use of the system |
| **Aksesibiliti / Accessibility** | Keupayaan digunakan oleh semua pengguna termasuk OKU / Ability to be used by all users including PWD |
| **Kebolehdapatan / Findability** | Kemudahan mencari maklumat / Ease of finding information |
| **Kebolehpercayaan / Credibility** | Kepercayaan pengguna terhadap sistem / User trust in the system |
| **Keinginan / Desirability** | Tarikan visual dan emosi / Visual and emotional appeal |
| **Nilai / Value** | Faedah yang diperoleh pengguna / Benefits obtained by user |

### 5.3 Prinsip UX dalam Multimedia Interaktif / UX Principles in Interactive Multimedia

1. **Konsistensi / Consistency** — Elemen navigasi, warna, dan tipografi harus konsisten di seluruh produk.
2. **Maklum Balas Segera / Immediate Feedback** — Sistem mesti memberi respons kepada setiap tindakan pengguna (contoh: butang berubah warna apabila diklik).
3. **Kawalan Pengguna / User Control** — Pengguna mesti berasa mereka mengawal pengalaman, bukan dikawal oleh sistem.
4. **Pencegahan Ralat / Error Prevention** — Reka bentuk yang menghalang pengguna daripada melakukan kesilapan adalah lebih baik daripada mesej ralat.
5. **Fleksibiliti / Flexibility** — Sediakan jalan pintas untuk pengguna berpengalaman sambil mengekalkan kemudahan untuk pengguna baharu.
6. **Estetik dan Reka Bentuk Minimalis / Aesthetic and Minimalist Design** — Elakkan maklumat yang tidak relevan; setiap elemen mesti mempunyai tujuan.

### 5.4 Proses Reka Bentuk Berpusatkan Pengguna / User-Centred Design Process

```

     (User Research)       (Problem Definition)  (Ideation)  (Prototype)    (Testing)    (Implementation)
```

## 6. Peta Struktur dan Carta Alir / Structure Maps and Flowcharts

### 6.1 Peta Struktur (Structure Map / Site Map)

Peta struktur menggambarkan hierarki dan hubungan antara semua skrin atau halaman dalam produk multimedia interaktif.

**Simbol yang digunakan / Symbols used:**
- Segiempat tepat / Rectangle — Skrin / halaman / Screen / page
- Anak panah / Arrow — Arah navigasi / Navigation direction
- Belah ketupat / Diamond — Titik keputusan / Decision point

### 6.2 Carta Alir (Flowchart)

Carta alir menggambarkan aliran proses dan logik navigasi secara terperinci, termasuk syarat dan tindakan.

**Kepentingan Peta Struktur dan Carta Alir:**
- Membantu pasukan pembangunan memahami skop projek
- Mengesan potensi masalah navigasi sebelum pembangunan bermula
- Memudahkan komunikasi dengan klien
- Menjadi rujukan semasa pembangunan dan pengujian

## 7. Istilah Penting / Key Terms

| Istilah (EN) | Istilah (BM) | Definisi Ringkas / Brief Definition |
|--------------|--------------|--------------------------------------|
| Interactivity | Interaktiviti | Kebolehan pengguna untuk mengawal atau mempengaruhi kandungan / Ability of user to control or influence content |

| User Experience (UX) | Pengalaman Pengguna | Keseluruhan pengalaman pengguna dengan produk digital / Overall user experience with a digital product |

| Flowchart | Carta Alir | Gambar rajah yang menggambarkan aliran proses / Diagram illustrating process flow |

| Linear Navigation | Navigasi Linear | Navigasi berurutan dari satu skrin ke skrin berikutnya / Sequential navigation from one screen to next |
| Branching | Percabangan | Laluan pelbagai pilihan dalam navigasi / Multiple-choice pathways in navigation |

---

## 8. Rumusan / Summary

Multimedia interaktif menggabungkan pelbagai jenis media dengan kawalan pengguna aktif, menjadikannya berbeza daripada multimedia linear. Terdapat empat model navigasi utama — linear, hierarki, bercabang, dan bukan linear — setiap satu sesuai untuk tujuan yang berbeza. Prinsip UX memastikan produk multimedia interaktif mudah digunakan, konsisten, dan memberikan pengalaman positif kepada pengguna. Peta struktur dan carta alir adalah alat penting dalam fasa reka bentuk untuk merancang navigasi dan struktur kandungan sebelum pembangunan bermula.
