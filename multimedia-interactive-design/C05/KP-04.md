## Tajuk / Title: User Interface (UI) Design Principles for Interactive Media

---

## 1. Objektif Pembelajaran / Learning Objectives

Selepas mempelajari Kertas Penerangan ini, pelatih akan dapat / After studying this Information Sheet, trainees will be able to:

1. Mendefinisikan Reka Bentuk Antara Muka Pengguna (UI) dan membezakannya daripada UX / Define User Interface (UI) Design and differentiate it from UX.
2. Mengaplikasikan prinsip-prinsip reka bentuk visual dalam rekabentuk antara muka multimedia interaktif / Apply visual design principles in interactive multimedia interface design.
3. Mereka bentuk elemen kawalan navigasi yang berkesan (butang, menu, ikon) / Design effective navigation control elements (buttons, menus, icons).
4. Memilih tipografi dan skema warna yang sesuai untuk antara muka media interaktif / Select appropriate typography and colour schemes for interactive media interfaces.
5. Menghasilkan prototaip wireframe antara muka pengguna untuk projek multimedia / Produce wireframe prototypes of user interfaces for multimedia projects.

---

## 2. Pengenalan Reka Bentuk UI / Introduction to UI Design

### 2.1 Definisi UI / Definition of UI

**Antara Muka Pengguna (User Interface / UI)** merujuk kepada semua elemen visual dan interaktif yang digunakan oleh pengguna untuk berinteraksi dengan sesebuah produk digital. UI adalah "wajah" sesuatu produk — apa yang pengguna lihat, sentuh, dan klik.

### 2.2 Perbezaan UI dan UX / Difference Between UI and UX

| Aspek | UI (Antara Muka Pengguna) | UX (Pengalaman Pengguna) |
|-------|--------------------------|--------------------------|
| **Fokus** | Rupa dan rasa visual / Look and visual feel | Keseluruhan pengalaman / Overall experience |
| **Soalan** | "Adakah ia kelihatan baik?" / "Does it look good?" | "Adakah ia berfungsi dengan baik?" / "Does it work well?" |
| **Elemen** | Warna, tipografi, ikon, butang / Colour, typography, icons, buttons | Aliran pengguna, senibina maklumat / User flow, information architecture |
| **Masa** | Semasa pembangunan / During development | Dari kajian hingga selepas pelancaran / From research to post-launch |
| **Output** | Fail reka bentuk (Figma, Photoshop) | Persona, wireframe, peta perjalanan / Personas, wireframes, journey maps |

**Pertalian:** UI yang baik adalah komponen penting UX yang baik. Produk boleh mempunyai UX yang sempurna tetapi UI yang buruk — dan pengalaman pengguna akan terjejas.

---

## 3. Prinsip Reka Bentuk Visual / Visual Design Principles

### 3.1 Hierarki Visual / Visual Hierarchy

Hierarki visual memandu mata pengguna kepada elemen yang paling penting terlebih dahulu, kemudian kepada elemen yang kurang penting.

**Teknik mencipta hierarki visual:**
- **Saiz / Size** — Elemen yang lebih besar kelihatan lebih penting.
- **Warna / Colour** — Warna terang atau kontras tinggi menarik perhatian.
- **Jarak / Spacing** — Ruang putih (white space) mengasingkan dan menonjolkan elemen.
- **Kedudukan / Position** — Elemen di atas dan kiri biasanya dilihat dahulu (pembaca Latin).
- **Tipografi / Typography** — Teks yang lebih besar, tebal, atau berwarna berbeza kelihatan lebih penting.

### 3.2 Keseimbangan / Balance

Keseimbangan memberikan kestabilan visual kepada reka bentuk.

| Jenis Keseimbangan | Penerangan | Contoh Penggunaan |
|-------------------|------------|-------------------|
| **Simetri / Symmetrical** | Kedua-dua belah sama berat / Both sides equal weight | Halaman utama formal, logo |
| **Asimetri / Asymmetrical** | Kedua-dua belah berbeza tetapi seimbang / Different sides but balanced | Reka bentuk moden, dinamik |
| **Radial** | Elemen mengelilingi pusat / Elements surrounding a centre | Infografik bulatan, menu pie |

### 3.3 Perpaduan dan Konsistensi / Unity and Consistency

Perpaduan memastikan semua elemen dalam reka bentuk kelihatan seperti sebahagian daripada satu entiti yang kohesif.

**Cara mencapai perpaduan:**
- Gunakan palet warna yang terhad (3–5 warna utama)
- Gunakan satu atau dua keluarga fon sahaja
- Gunakan gaya ikon yang konsisten (semuanya bergaris atau semua berisi)
- Gunakan saiz dan jarak yang konsisten (gunakan sistem grid)

### 3.4 Kontras / Contrast

Kontras memudahkan pembezaan antara elemen dan meningkatkan keterbacaan.

- **Kontras Warna** — Teks gelap pada latar cerah, atau sebaliknya.
- **Kontras Saiz** — Tajuk besar berbanding teks badan kecil.
- **Kontras Bentuk** — Butang bulat berbanding latar segi empat.

**Nisbah kontras minimum (WCAG 2.1):**
- Teks biasa: 4.5:1
- Teks besar (18pt+): 3:1

### 3.5 Perpaduan dan Kedekatan / Proximity

Elemen yang berkaitan harus diletakkan berdekatan antara satu sama lain, manakala elemen yang tidak berkaitan harus diasingkan.

## 4. Reka Bentuk Elemen Kawalan Navigasi / Navigation Control Element Design

### 4.1 Reka Bentuk Butang / Button Design

Butang adalah elemen interaktif yang paling asas dalam multimedia interaktif.

**Prinsip Reka Bentuk Butang:**
1. **Kelihatan seperti butang (affordance)** — Pengguna mesti dapat mengenal pasti bahawa ia boleh diklik.
2. **Saiz yang mencukupi** — Minimum 44×44 piksel (piawaian Apple/Google) untuk skrin sentuh.
3. **Maklum balas visual** — Berubah penampilan apabila dihover, diklik, atau dilumpuhkan.
4. **Label yang jelas** — Gunakan kata kerja tindakan: "Muat Turun", "Seterusnya", "Cuba Lagi".
5. **Warna yang konsisten** — Butang utama satu warna; butang sekunder warna berbeza.

**Keadaan Butang (Button States):**

| Keadaan | Penerangan | Petua Visual |
|---------|------------|--------------|
| **Normal** | Keadaan lalai / Default state | Warna asas butang |
| **Hover** | Kursor di atas butang / Cursor over button | Cerahkan atau gelapkan sedikit |
| **Pressed / Active** | Butang sedang diklik / Button being clicked | Gerakkan ke bawah sedikit; gelapkan |
| **Disabled** | Butang tidak aktif / Button not active | Pudarkan warna (opacity rendah) |
| **Focused** | Dipilih melalui papan kekunci / Selected via keyboard | Tambah garisan sempadan (outline) |

### 4.2 Reka Bentuk Menu Navigasi / Navigation Menu Design

| Jenis Menu | Penerangan | Kegunaan Terbaik |
|-----------|------------|-----------------|
| **Menu Mendatar / Horizontal Menu** | Bar navigasi di bahagian atas / Navigation bar at top | Laman web, e-pembelajaran dengan sedikit kategori |
| **Menu Menegak / Vertical Menu** | Panel navigasi di sisi / Side navigation panel | Aplikasi dengan banyak kategori |
| **Menu Hamburger** | Ikon 3 garisan yang menyembunyikan menu / 3-line icon hiding menu | Reka bentuk mudah alih (mobile) |
| **Menu Dropdown** | Menu yang muncul apabila item diklik / Menu appearing when item clicked | Navigasi bertingkat / Multilevel navigation |
| **Breadcrumb** | Jejak laluan pengguna / User path trail | Sistem dengan hierarki dalam |
| **Tab Navigation** | Bar tab mendatar / Horizontal tab bar | Kandungan berkategori pada satu halaman |

### 4.3 Reka Bentuk Ikon / Icon Design

- Ikon mesti universal dan mudah difahami.
- Gunakan label teks bersama ikon untuk kejelasan.
- Pastikan saiz ikon konsisten dalam seluruh produk.
- Gunakan ikon daripada set yang sama (contoh: Font Awesome, Material Icons).

## 5. Tipografi dalam Media Interaktif / Typography in Interactive Media

### 5.1 Prinsip Pemilihan Fon / Font Selection Principles

| Prinsip | Penerangan |
|---------|------------|
| **Keterbacaan / Readability** | Fon mesti mudah dibaca pada saiz paparan skrin |
| **Hierarki / Hierarchy** | Gunakan variasi saiz, berat (weight), dan gaya untuk hierarki |
| **Keserasian / Compatibility** | Fon mesti tersedia atau dimuatkan dari web (Google Fonts) |
| **Bilangan Terhad** | Gunakan maksimum 2–3 keluarga fon dalam satu projek |
| **Padan dengan Nada** | Fon serif untuk formaliti; sans-serif untuk moden dan bersih |

### 5.2 Jenis-Jenis Fon / Types of Fonts

| Jenis | Ciri | Contoh | Kegunaan |
|-------|------|--------|----------|
| **Serif** | Ada kaki kecil di hujung huruf | Georgia, Times New Roman | Kandungan teks panjang; suasana formal |
| **Sans-Serif** | Tiada kaki; garisan bersih | Arial, Helvetica, Roboto | Antara muka digital; mudah dibaca pada skrin |
| **Display / Decorative** | Ornamental; berciri kuat | Impact, Lobster | Tajuk besar; bukan untuk teks badan |
| **Monospace** | Setiap huruf lebar sama | Courier, Consolas | Kod pengaturcaraan; output terminal |

### 5.3 Hierarki Tipografi / Typographic Hierarchy

| Elemen | Saiz Disyorkan | Berat | Contoh Penggunaan |
|--------|----------------|-------|-------------------|
| **H1 (Tajuk Utama)** | 32–48 px | Bold | Nama produk, tajuk halaman |
| **H2 (Tajuk Bahagian)** | 24–32 px | Bold / Semi-Bold | Tajuk bahagian |
| **H3 (Sub-tajuk)** | 18–24 px | Semi-Bold | Sub-bahagian |
| **Teks Badan** | 14–18 px | Regular | Kandungan utama |
| **Kapsyen / Caption** | 11–13 px | Regular / Light | Kapsyen imej, nota kaki |
| **Label Butang** | 14–16 px | Medium / Bold | Teks pada butang |

## 6. Teori Warna dalam Antara Muka Pengguna / Colour Theory in UI

### 6.1 Model Warna / Colour Models

| Model | Penggunaan | Komponen |
|-------|------------|----------|
| **RGB** | Skrin digital / Digital screens | Red, Green, Blue (0–255) |
| **HEX** | Kod warna web / Web colour codes | #RRGGBB (contoh: #FF5733) |
| **HSL** | Pemilihan warna intuitif / Intuitive colour selection | Hue, Saturation, Lightness |
| **CMYK** | Cetakan / Printing | Cyan, Magenta, Yellow, Key (Black) |

### 6.2 Psikologi Warna / Colour Psychology

| Warna | Persepsi Biasa | Penggunaan dalam UI |
|-------|----------------|---------------------|
| **Biru** | Kepercayaan, profesional, tenang | Butang utama, jenama korporat |
| **Hijau** | Kejayaan, positif, semula jadi | Butang "Berjaya", pengesahan |
| **Merah** | Bahaya, kesegeraan, amaran | Ralat, padam, amaran |
| **Oren** | Tenaga, kreativiti, mesra | CTA (Call-to-Action), promosi |
| **Kelabu** | Neutral, lumpuh, latar | Elemen tidak aktif, latar belakang |
| **Hitam** | Elegans, formaliti | Teks, jenama premium |

### 6.3 Palet Warna UI yang Baik / Good UI Colour Palette

Sebuah palet UI yang baik biasanya mengandungi:
- **1 Warna Utama / Primary Colour** — Warna jenama; digunakan pada butang utama dan aksen.
- **1 Warna Sekunder / Secondary Colour** — Melengkapi warna utama; digunakan pada elemen sokongan.
- **Warna Neutral / Neutral Colours** — Hitam, putih, kelabu pelbagai ton untuk teks dan latar.
- **Warna Semantik / Semantic Colours** — Hijau (berjaya), merah (ralat), oren (amaran), biru (maklumat).

## 7. Wireframe dan Prototaip / Wireframe and Prototype

### 7.1 Definisi Wireframe

**Wireframe** ialah lakaran atau pelan asas (blueprint) antara muka pengguna yang menunjukkan susun atur elemen tanpa butiran visual seperti warna atau imej sebenar.

**Tujuan wireframe:**
- Merancang susun atur dan hierarki maklumat sebelum pembangunan penuh.
- Mendapatkan maklum balas awal daripada klien atau pengguna.
- Memudahkan komunikasi antara pereka bentuk dan pembangun.

### 7.2 Tahap Ketepatan Prototaip / Prototype Fidelity Levels

| Tahap | Penerangan | Alat |
|-------|------------|------|
| **Lo-Fi (Rendah)** | Lakaran tangan atau kotak-kotak ringkas / Hand sketches or simple boxes | Kertas, Balsamiq |
| **Mid-Fi (Sederhana)** | Susun atur digital tanpa warna sebenar / Digital layout without real colours | Figma (grayscale), Whimsical |
| **Hi-Fi (Tinggi)** | Prototaip hampir sama dengan produk akhir / Prototype nearly identical to final product | Figma, Adobe XD, InVision |

### 7.3 Alat Wireframing Popular / Popular Wireframing Tools

| Alat | Platform | Kelebihan |
|------|----------|-----------|
| **Figma** | Web, Windows, macOS | Kolaborasi masa nyata; percuma untuk individu |
| **Adobe XD** | Windows, macOS | Integrasi dengan Adobe Suite |
| **Balsamiq** | Web, Desktop | Cepat; gaya lakaran tangan |
| **Whimsical** | Web | Mudah; sesuai untuk lo-fi |
| **Canva** | Web | Mudah untuk bukan pereka bentuk |

| Istilah (EN) | Istilah (BM) | Definisi Ringkas |
|--------------|--------------|------------------|
| User Interface (UI) | Antara Muka Pengguna | Elemen visual yang pengguna berinteraksi dengan / Visual elements users interact with |
| Visual Hierarchy | Hierarki Visual | Susunan elemen mengikut kepentingan / Arrangement of elements by importance |
| Wireframe | Kerangka Wayar | Lakaran susun atur antara muka tanpa visual penuh / Interface layout sketch without full visuals |
| Prototype | Prototaip | Model percubaan produk untuk pengujian / Trial product model for testing |
| Affordance | Kemampuan Jelas | Sifat reka bentuk yang menunjukkan cara penggunaan / Design property showing how to use |
| Contrast | Kontras | Perbezaan antara elemen untuk meningkatkan keterlihatan / Difference between elements for visibility |
| Colour Palette | Palet Warna | Set warna yang dipilih untuk sesuatu projek / Set of colours chosen for a project |
| Typography | Tipografi | Seni dan teknik penyusunan teks / Art and technique of text arrangement |

---

## 9. Rumusan / Summary

Reka bentuk UI yang baik adalah gabungan prinsip-prinsip visual — hierarki, keseimbangan, kontras, perpaduan, dan kedekatan — dengan pemahaman tentang psikologi pengguna. Elemen kawalan navigasi seperti butang, menu, dan ikon mesti direka bentuk dengan mempertimbangkan kejelasan, konsistensi, dan maklum balas visual yang jelas. Pemilihan tipografi dan palet warna yang sesuai meningkatkan keterbacaan dan menyampaikan nada dan personaliti produk. Wireframe dan prototaip membolehkan pembangun mengesahkan reka bentuk sebelum fasa pembangunan penuh bermula, menjimatkan masa dan kos.
