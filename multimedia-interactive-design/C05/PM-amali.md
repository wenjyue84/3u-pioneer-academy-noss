## 2. Prasyarat / Prerequisites

Sebelum memulakan sesi amali, pelatih hendaklah:
- Telah menyelesaikan semua 5 Kertas Penerangan (KP-01 hingga KP-05)
- Mempunyai kemahiran asas komputer dan penggunaan perisian
- Memahami konsep asas multimedia interaktif
- Telah menyelesaikan semua Kertas Tugasan (KT-01 hingga KT-05)

---

## 3. Objektif Pembelajaran Amali / Practical Learning Objectives

Pada akhir sesi amali ini, pelatih akan dapat / By the end of these practical sessions, trainees will be able to:

1. Menghasilkan peta struktur dan carta alir navigasi untuk projek multimedia interaktif / Produce a structure map and navigation flowchart for an interactive multimedia project.
2. Membangunkan elemen multimedia interaktif menggunakan perisian pengarangan yang diluluskan / Develop interactive multimedia elements using approved authoring software.
3. Mengintegrasikan semua komponen multimedia (audio, video, grafik) ke dalam projek / Integrate all multimedia components (audio, video, graphics) into a project.
4. Menguji projek multimedia interaktif secara sistematik dan membetulkan semua ralat / Systematically test an interactive multimedia project and correct all errors.
5. Menerbitkan dan menyerahkan produk multimedia interaktif dalam format yang ditetapkan / Publish and deliver the interactive multimedia product in the specified format.

## 8. Keselamatan dan Kesihatan Pekerjaan / Occupational Safety and Health

- Pastikan kabel kuasa tidak menyekat laluan kecemasan.
- Laraskan kecerahan monitor kepada tahap yang selesa (kurangkan keletihan mata).
- Ambil rehat setiap 45–60 minit (bangun, regangkan badan).
- Pastikan pengudaraan makmal komputer yang baik.
- Simpan kerja secara berkala untuk mengelakkan kehilangan data.
- Laporkan sebarang kerosakan peralatan kepada pensyarah segera.
