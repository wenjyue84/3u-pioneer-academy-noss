## Tajuk Kerja / Work Title

**Membangunkan Elemen Multimedia Interaktif / Develop Interactive Multimedia Elements**

---

## 1. Amaran Keselamatan dan Kesihatan / Safety and Health Reminders

- Pastikan perisian Adobe Animate telah dipasang dan dilesenkan dengan betul sebelum memulakan.
- Simpan fail projek (.fla) secara berkala (setiap 10–15 minit) atau aktifkan auto-save.
- Simpan salinan sandaran (backup) fail projek ke pemacu kilat atau storan awan.
- Pastikan nama fail dan folder menggunakan aksara yang dibenarkan (tanpa ruang atau aksara khas).
- Laporkan sebarang kerosakan perisian kepada pensyarah.
- Jangan menutup Adobe Animate sebelum menyimpan semua kerja.

## 3. Prosedur Kerja / Work Procedure

**Langkah 1: Menyediakan Dokumen Baharu dalam Adobe Animate (10 minit)**

1. Buka Adobe Animate 2023.
2. Klik **Create New** → Pilih **HTML5 Canvas**.
3. Tetapkan dimensi Stage: **Lebar (Width): 1024px**, **Tinggi (Height): 768px**.
4. Tetapkan Frame Rate: **24 fps**.
5. Tetapkan warna latar Stage kepada **#FFFFFF** (putih).
6. Klik **Create**.
7. Simpan fail: **File → Save As** → Nama fail: `[nama_pelatih]_ICT_elearn.fla`.

**Rekod tetapan dokumen:**

| Tetapan | Nilai |
|---------|-------|
| Jenis Dokumen | HTML5 Canvas |
| Lebar | px |
| Tinggi | px |
| Frame Rate | fps |
| Warna Latar | # |

---

**Langkah 2: Mengatur Struktur Scene (10 minit)**

8. Buka panel Scene (**Window → Scene**).
9. Tambah scene untuk setiap halaman utama dalam peta struktur anda. Minimum 3 scene:
   - Scene 1: `HomepageScene`
   - Scene 2: `ContentScene`
   - Scene 3: `QuizScene`
10. Label setiap scene dengan nama yang jelas.

**Rekod scene yang dibuat:**

| Bil | Nama Scene | Tujuan |
|-----|-----------|--------|
| 1 | | |
| 2 | | |
| 3 | | |

---

**Langkah 3: Membangunkan Halaman Utama (Homepage) (45 minit)**

11. Klik pada Scene 1 (`HomepageScene`).
12. Buat lapisan (layers) berikut dalam timeline:
    - Layer "Background"
    - Layer "Title"
    - Layer "Buttons"
    - Layer "Actions"
13. Pada layer "Background": Lukis segiempat tepat memenuhi stage sebagai latar belakang. Pilih warna yang sesuai.
14. Pada layer "Title": Tambah teks tajuk modul menggunakan **Text Tool (T)**. Saiz fon: 36px, Bold. Letakkan di bahagian atas skrin.
15. Pada layer "Buttons": Buat **3 butang navigasi** menggunakan kaedah berikut:
    a. Pilih **Rectangle Tool (R)** → Lukis butang bersaiz 200×50px.
    b. Tambah teks label pada butang (contoh: "Topik 1", "Topik 2", "Topik 3").
    c. Pilih keduanya (segiempat dan teks) → **Modify → Convert to Symbol** → Jenis: **Button**, nama: `btn_topik1`.
    d. Ulangi untuk 2 butang lagi.
16. Susun ketiga-tiga butang secara menegak di bahagian tengah skrin.

---

**Langkah 4: Menambah Interaktiviti pada Butang (30 minit)**

17. Klik pada layer "Actions" → Pilih frame 1 → Buka **Actions Panel (F9)**.
18. Tambah kod untuk menghentikan timeline pada frame 1:
    ```javascript
    this.stop();
    ```
19. Klik pada butang `btn_topik1` di stage.
20. Dalam Actions Panel, tambah event listener untuk navigasi:
    ```javascript
    this.btn_topik1.addEventListener("click", fl_ClickToGoToScene.bind(this));
    function fl_ClickToGoToScene() {
        fl.getDocumentDOM().currentScene = "ContentScene";
    }
    ```
    *(Nota: Pengarah akan tunjukkan kaedah navigasi HTML5 Canvas yang sesuai)*
21. Ulangi untuk butang Topik 2 dan Topik 3 (menghala ke scene yang berbeza).
22. Tambah butang "Keluar" dengan fungsi yang sesuai.

---

**Langkah 5: Membangunkan Halaman Kandungan (Content Page) (45 minit)**

23. Klik pada Scene 2 (`ContentScene`).
24. Buat lapisan: "Background", "Header", "Content", "Navigation", "Actions".
25. Layer "Background": Latar belakang warna berbeza daripada homepage.
26. Layer "Header": Tajuk topik (contoh: "Topik 1: Keselamatan Kata Laluan"), saiz 28px.
27. Layer "Content": Kotak teks kandungan. Tambah sekurang-kurangnya 50 patah perkataan kandungan ringkas berkaitan topik.
28. Layer "Navigation": Buat DUA (2) butang navigasi:
    - Butang "Kembali" → kembali ke HomepageScene
    - Butang "Seterusnya" → ke QuizScene
29. Tambah tindakan `this.stop();` pada layer "Actions".

---

**Langkah 6: Membangunkan Animasi Tween (20 minit)**

30. Pada HomepageScene, pilih elemen tajuk pada layer "Title".
31. Klik kanan pada frame 1 timeline layer "Title" → **Create Motion Tween**.
32. Gerakkan playhead ke frame 24 (1 saat).
33. Laraskan kedudukan atau opacity elemen tajuk untuk mencipta animasi masuk (fade-in atau slide-in).
34. Tekan **Enter** untuk pratonton animasi.
35. Pastikan animasi berjalan dengan lancar.

---

**Langkah 7: Simpan dan Pratonton (10 minit)**

36. Simpan fail: **File → Save (Ctrl+S)**.
37. Pratonton dalam pelayar: **Control → Test (Ctrl+Enter)** atau **File → Publish Preview → Default (HTML)**.
38. Semak fungsi asas:
    - Animasi tajuk berjalan
    - Tiga butang topik kelihatan dan boleh diklik
    - Navigasi antara scene berfungsi
