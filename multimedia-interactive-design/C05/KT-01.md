## Bahagian B: Soalan Berstruktur / Section B: Structured Questions (40 markah)

**Soalan 7** (20 markah)

Anda dilantik sebagai pereka bentuk multimedia interaktif untuk membangunkan modul e-pembelajaran bertajuk "Keselamatan di Tempat Kerja" untuk sebuah syarikat pembuatan. Modul ini mengandungi 5 topik utama dan perlu disertakan dengan kuiz di akhir setiap topik.

You have been appointed as an interactive multimedia designer to develop an e-learning module titled "Workplace Safety" for a manufacturing company. The module contains 5 main topics and requires a quiz at the end of each topic.

(a) Cadangkan model navigasi yang paling sesuai untuk modul ini. Berikan justifikasi pilihan anda. (6 markah)
Suggest the most appropriate navigation model for this module. Provide justification for your choice.

(b) Lakarkan peta struktur (structure map) untuk modul e-pembelajaran ini. Pastikan peta struktur anda menunjukkan semua topik, subtopik, dan halaman kuiz. (10 markah)
Sketch a structure map for this e-learning module. Ensure your structure map shows all topics, subtopics, and quiz pages.

(c) Nyatakan DUA (2) prinsip UX yang perlu dipertimbangkan dalam reka bentuk modul ini dan terangkan bagaimana ia akan dilaksanakan. (4 markah)
State TWO (2) UX principles that need to be considered in the design of this module and explain how they will be implemented.

**Soalan 8** (20 markah)

Jadual di bawah menunjukkan maklum balas pengguna selepas menguji sebuah produk multimedia interaktif.

The table below shows user feedback after testing an interactive multimedia product.

| No. | Maklum Balas Pengguna | Kategori Masalah |
|-----|----------------------|------------------|
| 1 | "Saya tidak tahu di mana untuk klik seterusnya" | ? |
| 2 | "Butang 'Kembali' tidak membawa saya ke halaman sebelum ini" | ? |
| 3 | "Saya tidak pasti sama ada saya sudah melengkapkan semua modul" | ? |
| 4 | "Menu utama terlalu rumit untuk difahami" | ? |
| 5 | "Kandungan terlalu banyak pada satu halaman" | ? |

(a) Kenal pasti kategori masalah bagi setiap maklum balas pengguna di atas (pilih daripada: masalah navigasi, masalah UX, masalah reka bentuk antara muka, masalah kandungan). (5 markah)
Identify the problem category for each user feedback above (choose from: navigation problem, UX problem, interface design problem, content problem).

(b) Cadangkan penyelesaian yang spesifik bagi setiap masalah yang dikenal pasti. (10 markah)
Suggest specific solutions for each identified problem.

(c) Berdasarkan maklum balas pengguna di atas, terangkan bagaimana pengujian pengguna (user testing) dapat membantu meningkatkan kualiti produk multimedia interaktif. (5 markah)
Based on the user feedback above, explain how user testing can help improve the quality of interactive multimedia products.
