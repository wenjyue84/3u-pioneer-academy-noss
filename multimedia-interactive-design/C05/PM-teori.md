## 2. Objektif Pembelajaran / Learning Objectives

Pada akhir sesi teori ini, pelatih akan dapat / By the end of these theory sessions, trainees will be able to:

1. Menerangkan konsep multimedia interaktif, jenis interaktiviti, dan prinsip navigasi serta pengalaman pengguna (UX) / Explain interactive multimedia concepts, types of interactivity, navigation principles, and user experience (UX).
2. Mengenal pasti perisian pengarangan dan platform yang digunakan dalam pembangunan multimedia interaktif / Identify authoring software and platforms used in interactive multimedia development.
3. Menerangkan kaedah mengintegrasikan elemen audio, video, dan grafik dalam projek multimedia interaktif / Explain methods of integrating audio, video, and graphic elements into interactive multimedia projects.
4. Mengaplikasikan prinsip reka bentuk antara muka pengguna (UI) dalam media interaktif / Apply user interface (UI) design principles for interactive media.
5. Menerangkan prosedur pengujian, penyahpepijatan, dan penerbitan produk multimedia interaktif / Explain procedures for testing, debugging, and publishing interactive multimedia products.
