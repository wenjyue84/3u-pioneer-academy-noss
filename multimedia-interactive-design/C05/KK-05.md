## Tajuk Kerja / Work Title

**Menerbitkan dan Menyerahkan Multimedia Interaktif / Publish and Deliver Interactive Multimedia**

---

## 1. Amaran Keselamatan dan Kesihatan / Safety and Health Reminders

- Simpan salinan akhir fail projek sebelum memulakan proses penerbitan.
- Pastikan semua fail media disertakan dalam pakej penyerahan — jangan tinggalkan mana-mana aset.
- Semak semula hak cipta semua aset media sebelum menyerahkan kepada klien.
- Pastikan fail output HTML5 diuji sekali lagi dalam semua pelayar sasaran sebelum penyerahan.
- Simpan salinan sandaran pakej penyerahan dalam dua lokasi berbeza (contoh: pemacu kilat + Google Drive).
- Jangan mengubah suai mana-mana fail selepas penyerahan formal tanpa pemberitahuan klien.

---

## 2. Peralatan, Perisian dan Bahan / Equipment, Software and Materials

### Peralatan / Equipment
- [ ] Komputer PC / Laptop
- [ ] Pemacu kilat USB 8GB minimum (untuk penyerahan fizikal)
- [ ] Sambungan Internet (untuk penyerahan dalam talian jika diperlukan)

### Perisian / Software
- [ ] Adobe Animate 2023
- [ ] Google Chrome, Firefox, Edge (untuk ujian akhir)
- [ ] Windows Explorer (untuk penyusunan pakej)
- [ ] WinZip / 7-Zip (untuk memampatkan pakej penyerahan)
- [ ] Microsoft Word / Google Docs (untuk penyediaan dokumentasi)

### Bahan / Materials
- [ ] Fail projek Adobe Animate dari KK-04 (telah melalui pengujian dan bebas pepijat)
- [ ] Borang laporan pepijat yang lengkap dari KK-04
- [ ] Senarai semak pengujian yang lengkap dari KK-04

---

## 3. Prosedur Kerja / Work Procedure

**Langkah 1: Semakan Akhir Projek (15 minit)**

1. Buka fail projek Adobe Animate dari KK-04.
2. Jalankan semakan akhir menggunakan senarai semak berikut sebelum penerbitan:

| Perkara | Status (OK / Perlu Betul) |
|---------|--------------------------|
| Semua butang navigasi berfungsi | |
| Audio bermain dengan betul | |
| Grafik dipaparkan tanpa masalah | |
| Tiada ralat dalam Console DevTools | |
| Teks kandungan tepat dan lengkap | |
| Animasi berjalan dengan lancar | |
| Semua pepijat dari KK-04 telah dibetulkan | |

3. Jika terdapat item **"Perlu Betul"**, betulkan sebelum meneruskan ke langkah seterusnya.

---

**Langkah 2: Tetapkan Tetapan Penerbitan (Publish Settings) (10 minit)**

4. Dalam Adobe Animate, buka **File → Publish Settings**.
5. Semak tetapan penerbitan:

| Tetapan | Nilai Disyorkan |
|---------|----------------|
| Format Output | HTML5 Canvas |
| Lokasi Output | Folder `output/` dalam folder projek |
| Nama Fail HTML | `index.html` |
| Sertakan Fail JavaScript | Ya |
| Kualiti Imej | 80% |

6. Rekodkan tetapan penerbitan anda:

| Tetapan | Nilai Anda |
|---------|-----------|
| Format Output | |
| Lokasi Output | |
| Nama Fail HTML | |

---

**Langkah 3: Terbitkan Projek ke Format HTML5 (10 minit)**

7. Klik **Publish** dalam tetingkap Publish Settings.
8. Tunggu proses penerbitan selesai.
9. Buka folder output — pastikan fail berikut dihasilkan:
   - `index.html` (fail HTML utama)
   - `[nama_projek].js` (fail JavaScript)
   - `images/` atau `assets/` (fail media)
10. Catat senarai fail output yang dihasilkan:

| Bil | Nama Fail / Folder | Jenis | Saiz |
|-----|--------------------|-------|------|
| 1 | | | |
| 2 | | | |
| 3 | | | |
| 4 | | | |

---

**Langkah 4: Ujian Akhir Fail Output (20 minit)**

11. Buka fail `index.html` dalam **Google Chrome** — bukan daripada Adobe Animate, tetapi terus dari Windows Explorer atau dengan double-click.
12. Uji semua fungsi:
    - [ ] Halaman utama dimuatkan dengan betul
    - [ ] Audio bermain
    - [ ] Navigasi antara halaman berfungsi
    - [ ] Grafik kelihatan jelas
13. Buka fail `index.html` dalam **Mozilla Firefox** dan ulangi ujian.
14. Buka fail `index.html` dalam **Microsoft Edge** dan ulangi ujian.
15. Rekodkan keputusan ujian akhir:

| Ujian | Chrome | Firefox | Edge |
|-------|--------|---------|------|
| Halaman dimuatkan | | | |
| Audio berfungsi | | | |
| Navigasi berfungsi | | | |
| Grafik jelas | | | |

---

**Langkah 5: Sediakan Dokumentasi Projek (30 minit)**

16. Buka Microsoft Word atau Google Docs.
17. Cipta dokumen bertajuk **"Panduan Pengguna: Modul E-Pembelajaran Keselamatan ICT"**.
18. Sertakan bahagian-bahagian berikut dalam Panduan Pengguna:

**Bahagian 1: Keperluan Sistem**

| Perkara | Keperluan |
|---------|-----------|
| Sistem Operasi | Windows 10 / macOS 10.14 atau lebih baharu |
| Pelayar Web | Google Chrome 90+ / Firefox 88+ / Edge 90+ |
| Resolusi Skrin | Minimum 1024×768 |
| Sambungan Internet | Tidak diperlukan (fail standalone) |
| Plugin Tambahan | Tiada diperlukan |

**Bahagian 2: Cara Menggunakan Modul**
- Cara membuka modul (klik dua kali `index.html`)
- Cara menavigasi antara topik
- Cara menduduki kuiz
- Cara melihat keputusan

**Bahagian 3: Penyelesaian Masalah Biasa**
- Jika audio tidak bermain
- Jika halaman tidak dimuatkan
- Cara menghubungi sokongan teknikal

19. Simpan dokumen sebagai `[nama_pelatih]_panduan_pengguna.pdf`.

20. Cipta dokumen kedua bertajuk **"Nota Teknikal Projek"**:

| Perkara | Maklumat |
|---------|---------|
| Nama Projek | |
| Versi | 1.0 |
| Tarikh Siap | |
| Pembangun | |
| Perisian Pengarangan | Adobe Animate 2023 |
| Format Output | HTML5 Canvas |
| Dimensi Stage | 1024×768px |
| Fail Projek Sumber | .fla |
| Aset Utama | Audio: MP3 128kbps; Video: MP4 H.264; Grafik: PNG/JPEG |

---

**Langkah 6: Susun Pakej Penyerahan (20 minit)**

21. Cipta folder baharu bernama `PAKEJ_PENYERAHAN_[nama_pelatih]`.
22. Susun kandungan folder seperti berikut:

```
PAKEJ_PENYERAHAN_[nama_pelatih]/
├── 01_output/                    (fail HTML5 siap — salin keseluruhan folder output)
│   ├── index.html
│   ├── [projek].js
│   └── assets/
├── 02_fail_sumber/               (fail projek asal)
│   └── [nama_pelatih]_ICT_elearn.fla
├── 03_aset_media/                (semua aset audio, video, grafik asal)
│   ├── audio/
│   ├── video/
│   └── graphics/
├── 04_dokumentasi/               (dokumen sokongan)
│   ├── panduan_pengguna.pdf
│   ├── nota_teknikal.docx
│   ├── peta_struktur.pdf
│   ├── carta_alir.pdf
│   └── laporan_pengujian.pdf
└── README.txt                    (ringkasan kandungan pakej)
```

23. Cipta fail `README.txt` dan isi dengan maklumat berikut:
    - Nama projek
    - Nama pembangun
    - Tarikh penyerahan
    - Cara membuka projek
    - Senarai kandungan pakej

---

**Langkah 7: Mampatkan dan Serahkan Pakej (10 minit)**

24. Pilih folder `PAKEJ_PENYERAHAN_[nama_pelatih]`.
25. Klik kanan → **Send to → Compressed (zipped) folder** atau gunakan 7-Zip.
26. Namakan fail ZIP: `PAKEJ_[nama_pelatih]_ICT_elearn_v1.zip`.
27. Semak saiz fail ZIP — rekodkan: \_\_\_\_\_ MB.
28. Salin fail ZIP ke pemacu kilat USB.
29. Serahkan pemacu kilat kepada pensyarah BERSAMA-SAMA dengan kertas kerja ini yang telah dilengkapkan.

---

**Langkah 8: Pembentangan Produk Akhir (30 minit)**

30. Sediakan pembentangan ringkas (5–7 minit) tentang projek anda kepada pensyarah.
31. Tunjukkan demonstrasi langsung projek multimedia interaktif anda.
32. Terangkan kepada pensyarah:
    - Konsep dan reka bentuk produk
    - Ciri-ciri interaktif yang dibangunkan
    - Cabaran yang dihadapi dan cara penyelesaian
    - Format output dan platform sasaran
