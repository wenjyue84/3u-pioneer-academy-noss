## Tajuk / Title: Multimedia Integration: Embedding Audio, Video and Graphics

---

## 1. Objektif Pembelajaran / Learning Objectives

Selepas mempelajari Kertas Penerangan ini, pelatih akan dapat / After studying this Information Sheet, trainees will be able to:

1. Mengenal pasti format fail audio, video, dan grafik yang sesuai untuk projek multimedia interaktif / Identify appropriate audio, video, and graphic file formats for interactive multimedia projects.
2. Menerangkan prosedur penyematan (embedding) audio dan video dalam perisian pengarangan / Explain the procedure for embedding audio and video in authoring software.
3. Mengoptimumkan aset multimedia untuk prestasi dan keserasian / Optimise multimedia assets for performance and compatibility.
4. Mengurus pustaka aset (asset library) dalam projek multimedia / Manage an asset library in a multimedia project.
5. Menyelesaikan masalah biasa berkaitan integrasi media / Troubleshoot common media integration issues.

---

## 2. Pengenalan Integrasi Multimedia / Introduction to Multimedia Integration

Integrasi multimedia merujuk kepada proses menggabungkan pelbagai elemen media — teks, grafik, audio, video, dan animasi — ke dalam satu produk multimedia interaktif yang berfungsi. Integrasi yang berjaya memerlukan pemahaman tentang format fail yang sesuai, kaedah penyematan, dan pengoptimuman aset.

### 2.1 Prinsip Integrasi Multimedia yang Baik / Principles of Good Multimedia Integration

- **Konsistensi / Consistency** — Semua media harus menggunakan piawaian kualiti yang konsisten.
- **Pengoptimuman / Optimisation** — Saiz fail dioptimumkan untuk prestasi tanpa mengorbankan kualiti.
- **Keserasian / Compatibility** — Format yang dipilih mesti disokong oleh platform sasaran.
- **Organisasi / Organisation** — Aset disusun dalam struktur folder yang sistematik.
- **Hak Cipta / Copyright** — Semua aset yang digunakan mesti mematuhi undang-undang hak cipta (Akta Hak Cipta 1987, Akta 332).

## 3. Format Fail Audio / Audio File Formats

### 3.1 Jenis Format Audio / Types of Audio Formats

| Format | Jenis | Saiz Fail | Kualiti | Kegunaan |
|--------|-------|-----------|---------|----------|
| **WAV** | Tidak termampat / Uncompressed | Besar / Large | Sangat Tinggi / Very High | Rakaman studio, audio sumber / Studio recording, source audio |
| **MP3** | Tersekat-lossy / Lossy-compressed | Kecil / Small | Baik / Good | Web, e-pembelajaran, audio umum / Web, e-learning, general audio |
| **AAC** | Tersekat-lossy / Lossy-compressed | Kecil / Small | Baik / Good | iOS, iTunes, streaming |
| **OGG Vorbis** | Tersekat-lossy / Lossy-compressed | Kecil / Small | Baik / Good | Web (Firefox/Chrome), permainan / Web, games |
| **FLAC** | Tersekat-lossless / Lossless-compressed | Sederhana / Medium | Sangat Tinggi | Arkib audio, audio hi-fi / Audio archiving, hi-fi audio |
| **AIFF** | Tidak termampat / Uncompressed | Besar / Large | Sangat Tinggi | Platform macOS, audio studio |

### 3.2 Spesifikasi Audio yang Disyorkan / Recommended Audio Specifications

| Parameter | Nilai Disyorkan | Catatan |
|-----------|-----------------|---------|
| **Kadar Sampel / Sample Rate** | 44,100 Hz (44.1 kHz) | Standard CD; cukup untuk kebanyakan multimedia |
| **Kedalaman Bit / Bit Depth** | 16-bit | Standard CD; 24-bit untuk rakaman studio |
| **Saluran / Channels** | Stereo (2 saluran) | Mono untuk suara latar sahaja |
| **Format Output Web** | MP3 128–192 kbps | Keseimbangan kualiti dan saiz fail |
| **Format Sumber** | WAV 16-bit/44.1kHz | Simpan sumber dalam kualiti tinggi |

### 3.3 Prosedur Penyematan Audio dalam Adobe Animate / Audio Embedding in Adobe Animate

1. Import fail audio ke Library (File → Import → Import to Library).
2. Pilih frame pada timeline di mana audio perlu dimulakan.
3. Buka panel Properties → Sound.
4. Pilih fail audio daripada dropdown "Name".
5. Pilih kaedah sinkronisasi (Sync):
   - **Event** — Audio bermula apabila frame dicapai; berjalan secara bebas.
   - **Stream** — Audio diselaraskan dengan timeline; sesuai untuk animasi.
   - **Start** — Seperti Event tetapi tidak memulakan semula jika sudah bermain.
   - **Stop** — Menghentikan audio yang sedang bermain.
6. Tetapkan bilangan ulangan (Repeat / Loop) jika diperlukan.

### 3.4 Kawalan Audio Menggunakan Kod / Audio Control Using Code

**Contoh ActionScript 3.0 (Adobe Animate):**
```actionscript
// Import kelas yang diperlukan
import flash.media.Sound;
import flash.media.SoundChannel;

// Muat dan mainkan audio
var bunyi:Sound = new Sound(new URLRequest("audio/latar.mp3"));
var saluran:SoundChannel = bunyi.play();

// Hentikan audio
saluran.stop();
```

## 4. Format Fail Video / Video File Formats

### 4.1 Jenis Format Video / Types of Video Formats

| Format | Codec Video | Codec Audio | Kegunaan |
|--------|-------------|-------------|----------|
| **MP4 (MPEG-4)** | H.264 / H.265 | AAC | Universal; web, mudah alih, e-pembelajaran |
| **WebM** | VP8 / VP9 | Vorbis / Opus | Web (Chrome, Firefox); format terbuka |
| **OGV (Ogg Theora)** | Theora | Vorbis | Web (Firefox); format terbuka |
| **MOV** | H.264 / ProRes | AAC | Platform Apple; pengeditan video |
| **AVI** | Pelbagai / Various | Pelbagai | Windows; saiz fail besar |
| **FLV / F4V** | H.264 / Sorenson | MP3 / AAC | Adobe Flash (legacy) |

### 4.2 Spesifikasi Video yang Disyorkan / Recommended Video Specifications

| Parameter | Nilai Disyorkan | Catatan |
|-----------|-----------------|---------|
| **Format / Container** | MP4 (H.264) | Sokongan universal terluas |
| **Resolusi** | 1280×720 (HD) | Seimbang kualiti dan saiz fail |
| **Kadar Bingkai / Frame Rate** | 25 fps (PAL) atau 30 fps | Standard Malaysia: 25 fps |
| **Kadar Bit Video / Video Bitrate** | 2–5 Mbps (720p) | Bergantung kepada kompleksiti gerak |
| **Kadar Bit Audio / Audio Bitrate** | 128–192 kbps AAC | Untuk audio yang disertakan |
| **Nisbah Aspek / Aspect Ratio** | 16:9 | Widescreen standard |

### 4.3 Prosedur Penyematan Video dalam Adobe Animate / Video Embedding in Adobe Animate

Adobe Animate menyokong dua kaedah utama untuk video:

**Kaedah 1: Embed Video dalam FLA (untuk video pendek)**
1. File → Import → Import Video.
2. Pilih "Embed FLV in SWF and play in timeline".
3. Ikut wizard import untuk menyelesaikan proses.

**Kaedah 2: Load Video Secara Dinamik (disyorkan untuk video panjang)**
1. Sediakan fail MP4 dalam folder projek.
2. Gunakan komponen FLVPlayback atau kod ActionScript untuk memuatkan video.
3. Video dimuatkan semasa runtime, mengurangkan saiz fail output.

```actionscript
// Contoh memuatkan video secara dinamik
import fl.video.FLVPlayback;

var pemain:FLVPlayback = new FLVPlayback();
pemain.source = "video/intro.mp4";
pemain.width = 640;
pemain.height = 360;
addChild(pemain);
```

### 4.4 Video dalam HTML5 / Video in HTML5

```html
<!-- Tag video HTML5 dengan pelbagai format untuk keserasian silang-pelayar -->
<video width="640" height="360" controls>
  <source src="video/intro.mp4" type="video/mp4">
  <source src="video/intro.webm" type="video/webm">
  Pelayar anda tidak menyokong tag video HTML5.
</video>
```

## 5. Format Fail Grafik / Graphic File Formats

### 5.1 Grafik Raster / Raster Graphics

Grafik raster terdiri daripada grid piksel. Kualiti merosot apabila diperbesar.

| Format | Kegunaan | Ciri Utama |
|--------|----------|------------|
| **JPEG / JPG** | Foto, imej kompleks / Photos, complex images | Mampatan lossy; tiada ketelusan / Lossy compression; no transparency |
| **PNG** | Grafik dengan latar telus / Graphics with transparent background | Mampatan lossless; menyokong ketelusan alfa / Lossless; supports alpha transparency |
| **GIF** | Animasi ringkas, ikon / Simple animations, icons | Sokongan animasi; 256 warna sahaja / Animation support; 256 colours only |
| **WebP** | Penggantian JPEG/PNG untuk web / JPEG/PNG replacement for web | Saiz lebih kecil; menyokong ketelusan / Smaller size; supports transparency |
| **BMP** | Imej Windows tanpa mampatan / Uncompressed Windows images | Saiz sangat besar; tidak sesuai untuk web |

### 5.2 Grafik Vektor / Vector Graphics

Grafik vektor menggunakan formula matematik untuk menggambarkan bentuk. Boleh diperbesar tanpa kehilangan kualiti.

| Format | Kegunaan | Ciri Utama |
|--------|----------|------------|
| **SVG** | Grafik web, ikon, logo / Web graphics, icons, logos | Boleh diskalakan; boleh diedit dengan CSS/JS / Scalable; editable with CSS/JS |
| **AI** | Fail Adobe Illustrator | Format proprietari; untuk pengeditan |
| **EPS** | Cetakan profesional / Professional printing | Format lawas; sokongan luas |

### 5.3 Panduan Pengoptimuman Grafik / Graphic Optimisation Guidelines

| Jenis Grafik | Format Disyorkan | Resolusi | Catatan |
|--------------|------------------|----------|---------|
| Foto / Photo | JPEG (80% kualiti) | 72–96 PPI untuk skrin | Kompres menggunakan TinyJPEG atau alat seumpamanya |
| Grafik dengan latar telus | PNG-24 | 72–96 PPI | Gunakan PNG-8 jika hanya 256 warna diperlukan |
| Logo / Ikon | SVG | Tidak berkaitan | Vektor untuk skalabiliti penuh |
| Animasi ringkas | GIF atau CSS Animation | 72 PPI | Elakkan GIF bersaiz besar |
| Gambar latar (background) | JPEG atau WebP | 72 PPI | Mampat dengan agresif |

## 6. Pengoptimuman Aset / Asset Optimisation

### 6.1 Mengapa Pengoptimuman Penting? / Why is Optimisation Important?

- **Prestasi / Performance** — Fail yang lebih kecil dimuatkan lebih cepat, mengurangkan masa menunggu pengguna.
- **Pengalaman Pengguna / User Experience** — Pemuatan yang lambat menyebabkan pengguna meninggalkan produk.
- **Penggunaan Storan / Storage Usage** — Penting untuk projek yang diterbitkan pada peranti dengan storan terhad.
- **Penggunaan Lebar Jalur / Bandwidth Usage** — Kritikal untuk produk yang diterbitkan secara dalam talian.

### 6.2 Teknik Pengoptimuman / Optimisation Techniques

| Teknik | Penerangan |
|--------|------------|
| **Mampatan / Compression** | Mengurangkan saiz fail tanpa kehilangan kualiti yang ketara |
| **Penyesuaian Resolusi / Resolution Adjustment** | Gunakan resolusi yang diperlukan sahaja; elakkan lebih |
| **Sprite Sheet** | Gabungkan pelbagai imej kecil dalam satu fail untuk mengurangkan permintaan HTTP |
| **Lazy Loading** | Muatkan aset hanya apabila diperlukan, bukan semua sekaligus |
| **Caching** | Simpan aset yang kerap digunakan dalam memori untuk capaian pantas |
| **Format Moden / Modern Formats** | Gunakan WebP (gambar) dan Opus (audio) untuk saiz fail yang lebih kecil |

### 6.3 Pengurusan Pustaka Aset / Asset Library Management

**Struktur Folder yang Disyorkan / Recommended Folder Structure:**
```
projek-multimedia/
├── audio/
│   ├── narration/        (fail narasi)
│   ├── bgm/             (muzik latar)
│   └── sfx/             (kesan bunyi)
├── video/
│   ├── intro/
│   └── content/
├── graphics/
│   ├── backgrounds/
│   ├── icons/
│   ├── buttons/
│   └── characters/
├── fonts/
└── output/
```

**Konvensyen Penamaan Fail / File Naming Convention:**
- Gunakan huruf kecil dan tanda sempang / Use lowercase and hyphens: `audio-intro-01.mp3`
- Sertakan nombor versi jika perlu / Include version numbers if needed: `bg-home-v2.jpg`
- Elakkan ruang dan aksara khas / Avoid spaces and special characters

## 7. Menyelesaikan Masalah Biasa / Troubleshooting Common Issues

| Masalah / Problem | Punca Biasa / Common Cause | Penyelesaian / Solution |
|-------------------|---------------------------|------------------------|
| Audio tidak bermain / Audio not playing | Format tidak disokong / Unsupported format | Tukar ke MP3 atau OGG / Convert to MP3 or OGG |
| Video tidak dipaparkan / Video not displaying | Codec tidak disokong / Unsupported codec | Encode semula sebagai H.264 MP4 / Re-encode as H.264 MP4 |
| Imej berkualiti rendah / Low quality image | Resolusi terlalu rendah / Resolution too low | Guna imej resolusi lebih tinggi / Use higher resolution image |
| Fail terlalu besar / File too large | Tiada pengoptimuman / No optimisation | Mampat dan optimalkan aset / Compress and optimise assets |
| Media tidak ditemui / Media not found | Laluan fail salah / Incorrect file path | Semak dan betulkan laluan relatif / Check and correct relative paths |

## 8. Istilah Penting / Key Terms

| Istilah (EN) | Istilah (BM) | Definisi Ringkas |
|--------------|--------------|------------------|
| Embedding | Penyematan | Memasukkan media ke dalam fail projek / Inserting media into project file |
| Codec | Codec | Algoritma mampatan/penyahmpatan untuk audio/video / Compression/decompression algorithm |
| Bitrate | Kadar Bit | Jumlah data yang diproses sesaat / Amount of data processed per second |
| Resolution | Resolusi | Bilangan piksel dalam imej / Number of pixels in an image |
| Compression | Mampatan | Mengurangkan saiz data fail / Reducing data file size |
| Asset Library | Pustaka Aset | Koleksi fail media terurus untuk sesuatu projek / Managed collection of media files for a project |
| Transparency | Ketelusan | Tahap kebolehnampakan latar / Degree of background visibility |
| Lossless | Tanpa Kehilangan | Mampatan tanpa kehilangan data / Compression without data loss |

## 9. Rumusan / Summary

Integrasi multimedia yang berjaya memerlukan pemilihan format fail yang tepat untuk setiap jenis media. Untuk audio, MP3 adalah pilihan standard untuk web; WAV untuk sumber berkualiti tinggi. Untuk video, MP4 dengan codec H.264 menawarkan keserasian paling luas. Untuk grafik, JPEG sesuai untuk foto, PNG untuk grafik dengan ketelusan, dan SVG untuk elemen vektor. Pengoptimuman aset adalah langkah penting untuk memastikan prestasi produk multimedia yang baik. Pengurusan aset yang sistematik melalui struktur folder yang teratur dan konvensyen penamaan yang konsisten memudahkan proses pembangunan dan penyelenggaraan projek.
