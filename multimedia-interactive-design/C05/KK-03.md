## Tajuk Kerja / Work Title

**Mengintegrasikan Komponen Multimedia / Integrate Multimedia Components**

---

## 1. Amaran Keselamatan dan Kesihatan / Safety and Health Reminders

- Pastikan semua aset media yang digunakan adalah bebas hak cipta atau mempunyai lesen yang sah.
- Jangan menggunakan fail media daripada internet tanpa memeriksa lesen penggunaannya.
- Simpan fail projek sebelum mengimport aset baharu untuk mengelakkan kehilangan data.
- Pastikan fail media tidak dijangkiti virus sebelum digunakan (imbas dengan perisian antivirus).
- Simpan semua aset asal dalam folder yang berasingan daripada aset yang telah dioptimumkan.
- Jangan memadamkan fail aset asal selepas pengoptimuman — simpan kedua-duanya.

## 3. Prosedur Kerja / Work Procedure

**Langkah 1: Menyediakan Struktur Folder Projek (10 minit)**

1. Buka Windows Explorer.
2. Cari folder projek anda.
3. Cipta struktur folder berikut dalam folder projek:

```
[nama_pelatih]_ICT_elearn/
├── audio/
│   ├── narration/
│   └── bgm/
├── video/
├── graphics/
│   ├── backgrounds/
│   ├── buttons/
│   └── icons/
└── [nama_pelatih]_ICT_elearn.fla
```

4. Rekodkan struktur folder anda:

**Struktur folder yang dibuat:**

**Langkah 2: Terima dan Semak Aset Media (15 minit)**

5. Dapatkan pakej aset media daripada pensyarah.
6. Salin semua aset ke dalam folder projek anda mengikut kategori.
7. Lengkapkan jadual inventori aset berikut:

| Bil | Nama Fail | Jenis | Saiz Fail | Format | Lokasi Folder |
|-----|-----------|-------|-----------|--------|---------------|
| 1 | | Audio | | | |
| 2 | | Audio | | | |
| 3 | | Video | | | |
| 4 | | Grafik | | | |
| 5 | | Grafik | | | |

---

**Langkah 3: Mengoptimumkan Aset Audio (20 minit)**

8. Buka fail audio narasi dalam Adobe Audition atau Audacity.
9. Semak spesifikasi fail audio:
   - Kadar sampel (sample rate): \_\_\_\_\_ Hz
   - Kedalaman bit (bit depth): \_\_\_\_\_ bit
   - Saluran (channels): Mono / Stereo
   - Saiz fail semasa: \_\_\_\_\_ MB
10. Eksport fail audio dalam format MP3 dengan tetapan berikut:
    - Format: MP3
    - Kadar bit: 128 kbps
    - Kadar sampel: 44,100 Hz
    - Saluran: Mono (jika narasi sahaja)
11. Simpan fail MP3 dalam folder `audio/narration/`.
12. Rekodkan perbandingan:

| | Sebelum Pengoptimuman | Selepas Pengoptimuman |
|--|--|--|
| Format | | MP3 |
| Kadar Bit | | 128 kbps |
| Saiz Fail | | |
| Pengurangan Saiz | | |

---

**Langkah 4: Mengoptimumkan Aset Grafik (20 minit)**

13. Buka fail grafik latar belakang dalam Adobe Photoshop atau GIMP.
14. Semak dimensi dan saiz fail semasa.
15. Ubah saiz (resize) imej kepada 1024×768px jika melebihi dimensi stage.
16. Eksport fail dalam format JPEG (kualiti 80%) menggunakan **File → Export → Save for Web**.
17. Simpan dalam folder `graphics/backgrounds/`.
18. Buka fail grafik ikon/butang.
19. Pastikan latar belakang telus (transparent) jika diperlukan.
20. Eksport dalam format PNG-24.
21. Rekodkan perbandingan:

| Fail | Dimensi Asal | Dimensi Baharu | Saiz Asal | Saiz Baharu |
|------|-------------|----------------|-----------|-------------|
| Latar belakang | | 1024×768 | | |
| Ikon/butang | | | | |

---

**Langkah 5: Mengimport Aset ke Adobe Animate Library (20 minit)**

22. Buka fail projek Adobe Animate dari KK-02.
23. Import fail audio: **File → Import → Import to Library**.
24. Pilih fail MP3 audio narasi yang telah dioptimumkan → Klik **Open**.
25. Pastikan fail audio muncul dalam panel Library.
26. Import fail grafik: Ulangi proses import untuk fail PNG dan JPEG.
27. Import fail video (jika ada): **File → Import → Import Video**.
28. Semak panel Library — pastikan semua aset diimport dengan betul.
29. Susun aset dalam Library menggunakan folder (klik kanan dalam Library → New Folder).

---

**Langkah 6: Menyematkan Audio ke dalam Projek (20 minit)**

30. Pergi ke ContentScene (Scene 2).
31. Buat layer baharu bernama "Audio".
32. Klik pada frame 1 layer "Audio".
33. Dalam panel Properties, cari bahagian Sound.
34. Pilih fail audio narasi dari dropdown "Name".
35. Tetapkan Sync kepada **Stream** (untuk diselaraskan dengan timeline).
36. Tetapkan ulangan kepada **1**.
37. Pratonton: **Control → Test** untuk mengesahkan audio bermain.

**Rekodkan tetapan audio:**

| Tetapan | Nilai |
|---------|-------|
| Nama Fail Audio | |
| Jenis Sync | |
| Ulangan | |
| Berjaya bermain? (Ya/Tidak) | |

---

**Langkah 7: Menyematkan Grafik ke dalam Projek (15 minit)**

38. Pergi ke HomepageScene.
39. Pada layer "Background", import imej latar belakang yang telah dioptimumkan.
40. Pastikan imej memenuhi seluruh stage (1024×768px).
41. Kunci layer "Background" untuk mengelakkan perubahan tidak sengaja.
42. Pada layer "Content" di ContentScene, tambah grafik ikon yang berkaitan.
43. Laraskan saiz dan kedudukan grafik mengikut wireframe.

---

**Langkah 8: Mengintegrasikan Video (Jika Ada) (20 minit)**

44. Jika projek anda mengandungi video, pergi ke scene yang berkaitan.
45. Buat layer baharu bernama "Video".
46. Gunakan komponen FLVPlayback atau HTML5 Video untuk menyematkan video.
47. Tetapkan sumber video ke fail MP4 yang telah dioptimumkan.
48. Laraskan saiz dan kedudukan video player mengikut wireframe.
49. Pastikan video tidak memulakan secara automatik kecuali dikehendaki.

---

**Langkah 9: Simpan dan Ujian Asas Integrasi (10 minit)**

50. Simpan fail projek: **File → Save (Ctrl+S)**.
51. Pratonton dalam pelayar: **File → Publish Preview → Default**.
52. Uji semua media yang diintegrasikan:
    - [ ] Audio bermain dengan betul
    - [ ] Grafik dipaparkan dengan betul (tiada imej pecah)
    - [ ] Video dimainkan (jika ada)
    - [ ] Saiz fail output dalam had yang munasabah
