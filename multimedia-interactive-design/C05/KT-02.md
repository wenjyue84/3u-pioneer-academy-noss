## Bahagian B: Soalan Berstruktur / Section B: Structured Questions (40 markah)

**Soalan 7** (20 markah)

Sebuah syarikat latihan memerlukan anda membangunkan modul e-pembelajaran interaktif untuk melatih kakitangan baru tentang prosedur keselamatan kebakaran. Modul ini perlu:
- Dihantar melalui LMS syarikat (Moodle)
- Menyokong penjejakan kemajuan pelatih
- Merangkumi 4 topik dengan kuiz akhir
- Sesuai untuk diakses pada komputer desktop

A training company requires you to develop an interactive e-learning module to train new staff on fire safety procedures. The module needs to:
- Be delivered through the company LMS (Moodle)
- Support trainee progress tracking
- Cover 4 topics with a final quiz
- Be suitable for access on desktop computers

(a) Cadangkan perisian pengarangan yang paling sesuai untuk membangunkan modul ini. Berikan justifikasi yang jelas berdasarkan keperluan projek. (6 markah)
Suggest the most suitable authoring software to develop this module. Provide clear justification based on the project requirements.

(b) Terangkan format output yang perlu digunakan dan mengapa ia sesuai untuk keperluan projek ini. (4 markah)
Explain the output format that should be used and why it is appropriate for this project's requirements.

(c) Huraikan langkah-langkah utama dalam proses pembangunan modul e-pembelajaran ini menggunakan perisian yang anda cadangkan. (10 markah)
Describe the main steps in the development process of this e-learning module using the software you suggested.

**Soalan 8** (20 markah)

Anda dikehendaki membangunkan laman web interaktif menggunakan HTML5 dan JavaScript untuk mempromosikan sebuah majlis kebudayaan. Laman web ini perlu mengandungi galeri foto interaktif, klip video, dan borang pendaftaran peserta.

You are required to develop an interactive website using HTML5 and JavaScript to promote a cultural event. The website needs to contain an interactive photo gallery, video clips, and a participant registration form.

(a) Tulis kod HTML5 asas untuk menyematkan SATU (1) video dalam laman web tersebut. Video mestilah mempunyai kawalan pemutaran. (5 markah)
Write the basic HTML5 code to embed ONE (1) video in the website. The video must have playback controls.

(b) Terangkan bagaimana anda akan memastikan laman web ini berfungsi dengan baik pada pelbagai pelayar web (cross-browser compatibility). (5 markah)
Explain how you would ensure this website functions properly across various web browsers (cross-browser compatibility).

(c) Nyatakan rangka kerja JavaScript (JavaScript framework) yang paling sesuai untuk membangunkan galeri foto interaktif dan terangkan sebab pemilihan anda. (5 markah)
State the most appropriate JavaScript framework for developing the interactive photo gallery and explain your reason for the selection.

(d) Huraikan langkah-langkah untuk menerbitkan laman web ini ke platform dalam talian. (5 markah)
Describe the steps to publish this website to an online platform.

## Bahagian C: Esei / Section C: Essay (20 markah)

**Soalan 9** (20 markah)

Industri pembangunan multimedia interaktif menawarkan pelbagai perisian pengarangan dengan kelebihan dan kekangan tersendiri. Sebagai seorang pembangun multimedia interaktif, anda perlu bijak memilih perisian yang sesuai berdasarkan keperluan projek.

Bincangkan faktor-faktor yang perlu dipertimbangkan ketika memilih perisian pengarangan untuk sesebuah projek multimedia interaktif. Dalam perbincangan anda, rujuk sekurang-kurangnya DUA (2) perisian pengarangan yang berbeza dan berikan contoh jenis projek yang paling sesuai menggunakan setiap perisian tersebut.

The interactive multimedia development industry offers various authoring software with their own advantages and limitations. As an interactive multimedia developer, you need to be smart in choosing the right software based on project requirements.

Discuss the factors that need to be considered when choosing authoring software for an interactive multimedia project. In your discussion, refer to at least TWO (2) different authoring software and provide examples of project types most suitable for each software.
