## Tajuk / Title: Authoring Tools and Platforms for Interactive Multimedia

---

## 1. Objektif Pembelajaran / Learning Objectives

Selepas mempelajari Kertas Penerangan ini, pelatih akan dapat / After studying this Information Sheet, trainees will be able to:

1. Menerangkan kategori-kategori perisian pengarangan multimedia interaktif / Explain categories of interactive multimedia authoring software.
2. Mengenal pasti ciri-ciri utama perisian pengarangan yang biasa digunakan / Identify key features of commonly used authoring software.
3. Membandingkan kelebihan dan kelemahan pelbagai platform pengarangan / Compare advantages and limitations of various authoring platforms.
4. Memilih perisian pengarangan yang sesuai berdasarkan keperluan projek / Select appropriate authoring software based on project requirements.
5. Menerangkan konsep asas pengaturcaraan interaktif menggunakan perisian pengarangan / Explain basic interactive programming concepts using authoring software.

---

## 2. Pengenalan Perisian Pengarangan / Introduction to Authoring Software

**Perisian pengarangan (authoring software)** ialah aplikasi komputer yang digunakan oleh pembangun multimedia untuk mencipta produk multimedia interaktif tanpa memerlukan kemahiran pengaturcaraan yang mendalam. Perisian ini menyediakan persekitaran pembangunan bersepadu yang menggabungkan teks, grafik, audio, video, dan elemen interaktif.

### 2.1 Fungsi Utama Perisian Pengarangan / Key Functions of Authoring Software

- Menyediakan persekitaran reka bentuk visual / Provide visual design environment
- Membolehkan pembinaan elemen interaktif tanpa pengaturcaraan kompleks / Enable building interactive elements without complex programming
- Mengurus aset multimedia (audio, video, grafik) / Manage multimedia assets
- Mengeksport produk siap dalam pelbagai format output / Export finished products in various output formats
- Menyediakan alat pengujian dan penyahpepijatan / Provide testing and debugging tools

---

## 3. Kategori Perisian Pengarangan / Categories of Authoring Software

### 3.1 Berasaskan Timeline / Timeline-Based

Perisian jenis ini menggunakan garis masa (timeline) sebagai asas pembinaan animasi dan interaktiviti. Pembangun meletakkan elemen pada frame-frame tertentu dalam timeline.

**Contoh:** Adobe Animate, Adobe Flash (legacy)

**Ciri-ciri:**
- Kawalan tepat ke atas pemasaan animasi / Precise control over animation timing
- Sesuai untuk animasi yang kompleks / Suitable for complex animations
- Memerlukan pengetahuan ActionScript / JavaScript untuk interaktiviti lanjutan / Requires ActionScript / JavaScript for advanced interactivity

### 3.2 Berasaskan Halaman / Page-Based (Slide-Based)

Kandungan disusun dalam halaman atau slaid yang dihubungkan dengan navigasi.

**Contoh:** Articulate Storyline, Adobe Captivate, Microsoft PowerPoint (asas)

**Ciri-ciri:**
- Mudah untuk pemula / Easy for beginners
- Sesuai untuk e-pembelajaran dan persembahan / Suitable for e-learning and presentations
- Menyokong output SCORM untuk LMS / Supports SCORM output for LMS

### 3.3 Berasaskan Objek / Object-Based (Icon/Flow-Based)

Elemen-elemen projek diwakili sebagai objek yang dihubungkan dengan ikon atau carta alir.

**Contoh:** Adobe Authorware (legacy), Lectora Inspire

**Ciri-ciri:**
- Visualisasi aliran logik yang jelas / Clear visualisation of logic flow
- Sesuai untuk simulasi yang kompleks / Suitable for complex simulations

### 3.4 Berasaskan Web / Web-Based (HTML5)

Pembangunan menggunakan teknologi web standard (HTML5, CSS3, JavaScript).

**Contoh:** Adobe Animate (output HTML5), Tumult Hype, Google Web Designer

**Ciri-ciri:**
- Output berjalan pada semua pelayar moden tanpa plugin / Output runs on all modern browsers without plugins
- Responsif untuk pelbagai saiz skrin / Responsive for various screen sizes
- Paling sesuai untuk deployment web / Best suited for web deployment

---

## 4. Perisian Pengarangan Utama / Major Authoring Software

### 4.1 Adobe Animate

**Syarikat:** Adobe Systems | **Platform:** Windows, macOS

Adobe Animate (dahulu Adobe Flash Professional) ialah perisian pengarangan berasaskan timeline yang digunakan untuk mencipta animasi dan kandungan interaktif untuk web, aplikasi mudah alih, dan persembahan.

#### Antara Muka Adobe Animate / Adobe Animate Interface

| Komponen | Fungsi |
|----------|--------|
| **Stage** | Kawasan kerja utama di mana kandungan visual diletakkan / Main workspace where visual content is placed |
| **Timeline** | Panel kawalan masa untuk animasi dan frame-by-frame content / Time control panel for animations |
| **Library** | Penyimpanan semua aset projek (simbol, bitmap, audio, video) / Storage for all project assets |
| **Properties Panel** | Paparan dan pengeditan sifat objek terpilih / Display and editing of selected object properties |
| **Tools Panel** | Alat reka bentuk dan lukisan / Design and drawing tools |
| **Actions Panel** | Editor kod ActionScript / JavaScript / ActionScript / JavaScript code editor |

#### Konsep Utama Adobe Animate / Key Concepts

1. **Simbol (Symbol)** — Objek boleh guna semula dalam projek: Graphic, Button, Movie Clip.
2. **Frame dan Keyframe** — Unit asas timeline; keyframe menandakan perubahan dalam animasi.
3. **Tween Animasi** — Animasi automatik antara dua keyframe: Classic Tween, Motion Tween, Shape Tween.
4. **ActionScript / JavaScript** — Bahasa pengaturcaraan untuk menambah interaktiviti.
5. **Scene** — Bahagian projek yang boleh digunakan untuk mengatur kandungan.

#### Jenis Output Adobe Animate / Output Types

| Format | Kegunaan |
|--------|----------|
| HTML5 Canvas | Laman web, aplikasi web / Websites, web applications |
| WebGL | Grafik 3D berasaskan web / Web-based 3D graphics |
| AIR for Desktop | Aplikasi desktop (Windows/macOS) / Desktop applications |
| AIR for Android/iOS | Aplikasi mudah alih / Mobile applications |
| SVG | Grafik vektor berskala / Scalable vector graphics |

### 4.2 Articulate Storyline 360

**Syarikat:** Articulate Global | **Platform:** Windows

Articulate Storyline ialah perisian pengarangan e-pembelajaran berasaskan slaid yang digunakan secara meluas untuk mencipta kursus e-pembelajaran interaktif.

#### Ciri-Ciri Utama / Key Features

1. **Slide View** — Reka bentuk slaid seperti PowerPoint dengan keupayaan interaktif.
2. **Triggers** — Tindakan yang berlaku apabila pengguna berinteraksi (contoh: klik butang → tunjuk lapisan).
3. **Variables** — Pemboleh ubah untuk menyimpan data pengguna (skor, pilihan, status).
4. **Layers** — Lapisan tambahan pada slaid untuk kandungan bersyarat.
5. **States** — Keadaan visual objek (Normal, Hover, Selected, Visited, Hidden).
6. **Quiz Templates** — Templat soalan pra-bina (MCQ, True/False, Drag-and-Drop, dll.).
7. **SCORM/xAPI Export** — Output standard untuk LMS (Learning Management System).

#### Aliran Kerja Articulate Storyline / Storyline Workflow

```
Bina Slaid → Tambah Media → Tetapkan Triggers → Uji → Terbit (SCORM/HTML5)
Create Slides → Add Media → Set Triggers → Preview → Publish (SCORM/HTML5)
```

### 4.3 Adobe Captivate

**Syarikat:** Adobe Systems | **Platform:** Windows, macOS

Adobe Captivate ialah perisian pengarangan e-pembelajaran yang khusus untuk mencipta simulasi perisian, demonstrasi interaktif, dan kursus e-pembelajaran responsif.

#### Ciri-Ciri Utama / Key Features

- **Screen Recording** — Merakam skrin komputer untuk mencipta simulasi perisian secara automatik.
- **Responsive Design** — Reka bentuk adaptif untuk pelbagai peranti.
- **360° Media** — Menyokong foto dan video 360 darjah untuk pengalaman VR.
- **SCORM/xAPI** — Output standard e-pembelajaran.
- **Smart Shapes** — Bentuk dengan keupayaan interaktif terbina.

### 4.4 HTML5 dengan JavaScript

Pembangunan multimedia interaktif secara langsung menggunakan teknologi web:

| Teknologi | Peranan |
|-----------|---------|
| **HTML5** | Struktur dan kandungan halaman / Page structure and content |
| **CSS3** | Gaya visual, animasi asas / Visual styling, basic animations |
| **JavaScript** | Logik interaktif, manipulasi DOM / Interactive logic, DOM manipulation |
| **Canvas API** | Grafik dan animasi berasaskan pixel / Pixel-based graphics and animation |
| **Web Audio API** | Kawalan audio terperinci / Detailed audio control |
| **Video API** | Kawalan video terprogram / Programmatic video control |

#### Rangka Kerja / Frameworks

| Rangka Kerja | Kegunaan |
|--------------|----------|
| **GreenSock (GSAP)** | Animasi HTML5 yang kompleks / Complex HTML5 animation |
| **CreateJS** | Suite alat untuk HTML5 Canvas / Tools suite for HTML5 Canvas |
| **jQuery** | Manipulasi DOM dan pengendalian acara / DOM manipulation and event handling |
| **Phaser** | Pembangunan permainan HTML5 / HTML5 game development |

## 8. Rumusan / Summary

Perisian pengarangan multimedia interaktif boleh dikategorikan kepada empat jenis utama: berasaskan timeline, berasaskan halaman, berasaskan objek, dan berasaskan web. Adobe Animate sesuai untuk animasi dan kandungan interaktif web; Articulate Storyline untuk e-pembelajaran dengan output SCORM; Adobe Captivate untuk simulasi perisian; dan HTML5/JavaScript untuk projek web dengan kawalan kreatif penuh. Pemilihan perisian yang tepat bergantung kepada jenis projek, bajet, kepakaran pasukan, dan keperluan output. Seorang pengamal multimedia interaktif profesional perlu menguasai sekurang-kurangnya satu perisian pengarangan utama dan memahami asas HTML5/JavaScript.
