### FASA 1: PERSEDIAAN SEBELUM EKSPORT

**Langkah 1 — Semakan Akhir Projek Sebelum Eksport**

- [ ] Buka projek DAW dari KK-03 dan mainkan semula dari awal hingga akhir.
- [ ] Dengarkan dengan teliti pada fon telinga — cari sebarang masalah yang mungkin terlepas pandang:
  - Bunyi pop atau klik yang tidak diingini
  - Hingar yang berlebihan pada bahagian senyap
  - Fade in/out yang tidak halus
  - Tahap kelantangan yang tidak konsisten
- [ ] Catat sebarang masalah yang ditemui dan lakukan pembetulan sebelum meneruskan ke langkah eksport.

- [ ] Pantau meter pada trek master semasa main balik.

### FASA 2: EKSPORT FAIL AUDIO

**Langkah 4 — Eksport Format WAV (Master / Lossless)**

- [ ] Pastikan keseluruhan campuran dipilih (dari permulaan hingga akhir projek).
- [ ] Navigasi ke menu eksport dalam DAW:
  - **Audacity:** File > Export > Export as WAV
  - **Adobe Audition:** File > Export > File
- [ ] Tetapkan parameter eksport WAV:

| Parameter | Nilai |
| --- | --- |
| Format | WAV (Microsoft) |
| Sample Rate | 48,000 Hz |
| Bit Depth | 24-bit PCM |
| Channel | Stereo |

- [ ] Namakan fail: `[NoPelatih]_VO-Mix_Master_48k-24bit.wav`
- [ ] Simpan ke folder `03-mixed/`.
- [ ] Klik **Export / OK** dan tunggu sehingga selesai.

**Catatan pelatih:**

_______________________________________________

---

**Langkah 5 — Eksport Format MP3 (Pengedaran Umum)**

- [ ] Gunakan fail WAV yang baru dieksport sebagai sumber, atau eksport terus dari DAW.
- [ ] Tetapkan parameter eksport MP3:

| Parameter | Nilai |
| --- | --- |
| Format | MP3 |
| Bit Rate | 192 kbps (stereo) atau 128 kbps (mono, untuk podcast) |
| Sample Rate | 44,100 Hz |
| Channel | Stereo |

- [ ] Namakan fail: `[NoPelatih]_VO-Mix_Delivery_44k1-192kbps.mp3`
- [ ] Simpan ke folder `04-delivery/MP3/`.

**Catatan pelatih:**

_______________________________________________

| Channel | Stereo |

### FASA 3: SEMAKAN KUALITI (QUALITY CONTROL / QC)

**Langkah 7 — Semak Fail Eksport WAV**

- [ ] Buka fail WAV yang baru dieksport dalam pemutar media atau DAW baharu.
- [ ] Dengarkan dari awal hingga akhir.
- [ ] Sahkan: durasi betul, tiada clipping, fade in/out berfungsi, kualiti audio terpelihara.
- [ ] Semak sifat fail (file properties): saiz fail, sample rate, bit depth.
