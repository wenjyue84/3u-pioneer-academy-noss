## Prosedur Langkah demi Langkah / Step-by-Step Procedure

**LANGKAH 1: Persediaan Awal / Initial Preparation**

1. Hidupkan komputer dan log masuk ke akaun pengguna anda / Power on the computer and log in to your user account.
2. Buka folder kerja projek anda dan pastikan ia mengikut struktur folder yang betul / Open your project work folder and ensure it follows the correct folder structure.
3. Terima dokumen taklimat projek daripada pensyarah (dalam format PDF atau cetak) / Receive the project brief document from the instructor (in PDF format or printed).
4. Baca taklimat projek sekali sepenuhnya tanpa membuat nota dahulu untuk memahami gambaran keseluruhan / Read the project brief once fully without taking notes first to understand the overall picture.

**LANGKAH 2: Bacaan Semula dan Anotasi Taklimat / Re-reading and Annotating the Brief**

5. Baca semula taklimat projek untuk kali kedua, kali ini buat anotasi (garis bawah, tanda sisi) pada maklumat penting berikut / Re-read the project brief for the second time, this time annotating (underline, side marks) the following important information:
   - Nama dan latar belakang klien / Client name and background
   - Objektif projek / Project objectives
   - Skop kerja / Scope of work
   - Khalayak sasaran / Target audience
   - Jangka masa / Timeline
   - Bajet / Budget
   - Platform/medium penghantaran / Delivery platform/medium
   - Panduan reka bentuk / Design guidelines

**LANGKAH 3: Analisis Menggunakan Kaedah 5W1H / Analysis Using 5W1H Method**

6. Buka Borang Analisis 5W1H yang disediakan / Open the provided 5W1H Analysis Form.
7. Isi setiap bahagian borang 5W1H berdasarkan maklumat dalam taklimat projek / Fill in each section of the 5W1H form based on information in the project brief:
   - **WHO:** Siapa klien? Siapa khalayak sasaran? Siapa ahli pasukan?
   - **WHAT:** Apa produk multimedia yang perlu dihasilkan? Apa format penghantaran?
   - **WHEN:** Bila tarikh siap? Apa jangka masa setiap fasa?
   - **WHERE:** Di mana produk akan digunakan? Di mana rakaman/penghasilan berlaku?
   - **WHY:** Mengapa projek ini diperlukan? Apa masalah yang diselesaikan?
   - **HOW:** Bagaimana produk akan disampaikan? Apa teknologi/platform?
8. Bagi mana-mana soalan 5W1H yang tidak dijawab dalam taklimat, tandakan sebagai "MAKLUMAT DIPERLUKAN" dan sediakan soalan susulan / For any 5W1H questions not answered in the brief, mark as "INFORMATION REQUIRED" and prepare follow-up questions.

**LANGKAH 4: Penerapan Keutamaan MoSCoW / Applying MoSCoW Prioritisation**

9. Buka Borang MoSCoW yang disediakan / Open the provided MoSCoW Form.
10. Berdasarkan analisis 5W1H, senaraikan semua keperluan projek yang dikenal pasti / Based on the 5W1H analysis, list all identified project requirements.
11. Kategorikan setiap keperluan ke dalam kumpulan MoSCoW yang sesuai / Categorise each requirement into the appropriate MoSCoW group:
    - **Must Have:** Keperluan wajib — projek tidak boleh dihantar tanpanya
    - **Should Have:** Keperluan penting tetapi ada alternatif sementara
    - **Could Have:** Keperluan yang diingini jika masa dan bajet mengizinkan
    - **Won't Have:** Keperluan yang disepakati tidak akan dilaksanakan dalam skop ini
12. Sahkan kategorisasi MoSCoW dengan membaca semula taklimat sekali lagi / Verify the MoSCoW categorisation by re-reading the brief once more.

**LANGKAH 5: Mengenal Pasti Maklumat Kurang dan Sediakan Soalan Klien / Identifying Information Gaps and Preparing Client Questions**

13. Semak borang 5W1H dan senaraikan semua maklumat yang tidak terdapat dalam taklimat / Check the 5W1H form and list all information not found in the brief.
14. Hasilkan senarai soalan yang perlu dikemukakan kepada klien dalam mesyuarat susulan / Produce a list of questions to be raised with the client in the follow-up meeting.
15. Susun soalan mengikut keutamaan (paling kritikal dahulu) / Arrange questions by priority (most critical first).

**LANGKAH 6: Penyediaan Dokumen Keperluan Projek / Preparing Project Requirements Document**

16. Buka perisian pemproses kata (MS Word atau Google Docs) / Open the word processing software (MS Word or Google Docs).
17. Hasilkan dokumen keperluan projek dengan bahagian-bahagian berikut / Produce a project requirements document with the following sections:
    - Tajuk dan maklumat projek
    - Ringkasan eksekutif (1 perenggan)
    - Dapatan analisis 5W1H
    - Senarai keperluan MoSCoW
    - Soalan susulan untuk klien
    - Andaian awal projek
    - Risiko awal yang dikenal pasti
18. Format dokumen dengan kemas menggunakan gaya tajuk, jadual dan senarai bertanda / Format the document neatly using heading styles, tables and bulleted lists.
19. Simpan dokumen dalam format .docx dengan nama fail mengikut konvensyen: `[KodProjek]_AnalisisTaklimat_v1.docx` / Save the document in .docx format with filename following convention.

**LANGKAH 7: Semakan dan Pengesahan / Review and Verification**

20. Semak semula dokumen keperluan yang dihasilkan berdasarkan senarai semak di bawah / Review the produced requirements document based on the checklist below.
21. Lakukan pembetulan yang perlu sebelum menghantar kepada pensyarah / Make necessary corrections before submitting to instructor.
22. Simpan salinan sandaran dalam folder backup / Save a backup copy in the backup folder.
23. Cetak satu salinan dokumen akhir untuk diserahkan kepada pensyarah / Print one copy of the final document to submit to instructor.
