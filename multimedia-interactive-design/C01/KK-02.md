## Prosedur Langkah demi Langkah / Step-by-Step Procedure

**LANGKAH 1: Semakan Analisis Taklimat / Reviewing Brief Analysis**

1. Buka dan semak semula dokumen keperluan projek yang dihasilkan dalam KK-01 / Open and review the project requirements document produced in KK-01.
2. Fokus khususnya pada objektif projek, khalayak sasaran, mesej utama dan panduan reka bentuk / Focus specifically on project objectives, target audience, key message and design guidelines.
3. Senaraikan 3-5 kata kunci yang akan menjadi asas hala tuju kreatif projek / List 3-5 keywords that will form the basis of the project's creative direction.

**LANGKAH 2: Sesi Brainstorming dan Mind Mapping / Brainstorming and Mind Mapping Session**

4. Ambil sekeping kertas A3 dan tuliskan tajuk projek di bahagian tengah / Take a piece of A3 paper and write the project title in the centre.
5. Lakukan brainstorming idea kreatif secara bebas selama 10-15 minit / Freely brainstorm creative ideas for 10-15 minutes.
6. Hasilkan peta minda (mind map) yang menghubungkan / Produce a mind map linking:
   - Mesej utama / Main message
   - Nada visual (mood) / Visual tone (mood)
   - Warna yang dicadangkan / Proposed colours
   - Elemen visual utama / Key visual elements
   - Jenis muzik/audio / Music/audio type
   - Pendekatan penceritaan / Storytelling approach
7. Pilih dan tandakan idea-idea terbaik dalam peta minda / Select and mark the best ideas in the mind map.
8. Persetujui hala tuju konsep utama sebelum meneruskan ke mood board / Agree on the main concept direction before proceeding to mood board.

**LANGKAH 3: Penghasilan Mood Board Digital / Creating a Digital Mood Board**

9. Buka perisian reka bentuk pilihan anda (Canva, Adobe Express atau Photoshop) / Open your preferred design software (Canva, Adobe Express or Photoshop).
10. Hasilkan kanvas mood board dalam saiz A3 (landscape) atau saiz setara / Create a mood board canvas in A3 size (landscape) or equivalent.
11. Cari dan kumpulkan imej rujukan visual dari sumber bebas hak cipta (Unsplash, Pexels, Pixabay) / Search and collect visual reference images from copyright-free sources (Unsplash, Pexels, Pixabay).
12. Susun minimum 12 elemen visual dalam mood board, termasuk / Arrange a minimum of 12 visual elements in the mood board, including:
    - Imej/foto rujukan gaya visual / Visual style reference images/photos
    - Palet warna (minimum 5 warna dengan kod hex) / Colour palette (minimum 5 colours with hex codes)
    - Contoh tipografi / Typography examples
    - Contoh ikonografi atau ilustrasi / Iconography or illustration examples
    - Contoh komposisi layout / Layout composition examples
13. Tambah label dan anotasi pada setiap elemen mood board / Add labels and annotations to each mood board element.
14. Simpan mood board dalam format PNG atau PDF / Save mood board in PNG or PDF format.

**LANGKAH 4: Pembangunan Konsep Kreatif / Developing Creative Concept**

15. Berdasarkan peta minda dan mood board, tulis kenyataan konsep kreatif dalam 1-2 perenggan yang menerangkan / Based on the mind map and mood board, write a creative concept statement in 1-2 paragraphs explaining:
    - Hala tuju visual keseluruhan / Overall visual direction
    - Nada dan suasana yang ingin dicapai / Tone and mood to be achieved
    - Pendekatan penceritaan / Storytelling approach
    - Justifikasi bagaimana konsep memenuhi keperluan klien / Justification of how concept meets client needs
16. Tentukan elemen multimedia yang akan digunakan (contoh: animasi teks, footage sebenar, motion graphics, dll.) / Determine multimedia elements to be used (e.g.: text animation, real footage, motion graphics, etc.).

**LANGKAH 5: Penulisan Skrip Multimedia / Writing the Multimedia Script**

17. Buka templat skrip multimedia yang disediakan atau buka perisian pemproses kata / Open the provided multimedia script template or open word processing software.
18. Isi maklumat tajuk skrip: nama projek, versi, tarikh, penulis / Fill in script header information: project name, version, date, writer.
19. Bahagikan skrip kepada adegan/segmen mengikut struktur naratif tiga babak / Divide the script into scenes/segments following the three-act narrative structure:
    - **Babak 1 (Setup):** Perkenalkan konteks, watak atau produk (lebih kurang 20% masa)
    - **Babak 2 (Development):** Kembangkan mesej utama, tunjukkan nilai atau kelebihan (lebih kurang 60% masa)
    - **Babak 3 (Resolution):** Call-to-action, kesimpulan, jenama (lebih kurang 20% masa)
20. Untuk setiap adegan, tulis / For each scene, write:
    - Nombor adegan dan tajuk / Scene number and title
    - Penerangan visual / Visual description
    - Dialog atau naratif voiceover / Dialogue or voiceover narration
    - Arahan audio/muzik / Audio/music direction
    - Anggaran masa / Estimated timing
21. Pastikan jumlah masa skrip sesuai dengan tempoh projek yang ditetapkan / Ensure total script timing matches the project's specified duration.

**LANGKAH 6: Semakan Skrip Berpasangan / Peer Script Review**

22. Tukar skrip dengan rakan pasangan anda untuk semakan berpasangan (peer review) / Exchange script with your partner for peer review.
23. Semak skrip rakan anda berdasarkan kriteria berikut dan beri maklum balas bertulis / Review your partner's script based on the following criteria and provide written feedback:
    - Adakah skrip menepati objektif projek?
    - Adakah mesej utama disampaikan dengan jelas?
    - Adakah nada skrip sesuai dengan khalayak sasaran?
    - Adakah jumlah masa realistik?
    - Adakah terdapat bahagian yang mengelirukan atau tidak jelas?
24. Terima maklum balas daripada pasangan anda / Receive feedback from your partner.

**LANGKAH 7: Pemurnian dan Finalisasi / Refinement and Finalisation**

25. Semak maklum balas daripada pasangan dan pensyarah / Review feedback from partner and instructor.
26. Lakukan pindaan yang perlu pada skrip berdasarkan maklum balas / Make necessary revisions to the script based on feedback.
27. Simpan versi akhir skrip sebagai: `[KodProjek]_Skrip_v[nombor]_final.docx` / Save final version of script as: `[ProjectCode]_Script_v[number]_final.docx`.
28. Cetak satu salinan akhir skrip untuk diserahkan kepada pensyarah / Print one final copy of the script to submit to instructor.
