## Prosedur Langkah demi Langkah / Step-by-Step Procedure

**LANGKAH 1: Semakan Keperluan Sumber / Reviewing Resource Requirements**

1. Buka dokumen keperluan projek yang dihasilkan dalam KK-01 / Open the project requirements document produced in KK-01.
2. Kenal pasti semua jenis aset digital yang diperlukan untuk projek ini berdasarkan skrip dan papan cerita (KK-02 dan KK-03) / Identify all types of digital assets needed for this project based on the script and storyboard (KK-02 and KK-03).
3. Hasilkan senarai aset awal yang merangkumi / Produce an initial asset list covering:
   - Imej dan foto yang diperlukan / Required images and photos
   - Fail audio: muzik latar, SFX, voiceover / Audio files: background music, SFX, voiceover
   - Fon tipografi / Typography fonts
   - Ikon dan elemen grafik / Icons and graphic elements
   - Klip video (jika diperlukan) / Video clips (if required)
   - Templat atau aset lain / Templates or other assets

**LANGKAH 2: Persediaan Persekitaran Kerja / Work Environment Setup**

4. Laraskan kerusi ke ketinggian yang ergonomik — paha selari dengan lantai, kaki rata / Adjust chair to ergonomic height — thighs parallel to floor, feet flat.
5. Laraskan monitor supaya bahagian atas skrin sejajar dengan paras mata dan pada jarak 50-70 cm dari mata / Adjust monitor so the top of screen is at eye level and at a distance of 50-70 cm from eyes.
6. Pastikan pencahayaan bengkel mencukupi dan elakkan silau pada skrin / Ensure workshop lighting is adequate and avoid screen glare.
7. Lakukan kalibrasi asas monitor (jika alat tersedia) atau semak tetapan kecerahan dan suhu warna monitor / Perform basic monitor calibration (if tools available) or check monitor brightness and colour temperature settings.
   - Kecerahan / Brightness: 80-120 cd/m² (bergantung kepada pencahayaan bilik)
   - Suhu warna / Colour temperature: 6500K (D65)

**LANGKAH 3: Pemasangan dan Konfigurasi Perisian / Software Installation and Configuration**

8. Semak sama ada semua perisian yang diperlukan telah dipasang dan dikemaskini / Check whether all required software is installed and updated.
9. Jika ada perisian yang perlu dipasang, muat turun daripada sumber rasmi sahaja / If any software needs to be installed, download from official sources only.
10. Buka setiap perisian utama dan konfigurasikan tetapan workspace / Open each main software and configure workspace settings:
    - Adobe Photoshop: tetapkan colour settings kepada sRGB IEC61966-2.1
    - Adobe Premiere Pro: tetapkan sequence settings mengikut format output projek (contoh: 1920×1080, 25fps)
    - Audacity/Audition: tetapkan kadar pensampelan kepada 44.1 kHz, 16-bit stereo
11. Pastikan perisian diaktifkan dengan lesen yang sah / Ensure software is activated with a valid licence.

**LANGKAH 4: Penghasilan Struktur Folder Projek / Creating Project Folder Structure**

12. Navigasi ke pemacu storan yang ditetapkan (contoh: D:\Projects\ atau folder kerja yang ditetapkan oleh pusat latihan) / Navigate to the designated storage drive (e.g.: D:\Projects\ or work folder designated by training centre).
13. Cipta folder projek utama dengan nama mengikut format: `[KodProjek]_[NamaProjek]` / Create the main project folder with a name following the format: `[ProjectCode]_[ProjectName]`.
14. Di dalam folder projek utama, cipta struktur folder sub-folder berikut / Inside the main project folder, create the following sub-folder structure:
    ```
    [NamaProjek]/
    ├── 01_Brief/
    ├── 02_Concept/
    │   ├── mind_maps/
    │   └── mood_boards/
    ├── 03_Script/
    ├── 04_Storyboard/
    │   ├── thumbnails/
    │   └── final/
    ├── 05_Assets/
    │   ├── images/
    │   │   ├── raw/
    │   │   └── edited/
    │   ├── audio/
    │   │   ├── music/
    │   │   ├── sfx/
    │   │   └── voiceover/
    │   ├── video/
    │   ├── graphics/
    │   │   ├── logos/
    │   │   └── ui_elements/
    │   └── fonts/
    ├── 06_Project_Files/
    ├── 07_Export/
    │   ├── drafts/
    │   └── final/
    └── 08_Client_Comms/
    ```
15. Pindahkan semua hasil kerja sebelum ini (output KK-01, KK-02, KK-03) ke dalam folder yang sesuai / Move all previous work outputs (KK-01, KK-02, KK-03 outputs) into the appropriate folders.

**LANGKAH 5: Pencarian dan Pengesahan Aset Digital / Searching and Verifying Digital Assets**

16. Berdasarkan senarai aset yang dihasilkan dalam Langkah 1, mulakan proses mencari aset dari sumber yang sah / Based on the asset list produced in Step 1, begin searching for assets from legitimate sources.
17. Untuk setiap aset yang ditemui, sebelum memuat turun, sahkan jenis lesennya / For each asset found, before downloading, verify its licence type:
    - Public Domain / CC0: boleh guna tanpa sebarang sekatan
    - CC BY: boleh guna dengan kredit kepada pencipta
    - CC BY-SA: boleh guna dengan kredit, karya terbitan mesti berlesen sama
    - Royalty-Free: mungkin memerlukan bayaran satu kali
18. Muat turun aset dan simpan dalam sub-folder yang sesuai dalam `05_Assets/` / Download assets and save in the appropriate sub-folder under `05_Assets/`.
19. Namakan semua fail aset mengikut konvensyen penamaan yang ditetapkan / Name all asset files following the established naming convention.

**LANGKAH 6: Dokumentasi Log Aset / Asset Log Documentation**

20. Buka perisian hamparan data (MS Excel atau Google Sheets) / Open spreadsheet software (MS Excel or Google Sheets).
21. Hasilkan log aset digital dengan lajur-lajur berikut / Produce a digital asset log with the following columns:

| Bil | Nama Fail | Jenis Aset | Sumber/URL | Jenis Lesen | Pencipta | Kredit Diperlukan | Tarikh Muat Turun | Lokasi Folder |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| | | | | | | | | |

22. Isikan log aset untuk SEMUA aset yang dimuat turun — minimum 10 aset perlu didokumentasikan / Fill in the asset log for ALL downloaded assets — minimum 10 assets must be documented.
23. Simpan log aset sebagai: `[KodProjek]_AssetLog_v1.xlsx` / Save the asset log as: `[ProjectCode]_AssetLog_v1.xlsx`.

**LANGKAH 7: Penyediaan Senarai Semak Sumber Projek / Preparing Project Resource Checklist**

24. Hasilkan senarai semak sumber projek yang komprehensif menggunakan MS Word atau Google Docs / Produce a comprehensive project resource checklist using MS Word or Google Docs.
25. Senarai semak hendaklah merangkumi bahagian-bahagian berikut / The checklist should include the following sections:
    - Senarai semak perkakasan (komputer, monitor, periferi)
    - Senarai semak perisian (semua perisian dipasang dan dilesen)
    - Senarai semak persekitaran kerja (ergonomik, pencahayaan, kalibrasi)
    - Senarai semak aset digital (imej, audio, font, video)
    - Senarai semak pengurusan fail (struktur folder, konvensyen penamaan)
    - Senarai semak sandaran data
26. Tandakan setiap perkara dalam senarai semak dengan status semasa: Lengkap / Dalam Proses / Belum Dilakukan / Mark each item in the checklist with current status: Complete / In Progress / Not Started.
27. Simpan senarai semak sebagai: `[KodProjek]_ResourceChecklist_v1.docx` / Save the checklist as: `[ProjectCode]_ResourceChecklist_v1.docx`.

**LANGKAH 8: Sandaran Data dan Pengesahan Akhir / Data Backup and Final Verification**

28. Lakukan sandaran penuh semua fail projek ke USB Drive atau storan awan / Perform a full backup of all project files to USB Drive or cloud storage.
29. Sahkan sandaran berjaya dengan membuka beberapa fail dari lokasi sandaran / Verify the backup was successful by opening several files from the backup location.
30. Lakukan semakan akhir menggunakan senarai semak kualiti di bawah / Perform a final check using the quality checklist below.
31. Serahkan senarai semak sumber yang lengkap, log aset dan bukti struktur folder kepada pensyarah untuk penilaian / Submit the complete resource checklist, asset log and folder structure evidence to instructor for assessment.
