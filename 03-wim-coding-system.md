# WIM Coding System and Formatting Rules

## WIM Coding Format

Format: `[NOSS Code]-[CU Code]/[Document Code]([Sequence]/[Total])`

### Examples

| Code | Meaning |
|------|---------|
| `G452-010-3:2023-C01/KP(1/4)` | Information Sheet 1 of 4 for CU C01 (BEV) |
| `G452-010-3:2023-C01/KT(2/4)` | Assignment Sheet 2 of 4 for CU C01 |
| `G452-010-3:2023-C01/KK(1/3)` | Work Sheet 1 of 3 for CU C01 |
| `S960-002-3:2020-C01/KP(1/5)` | Information Sheet 1 of 5 for CU C01 (Aesthetic) |
| `IT-020-3:2013-C01/KP(1/7)` | Information Sheet 1 of 7 for CU C01 (IT) |

### CU Code Convention

CU codes use `C` prefix followed by a two-digit number:
- `C01` = Competency Unit 1 (Core)
- `C02` = Competency Unit 2 (Core)
- `E01` = Elective Unit 1

### Document Code Legend

| Code (BM) | Code (EN) | Document Type |
|-----------|-----------|--------------|
| KP | IS | Kertas Penerangan / Information Sheet |
| KT | AS | Kertas Tugasan / Assignment Sheet |
| KK | WS | Kertas Kerja / Work Sheet |
| PM | LP | Pelan Mengajar / Lesson Plan |
| KA | - | Penilaian Pengetahuan / Knowledge Assessment |
| PA | - | Penilaian Prestasi / Performance Assessment |

### Page Notation

Format: `Muka : [page] Drp : [total pages]`

Example: `Muka : 1 Drp : 23` means Page 1 of 23.

## Paper Color Requirements

| Document | Paper Color | Purpose |
|----------|-------------|---------|
| PM/LP (Lesson Plan) | YELLOW | Teaching plan |
| KP/IS (Information Sheet) | WHITE | Theory content |
| KT/AS (Assignment Sheet) | PINK | Theory exercises |
| KK/WS (Work Sheet) | BLUE | Practical instructions |
| KA (Knowledge Assessment) | PINK | Theory test |
| PA (Performance Assessment) | LIGHT BLUE (Ocean Blue) | Practical test |

## Typography Requirements

| Element | Font | Size | Style |
|---------|------|------|-------|
| Title | Arial | 18 | Bold |
| Body text | Arial | 12 | Regular |
| Line spacing | - | 1.5 | - |
| Headers | Arial | 14-16 | Bold |

## Language Rules

- WIM can be written in Bahasa Malaysia OR English
- If bilingual, the non-primary language must be italicized
- Technical terms may remain in English with BM translation in brackets
- Example: *High Voltage (HV)* — Voltan Tinggi

## Document Header Requirements

Every WIM document page must include:

1. **Institution logo** — top right corner
2. **Institution name and address** — top section, Arial Bold size 12
3. **Document code** — using the WIM coding format above
4. **Page notation** — `Muka : X Drp : Y`
5. **CU title** — full competency unit title

## Learning Objectives Rules

- Minimum 2, maximum 5 learning objectives per sheet
- Use active voice action verbs:
  - Theory: State, explain, describe, clarify, identify, list, define
  - Practical: Perform, demonstrate, execute, carry out, apply, operate
