## Prosedur Kerja / Work Steps

### Bahagian A: Pengiraan KPI Manual (30 minit)

**Langkah 1:** Menggunakan data dalam Dataset 1, kirakan KPI berikut untuk setiap bulan dan lengkapkan jadual di Borang Rekod A (halaman seterusnya):

- Yield Rate (%) = (Jumlah Unit - Unit Rosak) ÷ Jumlah Unit × 100
- PPM Defects = Unit Rosak ÷ Jumlah Unit × 1,000,000
- Availability (%) = Masa Operasi ÷ Masa Dirancang × 100
- Performance (%) = Kadar Pengeluaran Sebenar ÷ Kadar Pengeluaran Ideal × 100
- OEE (%) = Availability × Performance × Quality (Quality = Yield Rate / 100)

**Langkah 2:** Kenal pasti TIGA bulan dengan PPM tertinggi dan TIGA bulan dengan OEE terendah.

**Langkah 3:** Bina carta Pareto menggunakan data Dataset 2 (NCR mengikut jenis defek, jumlah tahunan). Kirakan % dan % kumulatif. Tentukan "vital few" — jenis defek yang menyumbang 80% NCR.

### Bahagian B: Membina Dashboard dalam Power BI (60 minit)

**Langkah 4:** Buka Power BI Desktop. Pilih **Get Data → Text/CSV**. Muat masuk `C07_KK01_dataset.csv`.

**Langkah 5:** Dalam **Data View**, bina Calculated Column berikut:
```
Yield Rate = ([Jumlah Unit] - [Unit Rosak]) / [Jumlah Unit] * 100
PPM = DIVIDE([Unit Rosak], [Jumlah Unit], 0) * 1000000
```

**Langkah 6:** Bina visual berikut dalam satu halaman laporan:
- Visual 1: Carta garis "OEE Trend 2026" — X: Bulan, Y: OEE (%)
- Visual 2: Carta garis "Yield Rate Trend 2026" — X: Bulan, Y: Yield Rate (%)
- Visual 3: Carta bar berkelompok "NCR Count Bulanan" — X: Bulan, Y: NCR Count
- Visual 4: Carta bar "Pareto Jenis Defek 2026" — dari data Dataset 2 (diasingkan)

**Langkah 7:** Tambah 4 "Card" visual untuk memaparkan:
- OEE Terkini (Dis 2026)
- PPM Terkini (Dis 2026)
- Jumlah NCR 2026
- Yield Rate Purata 2026

**Langkah 8:** Formatkan dashboard dengan warna yang konsisten. Tambah tajuk halaman: "Dashboard Kualiti 2026 — Syarikat Maju Presisi Sdn Bhd".

### Bahagian C: Carta Kawalan SPC (45 minit)

**Langkah 9:** Menggunakan Dataset 3, kirakan X-bar dan R untuk setiap subkumpulan secara manual (gunakan Excel jika perlu). Lengkapkan Borang Rekod B.

**Langkah 10:** Kirakan X-double-bar dan R-bar. Kemudian kirakan had kawalan:
- A₂ untuk n=5 = 0.577
- UCL = X-double-bar + (A₂ × R-bar)
- LCL = X-double-bar - (A₂ × R-bar)

**Langkah 11:** Plotkan carta X-bar menggunakan Excel atau Power BI. Lukis garis UCL, CL (pusat), dan LCL.

**Langkah 12:** Kenal pasti SEMUA subkumpulan yang mencetuskan isyarat keluar kawalan (gunakan Peraturan Western Electric). Tandakan dalam carta dengan warna merah.

### Bahagian D: Analisis dan Cadangan (30 minit)

**Langkah 13:** Berdasarkan dashboard dan carta SPC, jawab soalan dalam Borang Rekod C.

**Langkah 14:** Cetak atau eksport dashboard Power BI sebagai PDF. Serahkan bersama Borang Rekod kepada pengajar.
