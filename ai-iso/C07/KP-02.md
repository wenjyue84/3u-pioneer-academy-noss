## 1. Dashboard Kualiti — Konsep dan Keperluan

### 1.1 Apakah Dashboard Kualiti?

**Dashboard kualiti** adalah paparan visual interaktif yang mengumpulkan dan memaparkan data KPI kualiti dalam bentuk grafik, carta, dan angka ringkasan secara masa nyata (real-time) atau hampir masa nyata.

Keperluan ISO 9001:2015 Klausa 9.1.1 menyatakan bahawa organisasi mesti **menentukan apa yang perlu dipantau dan diukur, kaedah pemantauan, analisis, dan penilaian untuk memastikan keputusan yang sah**. Dashboard kualiti yang berkesan memenuhi keperluan ini.

### 1.2 Elemen Wajib Dashboard Kualiti untuk CU Ini

| Elemen Dashboard | KPI | Jenis Visualisasi |
|---|---|---|
| Trend OEE bulanan | OEE (%) | Carta garis (line chart) |
| Bilangan NCR bulanan ikut kategori | NCR count | Carta bar (bar chart) |
| Trend Yield Rate | Yield Rate (%) | Carta garis |
| 5 jenis defek teratas | Defect type | Carta Pareto |
| Carta SPC | Ukuran proses | Carta kawalan (control chart) |

## 2. Power BI AI untuk Kualiti

### 2.1 Gambaran Keseluruhan Power BI

**Microsoft Power BI** adalah platform analitik perniagaan yang membolehkan pengguna menghubungkan pelbagai sumber data, membina laporan interaktif, dan berkongsi dashboard melalui web atau mudah alih. Power BI mempunyai tiga komponen utama:

| Komponen | Fungsi |
|---|---|
| **Power BI Desktop** | Aplikasi Windows untuk membina laporan dan model data |
| **Power BI Service** | Platform cloud untuk berkongsi dan menerbit dashboard |
| **Power BI Mobile** | Apl mudah alih untuk melihat laporan |

### 2.2 Ciri AI dalam Power BI

Power BI menyertakan ciri AI yang relevan untuk analitik kualiti:

| Ciri AI | Fungsi | Kegunaan dalam Kualiti |
|---|---|---|
| **Q&A Natural Language** | Tanya soalan dalam bahasa biasa; Power BI jana visual jawapan | "Tunjukkan PPM untuk Januari hingga Jun 2026" |
| **Anomaly Detection** | AI mengesan titik data tidak normal secara automatik dalam carta garis | Mengesan lonjakan NCR yang tidak dijangka |
| **Key Influencers Visual** | AI mengenal pasti faktor yang paling mempengaruhi sesuatu metrik | Mengenal pasti punca utama peningkatan PPM |
| **Smart Narratives** | AI jana ringkasan teks automatik berdasarkan data | Jana rumusan trend OEE untuk laporan |
| **Decomposition Tree** | Visual analisis akar punca hierarki | Pecahkan NCR ikut kategori → punca → pekerja |

### 2.3 Langkah Membina Dashboard Kualiti Asas dalam Power BI

**Langkah 1: Sambung sumber data**
- Buka Power BI Desktop → Get Data → Excel / CSV / SQL Server
- Muat naik fail data pengeluaran bulanan

**Langkah 2: Bina model data**
- Pastikan jadual mempunyai: Tarikh, Nombor Lot, Jumlah Unit, Unit Rosak, Jenis Defek, No. Mesin
- Cipta Calculated Column untuk Yield Rate: `Yield Rate = [Unit Baik] / [Jumlah Unit] * 100`
- Cipta Measure untuk PPM: `PPM = DIVIDE([Unit Rosak], [Jumlah Unit], 0) * 1000000`

**Langkah 3: Bina visual**
- Seret "Tarikh" ke paksi X; "OEE" ke paksi Y → pilih Line Chart
- Bina Pareto chart: urutkan jenis defek dari tinggi ke rendah + tambah kumulatif %

**Langkah 4: Tetapkan peringatan automatik**
- Dalam Power BI Service → Set Alert pada ukuran PPM > 10,000
- Power BI akan hantar e-mel / notifikasi automatik apabila had dilanggar

**Langkah 5: Kongsikan dashboard**
- Terbit ke Power BI Workspace → kongsi dengan pengurus kualiti dan pengurusan atasan

### 2.4 Tableau AI

**Tableau** adalah alternatif Power BI yang lebih kuat untuk visualisasi data kompleks. Perbezaan utama:

| Aspek | Power BI | Tableau |

### 2.5 Google Looker

**Google Looker** adalah platform BI berasaskan cloud yang sesuai untuk berkongsi laporan dengan pelbagai pihak berkepentingan melalui pautan web. Kelebihan utama untuk kualiti:

## 3. Kawalan Proses Statistik (Statistical Process Control — SPC)

### 3.1 Apakah SPC?

**Statistical Process Control (SPC)** adalah kaedah yang menggunakan data statistik untuk memantau dan mengawal proses pengeluaran bagi memastikan produk yang konsisten mengikut spesifikasi. SPC menggunakan **carta kawalan (control charts)** untuk membezakan variasi normal daripada masalah sebenar.

SPC dikaitkan dengan ISO 9001:2015 Klausa 9.1.1 (Pemantauan, pengukuran, analisis, dan penilaian).

### 3.2 Dua Jenis Variasi Proses

| Jenis Variasi | Definisi | Punca | Tindakan |
|---|---|---|---|
| **Common Cause Variation (Variasi Sebab Biasa)** | Variasi semula jadi dalam proses yang terkawal; tidak boleh diramalkan titik mana yang tinggi/rendah | Bahagian kecil dalam komponen, suhu alam semula jadi, getaran kecil mesin | **Jangan bertindak balas** — tindakan balas membuat proses lebih tidak stabil (Russell Ackoff: "tampering") |
| **Special Cause Variation (Variasi Sebab Khas)** | Variasi yang tidak normal; menunjukkan sesuatu yang khusus berlaku | Bilah alat haus, pekerja baru tanpa latihan, bahan mentah lot berbeza | **Wajib bertindak** — kenal pasti dan buang punca |

### 3.3 Jenis-jenis Carta Kawalan

| Carta | Bila Digunakan | Data | Apa Yang Diukur |
|---|---|---|---|
| **X-bar / R Chart** | Data berterusan; sampel saiz 2–10 | Pengukuran fizikal (dimensi, berat, masa) | Purata sampel (X-bar) dan Julat (R) |
| **P-chart** | Data atribut; saiz sampel berbeza-beza | Peratusan cacat (bilangan ya/tidak) | Peratusan cacat per sampel |
| **C-chart** | Data atribut; saiz sampel tetap | Bilangan kecacatan per unit | Bilangan kecacatan per unit |

### 3.4 Pengiraan Had Kawalan untuk Carta X-bar

Had kawalan **bukan** had spesifikasi (specification limits). Had kawalan dikira dari data proses itu sendiri — ia menggambarkan had variasi semula jadi proses.

**Formula Had Kawalan (carta X-bar):**

```
UCL_X-bar = X-double-bar + A₂ × R-bar
CL_X-bar  = X-double-bar
LCL_X-bar = X-double-bar - A₂ × R-bar
```

Di mana:
- `X-double-bar` = purata semua purata sampel
- `R-bar` = purata semua julat sampel
- `A₂` = pemalar kawalan (bergantung pada saiz sampel, n)

**Nilai A₂ untuk saiz sampel biasa:**

| Saiz Sampel (n) | A₂ |
|---|---|
| 2 | 1.880 |
| 3 | 1.023 |
| 4 | 0.729 |
| 5 | 0.577 |
| 6 | 0.483 |

**Contoh Pengiraan Lengkap (Data Sintetik — Kilang Komponen PCB, Pasir Gudang):**

Pengukuran: Ketebalan lapisan solder (mm), saiz sampel n = 5, 10 subkumpulan.

| Subkumpulan | X₁ | X₂ | X₃ | X₄ | X₅ | X-bar (mm) | R (mm) |
|---|---|---|---|---|---|---|---|
| 1 | 0.31 | 0.29 | 0.33 | 0.30 | 0.32 | 0.310 | 0.04 |
| 2 | 0.28 | 0.32 | 0.30 | 0.31 | 0.29 | 0.300 | 0.04 |
| 3 | 0.30 | 0.31 | 0.30 | 0.32 | 0.30 | 0.306 | 0.02 |
| 4 | 0.29 | 0.30 | 0.31 | 0.29 | 0.32 | 0.302 | 0.03 |
| 5 | 0.33 | 0.31 | 0.30 | 0.32 | 0.31 | 0.314 | 0.03 |
| 6 | 0.30 | 0.29 | 0.32 | 0.30 | 0.31 | 0.304 | 0.03 |
| 7 | 0.31 | 0.30 | 0.29 | 0.31 | 0.30 | 0.302 | 0.02 |
| 8 | 0.29 | 0.32 | 0.31 | 0.30 | 0.29 | 0.302 | 0.03 |
| 9 | 0.30 | 0.31 | 0.32 | 0.29 | 0.30 | 0.304 | 0.03 |
| 10 | 0.32 | 0.30 | 0.31 | 0.31 | 0.30 | 0.308 | 0.02 |
| **Jumlah** | | | | | | **3.052** | **0.29** |

```
X-double-bar = 3.052 ÷ 10 = 0.3052 mm
R-bar        = 0.29 ÷ 10  = 0.029 mm

Dengan n = 5, A₂ = 0.577:

UCL_X-bar = 0.3052 + (0.577 × 0.029)
          = 0.3052 + 0.01673
          = 0.3219 mm

CL_X-bar  = 0.3052 mm

LCL_X-bar = 0.3052 - (0.577 × 0.029)
          = 0.3052 - 0.01673
          = 0.2885 mm
```

Semua 10 purata sampel berada dalam had kawalan (0.2885 mm hingga 0.3219 mm) → Proses **dalam kawalan** (in control).

### 3.5 Peraturan Western Electric — Mengenal Pasti Isyarat Keluar Kawalan

Carta kawalan dibahagikan kepada 3 zon (berdasarkan ±1σ, ±2σ, ±3σ dari garis pusat):

| Zon | Had |
|---|---|
| Zon A | Antara ±2σ dan ±3σ dari garis pusat |
| Zon B | Antara ±1σ dan ±2σ dari garis pusat |
| Zon C | Dalam ±1σ dari garis pusat |

**Empat Peraturan Utama (Western Electric Rules):**

| Peraturan | Isyarat Keluar Kawalan | Petanda |
|---|---|---|
| **Peraturan 1** | 1 titik melebihi ±3σ (luar Zon A) | Perubahan mendadak / ketakakuran serius |
| **Peraturan 2** | 2 daripada 3 titik berturut-turut dalam Zon A atau lebih jauh (sebelah yang sama) | Anjakan proses |
| **Peraturan 3** | 4 daripada 5 titik berturut-turut dalam Zon B atau lebih jauh (sebelah yang sama) | Anjakan proses yang lebih perlahan |
| **Peraturan 4** | 8 titik berturut-turut pada sebelah yang sama dari garis pusat | Proses telah beranjak ke paras baharu |

> **Amaran kepada penganalisis:** Apabila isyarat keluar kawalan dikesan, **jangan laras proses dahulu**. Selidik dahulu punca isyarat. Pelarasan tanpa penyelidikan punca akar boleh memperburuk proses (fenomenon "tampering").

### 3.6 AI dalam SPC — Peranan Automasi

Platform seperti Power BI AI, Tableau, dan sistem Manufacturing Execution System (MES) kini menggunakan AI untuk:

| Fungsi AI | Keterangan |
|---|---|
| **Pengesanan isyarat automatik** | AI memantau carta kawalan secara berterusan dan menghantar amaran apabila mana-mana peraturan Western Electric dilanggar |
| **Ramalan keluar kawalan** | Machine learning meramalkan bila proses akan keluar kawalan berdasarkan trend data — boleh bertindak sebelum masalah berlaku |
| **Klasifikasi punca akar** | AI membandingkan corak isyarat dengan pangkalan data sejarah untuk mencadangkan punca paling berkemungkinan |
| **Laporan SPC automatik** | AI menghasilkan laporan SPC harian tanpa campur tangan manual |

## 4. Carta Pareto untuk Penganalisaan Defek

### 4.1 Prinsip Pareto (80/20)

**Prinsip Pareto** menyatakan bahawa kira-kira **80% kesan berpunca daripada 20% punca**. Dalam kualiti, ini bermakna 20% jenis kecacatan menyumbang 80% daripada jumlah kecacatan.

Carta Pareto membantu pasukan kualiti **mengutamakan** tindakan pembetulan kepada kecacatan yang memberi kesan terbesar.

### 4.2 Membina Carta Pareto

**Contoh data (Data Sintetik — NCR bulanan kilang komponen):**

| Jenis Defek | Bilangan NCR | % | Kumulatif % |
|---|---|---|---|
| Solder bridging | 48 | 38.1% | 38.1% |
| Missing component | 31 | 24.6% | 62.7% |
| Misalignment | 22 | 17.5% | 80.2% |
| Insufficient solder | 14 | 11.1% | 91.3% |
| Tombstoning | 7 | 5.6% | 96.8% |
| Lain-lain | 4 | 3.2% | 100.0% |
| **Jumlah** | **126** | **100%** | |

Carta Pareto akan menunjukkan bahawa tiga jenis defek teratas (Solder bridging + Missing component + Misalignment) menyumbang 80.2% NCR — ini adalah **"vital few"** yang perlu difokuskan.
