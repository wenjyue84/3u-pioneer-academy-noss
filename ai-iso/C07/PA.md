### Aktiviti Kerja 2: IDENTIFY IMPROVEMENT OPPORTUNITIES USING AI PATTERN RECOGNITION

*(Dinilai semasa KK-01 — Analisis carta SPC dan pengenalpastian isyarat keluar kawalan)*

| No. | Kriteria Pemerhatian | Ya | Tidak | Catatan Assessor |
|---|---|---|---|---|
| 2.1 | Pelatih mengira X-bar dan R untuk setiap subkumpulan dengan betul | | | |
| 2.2 | X-double-bar dan R-bar dikira dengan betul | | | |
| 2.3 | UCL dan LCL dikira menggunakan formula yang betul (A₂ × R-bar) dengan nilai A₂ yang tepat untuk n=5 | | | |
| 2.4 | Carta SPC diplot dengan garis UCL, CL, dan LCL yang jelas | | | |
| 2.5 | Pelatih mengenal pasti isyarat keluar kawalan (subkumpulan 13–15 dalam dataset) menggunakan Peraturan Western Electric | | | |
| 2.6 | Pelatih dapat membezakan antara "common cause variation" dan "special cause variation" apabila ditanya | | | |
| 2.7 | Cadangan tindakan pembetulan yang dicadangkan adalah berkaitan dengan isyarat yang dikenal pasti | | | |
| 2.8 | Pelatih memahami bahawa proses tidak boleh dilaras sembarangan tanpa mengenal pasti jenis variasi terlebih dahulu | | | |

**Sub-jumlah Aktiviti Kerja 2** (1 markah setiap kriteria Ya): _____ / 8 markah

| Tahap | Markah | Deskripsi |
|---|---|---|
| **Cemerlang** | 8 | Semua pengiraan tepat; semua isyarat dikenal pasti; penjelasan variasi jelas dan tepat |
