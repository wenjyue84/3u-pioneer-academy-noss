**B3(a) — Skor Komposit Pembekal Alpha (8 markah):**

Penukaran markah yang betul: Kualiti (0.45% → Julat 0.11–0.50% → Markah 75), Penghantaran (93.2% → Julat 90–94.9% → Markah 70), NCR (58 jam → Julat 49–72 jam → Markah 60), CAPA (79% → Julat 75–84.9% → Markah 60), Dok (3 item → Julat 3–5 → Markah 60)

Skor Komposit: (75×0.40) + (70×0.30) + (60×0.15) + (60×0.10) + (60×0.05) = 30.0 + 21.0 + 9.0 + 6.0 + 3.0 = **69.0**

Pengesahan: 30.0 + 21.0 + 9.0 + 6.0 + 3.0 = 69.0 ✓

Status: **Bersyarat (Conditional)** (julat 55–69.9)

Tindakan: Masukkan ke Program Pembangunan Pembekal Peringkat 1; hantar surat maklum balas formal.

### Bahagian C — Panduan Pemarkahan

**C1 (20 markah):**
- (a) 6 markah: 2 markah setiap tindakan penahanan yang tepat (asingkan lot, hentikan penggunaan, notifikasi pasukan kualiti)

**C2 (20 markah):**
- 5 markah: Hubungan kegagalan pembekal — kualiti produk dengan contoh relevan
