# NOSS (National Occupational Skills Standards) Collection

## Welcome to the NOSS Information Hub

This repository contains comprehensive information about **NOSS** (National Occupational Skills Standards), Malaysia's premier skills development framework. NOSS is established by the **Department of Skills Development (DSD)** under the **Ministry of Human Resources, Malaysia**.

## 🏗️ NOSS Framework Structure

### Competency Levels
| Level | Certificate Type | Description |
|-------|------------------|-------------|
| **Level 1** | Malaysia Skills Certificate | Operation and Production Level |
| **Level 2** | Malaysia Skills Certificate | Operation and Production Level |
| **Level 3** | Malaysia Skills Certificate | Supervisory Level |
| **Level 4** | Malaysia Skills Diploma | Executive Level |
| **Level 5** | Malaysia Skills Advanced Diploma | Managerial Level |

### Document Types
- **Standard Practice (SP)**: Overview and framework information
- **Standard Content (SC)**: Detailed competency profiles and assessment criteria
- **Curriculum of Competency Units (CoCU)**: Detailed breakdown of each competency unit
- **Supporting Documents**: Executive summaries, job profiles, task analysis
