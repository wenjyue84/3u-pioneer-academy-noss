# Standard Rubric Template — WIM Performance Assessment (PA)

## Purpose

Defines the mandatory format for all PA rubric tables across all NOSS WIM subjects
(Tuinalogy, BEV, Aesthetic, IT). Every PA file must contain at least one compliant
rubric table for the validator to report it as compliant.

## Standard Rubric Format

Each rubric table MUST have the four required column headers (in any order, case-insensitive):

| Competency Dimension | Level Descriptor | Score | Evidence |
|----------------------|------------------|-------|----------|
| (criterion name)     | (what the level means) | (numeric) | (observable proof) |

### Column definitions

| Column | Aliases accepted | Description |
|--------|-----------------|-------------|
| **Competency Dimension** | Criteria, 评分项, Kriteria, Dimension | The skill or behaviour being assessed |
| **Level Descriptor** | Descriptor, Description, 满分, Level, Standard | Describes what competent performance looks like |
| **Score** | Marks, 评分, Markah, Points, Max | Numeric score or maximum points allocated |
| **Evidence** | Evidence Required, Proof, Observable, 证据 | Observable proof that criterion was met |

## Minimum Requirements

1. Every PA file must contain at least one rubric table
2. Rubric tables must have ≥ 3 columns matching the four required headers
3. A rubric table must have at least 2 data rows (beyond the header row)
4. Total marks must be traceable (either per-criterion or via a summary table)

## Passing Score Convention

- Competency-based: Minimum 70% (JPK standard) or as specified in the CU
- Criterion-based: Minimum Score 3/5 on descriptive rubrics (5-point scale)
- Point-based: ≥ 70/100 unless the NOSS CoCU specifies otherwise
