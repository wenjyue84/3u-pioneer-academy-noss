## Work Activity 3: Carry Out BEV HVAC System Servicing

## Objektif Prestasi
1. Perform HVAC system diagnostic inspection
2. Execute refrigerant recovery using recycling machine
3. Demonstrate HVAC component replacement
4. Perform HVAC system evacuation, recharge, and functionality test

## Equipment
- Diagnostic scan tool, air conditioning refrigerant recycling machine (R1234yf/R134a)
- Electronic refrigerant leak detector, temperature probe
- Insulated tools (for HV compressor work), common tools
- Replacement component (training part), new O-rings and refrigerant oil
- All safety equipment and PPE, training BEV

## Langkah Keselamatan
> **AMARAN:** R1234yf is mildly flammable — no open flames. Electric compressor operates on HV — de-energise before service. Never vent refrigerant to atmosphere. Never mix R1234yf and R134a.

## Prosedur Kerja

### Step 1: HVAC Diagnostic Inspection
1.1 Connect diagnostic scan tool; read HVAC fault codes
1.2 Check refrigerant pressure readings (high and low side)
1.3 Run active test: compressor, blower motor, PTC heater, water pumps, 3-way valves
1.4 Check PTC heater power draw via diagnostic tool
1.5 Measure cabin vent temperature during cooling and heating
1.6 Use electronic leak detector around all refrigerant connections
1.7 Record all diagnostic data

### Step 2: Refrigerant Recovery
2.1 Connect recycling machine hoses to vehicle service ports (high and low side)
2.2 Verify correct refrigerant type on machine matches vehicle specification
2.3 Start recovery process — machine extracts refrigerant
2.4 Allow machine to complete recovery cycle (automatic stop)
2.5 Record volume of refrigerant recovered

### Step 3: HV De-Energisation (if replacing HV component)
3.1 Perform complete HV de-energisation per C02/KK(2/6)
3.2 Verify zero-energy state

### Step 4: Component Replacement
4.1 Disconnect refrigerant lines from faulty component
4.2 Cap open lines immediately to prevent moisture entry
4.3 Disconnect electrical connectors
4.4 Remove mounting hardware
4.5 Remove faulty component
4.6 Install new component
4.7 Replace ALL O-rings at connection points
4.8 Apply refrigerant-compatible oil to O-rings
4.9 Reconnect refrigerant lines and torque to specification
4.10 Reconnect electrical connectors and mounting hardware

### Step 5: System Evacuation
5.1 Connect vacuum pump (via recycling machine) to service ports
5.2 Evacuate system to minimum 29 inHg vacuum
5.3 Maintain vacuum for minimum 30 minutes
5.4 Monitor vacuum gauge — any rise indicates a leak (find and fix before proceeding)

### Step 6: Refrigerant Recharge
6.1 Verify correct refrigerant type and charge volume (from manufacturer spec)
6.2 Use recycling machine to charge specified volume
6.3 Monitor pressures during charging — high and low side within specification

### Step 7: HV Re-Energisation (if applicable)
7.1 Perform HV re-energisation per C02/KK(2/6)

### Step 8: Functionality Test
8.1 Start vehicle in "READY" mode
8.2 **Cooling test:** Set HVAC to max cooling. Verify compressor engages. Measure vent temp (target 5-10 deg C in 5 min). Check pressures.
8.3 **Heating test:** Set HVAC to max heating. Verify PTC heater activates. Measure vent temp (target >40 deg C in 5 min). Verify water pump and 3-way valve operation.
8.4 Check for refrigerant leaks with electronic detector
8.5 Verify no fault codes
8.6 Record all results
