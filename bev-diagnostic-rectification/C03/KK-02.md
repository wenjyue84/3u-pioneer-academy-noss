## Work Activity 2: Carry Out BEV Liquid Cooling System Servicing

## Objektif Prestasi
1. Perform electric water pump functionality check
2. Execute cooling system leakage, corrosion, and clogging inspection
3. Demonstrate faulty cooling system component replacement
4. Perform cooling system functionality test

## Equipment
- Diagnostic scan tool, CAT III multimeter, coolant pressure tester
- Coolant refiller/suction tool, collection containers
- Replacement component (water pump or hose — training part)
- Manufacturer-specified coolant, PPE, training BEV

## Langkah Keselamatan
> **AMARAN:** Cooling system may be pressurised and contain hot coolant. Allow vehicle to cool before opening any cooling circuit. De-energise HV if working on HV-connected pumps.

## Prosedur Kerja

### Step 1: Diagnostic Inspection
1.1 Connect diagnostic scan tool
1.2 Read cooling system fault codes
1.3 Check coolant temperature readings across all circuits
1.4 Run active test: activate each water pump
1.5 Listen for abnormal noise (grinding, cavitation)
1.6 Record all diagnostic data

### Step 2: Visual Inspection
2.1 Inspect all coolant hoses for deterioration, swelling, cracks
2.2 Check hose clamps for tightness
2.3 Inspect expansion tank: coolant level, condition (colour, clarity)
2.4 Check heat exchanger fins for damage or blockage
2.5 Look for coolant stains indicating past or current leaks

### Step 3: Pressure Test
3.1 Ensure system is depressurised and cool
3.2 Connect coolant pressure tester to expansion tank
3.3 Pressurise to manufacturer specification (typically 1.0-1.5 bar)
3.4 Observe pressure gauge for 10 minutes
3.5 Any pressure drop indicates a leak — locate using visual inspection
3.6 Record results

### Step 4: Coolant Condition Check
4.1 Collect coolant sample from expansion tank
4.2 Check colour (should be clear, manufacturer-specified colour)
4.3 Check pH using test strip (should be 7.5-11.0 per typical specification)
4.4 Check for particulate contamination
4.5 If degraded — schedule coolant replacement

### Step 5: Component Replacement (if required)
5.1 De-energise HV if component is HV-connected
5.2 Place collection container under component
5.3 Drain coolant from relevant circuit
5.4 Disconnect electrical connectors from component
5.5 Remove hose connections
5.6 Remove mounting hardware
5.7 Remove faulty component
5.8 Install new component in reverse order
5.9 Reconnect all connections

### Step 6: Coolant Refill and Bleed
6.1 Refill with manufacturer-specified coolant type and volume
6.2 Bleed air from circuit per manufacturer procedure
6.3 Run water pumps via diagnostic tool active test
6.4 Recheck level after circulation; top up if needed
6.5 Verify no leaks at all connection points (visual and pressure test)

### Step 7: Functionality Test
7.1 Start vehicle in "READY" mode
7.2 Monitor coolant temperatures via diagnostic tool
7.3 Verify temperatures stabilise within specification
7.4 Verify all water pumps operating
7.5 Check for fault codes — should be none
7.6 Record all results
