# PELAN MENGAJAR AMALI / PRACTICAL LESSON PLAN

**Kod WIM / WIM Code:** G452-010-3:2023-C03/PM(Amali)
**Kertas Warna / Paper Color:** KUNING / YELLOW

---

## Competency Unit: Perform BEV Thermal Cooling System Rectification (20%)

## Performance Outcomes
1. Demonstrate thermal cooling system workplace preparation
2. Perform liquid cooling system inspection, component replacement, and testing
3. Execute HVAC system diagnosis, servicing, and functionality testing

## 4-Step Method

### Langkah 1: PERSEDIAAN (15 min)
- PPE check, safety briefing on coolant and refrigerant handling hazards

### Langkah 2: PENYAMPAIAN (90 min)
| 20 min | KK(1/3) | Workplace preparation for cooling system work |
| 35 min | KK(2/3) | Liquid cooling: pump test, leak inspection, component replacement, coolant refill |
| 35 min | KK(3/3) | HVAC: refrigerant recovery, compressor check, PTC heater test, system recharge |

### Langkah 3: PENGGUNAAN (210 min)
| 30 min | KK(1/3) | Workplace preparation practice |
| 90 min | KK(2/3) | Liquid cooling system servicing practice |
| 90 min | KK(3/3) | HVAC system servicing practice |

### Langkah 4: PENGESAHAN (25 min)
- Assessment, review, clean-up

## Total: approximately 340 minutes (5 hours 40 minutes)
