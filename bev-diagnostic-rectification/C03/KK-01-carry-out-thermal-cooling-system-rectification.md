## Work Activity 1: Carry Out Thermal Cooling System Rectification Workplace Preparation

## Objektif Prestasi
1. Demonstrate workplace preparation for thermal cooling system rectification
2. Set up coolant handling and spill containment area
3. Verify refrigerant recycling machine readiness

## Equipment
- All standard BEV safety equipment and PPE
- Coolant refiller/suction tool, coolant pressure tester
- Air conditioning refrigerant recycling machine (R1234yf/R134a)
- Spill kit with absorbent materials

## Prosedur Kerja

### Step 1: PPE and Safety Setup
1.1 Don full PPE including chemical-resistant gloves for coolant work
1.2 Deploy barriers and HV signage (if HV components involved)
1.3 Place insulated mat at work positions

### Step 2: Coolant Handling Area
2.1 Set up coolant collection containers with secondary containment
2.2 Prepare sealed, labeled waste containers for spent coolant
2.3 Verify correct replacement coolant type is available
2.4 Prepare spill kit within reach

### Step 3: Refrigerant Machine Setup
3.1 Verify refrigerant recycling machine is charged and calibrated
3.2 Confirm correct refrigerant type is loaded (R1234yf or R134a per vehicle)
3.3 Check machine hoses and connections for condition
3.4 Verify recovery tank has capacity

### Step 4: Tool and Equipment Verification
4.1 Verify coolant pressure tester is functional
4.2 Check diagnostic scan tool
4.3 Inspect all tools (insulated and common)
4.4 Complete JHA and toolbox talk
