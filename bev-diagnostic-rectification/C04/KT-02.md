## Work Activity 2: BEV Inverter Unit Replacement | **Reference:** C04/KP(2/5)

### S1 — Short Answer: a) Explain the function of the inverter in a BEV. b) List FOUR main components inside an inverter unit.
### S2 — MCQ: Why must you wait 5-10 minutes after de-energisation before working on an inverter? A. Motor needs to cool B. Coolant needs to drain C. DC bus capacitors retain lethal charge D. ECUs need to save data
### S3 — T/F: a) The inverter can be opened and its internal components repaired in the field. b) The inverter converts DC to three-phase AC. c) IGBT stands for Insulated Gate Bipolar Transistor.
### S4 — Short Answer: List FIVE common inverter fault code categories and describe each briefly.
### S5 — Matching: Match inverter component to function: 1. IGBT modules 2. DC bus capacitors 3. Current sensors 4. Gate drivers (a. Measure motor phase currents b. Control IGBT switching c. Create AC from DC d. Smooth DC input)
### S6 — Short Answer: Describe the inverter replacement procedure in sequential steps.

## Skema Jawapan
**S1:** a) Converts HV DC to 3-phase AC for motor; during regen, converts AC back to DC. b) IGBT/SiC power modules, DC bus capacitors, current sensors, control PCB, gate drivers, HV connectors, coolant channels. Any four.
**S2:** C
**S3:** a) FALSE — replace as complete unit b) TRUE c) TRUE
**S4:** Over-temperature, over-current, under/over-voltage, communication fault, IGBT fault, insulation fault. Any five.
**S5:** 1-c, 2-d, 3-a, 4-b
**S6:** HV de-energise, drain coolant, disconnect HV DC cables, disconnect motor phase cables, disconnect LV connectors, disconnect coolant hoses, remove mounting bolts, remove inverter, install new in reverse, refill coolant, re-energise, test, road test.
