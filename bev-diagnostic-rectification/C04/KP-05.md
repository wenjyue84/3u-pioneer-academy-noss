## Work Activity 5: Carry Out BEV Integrated Brake Control System Replacement

## Objektif Pembelajaran

---

> **AMARAN / WARNING:** The integrated brake control system is a safety-critical system. Any fault in this system can result in complete brake failure. After any brake system component replacement, brake system calibration via diagnostic scan tool is MANDATORY before returning the vehicle to service. Never road test without confirming all brake system fault codes are cleared and brake pedal feel is firm. Refer to Manufacturer's Service Manual for calibration procedure.

## 1. BEV Integrated Brake Control System

### 1.1 Function
BEV braking systems combine two braking methods:
- **Regenerative braking (brek regeneratif):** The traction motor operates as a generator, converting kinetic energy to electrical energy, which charges the battery. Controlled by the inverter.
- **Friction braking (brek geseran):** Conventional hydraulic disc brakes, same as ICE vehicles but used less frequently.

The integrated brake control system seamlessly blends these two methods to:
- Maximise energy recovery (extending range by 15-30%)
- Provide smooth, predictable braking feel
- Ensure full braking power even when regenerative braking is limited (e.g., battery fully charged, very cold conditions)

### 1.2 Components
| Component | Function |
|-----------|----------|
| Integrated Brake Control Unit (iBooster or equivalent) | Electric brake booster that replaces vacuum-assisted booster; enables brake-by-wire |
| Electronic Stability Control (ESC) module | Manages ABS, traction control, stability control |
| Brake pressure sensors | Monitor hydraulic pressure in each circuit |
| Wheel speed sensors | Measure individual wheel speeds for ABS/ESC |
| Brake pedal sensor | Measures driver brake pedal input (force and position) |
| Hydraulic Control Unit (HCU) | Controls brake pressure distribution to each wheel |
| Brake master cylinder | Generates hydraulic pressure |
| Brake calipers and pads | Friction braking at each wheel |

### 1.3 Regenerative-Friction Brake Blending (Campuran Brek Regeneratif-Geseran)

The brake control system continuously calculates the **optimal blend** of regenerative and friction braking:

| Condition | Regenerative Contribution | Friction Contribution |
|-----------|--------------------------|----------------------|
| Normal deceleration, battery available | Primary (up to 100%) | Minimal or zero |
| Heavy braking (> threshold) | Maximum available | Remainder to meet demand |
| Battery SOC ≥ 95% | Disabled (zero) | 100% |
| Speed < ~5 km/h | Reduced / zero | 100% |
| ABS activated | Disabled | 100% (ABS controlled) |
| Motor fault | Disabled | 100% |

The driver experiences consistent, smooth deceleration regardless of which system is active — the iBooster modulates hydraulic pressure to compensate as regenerative contribution changes. Refer to Manufacturer's Service Manual for regenerative braking calibration thresholds.

### 1.4 Regenerative Braking Levels
Many BEVs offer adjustable regenerative braking:
- **Off / Coast:** No regenerative braking; vehicle coasts freely
- **Low:** Mild deceleration when accelerator released
- **Medium:** Moderate deceleration
- **High / One-Pedal:** Strong deceleration; can bring vehicle to a stop without brake pedal

## 2. Brake Control System Diagnostics

### 2.1 Inspection
1. Connect diagnostic scan tool
2. Read brake system fault codes (ABS, ESC, brake booster, regenerative braking)
3. Check wheel speed sensor readings — all four should be consistent
4. Check brake pressure sensor readings
5. Verify regenerative braking function parameters
6. Check brake fluid level and condition

### 2.2 Common Fault Codes
| Category | Description |
|----------|-------------|
| ABS sensor fault | Wheel speed sensor failure or gap error |
| Brake booster fault | Electric booster motor failure |
| Pressure sensor fault | Brake circuit pressure sensor malfunction |
| Regenerative braking limited | Battery SOC too high, temperature too cold, motor fault |
| ESC/VDC fault | Stability control communication or sensor error |
| Brake fluid level low | Leak or worn brake pads |

---

## 3. Brake Control System Safety
- The brake system is a safety-critical system — improper work can cause brake failure
- BEV brake booster is ELECTRICALLY operated (not vacuum) — the 12V system must be functional for power braking assistance
- If the 12V system fails, brake pedal will feel very hard (manual braking only)
- Brake fluid is DOT 4 (or per manufacturer) — hygroscopic, absorbs moisture over time
- LV system disconnection will disable brake booster — do NOT drive the vehicle

## 4. Integrated Brake Control Component Replacement

### 4.1 General Procedure
1. Disconnect 12V battery (LV de-energisation — brake booster is 12V)
2. HV de-energisation if accessing HV components in proximity
3. Drain brake fluid from the affected circuit (if needed)
4. Disconnect electrical connectors from faulty component
5. Disconnect hydraulic brake lines
6. Remove mounting hardware
7. Remove faulty component
8. Install new component
9. Reconnect hydraulic lines — torque to specification
10. Reconnect electrical connectors
11. Bleed brake system per manufacturer procedure
12. Reconnect 12V battery
13. Perform brake system calibration via diagnostic tool
14. Functionality test

### 4.2 Brake System Bleeding
After any brake hydraulic work:
1. Fill brake fluid reservoir with correct specification
2. Bleed each wheel in manufacturer-specified sequence (typically: RR, LR, RF, LF or as specified)
3. Use either manual bleeding (two-person method) or pressure bleeder
4. Bleed until no air bubbles in fluid
5. Top up reservoir to MAX line
6. Verify firm, consistent brake pedal

---

## 5. Brake Control System Functionality Test
1. Reconnect 12V battery
2. Connect diagnostic scan tool
3. Perform brake system calibration/initialisation (required after component replacement)
4. Verify no brake system fault codes
5. Check brake pedal feel — firm, consistent, no sponginess
6. Verify ABS, ESC indicators on dashboard are OFF
7. Road test at low speed: verify braking performance, ABS activation on slippery surface (if safe to do so), regenerative braking response
8. Record all results
