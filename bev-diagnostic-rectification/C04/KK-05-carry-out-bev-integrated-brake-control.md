## Work Activity 5: Carry Out BEV Integrated Brake Control System Replacement

## Objektif Prestasi
1. Perform integrated brake control system diagnostic inspection
2. Execute brake control component replacement
3. Perform brake system bleeding and calibration
4. Demonstrate brake system functionality test

## Equipment
Common tools, diagnostic scan tool, brake bleeding kit (manual or pressure bleeder), brake fluid (DOT 4 or per spec), collection container, replacement component (training part), all safety equipment and PPE, training BEV

## Langkah Keselamatan
> **AMARAN:** Brake system is safety-critical. Improper work can cause brake failure. After any hydraulic work, system MUST be bled and tested before vehicle is driven. Do NOT drive vehicle with 12V disconnected — brake booster will not function.

## Prosedur Kerja

### Step 1: Brake System Diagnosis
1.1 Connect diagnostic scan tool
1.2 Read brake system fault codes (ABS, ESC, brake booster, regen braking)
1.3 Check wheel speed sensor readings (all four consistent)
1.4 Check brake pressure sensor readings
1.5 Verify brake fluid level and condition
1.6 Measure brake pedal feel — firm, consistent
1.7 Identify faulty component

### Step 2: LV De-Energisation
2.1 Turn vehicle OFF, remove key
2.2 Disconnect 12V battery (negative first)
2.3 HV de-energisation if accessing HV-adjacent components

### Step 3: Component Replacement
3.1 Disconnect electrical connectors from faulty component
3.2 Disconnect hydraulic brake lines (plug/cap open lines immediately)
3.3 Remove mounting hardware
3.4 Remove faulty component
3.5 Install new component
3.6 Reconnect hydraulic lines — torque to specification
3.7 Reconnect electrical connectors and mounting hardware

### Step 4: Brake System Bleeding
4.1 Fill brake fluid reservoir with correct specification (DOT 4)
4.2 Bleed each wheel in manufacturer-specified sequence
4.3 Bleed until no air bubbles in fluid at each caliper
4.4 Top up reservoir to MAX line
4.5 Verify firm, consistent brake pedal — no sponginess

### Step 5: System Calibration
5.1 Reconnect 12V battery (positive first, then negative)
5.2 Connect diagnostic scan tool
5.3 Perform brake system calibration/initialisation procedure
5.4 Verify no brake system fault codes
5.5 Verify ABS, ESC dashboard indicators are OFF

### Step 6: Functionality Test
6.1 Check brake pedal feel in stationary position
6.2 Slowly drive vehicle in controlled area (low speed)
6.3 Test braking: gradual stop, firm stop
6.4 Verify regenerative braking response
6.5 Record all results
