## Performance Outcomes

Upon completion of this practical module, trainees will be able to:
1. Demonstrate proper BEV scheduled maintenance workplace preparation procedures
2. Perform BEV health check activities using diagnostic scan tools
3. Execute BEV scheduled maintenance activities including inspection, top-up, and replacement tasks

## Kaedah Pengajaran 4 Langkah / 4-Step Instructional Method

### Langkah 1: PERSEDIAAN (Preparation) — 20 minutes

| Activity | Details |
|----------|---------|
| Sedia tempat latihan | Ensure BEV work bay is ready: anti-static floor clean, vehicle on lift, all tools and equipment laid out |
| PPE check | Verify all trainees have required PPE: insulated gloves, leather over-gloves, safety glasses, dielectric footwear, safety helmet |
| Tool inspection | Demonstrate insulated tool inspection procedure; trainees inspect their assigned tools |
| Safety briefing | Conduct toolbox talk: task overview, hazards, emergency procedures, assembly point |
| Nyatakan objektif | State the 3 performance outcomes |

### Langkah 2: PENYAMPAIAN (Presentation/Demonstration) — 90 minutes

| Time | KK Reference | Demonstration | Method |
|------|-------------|---------------|--------|
| 30 min | KK(1/3) | Demonstrate workplace preparation: workspace setup, barrier placement, tool layout, JHA form completion, waste management area identification | Instructor demonstration with trainee observation |
| 30 min | KK(2/3) | Demonstrate BEV health check: walk-around inspection, diagnostic scan tool connection, fault code reading, component active testing, report completion | Instructor demonstration on training BEV |
| 30 min | KK(3/3) | Demonstrate maintenance activities: VIN identification, maintenance checklist use, cabin air filter replacement, brake inspection, 12V battery test, fluid level checks | Instructor demonstration with step-by-step explanation |

### Langkah 3: PENGGUNAAN (Application/Practice) — 180 minutes

| Time | KK Reference | Activity | Method |
|------|-------------|----------|--------|
| 60 min | KK(1/3) | Trainees prepare BEV workplace: set up barriers, lay out tools, complete JHA form, identify waste disposal areas | Supervised hands-on practice in pairs |
| 60 min | KK(2/3) | Trainees perform health check: connect diagnostic tool, read/interpret fault codes, complete active tests, write health check report | Supervised hands-on practice in pairs |
| 60 min | KK(3/3) | Trainees perform maintenance: identify VIN, complete maintenance checklist, replace cabin air filter, check fluids, test 12V battery | Supervised hands-on practice in pairs |

### Langkah 4: PENGESAHAN (Confirmation) — 30 minutes

| Activity | Details |
|----------|---------|
| Assessment | Evaluate each trainee using KK assessment checklists (process, output, attitude, safety, environment) |
| Review | Review common mistakes observed during practice |
| Q&A session | Address trainee questions and clarify procedures |
| Clean-up | Trainees properly store tools, clean workspace, dispose of waste materials according to procedure |
| Summary | Key takeaways: (1) Workplace preparation prevents accidents, (2) Systematic health checks catch problems early, (3) Follow manufacturer's service manual for every procedure |
