## Langkah Keselamatan / Safety Precautions

> **AMARAN / WARNING:** Even during routine maintenance, BEV high voltage components are present. Never assume any component is de-energised.

1. Full PPE must be worn at all times in the BEV work bay
2. Do NOT remove or disconnect any orange HV cables or connectors during routine scheduled maintenance
3. When using a vehicle lift, position ONLY at manufacturer-specified lift points — the battery pack is on the underbody
4. Do NOT use standard automotive coolant — only use manufacturer-specified BEV coolant for HV systems
5. Ensure the vehicle is in "OFF" mode with key removed before performing any physical maintenance
6. When working under the raised vehicle, verify the lift is locked in position before proceeding

## Prosedur Kerja / Work Procedure

### Step 1: Vehicle Identification
1.1 Locate the VIN on the dashboard (through windscreen, driver side)
1.2 Locate the VIN on the door jamb sticker (driver side B-pillar)
1.3 Cross-reference with the vehicle registration card (VOC/Geran)
1.4 Record: manufacturer, model, year, battery type, battery capacity, motor type
1.5 Retrieve the correct service manual section for this vehicle model
1.6 Identify the scheduled maintenance items applicable for the current mileage interval

### Step 2: Scheduled Maintenance Checklist Preparation
2.1 Obtain the BEV scheduled maintenance checklist for the specific make/model
2.2 Review the checklist items applicable for the current service interval
2.3 Identify items requiring: INSPECT only, TOP-UP, or REPLACE
2.4 Prepare the required parts and consumables for replacement items

### Step 3: Diagnostic Pre-Check
3.1 Connect diagnostic scan tool to OBD-II port
3.2 Turn vehicle to "READY" mode
3.3 Perform a quick system scan — note any fault codes
3.4 Check software update availability — record if update is available
3.5 Turn vehicle to "OFF" mode
3.6 Disconnect scan tool (reconnect later for post-maintenance check)

### Step 4: Cabin Air Filter Replacement
4.1 Open the glove box and remove contents (if training on actual vehicle)
4.2 Release glove box stops/clips to allow the box to drop down
4.3 Locate the cabin air filter housing behind the glove box
4.4 Open the filter housing cover (note clip/tab mechanism)
4.5 Remove the old cabin air filter — note the airflow direction arrow
4.6 Inspect the filter housing for debris; clean with lint-free cloth if needed
4.7 Install the new cabin air filter with airflow arrow matching the housing direction
4.8 Close the filter housing cover securely
4.9 Refit the glove box

### Step 5: Fluid Level Checks and Top-Up
5.1 **Windscreen washer fluid:**
- Open the front trunk/bonnet
- Locate the washer fluid reservoir
- Check fluid level; top up to MAX line if low
- Close the cap securely

5.2 **Brake fluid:**
- Locate the brake fluid reservoir (typically in the engine bay / front compartment)
- Check fluid level against MIN/MAX markings
- Use brake fluid tester to check moisture content
- If level is low, investigate for leaks before topping up
- Top up with correct specification (DOT 4 or per manufacturer) to MAX line

5.3 **HV coolant (visual check ONLY):**
- Locate the HV coolant expansion tank (if accessible)
- Check level against MIN/MAX markings — VISUAL CHECK ONLY
- Do NOT open the HV coolant reservoir cap during routine maintenance
- If level is below MIN, report to supervisor — this may indicate a leak requiring further investigation
- Record coolant condition (colour, clarity)

5.4 **12V auxiliary battery:**
- Locate the 12V battery
- Clean battery terminals if corrosion is present (using baking soda solution and brush)
- Measure voltage using 12V battery tester — record reading
- Perform load test if tester supports this function
- Record battery condition: GOOD / ADVISORY / REPLACE

### Step 6: Underbody Inspection (Vehicle on Lift)
6.1 Position the vehicle lift pads at manufacturer-specified lift points ONLY
6.2 Raise the vehicle to a comfortable working height
6.3 Verify the lift is locked before working underneath
6.4 **Battery pack housing:** Inspect for dents, cracks, fluid stains, or foreign object damage
6.5 **HV cables (orange):** Visually inspect routing and condition — look for chafing, damage, displaced clips
6.6 **Suspension:** Inspect shock absorbers for leaks; check CV joint boots for splits
6.7 **Brakes:** Measure brake pad thickness through inspection window or by removing wheel (compare to manufacturer minimum)
6.8 **Tyres:** Inspect inner sidewall (not visible from ground level) for damage
6.9 Record all underbody findings on the maintenance checklist

### Step 7: Tyre Rotation (if scheduled)
7.1 Loosen wheel nuts before lifting the vehicle
7.2 Follow manufacturer-specified rotation pattern (front-to-rear, cross-pattern, etc.)
7.3 Torque wheel nuts to manufacturer specification using torque wrench
7.4 Reset TPMS (Tyre Pressure Monitoring System) if required — using diagnostic scan tool

### Step 8: Post-Maintenance Diagnostic Check
8.1 Lower the vehicle from the lift
8.2 Reconnect diagnostic scan tool
8.3 Turn vehicle to "READY" mode
8.4 Clear any maintenance-related fault codes (e.g., cabin filter reset)
8.5 Reset service interval indicator if applicable
8.6 Perform a final system scan — verify no new fault codes
8.7 Turn vehicle to "OFF" mode

### Step 9: Complete Maintenance Documentation
9.1 Complete all items on the scheduled maintenance checklist
9.2 Record all findings, fluid levels, measurements, and actions taken
9.3 Note any advisory items requiring attention at the next service
9.4 Sign and date the maintenance record
9.5 File the maintenance record per company SOP

### Step 10: Clean Up
10.1 Remove all tools and equipment from the vehicle and work bay
10.2 Dispose of used parts (old cabin filter, etc.) in the appropriate waste container
10.3 Clean the work area
10.4 Return all tools to their designated storage locations
10.5 Remove barrier stanchions
