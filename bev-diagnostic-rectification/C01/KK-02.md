## Langkah Keselamatan / Safety Precautions

> **AMARAN / WARNING:** Do NOT open or disassemble any HV component during a health check. Health checks are non-invasive diagnostic procedures.

1. Ensure full PPE is worn before commencing work
2. Do NOT touch any orange-coloured cable or HV component
3. If the IMD (Insulation Monitoring Device) indicates a fault, STOP immediately and report to instructor
4. Do NOT start or drive the vehicle during diagnostic scan — use "READY" mode only
5. Ensure the work bay is properly prepared (barriers, signage) as per KK(1/3)
6. Keep clear of moving parts when performing active tests (e.g., cooling pump activation)

## Prosedur Kerja / Work Procedure

### Step 1: Receive Vehicle and Verify Information
1.1 Receive the vehicle work order / service request
1.2 Verify vehicle details: registration number, make, model, VIN
1.3 Note the customer complaint or service request (if applicable)
1.4 Check the vehicle mileage reading from the odometer

### Step 2: Exterior Walk-Around Inspection
2.1 Perform a systematic walk-around starting from the driver's door, moving clockwise
2.2 **Front:** Check headlights, indicators, bumper condition, windscreen condition, wiper blades
2.3 **Right side:** Check mirrors, tyres (tread depth and damage), doors, panels
2.4 **Rear:** Check tail lights, brake lights, reverse lights, rear bumper, charging port cover
2.5 **Left side:** Check mirrors, tyres, doors, panels
2.6 **Underbody (visual from sides):** Look for signs of fluid leaks, damage to battery pack housing
2.7 Check all four tyre pressures using digital gauge; record readings and compare to door sticker specification
2.8 Record all exterior findings on the health check checklist

### Step 3: Interior Systems Check
3.1 Enter the vehicle and turn ignition to "ON" position (not "READY" mode yet)
3.2 Observe the dashboard: all warning lights should illuminate briefly during self-test, then extinguish
3.3 Note any warning lights that remain illuminated after self-test sequence
3.4 Check seat belts, horn, power windows, door locks, interior lights
3.5 Test HVAC system: heating and cooling functions
3.6 Test windscreen wipers and washer fluid
3.7 Record all interior findings

### Step 4: Connect Diagnostic Scan Tool
4.1 Locate the OBD-II port (16-pin DLC, typically under driver's side dashboard)
4.2 Connect the diagnostic scan tool cable to the OBD-II port
4.3 Power on the scan tool and select the correct vehicle make and model
4.4 Allow the scan tool to establish communication with all vehicle ECUs

### Step 5: Turn Vehicle to "READY" Mode
5.1 With the diagnostic tool connected, press the START/POWER button with foot on brake
5.2 Confirm the vehicle enters "READY" mode (dashboard indicator illuminates "READY")
5.3 Do NOT select any drive gear — remain in PARK

### Step 6: Read Fault Codes
6.1 Perform a full system scan — read all ECUs
6.2 Record all fault codes: code number, description, status (active/stored/pending)
6.3 For each active fault code, capture freeze frame data (SOC, temperature, speed at time of fault)
6.4 Record fault codes on the fault code recording form

### Step 7: BEV-Specific System Checks (via Diagnostic Tool)
7.1 **Battery Management System:**
- Read battery SOC (State of Charge) — record percentage
- Read battery SOH (State of Health) — record percentage
- Check individual cell voltages — verify all cells within +/- 0.05V
- Read battery temperature values across all zones
- Check HV insulation resistance value — must exceed manufacturer minimum (typically >500 ohm/V)

7.2 **Powertrain:**
- Check motor controller status
- Verify regenerative braking function parameters
- Read inverter status

7.3 **Thermal Management:**
- Check cooling pump operation status
- Read coolant temperature values
- Verify thermal valve positions

7.4 **Charging System:**
- Read on-board charger status
- Check AC and DC charging protocol status
- Verify charging port condition

### Step 8: Component Active Tests
8.1 Using the diagnostic tool's active test function:
- Activate cooling system pump — listen for operation and check for abnormal noise
- Activate horn (confirm earlier manual test)
- Test HV contactor operation (if scan tool supports this — observe on tool, do NOT physically check)
8.2 Record all active test results

### Step 9: 12V Auxiliary Battery Check
9.1 Turn vehicle to "OFF" mode
9.2 Locate the 12V auxiliary battery
9.3 Measure voltage with multimeter — should be >12.4V
9.4 Record voltage reading

### Step 10: Prepare Health Check Report
10.1 Compile all findings from Steps 2-9
10.2 Assign condition rating to each item: GOOD / ADVISORY / DEFECTIVE
10.3 List all fault codes with interpretation
10.4 Write recommendations for any advisory or defective items
10.5 Complete the technician details section (name, certification number)
10.6 Sign and date the report
10.7 Submit the report to the supervisor for review and countersign

### Step 11: Disconnect and Clean Up
11.1 Disconnect the diagnostic scan tool from the OBD-II port
11.2 Ensure the vehicle is in "OFF" mode with key removed
11.3 Remove barrier stanchions if work is complete
11.4 Store all tools and equipment properly
