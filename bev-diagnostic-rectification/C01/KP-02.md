## 1. BEV Health Check Safety (Keselamatan Pemeriksaan Kesihatan BEV)

### 1.1 Safety Equipment Inside the Vehicle

Before performing a health check, verify the following in-vehicle safety systems:
- **Airbag system:** Ensure airbag warning light is not illuminated. Airbag systems in BEVs are similar to ICE vehicles but may include additional sensors for battery compartment protection.
- **HV interlock system:** The HV interlock (sambungan kunci HV) is a safety circuit that detects whether HV connectors are properly seated. If any HV connector is disturbed, the interlock opens and the HV system is disabled.
- **Battery Management System (BMS) warnings:** Check the dashboard for any battery-related warning indicators (temperature, state of charge, cell imbalance).
- **Insulation Monitoring Device (IMD):** BEVs are equipped with an IMD that continuously monitors the insulation resistance between HV circuits and the vehicle chassis. A fault indication means potential HV leakage to the chassis — do NOT proceed until resolved.

### 1.2 Types of PPE and Specification

| PPE Item | Specification | Application During Health Check |
|----------|---------------|-------------------------------|
| Insulated gloves | Class 0 (1000V AC / 1500V DC) | Required when accessing any HV component or connector |
| Leather over-gloves | Per manufacturer spec | Physical protection over insulated gloves |
| Safety glasses | DIN EN166 | Always worn during diagnostic work |
| Dielectric footwear | DI rated | Always worn in BEV work bay |
| Safety helmet | MS 340 | When working under vehicle or near overhead hazards |

### 1.3 Condition of BEV Equipment and Parts

Before health check activities, inspect the following:
- Visual inspection of HV cables (orange-coloured) for damage, chafing, or discolouration
- Check HV connector integrity — no corrosion, no moisture
- Inspect battery pack housing for physical damage, leaks, or deformation
- Verify coolant level in HV system reservoir (where visible)
- Check 12V auxiliary battery voltage (should be above 12.4V)

## 2. BEV Health Check Tools and Equipment (Alatan dan Peralatan Pemeriksaan)

### 2.1 Diagnostic Scan Tool

The diagnostic scan tool is the primary instrument for BEV health checks. Modern BEV diagnostic tools connect via the OBD-II port (16-pin DLC connector, typically located under the dashboard) and communicate with multiple Electronic Control Units (ECUs):

| ECU | Function |
|-----|----------|
| BMS ECU | Battery state of charge (SOC), state of health (SOH), cell voltages, temperatures |
| Motor Control Unit (MCU) | Motor performance, inverter status, regenerative braking |
| Vehicle Control Unit (VCU) | Overall vehicle systems coordination |
| Thermal Management ECU | Cooling system status, pump operation, valve positions |
| Charging ECU | On-board charger status, charging protocols |

**Types of diagnostic scan tools:**
- **OEM-specific tools:** Manufacturer-proprietary (e.g., VIDA for Volvo, CONSULT for Nissan, IDS for Ford). Most comprehensive access.
- **Multi-brand tools:** Third-party tools (e.g., Autel MaxiSYS, Launch X431) supporting multiple BEV brands. May have limited access to certain HV parameters.

### 2.2 Digital Multimeter / Multimeter Digital (DMM)

A CAT III-rated digital multimeter (minimum 1000V, complying with IEC 61010-1 / MS IEC 61010-1) is essential for:
- Measuring 12V auxiliary battery voltage
- Checking low voltage circuit continuity
- Verifying sensor outputs

**CAUTION:** Never use a standard multimeter on HV circuits. Only CAT III-1000V rated meters with appropriate HV probes may be used for HV measurements by qualified personnel.

### 2.3 Additional Health Check Equipment

| Equipment | Purpose |
|-----------|---------|
| Inspection lamp / torch | Visual inspection in confined areas |
| Tyre pressure gauge | BEV tyre pressure verification (BEV tyres typically require higher pressure due to vehicle weight) |
| Brake fluid tester | Check brake fluid moisture content |
| Coolant tester (refractometer) | Verify coolant concentration and condition |
| Thermal imaging camera (optional) | Detect hot spots in electrical connections |

## 3. Procedure for BEV Component Active Test (Prosedur Ujian Aktif Komponen BEV)

### 3.1 Checklist Content

A BEV health check follows a structured checklist covering all major systems:

**Exterior Systems:**
- Tyre condition and pressure (all 4 tyres + spare if applicable)
- Brake pad thickness and disc condition
- Suspension components — visual inspection
- Lighting system — all exterior lights functional
- Windscreen wipers and washer fluid level
- Charging port condition and cover operation

**Interior Systems:**
- Dashboard warning lights — check all indicators during ignition-on sequence
- HVAC system operation
- Seat belt functionality
- Horn operation
- Power windows and mirrors

**HV System (using diagnostic scan tool — do NOT open HV components):**
- Battery SOC (State of Charge) and SOH (State of Health)
- Cell voltage balance — all cells within manufacturer specification (typically +/- 0.05V)
- Battery temperature readings across all zones
- HV insulation resistance value (must exceed manufacturer minimum, typically >500 ohm/V)
- Cooling system pump operation
- Charging system status (AC and DC charging protocols)

**Powertrain:**
- Motor operation — check for unusual noise or vibration
- Regenerative braking function
- Drive selector operation (P, R, N, D)
- 12V auxiliary battery voltage and charging status

### 3.2 Testing Procedure

1. Receive vehicle and verify customer complaint / service request
2. Perform visual walk-around inspection
3. Connect diagnostic scan tool to OBD-II port
4. Turn vehicle to "READY" mode (ignition on, do NOT drive)
5. Read all system fault codes (stored, pending, permanent)
6. Perform system scans — battery, motor, charging, thermal management
7. Run active tests as prescribed by diagnostic tool (e.g., cooling pump activation, contactor operation)
8. Record all readings and compare against manufacturer specifications
9. Turn vehicle off and disconnect diagnostic tool

### 3.3 Component Condition Assessment

Each component is assessed using a three-tier condition rating:

| Rating | Description | Action Required |
|--------|-------------|----------------|
| GOOD (Baik) | Within specification, no issues | No action — note in report |
| ADVISORY (Nasihat) | Approaching limit or minor concern | Schedule for next service |
| DEFECTIVE (Rosak) | Outside specification or failed | Immediate attention required |

## 4. Diagnostic Test (Ujian Diagnostik)

### 4.1 Function and Operation of Diagnostic System

Modern BEV diagnostic systems use Controller Area Network (CAN bus) communication protocol. The diagnostic scan tool communicates with vehicle ECUs through standardised protocols:

- **ISO 15765-4 (CAN):** Primary protocol for BEV diagnostics
- **ISO 14229 (UDS — Unified Diagnostic Services):** Standardised diagnostic commands
- **Manufacturer-specific protocols:** Additional access for HV-specific parameters

### 4.2 Types and Categories of Fault Codes

| Category | Code Format | Description |
|----------|-------------|-------------|
| Generic/Global | P0xxx, P2xxx | Standard OBD-II codes applicable to all vehicles |
| Manufacturer-specific | P1xxx, U1xxx | Codes unique to the vehicle manufacturer |
| Body | Bxxxx | Body system codes (lighting, HVAC, windows) |
| Chassis | Cxxxx | Chassis system codes (ABS, steering, brakes) |
| Network | Uxxxx | Communication network codes (CAN bus faults) |

**BEV-specific fault code categories commonly encountered:**
- Battery cell voltage deviation
- Insulation resistance fault
- BMS communication error
- Cooling system performance
- Charging system fault
- Motor/inverter over-temperature
- HV contactor malfunction

### 4.3 Interpreting Fault Codes

When interpreting fault codes:
1. **Record** the full code (e.g., P0A1F — Battery Energy Control Module)
2. **Check** whether the code is current (active) or historical (stored)
3. **Cross-reference** with manufacturer technical service bulletins (TSBs)
4. **Verify** with freeze frame data — conditions when the fault occurred (SOC, temperature, vehicle speed)
5. **Clear** codes only after root cause analysis; document before clearing
6. **Road test** or recheck to confirm fault does not recur

## 5. Procedure for Health Check Result Report (Prosedur Laporan Keputusan Pemeriksaan)

### 5.1 Report Contents

A BEV health check report must include:

| Section | Content |
|---------|---------|
| Vehicle Information | Registration number, VIN, make/model, mileage, date |
| Customer Information | Name, contact, complaint description |
| Checklist Results | All inspection items with condition ratings |
| Diagnostic Results | All fault codes (stored and active), freeze frame data |
| Battery Health Summary | SOC, SOH, cell balance status, insulation resistance |
| Recommendations | Required repairs, advisory items, next service schedule |
| Technician Details | Name, certification number, signature |
| Photo Documentation | Photos of any defects or areas of concern |

### 5.2 Report Submission and Filing

- Report must be signed by the performing technician and reviewed by the supervisor
- One copy to the customer, one copy retained in the workshop filing system
- Electronic copies stored in the workshop management system
- Reports must be retained for a minimum period as per company policy (typically 3-5 years)
