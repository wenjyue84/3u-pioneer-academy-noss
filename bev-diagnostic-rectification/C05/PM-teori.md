| CU Code | G452-010-3:2023-C05 |
| CU Title | Perform BEV Workshop Supervisory Function |
| CU Weight | 15% |

## Learning Outcomes
1. Explain BEV daily briefing communication techniques, content, and feedback reporting
2. Describe subordinate performance appraisal methods, evaluation criteria, and improvement techniques
3. Explain Training Needs Identification (TNI) and Training Needs Analysis (TNA) for BEV skills
4. Describe BEV workshop safety, health, and environment compliance monitoring and reporting
