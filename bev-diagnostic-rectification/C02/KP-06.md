4. Describe the DC-DC converter replacement procedure
5. Explain the DC-DC converter functionality test

## 1. BEV DC-DC Converter

### 1.1 Definition and Function
The DC-DC converter is a power electronics device that steps down the HV battery voltage (200-800V DC) to the 12V (or 48V) level required by the vehicle's low voltage system. It replaces the alternator found in ICE vehicles.

Functions:
- Converts HV DC to 12V DC to power all LV systems
- Charges the 12V auxiliary battery
- Maintains stable 12V supply during all vehicle operating conditions
- Provides power for ECUs, lighting, infotainment, HVAC blower, etc.

### 1.2 DC-DC Converter Specifications (Typical)

| Parameter | Typical Value |
|-----------|---------------|
| Input voltage | 200-800V DC (matches battery voltage) |
| Output voltage | 13.5-14.4V DC (to charge 12V battery) |
| Output power | 1.5-3.0 kW |
| Efficiency | >93% |
| Cooling | Liquid-cooled (integrated into HV cooling loop) |
| Weight | 3-8 kg |

### 1.3 DC-DC Converter Failure Modes

| Failure Mode | Symptom | Diagnosis |
|-------------|---------|-----------|
| Output voltage too low (<13V) | 12V battery drains; accessories malfunction | Measure LV output with DMM in READY mode |
| Output voltage too high (>14.8V) | 12V battery overcharging; bulging battery | Measure LV output; check regulation circuit |
| No output | 12V battery dead; vehicle cannot start | Verify HV input present; check LV output |
| Intermittent output | Random loss of 12V accessories | Monitor output voltage under load; check connectors |
| Coolant leak | Overtemperature fault; coolant level low | Visual inspection; pressure test cooling circuit |
| Communication failure | DC-DC fault codes; no response to VCU commands | CAN bus check; scan tool live data |
| HV input connector degradation | Input voltage drop; efficiency loss | Inspect HV connector; measure input voltage |

## 2. DC-DC Converter Inspection

> **AMARAN / WARNING:** The DC-DC converter is connected directly to the HV traction battery bus. Its HV input terminals carry full battery voltage (200–800V DC). Full HV disconnection must be completed and zero-energy verified before any physical access.

### 2.1 Diagnostic Inspection
1. Connect diagnostic scan tool
2. Read DC-DC converter-specific fault codes
3. Check DC-DC converter output voltage (should be 13.5-14.4V with vehicle in "READY" mode)
4. Monitor output voltage stability under load
5. Check communication between DC-DC converter and BMS/VCU

### 2.2 Physical Inspection (after HV de-energisation)
1. Visual check for coolant leaks
2. Inspect HV and LV connectors for damage
3. Check mounting brackets for cracks or looseness
4. Inspect coolant hoses for deterioration

---

## 3. DC-DC Converter Replacement Procedure

### 3.1 Preparation
1. Complete HV disconnection procedure
2. Drain DC-DC converter coolant circuit:
   - Place collection container under DC-DC converter
   - Disconnect coolant hoses
   - Allow complete drainage
   - Cap open connections
3. Dispose of coolant per waste management procedure

### 3.2 Removal
1. Disconnect LV output cables from DC-DC converter
2. Disconnect HV input cables (verify zero energy first)
3. Disconnect LV control/communication connectors
4. Remove coolant hoses (already drained)
5. Remove mounting bolts
6. Remove the DC-DC converter unit

### 3.3 Installation
1. Position new DC-DC converter and install mounting bolts (torque to specification)
2. Reconnect coolant hoses and secure with clamps
3. Reconnect LV control/communication connectors
4. Reconnect HV input cables (torque to specification)
5. Reconnect LV output cables

### 3.4 Coolant Refill
- Use manufacturer-specified coolant
- Refill to specified volume
- Bleed air from the circuit
- Run cooling pump via diagnostic tool
- Verify no leaks

---

## 4. DC-DC Converter Functionality Test

1. Re-energise HV system (interlock plug, 12V battery)
2. Turn vehicle to "READY" mode
3. Connect diagnostic scan tool and verify:
   - No DC-DC converter fault codes
   - Output voltage: 13.5-14.4V DC
   - Output stable under varying LV load
   - Communication with BMS/VCU established
   - Cooling system operational (check converter temperature)
4. Verify 12V auxiliary battery is charging
5. Test LV systems: headlights, HVAC blower, infotainment (load test)
6. Record all test results
