## Competency Unit: Perform Battery Management System (BMS) Rectification
## Work Activity 4: Carry Out BEV Pre-Charge Control System Servicing

---

## Objektif Pembelajaran / Learning Objectives

Upon completion of this Information Sheet, trainees will be able to:
1. Explain the function and components of the BEV pre-charge control system
2. Describe the safety requirements for pre-charge system work
3. Explain the inspection and diagnosis procedures for pre-charge control circuits
4. Describe the procedure for replacing a defective pre-charge relay pack
5. Explain the pre-charge system functionality test procedure

---

## 1. BEV Pre-Charge Control System

### 1.1 Function
The pre-charge system is a critical safety circuit that prevents damage to electrical components when the HV system is first energised. Without pre-charge, closing the main HV contactors would create an inrush current surge into the inverter capacitors, potentially causing:
- Welding of contactor contacts
- Damage to inverter capacitors
- Arc flash at contact points
- BMS fault and shutdown

### 1.2 Components

| Component | Function |
|-----------|----------|
| Pre-charge relay | Smaller contactor that closes before the main positive contactor |
| Pre-charge resistor | Limits current flow during capacitor charging (typically 50-200 ohm) |
| Main positive contactor | Closes after pre-charge is complete to provide full HV power |
| Main negative contactor | Connects the battery negative to the circuit |
| BMS control circuit | Manages the pre-charge sequence timing and monitoring |

### 1.3 Pre-Charge Sequence
1. BMS receives "READY" request from VCU
2. BMS closes the main NEGATIVE contactor
3. BMS closes the PRE-CHARGE relay (current flows through pre-charge resistor)
4. Inverter capacitors charge gradually (typically 2-5 seconds)
5. BMS monitors voltage across the main positive contactor
6. When voltage difference drops below threshold (typically <10V), pre-charge is complete
7. BMS closes the main POSITIVE contactor
8. BMS opens the pre-charge relay (no longer needed)
9. HV system is now fully operational

---

## 2. Pre-Charge System Safety

> **AMARAN / WARNING:** Pre-charge components (relay, resistor, contactors) are located inside or adjacent to the HV battery pack and carry full HV potential when energised. Full HV disconnection is mandatory. Pre-charge resistors may also be hot after recent operation — allow cooling time before contact.

- All BMS PPE and safety requirements apply
- The pre-charge system is located within or adjacent to the HV battery pack
- Full HV disconnection must be completed before any physical access
- Pre-charge resistors may be hot after recent vehicle operation
- Pre-charge components carry full HV potential when system is energised

---

## 3. Pre-Charge Control Circuit Inspection

### 3.1 Diagnostic Scan
- Read fault codes related to pre-charge system
- Common codes: pre-charge timeout, contactor welding detected, voltage monitoring fault
- Check pre-charge relay coil resistance (should match manufacturer specification)

### 3.2 Pre-Charge Circuit Diagnosis
After HV de-energisation and verification:
1. Access the pre-charge relay pack (typically inside or on the battery pack)
2. Measure pre-charge resistor value — compare to specification
3. Check pre-charge relay coil resistance — compare to specification
4. Check wiring continuity between BMS and pre-charge components
5. Inspect connector condition — no corrosion, moisture, or damage

---

## 4. Pre-Charge Relay Pack Replacement Procedure

1. Complete HV disconnection procedure
2. Access the pre-charge relay pack location
3. Disconnect LV control connectors from the relay pack
4. Disconnect HV connections (if separate from battery pack)
5. Remove mounting bolts
6. Remove the defective relay pack
7. Install new relay pack — verify correct orientation and part number
8. Reconnect HV connections and torque to specification
9. Reconnect LV control connectors
10. Verify all connections are secure

---

## 5. Pre-Charge System Functionality Test

After replacement:
1. Re-energise the HV system (12V battery, then interlock plug)
2. Connect diagnostic scan tool
3. Turn vehicle to "READY" mode
4. Monitor pre-charge sequence via diagnostic tool:
   - Verify negative contactor closes
   - Verify pre-charge relay closes
   - Verify capacitor voltage rises gradually
   - Verify main positive contactor closes after pre-charge complete
   - Verify pre-charge relay opens
5. Check for any fault codes
6. Verify vehicle enters "READY" mode without errors
7. Record all test results

---

## 6. Pre-Charge System Failure Modes

| Component | Failure Mode | Symptom | Diagnosis |
|-----------|-------------|---------|-----------|
| Pre-charge relay | Open circuit (coil burn) | Vehicle cannot enter READY; pre-charge timeout fault | Coil resistance test (should be 50–200 Ohm) |
| Pre-charge relay | Weld failure (stuck closed) | Relay remains closed; may over-stress resistor | Fault code; relay contact continuity test |
| Pre-charge resistor | Open circuit (overload) | Pre-charge circuit open; no capacitor charging | Resistance value out of specification |
| Pre-charge resistor | Degraded resistance | Slow pre-charge; timeout fault | Resistance test vs. specification |
| Main positive contactor | Weld failure | Vehicle cannot shut down HV; contactor fault code | Contactor contact resistance test |
| BMS control circuit | Timing/logic fault | Pre-charge sequence aborts; sequence error code | Scan tool live data monitoring |
