## Competency Unit: Perform Battery Management System (BMS) Rectification
## Work Activity 4: Carry Out BEV Pre-Charge Control System Servicing

---

## Objektif Prestasi / Performance Objectives

1. Perform pre-charge control system diagnostic inspection
2. Execute HV de-energisation and access the pre-charge relay pack
3. Demonstrate defective pre-charge relay pack replacement
4. Perform pre-charge system functionality test

---

## Peralatan dan Bahan / Equipment and Materials

- Insulated tool kit, diagnostic scan tool, CAT III multimeter
- Replacement pre-charge relay pack (training part)
- All safety equipment and PPE as per KK(1/6)
- Training BEV — 1 unit

---

## Prosedur Kerja / Work Procedure

### Step 1: Pre-Charge System Diagnosis
1.1 Connect diagnostic scan tool; read pre-charge related fault codes
1.2 Record fault codes (e.g., pre-charge timeout, contactor welding)
1.3 Verify fault points to pre-charge relay pack as the failed component

### Step 2: HV De-Energisation
2.1 Perform complete HV de-energisation per KK(2/6) Steps 2-3
2.2 Verify zero-energy state

### Step 3: Access Pre-Charge Relay Pack
3.1 Locate the pre-charge relay pack (typically inside or on the battery pack housing)
3.2 Remove access panel/cover as per manufacturer procedure
3.3 Identify the pre-charge relay, pre-charge resistor, and associated wiring

### Step 4: Component Testing
4.1 Measure pre-charge resistor value — compare to specification (typically 50-200 ohm)
4.2 Measure pre-charge relay coil resistance — compare to specification
4.3 Check wiring continuity between BMS connector and pre-charge components
4.4 Inspect connector condition for corrosion or damage
4.5 Record all measurements

### Step 5: Pre-Charge Relay Pack Replacement
5.1 Disconnect LV control connectors from relay pack
5.2 Disconnect HV connections (if separate from battery pack main assembly)
5.3 Remove mounting bolts
5.4 Remove defective relay pack
5.5 Verify new relay pack part number matches specification
5.6 Install new relay pack with correct orientation
5.7 Reconnect HV connections — torque to specification
5.8 Reconnect LV control connectors
5.9 Verify all connections secure

### Step 6: Reassembly
6.1 Replace access panel/cover
6.2 Verify no tools or foreign objects left inside

### Step 7: Functionality Test
7.1 Perform HV re-energisation
7.2 Connect diagnostic scan tool
7.3 Turn vehicle to "READY" mode
7.4 Monitor pre-charge sequence via diagnostic tool:
   - Negative contactor closes
   - Pre-charge relay closes
   - Capacitor voltage rises gradually
   - Main positive contactor closes
   - Pre-charge relay opens
7.5 Verify vehicle enters "READY" mode without fault codes
7.6 Record all test results
