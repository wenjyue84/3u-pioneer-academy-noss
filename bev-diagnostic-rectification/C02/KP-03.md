## Competency Unit: Perform Battery Management System (BMS) Rectification
## Work Activity 3: Carry Out BEV On-Board Charger (OBC) Replacement

---

## Objektif Pembelajaran / Learning Objectives

Upon completion of this Information Sheet, trainees will be able to:
1. Define the On-Board Charger (OBC) and explain its function in a BEV
2. Describe the OBC cooling system and its importance
3. Explain OBC inspection and diagnostic procedures
4. Describe the HV disconnection and coolant drainage procedures for OBC work
5. Explain the OBC replacement and system functionality test procedures

---

## 1. On-Board Charger (OBC) — Pengecas Atas Kenderaan

### 1.1 Definition
The On-Board Charger (OBC) is a power electronics unit permanently installed in the BEV that converts AC power from an external charging station (or household outlet) into DC power to charge the HV traction battery.

### 1.2 OBC Function
- Converts single-phase or three-phase AC to DC
- Typical power ratings: 3.3 kW (single-phase slow), 7.4 kW (single-phase), 11 kW (three-phase), 22 kW (three-phase fast)
- Communicates with the BMS to regulate charging voltage and current
- Monitors charging temperature and adjusts power accordingly
- Provides galvanic isolation between the AC grid and the HV DC battery system

### 1.3 OBC Cooling System
The OBC generates significant heat during charging (power conversion efficiency is typically 90-95%, meaning 5-10% energy is dissipated as heat). OBCs are typically liquid-cooled:
- Integrated into the vehicle's HV cooling loop
- Coolant flows through channels within the OBC housing
- Coolant must be drained before OBC removal
- **The same non-conductive coolant used for the battery pack is used for the OBC**

### 1.3a OBC Component Specifications (Typical)

| Parameter | Specification |
|-----------|--------------|
| AC input voltage | 220-240V AC (single-phase) or 380-415V AC (three-phase) |
| AC input frequency | 50 Hz |
| DC output voltage | Matches battery nominal voltage (e.g., 350-400V DC) |
| Power rating | 3.3 kW / 7.4 kW / 11 kW / 22 kW (varies by variant) |
| Efficiency | 90–95% (power conversion) |
| Galvanic isolation | Yes — AC grid isolated from HV DC bus |
| Cooling | Liquid-cooled (integrated into HV loop) |
| Weight | 5–15 kg |
| Communication | CAN bus to BMS and VCU |

### 1.4 OBC Inspection Procedure
- Visual: check for external damage, coolant leaks, connector condition
- Diagnostic: read OBC-specific fault codes via scan tool
- Functional: verify AC charging capability at different power levels
- Communication: verify OBC communicates correctly with BMS and VCU

## 2. OBC Safety Requirements

> **AMARAN / WARNING:** The OBC retains HV DC on its internal bus even when AC power is disconnected. Full HV de-energisation of the vehicle (including 12V disconnect and interlock removal) is required before handling the OBC.

- All BMS PPE requirements apply
- OBC contains HV DC internally even when AC is not connected (residual charge from HV bus)
- Coolant drainage creates chemical waste — follow waste management procedures
- OBC is typically heavy (5-15 kg) — use proper lifting technique

---

## 3. OBC Diagnostic Procedure

### 3.1 Common OBC Fault Codes
| Fault Category | Description | Possible Cause |
|---------------|-------------|----------------|
| Communication fault | OBC cannot communicate with BMS | Wiring fault, connector issue, ECU failure |
| Over-temperature | OBC internal temperature exceeded limit | Cooling system fault, blocked coolant flow |
| AC input fault | No AC power detected or voltage out of range | Charging cable, inlet, or OBC rectifier fault |
| DC output fault | DC output voltage/current out of specification | Internal power electronics failure |
| Isolation fault | Insulation resistance below threshold | Moisture intrusion, internal insulation breakdown |

### 3.2 Diagnosis Workflow
1. Connect diagnostic scan tool; read OBC fault codes
2. Check freeze frame data for fault conditions
3. Verify AC charging inlet connector condition
4. Check HV cable connections to OBC
5. Measure insulation resistance of OBC circuit
6. If fault confirmed as OBC internal — replacement required

---

## 4. Coolant Management for OBC

### 4.1 Coolant Drainage Procedure
1. Place a suitable collection container under the OBC coolant connections
2. Identify the coolant inlet and outlet hoses on the OBC
3. Loosen the hose clamps using insulated tools
4. Allow coolant to drain completely into the container
5. Cap the vehicle-side hoses to prevent further drainage and contamination

### 4.2 Coolant Disposal
- Spent HV coolant is classified as scheduled waste (SW305)
- Transfer to sealed, labeled containers
- Store in secondary containment area
- Dispose via licensed waste contractor

---

## 5. OBC Replacement Procedure (Overview)

1. Complete HV disconnection procedure (per KP(2/6) Section 4)
2. Drain coolant from OBC circuit
3. Disconnect HV cables from OBC (DC output and AC input connections)
4. Disconnect LV control connectors from OBC
5. Disconnect coolant hoses
6. Remove OBC mounting bolts
7. Remove the OBC unit (note weight — use appropriate technique)
8. Install new OBC in reverse order
9. Reconnect coolant hoses and refill coolant
10. Reconnect HV and LV connectors
11. Perform HV system re-energisation
12. Verify OBC functionality via diagnostic scan tool

### 5.1 Coolant Refill
- Use ONLY manufacturer-specified coolant type
- Refill to specified volume
- Bleed air from the cooling circuit per manufacturer procedure
- Run the cooling pump (via diagnostic tool active test) to circulate coolant
- Recheck level after circulation and top up if needed

---

## 6. OBC Functionality Test

After replacement:
1. Re-energise HV system
2. Connect diagnostic scan tool
3. Verify no OBC fault codes
4. Verify OBC communicates with BMS and VCU
5. Connect an AC charging cable
6. Verify charging initiates and operates at expected power level
7. Monitor OBC temperature during charging — should remain within specification
8. Disconnect charging cable and verify clean shutdown
