## Langkah Keselamatan / Safety Precautions

> **AMARAN / WARNING:** This activity involves direct interaction with HV circuits. Lethal voltages may be present. Follow every step precisely. NEVER skip the zero-energy verification step.

1. Full PPE must be worn at all times during this activity
2. HV work permit must be signed and posted before commencing
3. Minimum TWO qualified persons must be present throughout
4. NEVER assume any HV component is de-energised — always verify with CAT III multimeter
5. Insulated gloves must pass air inflation test before donning
6. Do NOT handle any orange HV cable without completing zero-energy verification (Step 3)
7. If any unexpected voltage reading is obtained — STOP, withdraw, and report to supervisor immediately

## Prosedur Kerja / Work Procedure

### Step 1: Pre-Work Verification
1.1 Confirm workplace preparation complete (per KK(1/6))
1.2 Confirm HV work permit signed and posted
1.3 Confirm second qualified person present

### Step 2: HV De-Energisation
2.1 Turn vehicle to "READY" OFF mode — confirm dashboard is off
2.2 Remove vehicle key fob — place in safety box and lock
2.3 Using insulated tools, disconnect 12V battery NEGATIVE terminal
2.4 Disconnect 12V battery POSITIVE terminal
2.5 Insulate exposed terminals with tape/covers
2.6 Locate the HV interlock/service plug (refer to manufacturer's manual for location)
2.7 Wearing insulated gloves, pull the interlock plug with firm, straight pull
2.8 Store interlock plug in safety box with vehicle key
2.9 **WAIT** the manufacturer-specified discharge time (minimum 5 minutes)
2.10 Record the start time of the waiting period

### Step 3: Zero-Energy Verification
3.1 Set CAT III multimeter to DC voltage, maximum range
3.2 Measure voltage between HV positive and HV negative terminals: must read <5V DC
3.3 Measure voltage between HV positive terminal and chassis ground: must read <5V DC
3.4 Measure voltage between HV negative terminal and chassis ground: must read <5V DC
3.5 **ALL THREE readings must confirm zero energy before proceeding**
3.6 Record all readings on the work documentation

### Step 4: HV Cable Inspection
4.1 Visually inspect the target cable: look for damage, chafing, discolouration, melting
4.2 Check cable connectors at both ends: corrosion, moisture, damaged pins, broken locks
4.3 Check connector seals (O-rings) for damage

### Step 5: Insulation Resistance Test
5.1 Set Mega Ohm meter to 500V DC test voltage
5.2 Connect one lead to the cable conductor (at disconnected connector end)
5.3 Connect the other lead to the cable shield or vehicle chassis
5.4 Initiate the test — allow reading to stabilise (30-60 seconds)
5.5 Read and record the insulation resistance value
5.6 Compare to manufacturer minimum (typically >1 MOhm)
5.7 If below minimum — cable replacement is required

### Step 6: Cable Replacement
6.1 Photograph the existing cable routing for reference
6.2 Disconnect the cable at both connector ends
6.3 Remove cable clips and routing guides
6.4 Remove the old cable
6.5 Route the new cable following the EXACT original path (refer to photos)
6.6 Secure with clips and routing guides at all original positions
6.7 Connect both ends — verify positive lock engagement at each connector
6.8 Perform insulation resistance test on the new cable (repeat Step 5)
6.9 Verify reading exceeds minimum specification

### Step 7: Interlock Continuity Verification
7.1 Set multimeter to continuity mode
7.2 Measure interlock loop continuity (per manufacturer procedure)
7.3 Confirm closed circuit — all HV connectors properly seated
7.4 Record the result

### Step 8: HV Re-Energisation
8.1 Retrieve interlock plug from safety box — reinstall
8.2 Reconnect 12V battery: POSITIVE terminal first, then NEGATIVE
8.3 Retrieve vehicle key from safety box
8.4 Turn vehicle to "READY" mode
8.5 Check dashboard — no HV-related warning lights should be present
8.6 Connect diagnostic scan tool:
   - Verify no new fault codes
   - Verify HV insulation resistance within specification
   - Verify all HV component communication restored

### Step 9: Documentation and Clean-Up
9.1 Complete all work documentation with readings, results, and actions
9.2 Remove barriers and signage (if all HV work is complete)
9.3 Store tools properly
9.4 Close HV work permit
