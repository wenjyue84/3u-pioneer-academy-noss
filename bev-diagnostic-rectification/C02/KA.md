### Section B
**B1:** (10 marks) 1. READY OFF (1m) 2. Key in safety box (1m) 3. Understand HV signage (1m) 4. Disconnect 12V negative (2m) 5. Remove interlock/store in safety box (2m) 6. Wait 5-10 min for capacitor discharge (1m) 7. Verify zero energy with CAT III multimeter — 3 measurements (2m)

**B2:** (8 marks — 2 each) a) Switch HV power on/off from battery to vehicle circuits b) Energises before main contactor to prevent inrush current c) Manual HV circuit break point for safety d) Measures charge/discharge current for BMS monitoring

**B3:** (8 marks) Place container (1m), identify hoses (1m), loosen clamps with insulated tools (1m), drain completely (1m), cap hoses (1m), transfer to sealed container (1m), label as SW305 (1m), dispose via licensed contractor (1m)

### Section C
**C1** (15 marks): a) Pre-charge timeout = capacitor voltage did not reach threshold within time limit. Normal sequence described (5m). b) Read fault codes, measure resistor value, relay coil resistance, check wiring, inspect connectors (5m). c) HV de-energisation, access relay pack, disconnect, remove, install new, reconnect, verify, test (5m).

**C2** (15 marks): a) De-energise, drain coolant, raise vehicle, disconnect HV/LV cables, position lift table, remove bolts, lower pack, secure on hanger (7m). b) Open housing, visual inspection, measure module voltages, identify deviant module, disconnect bus-bars/CMU, remove, install new, balance voltages (5m). c) Cell voltages, insulation resistance, BMS communication, pre-charge, cooling, no fault codes (3m).

**C3** (10 marks): Table with OBC vs DC-DC: Function (AC to DC vs HV DC to 12V DC), Input (AC 230/400V vs 200-800V DC), Output (200-800V DC vs 13.5-14.4V DC), Cooling (liquid vs liquid), Diagnostic (charging power/codes vs output voltage/stability).
