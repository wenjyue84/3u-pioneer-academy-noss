## Skema Jawapan / Answer Scheme

**S1:** B — The DC-DC converter replaces the alternator.
**S2:** a) Input: 200-800V DC; Output: 13.5-14.4V DC.
b) 12V battery constantly draining, dashboard warning lights, vehicle unable to enter "READY" mode, intermittent loss of 12V accessories.
**S3:** a) TRUE b) FALSE — most are liquid-cooled, integrated into HV cooling loop. c) TRUE
**S4:** Connect diagnostic scan tool. Read DC-DC converter fault codes. Check output voltage (should be 13.5-14.4V in READY mode). Monitor output stability under load. Check communication with BMS/VCU. Physical: inspect for coolant leaks, connector damage, mounting condition.
**S5:** C
**S6:** 2, 5, 4, 6, 3, 1, 7 → HV disconnect, drain coolant, disconnect HV cables, remove bolts, install new unit, reconnect coolant, test.
Correct order: 5, 2, 4, 6, 3, 1, 7
