## Competency Unit: Perform Battery Management System (BMS) Rectification
## Work Activity 5: Carry Out BEV Traction Battery Pack Replacement

---

## Objektif Pembelajaran / Learning Objectives

Upon completion of this Information Sheet, trainees will be able to:
1. Explain traction battery pack safety requirements and PPE for battery work
2. Describe traction battery pack components, specifications, and inspection procedures
3. Explain the procedure for battery pack removal, including coolant drainage and lifting
4. Describe battery module system inspection and faulty module replacement
5. Explain battery pack reinstallation, coolant refill, and functionality testing

---

## 1. Traction Battery Pack Safety

### 1.1 Safety Precautions

> **AMARAN / WARNING:** The traction battery pack contains lethal HV (200–800V DC) and weighs up to 700 kg. Damaged lithium-ion cells can cause THERMAL RUNAWAY — an uncontrollable fire exceeding 600°C releasing toxic HF gas. Never puncture, crush, or short-circuit any battery component.

The traction battery pack is the single most hazardous component in a BEV:
- Contains lethal HV (200-800V DC)
- Weighs 200-700 kg (requires specialised lifting equipment)
- Contains lithium-ion cells that can enter thermal runaway if mishandled
- Contains toxic electrolyte (lithium hexafluorophosphate — LiPF6)
- Coolant circuit must be drained before removal

### 1.2 PPE for Battery Pack Work
All standard BMS PPE plus:
- Safety helmet with face shield (for overhead work when battery is on lift table)
- Chemical-resistant apron (if electrolyte exposure risk exists)
- Respiratory protection (P100 or better) available for emergency use

### 1.3 Lifting Equipment
| Equipment | Capacity | Purpose |
|-----------|----------|---------|
| HV battery lifting table | 1 tonne minimum | Primary tool for lowering/raising battery pack |
| Balancing bar | >700 kg | Distributes load evenly during lift |
| Sling belts | >200 kg each | Secure attachment points to battery pack |
| Battery assembly transport hanger | Per manufacturer | Transport of removed battery pack |
| Hydraulic crane lifter | 1 tonne | Alternative/supplementary lifting |

## 2. Traction Battery Pack Components and Specification

### 2.1 Battery Pack Architecture
A typical BEV traction battery pack consists of:

| Component | Function |
|-----------|----------|
| Battery modules | Groups of cells connected in series/parallel; 8-36 modules per pack |
| Battery cells | Individual lithium-ion cells (pouch, prismatic, or cylindrical) |
| BMS master controller | Monitors and manages the overall pack |
| Cell Management Units (CMU) | Monitor individual cell voltages and temperatures |
| HV contactors | Main positive, main negative, pre-charge relay |
| Current sensor | Measures charge/discharge current |
| Cooling plate/channels | Liquid cooling pathways through the pack |
| Housing/enclosure | Structural, sealed, typically aluminium |
| Service plug/interlock | Manual disconnection point for safety |
| HV junction box | Distribution point for HV connections |

### 2.2 Battery Specifications (Typical Ranges)

| Parameter | Range |
|-----------|-------|
| Nominal voltage | 200-800V DC |
| Capacity | 30-120 kWh |
| Weight | 200-700 kg |
| Cell chemistry | NMC (Nickel Manganese Cobalt), LFP (Lithium Iron Phosphate), NCA (Nickel Cobalt Aluminium) |
| Cooling type | Liquid (most common), air (some older models) |
| Operating temperature | 15-45 deg C (optimal); BMS limits charging/discharging outside this range |

### 2.3 Battery Pack Inspection Procedure
Using diagnostic scan tool:
1. Read SOC (State of Charge) and SOH (State of Health)
2. Read individual cell voltages — check for deviations
3. Read temperature values across all zones
4. Check insulation resistance
5. Read current sensor calibration status
6. Check BMS fault code history

Physical inspection (after HV de-energisation):
1. Visual check of housing for damage, corrosion, deformation
2. Check for coolant leaks at fittings and seams
3. Inspect HV connectors and service plug condition
4. Check mounting bolt condition

## 3. Battery Pack Removal Procedure

### 3.1 Coolant Drainage
1. Locate the battery pack coolant inlet and outlet connections
2. Place collection containers at drain points
3. Open drain valves or disconnect hoses at the lowest point
4. Allow complete drainage — may take 10-20 minutes
5. Cap all open connections to prevent contamination
6. Dispose of coolant per waste management procedure (SW305)

### 3.2 Battery Pack Removal Steps
1. Complete HV disconnection and zero-energy verification
2. Drain coolant (Section 3.1)
3. Remove underbody shields/covers
4. Disconnect all HV cables from the battery pack
5. Disconnect all LV control cables (BMS, CMU, sensors)
6. Disconnect coolant hoses
7. Position the battery lifting table under the vehicle
8. Raise the lifting table until it contacts the battery pack
9. Remove battery pack mounting bolts (typically 8-16 bolts around the perimeter)
10. Slowly lower the lifting table — the battery pack separates from the vehicle
11. Lower completely and roll the lifting table out from under the vehicle
12. Secure the battery pack on the transport hanger

**CRITICAL SAFETY NOTE:** At least THREE qualified persons should be involved in battery pack removal — one operating the lifting table, two guiding and monitoring from each side.

---

## 4. Battery Module System Inspection

### 4.1 Module Inspection (on removed battery pack)
1. Open the battery pack housing (remove cover bolts)
2. Visual inspection of all modules: look for swelling, discolouration, electrolyte leakage
3. Check module connectors and bus-bar connections
4. Measure individual module voltages using insulated multimeter
5. Compare readings to manufacturer specification
6. Identify the faulty module(s)

### 4.2 Faulty Battery Module Replacement
1. Disconnect the faulty module bus-bar connections
2. Disconnect the CMU connector from the faulty module
3. Remove module mounting brackets
4. Carefully remove the faulty module (note weight — individual modules can weigh 10-40 kg)
5. Install the new module — verify correct orientation
6. Reconnect bus-bar connections and torque to specification
7. Reconnect CMU connector
8. Measure voltage of new module — must match other modules (within +/- 0.05V or per manufacturer)
9. Use HV battery module balancer if cell voltages need equalisation
10. Close battery pack housing

---

## 5. Battery Pack Reinstallation and Testing

### 5.1 Reinstallation
1. Position battery pack on lifting table under the vehicle
2. Raise the lifting table, guiding the pack into position
3. Install mounting bolts — torque to manufacturer specification in the prescribed sequence
4. Reconnect coolant hoses
5. Reconnect all LV control cables
6. Reconnect all HV cables
7. Reinstall underbody shields

### 5.2 Coolant Refill
- Use manufacturer-specified coolant type and volume
- Fill through the designated fill point
- Bleed air from the system per manufacturer procedure
- Run cooling pump via diagnostic tool active test
- Recheck level after circulation
- Verify no leaks at all connection points

### 5.3 Functionality Test
1. Reconnect interlock/service plug
2. Reconnect 12V battery
3. Turn vehicle to "READY" mode
4. Use diagnostic scan tool to verify:
   - All cell voltages within specification
   - Insulation resistance within specification
   - BMS communication restored with all CMUs
   - No fault codes
   - Pre-charge sequence completes successfully
   - Cooling system operational
5. Road test (if applicable) to verify under-load performance

## 6. Traction Battery Pack Failure Modes

| Component | Failure Mode | Symptom | Diagnosis |
|-----------|-------------|---------|-----------|
| Battery cell | Capacity degradation | Reduced range; SOH below 80% | BMS SOH reading via scan tool |
| Battery cell | Internal short circuit | Sudden voltage drop; thermal event risk | Cell voltage deviation >0.05V from average |
| Battery module | Cell voltage imbalance | Reduced capacity; BMS balancing fault | Individual cell voltage via scan tool |
| Battery module | Swelling (lithium plating) | Physical bulge on module housing | Visual inspection after pack removal |
| Cooling plate | Coolant leak | Overtemperature fault; coolant level low | Pressure test; visual inspection |
| Service plug | Connector degradation | Interlock fault; HV isolation fault | Continuity test; physical inspection |
| BMS master controller | Communication failure | Multiple fault codes; no HV enable | Scan tool; CAN bus check |
