The 3-working-day manual stock count will become an increasing bottleneck as the product range and distributor network grows.**

**B2. BUSINESS PROCESS IMPROVEMENT PROPOSAL**

Proposed improvement: **Replace the phone + manual spreadsheet order entry process with a simple online dealer ordering system or order management portal.**

Proposed change: **Implement an online order form or cloud-based order management system that allows dealers to place orders directly, automatically recording the order in the system without manual re-keying. Link the order system to inventory records to enable real-time stock visibility.**

Expected benefit: **Eliminates the approximately 6 keying errors per month, reduces order processing time, provides real-time order and inventory data accessible by the sales and operations teams, and reduces the stock count workload.
