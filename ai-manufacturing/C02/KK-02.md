## Dataset Sensor C02-KK02 — Huraian dan Contoh Data

Dataset yang disediakan oleh pensyarah (`C02-KK02-sensor-data.csv`) mengandungi 720 rekod (30 hari × 24 jam) data sensor siri masa untuk motor konveyor (conveyor motor) di kilang pemprosesan makanan. Dataset ini adalah **sintetik sepenuhnya** — cipta khas untuk tujuan latihan ini.

**Struktur Dataset:**

| Lajur | Jenis Data | Penerangan |
|---|---|---|
| `timestamp` | datetime | Tarikh dan masa bacaan sensor (setiap jam) |
| `temperature_celsius` | float | Suhu bearing (°C) |
| `vibration_rms` | float | Getaran RMS (mm/s) |
| `current_amp` | float | Arus motor elektrik (Ampere) |
| `pressure_bar` | float | Tekanan sistem penyejukan (bar) |
| `maintenance_flag` | integer | 1 = penyelenggaraan berlaku pada hari itu; 0 = tiada |
| `failure_flag` | integer | 1 = kegagalan berlaku; 0 = normal |

**Nota pada Dataset:**

| Hari | Peristiwa |
|---|---|
| Hari 1–15 | Operasi normal |
| Hari 16–20 | Kemerosotan bermula — suhu dan getaran meningkat secara progresif |
| Hari 21 | Kegagalan bearing (failure_flag = 1); kilang berhenti 4.5 jam |
| Hari 22 | Penyelenggaraan reaktif (maintenance_flag = 1); bearing digantikan |
| Hari 23–30 | Operasi kembali normal |

### Langkah 3: Pengesanan Anomali Menggunakan Isolation Forest (30 minit)

```python
# Langkah 3: Pengesanan anomali menggunakan Isolation Forest
from sklearn.ensemble import IsolationForest
from sklearn.preprocessing import StandardScaler

# Pilih ciri untuk analisis (gunakan semua sensor)
features = ['temperature_celsius', 'vibration_rms', 'current_amp', 'pressure_bar']
X = df[features].copy()

# Normalisasi (Z-score) — penting untuk Isolation Forest
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# Latih Isolation Forest
# contamination: anggaran nisbah anomali dalam dataset (kita tahu ~1/7 hari = 14%)
iso_forest = IsolationForest(
    n_estimators=100,      # Bilangan pokok
    contamination=0.15,    # Anggaran 15% data adalah anomali
    random_state=42        # Untuk kebolehulangan
)
iso_forest.fit(X_scaled)

# Ramalkan: -1 = anomali, 1 = normal
df['anomaly_prediction'] = iso_forest.predict(X_scaled)
df['anomaly_score'] = iso_forest.score_samples(X_scaled)  # Skor lebih rendah = lebih anomali

# Ringkasan keputusan
n_anomalies = (df['anomaly_prediction'] == -1).sum()
print(f"\n=== KEPUTUSAN ISOLATION FOREST ===")
print(f"Jumlah rekod: {len(df)}")
print(f"Rekod dikenal pasti sebagai anomali: {n_anomalies} ({n_anomalies/len(df)*100:.1f}%)")
print(f"\nRekod anomali yang bertindih dengan failure_flag=1 (kegagalan sebenar):")
print(df[df['failure_flag']==1]['anomaly_prediction'].value_counts())
```

```python
# Visualisasi anomali
```
