## Langkah Berjaga-Jaga Keselamatan

### Keselamatan Fizikal (jika memasang sensor pada peralatan sebenar)

> **AMARAN KESELAMATAN PENTING / CRITICAL SAFETY WARNING**
>
> Langkah-langkah keselamatan berikut MESTI dipatuhi sepenuhnya sebelum mendekati atau menyentuh sebarang peralatan kilang beroperasi. Kegagalan mematuhi boleh menyebabkan kecederaan serius atau kematian.

1. **Dapatkan kebenaran bertulis** daripada penyelia kilang sebelum mendekati mana-mana peralatan kritikal.
2. **Laksanakan prosedur Lockout/Tagout (LOTO)** yang lengkap sebelum memasang sensor pada peralatan elektrik atau mekanikal — rujuk KP-01, Bahagian 4.2.
3. **Pakai PPE yang lengkap:** topi keselamatan, kasut keselamatan, cermin mata keselamatan, sarung tangan sesuai.
4. **Periksa kawasan kerja:** Pastikan tiada risiko terjatuh, tersangkut pada bahagian berputar, atau terdedah kepada bahan berbahaya.
5. **Jangan bekerja berseorangan** pada peralatan kritikal — sistem buddy (dua orang) diperlukan.
6. **Patuhi OSHA 1994 (Akta 514)** dan peraturan keselamatan dalaman kilang.

### Keselamatan Digital (untuk aktiviti simulasi/cloud)

- Jangan masukkan sebarang nama peribadi sebenar, nombor IC, atau data sulit kilang sebenar ke dalam mana-mana platform cloud
- Gunakan akaun percubaan (trial account) dengan e-mel latihan — jangan gunakan akaun syarikat sebenar
- Padam semua sumber cloud selepas selesai latihan untuk mengelakkan caj yang tidak dijangka
- Simpan kata laluan dan kunci akses (access keys) dengan selamat — jangan kongsikan dalam e-mel atau kod program

### Langkah 3: Penjanaan Data Sensor Simulasi (30 minit)

Pensyarah menyediakan skrip Python berikut (`simulate_sensor.py`). Pelatih perlu memahami skrip ini, menjalankannya, dan mengubahsuai nilai ambang mengikut senario yang diberikan.

```python
# simulate_sensor.py
# Menghantar data sensor simulasi ke Azure IoT Hub
# PELATIH: Gantikan CONNECTION_STRING dengan nilai dari Langkah 2c

import time
import random
import json
from azure.iot.device import IoTHubDeviceClient, Message

CONNECTION_STRING = "GANTIKAN_DENGAN_CONNECTION_STRING_ANDA"

# Parameter sensor - sesuaikan mengikut senario anda
NORMAL_TEMPERATURE = 65.0    # Suhu operasi normal (°C)
NORMAL_VIBRATION = 3.5       # Getaran normal (mm/s RMS)
DEGRADATION_RATE = 0.05      # Kadar kemerosotan simulasi

def generate_sensor_data(timestamp, is_degrading=False):
    """Jana data sensor simulasi dengan variasi dan kemerosotan pilihan"""
    
    if is_degrading:
        # Simulasi kemerosotan progresif
        temp = NORMAL_TEMPERATURE + (timestamp * DEGRADATION_RATE) + random.gauss(0, 1.5)
        vibration = NORMAL_VIBRATION + (timestamp * DEGRADATION_RATE * 0.3) + random.gauss(0, 0.5)
    else:
        # Operasi normal dengan variasi rawak
        temp = NORMAL_TEMPERATURE + random.gauss(0, 2.0)
        vibration = NORMAL_VIBRATION + random.gauss(0, 0.8)
    
    return {
        "timestamp": time.strftime("%Y-%m-%dT%H:%M:%SZ", time.gmtime()),
        "device_id": "sensor-motor-001",
        "temperature_celsius": round(temp, 2),
        "vibration_rms_mm_per_s": round(vibration, 3),
        "simulation_mode": "degrading" if is_degrading else "normal"
    }

def main():
    client = IoTHubDeviceClient.create_from_connection_string(CONNECTION_STRING)
    print("Menyambung ke Azure IoT Hub...")
    client.connect()
    print("Berjaya disambungkan. Menghantar data sensor...")
    
    timestamp = 0
    try:
        while True:
            # Simulasi kemerosotan selepas 120 bacaan normal
            is_degrading = timestamp > 120
            data = generate_sensor_data(timestamp, is_degrading)
            message = Message(json.dumps(data))
            message.content_type = "application/json"
            message.content_encoding = "utf-8"
            client.send_message(message)
            print(f"Dihantar: Suhu={data['temperature_celsius']}°C, "
                  f"Getaran={data['vibration_rms_mm_per_s']} mm/s "
                  f"[{'MEROSOT' if is_degrading else 'Normal'}]")
            timestamp += 1
            time.sleep(5)  # Hantar setiap 5 saat
    except KeyboardInterrupt:
        print("Simulasi dihentikan oleh pelatih")
    finally:
        client.disconnect()

if __name__ == "__main__":
    main()
```

**4a.** Konfigurasi ambang amaran (alert thresholds) seperti berikut berdasarkan senario anda:

| Tahap Amaran | Warna | Suhu (°C) | Getaran (mm/s RMS) | Tindakan |
|---|---|---|---|---|
| Normal | Hijau | < 75 | < 7.1 | Pantau sahaja |
| Amaran | Kuning | 75 – 85 | 7.1 – 12.0 | Maklumkan teknisi; jadualkan semakan |
| Kritikal | Merah | > 85 | > 12.0 | Tindakan segera diperlukan |

> **NOTA:** Nilai ambang di atas adalah untuk tujuan latihan. Dalam persekitaran kilang sebenar, ambang mesti ditetapkan berdasarkan spesifikasi pengeluar peralatan dan data baseline peralatan tersebut.

**4b.** Ambil tangkapan skrin dashboard yang menunjukkan:
