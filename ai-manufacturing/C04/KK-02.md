## Prosedur / Procedure

### Bahagian A: Ramalan Permintaan dengan Prophet

**Langkah 1: Persediaan Persekitaran Python**

Buka Jupyter Notebook atau VS Code. Pastikan pakej Prophet telah dipasang:

```python
# Pasang pakej jika belum ada (jalankan dalam terminal, bukan dalam notebook)
# pip install prophet pandas matplotlib

# Import pakej
import pandas as pd
from prophet import Prophet
import matplotlib.pyplot as plt
```

**Langkah 2: Masukkan Data Sejarah**

```python
# Masukkan data permintaan sejarah kilang PCB (sintetik)
data_permintaan = {
    'ds': [
        '2025-08-31', '2025-09-30', '2025-10-31', '2025-11-30',
        '2025-12-31', '2026-01-31', '2026-02-28', '2026-03-31',
        '2026-04-30', '2026-05-31', '2026-06-30', '2026-07-31'
    ],
    'y': [4250, 4180, 4560, 4320, 4780, 3950, 4100, 4430,
          4250, 4640, 4800, 4550]
}

df = pd.DataFrame(data_permintaan)
df['ds'] = pd.to_datetime(df['ds'])

print("Data dimuat dengan berjaya. Baris:", len(df))
print(df)
```

**Langkah 3: Latih Model Prophet**

```python
# Konfigurasikan model Prophet
# Tambah hari cuti Malaysia yang relevan
cuti_malaysia = pd.DataFrame({
    'holiday': 'Hari_Raya',
    'ds': pd.to_datetime(['2026-04-01', '2026-04-02', '2026-04-03']),
    'lower_window': -3,  # 3 hari sebelum — pengeluaran meningkat
    'upper_window': 5,   # 5 hari selepas — pemulihan
})

cuti_cny = pd.DataFrame({
    'holiday': 'Chinese_New_Year',
    'ds': pd.to_datetime(['2026-01-29', '2026-01-30', '2026-01-31']),
    'lower_window': -5,
    'upper_window': 7,
})

semua_cuti = pd.concat([cuti_malaysia, cuti_cny])

# Latih model
model = Prophet(
    holidays=semua_cuti,
    yearly_seasonality=True,
    weekly_seasonality=False,  # Data bulanan — tiada corak mingguan
    changepoint_prior_scale=0.05  # Kawalan fleksibiliti trend
)
model.fit(df)

print("Model Prophet berjaya dilatih.")
```

**Langkah 4: Janakan Ramalan 3 Bulan Hadapan**

```python
# Janakan dataframe untuk 3 bulan hadapan (Ogos, September, Oktober 2026)
tempoh_akan_datang = model.make_future_dataframe(periods=3, freq='M')
ramalan = model.predict(tempoh_akan_datang)

# Paparkan ramalan 3 bulan terakhir (ramalan baharu)
ramalan_baharu = ramalan[['ds', 'yhat', 'yhat_lower', 'yhat_upper']].tail(3)
print("\n=== RAMALAN PERMINTAAN 3 BULAN HADAPAN ===")
print(ramalan_baharu.to_string(index=False))
```

**Output ramalan yang dijangka (pelatih akan mendapatkan nilai hampir dengan ini):**

> **NOTA:** Nilai sebenar mungkin berbeza sedikit bergantung kepada versi Prophet yang digunakan. Ini adalah output yang dijangka berdasarkan data input sintetik.

**Langkah 5: Plot Ramalan**

```python
# Plot ramalan
fig1 = model.plot(ramalan)
plt.title('Ramalan Permintaan PCB — Model Prophet')

plt.tight_layout()

```

### Bahagian B: Penyusunan Jadual Pengeluaran

**Langkah 6: Jana Jadual Pengeluaran Berdasarkan Ramalan AI**

Menggunakan ramalan Prophet untuk bulan Ogos 2026 (~4,620 unit), jana jadual pengeluaran mingguan:

**Andaian operasi:**
- Hari bekerja: 5 hari/minggu, 1 syif/hari
- Kapasiti bersih selepas bottleneck diatasi (ST-04 dinaik taraf): 125 unit/syif
- Kapasiti mingguan = 125 unit × 5 syif = 625 unit/minggu
- Ogos 2026 = 4 minggu kerja penuh (4 × 625 = 2,500 unit untuk separuh bulan pertama; sesuaikan untuk bulan penuh)

**Jadual Pengeluaran AI untuk Ogos 2026 (Sintetik):**

| Minggu | Tarikh | Ramalan Permintaan (unit) | Jadual AI (unit) | Kapasiti Tersedia | Lebihan/(Kekurangan) |
|--------|--------|--------------------------|-----------------|-------------------|----------------------|
| Minggu 1 | 3–7 Ogos | 1,155 | 1,150 | 625 × 2 syif = 1,250 | +100 |
| Minggu 2 | 10–14 Ogos | 1,155 | 1,150 | 1,250 | +100 |
| Minggu 3 | 17–21 Ogos | 1,155 | 1,150 | 1,250 | +100 |
| Minggu 4 | 24–28 Ogos | 1,155 | 1,170 | 1,250 | +80 |
| **Jumlah** | | **4,620** | **4,620** | **5,000** | **+380** |

> **Nota:** Jadual AI menetapkan pengeluaran tepat sama dengan ramalan permintaan untuk mengelakkan stok berlebihan, sambil memastikan kapasiti tersedia mencukupi.

**Langkah 7: Jana Jadual JIT Manual (Sebagai Perbandingan)**

Dalam pendekatan JIT manual, perancang menggunakan permintaan sejarah bulan lalu (Julai 2026 = 4,550 unit) sebagai asas, ditambah stok keselamatan 5%:

```
Jadual JIT = 4,550 × 1.05 = 4,778 unit (dibulatkan ke 4,800 unit)
Diagihkan sama rata: 4,800 ÷ 4 minggu = 1,200 unit/minggu
```

**Perbandingan Jadual:**

| Parameter | Jadual JIT Manual | Jadual AI Prophet |
|-----------|------------------|-------------------|
| Jumlah pengeluaran dirancang | 4,800 unit | 4,620 unit |
| Permintaan sebenar (ramalan) | — | 4,620 unit |
| Lebihan pengeluaran dijangka | 4,800 − 4,620 = **180 unit (stok berlebihan)** | 4,620 − 4,620 = **0 unit** |
| Nilai stok berlebihan (@ RM65/unit) | **RM11,700** | RM0 |
| Penyesuaian terhadap hari cuti | Tiada (kaedah manual) | Ya (Prophet mengambil kira pola cuti) |
| Masa penyediaan jadual | 2–3 jam manual | < 15 minit (automatik) |

### Bahagian C: Pengiraan Keuntungan Kecekapan

**Langkah 8: Kira Peningkatan OTD**

Gunakan andaian berikut:
- **Sebelum AI**: Ramalan JIT manual menghasilkan OTD 79% (khas kilang ini, berdasarkan rekod sejarah dalam data sintetik)
- **Selepas AI**: Ramalan Prophet lebih tepat → OTD dijangka meningkat kepada 91%

```
Peningkatan OTD = 91% − 79% = +12 mata peratusan
```

**Langkah 9: Kira Penjimatan Kos Inventori**

```
Nilai stok berlebihan dielakkan (bulanan) = 180 unit × RM65 = RM11,700
Kos penyimpanan inventori (anggaran 2% nilai inventori sebulan) = RM11,700 × 2% = RM234/bulan
Kos stok usang (risiko) = anggaran RM585/bulan (5% stok berlebihan tidak terjual dalam 30 hari)
Jumlah penjimatan kos inventori = RM234 + RM585 = RM819/bulan

Penjimatan tahunan (12 bulan) = RM819 × 12 = RM9,828/tahun (anggaran kasar)
```

> **NOTA PENTING:** Angka-angka di atas adalah ilustratif berdasarkan data sintetik. Dalam persekitaran sebenar, pelatih perlu menggunakan data kilang sebenar untuk pengiraan yang bermakna.
