## Senario Kilang KK-02 — REKAAN SEPENUHNYA

> **PERINGATAN:** Semua butiran dalam senario ini — nama, angka, syarikat, dan lokasi — adalah rekaan sepenuhnya untuk tujuan pengajaran. Sebarang persamaan dengan entiti sebenar adalah kebetulan semata-mata.

**Senario:** Anda adalah pengurus SCM baru sebuah kilang pemasangan komponen automotif di Senai FIZ, Johor. Kilang ini, yang kita panggil "**Kilang Kenanga Electronics (KKE)**" (rekaan), menghasilkan modul kawalan enjin (Engine Control Module / ECM) untuk pelanggan tunggal — sebuah pengeluar kenderaan komersial (rekaan). Kilang ini beroperasi secara lean dengan inventori penyangga (buffer stock) yang minimum.

**Maklumat Operasi KKE (rekaan):**

| Parameter | Maklumat |
|---|---|
| Pengeluaran harian | 450 unit ECM / hari (5 hari seminggu) |
| Pelanggan | Satu pelanggan OEM (rekaan) — 100% jualan |
| Bilangan pembekal aktif | 12 pembekal (4 dari Malaysia, 5 dari China, 2 dari Taiwan, 1 dari Jepun) |
| Komponen kritikal | Mikropemproses ARM (dari pembekal tunggal di Taiwan), Sensor suhu (dari pembekal Malaysia), Modul komunikasi CAN (dari China) |
| Lead time pembekal terjauh | 25 hari bekerja (Taiwan, melalui laut) |
| Lead time pembekal terdekat | 3 hari bekerja (pembekal Malaysia dalam Johor) |
| Polisi inventori semasa | Safety stock 5 hari pengeluaran untuk semua komponen |
| Rekod stockout 12 bulan lepas | 3 kejadian (sekali akibat kelewatan kastam; dua kali akibat kualiti ditolak) |
| Polisi pesanan semula | Manual — pengurus perolehan menyemak aras stok setiap Isnin |

## Arahan Langkah Demi Langkah / Step-by-Step Instructions

### Bahagian A: Pemetaan Rantaian Bekalan (30 minit)

#### Langkah 1: Lukis Peta Rantaian Bekalan KKE

Berdasarkan senario KKE di atas, lukis peta rantaian bekalan ringkas yang menunjukkan:

- **Peringkat 1:** Pembekal bahan mentah dan komponen (nyatakan negara asal setiap pembekal)
- **Peringkat 2:** Kilang KKE (proses pengeluaran ECM)
- **Peringkat 3:** Pelanggan OEM
- **Aliran:** Tunjukkan aliran bahan (→) dan aliran maklumat / pesanan (- - →)
- **Nod kritikal:** Tandakan nod yang paling kritikal atau berisiko tinggi (cth. pembekal tunggal)

Anda boleh melukis secara tangan di kertas A3, atau menggunakan alat digital (PowerPoint, draw.io, Canva).

**Panduan elemen minimum dalam peta:**

```
[Pembekal Malaysia ×4]  [Pembekal China ×5]  [Pembekal Taiwan ×2]  [Pembekal Jepun ×1]
          │                     │                      │                    │
          └──────────────────────┴──────────────────────┘────────────────────┘
                                         │
                               [Kilang Kenanga Electronics
                                Senai FIZ, Johor]
                                  (Pemasangan ECM)
                                         │
                                [Pelanggan OEM Tunggal]
```

### Bahagian B: Penilaian Risiko (40 minit)

#### Langkah 2: Kenal Pasti Risiko

Berdasarkan senario KKE, kenal pasti sekurang-kurangnya **5 risiko rantaian bekalan** merentasi minimum 3 kategori (Pembekal, Logistik, Permintaan, Geopolitik).

Gunakan struktur berikut untuk mengenal pasti risiko:

*Soalan panduan untuk mengenal pasti risiko:*
- Apakah yang boleh menyebabkan pengeluaran KKE berhenti selama lebih 1 hari?
- Pembekal manakah yang paling berisiko?
- Apakah yang boleh berlaku sekiranya pelanggan OEM tunggal tiba-tiba mengurangkan pesanan?
- Apakah risiko geopolitik yang mempengaruhi pembekal dari China dan Taiwan?
- Apakah kelemahan dalam proses semakan manual setiap Isnin?

#### Langkah 3: Nilai Risiko Menggunakan Matriks Kemungkinan × Impak

Untuk setiap risiko yang dikenal pasti, nilai Kemungkinan (1–5) dan Impak (1–5) menggunakan skala dalam KP-03.

#### Langkah 4: Analisis Risiko Utama

Daripada senarai risiko anda, pilih **3 risiko yang mendapat skor tertinggi** dan buat analisis yang lebih mendalam untuk setiap satu:

Untuk setiap risiko kritikal/tinggi:
- **Penerangan terperinci risiko** (apa, bagaimana, bila boleh berlaku)
- **Kesan jangka pendek** kepada operasi KKE (pengeluaran, kos, pelanggan)
- **Kesan jangka panjang** (reputasi, hubungan pelanggan, keuntungan)
- **Isyarat awal (early warning signs)** yang boleh dikesan sebelum risiko berlaku

### Bahagian C: Reka Bentuk Dashboard Amaran Awal AI (30 minit)

#### Langkah 5: Reka Seni Bina Dashboard Amaran Awal

Reka bentuk seni bina sistem amaran awal berkuasa AI untuk KKE yang merangkumi komponen berikut:

**5a. Sumber Data (Data Sources)**

Senaraikan sekurang-kurangnya **6 sumber data** yang perlu diintegrasikan ke dalam sistem amaran awal KKE. Untuk setiap sumber, nyatakan:
- Jenis data
- Kekerapan kemas kini
- Format data (cth. API, fail EDI, manual input)

**5b. Peraturan Amaran (Alert Rules)**

Reka bentuk sekurang-kurangnya **5 peraturan amaran** yang spesifik untuk KKE. Format:

| ID Peraturan | Nama Amaran | Pencetus (Trigger) | Penerima | Keutamaan |
|---|---|---|---|---|
| A01 | | | | |
| A02 | | | | |
| A03 | | | | |
| A04 | | | | |
| A05 | | | | |

**5c. Kandungan Dashboard (Dashboard Layout)**

Lakarkan atau huraikan kandungan papan pemuka utama yang akan dilihat oleh Pengurus SCM KKE setiap pagi. Nyatakan sekurang-kurangnya 5 panel/bahagian utama dan maklumat yang dipaparkan dalam setiap panel.

**5d. Protokol Eskalasi**

Huraikan 3 peringkat eskalasi yang berlaku apabila amaran kritikal tidak diselesaikan dalam masa yang ditetapkan.

---

### Bahagian D: Laporan dan Pembentangan (20 minit persediaan + 10 minit pembentang)

#### Langkah 6: Hasilkan Laporan Ringkas Penilaian Risiko dan Cadangan

Hasilkan laporan ringkas (1–2 halaman) yang mengandungi:

1. **Ringkasan Eksekutif** (3–5 ayat): Gambaran keseluruhan situasi risiko KKE dan keperluan sistem amaran awal.

2. **Peta Rantaian Bekalan** (lampirkan gambarajah dari Langkah 1)

3. **Daftar Risiko** (ringkasan jadual dari Langkah 3)

4. **Analisis 3 Risiko Kritikal/Tinggi** (dari Langkah 4)

5. **Cadangan Mitigasi** (minimum 3 cadangan spesifik):
   - Nyatakan tindakan yang dicadangkan
   - Nyatakan siapa yang bertanggungjawab
   - Nyatakan jangka masa pelaksanaan (segera / 3 bulan / 6 bulan)
   - Anggaran kos atau sumber diperlukan (jika relevan)

6. **Seni Bina Dashboard Amaran Awal** (gambarajah dan peraturan amaran dari Langkah 5)

#### Langkah 7: Persediaan Pembentangan (10 minit)

Sediakan pembentangan ringkas (5–7 slaid atau penjelasan lisan) untuk dibentangkan kepada pensyarah (sebagai simulasi pembentangan kepada Ketua Jabatan / Pengurusan KKE).

**Struktur pembentangan:**
1. Situasi semasa (1 slaid)
2. Risiko utama yang dikenal pasti (1 slaid)
3. Penilaian risiko — matriks (1 slaid)
4. Seni bina sistem amaran awal (1 slaid)
5. Cadangan mitigasi (1 slaid)
6. Langkah seterusnya (1 slaid)

## Kriteria Penilaian / Evaluation Criteria

| Kriteria | Sangat Baik (4) | Baik (3) | Mencukupi (2) | Perlu Penambahbaikan (1) |

| **Penilaian Risiko (L × I)** | Semua skor betul dan dijustifikasi dengan baik berdasarkan senario | Skor betul; justifikasi ringkas | Skor ada; justifikasi lemah | Skor tidak konsisten atau tidak dijustifikasi |

| **Laporan dan Pembentangan** | Laporan profesional; 3+ cadangan spesifik dengan tanggungjawab dan jangka masa; pembentangan yakin | Laporan tersusun; 3 cadangan; pembentangan baik | Laporan ada; 2 cadangan; pembentangan memadai | Laporan tidak lengkap; 1 cadangan atau pembentangan tidak berlaku |

4. Bagaimanakah sistem amaran awal AI yang anda reka bentuk berbeza daripada sistem semakan manual sedia ada? Huraikan 3 perbezaan utama yang memberi manfaat kepada KKE.
