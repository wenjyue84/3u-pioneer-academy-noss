### Bahagian B — Panduan Pemarkahan

**B1:**
- (a) EOQ = √(2 × 18,000 × 160 / 3.20) = √(5,760,000 / 3.20) = √1,800,000 = 1,342 unit *(±1 unit kerana pembundaran)*
- (b) SS = 1.960 × 18 × √14 = 1.960 × 18 × 3.742 = 132 unit *(±2 unit)*
- (c) d̄ = 18,000/250 = 72 unit/hari; ROP = 72 × 14 + 132 = 1,008 + 132 = 1,140 unit
- (d) Bilangan pesanan = 18,000 / 1,342 = 13.4 ≈ 14 pesanan/tahun

**B2:**
- MAPE: ralat % = 4.44%, 4.17%, 5.95%, 2.35% → MAPE = (4.44+4.17+5.95+2.35)/4 = 16.91/4 = 4.23% → Tafsiran: Baik (< 10%)
- Bias = [(470-450) + (460-480) + (445-420) + (498-510)] / 4 = [20 + (-20) + 25 + (-12)] / 4 = 13/4 = +3.25 unit/bulan → Over-forecast kecil

**B3:**
- Nilai kumulatif: 850,000 (88.8%), 95,000 (9.9%), 12,000 (1.3%); Jumlah = 957,000
- A: 850,000 (kumulatif 88.8%); B: 945,000 (kumulatif 98.7%); C: 957,000 (100%)
- SKU 12,000: C (ABC) + Z (XYZ) = CZ → Strategi: Pertimbangkan VMI atau JIT; kurangkan stok yang dipegang

**B4:** Empat komponen: Sumber Data, Enjin AI Pemprosesan, Enjin Peraturan Amaran, Papan Pemuka dan Pengagihan Amaran. Markah 2.5 setiap komponen: nama + penerangan + contoh.
