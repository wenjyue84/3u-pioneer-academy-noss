### Bahagian A: Persediaan Produk dan Taksonomi Kecacatan (30 minit)

| Pilihan | Produk | Jenis Kecacatan yang Mungkin |
|---|---|---|

| **B** | Botol plastik (pembungkusan minuman) | Lubang (pinhole), penyok (dent), cetakan kabur, penutup tidak betul |
| **C** | Baju T (tekstil) | Lubang, jahitan terlepas, kotor, label tidak betul |
| **D** | Roti/produk bakar | Permukaan terbakar (over-burnt), bentuk tidak teratur, kontaminan asing |

Rekodkan pilihan anda: _______________________

#### Langkah A2: Bina Taksonomi Kecacatan

Berdasarkan produk anda, tentukan **3–5 kelas kecacatan** yang akan diajar kepada model AI. Sertakan kelas "LULUS" (no_defect) sebagai kelas tambahan.

Isi jadual taksonomi kecacatan dalam Bahagian Rekod Pelatih (Jadual T1).

Panduan untuk setiap kelas kecacatan:
- Nama kelas (dalam English, tanpa spasi — contoh: `solder_bridge`)
- Penerangan kecacatan dalam 1–2 ayat
- Gred (Kritikal / Major / Minor)

---

### Bahagian B: Pengumpulan dan Anotasi Imej (60 minit)

#### Langkah B1: Muat Naik Imej ke Roboflow

1. Log masuk ke [roboflow.com](https://roboflow.com) dengan akaun anda.
2. Klik **Create New Project** → pilih **Object Detection**.
3. Namakan projek: `C03-[nama_anda]-[produk]` (contoh: `C03-ahmad-pcb`).
4. Muat naik semua imej yang disediakan pensyarah ATAU imej yang anda tangkap menggunakan kamera/webcam.

**Keperluan minimum:** 100 imej (sekurang-kurangnya 15 imej per kelas kecacatan).

#### Langkah B2: Anotasi Imej (Labelling)

1. Dalam Roboflow, klik **Annotate**.
2. Untuk setiap imej, lukis kotak pembatas (bounding box) di sekeliling setiap kecacatan yang kelihatan.
3. Pilih kelas kecacatan yang betul untuk setiap kotak.
4. Untuk imej LULUS (tiada kecacatan): jangan lukis sebarang kotak — tandakan imej sebagai `no_defect` menggunakan label imej jika platform membenarkan.

**Panduan anotasi bounding box:**
- Kotak mestilah menampung keseluruhan kecacatan
- Beri margin 2–3 piksel di sekeliling kecacatan
- Jangan memasukkan kawasan latar belakang yang terlalu besar dalam kotak

Rekod bilangan imej yang dianotasi dalam Bahagian Rekod Pelatih (Jadual T2).

#### Langkah B3: Semakan Kualiti Anotasi

Selepas 50 imej pertama dianotasi:
1. Minta rakan sekelas anda menyemak 10 imej yang anda anotasi.
2. Tandakan mana-mana anotasi yang tidak jelas atau tidak konsisten.
3. Perbetulkan sebelum meneruskan.

Rekod bilangan perbetulkan dalam Bahagian Rekod Pelatih.

#### Langkah B4: Jana Dataset dalam Format YOLO

1. Dalam Roboflow, klik **Generate** → pilih **Train/Valid/Test** split: 70% / 20% / 10%.
2. Aktifkan augmentasi berikut (pilih sekurang-kurangnya 3):
   - Flip: Horizontal
   - Rotation: -15° hingga +15°
   - Brightness: -20% hingga +20%
   - Blur: sehingga 1.5px
3. Klik **Generate** → pilih format **YOLOv8**.
4. Salin kod Snippet Python yang disediakan (mengandungi API key dan URL dataset).

Rekod ID projek Roboflow dan versi dataset anda dalam Bahagian Rekod Pelatih.


Rekod output (nama GPU) dalam Bahagian Rekod Pelatih.

#### Langkah C2: Muat Turun Dataset dari Roboflow

```python
# Sel 3: Muat turun dataset (gantikan dengan code snippet anda dari Roboflow)
from roboflow import Roboflow

# GANTIKAN nilai-nilai di bawah dengan maklumat projek anda
rf = Roboflow(api_key="GANTIKAN_DENGAN_API_KEY_ANDA")
project = rf.workspace("GANTIKAN_WORKSPACE_ANDA").project("GANTIKAN_PROJEK_ANDA")
version = project.version(1)  # guna nombor versi dataset anda
dataset = version.download("yolov8")
```

#### Langkah C3: Latih Model YOLOv8

```python
# Sel 4: Latihan model
from ultralytics import YOLO

# Muat model pra-latih (kecil — sesuai untuk Colab percuma)
model = YOLO("yolov8n.pt")

# Mulakan latihan
results = model.train(
    data=f"{dataset.location}/data.yaml",
    epochs=50,           # Boleh tingkatkan ke 100 untuk prestasi lebih baik
    imgsz=640,           # Saiz imej input
    batch=16,            # Kurangkan ke 8 jika Colab kehabisan memori GPU
    name="c03_defect_model",
    patience=10          # Henti awal jika tiada penambahbaikan selepas 10 epoch
)

print("Latihan selesai!")
print(f"Model terbaik disimpan di: {results.save_dir}/weights/best.pt")
```

> **Masa latihan dijangka:** 30–60 minit untuk 50 epoch pada GPU T4 dengan dataset ~100 imej.

Rekod masa latihan dan lokasi model dalam Bahagian Rekod Pelatih.

### Bahagian D: Inferens dan Penilaian Prestasi (45 minit)

#### Langkah D1: Jalankan Inferens pada Set Ujian

```python
# Sel 6: Muat model terbaik dan jalankan inferens pada set ujian
model_best = YOLO(f"{results.save_dir}/weights/best.pt")

# Inferens pada semua imej dalam folder ujian
test_results = model_best.predict(
    source=f"{dataset.location}/test/images",
    conf=0.50,          # Ambang keyakinan: 50%
    save=True,          # Simpan imej dengan anotasi
    save_txt=True,      # Simpan label ramalan (.txt)
    name="c03_test_inference"
)

print(f"Inferens selesai pada {len(test_results)} imej")
```

#### Langkah D2: Dapatkan Laporan Penilaian Model Automatik

```python
# Sel 7: Nilai model pada set pengesahan (validation set)
val_results = model_best.val(
    data=f"{dataset.location}/data.yaml",
    split="val"
)

print("=== KEPUTUSAN PENILAIAN ===")
print(f"mAP50: {val_results.box.map50:.4f}")
print(f"Precision: {val_results.box.mp:.4f}")
print(f"Recall: {val_results.box.mr:.4f}")
```

Rekod nilai mAP50, Precision, dan Recall dalam Bahagian Rekod Pelatih (Jadual T3).

- Label sebenar (dari nama fail atau anotasi asal)
- Label yang diramalkan oleh model (dari hasil inferens)

Isi Jadual T4 dalam Bahagian Rekod Pelatih.
