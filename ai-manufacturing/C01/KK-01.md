## Tajuk Aktiviti Kerja / Work Activity Title

Jalankan Penilaian Kesediaan Industri 4.0 dan Pemetaan Proses untuk Senario Kilang Malaysia

---

## Hasil Pembelajaran / Learning Outcomes

Pada akhir aktiviti ini, pelatih akan:

- Telah melengkapkan penilaian IMPAK merentasi lapan dimensi untuk senario kilang yang diberikan
- Telah mengira skor IMPAK keseluruhan dan menentukan peringkat kematangan kilang
- Telah menghasilkan carta radar IMPAK menggunakan Microsoft Excel
- Telah memetakan proses pengeluaran semasa dan mengenal pasti sekurang-kurangnya tiga titik integrasi AI
- Telah menghasilkan laporan penilaian berstruktur (2–3 halaman) yang sesuai untuk pembentangan kepada pengurusan kilang

## Arahan Langkah Demi Langkah / Step-by-Step Instructions

### Langkah 1: Fahami Senario Kilang (20 minit)

Baca penerangan senario kilang yang ditetapkan dengan teliti. Kemudian, jawab soalan-soalan berikut dalam Helaian Jawapan anda di bawah **Bahagian 1: Pemahaman Senario**:

1.1 Apakah produk utama yang dikeluarkan oleh kilang ini?

1.2 Apakah sektor industri dan pasaran sasaran kilang ini?

1.3 Apakah proses pengeluaran utama yang anda jangkakan wujud dalam kilang ini (senaraikan 4–6 proses)?

1.4 Apakah cabaran pengeluaran biasa dalam sektor ini (berdasarkan pengetahuan daripada KP-01)?

---

### Langkah 2: Penilaian IMPAK — Lapan Dimensi (45 minit)

Berdasarkan penerangan senario kilang, nilai kilang tersebut pada setiap dimensi IMPAK menggunakan skala 1–5.

Untuk setiap dimensi, anda mesti:
- Memberikan skor (1–5)
- Memberikan **justifikasi** (1–2 ayat) mengapa skor itu diberikan berdasarkan ciri-ciri senario kilang
- Mengenal pasti **peluang penambahbaikan** utama untuk dimensi tersebut

Rekodkan dalam Helaian Jawapan di bawah **Bahagian 2: Penilaian IMPAK**:

| Dimensi | Soalan Panduan | Skor (1–5) | Justifikasi | Peluang |
|---|---|---|---|---|
| **D1 — Operasi & Proses** | Adakah proses pengeluaran didokumenkan secara digital? Adakah SOP dalam sistem elektronik atau kertas? | | | |
| **D2 — Teknologi & Automasi** | Apakah peratusan anggaran mesin yang automatik berbanding operasi manual? | | | |
| **D3 — Data & Analitik** | Adakah data pengeluaran dikumpul secara automatik? Adakah dashboard prestasi wujud? | | | |
| **D4 — Kesambungan** | Adakah mesin, sistem MES/ERP, dan pekerja bersambung dalam satu platform? | | | |
| **D5 — Pembuatan Pintar** | Adakah AI atau analitik lanjutan digunakan untuk membuat keputusan pengeluaran? | | | |
| **D6 — Tenaga Kerja & Budaya** | Adakah pekerja mempunyai kemahiran data? Adakah budaya 'data-driven decision making'? | | | |
| **D7 — Keselamatan Siber** | Adakah sistem OT/IT kilang dilindungi daripada ancaman siber? Adakah polisi keselamatan siber ada? | | | |
| **D8 — Kemampanan** | Adakah kilang memantau penggunaan tenaga dan sisa pengeluaran secara sistematik? | | | |

---

### Langkah 3: Pengiraan Skor IMPAK dan Carta Radar (30 minit)

**3.1 Kira Skor IMPAK Keseluruhan**

Masukkan skor anda ke dalam template pengiraan Microsoft Excel yang disediakan.

Gunakan jadual wajaran berikut (sama seperti dalam KP-03):

| Dimensi | Skor anda | Wajaran | Skor Wajaran |
|---|---|---|---|
| D1 — Operasi & Proses | | 0.20 | |
| D2 — Teknologi & Automasi | | 0.20 | |
| D3 — Data & Analitik | | 0.15 | |
| D4 — Kesambungan | | 0.15 | |
| D5 — Pembuatan Pintar | | 0.10 | |
| D6 — Tenaga Kerja & Budaya | | 0.10 | |
| D7 — Keselamatan Siber | | 0.05 | |
| D8 — Kemampanan | | 0.05 | |
| **JUMLAH** | | **1.00** | |

**Formula:** Skor Wajaran = Skor × Wajaran. Jumlah semua Skor Wajaran = Skor IMPAK Keseluruhan (skala 1.00–5.00)

**Skor IMPAK Saya:** ________ / 5.00 → Peringkat: ________

**3.2 Hasilkan Carta Radar IMPAK**

Dalam Microsoft Excel:
1. Masukkan nama lapan dimensi dalam satu lajur
2. Masukkan skor anda dalam lajur bersebelahan
3. Pilih kedua-dua lajur → Insert → Chart → Radar Chart (Spider Chart)
4. Tambah tajuk: "Penilaian IMPAK — [Nama Senario Kilang]"
5. Simpan carta sebagai imej dan tampal dalam laporan anda

---

- Senario A: Talian SMT (Surface Mount Technology)
- Senario B: Lini pemesinan (machining line) untuk kepala silinder
- Senario C: Lini pembungkusan dan pelabelan produk halal

### Langkah 6: Hasilkan Laporan Penilaian (30 minit)

Gunakan Microsoft Word atau Google Docs untuk menghasilkan laporan ringkas (2–3 halaman) yang mengandungi:

**Struktur Laporan Penilaian Kesediaan Industri 4.0:**

```
1. RINGKASAN EKSEKUTIF (1/2 muka surat)
   • Nama kilang (nama senario fiktif)
   • Skor IMPAK: [X.XX / 5.00] — Peringkat [X]: [Nama Peringkat]
   • Tiga dimensi terkuat dan tiga dimensi paling lemah
   • Cadangan utama (3 perkara sahaja)

2. KEPUTUSAN PENILAIAN IMPAK (1 muka surat)
   • Jadual skor lapan dimensi
   • Carta radar IMPAK (tampal imej Excel)
   • Justifikasi ringkas setiap skor

3. PEMETAAN PROSES DAN TITIK INTEGRASI AI (1/2 muka surat)
   • Sub-proses yang dipetakan
   • Imej carta alir proses (dari draw.io atau lukisan)
   • Jadual tiga titik integrasi AI dengan keutamaan

4. CADANGAN TINDAKAN SEGERA (1/4 muka surat)
   • Satu projek AI yang disyorkan untuk dilaksanakan dalam 6 bulan
   • Justifikasi pemilihan: impak vs. kos vs. kesesuaian teknikal
```

## Kriteria Penilaian / Evaluation Criteria

| Kriteria | Cemerlang (4) | Baik (3) | Memuaskan (2) | Perlu Penambahbaikan (1) |
|---|---|---|---|---|
| **Ketelitian Penilaian IMPAK** | Lapan dimensi dinilai dengan justifikasi terperinci dan realistik | Tujuh dimensi mempunyai justifikasi; satu kurang terperinci | Lima atau lebih dimensi dinilai; justifikasi asas | Kurang dari lima dimensi atau skor tanpa justifikasi |
| **Ketepatan Pengiraan Skor** | Pengiraan wajaran betul; carta radar lengkap dan berlabel | Pengiraan betul; carta radar ada tetapi kurang berlabel | Pengiraan betul; tiada carta radar | Kesilapan pengiraan atau tiada usaha carta radar |
| **Kualiti Pemetaan Proses** | 6+ langkah dipetakan; carta alir jelas; masa kitaran dan masalah direkodkan | 5 langkah; carta ada; sebahagian maklumat dilengkapkan | 4 langkah; carta mudah; maklumat terhad | Kurang dari 4 langkah; tiada carta |
| **Kualiti Titik Integrasi AI** | 3 titik AI; setiap satu dengan masalah, jenis AI, manfaat, dan keutamaan yang jelas | 3 titik; kebanyakan maklumat dilengkapkan | 2 titik; maklumat asas | 1 titik atau tiada keutamaan |
| **Kualiti Laporan** | Format profesional; semua 4 bahagian lengkap; boleh dibentangkan kepada pengurusan | 3 bahagian lengkap; format sebahagiannya profesional | 2 bahagian lengkap; boleh dibaca | Tidak lengkap atau tidak berstruktur |

## Soalan Refleksi / Reflection Questions

1. Antara lapan dimensi IMPAK, dimensi manakah yang anda rasa paling sukar untuk dinilai dengan tepat, dan mengapa?

2. Semasa memetakan proses, apakah penemuan yang paling mengejutkan anda tentang proses pengeluaran dalam senario kilang tersebut?

3. Jika anda adalah pengurus kilang senario ini, titik integrasi AI manakah yang akan anda laksanakan **pertama sekali**, dan bagaimana anda akan meyakinkan pemilik kilang untuk meluluskan bajet pelaburan tersebut?

4. Bagaimanakah laporan penilaian kesediaan yang anda hasilkan boleh digunakan untuk menyokong permohonan insentif MIDA Industri 4.0?
