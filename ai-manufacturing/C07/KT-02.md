## Tugasan / Tasks

### Soalan 1 — SCADA Konvensional vs. SCADA Berteraskan AI (25 markah)

Kilang kimia *Nusa Chemicals Sdn Bhd* di Pasir Gudang, Johor (senario sintetik) menggunakan sistem SCADA GE iFIX yang dipasang 10 tahun lalu. Pengurus kilang menerima laporan bahawa pengendali kilang sering mengabaikan penggera kerana terlalu banyak penggera yang berbunyi setiap hari (alarm fatigue). Mereka mempertimbangkan untuk menambah modul AI kepada SCADA sedia ada.

**a)** Apakah **tiga (3)** batasan SCADA konvensional yang menjadi punca masalah di Nusa Chemicals, termasuk masalah alarm fatigue? Huraikan setiap batasan dengan jelas. **(12 markah)**

**b)** Cadangkan **dua (2)** modul AI yang boleh ditambah kepada sistem SCADA Nusa Chemicals untuk menangani masalah yang anda kenal pasti. Terangkan bagaimana setiap modul berfungsi dan masalah spesifik yang ia selesaikan. **(13 markah)**

---

### Soalan 2 — Evolusi dan Ciri HMI Pintar (20 markah)

**a)** Huraikan evolusi HMI dari Generasi 1 (analog panel) hingga Generasi 4 (Intelligent HMI). Untuk setiap generasi, nyatakan teknologi utama dan satu kelebihan berbanding generasi sebelumnya. **(12 markah)**

**b)** Kilang Nusa Chemicals ingin menaik taraf HMI mereka kepada Intelligent HMI. Namakan **dua (2)** ciri Intelligent HMI yang paling bermanfaat untuk kilang kimia yang menjalankan proses berbahaya, dan jelaskan mengapa ciri tersebut penting dalam konteks keselamatan. **(8 markah)**

---

### Soalan 3 — Tadbir Urus Data Kilang Pintar (30 markah)

Kilang Nusa Chemicals mengumpulkan data berikut setiap hari:
- Data tekanan tangki dari 40 sensor (setiap saat)
- Rekod ujian kualiti produk kimia (setiap batch)
- Data kehadiran pekerja menggunakan cap ibu jari (setiap hari)
- Rekod pesanan pelanggan dari ERP SAP (setiap hari)
- Log kejadian SCADA (penggera, penghantaran arahan)

**a)** Untuk **setiap** jenis data di atas, lengkapkan jadual tadbir urus data berikut: **(20 markah)**

| Jenis Data | Pemilik Data | Kawalan Akses (siapa boleh akses?) | Tempoh Simpanan | Implikasi PDPA 2010 |
|---|---|---|---|---|
| Data tekanan tangki | | | | |
| Rekod ujian kualiti | | | | |
| Data kehadiran pekerja | | | | |
| Rekod pesanan pelanggan | | | | |
| Log kejadian SCADA | | | | |

**b)** Mengapakah data kehadiran pekerja (cap ibu jari) memerlukan perlakuan tadbir urus yang **lebih ketat** berbanding data tekanan tangki? Huraikan berdasarkan prinsip PDPA 2010. **(10 markah)**

---

### Soalan 4 — Seni Bina Data Lake Tiga Zon (25 markah)

**a)** Bezakan antara **Data Lake** dan **Data Warehouse** menggunakan **empat (4)** dimensi perbandingan. **(8 markah)**

**b)** Kilang Nusa Chemicals ingin membina data lake menggunakan Azure Data Lake Storage Gen2. Lakarkan seni bina tiga zon (raw, curated, analytics) dan untuk setiap zon: **(17 markah)**

- Namakan zon tersebut (Bahasa Malaysia dan Inggeris)
- Berikan **dua (2)** contoh data Nusa Chemicals yang sesuai disimpan di zon tersebut
- Terangkan satu transformasi yang berlaku semasa data berpindah dari Zon Raw ke Zon Curated
