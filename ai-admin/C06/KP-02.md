## 1. Data Analysis with ChatGPT (Advanced Data Analysis)

### 1.1 Overview

ChatGPT's **Advanced Data Analysis** feature (available in ChatGPT Plus / Team accounts) allows users to upload files — CSV, Excel, PDF — and ask analytical questions in plain English. ChatGPT internally runs Python code to process the data and returns charts, summaries, and calculations.

This is particularly powerful for office administrators who understand their data but do not know how to write formulas or code.

### 1.2 Supported File Formats for Upload

| Format | Extension | Notes |
|---|---|---|
| CSV (Comma-Separated Values) | .csv | Most reliable; export from any spreadsheet |
| Microsoft Excel | .xlsx, .xls | Works well; ChatGPT reads all sheets |
| PDF (tabular data) | .pdf | Less reliable for complex tables; prefer CSV |
| JSON | .json | For API data exports |

### 1.3 Effective Prompting for Data Analysis

When uploading a CSV to ChatGPT, the quality of the output depends heavily on the quality of the prompt. Use the **CRAFT framework** for analytical prompts:

| Element | Meaning | Example for Data Analysis |
|---|---|---|
| **C — Context** | Who you are and what the data represents | "This is 12 months of sales data for a Malaysian electrical goods wholesaler" |
| **R — Role** | The role ChatGPT should play | "Act as a senior business analyst" |
| **A — Action** | The specific task | "Calculate monthly gross profit margin and identify the 3 lowest-performing months" |
| **F — Format** | How to present the output | "Present as a table with Month, Revenue, Expenses, Gross Profit, and Margin %" |
| **T — Tone** | The register of language | "Use plain language suitable for a non-technical Operations Director" |

## 2. Excel Copilot for Chart Generation and Trend Identification

### 2.1 What Is Excel Copilot?

**Excel Copilot** is the AI assistant built into Microsoft Excel 365 (Microsoft 365 subscription required). It is accessible via the Copilot button in the Excel ribbon or by pressing **Alt + C**.

Excel Copilot can:

- Generate charts from selected data with a single prompt
- Write formulas (SUM, AVERAGE, IF, VLOOKUP, pivot tables) based on a plain-language description
- Identify trends and patterns in data and write a summary
- Highlight rows that meet specified conditions
- Sort and filter data based on natural language instructions

### 2.2 Key Copilot Prompts for BI Analysis

| Task | Excel Copilot Prompt |
|---|---|
| Create a revenue trend chart | "Create a line chart showing Revenue by Month" |
| Calculate percentage change | "Add a column showing month-on-month % change in Revenue" |
| Identify outliers | "Highlight in red any months where Expenses exceeded RM 88,000" |
| Generate a summary | "Summarise the key trends in this sales data in 3 bullet points" |
| Create a pivot table | "Create a pivot table showing Total Expenses by Category" |
| Calculate gross profit margin | "Add a column for Gross Profit Margin % = (Revenue - Expenses) / Revenue × 100" |

### 2.3 Worked Example: Excel Copilot Analysis of Syarikat Mentari Raya Data

Using the 12-month dataset from KP-01, a trainee enters the following into Excel Copilot:

**Prompt:** "Calculate the gross profit margin percentage for each month and identify the three months with the lowest margin. Then create a bar chart of gross profit margin by month."

**Expected output table:**

| Month | Revenue (RM) | Expenses (RM) | Gross Profit (RM) | Gross Profit Margin % |
|---|---|---|---|---|
| Jan | 98,000 | 72,000 | 26,000 | 26.5% |
| Feb | 105,000 | 75,000 | 30,000 | 28.6% |
| Mar | 112,000 | 78,000 | 34,000 | 30.4% |
| Apr | 118,000 | 80,000 | 38,000 | 32.2% |
| May | 125,000 | 82,000 | 43,000 | 34.4% |
| Jun | 130,000 | 85,000 | 45,000 | 34.6% |
| Jul | 122,000 | 88,000 | 34,000 | 27.9% |
| Aug | 115,000 | 86,000 | 29,000 | 25.2% |
| Sep | 128,000 | 84,000 | 44,000 | 34.4% |
| Oct | 135,000 | 87,000 | 48,000 | 35.6% |
| Nov | 142,500 | 90,000 | 52,500 | 36.8% |
| Dec | 150,000 | 92,000 | 58,000 | 38.7% |

**Verification of Gross Profit Margin % (spot-check three months):**
- Jan: 26,000 ÷ 98,000 × 100 = **26.5%** ✓
- Aug: 29,000 ÷ 115,000 × 100 = **25.2%** ✓
- Dec: 58,000 ÷ 150,000 × 100 = **38.7%** ✓

**Lowest three months by margin:** August (25.2%), January (26.5%), July (27.9%)

**Interpretation:** The July–August dip is likely due to increased staff costs (RM 46,000 both months) and sustained logistics costs while revenue was below the second-half peak. This is a signal that the business should review logistics efficiency during the mid-year period.

## 3. Data Cleaning Before AI Analysis (Pembersihan Data)

### 3.1 Why Data Cleaning Is Critical

AI tools produce accurate outputs only when fed accurate inputs. In data analysis, this principle is expressed as **"Garbage In, Garbage Out" (GIGO)**. Common data quality problems in Malaysian SME environments include:

- Duplicate transaction records (same invoice recorded twice)
- Missing values (blank cells in key columns)
- Inconsistent formats (dates as "01/01/2025" in some rows and "1 Jan 25" in others)
- Typographical errors (RM "1,500" entered as "15,00" or "1.500")
- Inconsistent category names ("Logistics", "logistics", "LOGISTIC" all referring to the same category)

### 3.2 Five Core Data Cleaning Techniques

#### Technique 1: Remove Duplicates (Buang Pendua)

In Excel: Select the data range → **Data tab → Remove Duplicates** → select all columns → OK.

In ChatGPT prompt: *"Check if there are any duplicate rows in this dataset based on the Month column. If yes, list them."*

#### Technique 2: Fill or Flag Missing Values (Isi atau Tandakan Nilai Kosong)

| Strategy | When to Use | Action |
|---|---|---|
| Fill with zero | Expenses not incurred (e.g., no marketing spend in a month) | Replace blank with 0 |
| Fill with average | Minor data gaps where the value should be present | Use AVERAGE of adjacent rows |
| Flag and investigate | Large gaps that may indicate missing data | Highlight in yellow; ask data owner to verify |
| Delete row | Entire row is meaningless without the missing value | Delete only after backup copy made |

In Excel: Use **Ctrl + H** (Find & Replace) to replace blanks, or **Ctrl + G → Special → Blanks** to select all blank cells.

#### Technique 3: Standardise Formats (Seragamkan Format)

**Date format standardisation:** Always use one consistent format. In Malaysia, the recommended format for BI tools is **DD/MM/YYYY** (e.g., 01/01/2025). Use Excel's Format Cells (Ctrl + 1) → Date → select the correct format.

**Text case standardisation:** Use Excel formulas:
- `=UPPER(A1)` — converts to all uppercase (e.g., "LOGISTICS")
- `=LOWER(A1)` — converts to all lowercase (e.g., "logistics")
- `=PROPER(A1)` — capitalises first letter (e.g., "Logistics")

**Number format:** Ensure all monetary values are stored as numbers, not text. Numbers right-align in Excel cells; text left-aligns. If numbers are left-aligned, they need to be converted using `=VALUE(A1)`.

#### Technique 4: Correct Inconsistent Category Names (Seragamkan Nama Kategori)

This is the most common problem in Malaysian SME spreadsheets maintained by multiple staff. For the Syarikat Mentari Raya expense data, a badly maintained version might look like this:

| Entry | Problem |
|---|---|
| "logistics" | Lowercase — won't match "Logistics" in a pivot table |
| "LOGISTIC" | Plural missing — separate category in pivot |
| "Staff cost" | "cost" vs. "Costs" — two rows in pivot table |

**Fix:** Use Excel's Find & Replace (Ctrl + H) to standardise each category name, then run a pivot table to confirm only the expected categories appear.

#### Technique 5: Validate Totals (Sahkan Jumlah)

After cleaning, always verify that key totals are correct before importing into a BI tool:

```
Sum of all monthly expenses = Annual total in summary row
Sum of Category A + B + C + D + E = Monthly total for each month
```

Any discrepancy after cleaning indicates either a remaining error or a misunderstanding of the data structure.

### 3.3 Data Cleaning Checklist

Before uploading any dataset to Power BI, Looker Studio, or ChatGPT:

- [ ] Removed all duplicate rows
- [ ] Filled or flagged all blank cells (no silent blanks)
- [ ] All dates in consistent format (DD/MM/YYYY)
- [ ] All monetary values are numbers (not text)
- [ ] Category names are consistent (same spelling, same case)
- [ ] Row totals cross-check with column totals
- [ ] Made a backup copy of the original file before modifying

## 4. Python Pandas and Matplotlib — An Introduction (Optional Extension)

### 4.1 Why Python for Office Administrators?

Python is not required for this CU — all tasks can be completed using Power BI, Looker Studio, or ChatGPT. However, trainees who wish to extend their skills will find that Python's **Pandas** library (for data manipulation) and **Matplotlib** library (for charting) provide greater flexibility and automation capability.

> **No-code alternative:** For every Python step described in this section, a no-code equivalent using Excel or ChatGPT is provided.

### 4.2 Core Pandas Operations

| Operation | Python (Pandas) | No-Code Equivalent |
|---|---|---|
| Load a CSV file | `df = pd.read_csv('data.csv')` | Open file in Excel |
| View first 5 rows | `df.head()` | Scroll to top of sheet |
| Check for blank values | `df.isnull().sum()` | Ctrl + G → Special → Blanks |
| Calculate column sum | `df['Revenue'].sum()` | =SUM(B2:B13) |
| Calculate percentage | `df['Margin'] = df['Profit']/df['Revenue']*100` | Manual formula column in Excel |
| Filter rows | `df[df['Revenue'] > 120000]` | Excel filter → greater than 120,000 |
| Sort by column | `df.sort_values('Revenue', ascending=False)` | Excel sort → Largest to Smallest |
| Export to CSV | `df.to_csv('output.csv')` | File → Save As → CSV |

### 4.3 Core Matplotlib Chart Types

| Chart | Code Pattern | Use |
|---|---|---|
| Line chart | `plt.plot(x, y)` | Trends over time |
| Bar chart | `plt.bar(x, y)` | Category comparison |
| Pie chart | `plt.pie(values, labels=labels)` | Proportion breakdown |
| Scatter plot | `plt.scatter(x, y)` | Correlation between two variables |

For trainees interested in going further, the recommended learning path is: **Excel Copilot → ChatGPT Advanced Data Analysis → Power BI → Python Pandas**.

## 5. Verifying AI-Generated Figures — The Verification Protocol

AI tools, including ChatGPT and Excel Copilot, can produce figures that appear correct but contain calculation errors. This is known as **AI hallucination** in the context of data analysis. The following three-step protocol must be applied before including any AI-generated number in a management report:

| Step | Action | Tool |
|---|---|---|
| **Step 1: Trace to source** | Identify which rows in the source data the AI used for the calculation | Open the source file |
| **Step 2: Manual spot-check** | Manually calculate at least 2 figures from the AI output | Calculator or Excel formula |
| **Step 3: Totals cross-check** | Confirm that all subtotals sum to the overall total | =SUM() in Excel |

> **AMARAN / WARNING:** Never submit a report containing AI-generated figures without completing this protocol. A government reviewer or auditor checking the report may find a discrepancy that damages the credibility of both the report and the organisation.
