## Work Activity Title

Build an Automated Data Dashboard for Real-Time Business Performance Monitoring

---

## Learning Outcomes

By the end of this activity, trainees will have:

- Connected a provided CSV dataset to Power BI Desktop or Google Looker Studio
- Built a dashboard with at least 4 distinct visual components
- Applied dashboard design principles (clarity, visual hierarchy, colour coding)
- Identified and flagged one anomaly in the dataset
- Produced a 1-page interpretation memo suitable for management

### Step 2: Connect Dataset to BI Tool (15 minutes)

**Option A — Power BI Desktop:**
1. Open Power BI Desktop → click **Get Data** → select **Text/CSV**
2. Browse to `mentari_raya_2025.csv` → click **Load**
3. In the **Fields** pane (right side), confirm all 10 columns appear
4. Click **Transform Data** → verify that Month is recognised as Text and Revenue/Expenses as whole numbers
5. Close & Apply

**Option B — Google Looker Studio:**
1. First, upload the CSV to Google Drive as a Google Sheet: open Google Sheets → File → Import → Upload the CSV
2. In Looker Studio, click **+ Create → Report → Add data**
3. Select **Google Sheets** → choose your uploaded sheet → click **Add**
4. Confirm the dimensions (Month, Region) and metrics (Revenue, Expenses, etc.) are correctly identified

Record which tool you chose and any issues encountered:

### Step 3: Build the Four Dashboard Visuals (60 minutes)

You must build **exactly four visuals** in your dashboard. Use the specifications below.

#### Visual 1 — Revenue Scorecard

| Specification | Detail |
|---|---|
| Visual Type | **Card / Scorecard** |
| Metric | Total Revenue (sum of all 12 months) |
| Title | "Total 2025 Revenue (RM)" |
| Expected Value | RM 1,480,500 |
| Formatting | Display with comma separator; no decimal places |

**Power BI:** Drag "Revenue" to the **Fields** well of a **Card** visual. Set the title in Format → General → Title.

**Looker Studio:** Add a **Scorecard** → set Metric to SUM(Revenue) → set title in Style panel.

---

#### Visual 2 — Monthly Revenue Trend (Line Chart)

| Specification | Detail |
|---|---|
| Visual Type | **Line Chart** |
| X-axis | Month (Jan-25 to Dec-25) |
| Y-axis | Revenue (RM) |
| Title | "Monthly Revenue Trend — Jan to Dec 2025" |
| Expected peak | December: RM 150,000 |
| Expected dip | July: RM 122,000 |

Add data labels on the line so each month's value is visible.

---

#### Visual 3 — Expense Category Breakdown (Donut Chart)

| Specification | Detail |
|---|---|
| Visual Type | **Donut Chart** (Pie variant) |
| Segments | Staff_Costs, Logistics, Utilities, Marketing, Admin |
| Title | "2025 Annual Expense Breakdown by Category" |
| Expected largest segment | Staff Costs: RM 524,000 (52.5%) |
| Colour coding | Staff Costs = Blue; Logistics = Orange; Utilities = Green; Marketing = Purple; Admin = Grey |

Confirm the five segments sum to RM 999,000.

---

#### Visual 4 — Gross Profit Margin by Month (Bar Chart)

| Specification | Detail |
|---|---|
| Visual Type | **Bar Chart** (vertical / column chart) |
| X-axis | Month |
| Y-axis | Gross Profit Margin % |
| Title | "Monthly Gross Profit Margin % — 2025" |
| Calculation needed | Gross_Profit ÷ Revenue × 100 |
| Expected lowest | August: 25.2% |
| Expected highest | December: 38.7% |

**Power BI:** Create a measure: `GP Margin % = DIVIDE(SUM('Table'[Gross_Profit]), SUM('Table'[Revenue])) * 100`

**Looker Studio:** Create a Calculated Field: `(Gross_Profit / Revenue) * 100`

Add a reference line at 30% to show the target threshold.

---

### Step 4: Apply Dashboard Design Principles (15 minutes)

Arrange the four visuals on a single dashboard page following the visual hierarchy rule:

- **Top row:** Revenue Scorecard (left) + two summary numbers: Total Expenses (RM 999,000) and Total Gross Profit (RM 481,500) as additional Scorecards
- **Middle row:** Monthly Revenue Trend (line chart) — full width
- **Bottom row (left):** Expense Breakdown Donut | **Bottom row (right):** GP Margin Bar Chart

Check each item on the design checklist:
- [ ] All visuals have descriptive titles
- [ ] No more than 5 colours used across the entire dashboard
- [ ] All monetary values formatted with RM prefix and comma separator
- [ ] Percentage values formatted with one decimal place (e.g., 32.5%)
- [ ] Font size is readable at 100% zoom on a 14-inch screen
