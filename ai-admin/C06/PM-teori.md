## Jadual Pengajaran Teori / Theory Teaching Schedule

### MINGGU 1 / WEEK 1 — KP-01: Business Intelligence Tools (4 jam / 4 hours)

---

#### Sesi 1.1 — What Is Business Intelligence? (1 jam)

| Komponen | Perincian |
|---|---|
| **Tempoh / Duration** | 60 minit |
| **Topik** | KP-01 §1: Introduction to BI; BI Functions (Descriptive, Diagnostic, Predictive, Prescriptive); BI in Malaysian SME context |
| **Objektif Sesi** | Pelatih dapat mendefinisikan BI dan membezakan empat fungsi BI dengan contoh yang relevan |

**Pelaksanaan (60 minit):**

| Masa | Aktiviti | Kaedah |
|---|---|---|
| 0–10 min | Pembukaan: soal jawab — "Bagaimana pengurus syarikat anda/keluarga anda tahu perniagaan berjalan baik?" | Perbincangan |
| 10–30 min | Syarahan: Definisi BI, empat fungsi BI, kepentingan BI untuk PKS Malaysia | Kuliah + slaid |
| 30–45 min | Demonstrasi: Tunjukkan satu dashboard contoh (Power BI atau Looker Studio) yang menggambarkan keempat-empat fungsi BI | Demo langsung |
| 45–55 min | Aktiviti berstruktur: Pelatih mengklasifikasikan 8 pernyataan ke dalam Descriptive / Diagnostic / Predictive / Prescriptive | Kerja individu |
| 55–60 min | Rumusan dan soal jawab | Q&A |

**Bahan yang diperlukan:** Slaid KP-01 §1; contoh dashboard Power BI (pre-built dengan data mentari_raya_2025.csv); lembaran klasifikasi (8 pernyataan)

---

#### Sesi 1.2 — Microsoft Power BI: Features and AI Capabilities (1 jam 30 minit)

| Komponen | Perincian |
|---|---|
| **Tempoh / Duration** | 90 minit |
| **Topik** | KP-01 §2: Power BI editions; core concepts; AI features (Q&A, Copilot, Quick Insights, Anomaly Detection); connecting to data sources |
| **Objektif Sesi** | Pelatih dapat menjelaskan lima ciri AI Power BI dan kaedah menghubungkan Power BI kepada sumber data PKS Malaysia |

**Pelaksanaan (90 minit):**

| Masa | Aktiviti | Kaedah |
|---|---|---|
| 0–10 min | Semak semula Sesi 1.1: soal jawab pantas (4 fungsi BI) | Q&A |
| 10–35 min | Syarahan: Power BI editions, core concepts (Dataset, Report, Dashboard, Visual, Measure, Filter, Slicer), data source connections | Kuliah + slaid |
| 35–60 min | Demonstrasi langsung: Pensyarah membuka Power BI Desktop, import mentari_raya_2025.csv, menunjukkan Power Query, dan membina satu Visual Card | Demo langsung |
| 60–75 min | Demonstrasi: Power BI Q&A feature — taip soalan dalam Bahasa Inggeris dan lihat visual dijana automatik; Quick Insights pada dataset | Demo langsung |
| 75–85 min | Perbincangan: Bila menggunakan Q&A vs. Quick Insights? Apakah had AI Power BI? | Perbincangan |
| 85–90 min | Rumusan dan soal jawab | Q&A |

**Bahan yang diperlukan:** Power BI Desktop terpasang pada komputer pensyarah; fail mentari_raya_2025.csv; slaid KP-01 §2

---

#### Sesi 1.3 — Google Looker Studio and Dashboard Design Principles (1 jam 30 minit)

| Komponen | Perincian |
|---|---|
| **Tempoh / Duration** | 90 minit |
| **Topik** | KP-01 §3–5: Looker Studio features; comparing Power BI vs. Looker Studio; dashboard design principles (clarity, hierarchy, colour); anti-patterns; PDPA considerations |
| **Objektif Sesi** | Pelatih dapat membina satu visual asas dalam Looker Studio dan menilai sama ada sebuah dashboard mematuhi tiga prinsip reka bentuk |

**Pelaksanaan (90 minit):**

| Masa | Aktiviti | Kaedah |
|---|---|---|
| 0–15 min | Demonstrasi: Pensyarah log masuk ke lookerstudio.google.com, menyambung Google Sheet (mentari_raya diupload terlebih dahulu), tambah satu Scorecard visual | Demo langsung |
| 15–30 min | Syarahan: Perbezaan utama Power BI vs. Looker Studio (jadual perbandingan KP-01 §5) | Kuliah + slaid |
| 30–50 min | Syarahan dan aktiviti: Tiga prinsip reka bentuk dashboard — Clarity, Visual Hierarchy, Colour; lima anti-patterns | Kuliah + slaid |
| 50–70 min | Aktiviti penilaian dashboard: Pensyarah paparkan tiga contoh dashboard (satu cemerlang, satu sederhana, satu lemah). Pelatih nilai setiap dashboard menggunakan senarai semak reka bentuk. | Kerja individu + perbincangan |
| 70–80 min | Syarahan: PDPA 2010 considerations untuk BI dashboards (KP-01 §6) | Kuliah |
| 80–90 min | Rumusan sesi; pratonton KP-02 | Q&A |

**Bahan yang diperlukan:** Akaun Google pensyarah; mentari_raya_2025 diupload ke Google Sheets; tiga contoh dashboard (boleh dibina terlebih dahulu atau gunakan tangkap layar); senarai semak reka bentuk (dicetak atau digital)

### MINGGU 2 / WEEK 2 — KP-02: AI-Assisted Data Analysis and Data Cleaning (4 jam / 4 hours)

---

#### Sesi 2.1 — ChatGPT Advanced Data Analysis and the CRAFT Framework (1 jam 30 minit)

| Komponen | Perincian |
|---|---|
| **Tempoh / Duration** | 90 minit |
| **Topik** | KP-02 §1: ChatGPT file upload; supported formats; CRAFT framework; worked example with Syarikat Mentari Raya expense data |
| **Objektif Sesi** | Pelatih dapat menulis prompt CRAFT yang lengkap untuk analisis data CSV dan mengesahkan output ChatGPT terhadap data sumber |

**Pelaksanaan (90 minit):**

| Masa | Aktiviti | Kaedah |
|---|---|---|
| 0–10 min | Pembukaan: "Apakah risiko memuat naik data perniagaan ke ChatGPT tanpa verifikasi?" — perbincangan | Perbincangan |
| 10–25 min | Syarahan: ChatGPT Advanced Data Analysis — cara upload fail, format yang disokong, apa yang AI lakukan dengan data | Kuliah + slaid |
| 25–45 min | Syarahan: Rangka kerja CRAFT — setiap elemen dengan contoh untuk analisis data | Kuliah + slaid |
| 45–70 min | Demonstrasi langsung: Pensyarah upload mentari_raya_Q3_expense.csv ke ChatGPT, masukkan prompt CRAFT penuh, semak output terhadap pengiraan manual yang telah disediakan pada slaid | Demo langsung |
| 70–80 min | Perbincangan: ChatGPT mengeluarkan angka yang salah — bagaimana cara mengesan dan membetulkan? | Perbincangan |
| 80–90 min | Soal jawab dan rumusan | Q&A |

---

#### Sesi 2.2 — Excel Copilot and Data Cleaning (1 jam 30 minit)

| Komponen | Perincian |
|---|---|
| **Tempoh / Duration** | 90 minit |
| **Topik** | KP-02 §2–3: Excel Copilot features; data cleaning — 5 techniques; data cleaning checklist; GIGO principle |
| **Objektif Sesi** | Pelatih dapat menggunakan Excel Copilot untuk menjana carta dan mengesan arah aliran; dapat mengaplikasikan lima teknik pembersihan data kepada dataset yang diberikan |

**Pelaksanaan (90 minit):**

| Masa | Aktiviti | Kaedah |
|---|---|---|
| 0–20 min | Demonstrasi langsung: Excel Copilot — prompt untuk mencipta carta, menambah lajur peratus perubahan, menyerlahkan baris di mana perbelanjaan melebihi had | Demo langsung |
| 20–35 min | Syarahan: Prinsip GIGO — kenapa data kotor menghasilkan laporan salah | Kuliah + slaid |
| 35–65 min | Syarahan dan demonstrasi: Lima teknik pembersihan data — Remove Duplicates, Fill Missing Values, Standardise Formats, Correct Inconsistent Categories, Validate Totals. Untuk setiap teknik: tunjukkan contoh masalah dan langkah pembetulan dalam Excel | Demo langsung |
| 65–80 min | Aktiviti: Pelatih diberi lembaran Excel yang mengandungi 6 masalah data (termasuk pendua, nilai kosong, format tidak konsisten). Tugas: kenal pasti semua 6 masalah. | Kerja individu |
| 80–90 min | Semak jawapan bersama-sama; soal jawab | Perbincangan + Q&A |

---

#### Sesi 2.3 — Python Introduction and AI Verification Protocol (1 jam)

| Komponen | Perincian |
|---|---|
| **Tempoh / Duration** | 60 minit |
| **Topik** | KP-02 §4–5: Python Pandas/Matplotlib overview (no-code alternatives for each); three-step AI verification protocol |
| **Objektif Sesi** | Pelatih dapat menerangkan peranan Python Pandas dalam analisis data (tanpa perlu mengkod); dapat mengaplikasikan protokol pengesahan tiga langkah terhadap output AI |

**Pelaksanaan (60 minit):**

| Masa | Aktiviti | Kaedah |
|---|---|---|
| 0–20 min | Syarahan: Python Pandas dan Matplotlib — jadual perbandingan Python vs. Excel (KP-02 §4.2); tunjukkan bahawa setiap operasi Python ada padanannya di Excel | Kuliah + slaid |
| 20–35 min | Syarahan: Protokol Pengesahan AI Tiga Langkah (Trace → Spot-check → Cross-check totals) | Kuliah + slaid |
| 35–55 min | Aktiviti pengesahan: Pelatih diberi output ChatGPT yang mengandungi dua kesilapan angka. Tugas: gunakan protokol tiga langkah untuk mengesan kesilapan menggunakan data sumber yang disediakan. | Kerja individu |
| 55–60 min | Rumusan dan pratonton KP-03 | Q&A |

### MINGGU 3 / WEEK 3 — KP-03: SME KPI Frameworks and Performance Reporting (4 jam / 4 hours)

---

#### Sesi 3.1 — Five Core KPIs and Their Calculation (1 jam 30 minit)

| Komponen | Perincian |
|---|---|
| **Tempoh / Duration** | 90 minit |
| **Topik** | KP-03 §1–1.2: KPI definition; 5 core KPIs with formulas and worked examples; characteristics of good KPIs |
| **Objektif Sesi** | Pelatih dapat mengira kelima-lima KPI dengan tepat menggunakan data Syarikat Mentari Raya yang disediakan |

**Pelaksanaan (90 minit):**

| Masa | Aktiviti | Kaedah |
|---|---|---|
| 0–10 min | Perbincangan pembuka: "Apakah 3 nombor yang paling penting bagi pengurus PKS di Malaysia?" | Perbincangan |
| 10–25 min | Syarahan: Definisi KPI; empat ciri KPI yang baik (Specific, Measurable, Actionable, Time-bound) | Kuliah + slaid |
| 25–75 min | Syarahan berpandu dengan pengiraan: KPI 1 (Revenue Growth Rate), KPI 2 (Gross Profit Margin), KPI 3 (Employee Productivity), KPI 4 (Customer Acquisition Cost), KPI 5 (AR Days) — untuk setiap KPI: formula → pengiraan berpandu (pensyarah di papan putih) → pelatih kira nilai yang berbeza secara individu | Kuliah + latihan berstruktur |
| 75–85 min | Pelatih kongsi jawapan; semak kesilapan pengiraan biasa | Perbincangan |
| 85–90 min | Rumusan | Q&A |

**Nota:** Gunakan Syarikat Mentari Raya data untuk semua pengiraan. Verifikasi setiap jawapan terhadap nilai yang telah disahkan dalam KP-03.

---

#### Sesi 3.2 — Executive Narrative, Anomaly Detection, and Early Warning Indicators (1 jam)

| Komponen | Perincian |
|---|---|
| **Tempoh / Duration** | 60 minit |
| **Topik** | KP-03 §2–3: Writing executive narratives; three-question framework; anomaly types; early warning indicator thresholds |
| **Objektif Sesi** | Pelatih dapat menulis naratif eksekutif 3-soalan dan mengenal pasti anomali dalam data masa berurutan |

**Pelaksanaan (60 minit):**

| Masa | Aktiviti | Kaedah |
|---|---|---|
| 0–15 min | Syarahan: Rangka kerja tiga soalan naratif eksekutif; prompt AI untuk naratif; cara mengesahkan output AI terhadap data sumber | Kuliah + slaid |
| 15–25 min | Demonstrasi: Masukkan prompt naratif eksekutif ke ChatGPT menggunakan data Syarikat Mentari Raya; semak output terhadap KPI yang telah dikira | Demo langsung |
| 25–40 min | Syarahan: Empat jenis anomali (Spike, Dip, Trend break, Outlier in category); jadual petanda amaran awal untuk PKS | Kuliah + slaid |
| 40–55 min | Aktiviti: Tunjukkan carta Revenue bulanan Syarikat Mentari Raya. Pelatih kenal pasti setiap anomali dan tulis 1-ayat penjelasan berasaskan data | Kerja individu |
| 55–60 min | Rumusan | Q&A |

---

#### Sesi 3.3 — Quarterly Report Structure, KPI Scorecard, and Performance Visualisation (1 jam 30 minit)

| Komponen | Perincian |
|---|---|
| **Tempoh / Duration** | 90 minit |
| **Topik** | KP-03 §4–5: 7-section quarterly report structure; KPI Scorecard with RAG coding; data disclosure requirements; visualising KPIs for non-technical audiences; 5-second rule |
| **Objektif Sesi** | Pelatih dapat menyusun laporan suku tahunan yang lengkap dengan KPI Scorecard RAG dan naratif yang tepat |

**Pelaksanaan (90 minit):**

| Masa | Aktiviti | Kaedah |
|---|---|---|
| 0–20 min | Syarahan: 7 bahagian laporan suku tahunan; kepentingan setiap bahagian untuk pembaca pengurusan | Kuliah + slaid |
| 20–35 min | Demonstrasi: Bina KPI Scorecard Q4 Syarikat Mentari Raya dengan pengekodan RAG — pensyarah lakukan ini di hadapan kelas | Demo langsung |
| 35–50 min | Syarahan: Data dan AI Disclosure — mengapa penting; apa yang mesti dinyatakan; akibat laporan tanpa pengesahan | Kuliah + slaid |
| 50–65 min | Syarahan: Padankan jenis KPI kepada jenis carta; tajuk carta yang kuat vs. lemah; Peraturan 5 Saat | Kuliah + slaid |
| 65–80 min | Aktiviti: Pelatih bina draf ringkasan eksekutif (Bahagian 1 laporan suku tahunan) untuk Q2 Syarikat Mentari Raya menggunakan data yang telah dikira | Kerja individu |
| 80–88 min | 2–3 pelatih berkongsi draf; maklum balas dari pensyarah | Perbincangan |
| 88–90 min | Rumusan keseluruhan KP-01, KP-02, KP-03; pratonton KK-01 dan KK-02 | Rumusan |
