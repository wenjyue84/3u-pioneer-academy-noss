## Work Activity Title

Process Simulated Monthly Payroll and Generate Statutory Contribution Reports

---

## Learning Outcomes

By the end of this activity, trainees will have:

- Correctly identified the statutory contribution obligations for each of 5 simulated employees
- Calculated gross salary, statutory deductions, and net pay for each employee using verified contribution tables
- Generated 5 payslips using an AI-assisted template
- Produced an e-Caruman-format contribution summary for EPF, SOCSO, and EIS
- Completed a payroll checklist and data-handling declaration aligned with PDPA 2010

## Safety Precautions

- Do not enter real employee names, real IC numbers, real salary data, or real bank details into any public AI tool.
- The employee data in this exercise is entirely fictional — treat it as confidential for training purposes.
- Do not share payroll files with classmates who are not part of your assigned group.
- When using AI tools in this exercise, replace all employee names with "Employee A" through "Employee E" before pasting any data.
- Save all files with password protection before submission.

### Step 5: Generate Payslips Using AI-Assisted Template (30 minutes)

**Step 5a — Use AI to create the payslip template:**

Enter the following prompt into ChatGPT or Claude:

```
Create a clean, professional payslip template in a table format for a Malaysian SME.
The template must include the following fields:
Header: Company Name, Month/Year, Payslip Reference Number
Employee Section: Employee Code, Name (placeholder), Position, Department, Employment Date
Earnings Section: Basic Salary, Overtime Pay, Transport Allowance, Gross Salary (auto-summed)
Deductions Section: EPF (Employee), SOCSO (Employee), EIS (Employee), PCB/MTD (placeholder), Total Deductions
Net Salary: Gross Salary minus Total Deductions
Employer Contributions (for company records): Employer EPF, Employer SOCSO, Employer EIS
Footer: Authorised by (blank), Date, Note: "This payslip is computer-generated."
Language: English with BM labels in brackets.
Format: Simple, printable table. No colours.
```

Record the prompt and paste the AI-generated template in **Section 5a of the Answer Sheet**.

**Step 5b — Complete payslips for all 5 employees:**

Using the AI template as the base, fill in the data from Steps 2–4 for each employee. Use "Employee A" through "Employee E" (not the EMP codes) when entering data into the AI tool if you use AI assistance for completion.

Produce 5 completed payslips and paste them (or attach as a file) in **Section 5b of the Answer Sheet**.
