**TAJUK:** Kertas Tugasan — Payroll Compliance: EPF, SOCSO, EIS, and Automated HR Reporting

**TUJUAN:** Menguji pemahaman pelatih terhadap tiga skim caruman berkanun Malaysia (EPF, SOCSO, EIS), prosedur pemprosesan gaji, penjanaan slip gaji berbantu AI, perlindungan data gaji di bawah PDPA 2010, dan penghasilan laporan ringkasan HR bulanan.

<!-- /JPK_ENVELOPE_v1 -->

> **NOTA KADAR CARUMAN:** Kertas tugasan ini tidak meminta pelatih untuk memetik kadar peratusan caruman EPF, SOCSO, atau EIS yang tepat daripada ingatan. Mana-mana soalan yang memerlukan pengiraan akan menyediakan kadar yang telah disahkan, atau akan meminta pelatih menerangkan di mana kadar tersebut boleh disahkan. Ini selaras dengan amalan kerja sebenar — selalu semak kadar terkini dari portal rasmi KWSP dan PERKESO sebelum memproses gaji.

## Tugasan 1: Tiga Skim Caruman Berkanun (Three Statutory Contribution Schemes) (30 markah)

**Soalan 1a** (15 markah):  
Lengkapkan jadual perbandingan berikut untuk ketiga-tiga skim caruman berkanun Malaysia:

| Aspek | EPF (KWSP) | SOCSO (PERKESO) | EIS (SIP) |
|---|---|---|---|
| Nama penuh (Bahasa Malaysia) | | | |
| Badan pentadbir | | | |
| Perundangan utama | | | |
| Tujuan utama skim | | | |
| Siapa yang menyumbang (majikan / pekerja / kedua-dua) | | | |
| Portal penyerahan bulanan | | | |
| Tarikh akhir penyerahan bulanan | | | |
| Di mana semak kadar terkini | | | |

**Soalan 1b** (10 markah):  
Nota KP-03 menjelaskan bahawa "EIS" dalam konteks SOCSO merujuk kepada **Employment Injury Scheme**, manakala "EIS" yang berasingan merujuk kepada **Employment Insurance System (SIP)**.

(i) Jelaskan perbezaan utama antara kedua-dua skim ini dari segi tujuan dan undang-undang yang menguatkuasakannya. (5 markah)

(ii) Siapakah yang TIDAK layak untuk mendapatkan manfaat daripada Employment Insurance System (SIP) jika mereka kehilangan pekerjaan? Berikan **tiga** kategori pekerja yang dikecualikan. (5 markah)

**Soalan 1c** (5 markah):  
Seorang pekerja baru berumur 25 tahun memulakan kerja di syarikat anda. Beliau belum pernah bekerja sebelum ini dan tidak mempunyai nombor keahlian EPF atau SOCSO.

Jelaskan tindakan yang perlu diambil oleh majikan untuk mendaftarkan pekerja ini dengan EPF dan SOCSO, termasuk nama borang yang berkaitan.

## Tugasan 2: Pemprosesan Gaji (Payroll Processing) (30 markah)

**Soalan 2a** (10 markah):  
Susunkan lapan (8) langkah pemprosesan gaji bulanan dalam **urutan yang betul** dan huraikan setiap langkah secara ringkas (1–2 ayat). Langkah-langkah ini boleh dirujuk daripada KP-03.

**Soalan 2b** (12 markah):  
Seorang pekerja menerima gaji asas RM3,200 sebulan dan bekerja 4 jam kerja lebih masa pada hari biasa (weekday) dalam bulan ini. Tiada elaun lain.

Berdasarkan formula dalam KP-03 (kadar jam biasa = Gaji ÷ 26 ÷ 8; kadar kerja lebih masa hari biasa = 1.5×):

(i) Kirakan bayaran kerja lebih masa untuk 4 jam tersebut. Tunjukkan pengiraan anda langkah demi langkah. (6 markah)

(ii) Kirakan gaji kasar (gross salary) pekerja untuk bulan ini. (2 markah)

(iii) Untuk tujuan pengiraan caruman EPF, adakah bayaran kerja lebih masa termasuk dalam "gaji biasa" (ordinary wages)? Jawapan anda hendaklah berdasarkan maklumat dalam KP-03, dengan cadangan untuk mengesahkan perkara ini dengan sumber rasmi. (4 markah)

**Soalan 2c** (8 markah):  
Seorang pengurus baru mencadangkan untuk menggunakan ChatGPT untuk mengira caruman EPF dan SOCSO secara automatik daripada fail gaji syarikat.

Berikan pandangan anda tentang cadangan ini dengan mengambil kira:
- Ketepatan kadar dalam output AI
- Risiko PDPA 2010 jika fail sebenar dimuat naik ke ChatGPT awam
- Pendekatan alternatif yang lebih selamat

## Tugasan 3: Keselamatan Data Gaji dan PDPA 2010 (Payroll Data Security and PDPA 2010) (20 markah)

**Soalan 3a** (10 markah):  
Senaraikan **lima jenis data** yang terdapat dalam rekod gaji syarikat yang dikategorikan sebagai "data peribadi" di bawah PDPA 2010. Untuk setiap jenis, nyatakan mengapa ia sensitif dan satu langkah kawalan keselamatan yang sesuai.

**Soalan 3b** (10 markah):  
Berdasarkan kandungan KP-03, lengkapkan jadual berikut mengenai tempoh pengekalan rekod HR:

| Jenis Rekod | Tempoh Pengekalan Minimum | Perundangan / Alasan |
|---|---|---|
| Rekod gaji | | |
| Rekod caruman EPF / SOCSO | | |
| Kontrak pekerjaan | | |
| Slip gaji pekerja yang masih berkhidmat | | |
| Resume calon yang tidak berjaya (tanpa persetujuan talent pool) | | |

Soalan tambahan: Mengapa rekod gaji memerlukan tempoh pengekalan yang lebih panjang daripada kebanyakan rekod HR yang lain? Nyatakan satu sebab undang-undang. (4 markah daripada 10 yang diperuntukkan di atas)

## Tugasan 4: Laporan Ringkasan HR Bulanan (Monthly HR Summary Report) (20 markah)

**Soalan 4a** (10 markah):  
Anda diminta menyediakan **laporan ringkasan HR bulanan** untuk pembentangan kepada Pengurus Besar. Senaraikan **tujuh bahagian** yang sepatutnya terdapat dalam laporan ini (berdasarkan KP-03) dan terangkan kandungan setiap bahagian secara ringkas.

**Soalan 4b** (10 markah):  
Anda ingin menggunakan ChatGPT untuk membantu menjana laporan ringkasan HR bulanan daripada data yang dieksport daripada Kakitangan.com.

(i) Apakah langkah keselamatan data yang mesti dilakukan **sebelum** memuat naik sebarang data ke ChatGPT? (4 markah)

(ii) Tulis satu **prompt AI** yang sesuai untuk meminta ChatGPT menjana laporan HR ringkasan daripada data yang telah dianonimkan. Prompt anda mesti menyebut sekurang-kurangnya **empat bahagian** laporan yang dikehendaki dan mempunyai satu arahan yang menghalang AI daripada mencipta atau menganggar data yang tidak wujud dalam fail. (6 markah)
