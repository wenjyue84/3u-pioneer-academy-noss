Upon completion of this Information Sheet, trainees will be able to:

1. Identify the main AI-powered scheduling tools available for Malaysian office environments and describe their key features.

## 1. Overview of AI Scheduling Tools

### 1.1 What Is AI-Powered Scheduling?

**AI scheduling (penjadualan AI)** refers to the use of machine learning algorithms to automatically prioritise, protect, and arrange time blocks in a calendar — moving beyond simple event entry to proactively managing an individual's or team's time according to defined preferences and priorities.

Traditional calendar tools (Kalendar Tradisional) require a human to manually find available slots and enter events. AI scheduling tools analyse:

- Existing calendar commitments
- Declared priorities (e.g., "protect 2 hours of deep work each morning")
- Deadline proximity
- Participant availability across multiple calendars
- Historical meeting patterns

The result is a calendar that adapts dynamically as new meetings are booked or deadlines shift.

### 1.2 Core Concepts

| Concept | Definition | Malay Term |
|---|---|---|
| **Time Blocking** | Reserving specific calendar slots for focused work | Pengehadan Masa / Blok Masa |
| **Focus Time** | Protected blocks free from interruptions and meetings | Masa Fokus |
| **Buffer Time** | Short gaps between meetings to allow transition and preparation | Masa Penyangga |
| **Smart Scheduling** | AI-driven optimisation of when to schedule tasks and meetings | Penjadualan Pintar |
| **Availability Link** | A shareable URL that shows a person's available slots for booking | Pautan Ketersediaan |
| **Meeting Queue** | A backlog of meetings awaiting scheduling | Giliran Mesyuarat |

## 2. Key AI Scheduling Platforms

### 2.1 Reclaim.ai

**Reclaim.ai** (reclaim.ai) is an AI calendar management tool designed for Google Workspace users. It integrates directly with Google Calendar and uses machine learning to:

- Automatically schedule recurring tasks in available calendar gaps
- Protect "Habits" (e.g., daily exercise, focused work blocks) from being overridden by meetings
- Reschedule tasks when meetings conflict, finding the next best available slot
- Sync task lists from tools such as Asana, Todoist, and Jira

**Key features relevant to Malaysian office administrators:**

| Feature | How It Works | Use Case |
|---|---|---|
| **Smart 1:1 Scheduling** | Finds optimal time for recurring 1-on-1 meetings within both parties' working hours | Weekly manager check-ins |
| **Task Scheduling** | AI places tasks from a task list into available calendar gaps, respecting priority and deadlines | Deadline-driven admin work |
| **Habit Protection** | Locks recurring personal commitments (prayer time, lunch, focus blocks) | Preserving Zohor / Asar prayer slots for Muslim staff |
| **Buffer Time** | Automatically adds 5–15 minutes between consecutive meetings | Avoiding back-to-back fatigue |
| **Analytics** | Tracks how time is actually spent vs. intended | Weekly time audit reporting |

### 2.2 Motion AI

**Motion** (usemotion.com) is an AI task and calendar tool available for both Google Workspace and Microsoft 365 users. Motion's distinguishing feature is its **Intelligent Calendar** — it does not simply block time; it continuously re-plans the entire day in real time as priorities change.

**How Motion differs from Reclaim:**

| Dimension | Reclaim.ai | Motion |
|---|---|---|
| **Scheduling Logic** | Rule-based habits + task placement | Full real-time replanning engine |
| **Task Management** | Syncs with external tools | Built-in task management module |
| **Meeting Scheduling** | Smart 1:1 + group scheduling | Group meeting booking included |
| **Best For** | Individuals and small teams with established workflows | Individuals and project-heavy teams needing dynamic replanning |
| **Pricing (2026)** | Free tier + paid from ~USD 10/month | Paid only; ~USD 19/month |

### 2.3 Calendly

**Calendly** (calendly.com) is the leading automated appointment booking platform. Rather than manually comparing diaries, a host shares a Calendly link; invitees see only the host's declared available slots and book directly.

**Core workflow:**

1. Admin sets availability windows (e.g., Monday–Friday, 9 AM–5 PM, excluding lunch 1–2 PM)
2. Calendly generates a shareable booking link
3. Invitee clicks the link, selects a time, and Calendly creates calendar events for both parties
4. Automated reminders are sent by Calendly (24 hours before, 1 hour before)

**Malaysian scheduling considerations for Calendly:**

- **Hari Raya Aidilfitri:** Block the dates declared as public holidays by MOHA each year (typically 2 days nationwide + some state extensions). Calendly allows blackout dates in the Availability settings.
- **Friday–Saturday weekend states:** Kelantan, Terengganu, Kedah, and Johor observe a Friday–Saturday weekend (instead of Saturday–Sunday). Staff in these states or dealing with government counterparts in these states must adjust their availability windows accordingly. A Kelantan-based executive would set Saturday as unavailable and add Friday afternoon as a non-working period.
- **Time zones:** For cross-border teams, Calendly automatically converts displayed times to the invitee's local timezone. Malaysia Standard Time is **UTC+8 (Waktu Malaysia Standard / WMS)**, the same as Singapore, Philippines, and China Standard Time. No Daylight Saving Time applies in Malaysia.

### 2.4 Cal.com

**Cal.com** (cal.com) is an open-source alternative to Calendly offering the same appointment booking functionality with the added option of self-hosting — meaning an organisation can deploy Cal.com on its own server, keeping booking data within Malaysia and supporting data residency requirements relevant to government-linked companies.

**When to choose Cal.com over Calendly:**

| Factor | Calendly | Cal.com |
|---|---|---|
| **Data hosting** | US-based cloud (Cal.com cloud also available) | Self-hostable — data stays on your server |
| **Cost** | Free tier; paid from USD 10/month | Free (self-hosted); paid cloud tier available |
| **Customisation** | Limited to plan features | Fully customisable (open source) |
| **Technical skill needed** | None | Server setup required for self-hosted |
| **Best for** | SMEs wanting quick setup | Larger organisations with IT capability and data privacy requirements |

### 2.5 Microsoft Outlook AI Scheduling Assistant

Microsoft 365 users benefit from the **Scheduling Assistant** built into Outlook, which:

- Displays free/busy information for all meeting invitees in a single grid view
- Suggests optimal meeting times based on collective availability (Microsoft Copilot tier)
- Integrates with Microsoft Teams for automatic meeting link generation
- Can search for available rooms and resources in organisations using Microsoft Exchange

For Malaysian SMEs using Microsoft 365 Business Standard or higher, Outlook Scheduling Assistant is available at no additional cost beyond the subscription.

### 2.6 Google Calendar Smart Scheduling

Google Workspace users can use:

- **Find a time:** Side-by-side overlay of all invited attendees' calendars to spot open slots
- **Suggested times:** Google Workspace (Business Standard+) suggests meeting times based on attendee availability
- **Meet links:** Automatic Google Meet link generation for every calendar event

Google Workspace is widely used by Malaysian SMEs due to its lower entry cost and browser-based access requiring no software installation.

## 3. Multi-Timezone Scheduling for Malaysian Businesses

### 3.1 Malaysia Standard Time (MST / WMS)

Malaysia operates on a single time zone: **UTC+8**, known as **Waktu Malaysia Standard (WMS)** or Malaysia Standard Time (MST). There is no Daylight Saving Time in Malaysia.

Countries and territories sharing UTC+8 include:
- Singapore (SGT)
- Philippines (PST)
- China (CST — China Standard Time)
- Hong Kong (HKT)
- Brunei (BNT)
- Western Australia (AWST)

For Malaysian businesses dealing with these partners, no timezone conversion is needed. However, meetings with partners in other timezones require care:

| Partner Location | Timezone | Offset from MST | Example: 10:00 AM MST = |
|---|---|---|---|
| Indonesia (Jakarta) | WIB (UTC+7) | –1 hour | 9:00 AM WIB |
| Thailand / Vietnam | ICT (UTC+7) | –1 hour | 9:00 AM |
| India | IST (UTC+5:30) | –2.5 hours | 7:30 AM IST |
| United Kingdom | GMT/BST (UTC+0 / UTC+1) | –8 / –7 hours | 2:00 AM GMT |
| United States (Eastern) | EST/EDT (UTC-5 / UTC-4) | –13 / –12 hours | 9:00 PM previous day |

### 3.2 Best Practice for Cross-Border Meeting Scheduling

1. **State the timezone explicitly** in all meeting invitations: e.g., "10:00 AM MST (UTC+8)"
2. **Use a world clock converter** such as worldtimebuddy.com or the time zone feature built into Calendly and Google Calendar
3. **Avoid early Monday and late Friday** slots for Southeast Asian partners — many observe varied weekend start times
4. **Record all virtual meetings** for participants in highly different timezones who cannot attend live

## 4. Malaysian Public Holidays and State Variations

### 4.1 National Public Holidays

The following are national public holidays in Malaysia, applicable to all states. Exact dates for moveable holidays (those following the Islamic or Chinese lunar calendar) are proclaimed annually by the Ministry of Home Affairs (MOHA / KDN). The dates below are indicative based on the 2026 calendar and **must be verified annually against the official Gazette** — do not rely on AI-generated dates for official scheduling.

| Holiday | Type | Indicative Date (2026) |
|---|---|---|
| New Year's Day (Tahun Baru) | Fixed | 1 January |
| Thaipusam | Fixed | 11 February |
| Federal Territory Day (Hari Wilayah Persekutuan) | Fixed — KL/Putrajaya/Labuan only | 1 February |
| Chinese New Year (Tahun Baru Cina) | Moveable (lunar) | ~29–30 January 2026 |
| Labour Day (Hari Pekerja) | Fixed | 1 May |
| Wesak Day | Moveable | ~May |
| Yang di-Pertuan Agong's Birthday | Fixed | First Monday, June |
| Hari Raya Aidilfitri | Moveable (Hijri) | ~2 days, proclaimed annually |
| Hari Raya Aidiladha | Moveable (Hijri) | ~2 days, proclaimed annually |
| National Day (Hari Kebangsaan) | Fixed | 31 August |
| Malaysia Day (Hari Malaysia) | Fixed | 16 September |
| Deepavali | Moveable | ~October/November |
| Christmas Day | Fixed | 25 December |
| Awal Muharram (Maal Hijrah) | Moveable (Hijri) | Proclaimed annually |
| Prophet's Birthday (Maulidur Rasul) | Moveable (Hijri) | Proclaimed annually |

> **NOTA PENTING:** Do not input fixed dates for moveable Islamic and Chinese lunar holidays into scheduling systems without first checking the official Gazette proclamation for that year. AI tools may produce incorrect dates for these holidays.

### 4.2 State-Specific Holidays and Weekend Variations

Malaysia's states observe additional public holidays beyond the national list, and four states observe a **Friday–Saturday weekend** instead of the standard Saturday–Sunday:

| State | Weekend | Additional State Holidays (examples) |
|---|---|---|
| **Johor** | Friday–Saturday | Sultan of Johor's Birthday, Hol Almarhum Sultan Iskandar |
| **Kedah** | Friday–Saturday | Sultan of Kedah's Birthday, Hari Raya Kedah |
| **Kelantan** | Friday–Saturday | Sultan of Kelantan's Birthday, Isra Mi'raj (state observation) |
| **Terengganu** | Friday–Saturday | Sultan of Terengganu's Birthday, Isra Mi'raj (state observation) |
| **All other states** | Saturday–Sunday | Respective Sultan/Governor birthday, additional state holidays |

**Practical implication for scheduling tools:**
When an admin in Kuala Lumpur (Saturday–Sunday weekend) schedules a meeting with a government counterpart in Kota Bharu, Kelantan (Friday–Saturday weekend), they must ensure:
- The shared available window excludes Friday for the Kelantan party
- Outlook or Google Calendar **does not** automatically handle this — the admin must manually exclude Fridays for Kelantan participants or use separate availability rules in Calendly

## 5. Integrating Scheduling Tools with Email and CRM Systems

### 5.1 Email Integration

Most AI scheduling tools connect to email systems to:
- Read calendar data from the connected email account
- Send automated meeting confirmation and reminder emails
- Parse incoming email requests for meeting slots (some advanced tools)

| Tool | Microsoft 365 / Outlook | Google Workspace / Gmail |
|---|---|---|
| Reclaim.ai | Google Calendar primary; Outlook via workaround | Native |
| Motion | Both supported | Both supported |
| Calendly | Both supported | Both supported |
| Cal.com | Both supported | Both supported |

### 5.2 CRM Integration

**CRM (Customer Relationship Management / Sistem Pengurusan Hubungan Pelanggan)** integration allows scheduling tools to:
- Automatically log meetings against client records
- Create follow-up tasks after meetings
- Capture meeting notes linked to a contact or deal

Common CRM integrations relevant to Malaysian SMEs:

| CRM Platform | Scheduling Tools that Integrate | Integration Method |
|---|---|---|
| **HubSpot CRM** | Calendly (native), Cal.com (via Zapier) | Direct OAuth connection |
| **Salesforce** | Calendly, Motion | Native or via Zapier |
| **Zoho CRM** | Calendly (via Zapier), Cal.com | Via Zapier or Zoho Flow |
| **Monday.com CRM** | Calendly, Cal.com | Via Zapier / Monday Automations |
| **Notion (as a CRM)** | Calendly (via Zapier) | Via Zapier |

**Zapier** and **Microsoft Power Automate** serve as middleware connectors when a direct integration between a scheduling tool and a CRM is not natively available.

## 6. Setup Best Practices for Malaysian Office Administrators

### 6.1 Scheduling Configuration Checklist

Before going live with an AI scheduling tool, an administrator should complete the following setup steps:

| Step | Action | Notes |
|---|---|---|
| 1 | Connect primary calendar (Google or Outlook) | Required for availability data |
| 2 | Set working hours | Reflect actual working hours; exclude lunch (1–2 PM) |
| 3 | Block public holidays | Enter all national + state holidays for the year |
| 4 | Configure weekend type | Saturday–Sunday (most states) or Friday–Saturday (Johor/Kedah/Kelantan/Terengganu) |
| 5 | Add buffer time between meetings | Minimum 10 minutes recommended |
| 6 | Set meeting types | Define 30-min intro call, 60-min review, 15-min check-in etc. |
| 7 | Add confirmation question(s) | Collect agenda item before the meeting |
| 8 | Test booking link | Book a test appointment and verify reminders are sent |
| 9 | Share the booking link | Add to email signature, website, WhatsApp profile |
| 10 | Review weekly analytics | Check time allocation vs. target each Friday |

### 6.2 Privacy Considerations When Using Scheduling Tools

When sharing calendar availability data with external scheduling platforms, administrators must consider:

- **Data sent to the platform:** Free/busy status and event titles may be read by the tool
- **Sensitive meeting titles:** Avoid titles like "Discuss termination of [Name]" — use neutral codes if the calendar syncs to an external platform
- **Third-party data storage:** Calendly and Reclaim.ai store data on US-based servers. For government-linked companies or those handling sensitive client data, Cal.com self-hosted is a better option
- **Employee monitoring:** Automating an employee's calendar without disclosure may raise concerns under the Employment Act 1955 — inform staff of any monitoring or productivity tracking features
