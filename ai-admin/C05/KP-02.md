## 1. Introduction to AI Project Management

### 1.1 What Is AI Project Management?

**AI project management (pengurusan projek AI)** refers to the application of artificial intelligence capabilities within project management tools to automate planning, scheduling, risk identification, and status reporting — tasks that would traditionally require significant manual effort from a project manager.

In the context of a Malaysian office administrator, AI project management tools are most useful for:
- Setting up and tracking internal office improvement projects (e.g., rolling out a new software tool)
- Managing vendor procurement processes with multiple stakeholders and deadlines
- Coordinating cross-departmental events, audits, or training programmes
- Tracking recurring compliance tasks (e.g., annual SSM filing, quarterly SST returns)

### 1.2 Key Project Management Concepts

| Term | Definition | Malay Term |
|---|---|---|
| **Project** | A time-bound endeavour with a defined outcome and end date | Projek |
| **Milestone** | A significant checkpoint that marks the completion of a key phase | Pencapaian / Mercu Tanda |
| **Task** | An individual unit of work assigned to a person with a due date | Tugasan |
| **Task Dependency** | A task that cannot start until a preceding task is complete | Kebergantungan Tugasan |
| **Resource Allocation** | Assignment of people, time, or budget to specific tasks | Peruntukan Sumber |
| **Critical Path** | The longest sequence of dependent tasks that determines the shortest project duration | Laluan Kritikal |
| **Risk Register** | A document listing potential project risks, their likelihood, and mitigation plans | Daftar Risiko |
| **Project Brief** | A one-page summary of project scope, objectives, timeline, and key stakeholders | Ringkasan Projek |

## 2. Project Management Methodologies: Gantt vs. Kanban

### 2.1 Gantt Charts (Carta Gantt)

A **Gantt chart (Carta Gantt)** is a bar chart that displays project tasks against a timeline. Each bar represents one task, showing:
- When the task starts and ends
- How long it takes
- Which tasks depend on which others
- The overall project timeline

**When to use Gantt:**
- Projects with a clear start and end date
- Sequential tasks where Order A must complete before B starts
- Projects requiring resource scheduling across multiple people
- Projects that must be reported to management or clients with visual progress tracking

**Example suitable for Gantt:** Preparing for an annual JPK audit — tasks are sequential (gather documents → review → compile → submit), have fixed deadlines, and span multiple team members.

**Gantt chart components:**

| Component | Description |
|---|---|
| **Task bars** | Horizontal bars spanning the duration of each task |
| **Milestones** | Diamond symbols marking key completion points |
| **Dependencies** | Arrows connecting tasks that must be done in sequence |
| **Today line** | A vertical line showing the current date |
| **% Complete** | Shading inside the bar showing how much of a task is done |
| **Critical Path** | Tasks highlighted to show which ones control the end date |

### 2.2 Kanban Boards

A **Kanban board (Papan Kanban)** is a visual workflow management tool that organises tasks into columns representing their current status. The most basic Kanban setup uses three columns:

```
| To Do (Perlu Dibuat) | In Progress (Sedang Dibuat) | Done (Selesai) |
```

More advanced boards add columns such as:
- Backlog → Ready → In Review → Testing → Done

**When to use Kanban:**
- Ongoing work streams with no fixed end date (e.g., managing incoming admin requests)
- Teams doing parallel, independent tasks that do not follow a strict sequence
- Visual management of support queues or helpdesk tickets
- Content creation pipelines where tasks move through editing, approval, and publishing stages

**Example suitable for Kanban:** Managing the company's social media content pipeline — articles move from "Draft" to "Review" to "Approved" to "Published" independently of each other.

### 2.3 Choosing Between Gantt and Kanban

| Factor | Choose Gantt | Choose Kanban |
|---|---|---|
| **Project type** | Time-bound, defined scope | Ongoing, continuous work |
| **Task sequence** | Strongly sequential | Mostly parallel |
| **Deadline visibility** | Critical — Gantt shows timeline gaps clearly | Less critical |
| **Team size** | Multiple people with different role responsibilities | Small teams, individual contributors |
| **Reporting need** | Management wants timeline progress | Team wants daily workflow visibility |
| **Examples** | Office renovation, product launch, audit preparation | Customer support queue, content pipeline, maintenance tasks |

## 3. AI Project Management Tools

### 3.1 Microsoft Project Copilot

**Microsoft Project** is an enterprise-grade project management tool available as part of the Microsoft 365 ecosystem. The **Copilot** feature (available in Microsoft Project Plan 3 and above) allows users to:

- **Generate a project plan from a brief:** Type a project description in plain English; Copilot creates a task list with suggested durations, dependencies, and resource assignments
- **Adjust plans via natural language:** "Move all tasks assigned to Amirah out by 3 days" or "Add a review milestone before the final submission"
- **Identify schedule risks:** Copilot flags tasks on the critical path and warns when resource over-allocation would delay the project
- **Generate status reports:** Produce a concise project status summary suitable for a management email

**Limitation:** Microsoft Project is more complex than other tools and has a steeper learning curve. For small Malaysian SMEs, the subscription cost (Microsoft Project Plan 1 from approximately RM 45/user/month as of 2026) may be prohibitive.

### 3.2 Notion AI for Project Management

**Notion** (notion.so) is a flexible workspace tool that combines note-taking, databases, and project management. Its **AI features** include:

- **AI project plan generation:** Create a project plan table from a written brief with suggested tasks, owners, and timelines
- **Kanban views:** Any Notion database can be viewed as a Kanban board
- **Timeline view (Gantt-style):** Databases with date properties can be displayed as a Gantt-like timeline
- **AI summaries:** Summarise a long project document into a bullet-point brief
- **Meeting notes template with action items:** AI extracts action items from meeting notes and adds them to a task database

**Why Notion is popular in Malaysian SMEs:**
- Free plan available (suitable for small teams)
- Browser-based — no installation required
- Works on mobile (Android and iOS) — suitable for Malaysian mobile-first work culture
- Supports Bahasa Malaysia content without any special configuration
- Integrates with Google Calendar, Slack, and n8n

### 3.3 Asana

**Asana** (asana.com) is a dedicated project and task management platform with built-in AI features:

- **AI task prioritisation:** Suggests which tasks to focus on based on deadlines and dependencies
- **Workflow automations:** Set rules such as "When a task is marked complete, assign the next task to [person] and send a notification"
- **Workload view:** Shows how many hours each team member is assigned in the current week — prevents over-allocation
- **Goal tracking:** Connects individual tasks to team or company-level objectives

Asana is particularly well-suited for **cross-departmental projects** where tasks are owned by different people in HR, Finance, and Operations simultaneously.

### 3.4 Monday.com

**Monday.com** is a visual work operating system with strong automation capabilities:

- **AI column:** Generates AI-suggested text, categorisations, or risk flags within a project board column
- **Formula columns:** Calculate custom fields (e.g., days remaining, budget remaining)
- **Dashboard:** Aggregates data from multiple boards into a management overview
- **Automations:** E.g., "When status changes to 'Stuck', notify the project manager and create a follow-up task"

Monday.com's strength is its **visual flexibility** — boards can be configured to match almost any workflow type, from Kanban to timeline to form-based intake.

| Tool | Best For | Free Tier | AI Features |
|---|---|---|---|
| **Microsoft Project Copilot** | Enterprise, complex dependencies | No | Strong (Copilot) |
| **Notion AI** | SME, flexible documentation + tasks | Yes (limited) | Good (AI writing + plan generation) |
| **Asana** | Cross-team task management | Yes (up to 10 users) | Good (AI priorities, automations) |
| **Monday.com** | Visual workflow, automation-heavy | No | Good (AI column, automations) |

## 4. Core Project Tracking Features

### 4.1 Task Assignment and Ownership

Every task in a project must have:

| Field | Purpose | Example |
|---|---|---|
| **Task name** | Clear, action-oriented description | "Submit vendor quotations to Finance" |
| **Assignee** | The person responsible for completing it | Siti Nabilah |
| **Due date** | The date by which the task must be complete | 15 August 2026 |
| **Status** | Current state of the task | In Progress |
| **Priority** | Urgency level | High / Medium / Low |
| **Dependencies** | Tasks that must be done before this one | "Receive quotations from vendors" |

### 4.2 Task Dependencies

**Task dependencies (kebergantungan tugasan)** define the order in which tasks must be completed. There are four types of dependencies:

| Dependency Type | Meaning | Example |
|---|---|---|
| **Finish-to-Start (FS)** | Task B cannot start until Task A finishes | Cannot send report until data is collected |
| **Start-to-Start (SS)** | Task B cannot start until Task A starts | Training and room setup must start together |
| **Finish-to-Finish (FF)** | Task B cannot finish until Task A finishes | Proofreading cannot end before writing ends |
| **Start-to-Finish (SF)** | Task B cannot finish until Task A starts | Rarely used; shift handover scenarios |

In most office projects, **Finish-to-Start (FS)** is the most common dependency type.

### 4.3 Milestone Tracking

**Milestones (pencapaian)** mark the completion of a significant phase and are used as checkpoints for management reporting. A milestone has:
- Zero duration (it marks a moment in time, not a period of work)
- A clear completion criterion ("All vendor quotations received and compared")
- A designated owner responsible for confirming completion

### 4.4 Resource Allocation and Workload Balancing

**Resource allocation (peruntukan sumber)** ensures that no team member is assigned more work than their capacity allows. AI tools like Asana's Workload view and Microsoft Project's Resource Management feature help by:

- Displaying total assigned hours per person per week
- Flagging over-allocated individuals (assigned more hours than their working capacity)
- Suggesting which tasks could be reassigned to balance the workload

### 4.5 Deadline Alerts and Automated Notifications

AI project tools can send automatic reminders:

| Alert Type | Trigger | Recipient |
|---|---|---|
| **Task due soon** | 24–48 hours before due date | Task assignee |
| **Task overdue** | Due date passed without completion | Assignee + Project manager |
| **Status change** | Task moved to "Stuck" or "Blocked" | Project manager |
| **Milestone reached** | Milestone marked complete | All project stakeholders |
| **Weekly summary** | Every Monday morning | All team members |

## 5. Project Risk Management Basics

### 5.1 What Is a Risk Register?

A **risk register (daftar risiko)** is a document that identifies potential events that could negatively affect the project, assesses their likelihood and impact, and defines a mitigation plan and owner.

### 5.2 Risk Register Format

| Risk ID | Risk Description | Likelihood (H/M/L) | Impact (H/M/L) | Risk Score | Mitigation Strategy | Owner |
|---|---|---|---|---|---|---|
| R-01 | Key staff member on extended leave during critical phase | M | H | High | Cross-train at least one backup person on each critical task before project start | HR Manager |
| R-02 | Vendor delivers late, delaying dependent tasks | H | M | High | Build 3-day buffer after vendor deadline in the project plan | Procurement Admin |
| R-03 | Platform subscription not renewed on time | L | H | Medium | Set calendar reminder 30 days before renewal; assign Finance as reminder owner | Finance Admin |

**Risk Score Matrix:**

| Likelihood \ Impact | Low | Medium | High |
|---|---|---|---|
| **High** | Medium | High | Critical |
| **Medium** | Low | Medium | High |
| **Low** | Low | Low | Medium |
