## Bahagian A — Soalan Objektif / Objective Questions (20 markah)

*Pilih jawapan yang paling tepat. Setiap soalan bernilai 2 markah.*

**1.** Which AI scheduling tool is best described as a "full real-time replanning engine" that continuously re-plans the entire day as new tasks and meetings are added?

- A. Reclaim.ai
- B. Calendly
- C. Motion
- D. Cal.com

**2.** An admin in Kuala Lumpur wants to schedule a 10:00 AM MST (UTC+8) meeting with a colleague in Jakarta. What time should the Jakarta colleague be informed the meeting starts?

- A. 9:00 AM WIB
- B. 10:00 AM WIB
- C. 11:00 AM WIB
- D. 8:00 AM WIB

**3.** An organisation wants to use a scheduling tool but requires that all booking data remain hosted on Malaysian servers. Which tool best meets this requirement?

- A. Reclaim.ai
- B. Calendly
- C. Motion
- D. Cal.com (self-hosted)

**4.** Which of the following states in Malaysia observes a **Friday–Saturday weekend** instead of the standard Saturday–Sunday weekend?

- A. Selangor
- B. Perak
- C. Kelantan
- D. Sabah

**5.** The "Habits" feature in Reclaim.ai is designed to:

- A. Generate a summary of the previous week's meetings
- B. Automatically protect recurring personal or work commitments from being overridden by new meetings
- C. Send automated reminder emails to meeting participants
- D. Calculate the hourly cost of each meeting on the calendar

**6.** Which of the following is the correct Malaysia Standard Time (MST) offset from Coordinated Universal Time (UTC)?

- A. UTC+7
- B. UTC+8
- C. UTC+9
- D. UTC+6

**7.** An admin configures Calendly to show a booking link to external clients. The admin wants clients to see available slots automatically adjusted to the client's local timezone. Which Calendly feature handles this?

- A. Buffer Time setting
- B. Event Type colour coding
- C. Automatic timezone detection and conversion for the invitee
- D. CRM integration module

**8.** According to KP-01, which of the following is a recommended data privacy precaution when using AI scheduling tools?

- A. Share calendar data including meeting titles with the scheduling platform without restriction
- B. Avoid neutral meeting titles — all meetings should be descriptively titled
- C. Use sensitive meeting titles such as staff termination discussions freely on external platforms
- D. Use neutral or coded titles for sensitive calendar entries to avoid exposing confidential information through calendar syncing

**9.** A Malaysian company integrates Calendly with HubSpot CRM. What is the primary benefit of this integration?

- A. Calendly automatically generates invoices after each meeting
- B. Meeting bookings are automatically logged against the relevant client record in HubSpot
- C. HubSpot translates meeting invitations into Bahasa Malaysia
- D. Calendly's availability windows are set by HubSpot automatically

**10.** Which of the following is listed as a specific configuration step an admin must perform when setting up an AI scheduling tool for the first time?

- A. Configure tax settings for meeting expenses
- B. Block national and state public holidays for the year and configure the correct weekend type for the executive's state
- C. Upload the company's audited financial statements
- D. Set up payroll deduction rules for meeting overtime
