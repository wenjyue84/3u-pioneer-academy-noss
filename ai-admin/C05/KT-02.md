## Bahagian A — Soalan Objektif / Objective Questions (20 markah)

*Pilih jawapan yang paling tepat. Setiap soalan bernilai 2 markah.*

**1.** Which project management methodology is best suited for managing an **ongoing customer support queue** where tasks are processed continuously without a fixed end date?

- A. Gantt chart
- B. Kanban board
- C. Critical path method
- D. PERT chart

**2.** In Gantt chart terminology, a **milestone** is defined as:

- A. A task that takes more than 5 days to complete
- B. A resource allocation point where two team members share a task
- C. A zero-duration marker that indicates a significant project checkpoint
- D. The first task in any project plan

**3.** Which of the following is the most common type of task dependency in office administration projects?

- A. Start-to-Finish (SF)
- B. Finish-to-Finish (FF)
- C. Start-to-Start (SS)
- D. Finish-to-Start (FS)

**4.** According to KP-02, which AI project management tool is specifically described as a "full work operating system" with strong **automation** capabilities and an AI column feature?

- A. Asana
- B. Microsoft Project
- C. Monday.com
- D. Notion AI

**5.** The **critical path** of a project refers to:

- A. The most expensive sequence of tasks in the project budget
- B. The longest sequence of dependent tasks that determines the minimum project duration
- C. The list of tasks assigned to the most senior team member
- D. The tasks that can be completed in parallel without affecting the timeline

**6.** A Malaysian SME with a team of 8 people wants a project management tool with a **free tier and no software installation required**. Based on KP-02, which tool best meets this requirement?

- A. Microsoft Project Copilot
- B. Notion AI (free plan)
- C. Monday.com
- D. Motion

**7.** Asana's **Workload view** is primarily used to:

- A. Generate a Gantt chart from a written project brief
- B. Display and balance the total assigned hours per team member per week
- C. Auto-schedule tasks into available calendar gaps
- D. Generate meeting minutes after team calls

**8.** A task is described as follows: "Task B cannot start until Task A starts." This is an example of which dependency type?

- A. Finish-to-Start (FS)
- B. Finish-to-Finish (FF)
- C. Start-to-Start (SS)
- D. Start-to-Finish (SF)

**9.** In the risk score matrix in KP-02, a risk with **High Likelihood** and **High Impact** is classified as:

- A. Medium
- B. High
- C. Critical
- D. Low

**10.** Which of the following is a characteristic of **Gantt charts** that makes them better than Kanban boards for managing a time-bound office project with a fixed deadline?

- A. Gantt charts show tasks in a queue format making it easy to reprioritise
- B. Gantt charts display the full project timeline, task durations, and dependencies, making deadline gaps immediately visible
- C. Gantt charts automatically notify team members when tasks are overdue
- D. Gantt charts are only suitable for software development projects
