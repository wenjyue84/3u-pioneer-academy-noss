## Objektif Pembelajaran / Learning Objectives

Upon completion of this Information Sheet, trainees will be able to:
1. Describe the main categories of AI office automation tools and the problems each solves.
2. Compare the key features, pricing, and suitability of Microsoft 365 Copilot, Google Workspace Gemini, n8n, Zapier, and Microsoft Power Automate for a Malaysian SME context.
3. Explain the concept of Robotic Process Automation (RPA) and identify where it differs from generative AI assistance.
4. Apply a structured tool selection framework to recommend the most appropriate automation tool for a given scenario.
5. Evaluate tool compatibility with Malaysian data residency requirements and PDPA 2010 obligations.

## 1. Kategori Alat Automasi AI / Categories of AI Automation Tools

Office AI automation tools fall into three broad categories. Understanding these categories prevents mismatches between the problem and the solution.

| Category | What it does | Examples |
|---|---|---|
| **AI Writing & Productivity Assistants** | Generates, edits, and summarises documents; answers questions; drafts emails | Microsoft 365 Copilot, Google Workspace Gemini, ChatGPT |
| **Workflow Automation Platforms** | Connects different software applications and triggers automated sequences of steps (Zapier calls these "Zaps"; n8n calls them "workflows") | Zapier, Microsoft Power Automate, n8n, Make (Integromat) |
| **Robotic Process Automation (RPA)** | Mimics human mouse clicks and keyboard inputs on existing software — useful when no API integration is available | UiPath, Automation Anywhere, Microsoft Power Automate Desktop |

Most Malaysian SMEs will use a **combination** of Category 1 (for day-to-day knowledge work) and Category 2 (for connecting systems and automating multi-step sequences).

## 2. Microsoft 365 Copilot

### 2.1 What is Microsoft 365 Copilot?

**Microsoft 365 Copilot** is an AI assistant built into the Microsoft 365 suite — it is accessible from within Word, Excel, PowerPoint, Outlook, Teams, and OneNote. It is powered by large language models from OpenAI, combined with the organisation's own data stored in Microsoft 365 (emails, documents, calendar, Teams chats).

### 2.2 Key Features for Office Administration

| Application | Copilot Feature | Admin Use Case |
|---|---|---|
| **Outlook** | Draft email, summarise long email threads, suggest reply | Draft formal correspondence; summarise 50-email thread into 3 bullet points |
| **Word** | "Help me write" — generates document drafts from a brief prompt | Draft reports, SOPs, meeting minutes from bullet points |
| **Excel** | "Analyse data" — generates charts, pivot tables, trend analysis in natural language | "Show me which department had the highest expense in Q3" |
| **PowerPoint** | "Create a presentation about X" — generates slide deck from a Word doc or prompt | Management briefing slides from a text summary |
| **Teams** | Summarises meeting in real time; generates action items list | Post-meeting: instant minutes and assigned tasks |
| **OneNote** | Summarise notes; generate to-do lists from notes | Organise scattered meeting notes into structured action plan |

### 2.3 Pricing (MYR estimate, 2026)

| Plan | Features | Approx. Monthly Cost (MYR) per user |
|---|---|---|
| Microsoft 365 Business Basic | SharePoint, Teams, Exchange (no Copilot AI) | ~RM24–RM30 |
| Microsoft 365 Business Standard | Includes desktop Office apps (Word, Excel, PowerPoint) | ~RM55–RM65 |
| Microsoft 365 Copilot Add-on | Copilot AI features in all apps (requires Business Standard or above) | ~RM150–RM175 (add-on) |

> **Note:** USD pricing published by Microsoft: Copilot for Microsoft 365 is USD 30/user/month as of 2026. Convert to MYR at prevailing exchange rate. Verify current pricing at https://www.microsoft.com/en-my/microsoft-365

### 2.4 Data Residency and PDPA Considerations

Microsoft stores Malaysia customer data in **Australian or Singapore data centres** under the Microsoft 365 regional data residency programme (as of 2026, Malaysia data residency is in the Asia Pacific geo). For organisations handling sensitive Malaysian personal data, this should be confirmed with Microsoft's Data Processing Agreement (DPA) before adoption. Copilot processes data using the organisation's Microsoft Graph — it does **not** use company data to train global models.

## 3. Google Workspace Gemini

### 3.1 What is Google Workspace Gemini?

**Google Workspace Gemini** is Google's AI assistant integrated into Gmail, Google Docs, Sheets, Slides, Meet, and Chat. It is equivalent in function to Microsoft 365 Copilot but operates within the Google ecosystem.

### 3.2 Key Features for Office Administration

| Application | Gemini Feature | Admin Use Case |
|---|---|---|
| **Gmail** | "Help me write"; summarise email thread; smart reply | Draft professional emails; condense 30-email client thread |
| **Google Docs** | "Help me create" — generates document from prompt | Draft meeting agenda, project proposal, standard letter |
| **Google Sheets** | Natural language formulas; "Help me organise data" | "Summarise total sales by region for March" |
| **Google Slides** | Generate slide deck from a Docs outline or prompt | Sales presentation, management report |
| **Google Meet** | AI-generated meeting transcript and summary | Post-meeting notes with action items |

### 3.3 Pricing (MYR estimate, 2026)

| Plan | Features | Approx. Monthly Cost (MYR) per user |
|---|---|---|
| Google Workspace Business Starter | 30 GB storage, core apps, no AI | ~RM28–RM35 |
| Google Workspace Business Standard | 2 TB storage, Meet recording, basic AI | ~RM55–RM70 |
| Google Workspace Business Plus + Gemini | Full Gemini AI features | ~RM85–RM105 |

> **Note:** Pricing varies by reseller. Check Google's authorised Malaysian resellers for local pricing in MYR.

### 3.4 Microsoft 365 vs. Google Workspace — Comparison for Malaysian SMEs

| Criterion | Microsoft 365 Copilot | Google Workspace Gemini |
|---|---|---|
| Dominant Malaysian corporate adoption | Higher — most Malaysian companies use Outlook and Office | Lower — more popular with tech startups and education sector |
| Desktop application | Full desktop apps (Word, Excel) | Web-first; Google Docs, Sheets are cloud-only |
| Offline capability | Yes — desktop apps work offline | Limited — requires internet for most features |
| Integration with Malaysian accounting software | Better — AutoCount and SQL Accounting integrate with Excel | Possible via Google Sheets API but less common |
| AI features | Copilot deeply embedded in all apps | Gemini embedded; more limited in Sheets/Slides than Excel/PowerPoint |
| Cost for SME (indicative) | Higher (Copilot add-on adds RM150+/user/month) | Lower (Gemini features included in higher-tier plans) |
| **Recommendation for Malaysian admin staff** | Preferred if organisation already uses Office apps | Preferred if organisation is Google-first or has tight budget |

## 4. Workflow Automation Platforms

### 4.1 Zapier

**Zapier** is a no-code workflow automation platform that connects over 7,000 applications through pre-built connectors. A Zapier automation is called a **"Zap"** — it consists of a **Trigger** (an event in one app) and one or more **Actions** (steps performed in other apps).

**Example Zap for a Malaysian SME:**
- **Trigger:** New row added to Google Sheets (e.g., new customer enquiry from website form)
- **Action 1:** Send a WhatsApp message via Twilio (or 360dialog for WhatsApp Business API) to the sales team
- **Action 2:** Create a task in Trello or Notion
- **Action 3:** Send a welcome email via Gmail

This three-step automation runs automatically every time a new enquiry arrives — without any human intervention.

**Zapier Pricing (USD, 2026):**

| Plan | Monthly Zap runs | Price |
|---|---|---|
| Free | 100 tasks/month, 5 Zaps | USD 0 |
| Starter | 750 tasks/month, 20 Zaps | USD 19.99/month |
| Professional | 2,000 tasks/month, unlimited Zaps | USD 49/month |
| Team | 50,000 tasks/month, shared Zaps | USD 69/month |

> For a Malaysian SME starting with automation, the **Starter or Professional plan** (approx. RM90–RM230/month at prevailing exchange rate) is typically sufficient for 5–10 automated workflows.

### 4.2 Microsoft Power Automate

**Microsoft Power Automate** (formerly called Microsoft Flow) is Microsoft's workflow automation tool, part of the Microsoft 365 family. It is the recommended choice for organisations already on Microsoft 365.

**Advantages over Zapier for Microsoft 365 users:**
- Included in most Microsoft 365 business plans (no additional subscription cost)
- Deep native integration with SharePoint, Teams, Outlook, Excel — no extra connectors needed
- Power Automate Desktop (PAD) enables RPA — automating actions in non-connected software (e.g., legacy accounting systems, websites)

**Power Automate common admin use cases:**

| Use Case | Trigger | Automated Actions |
|---|---|---|
| Approval workflow for purchase orders | New form submitted in SharePoint | Manager notified via Teams; if approved, record created in Excel; if rejected, submitter notified |
| Meeting minutes distribution | Meeting ended in Microsoft Teams | AI summary generated; emailed to all attendees; task list created in Planner |
| Invoice routing | Email with attachment received in Outlook | PDF attachment saved to SharePoint folder; tagged in tracking spreadsheet; notification sent to accounts |
| Monthly HR report | 1st day of each month (scheduled trigger) | Attendance data pulled from HR system; report generated; emailed to HR manager |

**Power Automate Pricing:**
- Included in Microsoft 365 Business Basic and above for personal cloud flows
- Power Automate Premium: USD 15/user/month (required for premium connectors and RPA features)
- Power Automate Process: USD 150/bot/month (for attended/unattended RPA at scale)

### 4.3 n8n (Open-Source Workflow Automation)

**n8n** (pronounced "n-eight-n") is an open-source, self-hosted workflow automation platform. It is the most technically flexible option and has **no per-workflow or per-task pricing** — costs are limited to server hosting.

**Key characteristics:**

| Feature | Detail |
|---|---|
| Open-source | Source code is publicly available; self-hosted version is free |
| Node-based | Workflows are built as visual "nodes" connected by lines — similar to Zapier but more powerful |
| Self-hosted | Run on your own server (Hetzner, AWS, Azure, DigitalOcean) — data stays within your infrastructure |
| Cloud version | n8n.cloud available for teams that do not want to manage their own server |
| Integrations | 400+ native integrations; custom integrations via HTTP Request node |

**Why n8n is relevant in a Malaysian PDPA context:**
Because n8n can be self-hosted, organisations can ensure all workflow data (including customer data processed during automation) remains on servers within their control. This is a significant advantage for organisations handling sensitive personal data under PDPA 2010, where third-party data processing agreements (DPA) with cloud services may be a compliance concern.

**n8n Pricing (2026):**

| Option | Price | Best For |
|---|---|---|
| Self-hosted Community | Free | Technical teams comfortable with server management |
| n8n.cloud Starter | USD 20/month | Small teams; up to 2,500 workflow executions/month |
| n8n.cloud Pro | USD 50/month | Growing teams; 10,000 executions/month |

## 5. Automasi Proses Robotik / Robotic Process Automation (RPA)

### 5.1 What is RPA?

**Robotic Process Automation (RPA / Automasi Proses Robotik)** is a technology that uses software "bots" to mimic the mouse clicks, keyboard inputs, and screen interactions that a human would perform when operating a computer application. Unlike AI-powered integrations (which use APIs), RPA bots interact with the **user interface** of an application — making them particularly useful for legacy systems that have no API or integration capability.

### 5.2 RPA vs. AI Workflow Automation

| Dimension | RPA | AI Workflow Automation (Zapier / Power Automate) |
|---|---|---|
| How it connects | Screen/UI interaction (mouse & keyboard simulation) | API calls between applications |
| Requires API? | No — works with any software the human can see on screen | Yes — apps must have accessible APIs |
| Handles unstructured data? | Limited — suited for structured, predictable screens | Limited unless combined with AI (OCR, NLP) |
| Setup complexity | Higher — must record screen actions precisely | Lower — drag-and-drop in most platforms |
| Maintenance | Higher — breaks if UI changes (software update) | Lower — API-based; stable unless API changes |
| Best use case | Automating actions in legacy systems (older accounting software, government portals) | Connecting modern cloud apps |

**Practical Malaysian example:** A company uses an older government-portal-based system (e.g., a legacy EPF reporting portal) that has no API. An RPA bot can log into the portal, navigate to the contribution entry page, enter data from a prepared Excel file, and submit — exactly as a human would, but without human presence.

### 5.3 Microsoft Power Automate Desktop (PAD) for RPA

**Power Automate Desktop** is Microsoft's RPA tool, available for free on Windows 10 and 11. It allows users to:
- Record mouse and keyboard actions as a reusable "flow"
- Add conditions and loops to handle variations
- Combine RPA desktop flows with cloud flows (e.g., data comes from SharePoint, gets keyed into desktop application)

## 6. Kriteria Pemilihan Alat / Tool Selection Criteria

### 6.1 The CITED Framework for AI Tool Selection

Use the **CITED** framework when evaluating any AI automation tool:

| Letter | Criterion | Questions to Ask |
|---|---|---|
| **C** | Cost (Kos) | What is the total cost of ownership? Include subscription, setup, training, and ongoing maintenance. |
| **I** | Integration (Integrasi) | Does it connect to the tools we already use (AutoCount, SQL Accounting, Microsoft 365, WhatsApp)? |
| **T** | Training (Latihan) | How long will it take to train staff? Is it intuitive enough for non-technical users? |
| **E** | Environment (Persekitaran Data) | Where is data stored? Is it compliant with PDPA 2010? Does the vendor have a Data Processing Agreement? |
| **D** | Dependability (Kebolehpercayaan) | What is the uptime guarantee? What happens if the tool goes down? Is there local support? |

### 6.2 Tool Selection Decision Guide

Answer these questions in sequence:

```
Q1: Does your organisation already use Microsoft 365?
    YES → Start with Power Automate (included, no extra cost)
    NO  → Go to Q2

Q2: Is budget under RM100/month for automation tools?
    YES → Evaluate n8n self-hosted (free) or Zapier Free/Starter
    NO  → Go to Q3

Q3: Does your team have technical staff who can manage a server?
    YES → n8n self-hosted (most flexible, PDPA-friendly)
    NO  → Zapier Professional (easy setup, 2,000 tasks/month)

Q4: Do you need to automate a legacy system with no API?
    YES → Add Microsoft Power Automate Desktop (free on Windows)
    NO  → API-based tools are sufficient
```

### 6.3 Budget Planning Guide for Malaysian SMEs

This indicative budget table assumes a 10-person SME starting with AI automation:

| Tool | Annual Cost (MYR, indicative) | Users Covered | Notes |
|---|---|---|---|
| Microsoft 365 Business Standard | RM660–RM780/user/year | All 10 staff | Includes Power Automate basic |
| Microsoft 365 Copilot Add-on | RM1,800–RM2,100/user/year | Priority users (3–5) | Only for staff who do significant document/email work |
| Zapier Starter | RM1,080–RM1,440/year | Entire organisation (1 account) | For connecting non-Microsoft tools |
| n8n Self-hosted (Hetzner VPS) | RM240–RM480/year | Unlimited workflows | Server cost only; requires technical setup |

> **Reminder:** These are indicative figures. Obtain formal quotations from authorised Malaysian resellers before presenting to management.
