## Work Activity Title

Produce a Monthly Financial Summary Report Using AI Tools for a Simulated Malaysian SME

---

## Learning Outcomes

By the end of this activity, trainees will have:

- Cleaned and prepared a simulated SME financial dataset for AI analysis
- Used Excel Copilot or ChatGPT (data analysis) to generate key financial metrics
- Produced a structured monthly management financial summary report
- Verified AI-generated figures against the source dataset
- Completed an LHDN e-Invoice compliance checklist for the simulated period
- Identified any SST obligations arising from the simulated data

---

## Safety Precautions

- The dataset provided is simulated — do not treat figures as real financial data
- Do not upload the simulated dataset to a personal free-tier AI account linked to your personal details
- Use the trainer-provided ChatGPT account for AI analysis during this exercise
- Do not screenshot or share the simulated financial dataset outside the training room
- Verify every AI-generated figure against the source data before including it in the report

## Simulated Business Scenario

**Business:** Mutiara Kemas Sdn Bhd (simulated)
**Business type:** Corporate gift and premium printing services
**SST status:** SST-registered — Service Tax registered for professional printing services above threshold
**Accounting period:** March 2026
**Your role:** Finance Admin Executive — preparing the monthly management report for the Director

You have been given a simulated financial dataset for Mutiara Kemas Sdn Bhd for March 2026. The dataset contains:
- Revenue transactions (10 sales invoices to corporate customers)
- Expense transactions (16 expense entries across 6 categories)
- A note on whether each revenue invoice was submitted as an e-Invoice

Your task is to analyse this data using AI tools and produce a management-ready monthly financial summary report.

### Step 2: AI Analysis Using Excel Copilot or ChatGPT (35 minutes)

**Option A — If Microsoft 365 Copilot is available:**

Open the cleaned dataset in Excel. In the Copilot panel, enter the following prompts in sequence:

**Prompt 1:**
```
Calculate total revenue, total COGS (if applicable), and total operating expenses 
for March 2026 from this dataset. Show subtotals by expense category.
```

**Prompt 2:**
```
Calculate gross profit margin (%) and net profit margin (%) for March 2026.
Show the formula used.
```

**Prompt 3:**
```
Which expense category has the highest total for March 2026?
Show all expense categories ranked from highest to lowest.
```

**Prompt 4:**
```
Create a bar chart showing revenue vs. total expenses for March 2026.
```

**Prompt 5:**
```
Write a 5-bullet executive summary of the March 2026 financial performance
based on this data. Use plain language suitable for a business owner.
```

**Option B — If using ChatGPT with data analysis:**

Upload the cleaned CSV to ChatGPT (GPT-4, data analysis enabled) and enter the same prompts as above, adapted as:

```
I am uploading a CSV of financial transactions for Mutiara Kemas Sdn Bhd for March 2026.
Please [insert Prompt 1 / 2 / 3 / 4 / 5 from above].
Only use the figures in the uploaded file — do not estimate or invent any numbers.
```

**After completing all 5 prompts, record in Answer Sheet — Section 2:**
- AI-generated Total Revenue: RM _______________
- AI-generated Total Operating Expenses: RM _______________
- AI-generated Net Profit: RM _______________
- AI-generated Gross Profit Margin: _______________ %
- AI-generated Net Profit Margin: _______________ %
- Top expense category: _______________

Before using any AI-generated figure in the report, verify it manually:

**Sub-step 3a:** Manually calculate Total Revenue by summing the revenue column in the spreadsheet. Compare with AI figure.

|---|---|---|---|
| Total Revenue | | | Y / N |

**Sub-step 3b:** For any figure where AI output does NOT match manual calculation:

- Determine whether the error was in the AI calculation or in your manual calculation
