Upon completion of this Information Sheet, trainees will be able to:

1. Use Microsoft PowerPoint Copilot and Google Slides AI to generate professional presentation decks from a written brief.
2. Create data visualisations (charts and infographics) using AI tools from structured data.

## 1. AI-Assisted Presentation Design

### 1.1 Why AI Presentation Tools Matter

Creating professional presentation slides traditionally requires significant time for design decisions — layout, colour scheme, font hierarchy, chart type selection. AI presentation tools automate these decisions, allowing administrative professionals to focus on content accuracy and message structure.

**Common use cases in Malaysian office administration:**
- Monthly management briefings (taklimat pengurusan)
- Training programme proposals to HRDC / JPK
- Project progress presentations
- New employee orientation decks
- Client proposal presentations

### 1.2 Microsoft PowerPoint Copilot

Microsoft PowerPoint Copilot is embedded within PowerPoint (Microsoft 365 subscription required). It generates complete slide decks from a text brief.

**Accessing PowerPoint Copilot:**
1. Open PowerPoint → New blank presentation
2. Click **Copilot** button in the Home ribbon (blue sparkle icon)
3. Select "Create presentation about..."
4. Type your brief

**Step-by-step example — Creating a Training Programme Proposal:**

**Step 1:** Click Copilot → "Create presentation about..."

**Step 2:** Enter brief:
```
Create a 10-slide presentation for a training proposal titled 
"AI Workflow Automation for Admin Staff" for submission to HRDC. 
Include: executive summary, problem statement, programme overview, 
curriculum outline (7 modules), trainer qualifications, 
programme cost breakdown, ROI for employer, and next steps.
Audience: HRDC evaluators and company HR managers.
Tone: Professional, formal, results-focused.
```

**Step 3:** Copilot generates a complete deck. Review slide by slide.

**Step 4:** Use Copilot's "Edit" feature to:
- Adjust individual slides: "Make this slide more concise — 3 bullet points maximum"
- Change tone: "Rewrite the executive summary to be more persuasive"
- Add content: "Add a slide after Slide 3 about programme certification by JPK"

**Step 5:** Replace placeholder data — Copilot may generate illustrative figures that must be replaced with actual programme costs, real HRDC levy rates (0.5% of monthly payroll for employers with ≥10 employees), and verified statistics.

### 1.3 Evaluating PowerPoint Copilot Output

| Criterion | What to Check |
|---|---|
| **Slide count and structure** | Does it cover all required sections? Are sections logically sequenced? |
| **Content accuracy** | Are all figures, names, and facts verifiable? |
| **Design appropriateness** | Is the template suitable for a government/corporate audience? (Avoid overly casual themes) |
| **Language** | Is the English/BM register appropriate for the audience? |
| **Branding** | Does it need company logo, colours, and contact details added? |

### 1.4 Google Slides AI Features

Google Slides, within Google Workspace, offers AI features through **Duet AI** (now integrated as Google Workspace AI):

- **"Help me visualise":** Generates images for slide backgrounds
- **"Help me refine this slide":** Rewrites and restructures slide content
- **Auto-layout suggestions:** Recommends design adjustments when content is pasted

**Limitation:** Google Slides AI is less capable than PowerPoint Copilot for full deck generation from a brief. It excels at slide-level editing and image generation rather than full document creation. For complete decks, ChatGPT or Claude can produce an outline, which is then built into Slides manually.

## 2. AI-Generated Charts and Data Visualisation

### 2.1 Principles of Effective Data Visualisation

Before choosing an AI tool to generate a chart, the administrative professional must understand which chart type communicates the intended message:

| Chart Type | Best Used For | Malaysian Admin Example |
|---|---|---|
| **Line chart** (Graf garis) | Trends over time | Monthly training enrolment numbers Jan–Dec |
| **Bar chart** (Graf bar) | Comparing categories | Staff headcount by department |
| **Pie chart** (Carta pai) | Proportions of a whole | Budget allocation by expense category |
| **Stacked bar** | Composition over time | Revenue breakdown by product line per quarter |
| **Scatter plot** | Correlation between two variables | Training hours vs. employee performance score |
| **KPI card / Scorecard** | Single key metric at a glance | Current month attendance rate: 94.2% |

> **AMARAN:** Pie charts become unreadable with more than 5–6 segments. If your data has more categories, use a bar chart instead.

### 2.2 Generating Charts with Excel Copilot

Excel Copilot can generate charts and analyse data from a spreadsheet using natural language instructions.

**Step-by-step — Generate a Monthly Expense Chart:**

1. Open Excel with your data table (columns: Month, Category, Amount in MYR)
2. Select the data range
3. Click **Copilot** in the Home ribbon
4. Type: *"Create a stacked bar chart showing monthly expenses by category for January to June 2026. Use professional colours suitable for a management report."*
5. Copilot generates the chart. Review for:
   - Correct data mapping (check that months and categories are correctly assigned)
   - Axis labels in MYR
   - Legend clarity

**Step 6 — Verification (critical):** Manually add up 2–3 data bars against the source table. AI chart generation tools have been observed to occasionally swap data series — always verify before including in a report.

### 2.3 Generating Charts Using ChatGPT (with Data Upload)

ChatGPT (GPT-4o with data analysis mode) can accept CSV or Excel file uploads and generate:
- Statistical summaries
- Charts (downloadable as PNG)
- Trend analysis text

**Example workflow:**

1. Upload your Excel file to ChatGPT: "I am uploading monthly expense data for a Malaysian SME. Analyse this data and produce: (1) a line chart of total monthly expenses Jan–Jun 2026, (2) a summary of the top 3 expense categories, (3) a percentage breakdown."
2. Review the output charts and statistics.
3. **Critical verification step:** Download the generated chart → open the original data file → manually confirm at least 3 data points match the chart.
4. For the report, note: "Chart generated with ChatGPT data analysis. Source: [filename] dated [date]. Verified against source data on [date] by [name]."

### 2.4 Creating an Infographic with AI

Infographics are used in training proposals, annual reports, and presentations to communicate data to non-specialist audiences. AI image tools can generate infographic templates:

| Tool | Capability | Notes |
|---|---|---|
| **Canva AI** | Magic Design from data or brief | Easy drag-and-drop; Malaysian language support |
| **Microsoft Designer** | Generates infographic layouts from prompt | Integrated with Microsoft 365 |
| **ChatGPT + DALL-E** | Image generation from description | Less precise for data-heavy infographics |

**Best practice:** Use Canva AI to generate the visual template, then manually enter the verified data. Do not rely on AI to embed numbers automatically — the risk of chart mis-labelling is high.

## 3. Structuring Executive Reports with AI

### 3.1 Malaysian Business Report Structure

A standard Malaysian management report follows a formal structure. AI tools can generate an outline and draft each section, but the writer must provide the actual data and analysis.

**Standard Management Report Structure:**

| Section | BM Equivalent | Content |
|---|---|---|
| Cover Page | Muka Hadapan | Report title, date, prepared by, submitted to |
| Table of Contents | Kandungan | Page numbers for each section |
| Executive Summary | Ringkasan Eksekutif | 1-page summary of key findings and recommendations |
| Introduction | Pengenalan | Background, purpose, scope of the report |
| Methodology | Metodologi | How data was collected and analysed |
| Findings | Penemuan | The main data, charts, and analysis |
| Recommendations | Cadangan | Actionable recommendations with priorities |
| Conclusion | Kesimpulan | Brief closing summary |
| References | Rujukan | Sources cited |
| Appendices | Lampiran | Supporting data, raw tables, sample documents |

### 3.2 AI-Assisted Report Drafting Workflow

**Phase 1 — Outline generation:**
```
I am writing a management report on training programme effectiveness 
for submission to the Board of Directors of a Malaysian training company. 
The report covers Q1 2026 (January–March) and includes data on:
- Enrolment numbers by programme (3 programmes)
- Completion rates and assessment pass rates
- Trainee satisfaction survey results (5-point scale)
- Revenue and cost per trainee

Generate a 10-section report outline with a brief (1-sentence) 
description of what each section should contain.
```

**Phase 2 — Section drafting (one section at a time):**
```
Using this outline, draft the Executive Summary section of the report. 
Key findings are: [paste actual data points]. 
Length: 250–300 words. 
Tone: Formal, objective, suitable for Board presentation.
```

**Phase 3 — Human review and data insertion:**
- Replace all AI-generated placeholder figures with actual data
- Verify all percentages and calculations
- Ensure no fabricated company names or statistics remain

**Phase 4 — Final formatting:**
- Apply company letterhead/template in Word or Google Docs
- Number pages, add table of contents
- Obtain sign-off from authorised reviewer before distribution

### 3.3 Verifying AI-Generated Statistics

A critical professional responsibility is to **never publish AI-generated statistics without verification.** This is particularly important in reports submitted to government bodies (JPK, HRDC, MDEC) or corporate boards.

**Verification procedure:**

| Step | Action |
|---|---|
| 1 | Identify every statistic, percentage, and financial figure in the AI output |
| 2 | Trace each figure to its source data (the spreadsheet, survey, or database) |
| 3 | Calculate manually or use a formula check (not AI) to confirm |
| 4 | For any figure you cannot verify, remove it or replace with "data not available" |
| 5 | Add a data verification note at the bottom of the report: "All figures verified against source data [date] by [name]" |

## 4. Notion AI for Knowledge Management

### 4.1 What is Notion AI?

**Notion** is a cloud-based workspace tool that combines notes, databases, project management, and wikis. **Notion AI** adds generative AI capabilities directly within the workspace.

**Relevant features for admin professionals:**

| Feature | Use Case |
|---|---|
| **Summarise** | Condense a long meeting transcript into action points |
| **Write with AI** | Draft standard operating procedures (SOP), policy documents |
| **Translate** | Convert content between BM, English, and Chinese |
| **Action items** | Extract numbered action items from meeting notes |
| **Database templates** | Generate structured tables for tracking (e.g., document registry, training calendar) |

### 4.2 Creating Meeting Minutes with Notion AI

Meeting minutes (Minit Mesyuarat) are a required formal record in Malaysian government agencies and regulated companies.

**Standard Malaysian Meeting Minutes Structure:**

```
MINIT MESYUARAT [NAMA MESYUARAT]
Bil. [number] / [Year]

Tarikh    : [Date]
Masa      : [Start time] – [End time]
Tempat    : [Venue]
Pengerusi : [Chairperson Name, Designation]

HADIR:
1. [Name, Designation]
2. [Name, Designation]

TIDAK HADIR:
[Name, Designation] — [Reason if known]

AGENDA

1.0 UCAPAN ALUAN PENGERUSI
    1.1 [Summary of opening remarks]

2.0 PENGESAHAN MINIT MESYUARAT YANG LALU
    2.1 Minit mesyuarat Bil. [X]/[Year] bertarikh [date] telah disahkan tanpa 
        sebarang pindaan / dengan pindaan seperti berikut: [amendments]

3.0 PERKARA BERBANGKIT DARI MINIT YANG LALU
    [Action item follow-ups]

4.0 [AGENDA ITEM TITLE]
    4.1 [Discussion summary]
    4.2 KEPUTUSAN: [Decision made]
    4.3 TINDAKAN: [Person responsible] — [Deadline]

...

[N].0 TARIKH MESYUARAT AKAN DATANG
    [Next meeting date and venue]

[N+1].0 PENUTUP
    Pengerusi mengucapkan terima kasih...

Disediakan oleh:                    Disahkan oleh:

..............................      ..............................
[Nama Setiausaha]                   [Nama Pengerusi]
[Jawatan]                           [Jawatan]
[Tarikh]                            [Tarikh]
```

**Using Notion AI for minutes:**
1. Record meeting notes (or paste transcript) into a Notion page
2. Select all text → AI → "Summarise"
3. Then: "Extract all action items with assigned person and deadline"
4. Format the output into the standard minutes template
5. Circulate for confirmation within 48 hours of the meeting

## 5. Practical Summary — Tool Selection Guide

### 5.1 Matching AI Tools to Report/Presentation Tasks

| Task | Primary Tool | Backup Tool |
|---|---|---|
| Full presentation deck from brief | PowerPoint Copilot | ChatGPT → paste into Slides |
| Chart from Excel data | Excel Copilot | ChatGPT data analysis mode |
| Infographic layout | Canva AI | Microsoft Designer |
| Executive report outline | ChatGPT or Claude | Word Copilot |
| Section drafting | Claude or ChatGPT | Word Copilot |
| Meeting minutes | Notion AI | ChatGPT (paste raw notes) |
| Data verification | Manual / Excel formula | Not AI — always human-verified |

## Soalan Ulangkaji / Review Questions

1. A training officer uses PowerPoint Copilot to generate a proposal deck and submits it to HRDC with an AI-generated statistic that the programme "improves productivity by 47%." The source of this figure is unknown. Explain why this is a professional risk and describe the verification procedure that should have been followed.
2. Describe the correct chart type for each of the following scenarios and explain your choice: (a) showing 12 months of monthly training revenue, (b) showing the proportion of the training budget allocated to five expense categories, (c) comparing assessment pass rates across four programmes.
3. Using the standard Malaysian management report structure, identify which sections should contain AI-generated draft text, which sections require human-entered data only, and why.
4. Explain the function of **Notion AI** in an administrative office. Give two specific tasks where Notion AI would save significant time compared to manual drafting.
5. Why is "data verification" identified as a step that must be performed manually rather than delegated to an AI tool? Refer to at least one specific failure mode of AI data analysis.
