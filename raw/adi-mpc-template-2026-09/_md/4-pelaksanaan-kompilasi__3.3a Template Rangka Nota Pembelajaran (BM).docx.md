3.3a Template Pembangunan Rangka Nota Pembelajaran
Malay Guideline
Merujuk kepada NOSS, bahagian Curriculum of Competency Unit (CoCU), setiap CU mempunyai satu CoCU.
Dalam setiap Competency Unit (CU), ia mempunyai beberapa Work Activity (WA).
Dalam setiap Work Activity (WA), ia mempunyai Related Knowledge.
Topic Penerangan dalam Nota Pembelajaran adalah merujuk kepada Related Knowledge.
Rule of Thumb
1 Nota Pembelajaran menerangkan 1 Work Activity - Related Knowledge.
Sekiranya CU anda mempunyai 5 WA, bermaksud anda perlu hasilkan 5 Nota Pembelajaran.
Tujuan 1 WA = 1 Nota Pembelajaran kerana setiap WA dalam Jadual Spesifikasi Ujian (JSU) mempunyai bilangan pembinaan soalan yang berbeza. Menghasilkan nota mengikut WA berasingan memudahkan proses pembinaan soalan objektif berdasarkan bilangan soalan bagi WA tersebut.
Aliran Kerja Ringkas
Ambil butiran daripada NOSS, sediakan prompt Chatgpt/AI.
Masukkan prompt dalam Chatgpt/AI, hasilkan rangka Nota Pembelajaran.
Hasilkan penerangan lanjut untuk setiap topik/bab dalam rangka tersebut.
Hasilkan Tajuk, Ringkasan (Tujuan), Soalan Perbincangan dan Rujukan.
Tambahan: hasilkan soalan objektif berdasarkan bilangan soalan dan jenis kesukaran/keterampilan dalam JSU (rujuk 3.4a).
Setiap bahagian dihantar sebagai mesej berasingan supaya tidak melebihi had ChatGPT/AI versi percuma. Tunggu jawapan setiap prompt sebelum hantar prompt seterusnya.
Langkah 1 (Free): Bina Rangka Nota Pembelajaran
Ubahsuai bahagian bertanda [ ] mengikut NOSS dan syarikat anda, kemudian salin ke Chatgpt/AI (chat baharu).
| PROMPT CHATGPT/AI / Syarikat saya [COMPANY NAME]. / Syarikat saya [COMPANY BACKGROUND]. / Syarikat akan menawarkan program [NOSS TITLE] kepada pekerja kami yang berkerja sebagai [JAWATAN]. / Sila bantu membina rangka nota pembelajaran untuk topik di bawah sebelum kami membina bahan nota pembelajaran, dengan contoh yang berkenaan. / Module: [TAJUK COMPETENCY UNIT] / Work Activity: [TAJUK WORK ACTIVITY] / Senarai topik nota yang berkenaan dengan work activity: / [salin daripada Work Activity-Related Knowledge] / 3.1 Topic / - Subtopic / - Subtopic / 3.2 Topic / - Subtopic / ...... |

Langkah 2 (Free): Hasilkan Penerangan - Satu Bab Setiap Mesej
Dalam chat yang sama, hantar prompt di bawah untuk bangunkan setiap topik, SATU BAB PADA SATU MASA supaya output tidak terpotong.
| PROMPT CHATGPT/AI - Mesej 1 (Bab 1) / Bina bahan nota pembelajaran yang komprehensif untuk Bab 1, Topik 1.1 dalam rangka nota pembelajaran ialah Bab 1. |
| PROMPT CHATGPT/AI - Mesej 2 (Bab 2) / Sambung Bab 2. |
| PROMPT CHATGPT/AI - Mesej 3 (Bab 3) / Sambung Bab 3. |

Ulang "Sambung Bab [n]" sehingga semua topik/bab dalam rangka selesai dibina.
Langkah 3 (Free): Hasilkan Tajuk, Tujuan, Soalan Perbincangan dan Rujukan
Dalam chat yang sama (selepas semua bab/topic siap), hantar prompt berikut sebagai mesej akhir.
| PROMPT CHATGPT/AI / Secara keseluruhannya: / 1. Sila bina tajuk yang sesuai untuk nota ini. / 2. Sila bina ringkasan yang pendek untuk nota ini, bermula dengan 'Nota Pembelajaran ini bertujuan untuk ......' / 3. Sila bina 3 soalan jawapan pendek untuk tanya di dalam kelas selepas habis pembelajaran. / 4. Sila bina senarai rujukan untuk content dalam nota ini dalam format APA. |

Selepas Selesai
Salin semua hasil prompt Chatgpt/AI ke dalam template 3.3b Template Nota Pembelajaran. Nota Pembelajaran mempunyai 5 bahagian:
| Bahagian Nota | Sumber Hasil Prompt |
| I. Tajuk | Hasil arahan 1 (Tajuk) |
| II. Tujuan | Hasil arahan 2 (Ringkasan) |
| III. Penerangan | Hasil bahagian Penerangan (Bab 1 hingga Bab terakhir) |
| IV. Sesi Persoalan/Kerja Kumpulan | Hasil arahan 3 (3 Soalan Jawapan Pendek) |
| V. Rujukan | Hasil arahan 4 (Senarai Rujukan) |
