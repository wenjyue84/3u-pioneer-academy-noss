3.3a Template for Developing the Learning Note Outline
Guideline
Referring to the NOSS, under the Curriculum of Competency Unit (CoCU) section, each CU has one CoCU.
Each Competency Unit (CU) contains several Work Activities (WA).
Each Work Activity (WA) has Related Knowledge.
The "Penerangan" (Description) topic in the Learning Note refers to the Related Knowledge.
Rule of Thumb
1 Learning Note explains 1 Work Activity - Related Knowledge.
If your CU has 5 WA, you need to produce 5 Learning Notes.
The reason for 1 WA = 1 Learning Note is that each WA in the Jadual Spesifikasi Ujian (JSU / Test Specification Table) has a different number of questions to be built. Producing notes per separate WA makes it easier to build objective questions based on the question count for that WA.
Quick Workflow
Take the details from the NOSS and prepare the ChatGPT/AI prompt.
Enter the prompt into ChatGPT/AI to generate the Learning Note outline.
Generate further explanation for each topic/chapter in that outline.
Generate the Title, Summary (Purpose), Discussion Questions and References.
Additionally: generate objective questions based on the question count and difficulty/construct type in the JSU (refer to 3.4a).
Step 1 (Free): Build the Learning Note Outline
Edit the parts marked [ ] according to your NOSS and company, then copy into ChatGPT/AI (new chat).
| PROMPT CHATGPT/AI / My company is [COMPANY NAME]. / My company is [COMPANY BACKGROUND]. / The company will offer the [NOSS TITLE] programme to our employees working as [JOB TITLE]. / Please help build a learning note outline for the topics below before we build the learning note material, with relevant examples. / Module: [COMPETENCY UNIT TITLE] / Work Activity: [WORK ACTIVITY TITLE] / List of note topics related to the work activity: / [copy from the Work Activity-Related Knowledge] / 3.1 Topic / - Subtopic / - Subtopic / 3.2 Topic / - Subtopic / ...... |

Step 2 (Free): Generate the Explanation - One Chapter per Message
In the same chat, send the prompt below to develop each topic, ONE CHAPTER AT A TIME so the output is not cut off.
| PROMPT CHATGPT/AI - Message 1 (Chapter 1) / Build comprehensive learning note material for Chapter 1. Topic 1.1 in the learning note outline is Chapter 1. |
| PROMPT CHATGPT/AI - Message 2 (Chapter 2) / Continue Chapter 2. |
| PROMPT CHATGPT/AI - Message 3 (Chapter 3) / Continue Chapter 3. |

Repeat "Continue Chapter [n]" until every topic/chapter in the outline has been built.
Step 3 (Free): Generate the Title, Purpose, Discussion Questions and References
In the same chat (after all chapters/topics are done), send the following prompt as the final message.
| PROMPT CHATGPT/AI / Overall: / 1. Please create a suitable title for this note. / 2. Please create a short summary for this note, beginning with 'This Learning Note aims to ......' / 3. Please create 3 short-answer questions to ask in class after the lesson is completed. / 4. Please create a reference list for the content of this note in APA format. |

After Completion
Copy all ChatGPT/AI prompt results into the 3.3b Learning Note Template. A Learning Note has 5 sections:
| Note Section | Source of Prompt Result |
| I. Title | Result of instruction 1 (Title) |
| II. Purpose | Result of instruction 2 (Summary) |
| III. Description | Result of the Description section (Chapter 1 through the final chapter) |
| IV. Discussion/Group Work Session | Result of instruction 3 (3 Short Answer Questions) |
| V. References | Result of instruction 4 (Reference List) |
