PENERANGAN/INFORMATION:  
1. What is IT applications? 
1.1 An application is any program, or group of programs, that is designed for the 
end user . Application software can be divided into two general classes:  
systems software and applications software :  
i) Applications software (also called end-user programs) include such things 
as database programs, word processors , Web browsers  and 
spreadsheets. Figuratively speaking, applications software sits on top of 
systems software  because it is unable to run without the operating 
system and system utilities. 
ii) Systems software  consists of low -level programs that interact with the 
computer at a very basic level. This includes operating systems , 
compilers, and utilities for managing computer resources.

2. What are the 2 basic principle components of a computer? 
2.1 Computer hardware  
The collection of physical parts of a computer system. This includes the computer 
case, monitor, keyboard, and mouse. It also includes all the parts inside the 
computer case, such as the hard disk drive, motherboard, video card, and many 
others. Computer hardware is what you can physically touch. 
2.2 Computer software 
Software is any set of machine -readable instructions that directs a computer's 
processor to perform specif ic operations. A combination of hardware and software 
forms a usable computing system 
 
 
3. What is software applications? 
5.1 Application software is a set of one or more programs designed to carry out 
operations for a specific application. Application software cannot run on itself but 
is dependent on system software to execute. For example: MS Word, MS Excel, 
console game, library management system, billing system, etc. 
 
5.2 There are countless desktop applications out there, and they fall into many 
different categor ies. Some are more full-featured (like Microsoft Word ), while 
others may only do one or two things (like gadgets). Below are just a few types of 
applications you might use: 
 
i) Office software: Office softwares allows you to manage/create/edit 
documentation using word processor,presentation and spreadsheets 
softwares. A few of the well-known office softwares used are Microsoft 
Word, Excel and Powerpoint.There are Paid Office Softwares and Open 
Source Office Softwares (free). There are also offline and online types.

4. IT problems 
4.1 During utilization of IT application, it is normal to encounter problems 
especially technicalities. It is usually handled by t he IT Department for trouble 
shooting. 
 
4.2 However, there are several steps that can be taken to troubleshoot any 
problems that might arise before the expert handles the technical aspect. They are :  
 
i) First, ask yourself: is there really a problem here? 
ii) Acknowledge the problem. 
iii) Ask for help from the correct personnel. 
iv) Use 80 percent of your time to find solutions instead of complaining. 
v) Break the problem down into smaller pieces. 
vi) Find the opportunity and/or lesson within the problem.

5. What is document printing? 
5.1   Digital printing describes the process of transferring a document on a 
personal computer or other digital storage device to a printing substrate by means 
of a device that accepts text and graphic output. As with other digital processes, 
information is reduced to binary code, or "digitized," to facilitate its storage and 
reproduction. Digital printing has steadily replaced lithography in many markets, 
especially at the consumer and business level, as a result of its substantially lower 
production costs. 
 
5.2     The following peripheral s are all capable of digital printing: 
i) Inkjet printer 
ii) Laser printer 
iii) Multifunctional peripheral 
 
5.3    In normal use of documentations, software that utilizes words, excels or 
PowerPoint are the usual applications used and their output are usually printed 
apart from softcopies.
