| Key Term | Description |
|----------|-------------|
| Configuration | Wi‑Fi (SSID, security), email (IMAP/POP or Exchange), VPN (client and profile), certificates for access or email, and security (screen lock, encryption, remote wipe). Follow organisational policy and job order. |
| Troubleshoot | Connectivity (Wi‑Fi, mobile data), sync (email, calendar), battery, and app crashes. Factory reset is a last resort; obtain user consent and backup data first. |
| Commissioning | Hand over to user; document asset tag, config summary, and user acceptance. User is shown basic use and who to contact for support. |
