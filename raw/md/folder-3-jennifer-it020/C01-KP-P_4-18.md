## PENERANGAN

### SISTEM PENGOPERASIAN (OS)

Sistem pengoperasian (OS) adalah sebuah perisian asas yang digunakan untuk menjalankan dan mengendalikan sebuah sistem komputer. Apabila komputer anda mula dihidupkan BIOS akan dibaca dan dijalankan untuk mengesan perkakasan-perkakasan asas seperti cakera keras (hard disk), jumlah memori dan jenis pemproses, setelah itu sistem pengoperasian (OS) pula akan dibaca dan dimasukkan ke dalam memori.

#### 1) FUNGSI SISTEM PENGOPERASIAN

**1.1 Terdapat 4 tugas utama sistem pengoperasian iaitu:**

**a) Menguruskan proses-proses seperti menjalankan beberapa aplikasi pada satu masa.**

- Tugas utama sesebuah OS ialah untuk menguruskan proses-proses yang perlu diproses oleh pemproses.
- Fungsi ini mengendalikan penjadualan dan sistem penggiliran di antara aplikasi-aplikasi yang sedang berjalan pada satu-satu masa supaya dapat diproses oleh pemproses dengan cara bergilir.
- Kerja ini perlu dilakukan dengan efisien supaya kesemua aplikasi-aplikasi itu seolah-olah berjalan serentak.
- Tugas ini dipanggil multitasking atau multi tugas.
- Satu lagi tugas yang berkaitan ialah multireading iaitu apabila sesebuah aplikasi itu mempunyai beberapa proses yang boleh dijalankan serentak, sebagai contohnya sesebuah pemproses perkataan boleh mengedit sebuah dokumen dan mencetak dokumen lain pada masa yang sama.

**b) Menguruskan pembahagian dan penggunaan memori utama di antara aplikasi-aplikasi.**

- Tugasan pembahagian memori pula tidak kurang pentingnya kerana jumlah memori adalah terhad, sebagai contohnya 32MB atau 64MB manakala jumlah aplikasi yang sedang dijalankan memerlukan jumlah memori yang lebih banyak daripada memori yang sedia ada.
- Jika jumlah memori utama tidak mencukupi maka OS akan menggunakan ruangan cakera keras sebagai memori maya (virtual memory) yang bertindak sebagai memori tambahan walaupun ianya lebih lambat berbanding dengan memori utama.

**c) Menguruskan dan membaca fail-fail di dalam cakera keras.**

- Tugasan ini diperlukan kerana sesebuah fail itu disimpan di dalam cakera keras dalam beberapa segmen yang perlu dibaca dan dicantumkan semula menjadi satu dokumen atau aplikasi yang diperlukan oleh pengguna atau sesebuah aplikasi.
- Lokasi di mana fail-fail ini disimpan dalam cakera keras dan diletakkan di dalam sebuah fail yang diberi nama FAT (File Allocation Table) dalam DOS.
- Selain itu, sistem pengoperasian (OS) juga menyediakan kemudahan-kemudahan berkaitan seperti untuk menyalin (copy) dan memadam (delete) fail-fail

**d) Menguruskan peranti-peranti input dan output (I/O) seperti kad video, papan kekunci dan tetikus.**

- Tugasan terakhir yang biasanya dilakukan oleh sebuah OS ialah menguruskan peranti-peranti I/O seperti papan kekunci, kad video dan tetikus supaya interaksi dengan pengguna boleh berlaku baik dari segi penerimaan input (papan kekunci, tetikus dan pemacu CD-ROM) atau pemaparan output (skrin dan kad bunyi).
- Biasanya tugasan ini dibantu oleh perisian pemacu (software driver) yang direka khusus untuk sesebuah peranti itu.

#### 2) JENIS SISTEM PENGOPERASIAN

**a. Perisian berlesen**

**• Microsoft Windows**

- Microsoft Windows adalah sebahagian daripada sistem pengoperasian yang mengawal operasi dan sumber-sumber di dalam sistem komputer.
- Microsoft Windows merupakan suatu sistem operasi yang mengubah cara pengguna menggunakan komputer supaya lebih mudah dan ramah.
- Microsoft Windows juga merupakan satu program yang memberikan persekitaran kerja yang berdasarkan kepada penggunaan ikon dan menu.
- Sistem pengoperasian Microsoft Windows memberikan persekitaran kerja yang mesra pengguna (user-friendly) iaitu berdasarkan kepada konsep antara muka pengguna bergrafik, atau Graphical User Interface (GUI).
- Konsep antara muka pengguna bergrafik bagi Microsoft Windows adalah berlainan dengan konsep antara muka pengguna di dalam sistem pengoperasian MS-DOS yang bersifat Character User Interface (CUI), di mana pengguna perlu menaip arahan-arahan, manakala melalui Microsoft Windows, pengguna hanya perlu memilih ikon atau arahan-arahan di menu bar.
- Terdapat juga aplikasi yang direka khas untuk digunakan di dalam persekitaran Windows seperti Notepad, Paint Bursh, Calender, Calculator, dan lain-lain lagi.

**Kelebihan Microsoft Windows:**

- Pengguna boleh menggunakan lebih dari satu aplikasi dalam satu masa.
- Pengguna boleh membuka lebih dari satu fail pada masa yang sama.
- Pengguna boleh berkongsi data dari aplikasi yang lain, dengan mudah. Iaitu boleh menyalin (copy) dan mengalih (paste) maklumat.

**Keburukan Microsoft Windows:**

- Menyebabkan pergantungan terhadap penggunaan produk Microsoft. Contohnya, apabila kita menggunakan Microsoft Windows, secara terpaksa Internet Explorer diintegrasikan bersama. Ia akan meningkatkan monopoli pasaran Microsoft terhadap pelayar Internet yang lain seperti Netscape, Opera, Mosiac, Java dan lain-lain lagi.
- Memerlukan ruang cakera keras yang boleh dikatakan besar jika dibandingkan dengan sistem pengoperasian (OS) yang lain.
- Sistem keselamatan yang lemah dan senang dicerobohi oleh para pengodam (hackers).

**Senibina chipset / pemproses (32 bit dan 64 bit)**

Jumlah bit-bit di dalam sesebuah unit pemprosesan adalah merujuk kepada jumlah jenis-jenis data yang boleh dikendalikan serta jumlah yang boleh didafarkannya (size of its registry). Sebuah pemproses 64-bit mampu menyimpan 2^64 nilai pengiraan (2^64 computational values), termasuk alamat-alamat memorinya (memory adresses). Ini bermakna ia mampu mengakses ke memori fizikal empat juta kali ganda berbanding pemproses 32 bit! Ringkasnya: pemproses 32-bit hanya mampu mengendalikan jumlah RAM yang terhad, manakala bagi pemproses 64-bit pula ia berkemampuan mengoperasi lebih dari itu. Secara mudahnya, pemproses 64-bit dapat menunjukkan kemampuannya dengan sistem komputer yang mempunyai RAM yang lebih besar.

Laman web dari Microsoft ini menjelaskan secara terperinci had-had maksimum memori yang dapat dicapai mengikut jenis-jenis sistem operasi Windows.

**Beza sistem operasi 32 bit dan 64 bit.**

Melalui pertambahan bilangan pemproses 64-bit dan kapasiti RAM yang semakin besar, pihak Microsoft dan Apple telah mula membangun dan melancarkan sistem operasi versi 64-bit masing-masing supaya sesuai dengan seiring dengan keperluan teknologi semasa. Melihat contoh pada Microsoft Windows, versi asas sistem operasi 32-bitnya memang meletakkan had penggunaan memori bagi perisian-perisian tertentu. Begitu juga bagi versi Ultimate dan Profesionalnya, had memori maksimum yang mampu dicapai hanya pada 4GB.

Aplikasi berprestasi tinggi yang memerlukan akses memori lebih besar kini dapat memanfaatkan sepenuhnya senibina 64-bit ini. Kini, lebih banyak pembangun perisian mengeluarkan versi 64-bit masing-masing.

Senibina 64-bit amat berguna bagi program yang mampu menyimpan sejumlah besar maklumat untuk kegunaan akses segera, sebagaimana yang diperlukan oleh perisian suntingan gambar dan video.

Bagi sesetengah perisian permainan video pula, secara uniknya dibangunkan untuk memanfaatkan pemproses 64-bit dan juga sebarang pertambahan RAM. Melalui pertambahan keupayaan pengiraan yang lebih pantas serta akses ke memori yang lebih besar, mampu memberikan pemain pengalaman kepermainan yang maksimum dengan kemungkinan untuk berlaku lag yang minimum seperti melalui pertambahan bilangan kapal angkasa di dalam permainan komputer tersebut misalnya.

Bagaimanapun, grafik yang lebih cantik dan jelas masih lagi bergantung kepada jenis kad grafik yang digunakan. Lagipun, dengan adanya penggunaan kad grafik, pemprosesan grafik perisian tersebut tidak akan berkongsi memori dengan pemproses utama.

Kebanyakan perisian dibina dengan keserasian terkebelakang (backward compatible), di mana ia membenarkan korang melaksanakan aplikasi 32-bit dan ruang sistem 64-bit tanpa sebarang masalah. Perisian antivirus dan pemacu dikecualikan dalam hal ini, dimana kebanyakan pemacu perkakasan (hardware drivers) memerlukan versi sistem operasi yang betul untuk pemasangannya.

**• MacOS**

- MacOs dibangunkan oleh sebuah syarikat iaitu Apple Corp. yang terletak di California, Amerika Syarikat.
- MacOs tidak boleh beroperasi pada cip-cip Intel, AMD atau Cyrix. MacOs dibangunkan untuk cip mikropemproses yang dibuat oleh Motorolla seperti cip-cip 6800, 68020, 68030 dan yang terbaru mikropemproses G4.
- Ini bermakna, aturcara-aturcara DOS atau Windows tidak boleh dijalankan di MacOs dan sebaliknya.
- MacOS adalah suatu sistem pengoperasian yang berkuasa dan mempunyai pelbagai kelebihan terutamanya dengan gandingan penggunaan perkakasan terbaru yang dikeluarkan oleh Apple seperti iMac, Apple G3, G4, Macintosh G4 Power Cube dan lain-lain.
- Di antara kelebihannya ialah pantas dan laju, grafik yang menarik dan sesuai untuk hardcore designer kerana ianya dapat melakukan tugas-tugas image editing dengan lebih pantas, berkesan, serta menarik.
- Selain itu, ia adalah sistem pengoperasian yang paling mudah di dunia dan untuk memasang (install) MacOs, ia hanya mengambil masa selama 15 minit sahaja, sementara Windows XP pula mengambil masa selama 120 hingga 360 minit.

**b. Perisian sumber terbuka**

**• Linux**

- Linux adalah sistem pengoperasian (OS) seperti UNIX, yang merupakan implementasi independen dari POSIX, meliputi true-multitasking, virtual memory, shared libraries, demand-loading, proper memory management, dan multiuser.
- Linux masih dikembangkan oleh kelompok-kelompok open source, yang banyak dijumpai di Internet, tukar-menukar kod, dan menyelesaikan segala masalah yang ada.
- Sekarang Linux boleh diperoleh dari sumber-sumber yang umum digunakan, misalnya RedHat (Fedora), Debian, Slackware, Caldera, Stampede Linux, TurboLinux, suse dan lain-lain.
- Linux adalah sistem UNIX yang lengkap, boleh digunakan untuk jaringan (networking), pengembangan perisian, dan bahkan untuk sehari-hari.
- Linux sekarang merupakan alternatif sistem pengoperasian (OS) yang jauh lebih murah jika dibandingkan dengan Sistem Pengoperasian (OS) komersial, dengan kemampuan Linux yang setara bahkan lebih

**• UNIX**

- UNIX adalah antara sistem pengoperasian (OS) yang pertama ditulis di dalam bahasa atur cara peringkat tinggi iaitu Bahasa C (C Language).
- Secara amnya ia boleh dilaksanakan di mana-mana komputer yang mempunyai pengkompil C (C Compiler).
- Dengan ciri-ciri seperti berkuasa, portable dan fleksibel, UNIX menjadi sistem pengoperasian (OS) yang utama terutamanya untuk stesen kerja (workstation).
- Ia adalah kurang popular di kalangan komputer peribadi di mana ia dikenali sebagai Xenix (Microsoft) dan A/UX (Macintosh).
- Hanya sejak akhir-akhir ini sahaja komputer peribadi mempunyai keupayaan yang cukup untuk mengeksploitasi sepenuh kelebihan UNIX.
- Antara versi UNIX yang popular untuk komputer peribadi ini ialah seperti LINUX dan MINIX.

#### 1) PERISIAN PEMACU PERKAKASAN KOMPUTER (DEVICE DRIVER)

**1.1 Pemacu (Driver)**

Pemacu (driver) adalah satu program yang digunakan untuk memacu sesuatu perkakasan supaya perkakasan tersebut dapat berinteraksi dengan sistem pengoperasian. Pemacu (driver) perkakasan bertindak sebagai antara muka atau jambatan untuk komputer dan perkakasan berfungsi dengan baik.

Biasanya fail pemacu (driver) akan dibekalkan semasa pembelian perkakasan dan juga boleh diambil dari laman web pengeluar perkakasan berkenaan.

**1.2 Device Manager**

Device Manager merupakan satu fail yang digunakan untuk menyimpan dan menukar maklumat mengenai peranti perkakasan (hardware device) yang dimuatkan (install) di dalam sesebuah komputer. Anda boleh lihat senarai peranti (device) dengan cara *klik kanan pada ikon My Computer, kemudian pilih Properties. Selepas itu, klik pada ikon Hardware dan pilih Device Manager pada paparan tersebut.

*Nota: Untuk pengguna Windows XP.

**1.3 Device (Peranti)**

i) Peranti adalah sebuah komponen atau peralatan yang disambung kepada komputer. Kebanyakan peranti perkakasan mempunyai programnya sendiri yang disebut device driver yang berfungsi sebagai antara muka (interface) atau jambatan untuk komputer dan perkakasan.

ii) Jenis pemacu perkakasan komputer terdiri daripada :-

- Pemandu grafik (graphic driver)
- Pemacu kad bunyi (sound card driver)
- Pemandu chipset (chipset driver)
- Pemandu network (network driver)
- Pemandu monitor (monitor driver)

**1.4 Pengenalan jenis-jenis pemandu peranti komputer**

i) **Pemandu Grafik** - Pemandu grafik adalah program yang mengawal bagaimana komponen grafik anda bekerja dengan seluruh komputer anda: perisian anda, seperti SketchUp, monitor, dan lain-lain.

ii) **Pemacu kad bunyi** - Mendengar audio dari sistem komputer memerlukan kad bunyi. Dengan jenis kanan kad bunyi, anda boleh menutup komputer standard ke dalam sistem hiburan multimedia. Dalam usaha untuk membuat kad bunyi yang benar-benar bekerja, kami juga memerlukan pemacu kad bunyi. Pelbagai pengeluar kad bunyi memberikan anda pemandu yang unggul menjadikan peranti mereka melaksanakan.

iii) **Pemandu Chipset** - Pada satu masa, kebanyakan fungsi chipset yang telah dilakukan oleh pelbagai, cip pengawal yang lebih kecil. Terdapat cip berasingan (sering lebih daripada satu) bagi setiap fungsi: mengawal cache, persembahan capaian ingatan terus (DMA), pengendalian sampukan, memindahkan data melalui I / O bas, dan lain-lain Lebih masa cip ini telah bersepadu untuk membentuk set cip, atau chipset yang melaksanakan pelbagai ciri-ciri kawalan pada motherboard. Ini menggambarkan evolusi mikropemproses itu sendiri: pada satu masa banyak ciri-ciri pada Pentium contohnya ialah pada cip berasingan. Fungsi pemandu chipset ini adalah untuk mengawal pelbagai jenis cip di papan ibu supaya mereka boleh melaksanakan dengan cekap.

iv) **Pemandu Network** - pemandu peranti rangkaian adalah pemacu peranti yang membolehkan peranti rangkaian untuk berkomunikasi antara komputer dan sistem operasi dan juga dengan komputer rangkaian yang lain dan peranti rangkaian.

v) **Pemandu Monitor** - pemandu Monitor khusus untuk monitor. Mereka biasanya fail teks yang memberitahu sistem pengoperasian monitor adalah dan apa yang ia mampu. Mereka tidak perlu untuk monitor berfungsi.

#### 2) PERISIAN APLIKASI

**2.1** Perisian Aplikasi (Application Software) ialah sejenis program yang akan digunakan untuk menghasilkan sesuatu kerja atau tugasan dengan menggunakan komputer.

**2.2** Antara kerja-kerja yang dapat dilakukan adalah seperti:

i) Menghasilkan dokumen.
ii) Memproses teks atau laporan.
iii) Menghasilkan grafik atau lukisan.
iv) Pengiraan akaun.
v) Menghasilkan animasi.

**2.3** Jenis-jenis Perisian Aplikasi (Application Software)

i) Perisian Aplikasi (Application Software) terbahagi kepada 4 kategori iaitu:

**a) Word processing software**

- Digunakan untuk menghasilkan dokumen seperti surat, memorandum dan brochures.

**ii) Spreadsheet software**

- Digunakan untuk pengiraan nombor di dalam keadaan row dan columns.
- Software ini juga sesuai digunakan untuk aktiviti kewangan seperti budget.

**iii) Database software**

- Digunakan untuk menyimpan data organisasi, mengeluarkan data dan melihat data dalam pelbagai format.

**iv) Presentation graphics software**

- Digunakan untuk menghasilkan dokumen di dalam bentuk slide untuk membantu memberi penerangan kepada umum.
- Ia juga digunakan dalam penghasilan buku-buku ilmiah dan sebagainya.

**2.4** Terdapat juga pelbagai jenis software telah dihasilkan. Antaranya termasuklah dalam bentuk rujukan, pembelajaran, hiburan, photo dan video editing, multimedia authoring dan komunikasi.

**2.5** Perisian aplikasi (application software) boleh didapati dengan pelbagai bentuk lesen seperti packages, custom, freeware, public domain, shareware dan application service provider.

**2.6** Packages software

i) Packages software ialah sejenis software yang mana boleh dibekalkan oleh sesuatu syarikat pengeluar di dalam bentuk pakej.

ii) Terdapat pelbagai syarikat yang menyediakan software ini dan ianya mudah didapati samada melalui laman web dan sebagainya.

**2.7** Jenis-Jenis Lesen Perisian Aplikasi

i) **Freeware**

- sejenis software yang boleh digunakan dan ianya tidak memerlukan kos untuk mendapatkanya.
- Software ini boleh dibuat salinan dan boleh juga didapati daripada internet.

ii) **Public-domain**

- sejenis software yang dibekalkan percuma tetapi ianya digunakan untuk umum dan softwarenya tidak boleh dibuat salinan.

iii) **Shareware**

- sejenis software yang boleh disalin dan digunakan dalam tempoh tertentu.
- Setelah tempoh tamat, sekiranya anda ingin meneruskan penggunaan program ia akan dikenakan bayaran dengan kadar tertentu kepada pengeluar software berkenaan.
- Penggunaan software ini biasanya didaftarkan dan akan diberi perkhidmatan seperti updated dan servis.

**2.8** Antara kategori software yang boleh didapati termasuklah graphic program dan games. Beribu-ribu program software ingin boleh didapati daripada internet.

#### 3) KEPERLUAN MINIMUM PEMASANGAN PERISIAN

**3.1** Untuk pemasangan perisian, keperluan minimum biasanya diperlukan untuk PC untuk menyokong pelaksanaan perisian. Oleh itu dalam setiap pemasangan perisian biasanya keperluan asas adalah berdasarkan kepada syarat-syarat berikut:

i) Ruang cakera keras
ii) Memori
iii) Pemproses
iv) Pemacu optik

**Keperluan minimum pemasangan perisian Windows Vista:**

- 1 gigahertz (GHz) or faster 32-bit (x86) or 64-bit (x64) processor
- 1 gigabyte (GB) RAM (32-bit) or 2 GB RAM (64-bit)
- 16 GB available hard disk space (32-bit) or 20 GB (64-bit)
- DirectX 9 graphics device with WDDM 1.0 or higher driver

**3.2** Pemasangan kunci lesen Perisian - Untuk perisian berlesen biasanya ia akan datang bersama-sama dengan kunci lesen pemasangan. Kunci lesen pemasangan, juga dikenali sebagai perisian utama, adalah penting berasaskan perisian khusus untuk program komputer. Ia memperakui bahawa salinan program ini adalah asal. Pengaktifan kadang-kadang dilakukan di luar talian dengan memasukkan kunci, atau dengan perisian seperti Windows 7, pengaktifan talian diperlukan untuk mencegah beberapa orang menggunakan kekunci yang sama. Tidak semua perisian mempunyai kunci produk, kerana beberapa penerbit boleh memilih untuk menggunakan kaedah yang berbeza untuk melindungi hak cipta mereka, atau dalam beberapa kes, seperti perisian sumber terbuka, perlindungan hak cipta tidak digunakan.

#### 4) KEMAS KINI PERISIAN (SOFTWARE UPDATE)

**4.1** Mengemaskini Perisian Aplikasi

i) **Mengenalpasti Perisian Aplikasi**

- Meliputi perisian yang membolehkan seseorang melakukan tugas-tugas atau aplikasi yang dikehendaki
- Prosedur untuk semakan:
  - Tekan menu Start → Settings → Control Panel
  - Pilih ikon Add/Remove Programs
  - Antaramuka Add/Remove Programs Properties akan dipaparkan. Kita boleh menyemak perisian aplikasi pada senarai yang disediakan.
  - Klik Ok untuk keluar dari antaramuka tersebut.

ii) **Memperbaharui Perisian Aplikasi**

- Proses upgrade sesebuah perisian aplikasi kepada versi yang lebih tinggi juga boleh dilakukan dengan pelbagai cara iaitu:
  - Disket
  - CD–ROM
  - Internet

- Bagi proses upgrade melibatkan CD-ROM, terdapat 2 jenis iaitu:
  - CD full version
  - CD Upgrade

**Nota:**

- Sekiranya menggunakan CD full version, pengguna perlu membuang (remove) perisian aplikasi yang lama terlebih dahulu sebelum menginstall perisian aplikasi yang baru
- Bagi CD upgrade pula, pengguna hanya perlu reinstall terus tanpa remove dahulu perisian yang lama

**4.2** Mengemaskini perisian pemacu perkakasan

i) Sebahagian daripada perkakasan komputer memerlukan pemacunya (driver) sendiri untuk bekerja dengan sempurna. Setelah memasang perkakasan tersebut pada sistem komputer, kita perlu memasang pemacu supaya perkakasan tersebut dapat berfungsi.

ii) Oleh kerana peredaran masa dan teknologi semakin canggih, maka pengeluar perkakasan berlumba-lumba mengeluarkan perkakasan terbaru yang lebih canggih dan sempurna mengikut peredaran semasa. Maka dengan ini perkakasan memerlukan pemacu baru jika anda menukar perkakasan baru dan memerlukan pemacu baru juga jika pengeluar perkakasan tersebut menaiktarafkan kemampuan perkakasan tersebut yang dipanggil "version".

iii) Setiap pengeluar memperbaharui "update" setiap perkakasan yang dikeluarkan supaya dapat bersaing di pasaran dan memenuhi keperluan pengguna dari semasa ke semasa.

iv) Oleh yang demikian mengemaskini pemacu perkakasan komputer penting untuk mendapatkan kemudahan yang lebih canggih mengikut edaran semasa.

v) Bagi mengemaskini pemacu perkakasan ini kita boleh dapatkannya dari pembekal perkakasan itu sendiri atau pun yang lebih cepat adalah melalui internet. Kita boleh muat turun pemacu perkakasan tersebut terus ke komputer.

vi) Setelah kita mengemaskini pemacu perkakasan dengan yang baru secara automatiknya pemacu perkakasan yang lama akan hilang.

#### 6) PENGESAHAN KESELAMATAN KOMPUTER

**6.1** Anti-Virus

Virus komputer di dalam istilah komputer ialah sejenis program parasit yang tertanam di dalam salah sebuah perisian atau program. Kebiasaannya ia disimpan atau terletak di kawasan tertentu di dalam disk yang dinamakan "boot sector". Apabila kita menjalankan perisian yang dijangkiti virus tersebut atau cuba mengakses disk yang dijangkiti akan mengaktifkan virus tersebut.

Virus boleh diprogramkan untuk melakukan pelbagai perkara termasuklah menyalin diri mereka ke dalam program lain, memaparkan maklumat tertentu di monitor, memusnahkan fail maklumat atau memadam keseluruhan cakera keras "hard disk". Disamping itu, virus komputer juga boleh diprogramkan untuk bertindak pada masa-masa yang tertentu atau pada hari yang telah ditetapkan. Virus komputer dibahagikan kepada 3 kategori utama iaitu:-

i) Boot sector viruses
ii) Parasitic viruses
iii) Macro viruses.

**6.2** Virus Sektor But - Boot Sector Viruses

Sektor but adalah bahagian cekera keras yang memulakan proses penjanaan maklumat sebaik sahaja kuasa dibekalkan pada komputer. Virus sektor boot akan menggantikan sektor boot cekera yang asli dengan virusnya. Ia kemudian akan memuatkan diri pada ingatan dan merebak ke cekera keras yang lain atau cekera liut, setiap kali penjanaan maklumat dilakukan. Jangkitan pada cekera liut juga boleh berlaku apabila janaan maklumat dilakukan dan terdapat cekera liut pada pemacu.

**6.3** Virus Fail Berjangkit - Parasitic viruses

Virus fail akan berjangkit pada lain-lain fail pelaksana (executable files), lazimnya yang mempunyai sambungan .EXE atau .COM. Oleh yang demikian, virus akan berada dalam keadaan aktif setiap kali aturcara tersebut dilaksanakan. Dengan mengaktifkan aturcara, virus akan berjangkit kepada lain-lain fail atur cara, pada sistem komputer atau pada sistem lain. Rangkaian dan penggunaan cekera liut pada sistem yang berlainan akan membantu proses penyebaran virus tersebut.

**6.4** Virus Makro - Macro viruses

Virus Makro adalah yang paling kerap ditemui disebabkan proses yang mudah untuk menciptanya. Ia ditulis pada hamparan dalam bentuk bentuk bahasa makro atau perisian pemprosesan kata. Virus ini kerap muncul dalam fail-fail perisian kongsi seperti dokumen atau hamparan Microsoft Word dan Microsoft Excel. Virus ini mampu membuat gangguan yang hebat seperti meletakkan perkataan-perkataan ganjil dalam sesuatu dokumen, atau merosakan fail secara rambang.

**6.5** Dasar Firewall

Banyak organisasi mempunyai rangkaian perimeter firewall yang direka untuk mencegah kemasukan trafik berniat jahat masuk ke rangkaian organisasi, tetapi tidak mempunyai firewall berasaskan tuan rumah yang dibolehkan pada setiap komputer di dalam organisasi. Asas Firewall Dasar Design membantu anda untuk melindungi komputer dalam organisasi anda daripada trafik rangkaian yang tidak diingini yang mendapat melalui pertahanan perimeter, atau yang berasal dari dalam rangkaian anda. Dalam reka bentuk ini, anda menggunakan peraturan firewall untuk setiap komputer dalam organisasi anda untuk membolehkan lalu lintas yang diperlukan oleh program yang digunakan. Trafik yang tidak sepadan dengan kaedah-kaedah tersebut digugurkan.

Trafik boleh disekat atau dibenarkan berdasarkan ciri-ciri setiap paket rangkaian: alamat sumber atau destinasi IP, sumber atau pelabuhan destinasi nombor, program pada komputer yang menerima paket yang masuk, dan sebagainya. Reka bentuk ini juga boleh digunakan bersama dengan seorang atau lebih daripada reka bentuk lain yang menambah perlindungan IPsec kepada lalu lintas rangkaian dibenarkan.

**6.6** Internet tetapan keselamatan pelayar (Internet Browser) kita juga boleh melindungi tuan rumah kami dengan mengkonfigurasi tetapan di pelayar Internet.

#### 7) BACKUP DATA MENGGUNAKAN APLIKASI KOMPUTER

**7.1** Perisian back-up (Software back-up)

Banyak aplikasi yang dapat kita gunakan untuk melakukan backup dan restore data baik yang bawaan sistem operasi misalnya windows dan juga aplikasi pihak ketiga (third party). Berikut disampikan beberapa aplikasi yang dapat digunakan. Jenis-jenis perisian back-up

i) **Sistem menetapkan back-up (System setting back-up)**

ii) **OS memulihkan back-up (OS restore back-up)**

**7.2** Nero Start Smart / Nero Essensials

Salah satu software backup yang cukup popular adalah Nero Start Smart. Fungsi utama Nero sebagai software burning CD sangat mempermudah keperluan backup. Aplikasi Nero Burning ROM merupakan software aplikasi untuk melakukan backup software komputer dengan cara melakukan transfer dan copy program / file dari PC ke media penyimpan CD atau DVD menggunakan periferal bantu yaitu CD Writer (CD-RW) atau DVD-RW. Kapasitas simpan dalam CD bervariasi antara lain: 180Mb, 650 Mb dan 750 Mb sedangkan kapasitas simpan sebuah DVD adalah 4,7

**7.3** NTBACKUP.EXE

Microsoft Windows XP memiliki fitur Ntbackup.exe, software bawaan Windows XP. Dalam beberapa kasus, penggunaan Ntbackup.exe sudah mencukupi untuk backup data. Ntbackup.exe dapat diakses dari menu Run, ketik: Ntbackup.exe. Dapat juga diakses dari Start menu → Accesesoris → System Tools → Backup. Seperti software-software windows lain, Ntbackup.exe sangat mudah digunakan, apalagi dengan fasilitas wizard yang disertakan. Proses restore data pun sama mudahnya. Tinggal ikuti saja langkah-langkah yang diberikan dan tunggu proses sampai selesai.

**7.4** Tuneup Utilities

Tune Up Utilities adalah software utilitas yang cukup familiar di kalangan pengguna komputer. Selain fungsi utamanya untuk melakukan perawatan PC, kostumisasi, tweaking, ia juga memiliki fitur untuk melakukan fungsi restore (Recovery) data yang telah di delete dengan memanfaatkan fitur System Restore, namun hasilnya belum tentu sama dengan sebelumnya dan fitur ini juga tergantung dari aktif atau tidaknya System Restore pada komputer pengguna. tapi juga versi sebelumnya.

**7.5** Backup And Restore Center

Ini merupakan fitur bawaan dari Windows itu sendiri dan memiliki fitur yang tidak kalah dengan software backup dan restore data lainnya. Backup and Restore Center ini merupakan fitur backup dan restore data yang langsung dipaket dengan Windows dan Windows Backup and Restore terdapat pada Windows Vista ini merupakan pengembangan dari fitur backup dan restore pada Windows sebelumnya yaitu Windows XP ke bawah. Masing-masing fitur Windows Backup and Restore memiliki fiturnya sendiri yaitu sebagai berikut:

i) **Back Up Files:** memiliki fitur penyimpanan data yang dapat dilakukan pada drive tertentu yang kita inginkan misalnya partisi lain, CD±RW/R, DVD±RW/R/R+DL, Bluray, dan network drive/folder.

ii) **Restore Files:** fitur yang dimiliknya adalah kita dimungkinkan untuk memilih backup file yang akan di-restore misalnya backup paling terakhir, backup paling lama dan backup dari komputer lain. Untuk folder atau tempat tujuannya dapat dikembalikan ketempat asalnya atau tempat lain yang ingin dituju.

iii) **Complete PC Backup:** fungsinya adalah untuk mem-backup seluruh komputer (system file dan data-data lainnya) dimana kita seolah-olah membuat recovery data jika seandainya Windows bermasalah, kita dapat mengembalikan kondisi Windows seperti pada saat kita melakukan Complete PC Backup. Fitur ini juga digunakan untuk merepair windows yang rusak dengan CD/DVD Windows.

**7.6** Manual Backup

Untuk para pengguna komputer yang akan melakukan backup data, selain menggunakan software yang ada, bisa juga melakukan backup data secara manual dengan menggandakan file atau membuat duplikat file dan menyimpannya pada suatu tempat dan ini masih sangat rentan hilang atau terinfeksi virus atau dicuri orang baik secara langsung atau tidak langsung.

Untuk pengguna yang sudah sedikit lebih tahu tentang virus, mereka akan membuat sebuah file yang terkompresi (*.rar, *.zip, *.zipx, *.7z dsb) karena sebagian besar virus tidak dapat memasuki atau menginfeksi file tersebut namun umumnya virus akan menyembunyikan file tersebut dan membuat duplikatnya dengan nama atau ukuran atau extensi yang berbeda dengan aslinya sehingga pengguna menjadi kebingungan untuk mencari file yang di-backupnya. Bagi pengguna yang menggunakan cara ini sebaiknya melakukan proteksi file yang dibackupnya dengan software keamanan misalnya Firewall, AntiVirus, Folder Lock, Pengenkripsi Data, dsb.

**7.7** Backup Data Menggunakan Norton Ghost

Banyak Solusi Alternatif Backup Data, Salah Satunya Yaitu Menggunakan Norton Ghost. Norton Ghost Merupakan Aplikasi Khusus Untuk Membackup Data, Baik Backup Harddisk Secara Keseluruhan Maupun Salah Satu Partisi Harddisk Saja Yang Selanjutnya Disimpan Sebagai Image/File. Berikut Langkah Backup Data Dengan Norton Ghost, Pada Hal Ini Yang Dibackup Adalah Drive C Dimana Windows Terinstal.

i) Burning File ISO Norton Ghost Tersebut Kedalam CD.

ii) Install Ulang Windows Anda Karena Apabila Anda Membuat Backup Data System Operasi Yang Sudah Tidak Stabil/Rusak Akan Percuma Saja. Install Ulang Dahulu Windows Anda, Jangan Lupa Install Juga Driver Hardware Serta Program Aplikasi Yang Sering Anda Gunakan Seperti Aplikasi Office, Pemutar Audio Video, Aplikasi Compress Data, Atau Lainnya. Jangan Instal Semua, Karena Akan Berdampak Pada Kapasitas Harddisk Yang Anda Gunakan Untuk Menyimpan Backup File, Semakin Banyak Yang Anda Install Maka Akan Semakin Besar Pula Kapasitas Harddisk Yang Anda Gunakan Untuk Menyimpan File Backup.

iii) Setelah Semua Persiapan Selesai, Restart Komputer Anda, Dan Booting Melalui CD Yang Baru Anda Burning.

iv) Pilih Nomor 2 – Start Bootcd Untuk Boot Dari Cd Image Norton Ghost

v) Selanjutnya Pilih Nomor 2 – Disk Clone Tools.

vi) Pilih Nomor 2 – Norton Ghost.

vii) Pilih Nomor 8 – Ghost (Normal). Setelah Ini Biarkan Saja Proses Berjalan Secara Otomatis, Jangan Memilih Pilihan Apapun.

viii) Muncul Jendela Norton Ghost, Klik OK

ix) Terdapat beberapa pilihan pada menu Local:
   - Disk, untuk backup dan restore data satu harddisk
   - Partition, untuk backup dan restore data satu partisi
   - Check, untuk melihat kondisi dari suatu harddisk atau partisi

Pada masing-masing pilihan diatas, baik yang Disk ataupun Partition, Anda akan menemui pilihan To Disk atau To Partition, backup/restore seluruh harddisk atau salah satu partisi harddisk; To Image, backup/restore ke image (*.gho, *.iso); From Image, backup/restore dari image ke harddisk atau ke suatu partisi harddisk.

Untuk backup data pilih saja Harddisk – To Image atau Partition – To Image, tergantung Anda mau membackup seluruh data harddisk atau salah satu partisi saja.

x) Muncul jendela Select Source, pilih harddisk Anda selanjutnya pilih partisi yang akan di backup (partisi dalam hal ini adalah drive C).

xi) Simpan file image kedalam partisi selain drive C, beri nama file, setelah itu klik Save.

xii) Muncul jendela peringatan Use Compression, pilih saja NO

xiii) Tunggu hingga proses selesai setelah itu restart komputer Anda.

xiv) Jangan pernah menghapus file ghost yang baru saja Anda buat, karena suatu saat pasti akan dibutuhkan untuk direstore kembali.

**7.8** Backup Data Menggunakan Program Sap

Berikut ini akan dijelaskan tentang prosedur back Up dan Restore dengan menggunakan program SAP. Backup berarti melakukan duplikasi seluruh data base dari semua arsip yang disimpan dalam SAP ke media lainnya (hardisk). Back Up dan Restore hany dapat dilakukan oleh pengguna yang mempunyai otorisasi untuk itu, sehingga tidak semua pengguna SAP dapat melakukan proses ini nantinya. Langkah melakukan back Up dari program SAP adalah sebagai berikut: Dari menu awal program, klik pada menu pop-up Utilitas, kemudian klik Back Up. Program selanjutnya akan menampilkan dialog back Up Data Sistem Bulan: otomatis akan berisikan kode bulan saat melakukan back up

Tahun: otomatis akan berisikan kode tahun saat melakukan back up

Direktori Tujuan: Klik tombol Browse untuk menetukan ke direktori mana file hasil back up akan disimpan Pada contoh diatas file back up akan disimpan pada direktori d:\\efs\\backup. Klik tombol Back Up untuk menyelesaikan proses back Up. File hasil back up akan berupa file ZIP dengan penamaan NAMATAHUN\_BULAN.ZIP (2001\_06.ZIP). jika diurai dengan program WinZip, file ini berisikan seluruh file Data Base yang ada di server.

#### 8) RESTORE

Langkah melakukan Restore dari program SAP adalah sebagai berikut:

Dari menu awal program, klik pada menu pop-up Utilitas, kemudian klik Restore. Program selanjutnya akan menampilkan dialog Restore Data Sistem.

Bulan: isikan kode bulan file Back Up yang akan di Restore
Tahun: isikan kode tahun file Back Up yang akan di Restore
Direktori Asal: Klik tombol Browse untuk menetukan asal direktori file back up yang akan di Restore kembali.

- Klik tombol Open maka direktori asal file back up akan masuk pada kolom Direktori Asal.
- Pada contoh diatas file back up yang akan direstore berasal dari direktori d:\\efs\\backup.
- Klik tombol Restore untuk menyelesaikan proses ini.

#### 9) RESTORE DATA MENGUNAKAN NORTON GHOST

Apabila waktu terjadi sesuatu pada sistem windows komputer Anda, dan Anda merasa perlu untuk install ulang lagi, ikuti step by step berikut untuk restore file backup norton ghost yang sudah Anda buat sebelumnya pada langkah pertama dalam backup data menggunakan norton ghost, caranya:

- Ulangi langkah nomor 3 – 8 pada proses backup data yang sudah dilakukan sebelumnya.
- Masuk ke menu Local, Pilih Partition – From Image
- Keluar jendela baru, arahkan kepada file Ghost yang sudah Anda buat sebelumya.
- Akan diminta untuk memilih partisi mana yang akan menjadi tujuan dari restore file tersebut, dalam hal ini pilih saja partisi drive C (bila system windows Anda berada selain di drive C).
- Tunggu hingga proses selesai, setelah itu restart komputer Anda.
