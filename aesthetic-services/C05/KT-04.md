**Q1 (Matching):**
| Wrap | | Primary Effect |
|------|---|---------------|
| 1. Cold | | A. Mineral absorption, detoxification, skin purification |
| 2. Warm | | B. Vasoconstriction, firms, reduces puffiness |
| 3. Herbal | | C. Vasodilation, perspiration, inch loss |
| 4. Mud | | D. Depends on herbs — detoxifying, relaxing, stimulating |

**Q2:** Describe the body wrap application procedure in SIX steps. **Q3 (T/F):** a) The client should be checked every 30 minutes during a wrap. b) Plastic sheeting seals the product against the skin. c) A space blanket provides insulation over the wrap. **Q4:** State the typical duration for a warm body wrap. **Q5:** List THREE common herbs used in herbal wraps and their effects.

## Answers
**A1:** 1-B, 2-C, 3-D, 4-A. **A2:** Prepare product → apply evenly → wrap in plastic → insulate with blanket → set timer → monitor. **A3:** a) FALSE — Every 5-10 minutes. b) TRUE. c) TRUE. **A4:** 30-45 minutes. **A5:** Rosemary (stimulating), lavender (relaxing), chamomile (soothing), green tea (antioxidant) — any 3.
