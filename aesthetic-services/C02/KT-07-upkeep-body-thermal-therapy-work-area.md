## Questions (Soalan)

### Q1 — Matching
Match the thermal equipment with its correct cleaning method:
| Equipment | | Method |
|-----------|---|--------|
| 1. Hot stones | | A. Drain used material; clean interior; refill fresh |
| 2. Paraffin wax heater | | B. Launder at 60 C minimum |
| 3. Infrared blanket | | C. Wash with antibacterial soap; soak in disinfectant |
| 4. Towels | | D. Wipe housing with disinfectant; use disposable liner |

### Q2 — Short Answer
How should used paraffin wax be disposed of? State the correct waste category.

### Q3 — True or False (with justification)
a) Hot stones can be sanitised by simply rinsing under hot water.
b) FIFO stock rotation ensures older products are used before newer ones.
c) Empty product containers should be placed in clinical waste bags.

### Q4 — Short Answer
List FIVE (5) items that must be replenished after each thermal therapy session.

### Q5 — Multiple Choice
At what minimum temperature should salon towels and linen be laundered?
A. 40 C B. 50 C C. 60 C D. 80 C

---

## Answer Scheme

**A1:** 1-C, 2-A, 3-D, 4-B.

**A2:** Used paraffin wax should be disposed of as general waste (not recyclable due to product contamination). It cannot be reused.

**A3:** a) FALSE — Hot stones must be washed with antibacterial soap AND soaked in disinfectant solution; rinsing alone is insufficient. b) TRUE — FIFO (First-In, First-Out) ensures oldest stock is used first. c) FALSE — Empty product containers (if clean) should go in the recycling bin, not clinical waste.

**A4:** Any 5 of: Disposable liners/sheets, paraffin wax, pre-treatment cleansing products, towels and linen, disposable gloves and PPE, water for client hydration, sanitising products.

**A5:** C. 60 C.
