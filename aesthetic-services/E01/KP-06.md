# KERTAS PENERANGAN — S960-002-3:2020-E01/KP(6/9) | WA 6: Bust Firming Mask | WHITE

## Objectives
1. Describe types of bust firming masks.
2. Explain application and removal procedures.

## 1.0 Types of Bust Firming Masks

| Mask Type | Description | Effects |
|-----------|-------------|---------|
| **Cream mask** (*topeng krim*) | Rich cream formula applied and left to set | Moisturising, firming, nourishing |
| **Rubber/peel-off mask** (*topeng getah*) | Mixed from powder and liquid; sets into rubber layer | Tightening, firming, contouring |

## 2.0 Application
1. Select mask based on client's skin condition and treatment goals.
2. Mix rubber mask (if applicable) per manufacturer instructions.
3. Apply mask evenly to bust area (shoulder to below bust line).
4. Avoid nipple area (cover with gauze or cotton pads).
5. Allow to set per product instructions (typically 15-20 minutes).
6. Monitor client during setting time.

## 3.0 Removal
1. Cream mask: Remove with warm damp sponges.
2. Rubber mask: Peel off from edges; gentle, steady pull.
3. Wipe any residue.
4. Tone the area.
