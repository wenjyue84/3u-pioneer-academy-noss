# KERTAS KERJA / WORK SHEET

**Kod / Code:** S960-002-3:2020-C03/KK(2/6)
**CU:** C03 — Manual Body Massage | **WA 2:** Work Area Setup
**Paper Colour:** BLUE

---

## Objectives
1. Set up massage work area to professional standards.
2. Test equipment functionality.
3. Select and prepare massage medium.

## Equipment
Massage couch, bolsters, trolley, towels (6), massage oil/cream, tissues, hand sanitiser, disinfectant, fresh linen.

## Safety Precautions
Short nails, no jewellery, stable couch, no tripping hazards, correct room temperature.

## Procedure
1. Clean and disinfect massage couch surface.
2. Lay fresh linen on couch; position face hole cover.
3. Test couch adjustments (height, face hole, back angle).
4. Place bolsters at couch.
5. Arrange trolley: massage medium, tissues, hand sanitiser, spare towels.
6. Select massage medium appropriate to client's skin type.
7. Pour medium into a pump bottle or small dish (never dip hands into main container).
8. Set room temperature (24-26 C), dim lighting, ambient music (optional).
9. Check safety: no trailing cords, floor clear, fire exit accessible.
