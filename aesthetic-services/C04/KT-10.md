# KERTAS TUGASAN / ASSIGNMENT SHEET

**Kod / Code:** S960-002-3:2020-C04/KT(10/10) | **Ref:** KP(10/10) | **WA 10:** Equipment Maintenance
**Paper Colour:** PINK

---

**Q1 (Matching):**
| Equipment | | Cleaning Method |
|-----------|---|----------------|
| 1. Glass HF electrodes | | A. Wash, soak in disinfectant, air dry |
| 2. Ventouses/cups | | B. Wipe with alcohol, UV cabinet |
| 3. Machine housings | | C. Inspect for damage, wipe, coil loosely |
| 4. Cables | | D. Wipe with damp cloth (not wet) |

**Q2:** State the correct waste category for: a) Used disposable electrode pads b) Empty gel containers c) Expired conductive gel

**Q3 (T/F):** a) Machine housings may be submerged in water for cleaning. b) FIFO rotation applies to electrotherapy consumables. c) Cables should be tightly wound for compact storage.

**Q4:** List FOUR (4) items that must be replenished after electrotherapy sessions.

**Q5:** Describe the stock inventory process in THREE (3) steps.

---

## Answers
**A1:** 1-B, 2-A, 3-D, 4-C. **A2:** a) Clinical waste (yellow bag). b) Recycling. c) Chemical waste. **A3:** a) FALSE — Never submerge. b) TRUE. c) FALSE — Coil loosely to prevent damage. **A4:** Conductive gels, disposable pads, cotton tips, gloves, cleaning products. **A5:** Physical count, compare with stock cards, flag items at reorder level/submit report.
