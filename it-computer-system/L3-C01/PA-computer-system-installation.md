## Arahan kepada Pelatih / Instructions to Trainee

1. This is a PRACTICAL examination. You will be assessed on your ability to perform a complete computer system set-up.
2. You will be given a job request and a set of hardware and software. You must complete the full set-up cycle.
3. You will be assessed on: **Process** (how you do it), **Output** (the result), **Attitude** (professionalism), **Safety** (ESD and electrical), and **Environmental** compliance.
4. You must wear an anti-static wrist strap throughout the hardware assembly phase.
5. All work must be documented on the provided set-up report form.

---

## Arahan kepada Penilai / Instructions to Assessor

- Provide each trainee with a workstation, hardware components, tools, and a simulated job request.
- Observe each trainee continuously during the assessment.
- Do NOT assist the trainee unless there is a safety hazard.
- Mark each criterion on the assessment rubric as the trainee works.
- Verify the final output (working system, completed report) at the end.

---

## Tugasan / Task Description

**Scenario:** You are a Level 3 Computer System Technician. You receive the following job request:

| Field | Details |
|-------|---------|
| Job request number | PA-2026-001 |
| Requested by | Human Resources Department |
| Priority | Normal |
| Description | Set up a new desktop PC for a new employee |
| CPU | Intel Core i5 (LGA1700) |
| RAM | 16 GB DDR5 (2 x 8 GB) |
| Storage | 512 GB NVMe SSD |
| PSU | 550W, 80 Plus Bronze |
| OS | Windows 11 Pro |
| Applications | Microsoft Office, Google Chrome, antivirus |
| Peripherals | 24" Full HD monitor (HDMI), USB keyboard, USB mouse |
| Network | DHCP |
| Deadline | Today |

**You must complete the following tasks in order:**

1. Analyse the job request and prepare a bill of materials (10 minutes)
2. Gather and organise tools and materials (10 minutes)
3. Assemble the hardware (60 minutes)
4. Install the operating system and drivers (45 minutes)
5. Connect and configure peripherals (15 minutes)
6. Conduct functionality testing (20 minutes)
7. Complete the set-up report and prepare for handover (20 minutes)

**Total time allowed: 3 hours**
