## Objektif / Objective

Connect and configure peripheral devices (monitor, keyboard, mouse, printer) correctly.

---

## Tempoh / Duration

30 minutes

---

## Peralatan dan Bahan / Equipment and Materials

| No. | Item | Quantity |
|-----|------|----------|
| 1 | Installed computer from KK(4/7) | 1 |
| 2 | Monitor (24" or as specified) | 1 |
| 3 | HDMI or DisplayPort cable | 1 |
| 4 | USB keyboard | 1 |
| 5 | USB mouse | 1 |
| 6 | Printer (USB or network, if available) | 1 (shared) |
| 7 | USB peripherals (webcam, headset, as specified) | As needed |

---

## Langkah Keselamatan / Safety Precautions

- Ensure the system is powered on and OS is loaded before connecting peripherals
- Connect peripherals to the correct ports; do not force connectors into wrong port types
- For printer set-up, ensure the printer is powered on before installing the driver

---

## Prosedur / Procedures

| Langkah | Arahan / Instruction |
|---------|---------------------|
| 1 | **Verify monitor connection.** Confirm the monitor is connected to the GPU (or motherboard) output with the correct cable (HDMI or DisplayPort). Power on the monitor. |
| 2 | **Set monitor resolution.** Open Display Settings in the OS. Set the resolution to the monitor's native resolution (e.g. 1920x1080). Set the refresh rate to the maximum supported (e.g. 60 Hz, 144 Hz). |
| 3 | **Connect keyboard and mouse.** Connect the USB keyboard and USB mouse to available USB ports. Verify the OS detects both devices. |
| 4 | **Test input devices.** Open a text editor and type a test sentence to verify the keyboard. Move the mouse across the screen and verify pointer responds. |
| 5 | **Install printer driver (if applicable).** If a printer is specified in the job request, install the printer driver from the manufacturer's website or included media. |
| 6 | **Connect and add printer.** Connect the printer via USB cable, or configure the network printer by entering its IP address. Add the printer in Devices and Printers (or Settings > Printers). |
| 7 | **Send test print.** Print a test page to verify the printer is working. Confirm the output is correct (text clear, no misalignment). |
| 8 | **Configure peripheral settings.** Set keyboard layout (language), mouse sensitivity (pointer speed), and printer defaults (paper size, default quality) as specified in the job request or organisational policy. |
| 9 | **Verify in Device Manager.** Open Device Manager and confirm all connected peripherals appear without errors. |

---

## Hasil Jangkaan / Expected Outcome

- Monitor connected with correct resolution and refresh rate
- Keyboard and mouse functional and recognised by OS
- Printer (if applicable) installed, connected, and test page printed
- All peripherals visible in Device Manager with no errors
- Peripheral settings configured according to job request
