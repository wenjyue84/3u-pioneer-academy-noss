## BAHAGIAN A: SOALAN PELBAGAI PILIHAN / SECTION A: MULTIPLE CHOICE (30 marks)

Answer all 15 questions. Each question carries 2 marks. Circle the correct answer.

**1.** The document that formally initiates a computer system set-up task is called a:

- (a) Purchase order
- (b) Job request / work order
- (c) Delivery note
- (d) Invoice

**2.** Which of the following is a correct ESD prevention measure?

- (a) Working in a dry room without any grounding
- (b) Wearing an anti-static wrist strap connected to a grounded point
- (c) Handling the motherboard by its circuit traces
- (d) Using a standard vacuum cleaner on the motherboard

**3.** The CPU socket type must match between the:

- (a) CPU and RAM
- (b) CPU and motherboard
- (c) PSU and monitor
- (d) Storage drive and keyboard

**4.** Thermal paste is applied between the CPU and heatsink to:

- (a) Permanently glue them together
- (b) Fill microscopic gaps for efficient heat transfer
- (c) Make the CPU run at a higher speed
- (d) Prevent the CPU from being removed

**5.** For dual-channel RAM operation, modules should be installed in:

- (a) Any random slots
- (b) Matched paired slots as per the motherboard manual
- (c) A single slot only
- (d) The slot closest to the CPU

**6.** NVMe Gen5 storage drives connect via:

- (a) SATA data cable
- (b) M.2 PCIe Gen5 slot on the motherboard
- (c) USB 3.0 port
- (d) IDE ribbon cable

**7.** The recommended order for driver installation after OS setup is:

- (a) Audio > GPU > Chipset
- (b) Chipset > GPU > Network > Audio
- (c) GPU > Audio > Chipset
- (d) Any order is acceptable

**8.** TPM 2.0 must be enabled in BIOS/UEFI as a requirement for:

- (a) Linux Ubuntu
- (b) Windows 7
- (c) Windows 11
- (d) macOS

**9.** A yellow triangle in Device Manager indicates:

- (a) A device is working perfectly
- (b) A device has a driver problem or error
- (c) A device is a USB device
- (d) A device is a network printer

**10.** The `ping` command is used to:

- (a) Install drivers
- (b) Test network connectivity to a target address
- (c) Format a hard drive
- (d) Open Device Manager

**11.** What is the typical knowledge-to-performance hour ratio in NOSS training?

- (a) 50% / 50%
- (b) 30% / 70%
- (c) 70% / 30%
- (d) 20% / 80%

**12.** A modular PSU is preferred because:

- (a) It costs less than non-modular
- (b) Unused cables can be left off for better airflow
- (c) It does not require a power cable
- (d) It provides more wattage

**13.** Before installing the motherboard in the case, the technician must first install:

- (a) The hard drive
- (b) The I/O shield and standoffs
- (c) The RAM modules
- (d) The operating system

**14.** The set-up report is important because it:

- (a) Replaces the job request
- (b) Records all hardware details, software versions, and test results for future reference
- (c) Is used to order new parts
- (d) Is only needed for warranty claims

**15.** If the OS installer does not boot from USB, the FIRST troubleshooting step is:

- (a) Replace the motherboard
- (b) Check the boot order in BIOS/UEFI
- (c) Reformat the storage drive
- (d) Install more RAM

## BAHAGIAN C: SOALAN ESEI / SECTION C: ESSAY (40 marks)

Answer all 2 questions.

**21.** You receive a job request to set up a new workstation for a graphic designer. The specifications are:
- CPU: AMD Ryzen 9 7950X (AM5 socket)
- RAM: 64 GB DDR5-5600 (4 x 16 GB)
- Storage: 2 TB NVMe Gen5 SSD + 4 TB HDD
- GPU: NVIDIA RTX 4070 Ti (requires 2 x PCIe 8-pin power connectors)
- PSU: 850W 80 Plus Gold
- OS: Windows 11 Pro
- Software: Adobe Creative Cloud, AutoCAD
- Monitor: 32" 4K (3840x2160) via DisplayPort
- Deadline: 2 days

(a) Describe how you would analyse this job request, including what compatibility checks you would perform. (8 marks)

(b) List the hardware assembly sequence you would follow, with justification for the order. (6 marks)

(c) Describe the software installation process, including BIOS configuration, OS installation, and driver order. (6 marks)

**22.** After completing a computer set-up, you conduct the functionality test and discover:
- Device Manager shows two unknown devices with yellow triangles
- The system freezes after 3 minutes of a stress test
- The set-up report reveals one part was substituted from the original job request

(a) For each of the two issues (unknown devices, system freeze), explain the likely cause and the troubleshooting steps you would take. (10 marks)

(b) Explain how the part substitution should be documented in the set-up report, and what approval process should be followed. (5 marks)

(c) Describe the complete set-up report you would prepare for user handover, listing all sections and their contents. (5 marks)
