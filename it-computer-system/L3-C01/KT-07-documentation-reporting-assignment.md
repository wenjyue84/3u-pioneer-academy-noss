## Soalan / Questions

### Bahagian A: Soalan Jawapan Pendek / Short Answer (15 marks)

**A1.** State FOUR (4) purposes of the computer system set-up report. (4 marks)

**A2.** List SIX (6) hardware details that must be recorded in the hardware configuration section of the set-up report. (6 marks)

**A3.** What network configuration details should be documented in the set-up report? List FIVE (5) items. (5 marks)

### Bahagian B: Betul atau Salah / True or False (5 marks)

**B1.** The set-up report only needs to be signed by the technician; user sign-off is optional.

**B2.** Any deviations from the original job request should be documented and explained in the report.

**B3.** Serial numbers are not important and do not need to be recorded in the set-up report.

**B4.** A Device Manager screenshot should be included as a supporting attachment to the report.

**B5.** The set-up report supports future troubleshooting by providing baseline configuration data.

### Bahagian C: Tugasan Praktikal / Practical Writing Task (20 marks)

**C1.** Using the template structure described in KP(7/7), complete a mock set-up report for the following scenario:

**Scenario:** You have completed the set-up of a desktop computer for the Marketing Department.
- Job request number: JR-2026-0042
- User: Ahmad bin Ismail, Marketing Executive
- CPU: Intel Core i5-14400 (LGA1700)
- RAM: 16 GB DDR5-4800 (2 x 8 GB, dual-channel)
- Motherboard: ASUS PRIME B760M-A
- Storage: 512 GB Samsung 980 Pro NVMe SSD
- PSU: Corsair RM650x (650W, 80 Plus Gold)
- Monitor: Dell P2422H (24", 1920x1080)
- OS: Windows 11 Pro, Build 26100
- Applications: Microsoft Office 2024, Google Chrome, Kaspersky Antivirus
- Network: DHCP (IP: 192.168.1.45), joined to domain COMPANY.LOCAL
- All tests passed; no issues found

Complete the report including:
(a) Header information (4 marks)
(b) Hardware configuration table (6 marks)
(c) Software configuration table (4 marks)
(d) Network configuration table (3 marks)
(e) Test results summary (3 marks)
