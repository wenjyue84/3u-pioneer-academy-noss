## Soalan / Questions

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (10 marks)

**A1.** Before installing the OS from USB, which BIOS/UEFI setting must be configured?

- (a) Fan speed
- (b) Boot order (set USB as first boot device)
- (c) RAM voltage
- (d) Screen brightness

**A2.** What is the recommended driver installation order after OS installation?

- (a) Audio, then chipset, then GPU
- (b) GPU, then audio, then chipset
- (c) Chipset, then GPU, then network, then audio
- (d) Any order is acceptable

**A3.** TPM 2.0 must be enabled in BIOS/UEFI for which operating system requirement?

- (a) Windows XP
- (b) Windows 7
- (c) Windows 11
- (d) Linux Ubuntu

**A4.** The storage mode should be set to __________ in BIOS for optimal SSD/NVMe performance.

- (a) IDE
- (b) AHCI
- (c) Legacy
- (d) USB

**A5.** If the OS installer does not boot from USB, the FIRST troubleshooting step is:

- (a) Replace the motherboard
- (b) Check the boot order in BIOS/UEFI
- (c) Reformat the hard drive
- (d) Install more RAM

### Bahagian B: Soalan Jawapan Pendek / Short Answer (15 marks)

**B1.** List FOUR (4) types of software that are installed during computer system set-up, and give ONE (1) example of each. (8 marks)

**B2.** Explain why drivers should be installed in a specific order and what can happen if the chipset driver is installed last instead of first. (3 marks)

**B3.** Describe TWO (2) common software installation faults and the action to resolve each. (4 marks)

### Bahagian C: Soalan Esei / Essay (15 marks)

**C1.** A job request specifies: Windows 11 Pro, Microsoft Office 2024, antivirus software, and network printer driver. The system has a new NVMe SSD with no existing data.

Describe the complete software installation process from BIOS configuration through to post-installation verification. Include the BIOS settings you would check, the OS installation steps, driver installation order, and how you would verify the installation is complete and correct. (15 marks)
