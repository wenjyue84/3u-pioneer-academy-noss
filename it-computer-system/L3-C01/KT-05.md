## Soalan / Questions

### Bahagian A: Padanan / Matching (10 marks)

Match each peripheral (Column A) with its most common connection interface (Column B).

| No. | Column A -- Peripheral | | Column B -- Interface |
|-----|------------------------|-|-----------------------|
| 1 | Monitor (modern) | | (a) USB |
| 2 | Laser printer (office) | | (b) HDMI or DisplayPort |
| 3 | Wired keyboard | | (c) Network (Ethernet/Wi-Fi) |
| 4 | Wireless mouse | | (d) 3.5 mm audio jack |
| 5 | Desktop speakers | | (e) USB receiver (2.4 GHz) |

### Bahagian B: Soalan Jawapan Pendek / Short Answer (15 marks)

**B1.** List the FIVE (5) steps for connecting and configuring a monitor during computer set-up. (5 marks)

**B2.** Describe how to set up a network printer on a newly built computer. Include the connection method, driver installation, and test print steps. (5 marks)

**B3.** A user reports that their wireless mouse is not working after set-up. List THREE (3) possible causes and the troubleshooting step for each. (5 marks)

### Bahagian C: Betul atau Salah / True or False (5 marks)

**C1.** The monitor resolution should always be set to the lowest available setting to save energy.

**C2.** USB keyboards and mice are typically plug-and-play on modern operating systems.

**C3.** Bluetooth peripherals require the computer to have a Bluetooth adapter (built-in or USB dongle).

**C4.** Printer drivers are never needed because the OS always has built-in support for all printers.

**C5.** After connecting peripherals, the technician should verify all devices appear in Device Manager without errors.
