## Tajuk / Title: Documentation and Set-up Report Completion

---

## Objektif / Objective

Complete comprehensive documentation of the computer system set-up for user handover and future reference.

---

## Tempoh / Duration

30 minutes

---

## Peralatan dan Bahan / Equipment and Materials

| No. | Item | Quantity |
|-----|------|----------|
| 1 | Tested computer from KK(6/7) | 1 |
| 2 | Set-up report template (printed form) | 1 |
| 3 | Camera or screenshot tool (for Device Manager screenshot) | 1 |
| 4 | Pen for handwritten sections | 1 |
| 5 | Original job request document | 1 |
| 6 | Functionality test checklist (completed in KK-06) | 1 |

---

## Langkah Keselamatan / Safety Precautions

- Ensure all information recorded is accurate -- incorrect documentation can cause problems during future maintenance
- Handle licence keys and passwords with care; record them securely
- Do not share documentation containing sensitive information (passwords, keys) outside the authorised recipients

---

## Prosedur / Procedures

| Langkah | Arahan / Instruction |
|---------|---------------------|
| 1 | **Gather serial numbers.** Record the serial numbers and product keys from all hardware components: CPU, motherboard, RAM, storage, PSU, monitor, keyboard, mouse. Check labels on the hardware and system information in the OS. |
| 2 | **Record OS details.** Document the installed OS version, edition, build number, and licence key (if applicable). Use System Information (msinfo32) or Settings > About to get exact details. |
| 3 | **Document drivers and applications.** List all installed drivers with version numbers. List all installed applications with version numbers and licence keys. |
| 4 | **Record BIOS/UEFI settings.** Document any non-default BIOS settings: boot order, secure boot status, XMP/EXPO profile, TPM status, storage mode (AHCI). |
| 5 | **Capture Device Manager screenshot.** Open Device Manager with all categories expanded. Take a screenshot showing all recognised hardware. Save or print for attachment to the report. |
| 6 | **Take hardware photos.** Photograph the internal hardware configuration showing cable management and component layout. Photograph the front and rear panel connections. |
| 7 | **Record RAM configuration.** Document total capacity, speed, and dual-channel status. Use Task Manager > Performance > Memory for details. |
| 8 | **Record storage configuration.** Document drive types, total capacity, and partition layout. Use Disk Management for details. |
| 9 | **Document deviations.** Compare the completed set-up against the original job request. Record any differences (e.g. part substitution, specification change) and the reason for each deviation. |
| 10 | **Complete the set-up checklist.** Fill in all sections of the set-up report template: header, hardware, software, network, test results, deviations. Attach the functionality test checklist, Device Manager screenshot, and hardware photos. |
| 11 | **Obtain sign-off.** Present the completed report to the instructor (acting as senior technician) for review and sign-off. |
| 12 | **Prepare handover notes.** Write brief user handover notes: location of power button, how to log in, support contact information, and any special instructions. |

---

## Hasil Jangkaan / Expected Outcome

Complete set-up report containing:
- All hardware serial numbers and specifications
- OS version and licence information
- Installed drivers and applications with versions
- Non-default BIOS settings documented
- Device Manager screenshot and hardware photos attached
- System configuration notes
- Any deviations from the job request explained
- Senior technician sign-off obtained
- User handover notes prepared
