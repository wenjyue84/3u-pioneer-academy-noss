## Kaedah Pengajaran / Teaching Method (4-Step)

### 1. PERSEDIAAN (Preparation)

| Langkah / Step | Aktiviti / Activity | Masa / Duration |
|----------------|---------------------|-----------------|
| 1.1 | Welcome trainees and take attendance | 5 min |
| 1.2 | State the learning objectives for the session | 5 min |
| 1.3 | Relate topic to previous knowledge and workplace context | 5 min |
| 1.4 | Provide overview of the Information Sheet (KP) content | 5 min |

### 2. PENYAMPAIAN (Presentation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 2.1 | Deliver theory content from the relevant KP using slides, diagrams, and examples |
| 2.2 | Explain key terms, definitions, and concepts with real-world scenarios |
| 2.3 | Show relevant images and diagrams (hardware components, RAID levels, network diagrams) |
| 2.4 | Demonstrate common faults and troubleshooting approaches through discussion |
| 2.5 | Encourage questions and clarify misunderstandings |
| 2.6 | Highlight safety considerations: ESD protection, electrical safety, thermal handling |

### 3. PENGGUNAAN (Application)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 3.1 | Distribute the corresponding KT (Assignment Sheet) for the session |
| 3.2 | Trainees complete the assignment individually or in groups |
| 3.3 | Instructor provides guidance and support during the exercise |
| 3.4 | Discuss answers and common errors with the class |

### 4. PENGESAHAN (Confirmation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 4.1 | Review key learning points from the session |
| 4.2 | Conduct brief oral questioning to verify understanding |
| 4.3 | Collect completed KT for marking and feedback |
| 4.4 | Preview the next session topic |
| 4.5 | Record attendance and session completion |

## Penilaian Teori / Theory Assessment

Upon completion of all 7 KP/KT sessions, trainees will sit for the Knowledge Assessment (KA):
- **Code:** IT-020-3:2013-C01/KA
- **Minimum duration:** 1 hour
- **Format:** Written test (MCQ, short answer, essay, diagram labelling)
- **Pass mark:** As per institutional and JPK requirements
