## Tajuk / Title: Operating System and Driver Installation

---

## Objektif / Objective

Install the operating system and device drivers to bring the assembled system to a working state.

---

## Tempoh / Duration

75 minutes

---

## Peralatan dan Bahan / Equipment and Materials

| No. | Item | Quantity |
|-----|------|----------|
| 1 | Assembled computer from KK(3/7) | 1 |
| 2 | Monitor (HDMI or DisplayPort) | 1 |
| 3 | Keyboard and mouse (USB) | 1 each |
| 4 | USB bootable OS installer (Windows 11 Pro or as specified) | 1 |
| 5 | Driver media (USB or download) | 1 |
| 6 | OS licence key | 1 |
| 7 | Network cable (for driver downloads and updates) | 1 |

---

## Langkah Keselamatan / Safety Precautions

- Ensure the power cable is securely connected before powering on
- Do not disconnect storage or power during OS installation -- this can corrupt the drive
- Verify USB installer integrity before starting (corrupted media causes installation failure)

---

## Prosedur / Procedures

| Langkah | Arahan / Instruction |
|---------|---------------------|
| 1 | **Connect peripherals.** Connect the monitor to the GPU (or motherboard video output). Connect the keyboard and mouse via USB. Connect the power cable to the PSU and wall outlet. |
| 2 | **Power on.** Switch the PSU on. Press the power button on the case. Observe the POST sequence for any error beeps or messages. |
| 3 | **Enter BIOS/UEFI.** Press the BIOS key (DEL, F2, or F12 -- check motherboard manual) during POST. |
| 4 | **Verify hardware detection.** In BIOS, confirm the CPU, RAM (correct capacity and speed), and storage drive are detected. |
| 5 | **Configure BIOS settings.** Set storage mode to AHCI. Enable TPM 2.0 (for Windows 11). Enable XMP/EXPO for RAM if supported. Set boot order: USB first, then storage drive. Enable or disable Secure Boot as required by the OS installer. Save and exit. |
| 6 | **Insert USB installer.** Insert the bootable USB into a USB port. The system should reboot and boot from USB. |
| 7 | **Begin OS installation.** Follow the installer prompts: select language, time zone, and keyboard layout. Enter the licence key when prompted (or select "I don't have a product key" for later activation). |
| 8 | **Partition the drive.** Select the target drive. Create partitions as required by the job request (typically one system partition). Format and proceed with installation. |
| 9 | **Complete initial setup.** After file copying and reboots, configure the user account (name, password), privacy settings, and network connection. |
| 10 | **Remove USB installer.** Once the OS boots from the storage drive, remove the USB installer. Reboot to confirm the OS loads from the installed drive. |
| 11 | **Install chipset driver.** Install the motherboard chipset driver from the manufacturer's support page or driver media. Reboot if prompted. |
| 12 | **Install GPU driver.** Install the display/GPU driver from the GPU manufacturer (NVIDIA, AMD, or Intel). Reboot if prompted. |
| 13 | **Install network driver.** If network is not auto-detected, install the LAN/Wi-Fi driver. Verify network connectivity by opening a browser. |
| 14 | **Install audio and other drivers.** Install audio driver and any remaining device-specific drivers. |
| 15 | **Apply OS updates.** Run Windows Update (or equivalent). Download and install all available updates. Reboot as needed. Repeat until no more updates are available. |
| 16 | **Verify in Device Manager.** Open Device Manager and confirm all devices are recognised with no unknown devices (no yellow triangles). |

---

## Hasil Jangkaan / Expected Outcome

- Operating system installed and booting without errors
- All hardware detected in both BIOS and OS
- All device drivers installed -- no unknown devices in Device Manager
- Network connectivity confirmed
- OS activated and all updates applied
- System stable for initial use
