## Soalan / Questions

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (10 marks)

**A1.** What must match between the CPU and motherboard for compatibility?

- (a) Brand name only
- (b) Socket type (e.g. LGA1700, AM5)
- (c) Physical size of the CPU
- (d) Colour of the heatsink

**A2.** What is the purpose of thermal paste between the CPU and heatsink?

- (a) To glue the heatsink permanently to the CPU
- (b) To fill microscopic gaps for efficient heat transfer
- (c) To cool the CPU by absorbing heat permanently
- (d) To make the CPU run faster

**A3.** For dual-channel RAM configuration, modules should be installed in:

- (a) Any available slots
- (b) The correct paired slots as indicated in the motherboard manual
- (c) Only the first slot
- (d) Alternating slots starting from the right

**A4.** NVMe Gen5 drives use which interface?

- (a) SATA data cable
- (b) M.2 PCIe Gen5 slot
- (c) USB 3.0 port
- (d) IDE ribbon cable

**A5.** What should be installed in the case BEFORE the motherboard?

- (a) The hard drive
- (b) The I/O shield and standoffs
- (c) The power supply cables
- (d) The RAM modules

### Bahagian B: Isi Tempat Kosong / Fill in the Blanks (10 marks)

Complete each statement with the correct term.

**B1.** The __________ connector provides the main power to the motherboard and is typically a 24-pin connector.

**B2.** If a system shows no power and no POST, the first things to check are the __________ cable, power switch, and front-panel header connections.

**B3.** Proper __________ management prevents airflow obstruction and makes future maintenance easier.

**B4.** The motherboard form factor (e.g. ATX, __________) determines which computer cases are compatible.

**B5.** A __________ PSU allows unused power cables to be disconnected for better airflow.

### Bahagian C: Soalan Jawapan Pendek / Short Answer (10 marks)

**C1.** List the FIVE (5) main power connections a technician must make when connecting the PSU to a typical system with a discrete GPU. (5 marks)

**C2.** Describe the correct procedure for installing a CPU into its socket, including thermal paste application. (5 marks)
