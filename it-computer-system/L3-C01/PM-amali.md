## Kaedah Pengajaran / Teaching Method (4-Step)

### 1. PERSEDIAAN (Preparation)

| Langkah / Step | Aktiviti / Activity | Masa / Duration |
|----------------|---------------------|-----------------|
| 1.1 | Welcome trainees; take attendance and verify PPE (anti-static strap) | 5 min |
| 1.2 | State the practical learning objectives for the session | 5 min |
| 1.3 | Review safety rules: ESD protection, electrical safety, workspace hygiene | 5 min |
| 1.4 | Distribute the KK (Work Sheet) and explain the exercise structure | 5 min |
| 1.5 | Verify all equipment and materials are available at each workstation | 5 min |

### 2. PENYAMPAIAN (Demonstration)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 2.1 | Demonstrate the practical task step-by-step as per the KK procedures |
| 2.2 | Highlight critical safety steps (ESD handling, power disconnection, thermal paste application) |
| 2.3 | Show correct and incorrect techniques; explain consequences of errors |
| 2.4 | Answer questions before trainees begin their own work |

### 3. PENGGUNAAN (Practice)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 3.1 | Trainees perform the practical task at their individual workstations |
| 3.2 | Instructor circulates to observe, guide, and correct technique |
| 3.3 | Brief oral questioning during practice to verify understanding |
| 3.4 | Trainees complete the KK assessment checklist as they work |

### 4. PENGESAHAN (Confirmation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 4.1 | Instructor checks each trainee's completed work against the assessment checklist |
| 4.2 | Verify the expected outcome is achieved (e.g. system boots, peripherals work, report complete) |
| 4.3 | Provide feedback on process, output, attitude, safety, and workspace cleanliness |
| 4.4 | Trainees clean and return tools and materials to storage |
| 4.5 | Record session completion and any issues |

## Keselamatan / Safety Requirements

- Anti-static wrist strap MUST be worn when handling motherboard, CPU, RAM, and expansion cards
- Power must be disconnected before opening the chassis or handling internal components
- Thermal paste must be applied correctly -- excess paste can damage components
- Cables must be routed safely to avoid tripping hazards and fan obstruction
- E-waste (damaged components, packaging) must be disposed of through authorised recycling

## Penilaian Amali / Practical Assessment

Upon completion of all 7 KK sessions, trainees will sit for the Performance Assessment (PA):
- **Code:** IT-020-3:2013-C01/PA
- **Minimum duration:** 2 hours
- **Format:** Practical task (full system set-up from job request to handover report)
- **Assessment criteria:** Process, output, attitude, safety, environmental compliance
