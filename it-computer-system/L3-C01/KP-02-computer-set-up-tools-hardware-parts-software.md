## Objektif Pembelajaran / Learning Objectives

Upon completion of this Information Sheet, trainees shall be able to:

1. Identify and describe the tools required for computer system set-up
2. Explain the purpose and proper use of each tool
3. Describe the importance of electrostatic discharge (ESD) protection
4. List the hardware parts and software media needed for a standard and custom build

---

## 1.0 Introduction

Proper preparation of tools, hardware parts, and software before beginning the set-up is essential for efficiency, safety, and quality. A well-prepared workspace reduces the risk of damage to components, shortens set-up time, and ensures that nothing is missing when work begins.

---

## 2.0 Set-up Tools

The following tools are required for computer system set-up:

### 2.1 Screwdriver Set (Phillips, Flat, Torx)

The most used tools in computer set-up. Used to open the chassis, secure drives and expansion cards, and assemble or disassemble computer components. Phillips and flat heads are for general screws; Torx for manufacturer-specific screws on some brands. An anti-static wrist strap is recommended when handling boards to avoid electrostatic discharge (ESD) that can damage components.

### 2.2 Multimeter

Used to check power supply voltages (e.g. +3.3 V, +5 V, +12 V), continuity, and basic electrical safety before and after set-up. Ensures the PSU is within tolerance and that there are no short circuits before powering on the system.

### 2.3 Cable Tester / LAN Tester

Used to verify network cable wiring (e.g. straight-through, crossover) and connectivity. Confirms that each wire is correctly terminated and that the cable can carry signal. Essential when laying or repairing network cables.

### 2.4 Anti-static Mat and Wrist Strap

Reduces electrostatic discharge (ESD) when handling motherboards, RAM, and other sensitive components. The wrist strap is worn and connected to a grounded point or the chassis; the mat provides a grounded surface for components. Never handle boards without grounding in dry environments.

### 2.5 USB Bootable Media / Optical Drive

Used to load the operating system and drivers during software installation. The installer is prepared on USB or disc according to the job request (e.g. Windows, Linux). Some systems require legacy boot or secure boot settings in BIOS/UEFI.

### 2.6 Label Maker or Tags

Used to label cables, ports, and assets for identification and reporting. Labels help during troubleshooting and when completing the set-up report with asset and serial information.

---

## 3.0 Electrostatic Discharge (ESD) Protection

ESD is a sudden flow of electricity between two objects with different electrical charges. Even a small static charge (below what a human can feel) can permanently damage sensitive electronic components such as CPUs, RAM modules, and motherboards.

**ESD prevention measures:**

- Always wear an anti-static wrist strap connected to a grounded point
- Work on an anti-static mat
- Handle components by their edges; avoid touching pins, contacts, or circuit traces
- Keep components in anti-static bags until ready for installation
- Maintain moderate humidity in the workspace (dry environments increase static risk)
- Avoid wearing synthetic clothing that generates static

---

## 4.0 Hardware Parts

The hardware parts required depend on the job request. A standard set includes:

| Part | Description |
|------|-------------|
| CPU (Central Processing Unit) | Must match the motherboard socket type (e.g. LGA1700, AM5) |
| RAM (Random Access Memory) | DDR5 modules; capacity and speed compatible with motherboard |
| Motherboard | Form factor (ATX, micro-ATX) must fit the case |
| Storage (HDD / SSD / NVMe) | Interface (SATA, M.2 PCIe Gen5) must match the motherboard |
| Power Supply Unit (PSU) | Wattage must meet system requirements; modular preferred |
| Computer case / chassis | Must accommodate the motherboard form factor and all components |
| Peripherals | Monitor, keyboard, mouse, printer as specified |

---

## 5.0 Software Media

The following software items should be prepared before beginning the set-up:

- **Operating system installer** -- USB or disc with the specified OS version and valid licence key
- **Driver media** -- Chipset, GPU, network, and audio drivers from the manufacturer
- **Application installers** -- Office suite, browser, antivirus, and other applications as specified
- **System utilities** -- Disk management, device manager, and firmware update tools

---

## 6.0 Workspace Preparation

Before beginning hardware assembly:

1. Clear the work surface and lay out the anti-static mat
2. Connect the wrist strap to a grounded point
3. Organise tools within easy reach
4. Unbox hardware components and place them on the anti-static mat
5. Verify all items against the bill of materials from the job request analysis
6. Label cables and components for easy identification
7. Ensure adequate lighting for the workspace
