## Tajuk / Title: Gathering and Organizing Set-up Materials

---

## Objektif / Objective

Prepare and organize all tools, hardware, and software required for computer system set-up.

---

## Tempoh / Duration

30 minutes

---

## Peralatan dan Bahan / Equipment and Materials

| No. | Item | Quantity |
|-----|------|----------|
| 1 | Full technician toolkit (screwdrivers, Torx bits) | 1 set |
| 2 | Anti-static mat | 1 |
| 3 | Anti-static wrist strap | 1 |
| 4 | Multimeter | 1 |
| 5 | Cable tester | 1 |
| 6 | Thermal paste | 1 tube |
| 7 | Hardware components (CPU, RAM, motherboard, storage, PSU) | 1 set |
| 8 | USB bootable media (OS installer) | 1 |
| 9 | Driver disc or USB | 1 |
| 10 | Label maker or tags | 1 |
| 11 | Equipment checklist form | 1 |

---

## Langkah Keselamatan / Safety Precautions

- Wear anti-static wrist strap when handling hardware components
- Set up anti-static mat before placing any components on the work surface
- Handle components by their edges; avoid touching pins and circuit traces
- Keep components in anti-static bags until workspace is prepared

---

## Prosedur / Procedures

| Langkah | Arahan / Instruction |
|---------|---------------------|
| 1 | Gather all tools from the workshop: screwdrivers (Phillips, flat, Torx), multimeter, cable tester, anti-static strap, and thermal paste. |
| 2 | Retrieve the required hardware components from inventory: CPU, RAM modules, storage drive, motherboard, power supply, and peripherals as specified in the job request analysis. |
| 3 | Prepare OS and driver media: verify the USB installer is bootable and contains the correct OS version. Ensure driver media is available. |
| 4 | Set up the anti-static mat on the work surface. Connect the grounding clip. Verify grounding by touching the mat while wearing the wrist strap. |
| 5 | Organise all materials in a logical sequence for installation: motherboard and CPU first, then RAM, then storage, then PSU, then cables. |
| 6 | Create a checklist confirming all items are present and functional. Check each tool and component against the bill of materials. Tick off each item. |
| 7 | Label cables, connectors, and components for easy identification during installation. Use the label maker or tags to mark power cables, SATA cables, and front-panel connectors. |

---

## Hasil Jangkaan / Expected Outcome

- Organized workspace with anti-static protection in place
- All tools verified functional and within reach
- All hardware components present and undamaged
- Software media prepared and verified bootable
- Completed equipment checklist with all items confirmed
- Cables and components labelled for installation
