## Tajuk / Title: System Functionality Testing and Verification

---

## Objektif Pembelajaran / Learning Objectives

Upon completion of this Information Sheet, trainees shall be able to:

1. Explain the purpose and scope of system functionality testing
2. Describe the testing procedures for hardware, software, and network verification
3. Identify the system utilities used for testing and monitoring
4. Interpret test results and determine whether the system meets acceptance criteria

---

## 1.0 Introduction

System functionality testing is the final verification stage before user handover. Its purpose is to confirm that all hardware components are working correctly, all software is properly installed and configured, and the system is stable under normal operating conditions. Testing must be systematic, documented, and aligned with the requirements in the job request.

---

## 2.0 Testing Categories

### 2.1 Hardware Verification

| Test | Method | Expected Result |
|------|--------|-----------------|
| Boot sequence | Power on and observe POST | System boots without errors, beep codes, or warnings |
| Device detection | Check Device Manager | All hardware recognised; no unknown devices or error icons |
| Storage health | Run Check Disk (chkdsk) or SMART check | No bad sectors; SMART status: Good/OK |
| CPU/RAM monitoring | Task Manager or system utility | CPU and RAM usage within normal range during idle and light load |
| Temperature check | BIOS monitoring or HWiNFO/similar utility | CPU and GPU temperatures within manufacturer safe range (typically below 80 C under load) |

### 2.2 Software Verification

| Test | Method | Expected Result |
|------|--------|-----------------|
| OS boot | Restart and log in | OS boots without errors; user account functional |
| Driver status | Device Manager review | All drivers installed; no yellow triangles or error codes |
| Application launch | Open each specified application | Applications launch and respond normally |
| OS updates | Check Windows Update or equivalent | All critical updates installed; system current |
| Antivirus status | Open antivirus application | Definitions current; real-time protection active |

### 2.3 Network Verification

| Test | Method | Expected Result |
|------|--------|-----------------|
| Connectivity | Ping gateway and external address | Successful ping replies; no packet loss |
| DNS resolution | Open a website in browser | Website loads correctly |
| Speed test | Run speed test utility | Download/upload speeds within expected range |
| Domain join | Check system properties (if applicable) | Computer joined to correct domain |

---

## 3.0 System Utilities for Testing

| Utility | Purpose |
|---------|---------|
| Device Manager | View all hardware devices and their driver status |
| Task Manager | Monitor CPU, RAM, disk, and network usage in real time |
| Event Viewer | Review system, application, and security logs for errors |
| Check Disk (chkdsk) | Scan storage for file system errors and bad sectors |
| System Information (msinfo32) | View detailed system configuration and hardware summary |
| Command Prompt / PowerShell | Run ping, tracert, ipconfig, and other network diagnostics |
| HWiNFO / Core Temp | Monitor CPU, GPU, and component temperatures |

---

## 4.0 Stress Testing

A brief stress test (5-10 minutes) confirms the system is stable under sustained load:

- Run a CPU-intensive task (e.g. antivirus full scan, file compression, or dedicated stress tool)
- Monitor temperatures during the test -- they should remain within safe limits
- Observe for crashes, blue screens, or freezes
- If the system is unstable under load, investigate cooling, RAM seating, or PSU capacity

---

## 5.0 Acceptance Criteria

The system passes functionality testing when all of the following are true:

- [ ] System boots without errors
- [ ] All hardware detected with no unknown devices
- [ ] All drivers installed and current
- [ ] OS is activated and all updates applied
- [ ] All specified applications installed and functional
- [ ] Network connectivity confirmed
- [ ] Temperatures within safe range under load
- [ ] No errors in Event Viewer system log (critical/error entries)
- [ ] Storage health status is Good

If any criterion is not met, the technician must diagnose and resolve the issue before proceeding to documentation and handover.
