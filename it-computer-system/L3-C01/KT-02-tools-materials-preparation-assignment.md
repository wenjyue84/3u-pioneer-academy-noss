## Soalan / Questions

### Bahagian A: Padanan / Matching (10 marks)

Match each tool (Column A) with its primary purpose (Column B).

| No. | Column A -- Tool | | Column B -- Purpose |
|-----|------------------|-|---------------------|
| 1 | Multimeter | | (a) Verify network cable wiring and connectivity |
| 2 | Anti-static wrist strap | | (b) Check PSU voltages and continuity |
| 3 | Cable tester | | (c) Label cables and ports for identification |
| 4 | Label maker | | (d) Load the operating system onto the computer |
| 5 | USB bootable media | | (e) Prevent ESD when handling sensitive components |

### Bahagian B: Betul atau Salah / True or False (10 marks)

State whether each statement is TRUE or FALSE. If FALSE, provide the correct statement.

**B1.** A Phillips screwdriver and a Torx screwdriver are interchangeable for all computer screws.

**B2.** Electrostatic discharge (ESD) can permanently damage computer components even if the static charge is too small for a human to feel.

**B3.** It is acceptable to handle a motherboard by its circuit traces as long as you work quickly.

**B4.** Anti-static bags should be used to store components until they are ready for installation.

**B5.** A modular PSU allows unused cables to be left off for better airflow inside the case.

### Bahagian C: Soalan Jawapan Pendek / Short Answer (10 marks)

**C1.** List FOUR (4) ESD prevention measures that a technician should follow during computer set-up. (4 marks)

**C2.** For a standard desktop build, list the SIX (6) main hardware parts that the technician should gather from inventory. (6 marks)

### Bahagian D: Soalan Esei / Essay (10 marks)

**D1.** Describe the complete workspace preparation process a technician should follow before beginning hardware assembly. Include tools, ESD precautions, and material verification steps. (10 marks)
