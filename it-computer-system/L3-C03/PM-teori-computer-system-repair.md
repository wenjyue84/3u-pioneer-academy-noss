## Kandungan Pengajaran / Teaching Content Outline

### KP(1/4) — Repair Job Order Assessment and Scope of Work Interpretation (9 jam)

| Subtopik | Kandungan | Masa |
|----------|-----------|------|
| 1.1 Repair job order | Struktur borang permintaan pembaikan: nombor kerja, pemohon, simptom, keutamaan, tarikh siap | 1.5 j |
| 1.2 Penilaian simptom | Teknik soal-selidik pengguna; klasifikasi simptom: perkakasan, perisian, rangkaian | 2.0 j |
| 1.3 Skop kerja | Menentukan skop: pembaikan di tapak vs. penyelesaian masalah atas talian; eskalasi | 2.0 j |
| 1.4 Pengesahan sumber | Semak ketersediaan alatan, komponen gantian, dan kebenaran akses | 1.5 j |
| 1.5 Penjadualan dan keutamaan | Kaedah triage; menetapkan keutamaan berdasarkan impak perniagaan | 2.0 j |

### KP(2/4) — Online Troubleshooting Methods, Tools, and Remote Diagnostics (16 jam)

| Subtopik | Kandungan | Masa |
|----------|-----------|------|
| 2.1 Metodologi penyelesaian masalah | Pendekatan sistematik: kumpul maklumat > kenal pasti punca akar > cadang penyelesaian > uji > dokumentasikan | 2.0 j |
| 2.2 Alat diagnostik Windows | Event Viewer, Device Manager, Task Manager, Resource Monitor, Reliability Monitor | 3.0 j |
| 2.3 Alat baris arahan | `sfc /scannow`, `chkdsk`, `DISM`, `ipconfig`, `ping`, `tracert`, `netstat` | 3.0 j |
| 2.4 Akses jauh (remote access) | Remote Desktop Protocol (RDP), TeamViewer, AnyDesk — prosedur, keselamatan, had | 3.0 j |
| 2.5 Diagnosis perisian & OS | Penyelesaian masalah but, mod selamat (Safe Mode), pemulihan sistem (System Restore) | 3.0 j |
| 2.6 Dokumentasi sesi atas talian | Cara merekod tindakan, dapatan, dan keputusan sesi penyelesaian masalah atas talian | 2.0 j |

### KP(3/4) — On-Site Repair Procedures, Component Diagnosis, and Replacement (22 jam)

| Subtopik | Kandungan | Masa |
|----------|-----------|------|
| 3.1 Persediaan pembaikan di tapak | Senarai semak alatan, komponen gantian, borang kerja, PPE, akses tapak | 2.0 j |
| 3.2 Prosedur keselamatan ESD | Jenis ESD, kesan pada komponen, penggunaan wrist strap dan mat antistatik | 2.0 j |
| 3.3 Diagnosis perkakasan | Kaedah swap-and-test; kod bip POST; diagnosis PSU, RAM, HDD/SSD, motherboard, GPU | 5.0 j |
| 3.4 Prosedur penggantian komponen | Urutan pembongkaran dan pemasangan semula; teknik pengendalian komponen; pasang dan uji | 5.0 j |
| 3.5 Diagnosis perisian di tapak | Pemulihan sistem operasi; pembaikan Boot Record (MBR/GPT); pemulihan data | 4.0 j |
| 3.6 Ujian pengesahan pasca-pembaikan | Prosedur ujian fungsi menyeluruh: but, Device Manager, stress test, rangkaian | 4.0 j |

### KP(4/4) — Computer Status Report Preparation and Handover Documentation (7 jam)

| Subtopik | Kandungan | Masa |
|----------|-----------|------|
| 4.1 Struktur laporan status | Bahagian laporan: maklumat unit, simptom asal, tindakan diambil, komponen diganti, keputusan ujian, status akhir | 2.0 j |
| 4.2 Penulisan laporan teknikal | Bahasa teknikal yang tepat; penerangan tindakan yang boleh diaudit | 2.0 j |
| 4.3 Prosedur serah terima | Pembentangan dapatan kepada pengguna; tandatangan pengesahan; fail rekod | 2.0 j |
| 4.4 Rekod dan penyimpanan | Sistem fail rekod pembaikan; tempoh simpan; kerahsiaan maklumat pengguna | 1.0 j |

## Kaedah Pengajaran / Teaching Method (4-Step)

### 1. PERSEDIAAN (Preparation)

| Langkah / Step | Aktiviti / Activity | Masa / Duration |
|----------------|---------------------|-----------------|
| 1.1 | Sambut pelatih dan ambil kehadiran | 5 min |
| 1.2 | Nyatakan objektif pembelajaran untuk sesi | 5 min |
| 1.3 | Kaitkan topik dengan pengetahuan sedia ada dan konteks tempat kerja (kes pembaikan sebenar) | 5 min |
| 1.4 | Berikan gambaran keseluruhan kandungan Lembaran Maklumat (KP) untuk sesi | 5 min |

### 2. PENYAMPAIAN (Presentation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 2.1 | Sampaikan kandungan teori daripada KP berkaitan menggunakan slaid, gambar rajah, dan contoh sebenar |
| 2.2 | Terangkan istilah utama, definisi, dan konsep dengan senario tempat kerja yang realistik |
| 2.3 | Tunjukkan demonstrasi langsung: jalankan alat diagnostik pada komputer demonstrasi; tunjukkan kerosakan yang disimulasikan |
| 2.4 | Bincangkan kerosakan biasa dan pendekatan penyelesaian masalah melalui perbincangan kes |
| 2.5 | Galakkan soalan dan jelaskan salah faham |
| 2.6 | Tekankan pertimbangan keselamatan: perlindungan ESD, keselamatan elektrik, pengendalian komponen |

### 3. PENGGUNAAN (Application)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 3.1 | Edarkan Lembaran Tugasan (KT) yang berkaitan untuk sesi |
| 3.2 | Pelatih melengkapkan tugasan secara individu atau berkumpulan |
| 3.3 | Pengajar memberikan bimbingan dan sokongan semasa latihan |
| 3.4 | Bincangkan jawapan dan kesilapan biasa bersama kelas |

### 4. PENGESAHAN (Confirmation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 4.1 | Ulangkaji mata pembelajaran utama sesi |
| 4.2 | Lakukan soal-jawab lisan ringkas untuk mengesahkan kefahaman |
| 4.3 | Kumpul KT yang telah dilengkapkan untuk pemeriksaan dan maklum balas |
| 4.4 | Pratonton topik sesi seterusnya |
| 4.5 | Rekodkan kehadiran dan penyelesaian sesi |
