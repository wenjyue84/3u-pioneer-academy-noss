### Q3 — PSU Fault Diagnosis
**Type:** Short Answer | **Difficulty:** L2 | **Marks:** 4 | **LO Ref:** WA3.K4

State THREE checks a technician performs to diagnose a suspected faulty PSU using a multimeter.

**Model Answer:** (1) Measure +12 V rail at the ATX connector — should read 11.4–12.6 V.
(2) Measure +5 V rail — should read 4.75–5.25 V. (3) Measure +3.3 V rail — should read 3.135–3.465 V.
Any reading outside spec confirms PSU fault.

**Rubric:** 3=3 voltage checks with acceptable ranges | 2=2 correct checks | 1=1 correct check | 0=Wrong/blank

---

### Q4 — RAM Fault Diagnosis
**Type:** Short Answer | **Difficulty:** L2 | **Marks:** 4 | **LO Ref:** WA3.K4

Describe the steps to diagnose faulty RAM in a system that fails to POST.

**Model Answer:** (1) Reseat all RAM modules firmly. (2) Test with one stick in slot 1; try each stick
individually. (3) Run Memtest86 from bootable USB to confirm errors. (4) Replace any stick that
shows errors; record module serial number in status report.

**Rubric:** 3=All 4 steps correct | 2=Steps 1–3 correct | 1=Reseat only | 0=Incorrect/blank
