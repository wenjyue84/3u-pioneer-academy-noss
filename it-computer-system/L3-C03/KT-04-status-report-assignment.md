## Tugasan / Tasks

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (10 marks)

*Circle the letter of the best answer.*

**A1.** A computer status report prepared after repair serves PRIMARILY to:

- (a) Record the technician's personal overtime claims
- (b) Document the fault found, actions taken, components replaced, and current system status for accountability and future reference
- (c) Notify the supplier of parts consumed
- (d) Provide an invoice to the user's department

**A2.** Which of the following is NOT a standard section in a computer status report?

- (a) Fault description and diagnosis findings
- (b) Repair actions performed and parts replaced
- (c) Technician's personal medical history
- (d) System functionality test results after repair

**A3.** A status report must be signed by:

- (a) The technician only
- (b) Both the technician and the user/authorised representative as acknowledgement of completed repair
- (c) The supplier of the replacement parts
- (d) The building security guard

**A4.** When a repair cannot be completed within the agreed timeframe due to parts unavailability, the status report should:

- (a) Be left blank until the repair is fully completed
- (b) Record the current status, reason for delay, and estimated completion date
- (c) Only record the parts that were ordered
- (d) State that the job was completed even though it was not

**A5.** The computer status report is an important document because it:

- (a) Allows the technician to avoid future repair calls from the same user
- (b) Creates a traceable service record that supports warranty claims, audits, and asset management
- (c) Replaces the need for a job order in future repairs
- (d) Is only required when the repair fails

### Bahagian C: Situasi / Situational (15 marks)

**C1.** You have just completed an on-site repair for En. Rashdan in the IT Department. The following events occurred during the repair:

| Event | Details |
|---|---|
| Original fault reported | Hard disk making clicking noise; computer freezing frequently |
| Diagnosis finding | HDD confirmed failed (bad sectors across 85% of disk surface) |
| Action taken | Replaced failed HDD (500 GB SATA) with new SSD (500 GB SATA) from stock |
| Data recovery | Partial — 70% of data recovered from damaged sectors via recovery software; 30% unrecoverable |
| OS reinstallation | Windows 10 Pro reinstalled; original licence key applied |
| Software reinstalled | Microsoft Office 365 (user re-authenticated with existing licence) |
| Functionality test | System boots normally; all recovered data accessible; SSD performance verified |
| Parts consumed | 1× 500 GB SATA SSD (from stock, asset tag SSD-IT-2026-088) |
| Time on-site | 3.5 hours |

(i) Using the information above, draft a complete computer status report for this repair job. Your report must include all mandatory fields and clearly reflect the partial data loss situation. *(9 marks)*

(ii) En. Rashdan is concerned about the 30% data that could not be recovered. Explain how you would document this data loss in the report and what you would advise En. Rashdan to do going forward to prevent recurrence. *(4 marks)*

(iii) State the correct filing and handover procedure for this completed status report, including who receives copies and where the record is stored. *(2 marks)*
