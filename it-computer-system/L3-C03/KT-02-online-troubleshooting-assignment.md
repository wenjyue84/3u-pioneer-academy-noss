## Tugasan / Tasks

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (10 marks)

*Circle the letter of the best answer.*

**A1.** Online troubleshooting refers to resolving computer faults:

- (a) By physically opening the computer casing at the user's desk
- (b) Remotely via network tools, telephone, or chat-based guidance without physical presence
- (c) By replacing all hardware components without diagnosis
- (d) By reinstalling the operating system immediately

**A2.** Which of the following is a commonly used remote desktop tool for online troubleshooting in enterprise environments?

- (a) Windows Paint
- (b) Microsoft Remote Desktop (RDP) / TeamViewer
- (c) Notepad++
- (d) Windows Media Player

**A3.** During online troubleshooting, the FIRST action a technician should take is to:

- (a) Remotely restart the user's computer without warning
- (b) Gather information about the fault by asking the user to describe the problem
- (c) Immediately wipe and reinstall the operating system
- (d) Disconnect the user's network connection

**A4.** A technician is troubleshooting a user who reports that the computer "cannot connect to the internet." Which of the following is the BEST initial online diagnostic step?

- (a) Ask the user to physically replace the network card
- (b) Ask the user to open Command Prompt and run `ipconfig` to check the IP address and default gateway
- (c) Advise the user to purchase a new router
- (d) Schedule an on-site visit without attempting any remote checks

**A5.** After completing online troubleshooting, the technician should:

- (a) Close the ticket immediately without informing the user
- (b) Document the fault, steps taken, resolution, and confirm with the user that the issue is resolved
- (c) Delete all remote session logs to protect privacy
- (d) Recommend the user buys a new computer

### Bahagian B: Soalan Jawapan Pendek / Short Answer (15 marks)

**B1.** List FIVE (5) types of computer faults that are commonly resolved through online troubleshooting without requiring an on-site visit. *(5 marks)*

**B2.** Describe THREE (3) steps a technician must follow to ensure a secure and authorised remote desktop session when troubleshooting online. *(6 marks)*

**B3.** State TWO (2) limitations of online troubleshooting and explain in each case what the technician should do when the limitation is encountered. *(4 marks)*

---

### Bahagian C: Situasi / Situational (15 marks)

**C1.** A user, En. Farouk, calls the ICT Helpdesk and reports the following:

> "My computer was working fine this morning, but after I installed a software update, it restarts by itself every 10 minutes. I cannot finish any work."

The helpdesk technician decides to carry out online troubleshooting via remote desktop before scheduling an on-site visit.

(i) Describe the information the technician should collect from En. Farouk BEFORE initiating the remote session. *(4 marks)*

(ii) Once connected remotely, outline FOUR (4) diagnostic steps the technician should perform to identify the cause of the automatic restart. State the specific tools or commands used for each step. *(8 marks)*

(iii) After investigation, the technician determines that the installed update is incompatible and must be rolled back. The rollback requires administrator privileges that En. Farouk does not have. Explain the correct procedure the technician should follow to complete the resolution while maintaining security and audit compliance. *(3 marks)*
