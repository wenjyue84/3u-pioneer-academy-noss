## Kandungan Amali / Practical Content Outline

### KK(1/4) — Assessing Repair Job Orders and Planning the Repair Approach (18 jam)

| Aktiviti | Penerangan | Masa |
|----------|-----------|------|
| 1.1 Membaca dan mentafsir borang permintaan pembaikan | Pelatih menerima borang permintaan simulasi; mengenal pasti simptom, keutamaan, dan skop; menyediakan senarai semak penilaian | 4.0 j |
| 1.2 Temu bual pengguna simulasi | Menjalankan sesi temu bual berstruktur; menyoal pengguna mengenai simptom, masa mula, dan persekitaran penggunaan | 4.0 j |
| 1.3 Penilaian skop dan perancangan | Menentukan sama ada kes memerlukan penyelesaian masalah atas talian atau pembaikan di tapak; merancang urutan kerja | 4.0 j |
| 1.4 Pengesahan sumber dan alatan | Menyemak ketersediaan komponen gantian, alatan, dan kebenaran akses; melengkapkan senarai semak persediaan | 3.0 j |
| 1.5 Semakan dan maklum balas pengajar | Pengajar menyemak kerja penilaian pelatih; memberi maklum balas; pelatih membaiki kesilapan | 3.0 j |

### KK(2/4) — Online Troubleshooting and Remote Diagnostic Sessions (37.5 jam)

| Aktiviti | Penerangan | Masa |
|----------|-----------|------|
| 2.1 Menjalankan diagnostik Windows | Penggunaan praktikal: Event Viewer (menapis log ralat kritikal), Device Manager (mengenal pasti konflik), Task Manager (analisis prestasi) | 6.0 j |
| 2.2 Perintah diagnostik baris arahan | Latihan praktikal: `sfc /scannow`, `chkdsk /f /r`, `DISM /Online /Cleanup-Image /RestoreHealth`, `ipconfig /all`, `ping`, `tracert` | 7.0 j |
| 2.3 Sesi akses jauh | Latihan berpasangan menggunakan Remote Desktop / TeamViewer: menghubungkan, mendiagnos, dan mendokumentasikan sesi; amalan keselamatan | 8.0 j |
| 2.4 Penyelesaian masalah but dan OS | Latihan: mendiagnos kegagalan but; menggunakan Safe Mode, System Restore, Startup Repair; membaiki MBR/GPT dengan alatan WinRE | 8.0 j |
| 2.5 Diagnosis perisian dan pemacu | Mengenal pasti konflik pemacu; nyah-pasang dan pasang semula pemacu bermasalah; menggunakan Windows Update untuk pembaikan pemacu | 5.0 j |
| 2.6 Dokumentasi sesi atas talian | Pelatih melengkapkan log sesi penyelesaian masalah: tindakan, dapatan, keputusan, dan cadangan tindakan susulan | 3.5 j |

### KK(3/4) — On-Site Repair: Component Diagnosis, Replacement, and Testing (56 jam)

| Aktiviti | Penerangan | Masa |
|----------|-----------|------|
| 3.1 Persediaan tapak dan PPE | Menyediakan kit alatan, komponen gantian, borang kerja; memakai wrist strap antistatik; menyediakan ruang kerja ESD-selamat | 4.0 j |
| 3.2 Diagnosis PSU | Menggunakan multimeter untuk menguji voltan output PSU; kaedah paperclip test; mengenal pasti PSU yang rosak | 5.0 j |
| 3.3 Diagnosis dan gantian RAM | Kaedah swap-and-test dengan modul RAM; menjalankan MemTest86; mengenal pasti slot RAM yang rosak; menggantikan modul | 6.0 j |
| 3.4 Diagnosis dan gantian HDD/SSD | Menjalankan S.M.A.R.T. test; menggunakan CrystalDiskInfo; mengenal pasti sektor rosak; prosedur pemindahan data dan gantian cakera | 8.0 j |
| 3.5 Diagnosis dan gantian kad grafik (GPU) | Menguji dengan mod VGA asas; swap GPU; menguji output paparan; mengenal pasti kegagalan GPU berbanding kegagalan slot PCIe | 6.0 j |
| 3.6 Diagnosis motherboard dan CPU | Mentafsir kod bip POST; menggunakan POST card; mengenal pasti komponen yang terbakar secara visual; prosedur gantian CPU dan heatsink | 8.0 j |
| 3.7 Pemulihan sistem operasi di tapak | Pemulihan menggunakan media pemasangan; pembaikan partition; kloning cakera; pemulihan imej sistem | 8.0 j |
| 3.8 Ujian pengesahan pasca-pembaikan | Prosedur ujian menyeluruh: but, Device Manager, stress test (CPU-Z, HWMonitor), ujian rangkaian, ujian aplikasi | 6.0 j |
| 3.9 Semakan dan maklum balas pengajar | Pengajar menilai teknik dan hasil kerja pelatih; memberi maklum balas; pelatih mengulang prosedur yang lemah | 5.0 j |

### KK(4/4) — Computer Status Report Preparation and Handover (14.5 jam)

| Aktiviti | Penerangan | Masa |
|----------|-----------|------|
| 4.1 Menulis laporan status komputer | Pelatih melengkapkan laporan status sebenar berdasarkan kes pembaikan KK(3/4); merangkumi semua bahagian yang diperlukan | 4.0 j |
| 4.2 Simulasi pembentangan serah terima | Pelatih membentangkan dapatan dan laporan kepada pengajar (berperanan sebagai pengguna / pengurus jabatan) | 3.0 j |
| 4.3 Semakan rakan sebaya | Pelatih saling menyemak laporan antara satu sama lain mengikut senarai semak kriteria laporan | 3.0 j |
| 4.4 Pengemaskinian dan pemfailan rekod | Mengemaskini borang permintaan pembaikan asal dengan status akhir; memfailkan rekod mengikut prosedur | 2.0 j |
| 4.5 Semakan dan maklum balas pengajar | Pengajar menyemak laporan akhir pelatih; memberi maklum balas bertulis; pelatih melengkapkan semakan | 2.5 j |

## Kaedah Pengajaran / Teaching Method (4-Step)

### 1. PERSEDIAAN (Preparation)

| Langkah / Step | Aktiviti / Activity | Masa / Duration |
|----------------|---------------------|-----------------|
| 1.1 | Sambut pelatih; ambil kehadiran dan sahkan PPE (wrist strap antistatik) | 5 min |
| 1.2 | Nyatakan objektif pembelajaran praktikal untuk sesi | 5 min |
| 1.3 | Ulangkaji peraturan keselamatan: perlindungan ESD, keselamatan elektrik, kebersihan ruang kerja | 5 min |
| 1.4 | Edarkan KK (Lembaran Kerja) dan terangkan struktur latihan | 5 min |
| 1.5 | Sahkan semua peralatan dan bahan tersedia di setiap stesen kerja | 5 min |

### 2. PENYAMPAIAN (Demonstration)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 2.1 | Tunjukkan tugasan praktikal langkah demi langkah mengikut prosedur KK |
| 2.2 | Tekankan langkah keselamatan kritikal: pengendalian ESD, penanggalan kuasa, teknik pengendalian komponen |
| 2.3 | Tunjukkan teknik yang betul dan salah; terangkan akibat kesilapan (kerosakan komponen, kehilangan data) |
| 2.4 | Tunjukkan penggunaan alatan diagnostik pada komputer demonstrasi dengan kerosakan yang disimulasikan |
| 2.5 | Jawab soalan sebelum pelatih memulakan kerja mereka sendiri |

### 3. PENGGUNAAN (Practice)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 3.1 | Pelatih melaksanakan tugasan praktikal di stesen kerja individu mereka |
| 3.2 | Pengajar bergerak untuk memerhati, membimbing, dan membetulkan teknik |
| 3.3 | Soal-jawab lisan ringkas semasa latihan untuk mengesahkan kefahaman |
| 3.4 | Pelatih melengkapkan senarai semak penilaian KK semasa bekerja |

### 4. PENGESAHAN (Confirmation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 4.1 | Pengajar menyemak kerja siap setiap pelatih berdasarkan senarai semak penilaian |
| 4.2 | Sahkan hasil yang dijangkakan dicapai (contoh: komputer but, laporan lengkap, simptom diselesaikan) |
| 4.3 | Berikan maklum balas mengenai proses, hasil, sikap, keselamatan, dan kebersihan ruang kerja |
| 4.4 | Pelatih membersihkan dan memulangkan alatan serta bahan ke tempat penyimpanan |
| 4.5 | Rekodkan penyelesaian sesi dan sebarang isu yang diperhatikan |

## Keselamatan / Safety Requirements

- Tali pergelangan antistatik MESTI dipakai semasa mengendalikan motherboard, CPU, RAM, GPU, dan kad pengembangan
- Bekalan kuasa MESTI diputuskan sebelum membuka casis atau mengendalikan komponen dalaman
- Komponen mesti dipegang pada bahagian tepinya; JANGAN sentuh litar, pin, atau penyambung
- Kabel mesti dipasang dengan selamat untuk mengelakkan bahaya tersadung dan halangan kipas
- Sisa elektronik (e-waste), komponen rosak, dan bahan pembungkusan mesti dilupuskan melalui kitar semula yang diberi kuasa
- Pelatih tidak dibenarkan menanggalkan atau menggantikan komponen tanpa kebenaran pengajar
