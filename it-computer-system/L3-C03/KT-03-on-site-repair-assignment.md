## Tugasan / Tasks

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (10 marks)

*Circle the letter of the best answer.*

**A1.** Before performing on-site repair on a computer, the technician MUST:

- (a) Immediately open the computer casing without any preparation
- (b) Obtain authorisation from the job order and inform the user of the repair scope
- (c) Request the user to leave the room before starting work
- (d) Back up only the technician's own files

**A2.** The PRIMARY reason for grounding yourself (using an anti-static wrist strap) before handling internal computer components is to:

- (a) Prevent the technician from touching sharp edges
- (b) Prevent electrostatic discharge (ESD) that could damage sensitive components
- (c) Increase the speed of the repair process
- (d) Comply with the company dress code

**A3.** During an on-site repair, a technician discovers that the actual fault is more extensive than what was stated in the job order. The correct action is to:

- (a) Perform all additional repairs without informing anyone
- (b) Stop work, document the finding, and raise a change request for authorisation before proceeding
- (c) Complete all repairs and inform the user only after billing
- (d) Return the computer to the user unfixed

**A4.** After replacing a faulty RAM module on-site, the technician should:

- (a) Return the old faulty RAM to the user as a souvenir
- (b) Power on the system and verify that the fault is resolved before closing the job
- (c) Leave immediately without testing
- (d) Format the hard drive to ensure a clean system

**A5.** Which of the following safety practices is CORRECT when performing on-site repair involving the power supply unit (PSU)?

- (a) Test the PSU while it is still connected to the mains supply
- (b) Switch off and unplug the computer from the power source before opening the casing
- (c) Keep the computer plugged in so the internal fan keeps components cool during repair
- (d) Use a metal screwdriver to test live terminals

### Bahagian C: Situasi / Situational (15 marks)

**C1.** You are dispatched to the Finance Department to perform an on-site repair on a desktop computer belonging to Cik Suraya. The approved job order states:

| Field | Details |
|---|---|
| Reported Fault | Computer does not power on |
| Last Known State | Was working normally the previous day; no unusual events reported |
| Approved Scope | Diagnose and repair power-related fault |
| Special Notes | User has critical data on the computer — no data loss acceptable |

Upon arrival, you introduce yourself, inspect the unit, and find that the power LED does not light up at all when the power button is pressed.

(i) Describe the systematic diagnostic steps you would carry out on-site to identify whether the fault is in the power cable, power socket, PSU, or motherboard. List the steps in logical order. *(6 marks)*

(ii) After testing, you confirm the PSU is faulty. You have a compatible replacement PSU in your toolkit. Describe the step-by-step procedure to safely replace the PSU, including all safety measures. *(6 marks)*

(iii) After the replacement, the computer powers on successfully. Describe what you must do before closing the job and leaving the site, including verification and documentation steps. *(3 marks)*
