## Arahan kepada Pelatih / Instructions to Trainee

1. This is a PRACTICAL examination. You will be assessed on your ability to perform a complete computer system maintenance cycle.
2. You will be given a maintenance work order, a workstation with known issues, and a set of tools and software utilities.
3. You must complete all four maintenance phases: requirement identification, preventive maintenance, corrective maintenance, and report preparation.
4. You will be assessed on: **Process** (how you do it), **Output** (the result), **Attitude** (professionalism), **Safety** (ESD and electrical), and **Environmental** compliance.
5. You must wear an anti-static wrist strap throughout all hardware-handling phases.
6. All findings, actions taken, and results must be documented on the provided maintenance report form.

---

## Arahan kepada Penilai / Instructions to Assessor

- Provide each trainee with: a workstation with pre-configured hardware and software faults, a maintenance work order, a full maintenance toolkit, and the maintenance report form.
- Pre-configure the workstation with at least two observable faults (e.g., accumulated dust in CPU heatsink, outdated antivirus definitions, fragmented HDD, a loose RAM module).
- Observe each trainee continuously. Do NOT assist the trainee unless there is a safety hazard.
- Mark each criterion on the rubric as the trainee works.
- Verify the completed maintenance report and the restored system condition at the end of the assessment.

---

## Tugasan / Task Description

**Scenario:** You are a Level 3 Computer System Technician at a training institute. You receive the following maintenance work order:

| Field | Details |
|-------|---------|
| Work Order Number | PM-2026-C02-001 |
| Issued by | IT Department Supervisor |
| Priority | Scheduled — High |
| Asset Tag | WS-LAB-012 |
| System Description | Desktop PC — Intel Core i5, 8 GB DDR4 RAM, 1 TB HDD, Windows 10 Pro |
| Reported Issues | System running slowly; occasional random restarts; antivirus definitions out-of-date; user complaint of overheating |
| Maintenance Type | Scheduled Preventive + Corrective |
| Deadline | Today (within assessment duration) |

**You must complete the following tasks in order:**

1. Analyse the work order and identify maintenance requirements — categorise as preventive or corrective (20 minutes)
2. Carry out physical preventive maintenance — dust removal, thermal paste inspection/replacement, cable management, hardware reseating (60 minutes)
3. Carry out software preventive maintenance — OS updates, antivirus update and scan, disk check, defragmentation/TRIM, startup optimisation (40 minutes)
4. Perform corrective maintenance — diagnose and resolve the identified fault(s) causing slow performance and random restarts; document root cause (40 minutes)
5. Conduct post-maintenance functionality testing — verify system stability, performance benchmarks, no error events (20 minutes)
6. Complete the maintenance report — record findings, actions, parts replaced, test results, and recommendations (20 minutes)

**Total time allowed: 3 hours 20 minutes**
