## Objektif / Objective

By the end of this activity, trainees will be able to:
- Consolidate all maintenance records from Activities 1–3 into a structured Computer Maintenance Report
- Apply correct report format and technical writing conventions used in industry
- Summarise findings, actions taken, recommendations, and next scheduled maintenance date
- Present the report accurately and professionally for submission to a simulated supervisor

---

## Tempoh / Duration

1.5 hours

---

## Peralatan dan Bahan / Equipment and Materials

| No. | Item | Kuantiti / Quantity |
|-----|------|---------------------|
| 1 | Computer with word-processing software (Microsoft Word or LibreOffice Writer) | 1 unit |
| 2 | Completed Maintenance Request Form (from KK-01) | 1 |
| 3 | Completed PM Checklist and Maintenance Log (from KK-02) | 1 set |
| 4 | Completed Fault Report Form and Corrective Maintenance Log (from KK-03) | 1 set |
| 5 | Computer Maintenance Report template (provided by instructor) | 1 |
| 6 | Pen and notepad (for drafting notes before typing) | 1 set |
| 7 | USB flash drive (to save and submit the report) | 1 |

---

## Langkah Keselamatan / Safety Precautions

- Save the report file regularly during editing (every 10 minutes minimum) to prevent data loss
- Do not share or print reports containing the asset's serial number or user personal information outside the training room without instructor authorisation
- Return all physical forms and log sheets to the instructor at the end of the session — do not retain original source documents

---

## Prosedur / Procedures

### Bahagian A — Penyediaan Draf / Drafting Preparation

| Langkah | Arahan / Instruction |
|---------|----------------------|
| 1 | Gather all completed source documents: the Maintenance Request Form (KK-01), PM Checklist and Maintenance Log (KK-02), and Fault Report Form with Corrective Maintenance Log (KK-03). Lay them out in order — you will draw information from each section. |
| 2 | Before opening the word processor, spend 5 minutes reviewing all source documents. Identify: (a) the computer asset number and user details, (b) all maintenance tasks performed, (c) faults found and corrective actions taken, (d) current system status, (e) any outstanding issues or recommendations. Jot a brief outline on your notepad. |

### Bahagian B — Penulisan Laporan / Report Writing

| Langkah | Arahan / Instruction |
|---------|----------------------|
| 3 | Open the Computer Maintenance Report template on the computer. Save a copy immediately using the naming convention: `[AssetNo]_MaintenanceReport_[DDMMYYYY].docx` — e.g., `PC-LAB01_MaintenanceReport_23062026.docx`. |
| 4 | Complete the **Header Section** of the report: Computer Asset Number, Location, User Name (or Department), Date of Maintenance, Technician Name, and Report Reference Number. |
| 5 | Complete **Section 1 — Maintenance Type and Scope**: state whether this was Preventive Maintenance, Corrective Maintenance, or Both. Briefly describe the scope of work authorised (from KK-01 findings). |
| 6 | Complete **Section 2 — Physical Maintenance Summary**: list all physical tasks performed during the preventive maintenance (KK-02). Use a table format with columns: Task, Action Taken, Result/Status. Example entries: Dust removal (compressed air + brush — Completed), Thermal paste replacement (IPA clean + new paste applied — Completed), Cable management (rerouted and tied — Completed). |
| 7 | Complete **Section 3 — Software Maintenance Summary**: list all software tasks performed (KK-02). Use the same table format: Disk Cleanup (freed X MB — Completed), Disk Optimisation (type: HDD defrag / SSD TRIM — Completed), OS Updates (X updates installed — Completed), Antivirus Update and Scan (definitions updated; scan result — Completed / Threats Quarantined). |
| 8 | Complete **Section 4 — Fault Report and Corrective Action** (if applicable from KK-03): state the reported symptom, the diagnostic steps taken, the root cause identified, the corrective action performed, and the outcome. If no corrective maintenance was required, write "Nil — No faults identified during this maintenance cycle." |
| 9 | Complete **Section 5 — System Status After Maintenance**: state the current condition of the computer in clear language. Indicate: (a) all identified issues have been resolved, (b) the computer boots and operates normally, (c) temperatures are within normal range, (d) security software is active and updated. |
| 10 | Complete **Section 6 — Recommendations**: list any items that require follow-up action beyond the current maintenance cycle. Examples: "Replace HDD within 3 months — S.M.A.R.T. data shows increasing reallocated sectors", "Upgrade RAM from 4 GB to 8 GB to improve performance", "Schedule next preventive maintenance on [date]". If no recommendations, write "None — system is in good operating condition." |
| 11 | Complete **Section 7 — Next Scheduled Maintenance Date**: state the recommended date for the next preventive maintenance cycle. Standard recommendation: 6 months from today for office environments, 3 months for high-use or industrial environments. |

### Bahagian C — Semakan dan Pembentangan / Review and Submission

| Langkah | Arahan / Instruction |
|---------|----------------------|
| 12 | Proofread the complete report: check for spelling errors, missing fields, incorrect dates, and inconsistencies between the report and the source documents. All asset numbers, dates, and component names must match the source records exactly. |
| 13 | Ensure the report uses professional, clear language throughout. Avoid vague statements such as "Computer is OK" — use specific statements such as "System boots to Windows 11 desktop within 45 seconds; no POST errors detected; CPU temperature 42°C at idle." |
| 14 | Sign the report in the designated Technician Signature field. Note the date and time of report completion. |
| 15 | Save the final version of the report to the USB flash drive. Submit both the USB flash drive and all physical source forms to the instructor. |

---

## Hasil Dijangka / Expected Outcome

Upon completion, the trainee will have produced:
- A complete, accurate Computer Maintenance Report in the prescribed format
- All six report sections correctly populated with specific, verifiable information drawn from the source maintenance documents
- Professional technical language used throughout, with no blank or vague fields
- The report saved in the correct filename format and submitted together with all source forms
