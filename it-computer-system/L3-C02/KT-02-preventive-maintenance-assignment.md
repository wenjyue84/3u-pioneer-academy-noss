## Tugasan / Tasks

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (10 markah / marks)

**A1.** Antara berikut, yang manakah merupakan aktiviti penyelenggaraan pencegahan bagi **perkakasan** komputer? / Which of the following is a preventive maintenance activity for computer **hardware**?

- (a) Mengemas kini definisi antivirus / Updating antivirus definitions
- (b) Membersihkan habuk daripada heatsink dan kipas menggunakan udara termampat / Cleaning dust from heatsink and fan using compressed air
- (c) Memformat semula cakera keras / Reformatting the hard disk
- (d) Memasang semula sistem pengendalian / Reinstalling the operating system

**A2.** Apakah fungsi **thermal paste** dalam sistem pendinginan CPU? / What is the function of **thermal paste** in a CPU cooling system?

- (a) Melindungi CPU daripada litar pintas / Protecting the CPU from short circuits
- (b) Mengisi jurang udara antara CPU dan heatsink bagi memastikan pindahan haba yang lebih cekap / Filling air gaps between the CPU and heatsink for more efficient heat transfer
- (c) Meningkatkan kelajuan pemproses / Increasing processor speed
- (d) Menyejukkan RAM secara langsung / Directly cooling the RAM

**A3.** Dalam penyelenggaraan perisian, apakah tujuan menjalankan **disk defragmentation** pada cakera keras jenis HDD? / In software maintenance, what is the purpose of running **disk defragmentation** on an HDD?

- (a) Menghapuskan semua fail dalam komputer / Deleting all files in the computer
- (b) Menyusun semula data yang berselerak agar pemacu cakera dapat mengakses fail dengan lebih pantas / Rearranging fragmented data so the disk drive can access files more quickly
- (c) Mempercepatkan proses boot BIOS / Speeding up the BIOS boot process
- (d) Memperluaskan kapasiti storan pemacu / Expanding the storage capacity of the drive

**A4.** Mengapa **disk defragmentation** TIDAK disyorkan untuk pemacu **SSD (Solid State Drive)**? / Why is **disk defragmentation** NOT recommended for **SSD** drives?

- (a) SSD tidak mempunyai sistem fail / SSDs do not have a file system
- (b) Defragmentasi akan memperlahankan SSD secara kekal / Defragmentation will permanently slow down the SSD
- (c) SSD tidak menyimpan data secara berselerak dan defragmentasi menyebabkan kitaran tulis berlebihan yang memendekkan jangka hayatnya / SSDs do not store data in a fragmented manner and defragmentation causes excessive write cycles that shorten its lifespan
- (d) SSD memerlukan alat khas untuk defragmentasi / SSDs require special tools for defragmentation

**A5.** Apakah kepentingan mengemaskini **BIOS/firmware** sebagai sebahagian daripada penyelenggaraan pencegahan? / What is the importance of updating **BIOS/firmware** as part of preventive maintenance?

- (a) Meningkatkan kapasiti RAM komputer / Increasing the computer's RAM capacity
- (b) Mempertingkatkan keserasian perkakasan, kestabilan sistem, dan menutup kelemahan keselamatan / Improving hardware compatibility, system stability, and closing security vulnerabilities
- (c) Menukar antara muka pengguna sistem pengendalian / Changing the operating system user interface
- (d) Mempercepatkan sambungan internet / Speeding up the internet connection

**B4.** Nyatakan DUA (2) sebab mengapa **sandaran data (data backup)** merupakan komponen penting dalam penyelenggaraan pencegahan, dan nyatakan DUA (2) media storan yang boleh digunakan untuk tujuan sandaran. / State TWO (2) reasons why **data backup** is an important component of preventive maintenance, and state TWO (2) storage media that can be used for backup purposes. *(4 markah)*

### Bahagian C: Soalan Situasi / Situational Question (20 markah / marks)

**C1.** Sebuah pusat latihan vokasional mempunyai 20 unit komputer di makmal IT mereka. Komputer-komputer tersebut telah digunakan selama 18 bulan tanpa sebarang penyelenggaraan dijadualkan. Pelatih melaporkan komputer berjalan lambat, kipas berbunyi bising, dan beberapa unit mengalami ranap sesekali.

A vocational training centre has 20 computer units in their IT lab. The computers have been in use for 18 months without any scheduled maintenance. Trainees report that computers are running slowly, fans are noisy, and some units occasionally crash.

**(i)** Berdasarkan laporan di atas, kenal pasti dan terangkan EMPAT (4) tugas penyelenggaraan pencegahan yang harus segera dilaksanakan oleh juruteknik, merangkumi aspek perkakasan DAN perisian. Jelaskan mengapa setiap tugas itu penting berdasarkan gejala yang dilaporkan. / Based on the reports above, identify and explain FOUR (4) preventive maintenance tasks that the technician should immediately carry out, covering both hardware AND software aspects. Explain why each task is important based on the symptoms reported. *(12 markah)*

**(ii)** Rekabentuk sebuah **jadual penyelenggaraan pencegahan berjadual** (scheduled preventive maintenance schedule) untuk makmal IT tersebut, merangkumi aktiviti harian, mingguan, bulanan, dan tahunan. / Design a **scheduled preventive maintenance schedule** for the IT lab, covering daily, weekly, monthly, and annual activities. *(8 markah)*
