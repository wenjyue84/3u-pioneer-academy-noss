## Tugasan / Tasks

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (10 markah / marks)

**A1.** Apakah tujuan utama penyelenggaraan komputer dilaksanakan? / What is the primary purpose of carrying out computer maintenance?

- (a) Menambah bilangan pengguna komputer / To increase the number of computer users
- (b) Mengurangkan atau mengelakkan kerosakan teknikal dan memanjangkan jangka hayat komputer / To reduce or prevent technical failures and extend the lifespan of the computer
- (c) Menukar semua komponen komputer secara berkala / To replace all computer components periodically
- (d) Menyimpan data pengguna ke dalam storan awan / To store user data in cloud storage

**A2.** Yang manakah antara berikut BUKAN merupakan jenis penyelenggaraan komputer? / Which of the following is NOT a type of computer maintenance?

- (a) Penyelenggaraan pencegahan / Preventive maintenance
- (b) Penyelenggaraan pembetulan / Corrective maintenance
- (c) Penyelenggaraan ramalan / Predictive maintenance
- (d) Penyelenggaraan pemasaran / Marketing maintenance

**A3.** Penyelenggaraan pencegahan (Preventive Maintenance) dilakukan:

- (a) Selepas berlakunya kerosakan pada komputer / After a computer failure has occurred
- (b) Secara berkala sebelum berlakunya kerosakan / Periodically before any failure occurs
- (c) Hanya apabila pengguna membuat aduan / Only when a user makes a complaint
- (d) Sekali sahaja sepanjang hayat peralatan / Only once throughout the equipment's lifespan

**A4.** Dokumen yang digunakan untuk merekod permintaan penyelenggaraan daripada pengguna ialah: / The document used to record a maintenance request from a user is:

- (a) Laporan inventori / Inventory report
- (b) Borang permintaan penyelenggaraan / Maintenance request form (service request form)
- (c) Senarai semak pemasangan perisian / Software installation checklist
- (d) Rekod pembelian perkakasan / Hardware purchase record

**A5.** Apakah yang dimaksudkan dengan "fault history" (sejarah kerosakan) dalam konteks penyelenggaraan komputer? / What is meant by "fault history" in the context of computer maintenance?

- (a) Senarai harga pembaikan komputer / A list of computer repair costs
- (b) Rekod kerosakan dan tindakan pembetulan yang telah dilaksanakan pada sesebuah sistem / A record of past failures and corrective actions taken on a system
- (c) Jadual penyelenggaraan pencegahan yang dirancang / A scheduled preventive maintenance timetable
- (d) Senarai perisian yang dipasang pada komputer / A list of software installed on the computer

### Bahagian C: Soalan Situasi / Situational Question (20 markah / marks)

**C1.** Anda ialah juruteknik IT di sebuah syarikat yang mempunyai 30 unit komputer pejabat. Pengurus IT meminta anda mengenal pasti keperluan penyelenggaraan bagi semua unit tersebut. Berdasarkan senario ini:

You are an IT technician at a company with 30 office computers. The IT manager has asked you to identify the maintenance requirements for all units. Based on this scenario:

**(i)** Terangkan langkah-langkah yang anda akan ambil untuk mengenal pasti keperluan penyelenggaraan bagi kesemua 30 unit komputer tersebut. / Explain the steps you would take to identify the maintenance requirements for all 30 computer units. *(10 markah)*

**(ii)** Rekabentuk satu **senarai semak penyelenggaraan** (maintenance checklist) yang ringkas dengan sekurang-kurangnya LAPAN (8) item pemeriksaan, merangkumi aspek perkakasan (hardware) dan perisian (software). / Design a simple **maintenance checklist** with at least EIGHT (8) inspection items, covering both hardware and software aspects. *(10 markah)*
