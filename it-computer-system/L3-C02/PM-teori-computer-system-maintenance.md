## Kandungan Pengajaran / Content Outline

### KP(1/4) — Computer Maintenance Requirements Identification (9.0 hours)

| Topik | Kandungan / Content |
|-------|---------------------|
| 1.1 | Introduction to computer maintenance — definition, purpose, and importance |
| 1.2 | Types of maintenance: preventive (scheduled), corrective (breakdown), predictive, and periodic/TBM |
| 1.3 | Reading and interpreting a maintenance work order / service request form |
| 1.4 | Identifying maintenance scope — hardware components and software systems covered |
| 1.5 | Maintenance scheduling concepts — frequency, intervals, and priority classification |
| 1.6 | Maintenance safety requirements — ESD protection, electrical isolation, PPE |
| 1.7 | Preparation of maintenance checklist and tool/material requirements |

### KP(2/4) — Computer Scheduled Preventive Maintenance (12.0 hours)

| Topik | Kandungan / Content |
|-------|---------------------|
| 2.1 | Hardware preventive maintenance: dust removal (compressed air, vacuum cleaner), cable management, component reseating (RAM, expansion cards, connectors) |
| 2.2 | Thermal management: inspection and replacement of CPU thermal paste (compound); heatsink and fan cleaning |
| 2.3 | Storage preventive maintenance: SMART data analysis, disk error checking (chkdsk/fsck), disk cleanup, defragmentation (HDD), TRIM command (SSD) |
| 2.4 | Software updates: OS patches (Windows Update), device driver updates, BIOS/UEFI firmware updates |
| 2.5 | Security maintenance: antivirus definition updates, full system scan, firewall configuration review, internet settings check |
| 2.6 | Data backup and recovery: backup types (full, incremental, differential), backup media (internal/external HDD, cloud, NAS), backup verification |
| 2.7 | Performance optimisation: startup program management, registry cleanup, temporary file removal, power plan settings |

### KP(3/4) — Computer Corrective Maintenance (12.0 hours)

| Topik | Kandungan / Content |
|-------|---------------------|
| 3.1 | Corrective maintenance methodology — fault reporting, symptom analysis, root cause identification, corrective action, verification |
| 3.2 | Common hardware faults and diagnosis: POST beep codes, no-power scenarios, RAM errors (MemTest86), overheating (thermal monitoring tools), HDD/SSD failure (SMART, CrystalDiskInfo) |
| 3.3 | Common software faults and diagnosis: Blue Screen of Death (BSOD) — reading stop codes and minidump files; application crashes; boot failure recovery |
| 3.4 | Fault history and event log analysis: Windows Event Viewer (Application, System, Security logs); reading error codes and event IDs |
| 3.5 | Component-level corrective actions: reseating vs. replacing RAM; substitution testing; driver rollback; System Restore; OS repair |
| 3.6 | Network-related corrective maintenance: checking NIC status, IP configuration, connectivity testing (ping, tracert, ipconfig) |
| 3.7 | Peripheral corrective maintenance: USB port faults, display issues, keyboard/mouse non-detection |

### KP(4/4) — Computer Maintenance Report Preparation (3.0 hours)

| Topik | Kandungan / Content |
|-------|---------------------|
| 4.1 | Purpose and structure of a computer maintenance report |
| 4.2 | Sections of a maintenance report: asset details, work order reference, date/technician, findings, actions taken, parts replaced, post-maintenance test results, recommendations |
| 4.3 | Writing professional technical descriptions — root cause analysis language, clear and factual reporting |
| 4.4 | Maintenance record-keeping: updating asset maintenance log, scheduling next preventive maintenance cycle |
| 4.5 | Sample maintenance report forms — Computer Service Request Form, Maintenance Work Order, Individual Equipment Maintenance Record |

## Kaedah Pengajaran / Teaching Method (4-Step)

### 1. PERSEDIAAN (Preparation)

| Langkah / Step | Aktiviti / Activity | Masa / Duration |
|----------------|---------------------|-----------------|
| 1.1 | Welcome trainees and take attendance | 5 min |
| 1.2 | State the learning objectives for the session | 5 min |
| 1.3 | Relate the topic to real workplace scenarios (e.g., "What happens if a lab computer overheats and is never serviced?") | 5 min |
| 1.4 | Provide overview of the Information Sheet (KP) content for the session | 5 min |

### 2. PENYAMPAIAN (Presentation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 2.1 | Deliver theory content from the relevant KP using slides, diagrams, and worked examples |
| 2.2 | Explain key terms and definitions with real-world context (e.g., difference between preventive and corrective maintenance; how SMART data predicts HDD failure) |
| 2.3 | Show relevant images and diagrams (dust-clogged heatsink, thermal paste application, BSOD stop codes, Event Viewer screenshots, maintenance report sample) |
| 2.4 | Discuss fault case studies — walk through common computer faults (overheating due to dust, RAM instability, BSOD from driver conflict) and their resolution |
| 2.5 | Encourage questions and clarify misunderstandings throughout |
| 2.6 | Emphasise safety: ESD handling, electrical isolation before opening chassis, compressed air usage in ventilated areas |

### 3. PENGGUNAAN (Application)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 3.1 | Distribute the corresponding KT (Assignment Sheet) for the session |
| 3.2 | Trainees complete structured assignments (e.g., categorise given fault symptoms as preventive or corrective; fill in a sample maintenance report; identify the correct tool for a given task) |
| 3.3 | Instructor provides guidance and support during the exercise |
| 3.4 | Discuss answers and common errors with the class |

### 4. PENGESAHAN (Confirmation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 4.1 | Review key learning points from the session (oral summary by instructor) |
| 4.2 | Conduct brief oral questioning to verify trainee understanding (e.g., "What is the difference between corrective and predictive maintenance?") |
| 4.3 | Collect completed KT for marking and feedback |
| 4.4 | Preview the next session topic |
| 4.5 | Record attendance and session completion |

## Penilaian Teori / Theory Assessment

- **Code:** IT-020-3:2013-C02/KA
- **Minimum duration:** 1 hour
- **Format:** Written test (MCQ, short answer, fill-in-the-blank, diagram labelling, case study)
- **Pass mark:** As per institutional and JPK requirements
