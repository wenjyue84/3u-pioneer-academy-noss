## Tugasan / Tasks

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (10 markah / marks)

**A1.** Penyelenggaraan pembetulan (corrective maintenance) dilaksanakan apabila: / Corrective maintenance is carried out when:

- (a) Komputer masih berfungsi tetapi perlu dinaik taraf / The computer is still functional but needs upgrading
- (b) Sistem komputer disyaki atau telah rosak dan tidak dapat berfungsi seperti biasa / The computer system is suspected of or has broken down and cannot function normally
- (c) Jadual penyelenggaraan tahunan telah tiba / The annual maintenance schedule has arrived
- (d) Pengguna ingin menukar sistem pengendalian / The user wants to change the operating system

**A2.** Seorang juruteknik mendapati tetikus dan papan kekunci tidak dikesan oleh komputer. Tindakan pembetulan pertama yang paling sesuai ialah: / A technician finds that the mouse and keyboard are not detected by the computer. The most appropriate first corrective action is:

- (a) Menukar papan induk (motherboard) / Replace the motherboard
- (b) Memformat semula cakera keras / Reformat the hard disk
- (c) Memeriksa dan mencuba port USB yang berbeza; pastikan penyambung terpasang dengan betul / Check and try a different USB port; ensure the connector is properly seated
- (d) Memasang semula sistem pengendalian / Reinstall the operating system

**A3.** Apabila komputer mengeluarkan **bunyi bip (beep)** berulang semasa dihidupkan (POST), ini menunjukkan: / When a computer produces repeated **beep sounds** during startup (POST), this indicates:

- (a) Komputer berjaya dihidupkan tanpa masalah / The computer has started up successfully without issues
- (b) Terdapat masalah perkakasan yang dikesan semasa Power On Self-Test (POST) / There is a hardware problem detected during Power On Self-Test (POST)
- (c) Pemacu cakera keras penuh / The hard disk drive is full
- (d) Antivirus sedang menjalankan imbasan / The antivirus is running a scan

**A4.** Kaedah yang betul untuk membersihkan RAM yang tidak dikesan oleh sistem adalah dengan: / The correct method to clean RAM that is not detected by the system is to:

- (a) Merendamkan RAM dalam air suling / Submerging the RAM in distilled water
- (b) Menggunakan pemadam getah untuk membersihkan penyambung emas RAM dengan berhati-hati, kemudian pasang semula / Using a rubber eraser to carefully clean the RAM's gold contacts, then reseat it
- (c) Memanaskan RAM menggunakan pengering rambut / Heating the RAM using a hair dryer
- (d) Menggosok RAM dengan kain basah / Wiping the RAM with a wet cloth

**A5.** **Blue Screen of Death (BSOD)** pada Windows biasanya menunjukkan: / **Blue Screen of Death (BSOD)** on Windows typically indicates:

- (a) Sambungan internet yang terputus / A lost internet connection
- (b) Kegagalan perkakasan kritikal, ralat pemacu (driver), atau rasuah sistem yang menyebabkan Windows tidak dapat beroperasi dengan selamat / A critical hardware failure, driver error, or system corruption that prevents Windows from operating safely
- (c) Cakera keras hampir penuh / The hard disk is almost full
- (d) Berlakunya kemas kini sistem pengendalian yang berjaya / A successful operating system update

### Bahagian B: Soalan Jawapan Pendek / Short Answer (20 markah / marks)

**B1.** Padankan setiap **gejala kerosakan** di lajur kiri dengan **punca yang paling berkemungkinan** di lajur kanan. / Match each **fault symptom** in the left column with the **most likely cause** in the right column. *(5 markah)*

| Gejala / Symptom | Punca / Cause |
|---|---|
| 1. Komputer terlalu panas dan mati sendiri / Computer overheats and shuts down spontaneously | A. RAM tidak terpasang dengan betul atau rosak / RAM improperly seated or faulty |
| 2. Tiada paparan pada monitor walaupun komputer dihidupkan / No display on monitor even though computer is powered on | B. Habuk berlebihan menyumbat heatsink dan kipas / Excessive dust clogging heatsink and fan |
| 3. Komputer sangat perlahan dan sering tidak bertindak balas / Computer is very slow and frequently unresponsive | C. Jangkitan virus atau perisian hasad / Virus or malware infection |
| 4. Fail tidak dijumpai atau rosak tanpa sebab / Files missing or corrupted without reason | D. Sambungan kabel VGA/HDMI longgar atau kad grafik rosak / Loose VGA/HDMI cable or faulty graphics card |
| 5. Mesej ralat "No bootable device" semasa dihidupkan / "No bootable device" error message at startup | E. Cakera keras rosak atau partition boot tiada / Hard disk failure or missing boot partition |

**B2.** Terangkan apakah itu **S.M.A.R.T. (Self-Monitoring, Analysis and Reporting Technology)** dan bagaimana ia membantu juruteknik dalam penyelenggaraan pembetulan. / Explain what **S.M.A.R.T.** is and how it assists a technician in corrective maintenance. *(4 markah)*

**B3.** Senaraikan TIGA (3) contoh situasi yang memerlukan **pemulihan sistem (System Restore)** sebagai tindakan pembetulan, dan terangkan secara ringkas prosedur pelaksanaannya. / List THREE (3) example situations that require **System Restore** as a corrective action, and briefly explain the procedure to carry it out. *(6 markah)*

**B4.** Terangkan perbezaan antara **corrective maintenance yang ditangguhkan (deferred corrective maintenance)** dengan **corrective maintenance segera (immediate corrective maintenance)**. Berikan satu contoh bagi setiap jenis. / Explain the difference between **deferred corrective maintenance** and **immediate corrective maintenance**. Give one example for each type. *(5 markah)*

### Bahagian C: Soalan Situasi / Situational Question (20 markah / marks)

**C1.** Seorang pelatih di makmal IT melaporkan masalah berikut pada komputer yang digunakannya:

A trainee in the IT lab reports the following problems with the computer they are using:

- Komputer mengambil masa lebih 5 minit untuk but (boot) / The computer takes more than 5 minutes to boot
- Muncul mesej ralat "Disk Read Error" sesekali semasa but / "Disk Read Error" message appears occasionally during boot
- Program sering tidak bertindak balas (hang) / Programs frequently become unresponsive (hang)
- Bunyi berdecit (clicking sound) kedengaran daripada unit sistem / A clicking sound is heard from the system unit
- Antivirus melaporkan dua (2) jangkitan virus yang gagal dibuang secara automatik / Antivirus reports two (2) virus infections that failed to be automatically removed

**(i)** Sebagai juruteknik, laksanakan **diagnosis terperinci** terhadap masalah-masalah di atas. Kenal pasti punca bagi setiap gejala yang dilaporkan dan cadangkan tindakan pembetulan yang sesuai bagi setiap satu. / As a technician, carry out a **detailed diagnosis** of the problems above. Identify the likely cause for each reported symptom and suggest an appropriate corrective action for each. *(10 markah)*

**(ii)** Susun tindakan pembetulan yang anda cadangkan dalam **(i)** mengikut **keutamaan pelaksanaan** (yang paling kritikal dahulu) dan justifikasikan urutan tersebut. / Arrange the corrective actions you proposed in **(i)** according to **priority of execution** (most critical first) and justify that order. *(10 markah)*
