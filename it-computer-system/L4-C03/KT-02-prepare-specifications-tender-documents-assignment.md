## Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (20 marks — 4 marks each)

**A1.** A technical specification that states "Processor: Dell OptiPlex i7" is problematic because:

- (a) It specifies too many parameters
- (b) It names a specific brand/model, which may restrict competition
- (c) It does not include the warranty period
- (d) It is written in English

**A2.** In a weighted tender evaluation, if technical compliance is 60% and price is 30%, the remaining 10% is typically allocated to:

- (a) Vendor's marketing materials
- (b) Number of company vehicles
- (c) Vendor experience and support capability
- (d) Office location

**A3.** Which document in an RFQ package allows vendors to confirm compliance with each specification item?

- (a) Purchase Order
- (b) Supplier Compliance Checklist
- (c) Goods Received Note
- (d) Acceptance Certificate

**A4.** A Liquidated Damages (LD) clause in a procurement contract is intended to:

- (a) Reward the vendor for early delivery
- (b) Penalise the vendor for late delivery
- (c) Calculate the vendor's profit margin
- (d) Set the warranty period

**A5.** The minimum number of written quotations required for a Malaysian government quotation exercise (Sebut Harga) is:

- (a) 1
- (b) 2
- (c) 3
- (d) 5

## Bahagian B: Soalan Jawapan Pendek / Short Answer (30 marks)

**B1.** List FIVE (5) consequences of poorly written technical specifications in a procurement exercise. (10 marks)

**B2.** Describe the NINE (9) sections that should be included in a Technical Specification Document for ICT procurement. (9 marks)

**B3.** Explain the difference between a Request for Quotation (RFQ) and an Invitation to Tender (ITT). State TWO (2) differences. (6 marks)

**B4.** State THREE (3) principles that make a technical specification "technology-neutral." (5 marks)

## Bahagian C: Soalan Berstruktur / Structured Question (50 marks)

**C1.** Read the following scenario and answer all parts.

> **Scenario:** Your organisation has approved a procurement for 10 managed network switches for a new office building. The approved budget is RM 95,000. You are tasked with preparing the RFQ document set.

**(a)** Write a complete technical specification for ONE (1) managed network switch. Include at least 8 measurable parameters. Do not use brand names. (16 marks)

**(b)** Draft the Terms and Conditions section for the RFQ. Cover the following: delivery timeframe, payment terms, late delivery penalty (LD), and warranty obligations. (16 marks)

**(c)** Design a Supplier Compliance Checklist table for the switch specification you wrote in (a). The table must have columns for: Specification Item, Required Value, Vendor's Offered Value, and Compliant (Yes/No). Include all 8 parameters from your specification. (10 marks)

**(d)** State the evaluation criteria and weightages you would use for this procurement. Explain why you have assigned the weightages as you have. (8 marks)
