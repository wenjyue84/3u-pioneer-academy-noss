## Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (20 marks — 4 marks each)

**A1.** The primary purpose of maintaining a complete procurement file is to:

- (a) Impress the vendor
- (b) Provide an audit trail and enable dispute resolution
- (c) Reduce the time needed for future procurement
- (d) Store the vendor's catalogue

**A2.** Under Malaysian law, tender evaluation documents for a government agency must be retained for a minimum of:

- (a) 2 years
- (b) 3 years
- (c) 5 years
- (d) 7 years

**A3.** Which document triggers payment processing and marks the formal acceptance of delivered goods?

- (a) Goods Received Note
- (b) Purchase Order
- (c) Acceptance Certificate
- (d) Procurement Closure Report

**A4.** A Procurement Closure Report should include which of the following?

- (a) The vendor's profit margin
- (b) Lessons learned and recommendations for future procurement exercises
- (c) A list of rejected vendors' home addresses
- (d) The organisation's annual budget

**A5.** In a procurement file, the document that records when and by whom all quotation submissions were opened is called:

- (a) Compliance Matrix
- (b) Quotation Opening Record
- (c) Needs Assessment Report
- (d) Asset Registration Form

## Bahagian C: Soalan Berstruktur / Structured Question (50 marks)

**C1.** Read the following scenario and answer all parts.

> **Scenario:** An IT administrator has just completed a procurement exercise for 30 laptop computers. The exercise took 12 weeks — 3 weeks longer than planned due to a vendor delivering the wrong model on the first attempt. The corrected units were delivered 2 weeks late, triggering an LD deduction of RM 1,800. Final contract value: RM 135,000 (budget was RM 130,000). All 30 laptops passed FAT and have been accepted. The Procurement Committee has asked for a full Procurement Closure Report and confirmation that the procurement file is audit-ready.

**(a)** Prepare a Procurement File Checklist for this exercise. List at least 12 mandatory documents that should be in the file. For each document, state the procurement stage it belongs to (Initiation / Specification / Solicitation / Evaluation / Award / Delivery / Payment / Closure). (24 marks)

**(b)** Write the "Lessons Learned" section of the Procurement Closure Report for this scenario. Identify at least THREE (3) specific lessons drawn from the issues described. For each lesson, state: what happened, what the impact was, and what should be done differently in future. (18 marks)

**(c)** Write a complete Procurement Register row for this exercise. Include all fields from KP(5/5): procurement reference, description, method, estimated value, actual value, vendor, award date, required delivery date, actual delivery date, and status. You may use fictitious but realistic data for fields not specified in the scenario. (8 marks)
