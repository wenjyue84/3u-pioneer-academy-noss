**Tujuan / Objective:** Simulate the full delivery management cycle — from issuing a Purchase Order to completing a Functional Acceptance Test and signing the Acceptance Certificate — for a set of ICT equipment.

**Arahan:** Pelatih dikehendaki melaksanakan tugasan/kerja mengikut prosedur yang ditetapkan dalam kertas ini. Rujuk pensyarah sekiranya perlu penjelasan lanjut.

---

## Objektif / Objective

Issue a Purchase Order, inspect simulated delivered goods, conduct a Functional Acceptance Test on live equipment provided by the instructor, and complete all delivery management documentation.

---

## Tempoh / Duration

5 hours

---

## Peralatan dan Bahan / Equipment and Materials

| No. | Item | Quantity |
|-----|------|----------|
| 1 | Approved Evaluation Report and vendor recommendation (from KK-03) | 1 |
| 2 | Purchase Order template | 1 |
| 3 | Goods Received Note (GRN) template | 1 |
| 4 | Functional Acceptance Test (FAT) checklist | 1 per unit tested |
| 5 | Acceptance Certificate template | 1 |
| 6 | Simulated delivered ICT equipment (desktop PCs / network switch as available) | As provided |
| 7 | Simulated delivery note from vendor (provided by instructor) | 1 |
| 8 | Asset Registration Form | 1 per unit |
| 9 | Barcode/asset tag labels | As required |
| 10 | Computer with diagnostic software (CrystalDiskInfo, HWiNFO, or equivalent) | 1 |
| 11 | Camera or mobile phone (for photographing equipment condition) | 1 |

---

## Langkah Keselamatan / Safety Precautions

- Power off all equipment before connecting or disconnecting cables during inspection
- Handle ICT equipment carefully; do not drop or place on unstable surfaces
- Use anti-static precautions when inspecting internal components if required
- Photograph all packaging damage before opening; do not discard original packaging until FAT is complete

---

## Prosedur / Procedures

| Langkah | Arahan / Instruction |
|---------|---------------------|
| 1 | Complete the Purchase Order template using the awarded vendor's details and accepted quotation prices from KK-03. Fill in all fields: PO number, date, vendor details, item descriptions, quantities, unit prices, delivery address, required delivery date, and payment terms. Sign as the authorised purchasing officer. |
| 2 | Receive the simulated delivery. Compare the physical delivery against the PO: count all items, verify model numbers on the delivery note match the PO and specification. Photograph the equipment as received. |
| 3 | Complete the Goods Received Note (GRN). Record: GRN number, date received, vendor name, each item with quantity and condition. Note any discrepancies in the "Discrepancies" field. If no discrepancies, state "Nil." Sign and date. |
| 4 | If any item is physically damaged or incorrect: complete a Discrepancy Note (use the template provided). Do NOT complete acceptance for the discrepant item. Notify the instructor (simulating vendor notification). Continue FAT only on compliant items. |
| 5 | Conduct the Functional Acceptance Test on each unit. Follow the FAT checklist: power-on test, OS boot verification, BIOS check (correct firmware, TPM 2.0 enabled), Device Manager check (no unknown devices), RAM and storage verification, network port test (ping), and peripheral check. Record pass/fail for each test item. |
| 6 | Record the serial number of each unit tested on the FAT checklist and the Asset Registration Form. Affix an asset tag label to each unit in the location specified by the instructor. |
| 7 | Complete the Acceptance Certificate for all units that passed FAT. State: number of units accepted, date of acceptance, and confirmation that goods meet specification. Sign as Receiving Officer. Note any units pending (awaiting replacement for discrepancies). |
| 8 | Complete the Asset Registration Form for each accepted unit. Enter all required fields including purchase cost, warranty expiry, location, and assigned user (use simulated data provided by instructor). Submit all completed documents — PO, GRN, FAT checklists, Acceptance Certificate, and Asset Registration Forms — to the instructor. |

---

## Hasil Jangkaan / Expected Outcome

Complete delivery management documentation comprising:
- Signed Purchase Order
- Goods Received Note (with any discrepancies noted)
- Completed FAT checklist for each unit (pass/fail for all test items)
- Acceptance Certificate signed by Receiving Officer
- Asset Registration Form for each accepted unit with asset tag number
