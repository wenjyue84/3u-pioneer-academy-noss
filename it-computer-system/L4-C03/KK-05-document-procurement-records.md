**Tujuan / Objective:** Compile a complete procurement file from all documents produced in KK-01 to KK-04, maintain a Procurement Register entry, and produce a Procurement Closure Report with lessons learned.

**Arahan:** Pelatih dikehendaki melaksanakan tugasan/kerja mengikut prosedur yang ditetapkan dalam kertas ini. Rujuk pensyarah sekiranya perlu penjelasan lanjut.

---

## Objektif / Objective

Organise all procurement exercise documents into a complete, audit-ready procurement file, update the Procurement Register, and produce a Procurement Closure Report.

---

## Tempoh / Duration

3 hours

---

## Peralatan dan Bahan / Equipment and Materials

| No. | Item | Quantity |
|-----|------|----------|
| 1 | All documents produced in KK-01 to KK-04 | 1 complete set |
| 2 | Procurement File Checklist (provided by instructor) | 1 |
| 3 | Procurement Register template (spreadsheet) | 1 |
| 4 | Procurement Closure Report template | 1 |
| 5 | Document retention schedule reference card | 1 |
| 6 | Physical file folder / ring binder (or digital folder structure on computer) | 1 |
| 7 | Computer with word processing and spreadsheet software | 1 |

---

## Langkah Keselamatan / Safety Precautions

- All documents produced during this exercise are confidential; do not leave printed documents unattended
- Digital files must be saved in the folder specified by the instructor; do not save to personal devices
- Verify that all documents containing signatures are legible before filing

---

## Prosedur / Procedures

| Langkah | Arahan / Instruction |
|---------|---------------------|
| 1 | Collect all documents produced in KK-01 through KK-04. Organise them into the following sections using dividers (physical or digital folder tabs): (1) Initiation, (2) Specification, (3) Solicitation, (4) Evaluation, (5) Award, (6) Delivery, (7) Payment, (8) Closure. |
| 2 | Use the Procurement File Checklist to verify that every mandatory document is present. For each document in the checklist, mark: Present, Missing, or Not Applicable. For any missing document, note the reason and any corrective action taken (e.g. "Quotation opening record not produced — note that this must be completed during actual procurement"). |
| 3 | Apply the document retention schedule to the procurement file. For each document category, note the minimum retention period on the file cover sheet (e.g. "Tender evaluation documents: retain 7 years from contract completion"). |
| 4 | Open the Procurement Register spreadsheet. Add a new row for this procurement exercise. Complete all fields: procurement reference number, description, method, estimated value, actual value, vendor awarded, award date, required delivery date, actual delivery date, and status (set to "Closed"). |
| 5 | Open the Procurement Closure Report template. Complete the following sections: (a) Executive Summary — one paragraph summarising the procurement outcome; (b) Objectives vs Outcomes — compare original requirements against what was delivered; (c) Financial Summary — compare estimated budget vs actual award value; (d) Timeline Summary — compare planned vs actual milestone dates from all KKs; (e) Vendor Performance — assess the simulated vendor on delivery, quality, and responsiveness; (f) Issues Encountered — list any discrepancies or problems from KK-04; (g) Lessons Learned — record at least 3 lessons from the complete procurement exercise. |
| 6 | Review the completed procurement file for completeness and accuracy. Verify that all documents are in the correct section, all dates are consistent across documents, and all signatures are present. |
| 7 | Prepare a file cover sheet for the procurement file containing: procurement reference number, description, vendor, award value, date opened, and date closed. Attach as the first page of the file. |
| 8 | Submit the complete procurement file (physical binder or digital folder), Procurement Register entry, and Procurement Closure Report to the instructor for assessment. |

---

## Hasil Jangkaan / Expected Outcome

A complete, audit-ready procurement package comprising:
- Physical or digital procurement file organised into 8 sections
- Completed Procurement File Checklist with any gaps noted
- Retention schedule noted on file cover sheet
- Procurement Register updated with this procurement exercise
- Procurement Closure Report with all sections completed including at least 3 lessons learned
- File cover sheet as the first page
