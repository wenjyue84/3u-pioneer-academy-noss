## Kaedah Pengajaran / Teaching Method (4-Step)

### 1. PERSEDIAAN (Preparation)

| Langkah / Step | Aktiviti / Activity | Masa / Duration |
|----------------|---------------------|-----------------|
| 1.1 | Welcome trainees; take attendance | 5 min |
| 1.2 | State the practical learning objectives for the session | 5 min |
| 1.3 | Review ethical obligations: remind trainees that all procurement documents are confidential; reinforce COI declaration requirement for evaluation sessions | 10 min |
| 1.4 | Distribute the KK (Work Sheet) and explain the exercise structure, scenario, and available tools | 10 min |
| 1.5 | Verify all templates, documents, and equipment are available at each workstation | 5 min |

### 2. PENYAMPAIAN (Demonstration)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 2.1 | Demonstrate the practical task step-by-step as per the KK procedures, using the projector to show document completion in real time |
| 2.2 | For KK(1/5): demonstrate needs assessment walkthrough — reading a scenario, extracting requirements, selecting procurement method |
| 2.3 | For KK(2/5): demonstrate drafting a technology-neutral specification item and a compliance checklist row |
| 2.4 | For KK(3/5): demonstrate completing a compliance matrix row and applying the price scoring formula |
| 2.5 | For KK(4/5): demonstrate FAT procedure on a sample desktop PC — power-on, BIOS check, Device Manager verification, network test |
| 2.6 | For KK(5/5): demonstrate procurement file organisation — show correct section labelling and document placement |
| 2.7 | Show examples of common errors and their consequences (e.g. signing GRN without inspection, brand-specific specifications) |
| 2.8 | Answer trainee questions before they begin independent work |

### 3. PENGGUNAAN (Practice)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 3.1 | Trainees perform the practical task at their individual workstations using the scenario and templates provided |
| 3.2 | Instructor circulates to observe, guide technique, and ask oral questions to verify understanding |
| 3.3 | For KK(3/5) — evaluation sessions: ensure each trainee signs the COI Declaration before accessing quotation documents |
| 3.4 | For KK(4/5) — delivery sessions: instructor provides simulated ICT equipment for FAT; trainees conduct FAT and complete forms |
| 3.5 | Trainees complete the KK assessment checklist as they work |

### 4. PENGESAHAN (Confirmation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 4.1 | Instructor reviews each trainee's completed documents against the KK assessment checklist |
| 4.2 | Verify that key outputs are correct: procurement method justified, specifications technology-neutral, evaluation scores calculated accurately, FAT conducted systematically, procurement file complete |
| 4.3 | Provide verbal feedback on process, output quality, and any errors observed |
| 4.4 | Trainees correct any minor errors and resubmit for sign-off |
| 4.5 | Record session completion and any trainees requiring additional support |

## Keselamatan dan Etika / Safety and Ethics Requirements

- Trainees must treat all simulated procurement documents as confidential — do not share quotation details or evaluation scores with other trainees during exercises
- A signed Conflict of Interest Declaration is mandatory before any vendor evaluation exercise (KK-03)
- Handle ICT equipment during FAT (KK-04) with care: power off before connecting cables; use anti-static precautions if internal inspection is required
- Digital files must be saved in the instructor-designated shared folder; do not save to personal USB drives without instructor permission
- All printed documents must be collected and shredded at the end of the session (simulating document security practice)

## Penilaian Amali / Practical Assessment

Upon completion of all 5 KK sessions, trainees will sit for the Performance Assessment (PA):
- **Code:** IT-020-4:2013-C03/PA
- **Duration:** 4 hours
- **Format:** Integrated practical exercise — full procurement cycle from needs assessment to closure, using a new scenario not previously seen
- **Assessment criteria:** Process (30%), Output (35%), Attitude (15%), Safety/Ethics (10%), Environmental/Records (10%)
- **Pass mark:** 70 out of 100
