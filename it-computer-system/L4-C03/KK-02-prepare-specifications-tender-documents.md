**Tujuan / Objective:** Prepare a complete Request for Quotation (RFQ) document set for a given ICT procurement scenario, including technical specifications, compliance schedule, and evaluation criteria.

**Arahan:** Pelatih dikehendaki melaksanakan tugasan/kerja mengikut prosedur yang ditetapkan dalam kertas ini. Rujuk pensyarah sekiranya perlu penjelasan lanjut.

---

## Objektif / Objective

Using the approved Needs Assessment Report from KK(1/5), prepare a complete RFQ document set ready for issuance to at least 3 vendors.

---

## Tempoh / Duration

4 hours

---

## Peralatan dan Bahan / Equipment and Materials

| No. | Item | Quantity |
|-----|------|----------|
| 1 | Approved Needs Assessment Report (from KK-01) | 1 |
| 2 | RFQ document template (provided by instructor) | 1 |
| 3 | Technical Specification template | 1 |
| 4 | Supplier Compliance Checklist template | 1 |
| 5 | Computer with word processing and spreadsheet software | 1 |
| 6 | Reference: MAMPU Standard ICT Specification guidelines | 1 |

---

## Langkah Keselamatan / Safety Precautions

- All documents prepared are treated as official procurement documents — handle as confidential
- Do not copy specifications directly from a vendor's brochure or website (avoid proprietary bias)
- Save all files using the naming convention specified by instructor (e.g. RFQ-2026-C03-PRO001)

---

## Prosedur / Procedures

| Langkah | Arahan / Instruction |
|---------|---------------------|
| 1 | Open the RFQ template. Complete the cover page with the procurement reference number, issuing organisation (use simulated name provided by instructor), closing date (set 14 days from today), and submission instructions. |
| 2 | Write the Technical Specification section. For each item in the Needs Assessment Report, define: item name, quantity, and minimum 5 measurable technical parameters. Use performance-based language (e.g. "≥ 16 GB DDR5") rather than brand names. Include warranty and support requirements for each item. |
| 3 | Add a Compliance and Certification section. List all mandatory certifications the supplied equipment must carry (e.g. Energy Star, CE, SIRIM where applicable). Vendors must confirm compliance with each. |
| 4 | Complete the Quotation Submission Form template. This form requires vendors to fill in: item description, unit price, quantity, total price, delivery lead time, and warranty terms. Ensure the form has a column for vendor's authorised signature. |
| 5 | Prepare the Supplier Compliance Checklist. List every specification parameter from Step 2 in a table. Vendors must mark each as "Compliant / Non-compliant" and provide the model or reference confirming compliance. |
| 6 | Draft the Terms and Conditions section covering: delivery requirements, payment terms (30 days from acceptance), late delivery penalty, warranty obligations, and acceptance testing requirements. |
| 7 | Define the Evaluation Criteria section. State the weightage for: technical compliance (60%), price (30%), and vendor experience/support (10%). Explain that non-compliant items on mandatory specifications may result in disqualification. |
| 8 | Compile all sections into a single RFQ document. Verify completeness against the RFQ checklist below. Submit the complete document set to the instructor. |

---

## Hasil Jangkaan / Expected Outcome

A complete RFQ document set comprising:
- Completed cover page with all administrative details
- Technical Specification with measurable, technology-neutral parameters
- Compliance and certification requirements
- Quotation Submission Form for vendor pricing
- Supplier Compliance Checklist (column-by-column)
- Terms and Conditions
- Evaluation criteria with defined weightages
