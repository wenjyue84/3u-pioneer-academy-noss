## Kaedah Pengajaran / Teaching Method (4-Step)

### 1. PERSEDIAAN (Preparation)

| Langkah / Step | Aktiviti / Activity | Masa / Duration |
|----------------|---------------------|-----------------|
| 1.1 | Welcome trainees and take attendance | 5 min |
| 1.2 | State the learning objectives for the session | 5 min |
| 1.3 | Relate the topic to workplace context: why ICT procurement competency is essential at Level 4 | 10 min |
| 1.4 | Provide overview of the Information Sheet (KP) content and how it links to the Work Activity | 5 min |

### 2. PENYAMPAIAN (Presentation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 2.1 | Deliver theory content from the relevant KP using slides, worked examples, and real-world procurement scenarios |
| 2.2 | Explain the Malaysian government procurement regulatory framework: AP, Pekeliling Perbendaharaan, MOF thresholds, and MAMPU guidelines |
| 2.3 | Present case studies of procurement exercises — both compliant examples and examples of audit findings for non-compliance |
| 2.4 | Demonstrate document completion: walk through a Needs Assessment Report, a sample RFQ, a compliance matrix, and a procurement file structure using annotated sample documents |
| 2.5 | Discuss ethical obligations: conflict of interest, gifts prohibition under MACC Act 2009, consequences of non-disclosure |
| 2.6 | Encourage questions; correct common misconceptions (e.g. "lowest price always wins") |

### 3. PENGGUNAAN (Application)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 3.1 | Distribute the corresponding KT (Assignment Sheet) for the session |
| 3.2 | Trainees complete the assignment individually, applying the concepts from the KP |
| 3.3 | For KP(3/5) — Evaluation: conduct a structured group discussion on a case study evaluation scenario before the individual KT |
| 3.4 | Instructor provides guidance and support during the exercise; does not provide answers |
| 3.5 | Discuss answers and common errors with the class after submission |

### 4. PENGESAHAN (Confirmation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 4.1 | Review key learning points from the session |
| 4.2 | Conduct brief oral questioning to verify understanding of critical concepts (e.g. procurement thresholds, LD calculation, retention periods) |
| 4.3 | Collect completed KT for marking and feedback |
| 4.4 | Preview the next session topic |
| 4.5 | Record attendance and session completion |

## Topik Utama per KP / Key Topics per Information Sheet

| KP | Key Topics to Cover |
|----|---------------------|
| KP(1/5) | Procurement triggers; AP thresholds and methods; needs assessment 6-step process; functional vs non-functional requirements; budget approval levels; policy compliance (PDPA, MOF registration, Green procurement) |
| KP(2/5) | Characteristics of good specifications; technology-neutral language; RFQ vs ITT document structure; compliance checklist design; evaluation criteria and weightage; LD clause drafting |
| KP(3/5) | Pre-evaluation administrative checks; compliance matrix method; technical scoring; price scoring formula; vendor due diligence; combined score calculation; COI obligations under MACC Act 2009 |
| KP(4/5) | PO contents and issuance; pre-delivery preparation; GRN completion; physical inspection checklist; functional acceptance testing (FAT) items; discrepancy management; LD calculation; asset tagging and SPAS registration |
| KP(5/5) | Procurement file structure (8 sections); document retention requirements (7 years); physical vs digital records; Procurement Register maintenance; Procurement Closure Report structure; lessons learned |

## Penilaian Teori / Theory Assessment

Upon completion of all 5 KP/KT sessions, trainees will sit for the Knowledge Assessment (KA):
- **Code:** IT-020-4:2013-C03/KA
- **Duration:** 2 hours
- **Format:** Written examination (MCQ, short answer, essay/structured questions)
- **Pass mark:** 60 out of 100
