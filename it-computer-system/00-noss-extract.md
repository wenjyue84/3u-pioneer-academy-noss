- K4: Software maintenance — OS updates, antivirus definitions, event log review, SMART data
- K5: Maintenance report components — asset ID, tasks performed, parts used, sign-off

- K4: Hardware fault diagnosis — PSU multimeter checks, RAM Memtest86, SMART for storage
- K5: Computer status report — fault description, actions taken, parts used, test result

- K5: Server functionality testing — POST, network ping, service verification, handover report
