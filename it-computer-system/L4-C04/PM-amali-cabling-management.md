## Kaedah Pengajaran / Teaching Method (4-Step)

### 1. PERSEDIAAN (Preparation)

| Langkah / Step | Aktiviti / Activity | Masa / Duration |
|----------------|---------------------|-----------------|
| 1.1 | Welcome trainees; take attendance and verify PPE (safety glasses available for punch-down sessions) | 5 min |
| 1.2 | State the practical learning objectives for the session | 5 min |
| 1.3 | Review safety rules relevant to the session (punch-down safety; PTW awareness; cable bend radius) | 5 min |
| 1.4 | Distribute the KK (Work Sheet) and explain the exercise structure and expected outputs | 5 min |
| 1.5 | Verify all equipment, materials, and reference cards are available at each workstation | 5 min |

### 2. PENYAMPAIAN (Demonstration)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 2.1 | Demonstrate the practical task step-by-step as per the KK procedures |
| 2.2 | For KK(2/5): demonstrate correct cable stripping, pair untwist discipline, T568B punch-down sequence, and label application before termination |
| 2.3 | For KK(1/5) and KK(3/5): demonstrate how to annotate a floor plan, calculate cable counts, and update an as-built drawing revision table |
| 2.4 | For KK(4/5): demonstrate how to chair a pre-installation meeting and complete an NCR form |
| 2.5 | Show examples of correct and incorrect work: over-untwisted pairs, missing labels, incorrectly filled change request forms |
| 2.6 | Answer trainee questions before practical work begins |

### 3. PENGGUNAAN (Practice)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 3.1 | Trainees perform the practical task at their individual workstations or in pairs (KK(4/5) role-play) |
| 3.2 | Instructor circulates to observe, guide, and correct technique without performing the task for the trainee |
| 3.3 | Conduct brief oral questioning during practice: "Why do we minimise pair untwist?" / "What happens if the label is placed 300 mm from the termination?" |
| 3.4 | Trainees complete the KK assessment checklist as they progress through each step |

### 4. PENGESAHAN (Confirmation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 4.1 | Instructor checks each trainee's completed work against the assessment checklist |
| 4.2 | For KK(2/5): verify cable certification test result (PASS required before sign-off) |
| 4.3 | For KK(3/5): verify drawing revision table updated correctly; all new cable entries complete in schedule |
| 4.4 | Provide individual feedback covering: process followed, output quality, safety compliance, workspace cleanliness |
| 4.5 | Trainees clean and return all tools and materials; wire offcuts disposed of in waste container |
| 4.6 | Record session completion and any outstanding remediation required |

## Keselamatan / Safety Requirements

- Safety glasses MUST be worn during all punch-down termination operations
- Do not kink or overbend Cat6A cable — exceeding the minimum bend radius causes internal damage that cannot be detected visually
- Confirm with the instructor before disconnecting any cable from a patch panel — even in a training environment, simulate the safe-to-disconnect confirmation
- All wire offcuts must be collected immediately and disposed of in the designated waste container — loose offcuts on the floor are a puncture hazard
- For KK(4/5) role-play: when discussing PTW, trainees must articulate OSHA 1994 compliance as a mandatory legal requirement, not a procedural recommendation

## Penilaian Amali / Practical Assessment

Upon completion of all 5 KK sessions, trainees will sit for the Performance Assessment (PA):

- **Code:** IT-020-4:2013-C04/PA
- **Minimum duration:** 4 hours
- **Format:** Practical task — contractor inspection, patch panel termination, certification testing, record updating, as-built drawing revision, change completion report, pre-installation meeting agenda
- **Assessment criteria:** Process (30), Output (30), Attitude (15), Safety (15), Environmental (10) — total 100 marks; pass 60 marks

## Nota Pengajar / Instructor Notes

| Session | Key Instructor Actions |
|---------|----------------------|
| KK(1/5) — Planning exercise | Ensure floor plan scale is realistic (1:100 or 1:50 on A3). Walk through the cable count calculation with the class before individual work. Verify each trainee's TR distance measurement is along the pathway, not straight-line. |
| KK(2/5) — Termination practical | Demonstrate the complete termination sequence twice before trainees begin. Inspect each trainee's pair untwist before they punch down — correct at this stage rather than after. Do not allow trainees to proceed to testing until all 4 terminations have been visually inspected. |
| KK(3/5) — Records exercise | Provide the Rev A as-built and cable schedule at the start. Emphasise that the revision table must be filled in as part of the drawing update — a drawing with no revision table is non-compliant. |
| KK(4/5) — Coordination simulation | Brief the role-play carefully: the instructor playing the contractor should introduce one or two realistic complications (e.g. asking to substitute a material, arriving without a PTW) so trainees must respond correctly. |
| KK(5/5) — Change documentation | Emphasise the emergency change procedure: verbal approval is acceptable as a temporary measure but must be formalised in writing within 24 hours. Trainees who only record verbal approval as "complete" without the written follow-up should be corrected. |
