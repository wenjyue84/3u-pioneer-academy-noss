## Kaedah Pengajaran / Teaching Method (4-Step)

### 1. PERSEDIAAN (Preparation)

| Langkah / Step | Aktiviti / Activity | Masa / Duration |
|----------------|---------------------|-----------------|
| 1.1 | Welcome trainees and take attendance | 5 min |
| 1.2 | State the learning objectives for the session | 5 min |
| 1.3 | Relate the topic to workplace context (real cabling projects, industry standards) | 5 min |
| 1.4 | Provide an overview of the Information Sheet (KP) content for the session | 5 min |

### 2. PENYAMPAIAN (Presentation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 2.1 | Deliver theory content from the relevant KP using slides, diagrams, and real-world examples |
| 2.2 | Explain key technical terms in Malay and English: structured cabling (kabel berstruktur), horizontal cabling (kabel mendatar), telecommunications room (bilik telekomunikasi), as-built drawing (lukisan sebina bina), change request (permintaan perubahan) |
| 2.3 | Show relevant diagrams: structured cabling system topology, TR rack elevation, TIA-606-B label examples, cable count calculation worked examples |
| 2.4 | Discuss real consequences of poor cabling management: extended downtime, failed certification, regulatory issues |
| 2.5 | Reference the applicable standards throughout: ANSI/TIA-568.2-D, TIA-606-B, TIA-569-D, OSHA 1994 |
| 2.6 | Encourage questions; clarify misunderstandings immediately |
| 2.7 | Highlight safety considerations: PTW for installation work, OSHA 1994, firestop requirements |

### 3. PENGGUNAAN (Application)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 3.1 | Distribute the corresponding KT (Assignment Sheet) for the session |
| 3.2 | Trainees complete the assignment individually |
| 3.3 | Instructor provides guidance and clarification without giving direct answers |
| 3.4 | Discuss answers and common misconceptions with the class after individual work |

### 4. PENGESAHAN (Confirmation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 4.1 | Review key learning points from the session |
| 4.2 | Conduct brief oral questioning to verify understanding (2–3 questions per trainee) |
| 4.3 | Collect completed KT for marking and feedback |
| 4.4 | Preview the next session topic |
| 4.5 | Record attendance and session completion in the training log |

## Penilaian Teori / Theory Assessment

Upon completion of all 5 KP/KT sessions, trainees will sit for the Knowledge Assessment (KA):

- **Code:** IT-020-4:2013-C04/KA
- **Minimum duration:** 1 hour 30 minutes
- **Format:** Written test — Section A: MCQ (30 marks); Section B: Short Answer (30 marks); Section C: Essay (40 marks)
- **Pass mark:** 60% (60 marks out of 100)
- **Closed book:** No reference materials permitted

## Nota Pengajar / Instructor Notes

| Topic | Key Points to Emphasise |
|-------|------------------------|
| Cable distances | Students frequently confuse 90 m (permanent link) and 100 m (full channel). Reinforce the distinction at every opportunity |
| T568B wiring | Memorise the colour sequence: W/O, O, W/G, B, W/B, G, W/Br, Br. Practise recitation at start of each session |
| TIA-606-B labels | Show physical examples of correct and incorrect labels; students must understand why machine-printed labels are mandatory |
| Change management | Emphasise that verbal approvals and verbal change instructions are NOT acceptable — everything in writing |
| Contractor coordination | Discuss real-world consequences of poor coordination: warranty voided, regulatory non-compliance, unplanned outages |
| OSHA 1994 | Ensure all trainees understand that PTW is a legal requirement, not optional |
