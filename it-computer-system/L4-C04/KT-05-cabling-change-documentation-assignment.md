## Soalan / Questions

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (10 marks)

**A1.** The correct sequence for processing a routine cabling change is:

- (a) Execute the change → get approval → update records
- (b) Update records → execute the change → get approval
- (c) Submit change request → get approval → execute change → update records
- (d) Execute the change → submit change request → update records

**A2.** A "Move" cabling change refers to:

- (a) Installing a new cable where none existed before
- (b) Replacing a cable with a higher-category cable
- (c) Relocating an existing cable or device to a different position
- (d) Permanently removing a cable from service

**A3.** After an emergency cabling change is executed with verbal approval, full documentation must be completed within:

- (a) One week
- (b) One month
- (c) 24 hours
- (d) The next scheduled audit

**A4.** The Change Completion Report must include:

- (a) The contractor's invoice only
- (b) Summary of work, test results, records updated confirmation, and sign-off by IT administrator
- (c) Only the physical label photographs
- (d) A verbal summary to the IT manager

**A5.** What must happen to physical cable labels if an outlet is relocated and its ID changes?

- (a) The old labels may remain — the database is updated instead
- (b) New machine-printed labels must be applied at both cable ends and all termination points; old labels removed
- (c) Labels need only be updated at the patch panel end
- (d) Handwritten corrections to existing labels are acceptable

### Bahagian C: Soalan Esei / Essay (20 marks)

**C1.** A department in your organisation is undergoing a major reorganisation. Twenty workstations will be moved to new positions; 8 new workstations will be added; 5 workstations will be permanently removed.

Describe the complete change management process you would follow for this project, including: (a) how you would categorise and sequence the changes; (b) the documentation required before, during, and after the physical work; (c) how the cable schedule, as-built drawings, and labels will be updated; (d) what the change log and change completion reports will contain. (20 marks)
