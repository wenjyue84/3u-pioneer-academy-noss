## Huraian Kandungan Teori / Theory Content Outline

### KP(1/4) — 18 Hours: Analyse Computer Network Set-Up Specification

| Session | Topics | Hours |
|---------|--------|-------|
| 1 | Introduction to network installation management; role of the Level 4 Network Administrator; overview of CoCU 5 | 3.0 |
| 2 | Network specification document structure; reading and interpreting specification documents; completeness checklist | 3.0 |
| 3 | Network topology analysis: star, hierarchical, mesh, hybrid; topology selection criteria; scalability considerations | 3.0 |
| 4 | Cabling specification analysis: copper categories (Cat5e–Cat7), fibre types (OM3, OM4, OS2); TIA-568 and ISO 11801 standards; cable run length calculations | 3.0 |
| 5 | Equipment specification: switches, routers, access points, UPS, patch panels; compatibility verification | 3.0 |
| 6 | Site survey planning and execution; Gap and Risk Register preparation; business requirements analysis | 3.0 |

### KP(2/4) — 18 Hours: Plan Computer Network Installation

| Session | Topics | Hours |
|---------|--------|-------|
| 7 | Introduction to project planning; project plan components; planning tools overview | 3.0 |
| 8 | Bill of Quantities (BoQ): structure, quantity take-off process, waste allowances, cost estimation | 3.0 |
| 9 | Work Breakdown Structure (WBS): decomposition principles, WBS levels, WBS codes, work packages | 3.0 |
| 10 | Project scheduling: Gantt chart development, dependencies, critical path identification, milestones, float | 3.0 |
| 11 | Resource planning: roles and responsibilities, resource allocation, resource levelling | 3.0 |
| 12 | Procurement planning: lead times, vendor selection, purchase order process; risk management plan | 3.0 |

### KP(3/4) — 22.5 Hours: Manage Computer Network Installation Work

| Session | Topics | Hours |
|---------|--------|-------|
| 13 | Overview of installation management; site supervisor role; transition from planning to execution | 3.0 |
| 14 | Supervising cabling installation: copper cable routing, bend radius, conduit fill, separation standards, labelling | 3.0 |
| 15 | Supervising termination: Cat6A untwist limits, TIA-568-B wiring order, fibre connector types | 3.0 |
| 16 | Supervising active equipment installation: rack mounting, cable management, earthing, ventilation, PoE load | 3.0 |
| 17 | Contractor management: induction, performance monitoring, NCR process, escalation | 3.0 |
| 18 | Progress monitoring: progress measurement metrics, Earned Value Management (EVM) basics, weekly progress reporting | 4.5 |
| 19 | Acceptance testing: copper cable certification (TIA-568 parameters), fibre testing, network connectivity testing, UAT process | 3.0 |

### KP(4/4) — 13.5 Hours: Produce the Network Installation Management Report

| Session | Topics | Hours |
|---------|--------|-------|
| 20 | Report purpose and audience; report sections overview; as-built documentation requirements | 3.0 |
| 21 | Writing the Executive Summary; Installation Summary; Test Results Summary; professional language and formatting standards | 4.5 |
| 22 | Handover documentation: equipment register, warranty summary, credential management, maintenance schedule, network diagrams | 3.0 |
| 23 | Issues and Non-Conformances section; change control documentation; report version control; sign-off procedures | 3.0 |

## Kaedah Pengajaran / Teaching Method (4-Step)

### 1. PERSEDIAAN (Preparation)

| Langkah / Step | Aktiviti / Activity | Masa / Duration |
|----------------|---------------------|-----------------|
| 1.1 | Welcome trainees; take attendance | 5 min |
| 1.2 | State the learning objectives for the session (from the relevant KP) | 5 min |
| 1.3 | Link the current topic to previous sessions and real workplace scenarios | 5 min |
| 1.4 | Provide a brief overview of the session structure and the KP content to be covered | 5 min |

### 2. PENYAMPAIAN (Presentation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 2.1 | Deliver theory content from the relevant KP using slides, diagrams, and real-world examples |
| 2.2 | Explain key terms in both English and Bahasa Malaysia; define abbreviations on first use |
| 2.3 | Show network topology diagrams, cabling standard tables, BoQ examples, Gantt chart examples, and report templates |
| 2.4 | Use case studies: present a real (or realistic) network installation project; walk through each management decision |
| 2.5 | Highlight common mistakes and their consequences (e.g., unresolved gaps in specification, no change control, missing as-built documentation) |
| 2.6 | Encourage questions; use Socratic questioning to check understanding |

### 3. PENGGUNAAN (Application)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 3.1 | Distribute the corresponding KT (Assignment Sheet) for the session |
| 3.2 | Trainees complete the assignment individually |
| 3.3 | Instructor circulates to observe, guide, and provide targeted support |
| 3.4 | Discuss common errors and share model answers with the class |

### 4. PENGESAHAN (Confirmation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 4.1 | Review the key learning points from the session |
| 4.2 | Conduct brief oral questioning (2–3 questions) to verify comprehension |
| 4.3 | Collect completed KT for marking; return with written feedback in the next session |
| 4.4 | Preview the next session topic |
| 4.5 | Record attendance and session completion in the register |

## Penilaian Teori / Theory Assessment

Upon completion of all 4 KP/KT sessions, trainees will sit for the Knowledge Assessment (KA):

- **Code:** IT-020-4:2013-C05/KA
- **Duration:** 1 hour 30 minutes
- **Format:** Written examination — Section A (MCQ, 30 marks), Section B (Short Answer, 30 marks), Section C (Essay, 40 marks)
- **Pass mark:** 60% (60/100)
- **Reference:** Closed book; no reference materials permitted
