## Arahan kepada Pelatih / Instructions to Trainee

1. This is a PRACTICAL examination covering all four (4) Work Activities of CoCU 5.
2. You will be assessed across four tasks corresponding to each Work Activity.
3. You will be assessed on: **Process** (how you work), **Output** (the quality of deliverables), **Attitude** (professionalism and independence), **Safety** (site and personal safety compliance), and **Environmental** compliance.
4. All work must be completed within the total allocated time.
5. Submit all documentation produced during the assessment to the assessor at the end of each task phase.

## Senario Tugasan / Task Scenario

**Scenario:** You are a Level 4 Network Administrator for Syarikat Teknologi Sepadu Bhd. You have been assigned to manage the installation of a computer network for a client — a 2-storey office building with 60 network points total (35 on Floor 1, 25 on Floor 2). The project has 4 phases corresponding to the 4 Work Activities of CoCU 5. You will complete one representative task for each phase under timed conditions.

---

## Tugasan 1: Analyse the Network Set-Up Specification (Work Activity 1)

**Time allowed: 45 minutes**

The assessor will provide you with a 4-page simulated network installation specification for the above scenario. You must:

1. Read and review the specification using the Specification Review Checklist
2. Conduct a site walk-through of the designated training lab area (simulates the client site); record cable run measurements for at least 5 runs on the Cable Measurement Worksheet
3. Complete a Gap and Risk Register identifying at least 4 gaps or risks
4. Prepare a one-page Gap Notification Memo addressed to the client's project manager

**Deliverables:** Completed Specification Review Checklist, Cable Measurement Worksheet, Gap and Risk Register, Gap Notification Memo

---

## Tugasan 2: Plan the Network Installation (Work Activity 2)

**Time allowed: 60 minutes**

Based on the approved specification (with gaps resolved by the assessor), you must:

1. Prepare a Bill of Quantities (BoQ) covering Active Equipment, Passive Infrastructure, Power, Labour, and Miscellaneous sections — with at least 3 items per section and estimated quantities
2. Develop a Work Breakdown Structure (WBS) with at least 3 levels
3. Prepare a simplified 8-week project schedule (Gantt chart) showing major phases, dependencies, and 2 milestones
4. Prepare a resource plan identifying roles, numbers, and durations for each project phase

**Deliverables:** BoQ, WBS, Gantt chart, Resource Plan

---

## Tugasan 3: Manage Network Installation Work (Work Activity 3)

**Time allowed: 90 minutes**

The assessor will prepare the training lab with 10 pre-installed cable runs and at least 4 intentional workmanship deficiencies. You must:

1. Conduct a site inspection; complete the Site Inspection Checklist; issue NCR forms for all deficiencies found (minimum 3)
2. The assessor will present a Change Request (client wants 4 additional points in a new storage room). You must complete the CR form, assess the impact, and prepare a draft Variation Order
3. Test at least 5 of the 10 installed cable runs using the provided cable certification tester; record results on the Cable Test Record
4. Perform network connectivity tests (DHCP, ping to gateway, internet access) from one access port; record results on the Connectivity Test Record

**Deliverables:** Site Inspection Checklist, minimum 3 NCR forms, Change Request form, draft Variation Order, Cable Test Record (5 runs), Connectivity Test Record

---

## Tugasan 4: Produce the Network Installation Management Report (Work Activity 4)

**Time allowed: 60 minutes**

Using all deliverables produced in Tasks 1–3, you must produce a structured Network Installation Management Report containing:

1. Cover Page
2. Executive Summary (maximum 1 page for this exercise)
3. Installation Summary (cabling and equipment summary)
4. Test Results Summary (from Task 3 cable and connectivity tests)
5. Issues and Non-Conformances (transfer NCRs and VO from Task 3)
6. Handover Documentation section (equipment register with at least 4 items; maintenance schedule; spares recommendation)
7. Conclusion with sign-off table

**Deliverable:** Printed or handwritten Network Installation Management Report (all 7 sections)
