## Soalan / Questions

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (20 marks — 4 marks each)

**A1.** In a Bill of Quantities (BoQ), a 10% waste allowance is added to cable quantities because:

- (a) The supplier always delivers 10% less than ordered
- (b) Allowance is needed for cable routing, service loops at both ends, and cuts during installation
- (c) TIA-568 requires a 10% additional length per cable run
- (d) The quality assurance process consumes 10% of all cable

**A2.** The purpose of a Work Breakdown Structure (WBS) is to:

- (a) List all the tools needed for the installation
- (b) Decompose the total project scope into manageable, uniquely identified work packages
- (c) Show the timeline of the project in a calendar format
- (d) Assign costs to each team member

**A3.** On a Gantt chart, the critical path is:

- (a) The shortest route between the MDF and the furthest network outlet
- (b) The longest chain of dependent tasks; any delay on these tasks delays the overall project completion
- (c) The list of tasks that have the most float (slack)
- (d) The path that the cable crew takes through the building during installation

**A4.** A Variation Order (VO) is required when:

- (a) The project is completed ahead of schedule
- (b) A contractor requests to change the brand of equipment
- (c) The scope of work changes from the approved BoQ or specification, and additional or changed work must be authorised
- (d) The network administrator leaves the project

**A5.** When planning resource allocation, "resource levelling" means:

- (a) Ensuring all network cables are laid at the same horizontal level
- (b) Adjusting task timing so that no single resource is over-allocated at any point in time
- (c) Assigning the same number of resources to every project phase
- (d) Levelling the floor surface in the server room

### Bahagian B: Soalan Jawapan Pendek / Short Answer (30 marks)

**B1.** A network installation project has the following cable runs (horizontal measurement only, before routing allowance):

| Run ID | From | To | Measured Length (m) |
|--------|------|----|---------------------|
| H-001 | IDF-1, Port 1 | Room 101, Outlet A | 42 |
| H-002 | IDF-1, Port 2 | Room 105, Outlet B | 67 |
| H-003 | IDF-1, Port 3 | Room 112, Outlet C | 78 |

(a) Apply a 20% routing allowance to each run and calculate the routed length. (3 marks)

(b) For each run, verify whether the routed length is within the permanent link limit of 90 m (the remaining 10 m is reserved for patch cords). State which runs are acceptable and which require action. (3 marks)

(c) For any run that exceeds the permanent link limit, state TWO (2) options available to the network administrator. (4 marks)

**B2.** Explain Earned Value Management (EVM) at a basic level. Define: Planned Value (PV), Earned Value (EV), and Actual Cost (AC). If a project has PV = RM 50,000, EV = RM 40,000, and AC = RM 45,000, calculate the Schedule Variance (SV) and Cost Variance (CV). What does the result tell you about the project? (10 marks)

**B3.** List FOUR (4) common risks in a network installation project and for each risk, state one mitigation action. (10 marks)

### Bahagian C: Soalan Esei / Essay (50 marks)

**C1.** You are planning a network installation for a two-storey office building with the following scope:

- 120 network points total (70 on Floor 1, 50 on Floor 2)
- 1 MDF on Ground Floor; 2 IDFs (one per floor)
- Active equipment: 1 core switch (Layer 3), 2 distribution switches (48-port PoE+), 15 wireless access points
- Cabling: Cat6A UTP for horizontal runs; OM3 fibre for MDF-to-IDF backbone
- Project duration: 10 weeks

(a) Prepare a BoQ outline for this project. You are NOT required to provide exact quantities or prices, but you must list all the BoQ sections and at least THREE (3) line items per section (Active Equipment, Passive Infrastructure, Power, Labour, Miscellaneous). For each line item, state the unit of measurement. (20 marks)

(b) Describe how you would develop the project schedule using the Work Breakdown Structure (WBS) and Gantt chart approach. List the major phases (Level 2 WBS) for this project and for each phase, state: (i) the key activities within that phase; (ii) the dependencies on other phases; and (iii) the estimated duration. (20 marks)

(c) The client informs you that the fibre backbone equipment (core switch and distribution switches) has a delivery lead time of 8 weeks from the date of purchase order. The project start date is fixed. Explain how this lead time constraint affects your schedule, and describe the specific actions you would take during the first two weeks of the project to manage this constraint. (10 marks)
