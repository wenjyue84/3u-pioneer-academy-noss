## Huraian Kandungan Amali / Practical Content Outline

### KK(1/4) — 42 Hours: Analysing a Computer Network Set-Up Specification

| Session | Practical Activities | Hours |
|---------|---------------------|-------|
| P1 | Introduction to the training lab as a simulated site; familiarisation with specification documents; practise reading and annotating a specification | 6.0 |
| P2 | Practise using the Specification Review Checklist on progressively more complex simulated specifications; peer review exercise | 6.0 |
| P3 | Site walk-through exercise: measure cable runs using measuring tape; record on cable schedule; practise applying routing allowances | 6.0 |
| P4 | Complete site survey using the Site Survey Checklist for the training lab environment; identify physical constraints | 6.0 |
| P5 | Gap and Risk Register completion exercise: individual and group exercises using different simulated specifications | 9.0 |
| P6 | Gap Notification Memo writing: practise formal professional memo format; peer review and instructor feedback | 6.0 |
| P7 | Integrated exercise: full specification analysis from receipt to completed gap register and memo; timed practice (KK-01 format) | 9.0 |

### KK(2/4) — 42 Hours: Planning a Computer Network Installation

| Session | Practical Activities | Hours |
|---------|---------------------|-------|
| P8 | BoQ preparation exercise: practise quantity take-off from floor plans; calculate cable and conduit quantities with waste allowance | 9.0 |
| P9 | BoQ costing: obtain unit rates from instructor-provided price list; complete BoQ totals including contingency; verify cross-totals | 6.0 |
| P10 | WBS development: decompose a sample project into WBS levels; assign WBS codes; verify completeness of scope coverage | 6.0 |
| P11 | Gantt chart development: plot phases from WBS; draw dependencies; identify critical path; mark milestones | 9.0 |
| P12 | Resource planning: assign roles to phases; calculate resource-days; check for over-allocation; apply resource levelling | 6.0 |
| P13 | Procurement planning: identify long-lead items; calculate order dates from project start; practise writing a procurement action list | 6.0 |

### KK(3/4) — 54 Hours: Supervising and Acceptance Testing a Network Installation

| Session | Practical Activities | Hours |
|---------|---------------------|-------|
| P14 | Site inspection practise: instructor prepares lab with controlled deficiencies (wrong cable type, excessive bend radius, unlabelled cables); trainees inspect and document | 9.0 |
| P15 | NCR writing exercise: trainees practise writing clear, specific, actionable NCRs from their inspection observations; peer review | 6.0 |
| P16 | Change Request and Variation Order practise: instructor presents 3 different change scenarios; trainees complete CR forms, assess impact, draft VOs | 6.0 |
| P17 | Progress monitoring exercise: given project data (actual vs planned), calculate progress percentage; identify schedule variance; practise weekly progress reporting | 6.0 |
| P18 | Cable certification tester familiarisation: instructor demonstrates Fluke tester setup, test execution, and result interpretation; trainees repeat demonstration | 6.0 |
| P19 | Cable certification testing practise: trainees test assigned cable runs; record results; identify FAIL causes; document corrective actions | 9.0 |
| P20 | Network connectivity testing: practise DHCP verification, ping tests, VLAN isolation testing, wireless signal measurement; complete Connectivity Test Record | 6.0 |
| P21 | UAT simulation: trainee acts as network administrator; instructor acts as client representative; trainee demonstrates the working network and presents test results | 6.0 |

### KK(4/4) — 30 Hours: Producing the Network Installation Management Report

## Kaedah Pengajaran / Teaching Method (4-Step)

### 1. PERSEDIAAN (Preparation)

| Langkah / Step | Aktiviti / Activity | Masa / Duration |
|----------------|---------------------|-----------------|
| 1.1 | Welcome trainees; take attendance; verify any required PPE for the session | 5 min |
| 1.2 | State the practical learning objectives for the session | 5 min |
| 1.3 | Review safety rules relevant to the session (site safety, equipment handling, electrical) | 5 min |
| 1.4 | Distribute the KK (Work Sheet) and explain the exercise structure and expected outcomes | 5 min |
| 1.5 | Verify that all equipment, tools, templates, and simulated materials are available at each workstation | 5 min |

### 2. PENYAMPAIAN (Demonstration)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 2.1 | Demonstrate the practical task step-by-step as per the KK procedures |
| 2.2 | Show correct technique and explicitly demonstrate common errors (e.g., how not to do it) with explanation of consequences |
| 2.3 | Walk through the expected deliverable (e.g., show a completed BoQ, a completed NCR form, a cable test record) |
| 2.4 | Answer all questions before trainees begin their own work |

### 3. PENGGUNAAN (Practice)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 3.1 | Trainees perform the practical task at their individual workstations or in pairs as directed |
| 3.2 | Instructor circulates continuously to observe technique, give targeted guidance, and ask oral questions |
| 3.3 | Trainees complete the KK assessment checklist as they complete each step |
| 3.4 | Instructor notes observations for feedback |

### 4. PENGESAHAN (Confirmation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 4.1 | Instructor checks each trainee's completed deliverable against the KK assessment checklist |
| 4.2 | Verify the expected outcome is achieved (e.g., gap register complete, BoQ balanced, test results recorded correctly) |
| 4.3 | Provide feedback: strengths, specific errors, and improvement actions |
| 4.4 | Trainees clean up workstations; return tools, equipment, and templates to storage |
| 4.5 | Record session completion and any issues in the session register |

## Keselamatan / Safety Requirements

- Wear appropriate footwear and hi-visibility vest during site inspection simulation exercises
- Do not connect test equipment to active network ports without confirming with the instructor that the port is isolated or set to a safe VLAN
- Handle all laboratory network equipment carefully; do not force connectors or remove equipment from racks without instruction
- Report any cable or equipment damage to the instructor immediately — do not attempt to repair damage without authorisation
- E-waste (failed cables, old patch cords, packaging) must be disposed of through the institution's authorised recycling or disposal process

## Penilaian Amali / Practical Assessment

Upon completion of all 4 KK sessions, trainees will sit for the Performance Assessment (PA):

- **Code:** IT-020-4:2013-C05/PA
- **Total duration:** 4 hours 15 minutes (255 minutes across 4 tasks: 45 + 60 + 90 + 60 minutes)
- **Format:** Integrated practical assessment — Specification Analysis, Planning, Installation Management, and Report Production
- **Assessment criteria:** Process (30), Output (30), Attitude (15), Safety (15), Environmental (10) — Total 100 marks
- **Pass mark:** 60 / 100
