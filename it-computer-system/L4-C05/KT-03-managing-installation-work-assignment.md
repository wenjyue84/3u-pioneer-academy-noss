## Soalan / Questions

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (20 marks — 4 marks each)

**A1.** During a site inspection, the administrator finds that Cat6A cable is installed with an untwist length of approximately 25 mm at a patch panel punch-down point. The correct action is:

- (a) Accept the termination — 25 mm is within TIA-568 tolerance
- (b) Issue a Non-Conformance Report (NCR) and require the contractor to re-terminate to within 13 mm
- (c) Re-terminate the cable personally without informing the contractor
- (d) Note the observation but take no action unless the cable fails testing

**A2.** A contractor requests to change the conduit routing for Floor 2 because a structural beam blocks the original route. The network administrator's correct first action is:

- (a) Allow the contractor to proceed verbally and update the drawings later
- (b) Reject the request — changes to the approved design are not permitted
- (c) Ask the contractor to raise a formal Change Request (CR) form; assess the cost and schedule impact before approving
- (d) Contact the client and ask them to resolve it

**A3.** Cable certification testing using a Fluke DSX-8000 is performed to:

- (a) Test the network speed between two computers
- (b) Verify that the installed copper cabling meets the TIA-568 performance standard (wire map, length, insertion loss, NEXT, etc.)
- (c) Configure the IP addresses on each network port
- (d) Check the power consumption of PoE devices

**A4.** During a User Acceptance Test (UAT), the client's representative finds that one office area has no wireless signal. The network administrator's correct action is:

- (a) Inform the client that this area was not in the original specification
- (b) Issue a Variation Order to add a new access point, obtain approval, and schedule the additional work
- (c) Move the nearest access point to cover the affected area immediately without documentation
- (d) Ask the client to relocate their desks to an area with coverage

**A5.** The purpose of issuing a Non-Conformance Report (NCR) to a contractor is to:

- (a) Record the contractor's performance rating for future reference only
- (b) Formally document a quality or safety deficiency and require the contractor to take corrective action by a stated deadline
- (c) Terminate the contractor's appointment
- (d) Inform the client that the project is delayed

### Bahagian B: Soalan Jawapan Pendek / Short Answer (30 marks)

**B1.** During a cable certification test of 50 network points, the following results are obtained:

| Test Category | Total Points Tested | PASS | FAIL |
|--------------|---------------------|------|------|
| Wire map | 50 | 48 | 2 |
| Length | 50 | 50 | 0 |
| Insertion loss | 50 | 50 | 0 |
| NEXT | 50 | 49 | 1 |
| Overall (all parameters must pass) | 50 | 47 | 3 |

(a) Calculate the overall pass rate (%). (2 marks)

(b) State the minimum acceptable NEXT value at 500 MHz for a Cat6A channel test (TIA-568). (2 marks)

(c) For the 2 wire map failures: describe TWO (2) possible causes of a wire map failure, and the corrective action for each. (6 marks)

**B2.** Describe the step-by-step process a network administrator must follow when a contractor's team fails to meet a workmanship quality standard during installation. Include: how the deficiency is documented, how it is communicated to the contractor, what the deadline for corrective action should be, and what escalation path exists if the contractor does not rectify. (10 marks)

**B3.** List FIVE (5) items that must be checked during the supervision of copper cable termination at a patch panel. For each item, state the specific standard or requirement that applies. (10 marks)

### Bahagian C: Soalan Esei / Essay (50 marks)

**C1.** You are supervising the network installation for a 4-storey office building. At Week 6 of a 10-week project, you conduct a progress review and discover the following:

- Only 65% of cable points have been installed and labelled (against a plan of 85%)
- The contractor's cable crew has been reduced from 4 persons to 2 persons due to another project commitment
- Three NCRs have been issued (untwist length violations); two have been resolved and one remains open
- The client has requested 8 additional network points in a newly partitioned boardroom (not in original specification)
- Cable certification testing has not yet commenced (planned to start at Week 6)

(a) Analyse the project status. For each of the five issues above, state whether it represents a scope issue, a schedule issue, a quality issue, or a resource issue. (10 marks)

(b) Prepare a corrective action plan addressing ALL five issues. For each issue: state the corrective action, who is responsible, and the target completion date (expressed as a project week). (20 marks)

(c) Draft a Weekly Progress Report for this project for Week 6. The report must include: (i) summary of work completed; (ii) comparison of actual vs planned progress; (iii) issues and actions; (iv) anticipated status for Week 7. Write in formal English or Bahasa Malaysia as directed by your instructor. (20 marks)
