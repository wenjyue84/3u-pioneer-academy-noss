## BAHAGIAN A: SOALAN PELBAGAI PILIHAN / SECTION A: MULTIPLE CHOICE (30 marks)

Answer all 15 questions. Each question carries 2 marks. Circle the correct answer.

**1.** The first step in the network installation management process is to:

- (a) Order all network equipment from the supplier
- (b) Analyse the network installation specification to verify its completeness and accuracy
- (c) Brief the installation contractor on site safety
- (d) Prepare the Bill of Quantities

**2.** Which cabling standard applies to the installation and testing of balanced twisted-pair telecommunications cabling?

- (a) IEEE 802.11ax
- (b) ISO/IEC 11801
- (c) TIA-568
- (d) IEEE 802.3af

**3.** The maximum channel length for Cat6A copper cabling as specified by TIA-568 is:

- (a) 55 metres
- (b) 75 metres
- (c) 90 metres
- (d) 100 metres

**4.** A Bill of Quantities (BoQ) is used to:

- (a) Record the names of all project team members
- (b) List all materials, equipment, and labour items with quantities and estimated costs for a project
- (c) Track the number of days each contractor works on site
- (d) Document the IP addressing plan for the network

**5.** In a Gantt chart, the critical path is important because:

- (a) It shows which tasks can be delayed without affecting the project end date
- (b) It identifies the longest chain of dependent tasks — any delay on these tasks delays the overall project
- (c) It shows the fastest route through the building for cable installation
- (d) It lists all tasks in alphabetical order

**6.** The minimum separation distance between a Cat6A data cable and a parallel power cable (in the same conduit run) is:

- (a) 50 mm
- (b) 100 mm
- (c) 200 mm
- (d) 500 mm

**7.** A Non-Conformance Report (NCR) is issued to a contractor when:

- (a) The contractor completes work ahead of schedule
- (b) A workmanship quality or safety deficiency is identified that requires formal documentation and corrective action
- (c) The contractor requests a change to the approved scope
- (d) The client changes the project deadline

**8.** During copper cable termination at a patch panel, the maximum untwist length for Cat6A cable is:

- (a) 5 mm
- (b) 13 mm
- (c) 25 mm
- (d) 50 mm

**9.** The Fluke DSX-8000 cable certification tester is used to verify:

- (a) The IP connectivity between two computers on the network
- (b) The power consumption of PoE devices
- (c) That installed copper cabling meets TIA-568 performance parameters (wire map, length, NEXT, insertion loss, etc.)
- (d) The wireless signal strength in each room

**10.** "As-built documentation" differs from the original specification because it:

- (a) Is written in a different language
- (b) Documents the network as it was actually installed, including any approved variations from the original design
- (c) Is prepared by the contractor, not the network administrator
- (d) Contains only the financial summary of the project

**11.** A Variation Order (VO) must be signed before additional work commences because:

- (a) The contractor cannot work on weekends without a VO
- (b) It formally authorises the additional scope change and protects both parties from disputes over cost and scope
- (c) TIA-568 requires a VO for all network installation work
- (d) The JPK requires a VO for all NOSS training projects

**12.** Which of the following is a key item in the handover documentation provided to the client at project completion?

- (a) The contractor's payroll records
- (b) The original design specification only
- (c) Equipment register (brand, model, serial number, firmware version, warranty expiry) and as-built network diagrams
- (d) The network administrator's personal curriculum vitae

**13.** The Executive Summary of a Network Installation Management Report is intended primarily for:

- (a) The installation contractor for future reference
- (b) Senior management and the client's leadership — it is non-technical and concise (maximum 2 pages)
- (c) The JPK assessor only
- (d) The equipment suppliers

**14.** The maximum conduit fill ratio for copper data cables is:

- (a) 20%
- (b) 40%
- (c) 60%
- (d) 80%

**15.** User Acceptance Testing (UAT) is conducted:

- (a) Before any cable is installed
- (b) Immediately after the BoQ is approved
- (c) After all technical tests are passed, to demonstrate the working network to the client's representative and obtain sign-off
- (d) Only if the project is delayed

## BAHAGIAN C: SOALAN ESEI / SECTION C: ESSAY (40 marks)

Answer all 2 questions.

**21.** You are a Level 4 Network Administrator managing the installation of a network for a 3-storey office building. At the end of Week 5 of a 9-week project, you discover the following situation:

- Cable installation progress: 55% complete (planned: 75%)
- The installation contractor has 3 outstanding NCRs, of which 1 has been unresolved for 10 days (the deadline was 5 days)
- The client has verbally requested 10 additional network points on Floor 3 "as soon as possible"
- Two distribution switches have not yet arrived (delivery lead time was underestimated)

(a) For each of the four issues above, identify the type of problem (scope / schedule / quality / procurement) and describe the specific management action you would take as the network administrator. (16 marks)

(b) Describe the process for handling the client's request for 10 additional network points. Include: how the request is formally raised; how the cost and schedule impact is assessed; how approval is obtained; and how the work is authorised to the contractor. (12 marks)

(c) Prepare an outline of the weekly progress report you would submit to management at the end of Week 5, covering all four issues. You do not need to write the full report — list the section headings and the key points that would appear under each heading. (12 marks)

**22.** You have completed a network installation project and are preparing the final Network Installation Management Report for handover to the client.

(a) List ALL nine (9) sections of the report (as per KP(4/4)) and for each section, write two sentences explaining its purpose and the key information it contains. (18 marks)

(b) Explain why as-built documentation is considered the most operationally critical element of the handover package for the client's IT operations team. Give THREE (3) specific examples of operational problems that would arise if the as-built documentation is missing or inaccurate. (10 marks)

(c) The client's representative refuses to sign the Network Installation Acceptance Certificate, stating that "two rooms on Floor 2 have poor wireless coverage." Describe the steps you would take to resolve this issue professionally, including: how you would investigate; what documentation you would refer to; what options are available depending on whether the coverage requirement was or was not in the original specification; and how you would reach a formal resolution. (12 marks)
