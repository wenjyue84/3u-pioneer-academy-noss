## Soalan / Questions

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (20 marks — 4 marks each)

**A1.** The primary purpose of the Executive Summary in a Network Installation Management Report is to:

- (a) Provide detailed technical specifications of all installed equipment
- (b) Present a concise, non-technical overview of the project outcome for senior management and the client's leadership
- (c) Replace the cable certification test reports
- (d) List all the variations and change orders in detail

**A2.** "As-built documentation" refers to:

- (a) The original installation specification submitted before work commenced
- (b) Records that document the network exactly as it was physically installed, including any approved deviations from the original design
- (c) The building's architectural drawings
- (d) The contractor's invoice for completed works

**A3.** The Equipment Register in the handover documentation must include:

- (a) Only the brand names of all installed equipment
- (b) Brand, model, serial number, MAC address, IP address, firmware version, and warranty expiry for all active equipment
- (c) The purchase prices of all equipment
- (d) The names of the technicians who installed each device

**A4.** A network installation management report must include the cable certification test reports because:

- (a) It is required by the Income Tax Act
- (b) They provide objective, instrument-measured evidence that the cabling infrastructure meets the specified performance standard
- (c) The contractor requires them to submit a claim
- (d) They are needed to order replacement cables

**A5.** Version control in report writing means:

- (a) Controlling the number of copies printed
- (b) Tracking changes to the report with version numbers, dates, authors, and a description of changes, so that the most current approved version is always identifiable
- (c) Limiting who can read the report
- (d) Saving the report in multiple file formats

(a) As-built floor plan (3 marks)

(b) Equipment serial numbers in the equipment register (3 marks)

(c) Credential register (usernames and passwords for managed devices) (3 marks)

(d) Cable certification test reports (3 marks)

### Bahagian C: Soalan Esei / Essay (50 marks)

**C1.** You have just completed the installation of a network for a 2-storey factory. The project details are as follows:

- Client: Syarikat Logistik Mutiara Sdn Bhd, No. 12, Jalan Perindustrian 5, Senai, Johor
- Project reference: NW-2026-007
- Scope: 96 network points (Cat6A), 2 racks, 4 switches (PoE+), 12 wireless access points, 1 firewall, fibre backbone between floors (OM3)
- Duration: Planned 8 weeks; Actual 9 weeks (1-week delay due to conduit rerouting — Variation Order VO-001 approved)
- Cable test results: 96 points tested; 94 PASS on first test; 2 FAIL (re-terminated and re-tested; final result: 96/96 PASS)
- Network connectivity: All tests passed
- Variation: VO-001 — conduit rerouting on Floor 1 due to structural beam obstruction; additional cost RM 1,800; approved by client

(a) Write a complete Executive Summary for the above project. The summary must not exceed TWO (2) pages and must be suitable for the client's Managing Director, who is not a technical person. (20 marks)

(b) Prepare the Issues and Non-Conformances section for this report. Include the 2 cable test failures (as NCRs) and the Variation Order, presented in the standard issues table format (Item, Description, Action Taken, Status). (10 marks)

(c) Prepare the Handover Documentation section for this project. You do not need to provide actual equipment serial numbers or IP addresses — use realistic placeholder values (e.g., "SW-CORE-001", IP 192.168.10.1). Include: equipment register (at least 5 equipment items), recommended maintenance schedule, and spares recommendation. (20 marks)
