## Soalan / Questions

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (20 marks — 4 marks each)

**A1.** A network installation specification document is analysed BEFORE planning commences because:

- (a) It is a legal requirement under Malaysian law
- (b) Errors identified at the specification stage cost less to correct than errors identified during or after installation
- (c) The contractor requires it before submitting a quotation
- (d) The IT department cannot issue a purchase order without it

**A2.** A site survey is conducted to:

- (a) Verify that the physical conditions of the site match the assumptions in the specification document
- (b) Count the number of existing network cables already installed
- (c) Determine the cost of the project
- (d) Identify which contractor should be appointed

**A3.** The maximum copper cable channel length specified by TIA-568 for Cat6A is:

- (a) 50 metres
- (b) 75 metres
- (c) 90 metres
- (d) 100 metres

**A4.** A Gap in a network specification refers to:

- (a) A physical space in the server room that is not occupied by equipment
- (b) A specification element that is missing, incomplete, or insufficiently detailed
- (c) The difference between the planned and actual number of network points
- (d) The distance between two distribution switches

**A5.** When the maximum conduit fill ratio of 40% is exceeded, the consequence is:

- (a) The cables will carry less data
- (b) Cables cannot be pulled through the conduit without risk of damage; heat build-up may also occur
- (c) The conduit will fail the TIA-568 standard test
- (d) Additional cable certification is required

### Bahagian B: Soalan Jawapan Pendek / Short Answer (30 marks)

**B1.** List FIVE (5) sections that must be present in a complete network installation specification document, and for each section, state what information it should contain. (10 marks)

**B2.** Explain the difference between a GAP, a RISK, and an ASSUMPTION in the context of a Gap and Risk Register. Give one example of each for a network installation project. (9 marks)

**B3.** A network administrator measures a proposed cable run from the patch panel in IDF-1 to a network outlet in Room 215 as 84 metres (straight-line measurement along the intended conduit route). The specification states that Cat6A cable must be used.

(a) Is this run within the TIA-568 channel length limit? Show your calculation, including the routing allowance. (3 marks)

(b) What two additional lengths must be accounted for within the 100 m channel budget that are not included in the horizontal cable run measurement? (2 marks)

(c) If the measured run after routing allowance is 93 metres, what action should the administrator take? (3 marks)  *(Note: patch cords at each end typically total 7 m, giving a channel of 100 m — right at the limit)*

*(Hint: patch cord at the patch panel + patch cord at the workstation = typically up to 10 m combined.)*

### Bahagian C: Soalan Esei / Essay (50 marks)

**C1.** You are a Level 4 Network Administrator assigned to analyse the network installation specification for a new 3-storey office building. The specification you receive contains the following information:

- Network topology: Star topology with one Main Distribution Frame (MDF) on the ground floor and one Intermediate Distribution Frame (IDF) per floor
- Equipment: 1 × Core switch (Layer 3, 24-port SFP+); 3 × Distribution switches (48-port PoE+, model number not specified); 40 × Wireless access points (brand and model not specified; "Wi-Fi 6" stated)
- Cabling: "Cat6 or better, standard installation"
- IP plan: "To be confirmed"
- Security: "Firewall to be installed"
- Acceptance criteria: "Standard industry tests"
- Project timeline: "To be completed within 8 weeks from site readiness"

(a) Identify FOUR (4) significant gaps in this specification. For each gap, explain why it is a gap (i.e., what information is missing and why it matters for planning). (20 marks)

(b) Identify TWO (2) risks associated with proceeding to the planning stage with this specification in its current state. For each risk, state the likelihood (High/Medium/Low), the impact (High/Medium/Low), and a recommended mitigation action. (10 marks)

(c) You receive an additional piece of information from the client: "The ground floor includes a kitchen area and a loading bay. We would like network points in both areas." Describe the additional site survey checks you would perform specifically for these two locations before confirming the network design, and explain why these checks are necessary. (10 marks)

(d) Draft a professional Gap Notification Memo (Memo Notifikasi Jurang) addressed to the client's project manager. The memo should: (i) state the purpose of the memo; (ii) list the gaps identified (using the 4 gaps from part (a)); (iii) request the specific information needed to resolve each gap; (iv) state a deadline for the client to respond; and (v) state what will happen if the deadline is not met. (10 marks)
