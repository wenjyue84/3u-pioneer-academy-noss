## Objektif / Objective

Compile all project documentation from KK(1/4) to KK(3/4) and produce a complete, professional Network Installation Management Report suitable for submission to the client and management.

---

## Tempoh / Duration

4 hours

---

## Peralatan dan Bahan / Equipment and Materials

| No. | Item | Quantity |
|-----|------|----------|
| 1 | All outputs from KK(1/4), KK(2/4), and KK(3/4) | 1 set |
| 2 | Report template (provided by instructor) | 1 |
| 3 | As-built floor plan (updated during KK-03) | 1 |
| 4 | Cable test records from KK(3/4) | 1 set |
| 5 | Network connectivity test records from KK(3/4) | 1 set |
| 6 | Computer with word processing software | 1 |
| 7 | Printer | 1 (shared) |

---

## Langkah Keselamatan / Safety Precautions

- This is a desk-based documentation exercise; standard classroom safety applies
- Ensure all electronic files are saved regularly to avoid loss of work
- Handle all physical documents (NCR forms, test records) carefully — these form the appendices of your report

---

## Prosedur / Procedures

| Langkah | Arahan / Instruction |
|---------|---------------------|
| 1 | Open the report template on the computer. Review the required sections (as listed in KP(4/4)): Cover Page, Executive Summary, Project Background, Installation Summary, Test Results Summary, As-Built Documentation, Issues and Non-Conformances, Handover Documentation, Conclusion and Sign-Off. |
| 2 | **Complete the Cover Page.** Fill in: report title (in both English and Bahasa Malaysia), project reference, your name and designation as "Network Administrator (Trainee)", today's date, version "v1.0 — Final", and the distribution list (instructor, client representative, management). |
| 3 | **Write the Executive Summary.** In no more than two (2) pages, summarise: project objectives, start and end dates (planned vs actual), total network points installed, summary test results (pass rate), any approved variations, and the overall outcome statement. Write in formal Bahasa Malaysia or English as directed by your instructor. |
| 4 | **Complete the Project Background section.** Use the project details from the simulated specification. State the client, site, project objectives, scope of work, and project team members (use trainee names for the role assignments from the resource plan). |
| 5 | **Complete the Installation Summary.** Include: cabling works summary (total metres by type, total points); active equipment summary (equipment list with model, serial number if available from simulation, firmware version); IP addressing summary (VLANs and subnets as configured in KK-03); list of all Variation Orders raised; schedule performance (planned vs actual for each phase, with explanations for any deviations). |
| 6 | **Complete the Test Results Summary.** Transfer the cable test records from KK(3/4) into the copper cable test summary table. Transfer the network connectivity results. Calculate and state the overall pass rate for each test type. |
| 7 | **Compile the As-Built Documentation.** Attach or insert: (a) updated floor plan with actual cable routes and network point locations marked; (b) cable schedule with all cable IDs, routes, types, lengths, and test result references; (c) equipment register with all active equipment details. Note: for the training exercise, use the simulated data; state "as-simulated" where actual serial numbers are not available. |
| 8 | **Complete the Issues and Non-Conformances section.** Transfer all NCR forms from KK(3/4) into the issues table. For each NCR, state: reference number, description, corrective action taken, and final status (Closed / Open). Also list the Change Request and Variation Order. |
| 9 | **Complete the Handover Documentation section.** Prepare: (a) equipment warranty summary table; (b) network diagram (draw a simple logical diagram in the word processor or attach a hand-drawn diagram); (c) recommended maintenance schedule table; (d) spares recommendation list. |
| 10 | **Write the Conclusion.** State that the network installation has been completed in accordance with the specification (with the stated variations). Confirm that all acceptance criteria have been met. State any outstanding items (if any) with agreed resolution dates. |
| 11 | **Review and proofread the entire report.** Check: spelling and grammar; consistent terminology throughout; all tables complete (no blank cells that should have data); all section references correct; all appendices listed and attached. |
| 12 | Print one (1) copy of the report. Present it to the instructor as the "client". Deliver a 10-minute verbal presentation of the key findings to the instructor and class, covering: project outcome, test results, variations, and recommendations. |

---

## Hasil Jangkaan / Expected Outcome

- Complete Network Installation Management Report (all 9 sections)
- Report is professionally formatted, bilingual where required, and free of spelling errors
- All test records, NCR forms, and as-built documents are included as appendices
- Verbal presentation delivered (10 minutes)
