## Objektif / Objective

Develop a complete set of project planning documents for a simulated network installation, including a Bill of Quantities (BoQ), a Work Breakdown Structure (WBS), a project schedule (Gantt chart), and a resource plan.

---

## Tempoh / Duration

4 hours

---

## Peralatan dan Bahan / Equipment and Materials

| No. | Item | Quantity |
|-----|------|----------|
| 1 | Approved simulated specification and gap register from KK(1/4) | 1 set |
| 2 | BoQ template (blank) | 1 |
| 3 | WBS template (blank) | 1 |
| 4 | Gantt chart template (blank, 10-week grid) | 1 |
| 5 | Resource plan template (blank) | 1 |
| 6 | Calculator | 1 |
| 7 | Ruler and pencil | 1 set |
| 8 | Reference: current market price list for network equipment (provided by instructor) | 1 |

---

## Langkah Keselamatan / Safety Precautions

- This is a desk-based planning exercise; standard classroom safety applies
- Handle all templates and reference documents carefully; return to instructor on completion
- All cost estimates in this exercise are for training purposes only and do not reflect actual procurement

---

## Prosedur / Procedures

| Langkah | Arahan / Instruction |
|---------|---------------------|
| 1 | Review the approved specification and the gap register from KK(1/4). Note which gaps have been resolved with assumptions for the purpose of this planning exercise (instructor will advise). |
| 2 | **Prepare the Bill of Quantities (BoQ).** Using the BoQ template, list all items under the following sections: (A) Active Equipment, (B) Passive Infrastructure, (C) Power, (D) Labour, (E) Miscellaneous. For each item, state: description, unit, quantity, and estimated unit rate. Calculate the total for each section and the overall project total. Add a 10% contingency line item. |
| 3 | **Verify BoQ quantities.** Cross-check your cable quantities against the cable run measurements from KK(1/4). Add 10% waste allowance to cable and conduit quantities. Verify that the equipment quantities match the network topology diagram. |
| 4 | **Develop the Work Breakdown Structure (WBS).** Decompose the project into a minimum of three WBS levels: Level 1 = Project; Level 2 = Phase (e.g., Planning, Site Preparation, Cabling, Active Equipment, Configuration, Testing, Handover); Level 3 = Work Package. Assign a unique WBS code to each work package. |
| 5 | **Develop the project schedule.** Using the Gantt chart template (10-week grid), plot each Level 2 phase as a bar. Mark dependencies between phases with an arrow. Identify the critical path by tracing the longest chain of dependent tasks. Mark at least THREE (3) milestones (e.g., Site Ready, Cabling Complete, Acceptance Sign-Off). |
| 6 | **Prepare the resource plan.** For each project phase, identify: (a) the roles required; (b) the number of persons per role; (c) the number of days each role is required. Use the roles defined in KP(2/4): Network Administrator, Network Installation Technician, Cable Crew, Termination Specialist, Testing Technician. |
| 7 | **Identify procurement lead times.** From the price list provided, identify the THREE items with the longest delivery lead time. State what action must be taken to avoid these items causing a schedule delay. |
| 8 | **Review and cross-check all documents.** Verify that: the BoQ items all appear in the WBS; the WBS work packages all appear in the Gantt chart; the resource plan covers all phases in the Gantt chart. Correct any inconsistencies. |
| 9 | Submit all four documents (BoQ, WBS, Gantt chart, resource plan) to the instructor for review. Be prepared to explain and justify your planning decisions. |

---

## Hasil Jangkaan / Expected Outcome

- Completed BoQ with all five sections, quantities, unit rates, and totals (including 10% contingency)
- WBS with minimum 3 levels and unique WBS codes
- 10-week Gantt chart with phase bars, dependency arrows, critical path identified, and milestones marked
- Resource plan covering all project phases
- Procurement lead time analysis with recommended actions
