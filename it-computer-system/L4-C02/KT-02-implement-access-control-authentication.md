## Bahagian A: Soalan Pelbagai Pilihan / Section A: Multiple Choice (20 marks — 4 marks each)

**A1.** The AAA framework in access control stands for:

- (a) Authentication, Authorisation, Accounting
- (b) Access, Audit, Availability
- (c) Authentication, Access, Analysis
- (d) Authorisation, Allocation, Accounting

**A2.** Which of the following is an example of "something you have" in multi-factor authentication?

- (a) A password
- (b) A fingerprint
- (c) A hardware token (YubiKey)
- (d) A security question answer

**A3.** The principle of least privilege states that:

- (a) All users should have administrator access for maximum productivity
- (b) Users should have the minimum permissions necessary to perform their job functions
- (c) Permissions should be assigned to individual users rather than groups
- (d) Administrator accounts should be used for all daily tasks

**A4.** In Active Directory, the BEST practice for assigning permissions to shared resources is to:

- (a) Assign permissions directly to individual user accounts
- (b) Assign permissions to security groups and add users to those groups
- (c) Use the built-in Everyone group for convenience
- (d) Share resources with full control to all authenticated users

**A5.** Which Windows Group Policy setting prevents a user account from logging in interactively to a server?

- (a) Account lockout threshold
- (b) Deny log on locally
- (c) Password must meet complexity requirements
- (d) Minimum password age

## Bahagian B: Soalan Jawapan Pendek / Section B: Short Answer (30 marks)

**B1.** Explain the difference between Authentication, Authorisation, and Accounting (AAA). Provide one real-world example of each in a Windows Server domain environment. (9 marks)

**B2.** Describe THREE (3) differences between a Domain User Account and a Local User Account in Windows Server. State when each type should be used. (9 marks)

**B3.** List the recommended Windows Group Policy password policy settings for an enterprise environment. For each setting, state the recommended value and justify why. (6 marks)

**B4.** Explain what Privileged Access Management (PAM) is and describe TWO (2) specific controls used to manage privileged accounts securely. (6 marks)

## Bahagian C: Soalan Situasi / Section C: Situational Question (50 marks)

**C1.** Syarikat Teknologi Nusantara Sdn Bhd has the following departments and access requirements:

| Department | Required Access |
|-----------|----------------|
| Finance | Read/write: Finance share; Read-only: Audit reports share |
| Human Resources | Read/write: HR share; No access to Finance or IT shares |
| IT Operations | Full access to all shares; Local administrator on all servers |
| Sales | Read/write: Sales share; Read-only: Product catalogue share |
| Reception | Read-only: Company announcements share only |

(a) Design an Active Directory group structure to implement RBAC for this company. Name each group, state its purpose, and list which user roles belong to it. (15 marks)

(b) You are instructed to configure a password policy for the domain. Write the complete set of Group Policy password and account lockout settings you would apply, including all parameter values, and justify each setting. (15 marks)

(c) Three months after implementation, you discover that several employees have been sharing their passwords with colleagues to cover for each other during leave. Describe: (i) the security risk this creates; (ii) the technical controls you would implement to enforce individual accountability; (iii) the non-technical (policy/training) measures you would recommend. (20 marks)
