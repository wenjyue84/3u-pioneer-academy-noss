## Kaedah Pengajaran / Teaching Method (4-Step)

### 1. PERSEDIAAN (Preparation)

| Langkah / Step | Aktiviti / Activity | Masa / Duration |
|----------------|---------------------|-----------------|
| 1.1 | Welcome trainees; take attendance | 5 min |
| 1.2 | State the learning objectives for the session (read from relevant KP) | 5 min |
| 1.3 | Relate topic to workplace context — ask trainees about security incidents they have heard about (ransomware, data breaches) | 10 min |
| 1.4 | Provide overview of the Information Sheet (KP) content and how it maps to the Work Activity | 5 min |

### 2. PENYAMPAIAN (Presentation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 2.1 | Deliver theory content from the relevant KP using slides, diagrams, and real-world case studies |
| 2.2 | Explain key terms in both English and Malay; write key terms on whiteboard for reference |
| 2.3 | Show relevant diagrams: CIA Triad, RBAC model, DMZ network diagram, patch management lifecycle, incident response lifecycle |
| 2.4 | Use live demonstration where feasible: e.g. show Event Viewer logs, demonstrate a GPO password policy setting, demonstrate a WSUS console view |
| 2.5 | Present real-world examples: WannaCry patch failure (KP4), Windows Active Directory misconfiguration (KP2), firewall rule gaps (KP3) |
| 2.6 | Encourage questions; clarify misconceptions immediately |
| 2.7 | Highlight regulatory obligations: PDPA 2010, MS ISO/IEC 27001 relevance to each topic |

### 3. PENGGUNAAN (Application)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 3.1 | Distribute the corresponding KT (Assignment Sheet) for the session |
| 3.2 | Trainees complete the assignment individually; instructor observes and provides targeted guidance |
| 3.3 | For complex situational questions in Bahagian C, trainees may discuss in pairs before writing individual answers |
| 3.4 | Discuss answers and common errors with the class after submission; highlight marking criteria |

### 4. PENGESAHAN (Confirmation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 4.1 | Review the key learning points from the session using a summary slide |
| 4.2 | Conduct brief oral questioning — select 3–4 trainees to answer questions drawn from the KP |
| 4.3 | Collect completed KT for marking; provide written feedback within one week |
| 4.4 | Preview the next session topic |
| 4.5 | Record attendance and session completion in the training register |

## Perincian Sesi Pengajaran / Session-by-Session Detail

### Sesi 1–3: KP(1/5) — Identify Security Requirements (9 jam)

| Sesi | Tajuk Sesi | Kandungan Utama | Masa |
|------|-----------|-----------------|------|
| 1 | Introduction to Security Concepts | CIA Triad, AAA framework, key terms (threat, vulnerability, risk, asset, control), threat classification | 3 jam |
| 2 | Vulnerability Assessment and Risk Analysis | Vulnerability categories, vulnerability assessment steps, CVSS scoring, risk rating (likelihood × impact), risk register | 3 jam |
| 3 | Security Policy and Requirements Specification | Security policy types, PDPA 2010, MS ISO/IEC 27001, SRS structure and production; KT(1/5) assignment | 3 jam |

### Sesi 4–8: KP(2/5) — Implement Access Control and Authentication (15 jam)

| Sesi | Tajuk Sesi | Kandungan Utama | Masa |
|------|-----------|-----------------|------|
| 4 | Authentication Methods and MFA | Authentication factors, password policy parameters, account lockout policy, MFA options (TOTP, hardware token, Windows Hello) | 3 jam |
| 5 | Access Control Models | DAC, MAC, RBAC, principle of least privilege, access control matrix | 3 jam |
| 6 | Active Directory User and Group Management | Account types, OU design, security groups, GPO for access control | 3 jam |
| 7 | Linux User and Permission Management | useradd, chmod, chown, setfacl; permission notation; Linux equivalents of Windows RBAC | 3 jam |
| 8 | Privileged Access Management; KT(2/5) | PAM concepts, separate admin accounts, JIT access, PAW; KT(2/5) assignment | 3 jam |

### Sesi 9–13: KP(3/5) — Configure Firewall and Network Security (15 jam)

| Sesi | Tajuk Sesi | Kandungan Utama | Masa |
|------|-----------|-----------------|------|
| 9 | Firewall Types and Functions | Packet filter, stateful inspection, application layer, NGFW, host-based firewall; comparison table | 3 jam |
| 10 | Windows Defender Firewall Configuration | wf.msc, inbound/outbound/connection security rules; PowerShell New-NetFirewallRule; common rule set | 3 jam |
| 11 | Network Segmentation — VLAN and DMZ | VLAN purpose and design, trunk/access ports, inter-VLAN routing; DMZ architecture | 3 jam |
| 12 | Attack Surface Reduction | Disabling unnecessary services and ports; insecure protocols and secure alternatives; netstat / Get-NetTCPConnection | 3 jam |
| 13 | IDS/IPS; KT(3/5) | IDS vs IPS, detection methods (signature, anomaly, policy), network and host-based placement; KT(3/5) assignment | 3 jam |

### Sesi 14–18: KP(4/5) — Manage Patches and Security Updates (15 jam)

| Sesi | Tajuk Sesi | Kandungan Utama | Masa |
|------|-----------|-----------------|------|
| 14 | Patch Types and Severity Classification | Security update, critical update, service pack, feature update, firmware; Microsoft severity ratings; CVSS 0–10 scale | 3 jam |
| 15 | Patch Management Lifecycle | Eight phases: identification → categorisation → acquisition → testing → approval → deployment → verification → documentation | 3 jam |
| 16 | WSUS Architecture and Configuration | WSUS role installation, configuration wizard, sync with Microsoft Update, computer groups, GPO client settings | 3 jam |
| 17 | Staging Environment Testing and Compliance Verification | Staging requirements, patch testing checklist, Get-HotFix, WSUS reports, MBSA / Security Compliance Toolkit | 3 jam |
| 18 | Patch Register; KT(4/5) | Patch register fields and maintenance; change advisory board (CAB) process; rollback planning; KT(4/5) assignment | 3 jam |

### Sesi 19–20: KP(5/5) — Document Security Configuration and Incidents (6 jam)

| Sesi | Tajuk Sesi | Kandungan Utama | Masa |
|------|-----------|-----------------|------|
| 19 | Security Configuration Documentation | Baseline record components, configuration management register, hardening checklist; version control principles | 3 jam |
| 20 | Incident Response and Reporting; KT(5/5) | Incident definition and severity classification; NIST IR lifecycle; incident report structure; audit logging (AuditPol, Event IDs); PDPA obligations; KT(5/5) assignment | 3 jam |

## Penilaian Teori / Theory Assessment

Setelah semua 5 KP dan KT diselesaikan, pelatih akan menduduki Penilaian Pengetahuan (KA):

- **Kod:** IT-020-4:2013-C02/KA
- **Tempoh:** 2 jam
- **Format:** Peperiksaan bertulis — MCQ (30 markah), Jawapan Pendek (30 markah), Esei (40 markah)
- **Markah lulus:** 60/100
- **Syarat:** Semua KT mesti diserahkan dan dinilai sebelum pelatih dibenarkan menduduki KA
