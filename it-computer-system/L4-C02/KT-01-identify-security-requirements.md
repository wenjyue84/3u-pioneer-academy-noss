## Bahagian A: Soalan Pelbagai Pilihan / Section A: Multiple Choice (20 marks — 4 marks each)

**A1.** Which of the following BEST describes the CIA Triad in information security?

- (a) Confidentiality, Implementation, Availability
- (b) Confidentiality, Integrity, Availability
- (c) Control, Integrity, Authentication
- (d) Compliance, Integration, Access

**A2.** A systems administrator discovers that a web server is running an outdated version of Apache with a known remote code execution vulnerability. This is an example of:

- (a) A threat
- (b) A risk
- (c) A vulnerability
- (d) A control

**A3.** The Personal Data Protection Act 2010 (PDPA) is relevant to IT security because it:

- (a) Requires all employees to use multi-factor authentication
- (b) Mandates that organisations implement adequate security controls for personal data
- (c) Prohibits the use of cloud storage in Malaysia
- (d) Only applies to financial institutions

**A4.** In a risk assessment, risk is calculated as:

- (a) Threat multiplied by asset value
- (b) Vulnerability divided by control effectiveness
- (c) Likelihood multiplied by impact
- (d) Asset value minus residual risk

**A5.** Which document type defines the minimum security settings that all systems of a given type must meet?

- (a) Incident report
- (b) Patch register
- (c) Security configuration baseline
- (d) Acceptable Use Policy

## Bahagian C: Soalan Situasi / Section C: Situational Question (50 marks)

**C1.** You are the systems administrator for a private hospital with the following IT environment:
- 3 Windows Server 2022 servers (patient records, billing, email)
- 150 Windows 11 workstations used by doctors, nurses, and administrative staff
- 1 internet-facing patient portal (web server)
- Wireless network accessible by staff and visitors

The hospital CEO has requested a Security Requirements Specification (SRS) before any new controls are implemented.

(a) Define the system boundary for this environment. What would you include and what would you explicitly exclude from scope? Justify your decisions. (10 marks)

(b) Identify and classify EIGHT (8) distinct threats relevant to this hospital environment. For each threat, state: the threat description, the asset(s) at risk, and the likelihood (High / Medium / Low) with justification. (24 marks)

(c) Select the THREE (3) highest-risk threats from your list. For each, recommend one specific security control and explain how the control reduces the identified risk. (12 marks)

(d) State which sections of the PDPA 2010 are most relevant to protecting patient data in this environment and what obligations they impose on the hospital. (4 marks)
