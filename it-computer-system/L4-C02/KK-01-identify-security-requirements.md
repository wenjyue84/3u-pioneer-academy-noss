## Objektif / Objective

Conduct a structured security requirements analysis for a given computing environment and produce a Security Requirements Specification (SRS) document.

---

3 hours

## Prosedur / Procedures

**Scenario:** You are the systems administrator for Syarikat Maju Jaya Sdn Bhd, a medium-sized company with 80 staff. The company has: 2 Windows Server 2022 domain controllers, 1 file server, 1 web server (internet-facing), 80 Windows 11 workstations, and 1 network-attached storage (NAS) device. The IT manager has instructed you to conduct a security requirements analysis before implementing new security controls.

| Langkah | Arahan / Instruction |
|---------|---------------------|
| 1 | Read the scenario brief carefully. Identify the boundary of the system to be analysed. Draw a simple network diagram showing servers, workstations, internet connection, and NAS. |
| 2 | Complete the asset inventory template. List every asset in the scenario, classify it as Hardware / Software / Data, and assign a value rating (High / Medium / Low) based on its business importance. |
| 3 | Using the threat categories from KP(1/5), identify at least EIGHT (8) plausible threats relevant to this environment. Record each threat in the threat register template with: threat description, affected assets, and likelihood rating (High / Medium / Low). |
| 4 | For each identified threat, identify at least one corresponding vulnerability that could allow the threat to materialise. Record in the vulnerability column of the register. |
| 5 | Calculate a risk rating for each threat: Risk = Likelihood × Impact (use High=3, Medium=2, Low=1). Rank the threats from highest to lowest risk. |
| 6 | For the top FIVE (5) risks, select at least one appropriate security control (preventive, detective, or corrective). Record your justification for each control selection. |
| 7 | Compile the analysis into the SRS template. Include: system boundary, asset list, threat register (with risk ratings), top-5 risk controls, and applicable compliance requirements (PDPA, MS ISO/IEC 27001). |
| 8 | Present your SRS summary to the instructor (5 minutes). Be prepared to justify your risk ratings and control choices. |

---

## Hasil Jangkaan / Expected Outcome

- Completed asset inventory with value ratings for all identified assets
- Completed threat and risk register with at least 8 threats, vulnerability mapping, and risk ratings
- SRS document covering all required sections
- Verbal justification of top-5 risk control choices
