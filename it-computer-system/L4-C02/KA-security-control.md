## BAHAGIAN A: SOALAN PELBAGAI PILIHAN / SECTION A: MULTIPLE CHOICE (30 markah — 2 markah setiap soalan)

Jawab semua 15 soalan. Bulatkan jawapan yang betul.

**1.** The three components of the CIA Triad are:

- (a) Control, Integrity, Authentication
- (b) Confidentiality, Integrity, Availability
- (c) Compliance, Implementation, Accountability
- (d) Confidentiality, Integration, Authorisation

**2.** A hacker sends a fraudulent email impersonating the CEO to trick an employee into transferring funds. This attack is classified as:

- (a) Denial of Service
- (b) Malware
- (c) Social engineering
- (d) Supply chain attack

**3.** Risk in information security is calculated as:

- (a) Asset value × control cost
- (b) Likelihood × Impact
- (c) Threat count ÷ vulnerability count
- (d) Impact − residual risk

**4.** Which of the following BEST describes the principle of least privilege?

- (a) All users should share a single administrator account
- (b) Users should receive only the minimum permissions required to perform their job functions
- (c) Permissions should be reviewed only when a user leaves the organisation
- (d) Service accounts should have full domain administrator rights for reliability

**5.** In Windows Active Directory, the RECOMMENDED method for assigning permissions to resources is:

- (a) Assign permissions directly to each individual user account
- (b) Add users to security groups and assign permissions to those groups
- (c) Use the built-in Everyone group with Read permission
- (d) Grant temporary permissions via email approval only

**6.** Multi-factor authentication (MFA) is more secure than single-factor authentication because:

- (a) It requires the user to answer two security questions
- (b) An attacker must compromise two or more independent factors to gain access
- (c) It eliminates the need for passwords entirely
- (d) It locks the account after one failed attempt

**7.** Windows Defender Firewall with Advanced Security is accessed via which tool?

- (a) `compmgmt.msc`
- (b) `gpedit.msc`
- (c) `wf.msc`
- (d) `services.msc`

**8.** A DMZ (Demilitarised Zone) in network architecture is designed to:

- (a) Replace the internal firewall
- (b) House public-facing servers in a zone isolated from the internal LAN
- (c) Store encrypted backups of all internal data
- (d) Provide guest wireless access

**9.** Telnet should be replaced with SSH because:

- (a) SSH is faster than Telnet
- (b) Telnet transmits data including credentials in cleartext
- (c) SSH is free and Telnet requires a licence
- (d) Telnet does not support Windows Server

**10.** A CVSS score of 9.8 indicates which severity level?

- (a) Low
- (b) Medium
- (c) High
- (d) Critical

**11.** The PRIMARY purpose of Windows Server Update Services (WSUS) is to:

- (a) Provide antivirus definitions to all workstations
- (b) Centralise management and approval of Microsoft updates across the organisation
- (c) Monitor network traffic for intrusions
- (d) Synchronise user accounts across multiple domain controllers

**12.** Before deploying a Critical security patch to a production server, the administrator should:

- (a) Apply it immediately to minimise exposure
- (b) Wait for the next scheduled quarterly maintenance window
- (c) Test it in a staging environment and obtain change management approval
- (d) Apply it only to workstations; servers do not require patching

**13.** Windows Security Event ID 4740 indicates:

- (a) A user account was created
- (b) A failed logon attempt
- (c) A user account was locked out
- (d) A successful logon

**14.** According to NIST SP 800-61, which phase of the incident response lifecycle involves removing the cause of the incident (e.g. malware, unauthorised accounts)?

- (a) Containment
- (b) Eradication
- (c) Recovery
- (d) Post-Incident Activity

**15.** Storing audit logs only on the affected local system is a security weakness because:

- (a) Local storage is too expensive for log data
- (b) Event Viewer can only store 512 MB of logs
- (c) An attacker who compromises the system can delete or alter logs, destroying evidence
- (d) Local logs cannot be read by administrators

## BAHAGIAN C: SOALAN ESEI / SECTION C: ESSAY (40 markah)

Jawab kedua-dua soalan.

**21.** You are the systems administrator for Universiti Wawasan, a private university with 2,000 students and 300 staff. The university's IT environment includes:
- 5 Windows Server 2022 servers (student portal, email, file, database, authentication)
- 300 staff Windows 11 workstations
- 500 student-accessible computer lab workstations
- Open Wi-Fi accessible by students and visitors
- A public-facing student registration portal

The university's IT manager has assigned you to implement computer system security controls for CoCu 2.

(a) Conduct a security requirements analysis for this environment. Identify the system boundary, classify at least SIX (6) assets, identify SIX (6) threats with risk ratings (likelihood × impact), and recommend one control per top-three risk. (15 marks)

(b) Design the access control structure for the university. Describe: the user roles and their required access; the Active Directory group structure; the password policy settings (all parameters and values); and the MFA implementation plan for staff administrator accounts. (15 marks)

(c) Describe the complete patch management process you would implement for this university, including: WSUS architecture; computer group structure for staged deployment; approval workflow; and the patch register fields you would maintain. (10 marks)

**22.** At 09:20 on a Wednesday morning, the university's SIEM generates an alert showing 47 failed logon attempts against the student portal administrator account (`portal-admin`) from an external IP address within the previous 10 minutes. At 09:31, a successful logon is recorded for `portal-admin` from the same external IP. At 09:45, the database server logs show 3,500 student records being exported via an SQL query run under the `portal-admin` session.

(a) Classify this incident by type and severity (P1–P4). Provide full justification for your classification, including which CIA Triad properties have been violated. (8 marks)

(b) Describe the step-by-step containment and eradication actions you would take, in sequence, from the moment the SIEM alert is acknowledged to the point where the threat is eliminated. (12 marks)

(c) Prepare the complete Lessons Learned section of the incident report. Identify at least FOUR (4) specific security weaknesses revealed by this incident, and for each weakness recommend a specific corrective action, named owner, and deadline. (10 marks)

(d) Explain whether this incident triggers any obligations under the Personal Data Protection Act 2010 (PDPA). State what specific actions the university must take and within what timeframe. (10 marks)
