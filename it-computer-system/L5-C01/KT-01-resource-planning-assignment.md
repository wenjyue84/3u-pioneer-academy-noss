## Soalan / Questions

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (20 marks — 4 marks each)

**A1.** An IT Manager conducts a capacity planning review and finds that the primary file server's average CPU utilisation has been 83% over the past three months. According to best practice thresholds, this situation requires:

- (a) No action — 83% is within the normal operating range
- (b) Immediate decommission of the server
- (c) Initiation of a procurement or capacity expansion plan
- (d) Reduction in the number of users allowed to access the server

**A2.** The Total Cost of Ownership (TCO) of an IT asset includes:

- (a) Only the purchase price of the hardware
- (b) Purchase price, installation, annual operating costs, and disposal costs over the asset's full life
- (c) Only capital expenditure (CAPEX) items
- (d) Only the cost of annual maintenance contracts

**A3.** An organisation's ERP server is 6.5 years old. The vendor has announced end-of-support in 8 months. According to lifecycle management best practice, the IT Manager should:

- (a) Continue operating the server until it physically fails
- (b) Begin a refresh planning project immediately, as 8 months provides limited lead time for procurement and migration
- (c) Apply for a vendor support extension without evaluating alternatives
- (d) Migrate all ERP data to an unmanaged cloud service to save cost

**A4.** Capital Expenditure (CAPEX) differs from Operational Expenditure (OPEX) in that CAPEX:

- (a) Is expensed in full in the period it is incurred
- (b) Covers only software subscription costs
- (c) Is capitalised and depreciated over the asset's useful life
- (d) Does not require management approval

**A5.** The CMDB (Configuration Management Database) is used in lifecycle management to:

- (a) Store the source code of all enterprise applications
- (b) Record all IT assets with attributes including purchase date, warranty expiry, and support end date — enabling automated lifecycle alerts
- (c) Process user service requests
- (d) Approve change requests

### Bahagian B: Soalan Jawapan Pendek / Short Answer (30 marks)

**B1.** Explain the THREE (3) capacity planning thresholds defined in KP(1/4) and the management action required at each threshold. (9 marks)

**B2.** An organisation's storage array has a total capacity of 80 TB. Current utilisation is 67 TB. The IT Manager forecasts that new workloads over the next 6 months will consume an additional 9 TB.

(a) Calculate the current utilisation percentage. (2 marks)

(b) Calculate the projected utilisation percentage after 6 months. (2 marks)

(c) Based on the thresholds in KP(1/4), what action should the IT Manager take, and when? (3 marks)

**B3.** List FIVE (5) mandatory fields that should be recorded in a CMDB for each IT asset, and explain why each field is important for lifecycle management. (10 marks)

**B4.** Define the term "IT budget contingency" and explain why it is included in the IT budget. State the typical contingency percentage range. (4 marks)

### Bahagian C: Soalan Situasi / Situational Question (50 marks)

**C1.** You are the IT Manager of a government agency with 200 staff. Your asset register shows the following:

| Asset Class | Quantity | Average Age | Vendor Support Status |
|------------|---------|------------|----------------------|
| Desktop PCs | 200 | 4.2 years | 1.5 years remaining |
| Servers (rack-mounted) | 15 | 5.8 years | 6 months remaining |
| Network switches | 8 | 7.1 years | Already expired |
| NAS storage | 2 × 40 TB | 4.5 years | 2 years remaining |

Server utilisation (current): CPU 77%, RAM 82%, Storage 71%.

The agency is planning to implement a new HR system in 8 months, requiring 4 new VMs and 5 TB additional storage.

**Finance has approved an IT budget cap of RM 400,000 for the next financial year.**

(a) Identify and prioritise ALL assets that require action in the next 12 months. Justify the priority order using lifecycle management and risk principles. (15 marks)

(b) For the server estate, explain whether the IT Manager should recommend: (i) on-premises server refresh; (ii) migration to cloud (IaaS); or (iii) a hybrid approach. Provide a structured rationale using TCO considerations. (15 marks)

(c) Prepare a line-item IT budget proposal for the next financial year, staying within the RM 400,000 cap. If you cannot address all identified needs within the cap, clearly state which items are deferred and explain the risk of deferral. (20 marks)
