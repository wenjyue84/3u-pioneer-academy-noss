## Tugasan / Questions

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (20 marks — 4 marks each)

**A1.** At Level 4, the primary purpose of server requirements analysis is to:

- (a) Purchase server hardware as quickly as possible
- (b) Translate organisational needs into verified technical specifications before any configuration begins
- (c) Assign a technician to assemble the server
- (d) Write a report for the finance department only

**A2.** Which of the following is a COMPLIANCE requirement (Keperluan Pematuhan) for a Malaysian organisation?

- (a) 64 GB ECC RAM minimum
- (b) RAID 10 for the database volume
- (c) Data at rest must be encrypted under PDPA 2010
- (d) 10GbE network interface

**A3.** The MoSCoW method is used to:

- (a) Select a RAID level for storage
- (b) Prioritise requirements into Must Have, Should Have, Could Have, and Won't Have categories
- (c) Design a network topology
- (d) Identify the server's physical location in the rack

**A4.** In a Requirements Traceability Matrix (RTM), the "Source" column records:

- (a) The IP address of the server
- (b) Which stakeholder or document originated the requirement
- (c) The name of the vendor supplying the hardware
- (d) The date the requirement was implemented

**A5.** A requirement states: "The server must support 500 concurrent users." This is a BUSINESS requirement because:

- (a) It specifies a hardware component
- (b) It defines a business-level outcome without specifying the technical implementation
- (c) It refers to a PDPA 2010 obligation
- (d) It was written by the IT Manager

---

### Bahagian B: Soalan Jawapan Pendek / Short Answer (30 marks)

**B1.** List and briefly describe THREE (3) categories of server requirements and give ONE example of each. (9 marks)

**B2.** An administrator is planning a database server for a financial services company. Identify FOUR (4) technical parameters that must be captured for this server and explain why each is important for a database workload. (8 marks)

**B3.** Explain what a "gap" is in the context of requirements analysis, and describe what an administrator should do when a gap is identified. (6 marks)

**B4.** State THREE (3) consequences of conducting inadequate server requirements analysis. (3 marks)

**B5.** Describe what "30% free space buffer" means in the context of storage sizing and why it is important for SSD-based storage. (4 marks)

---

### Bahagian C: Soalan Situasi / Situational Question (50 marks)

**C1.** You are the IT Administrator at Pioneer Academy, a private educational institution with 800 students and 120 staff. The IT Manager has instructed you to deploy a new server to replace the existing ageing file server and also act as a new domain controller. The IT Manager's verbal brief was: "We need a new server — it has to be fast, and all the student records must be safe."

Using the requirements analysis methodology from KP(1/6):

**(a)** Identify ALL stakeholders you would consult for this deployment and state ONE specific question you would ask each stakeholder. (10 marks)

**(b)** From the verbal brief and your knowledge of the deployment context, extract and categorise at least EIGHT (8) requirements. For each requirement, state: Req ID, Description, Category (Business/Technical/Compliance), and MoSCoW Priority with justification. (24 marks)

**(c)** Identify THREE (3) gaps or ambiguities in the IT Manager's brief that must be resolved before planning can begin. For each gap, state what information is missing and which stakeholder should provide it. (9 marks)

**(d)** Explain what "data residency" means in the context of PDPA 2010 and why it is relevant to this deployment. (7 marks)
