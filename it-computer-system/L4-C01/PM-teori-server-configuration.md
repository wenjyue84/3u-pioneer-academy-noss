## Kaedah Pengajaran / Teaching Method (4-Step)

### 1. PERSEDIAAN (Preparation)

| Langkah / Step | Aktiviti / Activity | Masa / Duration |
|----------------|---------------------|-----------------|
| 1.1 | Welcome trainees and take attendance | 5 min |
| 1.2 | State the learning objectives for the session — link to the specific KP and Work Activity | 5 min |
| 1.3 | Activate prior knowledge: pose an opening question related to the topic (e.g. "What is the difference between a domain controller and a member server?") | 5 min |
| 1.4 | Provide overview of the KP structure and key concepts to be covered | 5 min |

### 2. PENYAMPAIAN (Presentation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 2.1 | Deliver theory content from the relevant KP using structured slides; use tables and diagrams as primary teaching tools |
| 2.2 | Explain bilingual technical terms in context (EN/BM): Keperluan Pematuhan = Compliance Requirements; Pelayan Direktori = Directory Server |
| 2.3 | Use real-world case studies and scenarios drawn from Malaysian SME and institutional IT contexts |
| 2.4 | Demonstrate concepts using live command-line or GUI examples on the instructor's demonstration workstation (projected) |
| 2.5 | Pose check-for-understanding questions throughout — do not wait until the end |
| 2.6 | Emphasise Level 4 altitude: administration and decision-making, not just execution of steps |

### 3. PENGGUNAAN (Application)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 3.1 | Distribute the corresponding KT (Assignment Sheet) for the session |
| 3.2 | Trainees complete the assignment individually — 45 to 60 minutes per KT |
| 3.3 | For situational questions (Bahagian C), allow peer discussion after individual attempt |
| 3.4 | Instructor circulates to observe reasoning, not just answers — probe with "why did you choose that?" |
| 3.5 | Discuss common misconceptions and errors identified during circulation |

### 4. PENGESAHAN (Confirmation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 4.1 | Review key concepts from the session using a structured recap (3–5 key points per KP) |
| 4.2 | Conduct oral questioning: select 3–4 trainees to answer one question each; encourage others to agree or challenge |
| 4.3 | Collect completed KT assignments; confirm marking and feedback timeline |
| 4.4 | Preview the next session topic and advise trainees to review the relevant KP before the next class |
| 4.5 | Record attendance and session completion in the training register |

## Rancangan Sesi Terperinci / Detailed Session Plan

### KP(1/6) — Server Configuration Requirements Analysis (9.0 hours)

| Session | Topic | Duration | Teaching Aids |
|---------|-------|---------|--------------|
| 1A | Introduction: why Level 4 differs from Level 3; the role of requirements analysis | 1.5 hr | Slides, comparison table L3 vs L4 |
| 1B | Requirement categories: Business, Technical, Compliance; MoSCoW prioritisation | 1.5 hr | Slides, categorisation exercise |
| 1C | Stakeholders and requirements elicitation; RTM structure | 1.5 hr | Stakeholder diagram, RTM template |
| 1D | Validation methodology and gap identification | 1.5 hr | Case study: school server scenario |
| 1E | KT(1/6) assignment session | 3.0 hr | KT assignment, answer discussion |

### KP(2/6) — Planning Server Roles and Services (9.0 hours)

| Session | Topic | Duration | Teaching Aids |
|---------|-------|---------|--------------|
| 2A | Common server roles overview: DC, File, Web, DB, DHCP, DNS, Virtualisation | 2.0 hr | Slides, role comparison table |
| 2B | Role consolidation vs dedicated server; virtualisation strategy | 1.5 hr | Decision matrix, scenario examples |
| 2C | Capacity planning: CPU, RAM, storage formulas with worked examples | 2.0 hr | Whiteboard calculations, spreadsheet |
| 2D | Network topology design; VLAN planning; Server Role Plan document | 1.5 hr | Visio/draw.io diagram demonstration |
| 2E | KT(2/6) assignment session | 2.0 hr | KT assignment, diagram exercise |

### KP(3/6) — Server Hardware and Storage Configuration (12.0 hours)

| Session | Topic | Duration | Teaching Aids |
|---------|-------|---------|--------------|
| 3A | Enterprise server hardware: CPU (Xeon/EPYC), ECC RAM (RDIMM/LRDIMM), enterprise NICs | 2.0 hr | Slides, hardware comparison table, physical sample components |

| 3C | RAID levels: 0, 1, 5, 6, 10 — with capacity calculations and I/O characteristics | 3.0 hr | Slides, RAID comparison table, calculation exercises |

## Penilaian Teori / Theory Assessment

Upon completion of all 6 KP/KT sessions, trainees will sit for the Knowledge Assessment (KA):

- **Kod / Code:** IT-020-4:2013-C01/KA
- **Tempoh / Duration:** 1 hour 30 minutes
- **Format:** Written test — MCQ (30 marks), Short Answer (30 marks), Essay (40 marks)
- **Pass mark:** 60 / 100
- **Mode:** Closed book
