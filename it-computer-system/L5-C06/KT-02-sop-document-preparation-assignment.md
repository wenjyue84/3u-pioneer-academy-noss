- (c) The version number changes from v1.1 to v2.0
- (d) The version number is reset to Draft v0.1

**A2.** In a RACI matrix, the "A" (Accountable) designation means:

- (a) The person who physically performs the task
- (b) The person who must be kept informed of progress
- (c) The person who is ultimately answerable for the correct completion of the activity

### Bahagian C: Soalan Esei / Essay (50 marks)

**C1.** You are preparing a Server Patch Management SOP for a government agency. The process involves four roles: IT Security Officer, Systems Administrator, Change Advisory Board (CAB), and IT Director. The process must comply with MS ISO/IEC 27001:2022 control A.8.8 (Management of technical vulnerabilities).

The process follows this sequence:
1. IT Security Officer identifies and assesses new patches from vendor advisories each Monday
2. IT Security Officer classifies each patch as Critical, High, Medium, or Low based on CVSS score
3. Critical patches are fast-tracked: IT Director approves within 24 hours; Systems Administrator applies within 48 hours of approval
4. High, Medium, and Low patches go through standard change management: IT Security Officer submits a Request for Change (RFC) to CAB; CAB approves or rejects within 5 working days; approved patches are applied by Systems Administrator in the next scheduled maintenance window
5. After patch application, Systems Administrator verifies and documents results; IT Security Officer updates the Vulnerability Register
6. Monthly: IT Security Officer produces a Patch Compliance Report for the IT Director

(a) Draft a complete RACI matrix for this process. Identify all activities (at least 8) and assign R, A, C, and I designations for each of the four roles. Justify any designation where the assignment is not immediately obvious. (15 marks)

(b) Write the complete Purpose and Scope sections for this SOP. The Purpose must cover all three required elements (what, why, outcome). The Scope must specify all four scope dimensions (functional, organisational, technical, and regulatory). (15 marks)

(c) Describe how you would conduct the review and validation process for this SOP before it is submitted for management approval. Identify the reviewers, the type of review each would conduct, the documentation required, and the validation testing approach. (20 marks)
