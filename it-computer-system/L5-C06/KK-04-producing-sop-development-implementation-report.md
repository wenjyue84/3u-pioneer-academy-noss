## Objektif / Objective

Compile and present a complete SOP Development and Implementation Completion Report, including a compliance metrics table, executive summary, lessons learned register, and SOP inventory — based on a simulated programme data set provided by the instructor.

---

## Tempoh / Duration

3 hours (180 minutes)

---

## Peralatan dan Bahan / Equipment and Materials

| No. | Item | Quantity |
|-----|------|----------|
| 1 | Programme data set (simulated — provided by instructor): includes milestone dates, SOP inventory, training completion data, KPI results, non-conformance records, and lessons learned inputs from a simulated SOP programme | 1 per trainee |
| 2 | Completion Report Template (Form ICT-SOP-CR-FINAL-001) | 1 per trainee |
| 3 | SOP Inventory Table Template | 1 per trainee |
| 4 | Lessons Learned Register Template (Form ICT-SOP-LL-001) | 1 per trainee |
| 5 | Computer with word processing and spreadsheet software | 1 per trainee |
| 6 | Calculator | 1 per trainee |

---

## Langkah Keselamatan / Safety Precautions

- Treat the programme data set as SULIT (Confidential) — do not share outside the training room
- All reports produced are training artefacts; clearly mark each "LATIHAN / TRAINING USE ONLY"
- Return all printed materials to the instructor at the end of the session

---

## Prosedur / Procedures

| Langkah | Arahan / Instruction |
|---------|---------------------|
| 1 | Receive and read the programme data set in full before beginning any report section. Identify the: (a) total number of SOPs developed and implemented, (b) programme start and end dates, (c) training completion rates by staff category, (d) KPI results for the monitoring period, (e) number and severity of non-conformances raised and closed, and (f) any outstanding actions at programme closure. |
| 2 | Calculate the following KPIs from the data set. Show your working: (a) Overall SOP compliance rate (%), (b) Training completion rate (%), (c) Non-conformance closure rate within 30 days (%), (d) Percentage of SOPs reviewed within their scheduled review date. Compare each KPI to its target and classify as: On Target / Below Target / Above Target. |
| 3 | Complete the SOP Inventory Table for all SOPs in the data set. For each SOP, record: Document Number, Title (Bahasa Malaysia and English), Version, Status (Active / Retired), Effective Date, Review Date, and Owner (job title). |
| 4 | Complete the Lessons Learned Register. For each lesson learned input in the data set, record: Reference, Area (e.g. Requirements Analysis / Document Preparation / Training / Compliance Monitoring), Observation, Impact (quantified if possible), and Recommendation for future programmes. |
| 5 | Draft Section 7 (Compliance Monitoring Results) of the Completion Report: include the KPI summary table (from Step 2), a trend analysis paragraph (improving / stable / deteriorating), and a summary of the top three non-conformance root causes with corrective actions taken. |
| 6 | Draft Section 8 (Lessons Learned) of the Completion Report, drawing from the Lessons Learned Register. Group lessons by theme (e.g. Planning, Stakeholder Engagement, Training, Monitoring). Present as a structured table followed by three to five prioritised recommendations for the organisation's next SOP programme. |
| 7 | Document any outstanding actions from the data set in Section 9 (Outstanding Actions) of the Completion Report: for each outstanding action, record the description, responsible officer (job title), target date, and risk if not completed. |
| 8 | Write the Executive Summary for the Completion Report. It must: (a) state the programme outcome in the first sentence, (b) summarise key achievements in 3–5 bullet points, (c) state headline KPI results, (d) identify the top 3 issues encountered and how they were resolved, and (e) present 3–5 prioritised recommendations. Length: one page maximum. |
| 9 | Compile the complete Completion Report by inserting all drafted sections and completed templates into the Completion Report Template. Verify that all sections are present and that the document control header is complete (document number, version, date, owner, approver). |
| 10 | Prepare a 5-minute verbal presentation of the Completion Report for the instructor (who will act as the CIO / Programme Sponsor). The presentation must cover: programme outcome, top 3 achievements, top 3 issues, headline KPI results, and top 3 recommendations. |
| 11 | Deliver the verbal presentation. Submit all written outputs (Completion Report, SOP Inventory Table, Lessons Learned Register, KPI calculation worksheet) to the instructor immediately after the presentation. |

---

## Hasil Jangkaan / Expected Outcome

Completed SOP Programme Completion Report package comprising:
- Completion Report (all 9 sections) with completed document control header
- SOP Inventory Table with all SOPs listed
- Lessons Learned Register with recommendations
- KPI calculation worksheet showing workings
- Verbal presentation delivered (5 minutes)
