## Tugasan / Task Description

**Scenario:** You are the IT Systems Manager at a government-linked statutory body (Badan Berkanun). The organisation employs 220 staff across two sites. The Board of Directors has directed the IT Department to develop and implement a set of computer system and network SOPs as a prerequisite for applying for MS ISO/IEC 27001:2022 certification.

You have been appointed Programme Manager for this initiative. Your scope covers five process areas. The following information is provided:

**Existing SOP Status (Simulated Inventory):**

| Process Area | Existing Documentation |
|---|---|
| Firewall rule change management | No documented procedure |
| Server patch management | SOP dated 2020; references superseded platform |
| User account lifecycle management | SOP exists; no offboarding steps; last reviewed 18 months ago |
| Network incident response | Informal checklist; never approved |
| VPN access provisioning | No documented procedure |

**Additional context provided in the scenario data set:**
- Organisation chart with 8 relevant job titles
- Staff count per affected role
- Applicable ISO 27001:2022 Annex A controls per process area
- Simulated ITSM tool report with 3 months of compliance observation data
- Programme timeline constraints: management expects all SOPs approved within 10 weeks; implementation (training + go-live) within 16 weeks

**You must complete the following tasks:**

| Session | Task | Duration |
|---------|------|----------|
| Session 1 | Task 1: Requirements Analysis | 90 min |
| Session 1 | Task 2: SOP Document Preparation (one SOP assigned by assessor) | 150 min |
| Session 2 | Task 3: Implementation Planning | 120 min |
| Session 2 | Task 4: Compliance Monitoring and NC Management | 90 min |
| Session 2 | Task 5: Completion Report and Verbal Presentation | 90 min |

**Task details:**

**Task 1 — Requirements Analysis (90 min):**
Conduct a gap analysis on the five process areas. Produce a completed Gap Analysis Worksheet, Requirements Register, and one-page Executive Summary for the Requirements Report.

**Task 2 — SOP Document Preparation (150 min):**
Draft a complete SOP for the process area assigned by the assessor (one of the five above). The SOP must include all 10 mandatory sections, a swimlane flowchart diagram, and one supporting form. Submit with a completed Document Control Header.

**Task 3 — Implementation Planning (120 min):**
Produce a Communication Plan and Training Plan for the implementation of the SOP developed in Task 2. The plan must address: all affected staff categories, training method selection with justification, training records requirements, and go-live communication sequence.

**Task 4 — Compliance Monitoring and NC Management (90 min):**
Using the compliance observation data in the scenario data set, assess each observation against the SOP produced in Task 2. Raise Non-Conformance Records for all non-conformances found. Calculate the SOP compliance rate KPI. Draft a half-page compliance monitoring summary for management.

**Task 5 — Completion Report and Verbal Presentation (90 min):**
Using the programme data provided in the scenario data set, compile the Completion Report: SOP Inventory Table, Lessons Learned Register, KPI summary, outstanding actions, and Executive Summary. Deliver a 5-minute verbal presentation to the assessor (acting as CIO).
