## Objektif / Objective

Plan and execute a simulated SOP implementation programme: develop a communication plan, design a training plan, perform a compliance monitoring exercise, and manage a simulated non-conformance and change control event.

---

## Tempoh / Duration

5 hours (300 minutes)

---

## Peralatan dan Bahan / Equipment and Materials

| No. | Item | Quantity |
|-----|------|----------|
| 1 | Implementation scenario brief (provided by instructor) | 1 per trainee |
| 2 | Approved SOP document (from KK-02 exercise, or instructor-provided) | 1 per trainee |
| 3 | Communication Plan Template (Form ICT-SOP-CP-001) | 1 per trainee |
| 4 | Training Plan Template (Form ICT-SOP-TP-001) | 1 per trainee |
| 5 | Compliance Monitoring Checklist (Form ICT-SOP-CM-001) | 1 per trainee |
| 6 | Non-Conformance Record Form (Form ICT-SOP-NC-001) | 1 per trainee |
| 7 | SOP Change Request Form (Form ICT-SOP-CR-001) | 1 per trainee |
| 8 | Computer with word processing and spreadsheet software | 1 per trainee |
| 9 | Organisation chart and staff list (simulated — provided by instructor) | 1 per trainee |

---

## Langkah Keselamatan / Safety Precautions

- All simulated staff data (names, email addresses) are fictional — do not use real personal data
- Documents prepared in this exercise are training artefacts only; clearly mark each "LATIHAN / TRAINING USE ONLY"
- Return all printed materials to the instructor at the end of the session

## Prosedur / Procedures

### Bahagian A: Communication and Training Planning (90 minutes)

| Langkah | Arahan / Instruction |
|---------|---------------------|
| A1 | Read the implementation scenario brief. The scenario specifies: the approved SOP, the go-live date (4 weeks from today), the affected departments and staff categories, and any known implementation risks (e.g. staff resistance, shift workers, multi-site deployment). |
| A2 | Complete the Communication Plan Template. For each communication event, specify: audience, communication channel, timing relative to go-live, content summary, and the person responsible for delivery. You must include at minimum: executive briefing, all-staff announcement, training reminder, go-live notice, and post-implementation update. |
| A3 | Complete the Training Plan Template. Identify all staff categories that require training. For each category, specify: training method (classroom / lab / e-learning), training content (overview vs detailed procedure), duration, trainer, venue/platform, and target completion date relative to go-live. |
| A4 | Using the simulated organisation chart, identify any staff groups that present training delivery challenges (e.g. shift workers, remote site staff, contractors). Document how you will address each challenge in the Training Plan. |
| A5 | Specify the training record requirements: what will be recorded, in which system, and what constitutes evidence of training completion. |

### Bahagian B: Compliance Monitoring Exercise (90 minutes)

| Langkah | Arahan / Instruction |
|---------|---------------------|
| B1 | The instructor will provide a simulated compliance monitoring scenario: a set of 10 process observations (described as text records) from staff performing the process covered by the SOP. Some observations are compliant; some represent non-conformances. |
| B2 | For each of the 10 observations, use the Compliance Monitoring Checklist to assess whether the observation is: (a) Compliant with the SOP, (b) Minor non-conformance, or (c) Major non-conformance. Record your assessment with justification referencing the specific SOP section. |
| B3 | For each non-conformance identified, complete a Non-Conformance Record Form: record the NC reference, date, description, SOP clause breached, severity (Minor / Major), root cause (select from: unclear SOP / inadequate training / resource constraint / wilful non-compliance / other), proposed corrective action, responsible officer, and target closure date. |
| B4 | Calculate the following KPIs from the 10 observations: (a) SOP compliance rate (%), (b) number of Minor NCs, (c) number of Major NCs. State whether each KPI meets the target defined in KP-03 (compliance rate ≥ 95%). |
| B5 | Write a short compliance monitoring summary (half-page maximum) suitable for inclusion in a management report. Include: overall compliance status, key non-conformances, root cause analysis, and recommended corrective actions. |

### Bahagian C: Change Control Simulation (60 minutes)

| Langkah | Arahan / Instruction |
|---------|---------------------|
| C1 | The instructor will present a change trigger: a new security policy has been issued that requires an additional two-person authorisation step for all network firewall changes. The current SOP (from the scenario) does not include this step. |
| C2 | Complete the SOP Change Request Form: document the trigger, describe the required change to the SOP, assess the impact (which steps are affected, which staff roles are affected, whether re-training is needed), and assign a priority (Minor revision / Major revision). |
| C3 | Outline the change control workflow for this SOP revision: list each step of the workflow from change request submission to effective date communication. State who is responsible at each step and the maximum time allowed at each step. |
| C4 | Draft the revised procedure step(s) that must be added or modified in the SOP to comply with the new policy. Write the step(s) using the same format as the original SOP (Step | Responsible Role | Action | Input | Output/Evidence). |
| C5 | State what additional training, if any, is required as a result of this change, and how controlled copy distribution will be managed (i.e. how will superseded copies be recalled or invalidated). |

---

## Hasil Jangkaan / Expected Outcome

Completed implementation management package comprising:
- Communication Plan with all required communication events specified
- Training Plan addressing all staff categories including those with special delivery challenges
- Completed Compliance Monitoring Checklist with all 10 observations assessed
- Non-Conformance Records for all identified non-conformances
- KPI calculation with status assessment
- Compliance monitoring summary suitable for a management report
- Completed SOP Change Request Form
- Draft revised SOP procedure step(s) with change control workflow outlined
