## Agihan Masa Teori / Theory Time Allocation

Total theory hours for CoCU 6: **90 hours** (30% of 300 hours)

| KP | Tajuk / Title | Jam / Hours |
|----|--------------|-------------|
| KP(1/4) | Computer System & Network SOP Development and Implementation Requirements Analysis | 27.0 |
| KP(2/4) | Computer System & Network SOP Document Preparation | 22.5 |
| KP(3/4) | SOP Implementation Management | 31.5 |
| KP(4/4) | SOP Development and Implementation Reporting | 9.0 |
| **Jumlah / Total** | | **90.0** |

**Note on hour allocation rationale:**
- KP(1/4) carries the highest theory hours because requirements analysis is the foundation of the entire programme — errors here cascade into all subsequent phases. It covers stakeholder mapping, gap analysis, risk scoring, regulatory alignment, and Requirements Register preparation.
- KP(3/4) has the second highest allocation because SOP implementation management — covering change management, training design, compliance monitoring, non-conformance handling, and post-implementation change control — is the most operationally complex phase and the one most likely to be encountered repeatedly in the trainee's career.

## Kaedah Pengajaran / Teaching Method (4-Step)

### 1. PERSEDIAAN (Preparation)

| Langkah / Step | Aktiviti / Activity | Masa / Duration |
|----------------|---------------------|-----------------|
| 1.1 | Welcome trainees; take attendance | 5 min |
| 1.2 | State learning objectives for the session; relate to CoCU 6 Work Activity | 5 min |
| 1.3 | Activate prior knowledge: ask trainees about their experience with SOPs or procedures in the workplace | 10 min |
| 1.4 | Provide overview of the Information Sheet (KP) content and how it connects to the practical KK exercise | 5 min |
| 1.5 | Distribute the KP handout and any case study materials for the session | 5 min |

### 2. PENYAMPAIAN (Presentation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 2.1 | Deliver theory content from the relevant KP using slides, diagrams, and real-world examples |
| 2.2 | For KP(1/4): present and walk through a completed Gap Analysis Worksheet and Requirements Register using a real or near-real case study |
| 2.3 | For KP(2/4): demonstrate a complete SOP document using a projected example; highlight each mandatory section and explain common drafting errors |
| 2.4 | For KP(3/4): present the ADKAR model applied to SOP rollout; walk through a Communication Plan and Training Plan example; demonstrate how to complete a Non-Conformance Record |
| 2.5 | For KP(4/4): present and deconstruct an Executive Summary example; walk through KPI calculation with sample data on whiteboard |
| 2.6 | Use Socratic questioning throughout: "What would happen if this step were skipped?" "Who should be accountable for this activity?" |
| 2.7 | Highlight regulatory requirements: which ISO 27001 / ISO 9001 clauses mandate each element covered in the KP |

### 3. PENGGUNAAN (Application)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 3.1 | Distribute the corresponding KT (Assignment Sheet) for the session |
| 3.2 | Trainees work on the assignment individually or in pairs as directed |
| 3.3 | Instructor circulates to provide guidance; does not provide answers but asks guiding questions |
| 3.4 | Selected trainees present their answers to the class; class discusses and critiques |
| 3.5 | Instructor provides model answer or key points; corrects misconceptions |

### 4. PENGESAHAN (Confirmation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 4.1 | Review the key learning points from the session (3–5 points maximum) |
| 4.2 | Conduct brief oral questioning: cold-call trainees on definitions, criteria, and decision rules from the KP |
| 4.3 | Collect completed KT for marking; return with feedback at next session |
| 4.4 | Preview the next KP topic and its connection to today's session |
| 4.5 | Record attendance and session completion in the training record system |

## Catatan Pengajar / Instructor Notes

- Level 5 trainees are expected to have prior workplace experience. Draw on this: ask trainees to share examples of SOP deficiencies or implementation failures they have personally encountered. This contextualises the theory and accelerates learning.
- Bilingual competency is essential at this level. Ensure all KP key terms are introduced in both Bahasa Malaysia and English; have trainees practise writing SOP headings bilingually.
- The gap analysis priority scoring exercise in KP(1/4) is often the most challenging — trainees tend to score all gaps as "High". Use guided examples to show how to differentiate scores based on evidence, not intuition.
- For KP(3/4), the ADKAR model should be introduced as a practical tool, not an academic framework. Use role-play to demonstrate "Awareness" communication vs actual "Knowledge" transfer.
