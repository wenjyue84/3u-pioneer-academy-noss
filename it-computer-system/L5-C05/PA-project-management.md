## Arahan kepada Pelatih / Instructions to Trainee

1. This is a PRACTICAL assessment. You will manage a simulated computer system and network project through all four work activities — from requirements analysis to project closure.
2. The assessment is conducted in stages over the assessment period. Each stage corresponds to one Work Activity (WA1–WA4).
3. You will be assessed on: **Process** (how you manage the project), **Output** (quality of deliverables), **Attitude** (professionalism and leadership), **Safety** (data security and document handling), and **Environmental** (professional workspace management).
4. All deliverables must be documented and submitted at the end of each stage.
5. You must work independently. Consultation with the assessor is permitted only to clarify ambiguous instructions — not to obtain guidance on what to do.

---

## Arahan kepada Penilai / Instructions to Assessor

- Provide each trainee with the project brief (Scenario Package) at the start of WA1.
- Observe each trainee continuously during practical sessions. Do NOT provide guidance beyond clarifying ambiguous instructions.
- Assess each criterion as the trainee works through each stage.
- Conduct a brief oral questioning session (10–15 minutes) at the end of each stage to verify understanding of decisions made.
- Verify all submitted documents against the expected output criteria before recording marks.
- Two assessors are recommended for the WA3 stage (simulated steering committee and conflict scenario).

## Tugasan / Task Description

### Senario Projek / Project Scenario

**Nama Projek / Project Name:** Sistem Rangkaian dan Komputer Pejabat Cawangan / Branch Office Computer and Network System

**Latar Belakang / Background:**

Sebuah syarikat perkhidmatan kewangan sederhana besar baru sahaja menyewa pejabat baharu di sebuah bangunan 4 tingkat di Petaling Jaya. Pejabat baharu ini akan menempatkan 120 kakitangan merangkumi Jabatan Kewangan, Operasi, Pemasaran, dan IT. Tiada infrastruktur rangkaian atau sistem komputer sedia ada di lokasi ini. Syarikat memerlukan rangkaian yang selamat, bersegmen VLAN, dan infrastruktur komputer yang lengkap — termasuk pelayan fail, sistem sandaran, akses Wi-Fi, dan keselamatan rangkaian — siap beroperasi dalam tempoh 16 minggu dengan bajet RM 380,000.

*(A medium-sized financial services company has leased new office space in a 4-floor building in Petaling Jaya. The new office will house 120 staff across Finance, Operations, Marketing, and IT departments. There is no existing network or computer infrastructure at this location. The company requires a secure, VLAN-segmented network and complete computing infrastructure — including file server, backup system, Wi-Fi access, and network security — operational within 16 weeks with a budget of RM 380,000.)*

## Peringkat Penilaian / Assessment Stages

### PERINGKAT WA1: Analisis Keperluan Projek / WA1 Stage: Project Requirements Analysis

**Tempoh / Duration:** 3 hours

**Tugasan / Tasks:**

1. Analyse the project brief and identify a minimum of 20 requirements classified into Functional, Non-Functional, Technical, and Business categories
2. Conduct two simulated stakeholder interviews (instructor role-plays assigned stakeholders) and extract additional requirements
3. Apply MoSCoW prioritisation with written justification for each classification
4. Validate all requirements against the four criteria (Complete, Consistent, Testable, Achievable)
5. Produce a completed Requirements Traceability Matrix (RTM) with minimum 20 requirements

**Penyerahan WA1 / WA1 Deliverables:** Requirements classification table, Interview notes, MoSCoW table, Validated RTM

---

### PERINGKAT WA2: Perancangan Projek / WA2 Stage: Project Planning

**Tempoh / Duration:** 4 hours

**Tugasan / Tasks:**

1. Develop WBS (minimum Level 3, 20+ work packages) with WBS Dictionary entries
2. Produce Activity List with durations, resources, and dependencies
3. Identify the critical path (CPM — manual calculation for minimum 8 activities)
4. Develop Gantt chart (schedule baseline) using provided software
5. Prepare bottom-up budget (must not exceed RM 380,000 including contingency)
6. Develop Risk Register (minimum 8 risks with full response plans)
7. Develop Communications Management Plan

**Penyerahan WA2 / WA2 Deliverables:** WBS + Dictionary, Activity List, CPM calculation, Gantt chart, Budget table, Risk Register, Communications Plan

---

### PERINGKAT WA3: Pengurusan Pelaksanaan Projek / WA3 Stage: Managing Project Execution

**Tempoh / Duration:** 4 hours

**Tugasan / Tasks:**

1. Process two change requests (provided in sealed envelope by assessor) through full change control process
2. Calculate EVM metrics from Week 8 performance data (provided by assessor); interpret results and propose corrective action
3. Resolve a team conflict scenario (assessor role-plays the conflicting party)
4. Update the Risk Register based on the Week 8 situation report
5. Produce a formal Week 8 Project Status Report
6. Present the status report in a 15-minute simulated Steering Committee (assessor role-plays sponsor)

**Penyerahan WA3 / WA3 Deliverables:** Two completed Change Request Forms with impact analysis, EVM calculation and corrective action plan, Conflict resolution record, Updated Risk Register, Formal Status Report

---

### PERINGKAT WA4: Penutupan Projek / WA4 Stage: Project Closure

**Tempoh / Duration:** 3 hours

**Tugasan / Tasks:**

1. Complete the Final Acceptance Checklist
2. Produce a representative As-Built Documentation package (network diagram, equipment inventory table, IP address plan, one SOP)
3. Produce Lessons Learned Register (minimum 6 entries, 3+ categories)
4. Produce Project Closure Report (all required sections)
5. Present closure package and conduct 10-minute handover to assessor (role-playing as client CIO)
6. Obtain assessor's signature on the Project Acceptance Certificate

**Penyerahan WA4 / WA4 Deliverables:** Final Acceptance Checklist, As-Built Documentation package, Lessons Learned Register, Project Closure Report, Signed Project Acceptance Certificate
