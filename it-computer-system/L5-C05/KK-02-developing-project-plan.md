**Objektif / Objective:** Develop a comprehensive project management plan for the headquarters network upgrade project, including WBS, Gantt chart, budget, and risk register.

**Arahan / Instructions:** Trainees are required to complete all tasks using the approved requirements (RTM) from KK(1/4) as the input. Refer to KP(2/4) for reference. Consult the instructor if clarification is needed.

---

## Objektif / Objective

Produce an integrated project management plan covering scope (WBS), schedule (Gantt/CPM), budget (bottom-up estimate with EVM baseline), and risk management for a computer system and network upgrade project.

---

## Tempoh / Duration

10 hours (distributed across 2–3 sessions)

## Senario / Scenario

Continuation of the Prisma Teknologi Sdn. Bhd. Headquarters Integrated Network System project from KK(1/4). The RTM has been approved by the stakeholders. You are now tasked with developing the full project management plan.

**Maklumat Tambahan / Additional Information:**

| Parameter | Nilai / Value |
|-----------|---------------|

| Tarikh Siap Dikehendaki / Required Completion Date | 31 Oktober 2026 (18 minggu / 18 weeks) |

## Prosedur / Procedures

| Langkah | Arahan / Instruction |
|---------|---------------------|
| **1** | Using the approved RTM from KK(1/4), identify all major project deliverables. Organise these into a Work Breakdown Structure (WBS) to at least Level 3 (minimum 6 Level-2 categories; minimum 25 Level-3 work packages). Prepare a WBS Dictionary entry for each Level-3 work package, including: description, owner, estimated effort (person-hours), and acceptance criteria. |
| **2** | List all activities required to complete each WBS work package. For each activity, determine: (a) estimated duration in working days, (b) resource required (role, not name), and (c) predecessor activities (dependency type: FS, SS, FF). Produce an Activity List with minimum 30 activities. |
| **3** | Draw the precedence network diagram for all activities. Perform the Forward Pass and Backward Pass calculations manually for a subset of at least 10 activities to identify the critical path. Clearly mark the critical path. Calculate total project duration and compare against the required completion date (18 weeks). |
| **4** | Develop the project Gantt chart using the project management software provided. Include: (a) all activities from Step 2, (b) milestone diamonds at key approval points (design sign-off, procurement complete, implementation complete, UAT complete, go-live), (c) dependency arrows, (d) resource assignments. Save the Gantt chart as the **Schedule Baseline**. |
| **5** | If the initial schedule exceeds 18 weeks, apply schedule compression. Document which technique you used (crashing or fast tracking), which activities were targeted, the rationale, the cost impact, and the revised project duration. |
| **6** | Develop a bottom-up cost estimate using the instructor-provided price list. Prepare a budget table covering: hardware, software licences, cabling, labour, project management, training, and contingency reserve (12%). Verify that the total budget does not exceed RM 500,000. If it does, identify which items to reduce or defer, with justification. |
| **7** | Establish the Cost Baseline (time-phased budget — how much is planned to be spent each week). Plot the planned S-curve (Planned Value vs. time) for the 18-week project. |
| **8** | Develop the Risk Register for the project. Identify minimum 10 risks across at least three categories (Technical, Management, External). For each risk: assign ID, describe the risk event, assess probability (High/Medium/Low) and impact (High/Medium/Low), determine risk level, select a response strategy, assign an owner, and describe the specific mitigation or contingency action. |
| **9** | Develop a Communications Management Plan. Define: (a) who receives information, (b) what information (type and content), (c) format (email, report, meeting, dashboard), (d) frequency, and (e) responsible sender. Cover all stakeholders identified in KK(1/4). |
| **10** | Compile all planning outputs into a draft Project Management Plan document with a cover page, table of contents, and the following sections: Scope Management, Schedule, Budget, Risk Register, and Communications Plan. Present the plan to the instructor for a simulated sponsor approval review. Incorporate feedback and produce the final approved version. |

---

## Hasil Jangkaan / Expected Outcome

Upon completion of this Work Sheet, trainees shall produce:

1. WBS diagram (minimum Level 3, 25+ work packages) with WBS Dictionary
2. Activity List with durations, resources, and dependencies (30+ activities)
3. Critical path network diagram with Forward/Backward Pass calculations
4. Gantt chart (schedule baseline) showing all activities, milestones, and dependencies
5. Schedule compression analysis (if required)
6. Bottom-up budget table with contingency and cost baseline S-curve
7. Risk Register (minimum 10 risks with full response plans)
8. Communications Management Plan
9. Compiled Project Management Plan document
