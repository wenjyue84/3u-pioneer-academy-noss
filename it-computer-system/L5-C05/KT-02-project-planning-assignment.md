## Bahagian A: Soalan Pelbagai Pilihan / Section A: Multiple Choice (20 marks)

Answer all 10 questions. Each question carries 2 marks.

**A1.** The Work Breakdown Structure (WBS) is defined as:

- (a) The project's communication plan displayed as a hierarchy
- (b) A hierarchical decomposition of the total project scope into work packages
- (c) A list of all project risks organised by category
- (d) The project organisational chart

**A2.** In a Finish-to-Start (FS) dependency, Activity B can begin only when:

- (a) Activity B is 50% complete
- (b) Activity A has started
- (c) Activity A has finished
- (d) Both A and B start simultaneously

**A3.** Which activity characteristic defines the Critical Path?

- (a) Activities with the highest cost
- (b) Activities with the longest individual duration
- (c) Activities with Total Float = 0
- (d) Activities assigned to the most experienced team member

**A4.** The "Fast Tracking" schedule compression technique involves:

- (a) Hiring additional resources for critical path activities
- (b) Removing lower-priority deliverables from scope
- (c) Performing sequential activities in parallel or with overlap
- (d) Replacing slow workers with faster ones

**A5.** The most accurate cost estimation method for a project is:

- (a) Analogous estimating
- (b) Parametric estimating
- (c) Bottom-up estimating
- (d) Expert judgment only

**A6.** A contingency reserve in the project budget is intended to cover:

- (a) Unknown unknowns that cannot be anticipated
- (b) Identified risks with quantified cost impact
- (c) The project manager's personal expenses
- (d) Vendor profit margin

**A7.** If a project's Cost Performance Index (CPI) is 0.88, this means:

- (a) The project is 88% complete
- (b) The project is spending RM 1.14 for every RM 1.00 of work accomplished
- (c) The project is 12% under budget
- (d) The project is 12% ahead of schedule

**A8.** The formula for Estimate at Completion (EAC) assuming current CPI continues is:

- (a) BAC − EV
- (b) BAC / CPI
- (c) EV / PV
- (d) AC + (BAC − EV)

**A9.** A risk that has a HIGH probability and HIGH impact should be:

- (a) Accepted passively with no action
- (b) Deferred until after project completion
- (c) Treated as critical — immediate mitigation required
- (d) Transferred to the client automatically

**A10.** The WBS Dictionary contains, for each work package:

- (a) Only the work package name and assigned resource
- (b) Description, owner, estimated effort, cost, acceptance criteria, and dependencies
- (c) The CPM network diagram
- (d) The vendor quotation for that work package

## Bahagian B: Soalan Jawapan Pendek / Section B: Short Answer (30 marks)

**B1.** A project has the following activities:

| Aktiviti | Tempoh (hari) | Bergantung Kepada |
|----------|---------------|-------------------|
| A | 4 | — |
| B | 6 | A |
| C | 3 | A |
| D | 5 | B |
| E | 4 | C |
| F | 2 | D, E |

(a) Draw the precedence network diagram for this project. *(4 marks)*

(b) Perform the Forward Pass and Backward Pass calculations. Show all ES, EF, LS, LF, and Total Float values for each activity. *(6 marks)*

(c) Identify the critical path and state the total project duration. *(2 marks)*

**B2.** Explain the difference between "Crashing" and "Fast Tracking" as schedule compression techniques. State ONE advantage and ONE disadvantage of each. *(8 marks)*

**B3.** Describe the purpose of the Communications Management Plan and list FOUR (4) elements it must contain for each identified communication. *(5 marks)*

**B4.** Explain the difference between a Contingency Reserve and a Management Reserve. Who controls each, and under what circumstances is each used? *(5 marks)*

## Bahagian C: Soalan Esei / Section C: Essay (50 marks)

**C1.** A government agency has appointed you to manage a data centre consolidation project. The approved budget is RM 2.8 million and the project must be completed within 9 months.

(a) Describe the process you would use to develop the Work Breakdown Structure (WBS) for this project, including the levels of decomposition, what a WBS Dictionary entry contains, and how the WBS ensures the "100% Rule" is met. *(15 marks)*

(b) The project is at Week 12 of 36. The following EVM data has been reported:

| Item | Nilai / Value |
|------|---------------|
| BAC | RM 2,800,000 |
| % planned complete at Week 12 | 33% |
| % actually complete at Week 12 | 28% |
| Actual cost spent to date | RM 870,000 |

Calculate: PV, EV, AC, SV, CV, SPI, CPI, and EAC. Interpret the project's current performance and recommend TWO (2) corrective actions. *(20 marks)*

(c) Develop a Risk Register for FIVE (5) risks relevant to a data centre consolidation project. For each risk, provide: Risk ID, Description, Category, Probability (H/M/L), Impact (H/M/L), Risk Level, Response Strategy, and Specific Mitigation Action. *(15 marks)*
