## Bahagian A: Soalan Pelbagai Pilihan / Section A: Multiple Choice (20 marks)

Answer all 10 questions. Each question carries 2 marks.

**A1.** The Project Acceptance Certificate is signed by:

- (a) Only the project manager
- (b) Only the project sponsor
- (c) The client's authorised representative and the project manager
- (d) All project team members

**A2.** As-built documentation differs from design documentation because:

- (a) As-built documents are produced at project initiation
- (b) As-built documents record the system as it was actually constructed, not as it was originally designed
- (c) Design documentation is more detailed than as-built documentation
- (d) As-built documents are only required for construction projects, not IT projects

**A3.** The minimum recommended document retention period for government-related IT projects in Malaysia is:

- (a) 2 years
- (b) 5 years
- (c) 7 years
- (d) 10 years

**A4.** A Post-Implementation Review (PIR) is typically conducted:

- (a) Immediately before project go-live
- (b) During UAT testing
- (c) 30–90 days after go-live
- (d) At the start of the next project

**A5.** The primary purpose of a lessons learned workshop is to:

- (a) Identify team members who underperformed
- (b) Capture knowledge — both positive and negative — to improve future projects
- (c) Prepare the project closure report
- (d) Obtain final sign-off from the client

**A6.** The "hypercare" period after project go-live typically involves:

- (a) The project team being formally disbanded immediately
- (b) The project team remaining available to support the operations team during the initial 30–60 days post go-live
- (c) The client managing all issues without project team involvement
- (d) The vendor taking full responsibility for all issues

**A7.** An "early closure" (premature project termination) requires:

- (a) No documentation — just stop work
- (b) Documenting reasons, closing contracts, archiving partial work, and capturing lessons learned
- (c) Completing all remaining deliverables before closure
- (d) Returning all project funds to the sponsor without a report

**A8.** The Project Closure Report is submitted to:

- (a) The project team for archiving only
- (b) The project sponsor for approval
- (c) All end users of the system
- (d) The vendor as a contractual requirement

**A9.** Outstanding items at project closure that are minor and do not prevent acceptance should be:

- (a) Ignored once the acceptance certificate is signed
- (b) Added to the Risk Register
- (c) Documented in an Outstanding Items Register with a resolution schedule; client formally acknowledges them in writing
- (d) Resolved before any closure documents are prepared

**A10.** Which document provides the IT operations team with the step-by-step instructions for common administrative tasks on the new system?

- (a) Project Charter
- (b) Risk Register
- (c) Standard Operating Procedure (SOP)
- (d) Requirements Traceability Matrix

## Bahagian B: Soalan Jawapan Pendek / Section B: Short Answer (30 marks)

**B1.** List FIVE (5) types of documents that must be included in an as-built documentation package for a network infrastructure project. For each, state what information it should contain. *(10 marks)*

**B2.** Explain the purpose of a lessons learned register and describe FOUR (4) guiding questions that are typically used in a lessons learned workshop. *(8 marks)*

**B3.** A project has been completed with the following final data:

| Item | Nilai / Value |
|------|---------------|
| Approved budget (BAC) | RM 750,000 |
| Actual final cost | RM 782,000 |
| Original planned completion date | 15 September 2026 |
| Actual completion date | 3 October 2026 |
| UAT pass rate | 94.5% |
| Critical defects at closure | 0 |

Prepare the Budget vs. Actual comparison section of the Project Closure Report for this project, including the variance amount, variance percentage, and a brief narrative explanation. *(7 marks)*

**B4.** Describe the BAU (Business As Usual) transition plan activities that must occur BEFORE the project team is formally withdrawn from a network infrastructure project. List minimum FOUR (4) specific activities. *(5 marks)*

## Bahagian C: Soalan Esei / Section C: Essay (50 marks)

**C1.** You have just completed a server virtualisation project for a private hospital. The project delivered 12 virtual servers replacing 30 physical servers. All UAT cases passed. The project came in RM 23,000 over the approved budget of RM 380,000, and was completed 2 weeks later than planned.

(a) Describe the complete client handover process you would execute, including: the final acceptance checklist, how you would handle the minor budget and schedule variances, the demonstration and sign-off process, and what the Project Acceptance Certificate must contain. *(20 marks)*

(b) Facilitate a simulated lessons learned discussion for this project. Identify and document FIVE (5) lessons learned entries in a properly formatted Lessons Learned Register. Your entries must cover at least THREE (3) different categories (e.g., Planning, Technical, Communication, Procurement, Quality) and must include both positive lessons (things that went well) and negative lessons (things to improve). *(15 marks)*

(c) Develop a Post-Implementation Review (PIR) plan for this project, to be conducted 45 days after go-live. Your plan must define: (i) the five evaluation questions with measurable success criteria specific to a server virtualisation project, (ii) the data source for each question, and (iii) who will conduct the PIR and who will receive the findings. *(15 marks)*
