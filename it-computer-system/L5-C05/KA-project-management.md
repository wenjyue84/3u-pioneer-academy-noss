## BAHAGIAN A: SOALAN PELBAGAI PILIHAN / SECTION A: MULTIPLE CHOICE (30 marks)

Answer all 15 questions. Each question carries 2 marks. Circle the correct answer.

**1.** The document that formally authorises a project and names the project manager is:

- (a) Project Management Plan
- (b) Project Charter
- (c) Requirements Traceability Matrix
- (d) Statement of Work

**2.** A Functional requirement for a network project states "what" the system must do. An example is:

- (a) "Network uptime must be ≥ 99.9% monthly"
- (b) "The system must support VLAN segmentation for Finance, HR, and Operations"
- (c) "The project must comply with PDPA 2010"
- (d) "Core switches must support 48 PoE+ ports"

**3.** The MoSCoW "Must Have" category means:

- (a) The requirement is desirable but can be deferred
- (b) The project will fail without this requirement being delivered
- (c) This requirement is excluded from the current project
- (d) This requirement is under review by the CCB

**4.** The WBS "100% Rule" states that:

- (a) All work packages must be completed in 100 days
- (b) Every team member must be 100% allocated to the project
- (c) The WBS captures 100% of the project scope — nothing more and nothing less
- (d) 100% of risks must be documented in the Risk Register

**5.** An activity on the Critical Path has a Total Float of:

- (a) Greater than 5 days
- (b) 1 day
- (c) 0
- (d) Any positive number

**6.** The schedule compression technique that increases project risk but does not increase cost is:

- (a) Crashing
- (b) Resource levelling
- (c) Fast tracking
- (d) Scope reduction

**7.** At Week 6 of a project: BAC = RM 400,000; EV = RM 100,000; AC = RM 115,000. The Cost Variance (CV) is:

- (a) +RM 15,000
- (b) −RM 15,000
- (c) −RM 115,000
- (d) +RM 100,000

**8.** An Estimate at Completion (EAC) of RM 520,000 against a BAC of RM 480,000 means:

- (a) The project will finish RM 40,000 under budget
- (b) The project is projected to overspend by RM 40,000
- (c) The project is 40% complete
- (d) The project has spent RM 520,000 so far

**9.** The risk response strategy of "transferring" a risk means:

- (a) Eliminating the risk by changing the project plan
- (b) Reducing the probability or impact of the risk
- (c) Shifting the financial impact of the risk to a third party (e.g., via insurance or vendor SLA)
- (d) Accepting the risk without any action

**10.** In Tuckman's team development model, the "Performing" stage is characterised by:

- (a) Team members being polite but uncertain of their roles
- (b) Disagreements over approaches and priorities
- (c) High productivity; team self-manages effectively
- (d) Team disbanding after project completion

**11.** The RACI chart cell "A" (Accountable) means:

- (a) The person who physically does the work
- (b) The person who must answer for the correct completion of the work — only one per activity
- (c) The person who is kept informed of progress
- (d) The person whose input is required before completion

**12.** A quality gate in an IT project serves as:

- (a) A physical security door protecting the server room
- (b) A formal checkpoint where defined criteria must be met before the project proceeds to the next phase
- (c) The final acceptance test performed by end users
- (d) A review of the project budget only

**13.** The Project Acceptance Certificate is significant because it:

- (a) Authorises the project manager to start the project
- (b) Transfers risk from the client to the vendor
- (c) Formally confirms that the client has received and accepted all project deliverables
- (d) Releases the project contingency reserve

**14.** As-built documentation differs from design documentation in that it records:

- (a) The original intended design
- (b) The system as it was actually built, which may differ from the design due to approved changes
- (c) Only the components that failed during testing
- (d) The vendor's technical specifications, not the actual configuration

**15.** A Post-Implementation Review (PIR) is best conducted:

- (a) On the day of project go-live
- (b) During the UAT phase
- (c) 30–90 days after go-live when the system has been in production use
- (d) One year after the project ends

## BAHAGIAN B: SOALAN JAWAPAN PENDEK / SECTION B: SHORT ANSWER (30 marks)

Answer all 6 questions.

**16.** A network upgrade project has the following activities and dependencies:

| Aktiviti | Tempoh (hari) | Bergantung Kepada |
|----------|---------------|-------------------|
| A: Requirements analysis | 5 | — |
| B: Network design | 8 | A |
| C: Procurement | 12 | B |
| D: Cabling works | 7 | C |
| E: Switch configuration | 4 | C |
| F: Server deployment | 6 | D |
| G: Integration testing | 5 | E, F |
| H: UAT | 4 | G |

(a) Identify ALL paths through the network and calculate the duration of each path. *(3 marks)*

(b) State the critical path and total project duration. *(2 marks)*

**17.** At Week 15 of a 30-week project:
- BAC = RM 900,000
- % planned complete = 50%
- % actually complete = 43%
- Actual cost to date = RM 408,000

Calculate: PV, EV, AC, SV, CV, SPI, CPI, and EAC. *(8 marks)*

**18.** Describe the FOUR (4) validation criteria that every requirement must satisfy before it can be baselined. For each criterion, provide a brief example of a requirement that fails that criterion. *(8 marks)*

**19.** Explain the difference between a project "issue" and a project "risk". Describe how each is managed using the appropriate project management tool. *(4 marks)*

**20.** List FIVE (5) documents that must be handed over to the client as part of the as-built documentation package for a network infrastructure project. State the purpose of each. *(5 marks)*

## BAHAGIAN C: SOALAN ESEI / SECTION C: ESSAY (40 marks)

Answer both questions.

**21.** You are the project manager for a university network modernisation project. The university has 3,000 students and 500 staff across a 15-building campus. The approved budget is RM 1.8 million and the project duration is 12 months.

(a) Describe how you would conduct the requirements analysis for this project. Include: the elicitation techniques you would use and for which stakeholders, how you would classify and validate requirements, and how you would handle a situation where the IT Director's requirements conflict with the Finance Director's requirements. *(10 marks)*

(b) Develop the project's risk management plan. Identify FIVE (5) specific risks for a large campus network project, assess each risk using the Probability × Impact matrix, select an appropriate response strategy for each, and describe the specific mitigation action. *(10 marks)*

(c) At Month 8 of 12, you receive this EVM data: BAC = RM 1,800,000; PV = RM 1,200,000; EV = RM 1,044,000; AC = RM 1,100,000. A key stakeholder has also submitted a change request to extend Wi-Fi coverage to student residential halls (3 additional buildings), estimated at +RM 180,000 and +6 weeks.

Calculate all EVM metrics, interpret the project health, process the change request through the full change control process (including impact analysis and CCB recommendation), and describe how the project plan would be updated if the change is approved. *(20 marks)*
