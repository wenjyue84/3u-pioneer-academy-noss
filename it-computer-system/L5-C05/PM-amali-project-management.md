## Kaedah Pengajaran / Teaching Method (4-Step)

### 1. PERSEDIAAN (Preparation)

| Langkah / Step | Aktiviti / Activity | Masa / Duration |
|----------------|---------------------|-----------------|
| 1.1 | Welcome trainees; take attendance; verify workstation readiness | 5 min |
| 1.2 | State the practical learning objectives for the session, referencing the relevant KK | 10 min |
| 1.3 | Review safety and professional standards: document handling, data confidentiality, software licensing | 5 min |
| 1.4 | Distribute the KK (Work Sheet) and explain the scenario, tasks, and expected outputs | 10 min |
| 1.5 | Verify that all required templates, software, and scenario materials are available at each workstation | 5 min |

### 2. PENYAMPAIAN (Demonstration)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 2.1 | Demonstrate the key practical task step-by-step using the projector (e.g., build a WBS in ProjectLibre, construct an RTM in Excel, process a change request using the standard form) |
| 2.2 | Walk through a complete worked example for numerical tasks (CPM Forward/Backward Pass, EVM calculation) — show every step on the whiteboard before trainees attempt independently |
| 2.3 | Demonstrate common errors and how to identify them (e.g., forgetting to update the baseline after an approved change, incorrectly classifying a non-functional requirement as functional) |
| 2.4 | Model professional PM behaviour during simulation exercises (e.g., how to chair a CCB meeting, how to deliver bad news in a status report without alarming stakeholders unnecessarily) |
| 2.5 | Answer clarifying questions before trainees begin independent work |

### 3. PENGGUNAAN (Practice)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 3.1 | Trainees perform the practical tasks at their individual workstations following the KK procedure |
| 3.2 | Instructor circulates to observe approach, identify misconceptions, and provide targeted guidance without giving answers |
| 3.3 | For simulation exercises (stakeholder interviews, CCB meetings, conflict resolution, Steering Committee presentations), instructor rotates through groups to observe and facilitate |
| 3.4 | Brief oral questioning during practice: "Why did you classify this as Non-Functional?", "What would happen if you approved this change without an impact analysis?" |
| 3.5 | Trainees complete the KK Assessment Checklist as they work through each step |

### 4. PENGESAHAN (Confirmation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 4.1 | Instructor reviews each trainee's key deliverable against the expected outcome criteria before session ends |
| 4.2 | Conduct a 10-minute group debrief: what worked well, what was difficult, what would they do differently |
| 4.3 | Provide structured feedback on process (methodology followed), output (quality of deliverable), and professional conduct |
| 4.4 | Trainees save and organise all work to the designated shared drive folder before leaving |
| 4.5 | Record session completion in the instructor log; note any trainees requiring remediation before the next session |

## Keselamatan dan Etika Profesional / Safety and Professional Ethics

- All project scenario documents are confidential training materials — do not share outside the classroom or post online
- Follow organisational file naming conventions for all documents produced (as specified in the KK procedures)
- Do not install unauthorised software on laboratory computers
- Log out of all systems and save all work before leaving each session
- Treat simulated stakeholder scenarios with the same professional respect as real stakeholder interactions
- In simulation exercises involving role-play (conflict, difficult stakeholders), maintain professional conduct at all times

## Penilaian Amali / Practical Assessment

Upon completion of all 4 KK sessions, trainees will sit for the Performance Assessment (PA):

- **Kod / Code:** IT-020-5:2013-C05/PA
- **Tempoh minimum / Minimum duration:** 14 hours (conducted in 4 stages across assessment days)
- **Format:** Practical project management simulation — 4 stages (WA1–WA4)
- **Kriteria penilaian / Assessment criteria:** Process (30%), Output (30%), Attitude (15%), Safety (15%), Environmental (10%)
- **Markah lulus / Pass mark:** 60% (as per JPK and institutional requirements)
