## Bahagian A: Soalan Pelbagai Pilihan / Section A: Multiple Choice (20 marks)

Answer all 10 questions. Each question carries 2 marks.

**A1.** In Tuckman's model of team development, the stage where disagreements over approaches and roles are most common is:

- (a) Forming
- (b) Storming
- (c) Norming
- (d) Performing

**A2.** A project status report shows SPI = 0.87 and CPI = 1.05. This means the project is:

- (a) Ahead of schedule and over budget
- (b) Behind schedule and under budget
- (c) Behind schedule and over budget
- (d) On schedule and under budget

**A3.** The PREFERRED conflict resolution technique in PMBOK® is:

- (a) Forcing
- (b) Withdrawing
- (c) Collaborating
- (d) Compromising

**A4.** An "issue" in project management differs from a "risk" because:

- (a) Issues only affect the schedule; risks only affect the budget
- (b) An issue is a current problem; a risk is a future uncertain event
- (c) Issues are managed by the sponsor; risks by the project manager
- (d) There is no practical difference between them

**A5.** The Change Control Board (CCB) is responsible for:

- (a) Raising change requests on behalf of users
- (b) Implementing approved changes in the technical environment
- (c) Reviewing change requests and deciding to approve, reject, or defer them
- (d) Tracking the project schedule on behalf of the sponsor

**A6.** Quality Assurance (QA) differs from Quality Control (QC) in that:

- (a) QA checks the final product; QC checks the process
- (b) QA is performed by external auditors only; QC is internal
- (c) QA audits processes and methodology; QC inspects products and deliverables
- (d) QA is done at project closure; QC is done at project initiation

**A7.** Configuration management in an IT project ensures that:

- (a) All network cables are labelled correctly
- (b) Every configuration change is documented with who, when, what, and why
- (c) The project budget is not exceeded
- (d) Vendor invoices are processed promptly

**A8.** A "traffic light" status of AMBER in a project status report indicates:

- (a) The project is on track with no significant issues
- (b) The project is at risk — issues identified but corrective action is in progress
- (c) The project has failed and must be terminated
- (d) The project is ahead of schedule and under budget

**A9.** When a risk event actually occurs during project execution, it should be:

- (a) Ignored if the impact is less than RM 5,000
- (b) Removed from the Risk Register and forgotten
- (c) Escalated immediately to the sponsor without analysis
- (d) Logged as an issue in the Issue Log and the pre-planned risk response activated

**A10.** The RACI model in team management stands for:

- (a) Report, Approve, Coordinate, Inform
- (b) Responsible, Accountable, Consulted, Informed
- (c) Review, Assign, Control, Implement
- (d) Risk, Assumption, Constraint, Issue

- BAC = RM 600,000
- % planned complete = 40%
- % actually complete = 35%
- Actual cost to date = RM 228,000

Calculate: PV, EV, AC, SV, CV, SPI, CPI, and EAC. State whether the project is on track, behind schedule, over budget, or a combination. *(10 marks)*

**B2.** Describe the FIVE (5) stages in Tuckman's team development model. For each stage, state ONE specific action a project manager should take. *(10 marks)*

**B3.** Explain the difference between Quality Assurance (QA) and Quality Control (QC) in the context of a network infrastructure project. Give ONE specific example of a QA activity and ONE specific example of a QC activity. *(5 marks)*

**B4.** A stakeholder requests a change that would add RM 45,000 to the project budget and delay completion by 10 days. Describe the FOUR steps of the Integrated Change Control Process that the project manager must follow. *(5 marks)*

## Bahagian C: Soalan Esei / Section C: Essay (50 marks)

**C1.** You are managing a wide area network (WAN) upgrade project for a company with offices in Kuala Lumpur, Penang, and Johor Bahru. The project is at Week 14 of 24 weeks. You receive the following situation report:

*EVM data: BAC = RM 1,200,000; PV = RM 700,000; EV = RM 588,000; AC = RM 672,000*

*Issues: (a) The Penang office installation is 3 weeks behind because the building management has not granted access to the server room. (b) A key network engineer has resigned and cannot be replaced for 2 weeks. (c) The client has requested adding video conferencing infrastructure to the scope — estimated RM 85,000 additional cost and 3 weeks additional schedule.*

(a) Calculate all EVM metrics (SV, CV, SPI, CPI, EAC, VAC). Interpret the results and state what the data tells you about overall project health. *(15 marks)*

(b) For EACH of the three issues described above: (i) assess the severity and impact on the project, (ii) describe the corrective or preventive action you would take, and (iii) state whether escalation to the sponsor is required and why. *(20 marks)*

(c) Process the client's scope change request for video conferencing infrastructure. Describe the complete change control process you would follow, the impact analysis you would perform, your CCB recommendation with full justification, and how the project plan would be updated if the change is approved. *(15 marks)*
