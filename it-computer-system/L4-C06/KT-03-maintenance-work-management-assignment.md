## Soalan / Questions

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (20 marks)

**A1.** The correct lifecycle sequence for a work order is:

- (a) Assigned → Raised → In Progress → Closed → Completed → Verified
- (b) Raised → Assigned → In Progress → Completed → Verified → Closed
- (c) In Progress → Raised → Assigned → Verified → Completed → Closed
- (d) Raised → Completed → Assigned → In Progress → Verified → Closed

**A2.** A CMMS (Computerised Maintenance Management System) is used to:

- (a) Remotely control technicians' movements during maintenance
- (b) Automatically generate scheduled work orders, track status, manage inventory, and report KPIs
- (c) Replace the maintenance manager role with artificial intelligence
- (d) Only manage contractor invoices and payments

**A3.** When a technician discovers an unexpected fault during a planned PM, the maintenance manager should FIRST:

- (a) Ignore it and proceed with the scheduled PM only
- (b) Log a new work order, assess priority, and decide whether to fix immediately or schedule separately
- (c) Ask the technician to fix it without logging anything
- (d) Cancel the maintenance window immediately

**A4.** Before a contractor begins work on the server room, the maintenance manager must ensure:

- (a) The contractor has brought their own tools and does not need supervision
- (b) A site access authorisation, work permit (if applicable), and data security undertaking are in place
- (c) The contractor has a university degree in IT
- (d) The contractor is a personal friend of the IT Manager

**A5.** Which of the following is NOT a valid quality assurance check before closing a work order?

- (a) Verifying work was performed as per the SOP
- (b) Confirming system functionality after maintenance
- (c) Checking that the technician's uniform is clean
- (d) Ensuring spare parts used are recorded in inventory

### Bahagian C: Soalan Esei / Essay (30 marks)

**C1.** Read the following scenario and answer the questions:

You are the IT Maintenance Manager supervising a Saturday maintenance window. Three activities are scheduled:
- Server A: monthly physical check (Technician 1)
- Switch SW-02: firmware update (Technician 2)
- UPS: annual battery replacement (external contractor — Powertech Services)

At 02:15, you receive the following reports:
- Technician 1: "Server A is back online — no issues found."
- Technician 2: "The firmware update failed. The switch is now showing no active ports. All wired connections to the server room are down."
- Contractor: "We replaced the UPS battery. System is running. We need you to sign off."

(a) For the switch failure: classify the incident, assign a priority, and describe the steps you would take as manager in the next 30 minutes. (12 marks)

(b) For the UPS contractor sign-off: describe what you must verify before signing, and what documentation you must obtain from the contractor. (8 marks)

(c) Describe the maintenance session summary report you would prepare for the IT Manager after the window closes. What sections must it contain? (10 marks)
