## Kaedah Pengajaran / Teaching Method (4-Step)

### 1. PERSEDIAAN (Preparation)

| Langkah / Step | Aktiviti / Activity | Masa / Duration |
|----------------|---------------------|-----------------|
| 1.1 | Welcome trainees and take attendance | 5 min |
| 1.2 | State the learning objectives for the session | 5 min |
| 1.3 | Relate the topic to the management context — Level 4 is about organising, planning, and directing; not just doing | 10 min |
| 1.4 | Provide an overview of the KP content and how it connects to the other Work Activities in the CU | 5 min |

### 2. PENYAMPAIAN (Presentation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 2.1 | Deliver theory content from the relevant KP using slides, management frameworks, and real-world case studies |
| 2.2 | Explain key management concepts: MRA methodology, SLA interpretation, maintenance strategy, work order management, incident vs problem management, KPI reporting |
| 2.3 | Use worked examples for quantitative topics: MTBF/MTTR/Availability calculations, KPI calculations, risk scoring, budget variance |
| 2.4 | Present case studies of maintenance management successes and failures — discuss what the manager should have done differently |
| 2.5 | Use the Universiti Harapan Malaysia scenario as a running thread across all five KP sessions to build continuity |
| 2.6 | Encourage questions — particularly on decision-making scenarios (e.g. "what would you do if...?") |
| 2.7 | Highlight the distinction between Level 3 (doing) and Level 4 (managing): the same technical situation requires a different response at each level |

### 3. PENGGUNAAN (Application)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 3.1 | Distribute the corresponding KT (Assignment Sheet) for the session |
| 3.2 | Trainees complete Section A (MCQ) individually, then Sections B and C individually or in guided discussion |
| 3.3 | For essay questions, require trainees to write in structured management language — not bullet points alone |
| 3.4 | Conduct a class discussion on the essay answers — focus on whether the decision-making rationale is sound |
| 3.5 | Instructor provides correction and feedback; highlight common errors (e.g. describing what a technician does rather than what a manager does) |

### 4. PENGESAHAN (Confirmation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 4.1 | Review key management frameworks from the session (e.g. MRA steps, work order lifecycle, incident priority matrix, RAG dashboard) |
| 4.2 | Conduct brief oral questioning on management decisions: "Given this scenario, what is your first action as manager?" |
| 4.3 | Collect completed KT for marking and feedback |
| 4.4 | Preview the next session — explain how the next KP builds on the current one |
| 4.5 | Record attendance and session completion |

## Panduan Pengajaran / Teaching Notes per KP Session

| KP | Key Teaching Points | Common Trainee Errors |
|----|--------------------|-----------------------|
| KP(1/5) — MRA | Asset criticality tiers; MTBF/MTTR calculation; SLA-to-requirement mapping; risk matrix | Confusing maintenance type (PM vs CM vs PdM); arithmetic errors in MTBF/MTTR |
| KP(2/5) — Plan Development | Maintenance plan structure; schedule conflict avoidance; SOP writing; resource and budget planning | Writing SOPs as technician instructions rather than management tools; unrealistic budget estimates |
| KP(3/5) — Work Management | Work order lifecycle; contractor control points; deviation management; quality assurance | Describing the technical fix rather than the management response; missing escalation steps |
| KP(4/5) — Troubleshooting Management | Incident vs problem vs known error; priority matrix; structured troubleshooting at manager level; 5 Whys RCA | Treating a problem like an incident (fix it and close it, without RCA); RCA stopping at the immediate cause |
| KP(5/5) — Report Production | KPI calculation; RAG status assignment; executive summary writing; verbal presentation | Incorrect KPI formulas; writing reports for technical audiences rather than management; failing to link recommendations to data |

## Penilaian Teori / Theory Assessment

Upon completion of all 5 KP/KT sessions, trainees will sit for the Knowledge Assessment (KA):

- **Code:** IT-020-4:2013-C06/KA
- **Duration:** 1 hour 30 minutes
- **Format:** Written test — MCQ (30 marks), Short Answer (30 marks), Essay (40 marks)
- **Pass mark:** 60% (60/100 marks)
- **Scope:** All 5 Work Activities of CoCU 6
- **Venue:** Examination hall (closed book)
