## Soalan / Questions

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (20 marks)

**A1.** A maintenance window is best defined as:

- (a) The physical opening in a server rack for cable management
- (b) A pre-approved time period during which disruptive maintenance activities may be performed
- (c) The browser window used to access the CMMS system
- (d) The number of hours a technician is permitted to work per day

**A2.** Which of the following should be included in a Standard Operating Procedure (SOP)?

- (a) Technician's personal contact number
- (b) Step-by-step procedure, safety precautions, prerequisites, and acceptance criteria
- (c) Monthly budget figures
- (d) A list of all staff who have ever performed the task

**A3.** For a Tier 1 mission-critical server, the recommended PM frequency is:

- (a) Once every two years
- (b) Only when it fails
- (c) Monthly physical check; quarterly full PM
- (d) Daily full shutdown and inspection

**A4.** The purpose of a spare parts minimum stock holding is to:

- (a) Reduce the technician's workload
- (b) Ensure replacement parts are available within the SLA resolution window
- (c) Lower the annual IT budget
- (d) Satisfy an audit requirement only

**A5.** The maintenance plan must be formally approved because:

- (a) It is a legal requirement under the Penal Code
- (b) Approval ensures management commitment to the resources and schedule the plan requires
- (c) Technicians cannot start work without a signed document
- (d) Approval is needed only for plans involving contractors

### Bahagian B: Soalan Jawapan Pendek / Short Answer (30 marks)

**B1.** List the TEN (10) sections that should be included in a complete Computer System Maintenance Plan. (10 marks)

**B2.** Explain the difference between a Standard maintenance window and an Extended maintenance window. Give ONE (1) example of an activity suitable for each. (6 marks)

**B3.** Describe FOUR (4) factors that determine how frequently a preventive maintenance activity should be scheduled for a given asset. (8 marks)

**B4.** State THREE (3) circumstances that should trigger a review and update of the maintenance plan during its active period. (6 marks)

---

### Bahagian C: Soalan Esei / Essay (30 marks)

**C1.** Using the MRA output from KT-01 (the logistics company scenario), develop the key elements of a maintenance plan:

(a) Recommend a maintenance strategy (PM / PdM / CBM mix) for the web servers, database server, workstations, and network devices. Justify each recommendation. (12 marks)

(b) Design a 6-month maintenance calendar extract (July–December) for the web servers and workstations. Assume the approved maintenance window is every Sunday, 00:00–04:00. Identify any scheduling conflicts and explain how you resolve them. (10 marks)

(c) Write a brief SOP outline (minimum 6 steps) for one of the following: quarterly web server PM, OR semi-annual workstation health check. Include purpose, prerequisites, two safety precautions, and at least one acceptance criterion. (8 marks)
