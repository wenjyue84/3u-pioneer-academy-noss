## Kaedah Pengajaran / Teaching Method (4-Step)

### 1. PERSEDIAAN (Preparation)

| Langkah / Step | Aktiviti / Activity | Masa / Duration |
|----------------|---------------------|-----------------|
| 1.1 | Welcome trainees; take attendance | 5 min |
| 1.2 | State the practical learning objectives for the session | 5 min |
| 1.3 | Review the corresponding KP content briefly — reinforce the theoretical foundation before the practical application | 10 min |
| 1.4 | Distribute the KK (Work Sheet), scenario materials, and templates | 5 min |
| 1.5 | Verify all required tools, data packs, and computer access are ready for each trainee | 5 min |

### 2. PENYAMPAIAN (Demonstration)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 2.1 | Demonstrate the management task step-by-step: e.g. walk through completing an MRA, filling a work order, conducting a 5 Whys, building a KPI table |
| 2.2 | Model the decision-making process verbally: "As manager, I receive this information — my first action is... because..." |
| 2.3 | Show the difference between a weak and a strong management output (e.g. a vague recommendation vs a specific, data-backed recommendation) |
| 2.4 | Answer questions before trainees begin independent work |

### 3. PENGGUNAAN (Practice)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 3.1 | Trainees work through the KK independently at their workstations |
| 3.2 | Instructor circulates to observe, ask probing questions, and redirect if the trainee is describing technician actions rather than management actions |
| 3.3 | For role-play exercises (KK-03 and KK-04), the instructor plays the role of IT Manager and technicians as required |
| 3.4 | Introduce injected scenarios at the appropriate time as specified in the KK |
| 3.5 | Trainees complete the KK assessment checklist as they work |

### 4. PENGESAHAN (Confirmation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 4.1 | Review each trainee's deliverables against the KK assessment checklist |
| 4.2 | Conduct a debrief — discuss the management decisions made during the session; highlight strong and weak responses |
| 4.3 | Provide individual feedback on document quality, decision-making soundness, and communication effectiveness |
| 4.4 | Trainees file all completed documents in their portfolio |
| 4.5 | Record session completion and any issues requiring follow-up |

## Panduan Amali / Practical Session Notes per KK

| KK | Session Focus | Instructor Role | Key Assessment Points |
|----|---------------|-----------------|-----------------------|
| KK(1/5) — MRA | Structured analysis from data | Provide data pack; observe classification logic | Asset criticality justified; calculations correct; gap analysis realistic |
| KK(2/5) — Plan Development | Document production | Provide scenario context from KK-01; review plan structure | Calendar conflict-free; SOP complete; budget within limit |
| KK(3/5) — Work Management | Role-play as IT Manager | Play IT Manager role; introduce deviation cards at specified times | Work orders complete; deviations documented; session report management-appropriate |
| KK(4/5) — Troubleshooting Mgmt | Role-play as IT Manager + inject P1 incident | Receive escalation messages; observe structured response | P1 classified correctly; RCA reaches root cause (not just symptom); PIR complete |
| KK(5/5) — Report Production | Document production + verbal presentation | Play IT Manager for verbal presentation | KPI calculations correct; RAG assigned correctly; executive summary is management-targeted; verbal presentation structured and within time |

## Keselamatan / Safety Requirements

- Trainees must not access live production systems during practical exercises; all work is simulation-based
- Role-play exercises must remain professional — no disruptive behaviour during simulated escalation scenarios
- All simulated documents and data packs are treated as confidential within the classroom
- Computer workstations must be used for this exercise only; no personal internet browsing

---

## Penilaian Amali / Practical Assessment

Upon completion of all 5 KK sessions, trainees will sit for the Performance Assessment (PA):

- **Code:** IT-020-4:2013-C06/PA
- **Duration:** 4 hours
- **Format:** Integrated management simulation — MRA, plan, work management, troubleshooting, and report production across a single organisation scenario with injected incidents
- **Assessment criteria:** Management Process, Output Quality, Attitude and Communication, Decision-Making and Action, Documentation
- **Pass mark:** 60% (60/100 marks)
- **Venue:** Simulation lab with computer access
