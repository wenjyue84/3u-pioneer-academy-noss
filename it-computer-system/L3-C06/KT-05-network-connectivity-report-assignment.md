## Tugasan / Tasks

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (10 markah / marks)

**A1.** Apakah tujuan utama laporan ketersambungan rangkaian disediakan? / What is the main purpose of preparing a network connectivity report?

- (a) Untuk dihantar kepada pembekal peralatan bagi tujuan waranti / To be sent to equipment suppliers for warranty purposes
- (b) Untuk merekod kerja yang telah dilaksanakan, keputusan ujian, dan status akhir rangkaian sebagai rujukan rasmi / To record work performed, test results, and final network status as an official reference
- (c) Untuk menentukan bayaran yang perlu dibuat kepada juruteknik / To determine the payment to be made to the technician
- (d) Untuk memaklumkan pengguna tentang kos pemasangan rangkaian / To inform users of the network installation cost

**A2.** Yang manakah antara berikut BUKAN merupakan komponen penting dalam laporan ketersambungan rangkaian? / Which of the following is NOT an essential component of a network connectivity report?

- (a) Maklumat konfigurasi rangkaian (skema IP, topologi) / Network configuration information (IP scheme, topology)
- (b) Keputusan ujian ketersambungan / Connectivity test results
- (c) Rekod cuti tahunan juruteknik / Technician's annual leave record
- (d) Senarai peralatan yang digunakan / List of equipment used

**A3.** Dalam laporan ketersambungan, bahagian "keputusan ujian" sepatutnya mengandungi: / In a connectivity report, the "test results" section should contain:

- (a) Pendapat peribadi juruteknik tentang kualiti peralatan / Technician's personal opinion about equipment quality
- (b) Rekod ujian yang dilaksanakan, output yang diperoleh, dan status lulus/gagal setiap ujian / Record of tests performed, output obtained, and pass/fail status of each test
- (c) Senarai harga pasaran peralatan rangkaian / Market price list of network equipment
- (d) Cadangan untuk menambah bilangan pengguna pada masa hadapan / Recommendations for adding more users in the future

**A4.** Laporan ketersambungan rangkaian perlu ditandatangani oleh: / A network connectivity report should be signed by:

- (a) Juruteknik yang melaksanakan kerja sahaja / Only the technician who performed the work
- (b) Pengurus IT sahaja / Only the IT manager
- (c) Juruteknik yang melaksanakan kerja dan penyelia atau penerima kerja (klien/wakil organisasi) / The technician who performed the work and the supervisor or work recipient (client/organisation representative)
- (d) Pengguna akhir semua komputer yang terlibat / All end-users of the computers involved

**A5.** Apakah yang dimaksudkan dengan "lampiran" (attachment/appendix) dalam laporan ketersambungan rangkaian? / What is meant by "appendix/attachment" in a network connectivity report?

- (a) Bahagian laporan yang mengandungi cadangan kenaikan gaji juruteknik / Section of the report containing salary increment recommendations for the technician
- (b) Dokumen sokongan seperti gambar rajah rangkaian, senarai inventori, dan tangkapan skrin hasil ujian / Supporting documents such as network diagrams, inventory lists, and screenshots of test results
- (c) Salinan kontrak perjanjian pemasangan rangkaian / Copy of the network installation contract
- (d) Borang aduan pengguna tentang masalah rangkaian / User complaint forms about network problems

### Bahagian C: Soalan Situasi / Situational Question (20 markah / marks)

**C1.** Anda baru selesai memasang dan mengkonfigurasi rangkaian baharu bagi sebuah syarikat perniagaan kecil. Berikut adalah maklumat ringkas tentang kerja yang telah dilaksanakan:

You have just completed installing and configuring a new network for a small business company. Below is a summary of the work performed:

- **Lokasi / Location:** Pejabat Syarikat ABC Sdn Bhd, Tingkat 3
- **Tarikh / Date:** Hari ini / Today
- **Topologi / Topology:** Star, menggunakan 1 suis 16-port / using 1 x 16-port switch
- **Skema IP / IP Scheme:** 10.0.1.0/24, default gateway 10.0.1.1
- **Bilangan peranti / Number of devices:** 8 komputer, 1 pencetak rangkaian, 1 pelayan fail / 8 computers, 1 network printer, 1 file server
- **Ujian yang dilaksanakan / Tests performed:** ping loopback, ping gateway, ping antara komputer, ujian akses pencetak, ujian akses internet / loopback ping, gateway ping, inter-computer ping, printer access test, internet access test
- **Keputusan ujian / Test results:** Semua ujian lulus kecuali internet pada 1 komputer (IP: 10.0.1.15) — DNS server dikonfigurasikan dengan salah; telah diperbetulkan / All tests passed except internet on 1 computer (IP: 10.0.1.15) — DNS server misconfigured; corrected
- **Status akhir / Final status:** Semua peranti berfungsi dengan normal / All devices functioning normally

Berdasarkan maklumat di atas: / Based on the information above:

**(i)** Sediakan **laporan ketersambungan rangkaian** yang lengkap dan profesional berdasarkan maklumat di atas. Laporan hendaklah mengandungi semua bahagian yang diperlukan, ditulis dengan bahasa yang formal dan jelas. / Prepare a **complete and professional network connectivity report** based on the information above. The report must contain all required sections, written in formal and clear language. *(10 markah)*

**(ii)** Terangkan kepentingan menyimpan salinan laporan ini dan nyatakan sekurang-kurangnya TIGA (3) pihak atau situasi di mana laporan ini akan berguna pada masa hadapan. / Explain the importance of keeping a copy of this report and state at least THREE (3) parties or situations where this report will be useful in the future. *(10 markah)*
