## Arahan kepada Pelatih / Instructions to Trainee

1. Ini adalah peperiksaan PRAKTIKAL. Anda akan dinilai berdasarkan keupayaan anda untuk melaksanakan persediaan sambungan rangkaian komputer secara lengkap.
2. Anda akan diberikan spesifikasi konfigurasi rangkaian, peralatan, dan bahan. Anda mesti menyiapkan keseluruhan kitaran persediaan.
3. Anda akan dinilai berdasarkan: **Proses** (cara melaksanakan), **Hasil** (keputusan kerja), **Sikap** (profesionalisme), **Keselamatan** (ESD dan elektrik), dan pematuhan **Alam Sekitar**.
4. Semua kerja mesti didokumenkan dalam borang laporan sambungan yang disediakan.
5. Dapatkan kelulusan penilai sebelum meneruskan ke peringkat seterusnya jika diminta.

## Tugasan / Task Description

**Senario:** Anda adalah Juruteknik Sistem Komputer Tahap 3. Anda menerima spesifikasi konfigurasi rangkaian berikut untuk pejabat baru:

| Medan | Butiran |
|-------|---------|
| Nombor Spesifikasi | PA-NET-2026-006 |
| Diminta oleh | Jabatan Pentadbiran |
| Keutamaan | Biasa |
| Penerangan | Persediaan rangkaian pejabat baru — 10 stesen kerja, 2 pencetak rangkaian |
| Topologi | Star topology, satu managed switch pusat |
| Pengalamatan IP | 192.168.6.0/24; gateway 192.168.6.1; DNS 8.8.8.8 |
| Penghantaran IP | DHCP untuk stesen kerja; IP statik untuk pencetak |
| Pencetak 1 | 192.168.6.201 |
| Pencetak 2 | 192.168.6.202 |
| Kabel | Cat 6 UTP, piawaian T568B |
| Capaian Internet | Melalui router sedia ada (192.168.6.1) |
| Tempoh | Hari ini |

**Anda mesti menyiapkan tugas-tugas berikut mengikut urutan:**

1. Menganalisis spesifikasi konfigurasi rangkaian dan menyediakan senarai semak pemasangan (20 minit)
2. Menyediakan peralatan, kabel, dan peralatan rangkaian (15 minit)
3. Melaksanakan konfigurasi rangkaian — crimping kabel, konfigurasi switch, dan penyambungan peralatan (60 minit)
4. Menjalankan ujian sambungan — ping, tracert, ipconfig, dan pengesahan perkhidmatan (30 minit)
5. Menjalankan penyelesaian masalah rangkaian jika diperlukan (20 minit)
6. Menyediakan laporan sambungan dan handover kepada penilai (15 minit)

**Jumlah masa yang dibenarkan: 3 jam**
