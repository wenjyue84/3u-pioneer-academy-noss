## Tugasan / Tasks

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (10 markah / marks)

**A1.** Apakah fungsi utama suis (switch) dalam konfigurasi rangkaian bintang (star topology)? / What is the main function of a switch in a star topology network configuration?

- (a) Menghubungkan rangkaian LAN kepada internet / Connect the LAN to the internet
- (b) Menjadi titik pusat yang menghubungkan semua peranti dalam rangkaian / Act as a central point connecting all devices in the network
- (c) Menyulitkan semua trafik data dalam rangkaian / Encrypt all data traffic in the network
- (d) Menyimpan alamat IP semua peranti secara kekal / Permanently store IP addresses of all devices

**A2.** Semasa mengkonfigurasi kad antara muka rangkaian (NIC) pada komputer Windows, apakah tetapan yang perlu dikonfigurasikan untuk pengalamatan IP statik? / When configuring a Network Interface Card (NIC) on a Windows computer, which settings must be configured for static IP addressing?

- (a) Alamat IP, subnet mask, default gateway, dan DNS server sahaja / IP address, subnet mask, default gateway, and DNS server only
- (b) Alamat IP dan nama pengguna / IP address and username
- (c) Alamat MAC dan subnet mask / MAC address and subnet mask
- (d) Nama hos dan kata laluan rangkaian / Hostname and network password

**A3.** Apakah perbezaan antara pengalamatan IP **statik** dan **dinamik (DHCP)**? / What is the difference between **static** and **dynamic (DHCP)** IP addressing?

- (a) IP statik berubah setiap kali komputer dimulakan semula; IP DHCP kekal tetap / Static IP changes every restart; DHCP IP remains fixed
- (b) IP statik ditetapkan secara manual dan kekal; IP DHCP diberikan secara automatik oleh pelayan DHCP / Static IP is manually set and fixed; DHCP IP is automatically assigned by a DHCP server
- (c) IP statik digunakan untuk rangkaian wayarles sahaja; IP DHCP untuk rangkaian berwayar / Static IP is for wireless networks only; DHCP for wired networks
- (d) Tiada perbezaan antara kedua-duanya / There is no difference between the two

**A4.** Apakah langkah yang perlu dilakukan selepas menyambung semua kabel rangkaian dan sebelum mengkonfigurasi perisian? / What step should be performed after connecting all network cables and before configuring software?

- (a) Terus memasang sistem operasi baharu / Immediately install a new operating system
- (b) Sahkan sambungan fizikal dengan menyemak LED penunjuk pada suis dan NIC / Verify physical connections by checking indicator LEDs on the switch and NIC
- (c) Padam semua tetapan rangkaian sedia ada / Delete all existing network settings
- (d) Hubungi pembekal untuk mendapatkan kebenaran / Contact the supplier for authorisation

**A5.** Dalam konfigurasi rangkaian wayarles (wireless), apakah yang dimaksudkan dengan SSID? / In a wireless network configuration, what is meant by SSID?

- (a) Nombor siri penghala wayarles / Serial number of the wireless router
- (b) Nama pengenalan rangkaian wayarles yang disiarkan oleh titik akses / The identifying name of the wireless network broadcast by the access point
- (c) Protokol keselamatan yang digunakan untuk menyulitkan data wayarles / Security protocol used to encrypt wireless data
- (d) Alamat IP lalai penghala wayarles / Default IP address of the wireless router

### Bahagian C: Soalan Situasi / Situational Question (20 markah / marks)

**C1.** Anda telah diberikan tugas untuk mengkonfigurasi rangkaian baharu bagi sebuah makmal komputer di sekolah yang mempunyai 15 komputer pelajar dan 1 komputer guru. Spesifikasi yang diberikan adalah seperti berikut:

You have been assigned to configure a new network for a school computer lab with 15 student computers and 1 teacher's computer. The specification given is as follows:

- Topologi / Topology: Star
- Skema IP / IP Scheme: 172.16.5.0/24
- Default Gateway: 172.16.5.1
- DNS Server: 8.8.8.8
- Komputer guru / Teacher's computer: 172.16.5.10 (statik)
- Komputer pelajar / Student computers: 172.16.5.20 – 172.16.5.34 (statik)
- Peralatan / Equipment: 1 penghala (router), 1 suis (switch) 24-port

Berdasarkan senario di atas: / Based on the scenario above:

**(i)** Huraikan langkah-langkah penuh untuk melaksanakan konfigurasi rangkaian tersebut dari awal hingga selesai, termasuk penyambungan fizikal dan konfigurasi perisian. / Describe the complete steps to carry out the network configuration from start to finish, including physical connection and software configuration. *(10 markah)*

**(ii)** Semasa proses konfigurasi, anda mendapati dua komputer pelajar mendapat mesej ralat "IP address conflict". Terangkan punca masalah ini dan langkah-langkah yang akan anda ambil untuk menyelesaikannya. / During the configuration process, you find that two student computers display an "IP address conflict" error. Explain the cause of this problem and the steps you would take to resolve it. *(10 markah)*
