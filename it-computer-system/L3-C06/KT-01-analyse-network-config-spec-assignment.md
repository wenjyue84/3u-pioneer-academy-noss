## Tugasan / Tasks

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (10 markah / marks)

**A1.** Apakah tujuan utama menganalisis spesifikasi konfigurasi rangkaian sebelum memulakan pemasangan? / What is the primary purpose of analysing a network configuration specification before beginning installation?

- (a) Untuk memesan peralatan baharu dari pembekal / To order new equipment from a supplier
- (b) Untuk memahami keperluan teknikal dan memastikan sumber yang sesuai disediakan / To understand technical requirements and ensure appropriate resources are prepared
- (c) Untuk merekod kos projek rangkaian / To record the cost of the network project
- (d) Untuk menyemak kelayakan pengguna akhir / To verify end-user qualifications

**A2.** Yang manakah antara berikut merupakan topologi rangkaian yang paling biasa digunakan dalam persekitaran LAN pejabat? / Which of the following is the most commonly used network topology in an office LAN environment?

- (a) Bus
- (b) Ring
- (c) Star (Bintang)
- (d) Mesh

**A3.** Dalam spesifikasi konfigurasi rangkaian, "subnet mask" digunakan untuk: / In a network configuration specification, a "subnet mask" is used to:

- (a) Menyulitkan data yang dihantar melalui rangkaian / Encrypt data transmitted over the network
- (b) Menentukan bahagian rangkaian dan bahagian hos dalam alamat IP / Determine the network portion and host portion of an IP address
- (c) Mengawal kelajuan penghantaran data / Control the speed of data transmission
- (d) Mengenal pasti pengeluar perkakasan rangkaian / Identify the network hardware manufacturer

**A4.** Dokumen spesifikasi konfigurasi rangkaian lazimnya mengandungi maklumat tentang: / A network configuration specification document typically contains information about:

- (a) Nama pengguna dan kata laluan peribadi / Personal usernames and passwords
- (b) Skema pengalamatan IP, topologi, dan peralatan yang diperlukan / IP addressing scheme, topology, and required equipment
- (c) Rekod gaji kakitangan IT / IT staff salary records
- (d) Jadual cuti pekerja / Employee leave schedule

**A5.** Apakah yang dimaksudkan dengan "default gateway" dalam konfigurasi rangkaian? / What is meant by "default gateway" in network configuration?

- (a) Kata laluan lalai untuk mengakses penghala / Default password to access the router
- (b) Alamat IP pelayan cetak dalam rangkaian / IP address of the print server in the network
- (c) Alamat IP antara muka penghala yang menjadi titik keluar untuk trafik ke luar rangkaian setempat / IP address of the router interface that serves as the exit point for traffic leaving the local network
- (d) Nama hos komputer pertama dalam rangkaian / Host name of the first computer in the network

### Bahagian C: Soalan Situasi / Situational Question (20 markah / marks)

**C1.** Anda ialah juruteknik IT yang menerima dokumen spesifikasi konfigurasi rangkaian bagi sebuah pejabat baharu yang mempunyai 20 pengguna. Berikut adalah maklumat yang diberikan:

You are an IT technician who has received a network configuration specification document for a new office with 20 users. The following information is provided:

- Topologi / Topology: Star
- Skema IP / IP Scheme: 192.168.10.0/24
- Default Gateway: 192.168.10.1
- DNS Server: 192.168.10.2
- Julat IP pengguna / User IP range: 192.168.10.10 – 192.168.10.30 (statik / static)
- Peralatan / Equipment: 1 penghala (router), 2 suis (switches) 24-port, 20 komputer

Berdasarkan senario di atas: / Based on the scenario above:

**(i)** Analisis dan sahkan sama ada spesifikasi tersebut mencukupi untuk menyambungkan 20 pengguna. Nyatakan sebarang isu atau jurang yang anda kenal pasti. / Analyse and verify whether the specification is sufficient to connect 20 users. State any issues or gaps you identify. *(10 markah)*

**(ii)** Lukis atau huraikan gambar rajah topologi rangkaian berdasarkan spesifikasi di atas, termasuk kedudukan penghala, suis, dan komputer pengguna. / Draw or describe a network topology diagram based on the above specification, including the placement of the router, switches, and user computers. *(10 markah)*
