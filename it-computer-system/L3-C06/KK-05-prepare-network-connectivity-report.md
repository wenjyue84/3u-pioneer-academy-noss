## Objektif / Objectives

By the end of this work activity, trainees will be able to:

1. Compile all network setup, test, and troubleshooting records into a structured connectivity report.
2. Present network topology, device configuration summary, and test results in a professional format.
3. Document any outstanding issues and recommended follow-up actions.
4. Produce a report that meets organisational documentation standards.

## Langkah Keselamatan / Safety Precautions

- Save the report file regularly and maintain a backup copy to prevent data loss.
- Do not include sensitive credentials (passwords, SNMP community strings) in the report unless required by the organisation's template and the document is classified appropriately.
- Use only factual data from completed worksheets — do not alter or fabricate test results.
- Obtain instructor approval before printing if using shared printer resources.

---

## Prosedur / Procedure

| Langkah / Step | Arahan / Instruction |
|----------------|----------------------|
| 1 | Open the connectivity report template in the word processor. Fill in the report header: project title, date, trainee name, instructor name, and the network environment name. |
| 2 | Write **Section 1 — Introduction**: briefly describe the purpose of the network connectivity set-up (1–2 paragraphs). State the scope: which devices, subnets, and services are covered. |
| 3 | Write **Section 2 — Network Overview**: insert the finalised network topology diagram. Below the diagram, provide a short description of the topology type, the number and types of devices, and the IP addressing scheme used. |
| 4 | Write **Section 3 — Device Configuration Summary**: create a table listing each network device (hostname, device type, management IP, key interfaces configured, VLANs assigned, services enabled). This data comes from the KK-02 configuration record sheet. |
| 5 | Write **Section 4 — IP Address Allocation Table**: present the full IP address plan as a table — columns: Device/Host, Interface, IP Address, Subnet Mask, Default Gateway, DNS Server. Verify all entries against the specification. |
| 6 | Write **Section 5 — Connectivity Test Results**: insert the completed test record from KK-03. For each test case, show: Test ID, Source, Destination, Tool Used, Expected Result, Actual Result, and Pass/Fail status. |
| 7 | Write **Section 6 — Troubleshooting Record** (if applicable): summarise each fault encountered during KK-04 — fault description, OSI layer, root cause, corrective action taken, and outcome. If no faults were encountered, state "No faults were encountered during testing." |
| 8 | Write **Section 7 — Outstanding Issues and Recommendations**: list any test cases that failed and were not resolved, any specification items that could not be implemented, and recommended actions (e.g., "Replace faulty patch cable on Switch port Fa0/5 before production handover"). |
| 9 | Write **Section 8 — Conclusion**: summarise the overall outcome of the network connectivity set-up (2–3 sentences). State whether the network meets the specification requirements. |
| 10 | Review the completed report for accuracy, completeness, and professional language. Check that all tables are correctly formatted and the topology diagram is legible. Correct any errors. |
| 11 | Add page numbers, a table of contents, and the report date. Save the final document as a PDF. |
| 12 | Submit the PDF report to the instructor for review and sign-off. |

---

## Hasil Dijangka / Expected Outcome

Upon completion, trainees will have produced a professional network connectivity report containing:

- A network topology diagram with accompanying description.
- A device configuration summary table.
- A complete IP address allocation table.
- Connectivity test results with pass/fail outcomes for all test cases.
- A troubleshooting record (where applicable).
- Outstanding issues and recommendations.
- A conclusion confirming whether the network meets specification.
