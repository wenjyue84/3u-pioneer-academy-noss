## Huraian Kandungan Teori / Theory Content Description

### KP(1/5) — Network Configuration Specification Analysis (7.2 jam)

| Topik | Huraian |
|-------|---------|
| 1.1 | Types and purpose of network configuration specification documents |
| 1.2 | Network topology types: star, bus, ring, mesh, hybrid |
| 1.3 | IP addressing fundamentals: IPv4 classes, subnetting, CIDR notation |
| 1.4 | Network hardware components: routers, switches (managed/unmanaged), access points, patch panels |
| 1.5 | Cabling standards: UTP Cat 5e / Cat 6, T568A / T568B wiring, straight-through vs crossover |
| 1.6 | Reading and interpreting network diagrams and IP address schemes |
| 1.7 | Pre-installation checklist preparation and documentation |

### KP(2/5) — Network Configuration — IP Addressing, Devices, and Cabling (9.0 jam)

| Topik | Huraian |
|-------|---------|
| 2.1 | Static vs dynamic (DHCP) IP address assignment — advantages and use cases |
| 2.2 | DHCP server configuration: scope, lease duration, exclusion ranges, reservations |
| 2.3 | Default gateway and DNS server configuration |
| 2.4 | VLAN concepts and managed switch port configuration |
| 2.5 | Crimping UTP cables: RJ-45 connector, T568B pin-out, cable continuity testing |
| 2.6 | Physical installation: patch panel termination, cable labelling, cable management |
| 2.7 | Network configuration commands: `ipconfig`, `netsh`, Windows Network Adapter settings |

### KP(3/5) — Network Connectivity Testing Methods and Tools (7.2 jam)

| Topik | Huraian |
|-------|---------|
| 3.1 | Connectivity testing methodology: systematic, layer-by-layer approach (OSI model) |
| 3.2 | `ping` command — syntax, interpretation of results (TTL, round-trip time, packet loss) |
| 3.3 | `tracert` / `traceroute` — interpreting hop-by-hop path and latency |
| 3.4 | `ipconfig /all` — verifying IP assignment, DHCP lease, MAC address |
| 3.5 | `nslookup` — DNS resolution testing |
| 3.6 | `netstat` — active connections and port status |
| 3.7 | Physical-layer tools: cable tester, toner and probe, PoE tester |
| 3.8 | Documenting test results: recording commands and output for the connectivity report |

### KP(4/5) — Network Troubleshooting Techniques (9.0 jam)

| Topik | Huraian |
|-------|---------|
| 4.1 | Systematic troubleshooting methodology: top-down, bottom-up, divide-and-conquer |
| 4.2 | Common network faults: IP conflict, incorrect subnet mask, wrong default gateway, DHCP failure (APIPA) |
| 4.3 | Physical-layer faults: damaged cable, wrong pin-out, faulty patch port, link light absent |
| 4.4 | Switch and VLAN configuration errors: port not in correct VLAN, trunk link misconfiguration |
| 4.5 | DNS-related faults: cannot resolve hostname, incorrect DNS server entry |
| 4.6 | Firewall and security: ICMP blocked, port filtering, Windows Firewall impact on ping |
| 4.7 | Fault documentation: recording symptoms, diagnosis steps, root cause, and corrective action |

### KP(5/5) — Network Connectivity Reporting (3.6 jam)

| Topik | Huraian |
|-------|---------|
| 5.1 | Purpose and importance of the connectivity report |
| 5.2 | Required sections: network specification summary, IP address table, equipment list, test results, fault log, sign-off |
| 5.3 | Presenting the completed report to the client or supervisor |
| 5.4 | Record-keeping requirements for audit and future maintenance |
| 5.5 | Handover procedures: informing users, providing documentation, confirming acceptance |

## Kaedah Pengajaran / Teaching Method (4-Step)

### 1. PERSEDIAAN (Preparation)

| Langkah / Step | Aktiviti / Activity | Masa / Duration |
|----------------|---------------------|-----------------|
| 1.1 | Sambut pelatih dan ambil kehadiran | 5 minit |
| 1.2 | Nyatakan objektif pembelajaran untuk sesi tersebut | 5 minit |
| 1.3 | Kaitkan topik dengan pengetahuan lepas dan konteks tempat kerja | 5 minit |
| 1.4 | Berikan gambaran keseluruhan kandungan Lembaran Maklumat (KP) | 5 minit |

### 2. PENYAMPAIAN (Presentation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 2.1 | Sampaikan kandungan teori daripada KP yang relevan menggunakan slaid, rajah rangkaian, dan contoh |
| 2.2 | Terangkan istilah utama, definisi, dan konsep dengan senario dunia sebenar |
| 2.3 | Tunjukkan rajah topologi rangkaian, jadual pengalamatan IP, dan skrin tangkap konfigurasi |
| 2.4 | Demonstrasikan output arahan diagnostik rangkaian biasa melalui perbincangan |
| 2.5 | Galakkan soalan dan jelaskan kesalahfahaman |
| 2.6 | Tekankan pertimbangan keselamatan: kawasan kerja selamat, pengendalian kabel, dokumentasi konfigurasi |

### 3. PENGGUNAAN (Application)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 3.1 | Edarkan KT (Lembaran Tugasan) yang sepadan untuk sesi tersebut |
| 3.2 | Pelatih menyiapkan tugasan secara individu atau berkumpulan |
| 3.3 | Pengajar memberikan bimbingan dan sokongan semasa latihan |
| 3.4 | Bincangkan jawapan dan kesilapan lazim bersama kelas |

### 4. PENGESAHAN (Confirmation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 4.1 | Ulangkaji perkara pembelajaran utama daripada sesi |
| 4.2 | Jalankan soal selidik lisan ringkas untuk mengesahkan kefahaman |
| 4.3 | Kumpul KT yang telah disiapkan untuk penandaan dan maklum balas |
| 4.4 | Pratonton topik sesi berikutnya |
| 4.5 | Rekod kehadiran dan penyelesaian sesi |
