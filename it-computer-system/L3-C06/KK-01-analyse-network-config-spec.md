## Objektif / Objectives

By the end of this work activity, trainees will be able to:

1. Interpret a network configuration specification document.
2. Identify network topology, IP addressing scheme, and device roles.
3. Verify that specifications meet organisational and technical requirements.
4. Document gaps or inconsistencies in the specification for escalation.

## Prosedur / Procedure

| Langkah / Step | Arahan / Instruction |
|----------------|----------------------|
| 1 | Receive the simulated network configuration specification document from the instructor. Read the entire document before taking any notes. |
| 2 | Identify the network topology specified (e.g., star, hierarchical, mesh). Sketch the physical and logical topology on the blank network diagram template. |
| 3 | Extract the IP addressing scheme: note the network address, subnet mask, CIDR notation, gateway address, and DNS server addresses. Record these in the IP address planning worksheet. |
| 4 | List all network devices specified (routers, switches, access points, firewalls, servers, end-user devices). For each device, record its hostname, role, interface, and assigned IP address. |
| 5 | Identify the required network services (e.g., DHCP, DNS, VPN, NAT) and note which device is responsible for each service. |
| 6 | Verify the specification for consistency: check that IP addresses fall within the declared subnet, no addresses are duplicated, and the gateway is reachable within the subnet. |
| 7 | Cross-reference the specification against organisational requirements (e.g., VLAN segmentation, security policy, bandwidth requirements). Note any requirement that is not addressed. |
| 8 | Document all gaps, ambiguities, or non-compliant items found. For each issue, state the section of the specification affected, the nature of the problem, and a recommended action (e.g., clarify with network administrator, revise subnet plan). |
| 9 | Compile a completed analysis report containing: topology diagram, IP address table, device inventory, service mapping, compliance check results, and gap list. Submit to the instructor for review. |

---

## Hasil Dijangka / Expected Outcome

Upon completion, trainees will have produced:

- An annotated network topology diagram (physical and logical).
- A fully populated IP address planning worksheet with no conflicts.
- A device inventory table listing all nodes, roles, and addresses.
- A compliance and gap analysis report identifying any specification deficiencies.
