## Tugasan / Tasks

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (10 markah / marks)

**A1.** Apakah arahan yang digunakan untuk menguji sama ada dua komputer dalam rangkaian boleh berkomunikasi antara satu sama lain? / What command is used to test whether two computers in a network can communicate with each other?

- (a) `ipconfig`
- (b) `ping`
- (c) `netstat`
- (d) `tracert`

**A2.** Apakah yang ditunjukkan oleh mesej "Request timed out" apabila menjalankan ujian `ping`? / What does the message "Request timed out" indicate when running a `ping` test?

- (a) Sasaran menerima paket dengan jayanya / The target received the packet successfully
- (b) Sambungan rangkaian berfungsi dengan baik / The network connection is working correctly
- (c) Tiada respons diterima daripada destinasi; kemungkinan peranti tidak dapat dicapai atau trafik disekat / No response received from destination; device may be unreachable or traffic is blocked
- (d) Kelajuan rangkaian adalah terlalu tinggi / The network speed is too high

**A3.** Arahan `ipconfig /all` pada Windows digunakan untuk: / The `ipconfig /all` command on Windows is used to:

- (a) Memadam semua tetapan rangkaian pada komputer / Delete all network settings on the computer
- (b) Memaparkan maklumat konfigurasi rangkaian yang terperinci termasuk alamat MAC dan tetapan DNS / Display detailed network configuration information including MAC address and DNS settings
- (c) Memulakan semula perkhidmatan DHCP / Restart the DHCP service
- (d) Memindahkan fail antara komputer dalam rangkaian / Transfer files between computers in the network

**A4.** Ujian `ping 127.0.0.1` pada sesebuah komputer bertujuan untuk: / The `ping 127.0.0.1` test on a computer is intended to:

- (a) Menguji sambungan internet komputer / Test the computer's internet connection
- (b) Menguji sama ada NIC komputer lain dalam rangkaian berfungsi / Test whether another computer's NIC in the network is functioning
- (c) Mengesahkan tindanan TCP/IP pada komputer tempatan berfungsi (loopback test) / Verify that the local computer's TCP/IP stack is functioning (loopback test)
- (d) Mengukur lebar jalur (bandwidth) rangkaian / Measure network bandwidth

**A5.** Arahan `tracert` (traceroute) digunakan untuk: / The `tracert` (traceroute) command is used to:

- (a) Memaparkan semua fail yang dikongsi dalam rangkaian / Display all shared files in the network
- (b) Mengesan laluan paket data dari sumber ke destinasi melalui pelbagai nod rangkaian / Trace the path of data packets from source to destination through various network nodes
- (c) Menguji keselamatan rangkaian daripada pencerobohan luar / Test network security against external intrusion
- (d) Menetapkan semula alamat IP secara automatik / Automatically reset the IP address

### Bahagian C: Soalan Situasi / Situational Question (20 markah / marks)

**C1.** Anda baru selesai mengkonfigurasi rangkaian bagi 10 komputer dalam sebuah pejabat. Semua komputer telah ditetapkan dengan alamat IP statik dalam julat 192.168.2.10 – 192.168.2.19, dengan default gateway 192.168.2.1 dan DNS 8.8.8.8. Anda perlu menjalankan ujian ketersambungan menyeluruh untuk mengesahkan rangkaian berfungsi dengan betul.

You have just finished configuring a network for 10 computers in an office. All computers have been assigned static IP addresses in the range 192.168.2.10 – 192.168.2.19, with default gateway 192.168.2.1 and DNS 8.8.8.8. You need to perform a comprehensive connectivity test to verify the network is functioning correctly.

Berdasarkan senario di atas: / Based on the scenario above:

**(i)** Huraikan pelan ujian ketersambungan yang lengkap yang akan anda laksanakan, termasuk ujian yang perlu dilakukan dari setiap komputer, arahan yang digunakan, dan output yang dijangkakan bagi setiap ujian. / Describe a complete connectivity test plan you would implement, including tests to be performed from each computer, commands used, and expected output for each test. *(10 markah)*

**(ii)** Semasa menjalankan ujian, anda mendapati bahawa Komputer 7 (IP: 192.168.2.16) boleh `ping` semua komputer lain dalam rangkaian tetapi **tidak boleh** mengakses internet. Komputer-komputer lain boleh mengakses internet dengan normal. Berdasarkan maklumat ini, analisis punca masalah yang mungkin dan cadangkan langkah-langkah pemeriksaan untuk mengenal pastinya. / During testing, you find that Computer 7 (IP: 192.168.2.16) can `ping` all other computers in the network but **cannot** access the internet. Other computers can access the internet normally. Based on this information, analyse possible causes and suggest inspection steps to identify the problem. *(10 markah)*
