## Tugasan / Tasks

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (10 markah / marks)

**A1.** Apakah pendekatan yang paling sistematik untuk menyelesaikan masalah rangkaian? / What is the most systematic approach to troubleshoot a network problem?

- (a) Gantikan semua peralatan rangkaian dengan yang baharu / Replace all network equipment with new ones
- (b) Mulakan semula komputer yang bermasalah sahaja / Restart only the affected computer
- (c) Ikuti model berlapis OSI atau pendekatan dari bawah ke atas (bottom-up): periksa lapisan fizikal dahulu, kemudian data link, rangkaian, dan seterusnya / Follow the OSI layered model or bottom-up approach: check physical layer first, then data link, network, and so on
- (d) Hubungi pembekal perkhidmatan internet (ISP) segera / Contact the Internet Service Provider (ISP) immediately

**A2.** Seorang pengguna melaporkan bahawa komputernya tidak dapat menyambung ke rangkaian. LED pada port suis yang dihubungkan ke komputer tersebut tidak menyala. Apakah langkah pertama yang perlu dilakukan? / A user reports that their computer cannot connect to the network. The LED on the switch port connected to that computer is not lit. What is the first step to take?

- (a) Tetapkan semula alamat IP komputer / Reset the computer's IP address
- (b) Periksa kabel rangkaian — pastikan ia terpasang dengan kukuh di kedua-dua hujung / Check the network cable — ensure it is firmly connected at both ends
- (c) Pasang semula pemacu (driver) NIC / Reinstall the NIC driver
- (d) Gantikan suis dengan unit yang baharu / Replace the switch with a new unit

**A3.** Apakah yang dimaksudkan dengan "APIPA address" (169.254.x.x) pada sesebuah komputer? / What does an "APIPA address" (169.254.x.x) on a computer indicate?

- (a) Komputer telah berjaya mendapat alamat IP daripada pelayan DHCP / The computer has successfully obtained an IP address from the DHCP server
- (b) Komputer gagal menghubungi pelayan DHCP dan telah menetapkan sendiri alamat IP sementara / The computer failed to contact the DHCP server and has self-assigned a temporary IP address
- (c) Komputer menggunakan alamat IP statik yang telah dikonfigurasi / The computer is using a statically configured IP address
- (d) Komputer telah berjaya menyambung ke internet / The computer has successfully connected to the internet

**A4.** Semasa penyelesaian masalah rangkaian, apakah maklumat yang diperoleh daripada arahan `netstat -an`? / During network troubleshooting, what information is obtained from the `netstat -an` command?

- (a) Konfigurasi alamat IP semua antara muka rangkaian / IP address configuration of all network interfaces
- (b) Senarai semua sambungan TCP/UDP aktif dan port yang sedang mendengar / List of all active TCP/UDP connections and listening ports
- (c) Laluan (route) yang digunakan oleh paket data dalam rangkaian / Routes used by data packets in the network
- (d) Statistik trafik kabel rangkaian / Network cable traffic statistics

**A5.** Apakah yang perlu dilakukan setelah masalah rangkaian berjaya diselesaikan? / What should be done after a network problem has been successfully resolved?

- (a) Tutup tiket aduan tanpa sebarang dokumentasi / Close the complaint ticket without any documentation
- (b) Maklumkan kepada pengguna bahawa masalah telah selesai, tetapi tidak perlu merekodnya / Inform the user that the problem is resolved, but no recording is necessary
- (c) Dokumenkan punca masalah, tindakan yang diambil, dan keputusan ujian dalam laporan penyelesaian masalah / Document the root cause, actions taken, and test results in a troubleshooting report
- (d) Gantikan semua peralatan yang terlibat sebagai langkah pencegahan / Replace all involved equipment as a precautionary measure

### Bahagian C: Soalan Situasi / Situational Question (20 markah / marks)

**C1.** Anda menerima aduan daripada pengurus pejabat bahawa tiga daripada lapan komputer dalam rangkaian tidak dapat mengakses pencetak rangkaian (network printer) dan internet. Lima komputer yang lain berfungsi seperti biasa. Semua komputer berada dalam subnet yang sama: 192.168.50.0/24, default gateway 192.168.50.1. Ketiga-tiga komputer bermasalah menerima alamat IP dalam julat 169.254.x.x.

You receive a complaint from an office manager that three out of eight computers in the network cannot access the network printer or the internet. The other five computers are functioning normally. All computers are on the same subnet: 192.168.50.0/24, default gateway 192.168.50.1. The three affected computers are receiving IP addresses in the range 169.254.x.x.

Berdasarkan senario di atas: / Based on the scenario above:

**(i)** Menggunakan pendekatan penyelesaian masalah yang sistematik, kenal pasti punca masalah yang paling berkemungkinan dan huraikan langkah-langkah yang akan anda ambil untuk mengesahkan diagnosis anda. / Using a systematic troubleshooting approach, identify the most likely root cause and describe the steps you would take to confirm your diagnosis. *(10 markah)*

**(ii)** Setelah mengesahkan punca masalah, huraikan langkah-langkah penyelesaian yang lengkap, termasuk cara untuk menguji bahawa masalah telah diselesaikan sepenuhnya dan apa yang perlu didokumenkan dalam laporan penyelesaian masalah. / After confirming the root cause, describe the complete resolution steps, including how to verify that the problem is fully resolved and what must be documented in the troubleshooting report. *(10 markah)*
