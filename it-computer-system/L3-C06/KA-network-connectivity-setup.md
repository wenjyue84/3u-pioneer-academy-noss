## BAHAGIAN A: SOALAN PELBAGAI PILIHAN / SECTION A: MULTIPLE CHOICE (30 markah)

Jawab semua 15 soalan. Setiap soalan membawa 2 markah. Bulatkan jawapan yang betul.

**1.** A network configuration specification document primarily serves to:

- (a) Record the purchase price of network equipment
- (b) Define IP addressing, topology, hardware, and connectivity requirements before implementation
- (c) List the names of network users
- (d) Replace the network troubleshooting report

**2.** Which IP address class is typically used for large enterprise networks with more than 65,000 hosts?

- (a) Class C
- (b) Class B
- (c) Class A
- (d) Class D

**3.** The subnet mask `255.255.255.0` written in CIDR notation is:

- (a) /16
- (b) /24
- (c) /8
- (d) /32

**4.** A managed switch differs from an unmanaged switch because it:

- (a) Has more physical ports
- (b) Supports VLAN configuration, port mirroring, and remote management
- (c) Is cheaper to purchase
- (d) Operates only at Layer 1 of the OSI model

**5.** Which cable category is recommended for Gigabit Ethernet (1000BASE-T) network installations?

- (a) Cat 3
- (b) Cat 5
- (c) Cat 5e or Cat 6
- (d) Coaxial RG-6

**6.** The `ipconfig /all` command on a Windows workstation displays:

- (a) Only the default gateway
- (b) Full IP configuration including MAC address, DNS, DHCP server, and lease information
- (c) Only the subnet mask
- (d) The current username and password

**7.** DHCP is used in a network to:

- (a) Encrypt data transmissions between devices
- (b) Automatically assign IP addresses and network parameters to client devices
- (c) Block unauthorised users from accessing the network
- (d) Monitor network traffic in real time

**8.** A `ping` command returns "Request Timed Out." The MOST likely cause is:

- (a) The source computer has no network card
- (b) The target device is unreachable or ICMP is blocked by a firewall
- (c) The subnet mask is incorrect on the switch
- (d) The DNS server is offline

**9.** The `tracert` (traceroute) command is used to:

- (a) Assign a static IP address to a device
- (b) Display the path and latency of packets travelling to a destination
- (c) Configure VLAN settings on a switch
- (d) Reset the network adapter driver

**10.** Which OSI model layer is responsible for logical addressing (IP addresses)?

- (a) Layer 1 – Physical
- (b) Layer 2 – Data Link
- (c) Layer 3 – Network
- (d) Layer 4 – Transport

**11.** A workstation is assigned an IP address of `169.254.x.x` automatically. This indicates:

- (a) The device has successfully connected to a DHCP server
- (b) DHCP has failed and the device has self-assigned an APIPA address
- (c) The device is on a Class B network
- (d) The default gateway is unreachable

**12.** The purpose of a network connectivity report is to:

- (a) Replace the network configuration specification
- (b) Document test results, identified faults, corrective actions taken, and sign-off for the completed network set-up
- (c) List all software installed on each workstation
- (d) Record employee attendance during network installation

**13.** When performing a connectivity test between two devices on different VLANs, which device must be configured correctly for communication to succeed?

- (a) The unmanaged switch
- (b) The router or Layer 3 switch performing inter-VLAN routing
- (c) The DHCP client on each device
- (d) The DNS server

**14.** Which tool is most appropriate for testing the continuity and wiring standard of a newly crimped UTP patch cable?

- (a) Multimeter
- (b) Toner and probe kit
- (c) Cable continuity tester / network cable tester
- (d) Spectrum analyser

**15.** The standard wiring sequence for a T568B straight-through Ethernet cable is:

- (a) Orange-White, Orange, Green-White, Blue, Blue-White, Green, Brown-White, Brown
- (b) Green-White, Green, Orange-White, Blue, Blue-White, Orange, Brown-White, Brown
- (c) Blue, Blue-White, Orange, Orange-White, Green, Green-White, Brown, Brown-White
- (d) Orange-White, Orange, Green-White, Green, Blue-White, Blue, Brown-White, Brown

## BAHAGIAN C: SOALAN ESEI / SECTION C: ESSAY (40 markah)

Jawab semua 2 soalan.

**21.** You receive a network configuration specification for a new office with the following requirements:

- 30 workstations across 3 departments (Sales: 10, Finance: 10, Operations: 10)
- Each department must be on a separate VLAN (VLAN 10, 20, 30)
- IP addressing scheme: 192.168.1.0/24 to be subnetted per VLAN
- Inter-VLAN routing required
- One DHCP server to serve all three VLANs
- Internet access via a single broadband router
- All workstations connected via Cat 6 UTP cabling to a managed core switch

(a) Describe how you would analyse this network configuration specification, including the compatibility checks and documentation you would produce before any physical installation. (8 markah)

(b) Describe the sequence of steps you would follow to carry out the network configuration, starting from switch VLAN setup through to workstation IP assignment. (6 markah)

(c) Describe the connectivity tests you would perform to verify that each VLAN is correctly isolated and that inter-VLAN routing is functioning. State the commands used and the expected results. (6 markah)

**22.** After completing the network configuration of the office described above, you conduct connectivity testing and discover the following:

- Workstations in VLAN 10 (Sales) cannot communicate with workstations in VLAN 20 (Finance)
- Two workstations in VLAN 30 (Operations) have self-assigned APIPA addresses (169.254.x.x)
- One workstation in Finance can ping its default gateway but cannot browse the internet

(a) For each of the three faults identified, explain the most likely cause and the step-by-step troubleshooting process you would follow to resolve it. (10 markah)

(b) Explain how you would document each fault and its resolution in the connectivity report, and what information must be recorded for audit and future maintenance purposes. (5 markah)

(c) Describe the complete network connectivity report you would prepare at the conclusion of the set-up, listing all required sections and their contents. (5 markah)
