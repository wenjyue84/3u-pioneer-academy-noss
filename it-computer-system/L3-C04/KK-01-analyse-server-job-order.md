## Objektif / Objectives

Upon completing this activity, the trainee will be able to:
- Read and interpret a server job order or change request document accurately
- Extract server hardware, software, and network requirements from the job order
- Identify scope, constraints, and approval requirements before commencing installation
- Prepare a structured pre-installation checklist based on the job order

## Langkah Keselamatan / Safety Precautions

- Handle all job order documents with care; do not alter or mark the original form
- Do not commence any physical installation work until the job order analysis is signed off by the instructor
- Verify the change request approval status before planning any system modification
- Treat all server specifications and network details as confidential

---

## Prosedur / Procedure

| Langkah | Arahan / Instruction |
|---------|----------------------|
| 1 | Receive the simulated server job order / change request from the instructor. Read the entire document before writing anything. Note the requestor name, date, and authorisation signature. |
| 2 | Identify the type of request: new server installation, hardware upgrade, or configuration change. Record the request type at the top of the pre-installation checklist. |
| 3 | Extract all server hardware requirements from the job order. List CPU model, RAM capacity, storage type and capacity, number of network interface cards (NIC), and power supply specification. |
| 4 | Extract all software requirements. Record the required server operating system (OS), version, and licence key if provided. Note any middleware, database, or application roles required. |
| 5 | Extract network requirements. Record the assigned IP address(es), subnet mask, default gateway, DNS server addresses, VLAN membership, and any firewall or security policy references. |
| 6 | Review the installation environment details: server room location, rack unit (U) position, power outlet type, cooling capacity, and physical access restrictions. |
| 7 | Cross-check the job order against the server specification reference sheet. Identify any discrepancies, missing information, or specifications that conflict with site standards. Document each issue. |
| 8 | Determine the scope of work: list every task required to fulfil the job order. Estimate the time required for each task and identify which tasks require downtime or service interruption. |
| 9 | Identify dependencies and risks. Note whether any existing services will be affected, whether a rollback plan is needed, and whether the change requires a maintenance window. |
| 10 | Complete the pre-installation checklist. Sign and date it. Present the completed checklist to the instructor for review and approval before proceeding to hardware installation (KK-02). |

---

## Hasil Dijangka / Expected Outcome

A fully completed pre-installation checklist containing:
- Confirmed request type and authorisation status
- Complete hardware, software, and network requirement lists
- Identified discrepancies or missing information with proposed resolution
- Defined scope of work with estimated task durations
- Risk and dependency summary
- Instructor sign-off obtained
