## Objektif / Objectives

Upon completing this activity, the trainee will be able to:
- Compile all job order, hardware, software, and test records into a structured server installation report
- Document the as-built server configuration accurately and completely
- Record any deviations from the original job order with justification
- Present the completed report to the instructor for sign-off and handover

---

| 2 | Hardware installation record (from KK-02) | 1 |

---

## Langkah Keselamatan / Safety Precautions

- Do not include actual passwords, private keys, or sensitive network credentials in the report — use placeholders (e.g., "stored in the organisation's password vault")
- Treat the completed report as a controlled document; do not share it outside the training environment
- Ensure all records referenced in the report are factual and reflect the actual installation performed — do not falsify or estimate data
- Save a digital backup of the report before printing the final copy

## Prosedur / Procedure

| Langkah | Arahan / Instruction |
|---------|----------------------|
| 1 | **Gather all source documents.** Collect the approved job order (KK-01), hardware installation record (KK-02), software installation record (KK-03), and the completed functionality test checklist (KK-04). Verify that all documents are signed by the instructor. |
| 2 | **Open the server installation report template.** The template contains the following sections: (a) Project Information, (b) Hardware Configuration Summary, (c) Software Configuration Summary, (d) Network Configuration Summary, (e) Functionality Test Summary, (f) Deviations and Issues, (g) Handover Checklist, (h) Sign-off. |
| 3 | **Complete Section A — Project Information.** Fill in the report title, report date, server hostname, rack location (rack name and unit position), job order reference number, requestor name, technician name, and installation start and completion dates. |
| 4 | **Complete Section B — Hardware Configuration Summary.** Record the as-built hardware specifications: server model and serial number, CPU model and quantity, total installed RAM, storage drive models, capacities, and bay assignments, NIC models and port assignments, PSU configuration (single or redundant), and any additional expansion cards. |
| 5 | **Complete Section C — Software Configuration Summary.** Record the OS name, edition, version, and licence key (last 5 characters only). List all installed server roles and features with their current status. Record the date and result of the last OS update. |
| 6 | **Complete Section D — Network Configuration Summary.** Record the server hostname, IP address, subnet mask, default gateway, DNS server(s), VLAN assignment, and the MAC address of each NIC. Verify these match the job order specifications. |
| 7 | **Complete Section E — Functionality Test Summary.** Transfer the test results from the KK-04 checklist. For each test item, record the test performed, the result (PASS/FAIL), and any corrective action taken. Confirm the overall test outcome is satisfactory. |
| 8 | **Complete Section F — Deviations and Issues.** List any aspect of the installation that differed from the original job order (e.g., a specified drive model was substituted, an additional NIC was installed). For each deviation, state: the original specification, what was actually implemented, the reason, and whether the change was approved. If there were no deviations, state "Nil". |
| 9 | **Complete Section G — Handover Checklist.** Verify and tick each item: (a) server is powered on and all services are running, (b) all test results are PASS, (c) administrator credentials have been securely recorded and handed to the authorised person, (d) all installation media (USB drives, DVDs) have been collected and stored, (e) all tools have been removed from the work area, (f) server room / rack area is clean and tidy, (g) all documentation is complete and signed. |
| 10 | **Review and proofread the report.** Read through the entire report. Check that all fields are filled, all data is accurate, and the language is clear and professional. Correct any errors before printing. |
| 11 | **Print and submit the report.** Print one copy of the completed report. Sign the trainee sign-off block on the last page. Submit to the instructor for review, instructor sign-off, and final acceptance. |

---

## Hasil Dijangka / Expected Outcome

A complete, accurate, and professionally presented server installation set-up report containing:
- Full project information and installation timeline
- As-built hardware configuration summary
- Software configuration summary with OS and installed roles
- Network configuration details matching the job order
- Functionality test results with all items PASS
- Deviations and issues documented (or confirmed as nil)
- Handover checklist fully completed
- Report signed by both the trainee and instructor
