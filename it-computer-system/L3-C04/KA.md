### Q3 — Server Rack Installation
**Type:** Short Answer | **Difficulty:** L2 | **Marks:** 4 | **LO Ref:** WA2.K3

State THREE considerations when installing a rack-mount server in a server rack.

**Model Answer:** (1) Verify rack unit (U) space is available and rails are compatible with server chassis.
(2) Route power cables to redundant PDUs to avoid single point of failure. (3) Manage cables neatly
with cable managers to ensure airflow is not obstructed; label all connections.

**Rubric:** 3=All 3 correct | 2=2 correct | 1=1 correct | 0=Incorrect/blank

### Q4 — Server OS Installation
**Type:** Short Answer | **Difficulty:** L2 | **Marks:** 4 | **LO Ref:** WA3.K4

List FOUR steps performed after OS installation when configuring a new server.

**Model Answer:** (1) Install chipset and NIC drivers. (2) Apply current OS security updates/patches.
(3) Enable required server roles/features (e.g. IIS, DNS, DHCP). (4) Configure hostname, IP address,
domain membership; verify remote management access.

**Rubric:** 3=4 steps correct | 2=3 steps correct | 1=1–2 steps | 0=Incorrect/blank
