## Tugasan / Tasks

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (10 markah / marks)

**A1.** Before installing a server into a rack unit, the technician MUST first:

- (a) Power on the rack PDU to test the power rails
- (b) Verify the rack unit clearance, weight capacity, and rail kit compatibility
- (c) Install the operating system on the server
- (d) Label all cables with permanent marker

**A2.** ECC (Error-Correcting Code) RAM is preferred in servers because:

- (a) It is cheaper than standard RAM modules
- (b) It automatically detects and corrects single-bit memory errors, improving reliability
- (c) It operates at a higher clock speed than non-ECC RAM
- (d) It does not require a memory controller

**A3.** Which RAID level provides both striping and mirroring, requiring a minimum of FOUR drives?

- (a) RAID 0
- (b) RAID 1
- (c) RAID 5
- (d) RAID 10

**A4.** When installing a dual-socket server CPU, the technician should:

- (a) Install both CPUs simultaneously without checking socket compatibility
- (b) Verify that both CPUs are identical models and apply thermal paste evenly before seating
- (c) Install only one CPU and leave the second socket empty for better airflow
- (d) Reuse the existing thermal paste from the previous CPU installation

**A5.** A server's hot-swap drive bay allows the technician to:

- (a) Replace a failed hard drive while the server remains powered on and operational
- (b) Install the operating system faster than a standard drive bay
- (c) Use consumer SATA drives in a SAS backplane without adapters
- (d) Increase server RAM without powering down

**B1.** List FIVE (5) hardware components typically installed during a server hardware installation. *(5 markah)*

**B2.** Explain THREE (3) safety precautions a technician must observe when installing server hardware in a rack environment. *(6 markah)*

**B3.** Describe the correct procedure for installing a RAID controller card into a server, including TWO (2) post-installation verification steps. *(4 markah)*

### Bahagian C: Soalan Situasi / Situational Question (15 markah / marks)

**C1.** You are tasked with executing the hardware installation for a rack-mounted server based on the following specifications:

> **Server Model:** 2U Rack Server
> **CPU:** 2 × Intel Xeon Silver 4314 (LGA4189)
> **RAM:** 8 × 8 GB DDR4 ECC Registered DIMM (64 GB total, Quad-channel)
> **Storage Controller:** 12-port SAS/SATA RAID Controller (RAID 5)
> **Storage:** 4 × 2 TB 7200 RPM SAS HDD (Hot-swap bays 0–3)
> **NIC:** Dual-port 10GbE SFP+ PCIe Card
> **Power Supply:** Dual redundant 800W PSU
> **Rack Position:** Unit 12–14, Server Room B

Describe the complete step-by-step hardware installation procedure, from unpacking to final physical verification. Include the correct sequence for installing CPUs, RAM, storage, and NIC, and explain how you would verify the installation is mechanically complete and correct before powering on the server. *(15 markah)*
