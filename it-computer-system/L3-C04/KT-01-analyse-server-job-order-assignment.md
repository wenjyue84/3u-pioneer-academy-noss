## Tugasan / Tasks

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (10 markah / marks)

**A1.** What is the primary purpose of a server job order?

- (a) To record the price of server hardware
- (b) To formally document the server installation requirements and specifications
- (c) To schedule the technician's working hours
- (d) To track the server's electricity consumption

**A2.** A change request for a server installation is best described as:

- (a) A verbal instruction from the user to change the server location
- (b) A formal, documented modification to an approved server job order
- (c) A replacement for the original job order
- (d) An informal note attached to the server chassis

**A3.** Which of the following details is MOST critical to verify in a server job order?

- (a) The brand of the server casing
- (b) The server role, hardware specifications, and intended workload
- (c) The name of the delivery driver
- (d) The colour of the rack unit

**A4.** When a server job order contains conflicting specifications (e.g., storage capacity exceeds RAID controller limit), the technician should:

- (a) Proceed with the installation and report the issue later
- (b) Ignore the conflict as it will resolve itself during setup
- (c) Clarify the discrepancy with the authorised requestor before proceeding
- (d) Select the cheaper option without consultation

**A5.** Which document type must be completed and approved BEFORE a server job order is actioned?

- (a) Server installation report
- (b) Server functionality test checklist
- (c) Authorised job order or work order form
- (d) Server decommission notice

### Bahagian B: Soalan Jawapan Pendek / Short Answer (15 markah / marks)

**B1.** List FIVE (5) mandatory fields typically found in a server job order document. *(5 markah)*

**B2.** Explain THREE (3) differences between a server job order and a server change request. *(6 markah)*

**B3.** Describe TWO (2) common errors that occur during server job order analysis and state ONE (1) corrective action for each. *(4 markah)*

### Bahagian C: Soalan Situasi / Situational Question (15 markah / marks)

**C1.** You receive the following server job order from the IT Manager:

> **Job Order Ref:** JO-SRV-2024-011
> **Requestor:** IT Manager, Puan Hasmah binti Zainal
> **Date Required:** Within 5 working days
> **Server Role:** File and Print Server (Pelayan Fail dan Cetak)
> **CPU:** Intel Xeon Silver 4314 (16-Core)
> **RAM:** 64 GB DDR4 ECC Registered
> **Storage:** 4 × 2 TB SAS HDD configured as RAID 5
> **Network Interface:** Dual 10GbE ports (LACP bonding required)
> **Operating System:** Windows Server 2022 Standard
> **Applications:** Print Management Services, File Share with Active Directory integration
> **Location:** Server Room B, Rack Unit 12–14
> **Remarks:** Must comply with MS ISO/IEC 20000 internal SLA for server provisioning

Describe the step-by-step process you would follow to analyse this job order, including what you would verify, what potential issues you would identify, and how you would document your analysis before proceeding to hardware preparation. *(15 markah)*
