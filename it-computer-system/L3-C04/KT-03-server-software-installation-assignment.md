## Tugasan / Tasks

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (10 markah / marks)

**A1.** Before installing a server operating system, the technician must first:

- (a) Configure the IP address of the server
- (b) Verify BIOS/UEFI settings, boot order, and RAID volume creation
- (c) Install all server roles and features
- (d) Join the server to the Active Directory domain

**A2.** Which installation method is MOST suitable for deploying an identical OS configuration across multiple servers simultaneously?

- (a) Manual installation from a USB bootable drive, one server at a time
- (b) Network-based deployment using Windows Deployment Services (WDS) or PXE boot
- (c) Installing from a DVD-ROM drive on each server individually
- (d) Copying the OS files directly from another server using a USB cable

**A3.** After installing Windows Server 2022, the FIRST post-installation step should be:

- (a) Installing third-party antivirus software
- (b) Applying all available Windows Updates and security patches
- (c) Creating user accounts for all staff
- (d) Configuring the server wallpaper and display settings

**A4.** A server role in Windows Server is best described as:

- (a) A type of user account with administrative privileges
- (b) A collection of software programs that allows a server to perform a specific function for users
- (c) A hardware component that determines the server's processing power
- (d) A backup schedule configured in Windows Task Scheduler

**A5.** When installing server software that requires a product licence key, the technician must:

- (a) Use any available key from the internet to complete the installation
- (b) Record and store the licence key in the server installation report for compliance purposes
- (c) Skip the licence entry step to save time during installation
- (d) Share the licence key with other technicians for future use on other servers

### Bahagian B: Soalan Jawapan Pendek / Short Answer (15 markah / marks)

**B1.** List FIVE (5) common server roles available in Windows Server that may be installed based on organisational requirements. *(5 markah)*

**B2.** Explain THREE (3) differences between a Server Core installation and a Desktop Experience installation of Windows Server. *(6 markah)*

**B3.** Describe TWO (2) steps a technician must carry out to harden a server OS immediately after installation to reduce security vulnerabilities. *(4 markah)*

### Bahagian C: Soalan Situasi / Situational Question (15 markah / marks)

**C1.** You are carrying out software installation on a newly assembled rack server. The job order specifies the following software requirements:

> **Operating System:** Windows Server 2022 Standard (Desktop Experience)
> **Server Roles Required:**
> - Active Directory Domain Services (AD DS) — promote as additional domain controller
> - DNS Server
> - File and Storage Services (File Share with DFS Namespace)
> - Print and Document Services
> **Additional Software:** Symantec Endpoint Protection (licence provided), Dell OpenManage Server Administrator (OMSA)
> **Network:** Static IP — 192.168.10.20/24, Gateway 192.168.10.1, DNS 192.168.10.10
> **Domain:** corp.prisma.local
> **Post-install requirement:** All Windows Updates applied; server to be restarted and verified before handover

Describe the complete step-by-step software installation and configuration procedure from OS installation through to server role configuration and post-installation hardening. Identify TWO (2) potential issues you may encounter and state how you would resolve each. *(15 markah)*
