## BAHAGIAN A: SOALAN PELBAGAI PILIHAN / SECTION A: MULTIPLE CHOICE (30 marks)

Answer all 15 questions. Each question carries 2 marks. Circle the correct answer.

**1.** The document that formally authorises a server installation task is called a:

- (a) Service level agreement (SLA)
- (b) Job order / work order
- (c) Network topology diagram
- (d) Warranty card

**2.** Which of the following server form factors is designed to be mounted in a standard 19-inch equipment rack?

- (a) Tower server
- (b) Desktop server
- (c) Rack-mount server (1U/2U/4U)
- (d) Blade enclosure only

**3.** ECC RAM is preferred in servers because it:

- (a) Operates at higher clock speeds than standard DDR5
- (b) Detects and corrects single-bit memory errors automatically
- (c) Consumes less power than non-ECC modules
- (d) Is cheaper than standard desktop RAM

**4.** A RAID 5 array requires a minimum of:

- (a) 2 drives
- (b) 3 drives
- (c) 4 drives
- (d) 5 drives

**5.** In a server environment, an ILO/IPMI interface is used to:

- (a) Manage network switch port VLANs
- (b) Allow remote out-of-band management even when the OS is offline
- (c) Configure RAID arrays only
- (d) Monitor UPS battery levels

**6.** A dual-socket (2P) server motherboard is designed to support:

- (a) Two GPU cards in SLI mode
- (b) Two physical CPUs operating in parallel
- (c) Two independent OS installations
- (d) Two independent power supplies only

**7.** Which POST error indicates that no bootable device was detected?

- (a) CPU over-temperature warning
- (b) "No boot device found" or "Operating System not found"
- (c) Memory training failure
- (d) PCIe device error

**8.** The purpose of applying thermal interface material (TIM) to a server CPU is to:

- (a) Permanently bond the heatsink to the CPU lid
- (b) Fill microscopic surface irregularities for efficient heat transfer between CPU and heatsink
- (c) Increase the CPU operating frequency
- (d) Prevent electrostatic discharge during installation

**9.** When installing a server operating system, the partition where the OS is installed is commonly called the:

- (a) Data volume
- (b) System/boot partition
- (c) Backup partition
- (d) RAID stripe set

**10.** Which command is used on a Windows Server to verify that the NIC has a valid IP address and is reachable on the network?

- (a) `netstat -an`
- (b) `ipconfig /all` followed by `ping <gateway>`
- (c) `tracert localhost`
- (d) `nslookup`

**11.** A server installation set-up report must include:

- (a) The technician's personal contact number
- (b) Hardware specifications, OS version, RAID configuration, IP address, and test results
- (c) The cost of all components purchased
- (d) A copy of the vendor invoice only

**12.** Which of the following is the correct sequence for racking a 2U server safely?

- (a) Mount server without rails, then attach rails afterwards
- (b) Install rack rails, slide server onto rails, secure with rack screws, connect cables last
- (c) Connect all cables first, then slide server into rack
- (d) Place server on top of other equipment and secure with cable ties

**13.** A server BIOS/UEFI setting that must be enabled to support virtualisation workloads is:

- (a) Secure Boot
- (b) Intel VT-x / AMD-V (hardware virtualisation)
- (c) Fast Boot
- (d) Legacy CSM mode

**14.** What does a "memory training failure" during POST indicate?

- (a) The CPU is incompatible with the operating system
- (b) A RAM module is improperly seated, faulty, or incompatible with the platform
- (c) The RAID controller has failed
- (d) The server NIC driver is missing

**15.** The primary purpose of a UPS (Uninterruptible Power Supply) in a server room is to:

- (a) Increase the server's CPU performance
- (b) Provide temporary power during outages to allow controlled shutdown
- (c) Replace the server's internal power supply
- (d) Cool the server rack

## BAHAGIAN C: SOALAN ESEI / SECTION C: ESSAY (40 marks)

Answer all 2 questions.

**21.** You receive a job order to install a new server for a small enterprise with the following specifications:

| Field | Details |
|-------|---------|
| Form factor | 2U rack-mount |
| CPU | 2 x Intel Xeon Silver (LGA4677) |
| RAM | 128 GB ECC DDR5 (8 x 16 GB) |
| Storage | RAID 5 using 4 x 2 TB SAS drives |
| NIC | Dual 10GbE |
| OS | Windows Server 2022 Standard |
| Role | File server and domain controller |
| Rack position | 3rd slot from top, 42U rack |
| Deadline | 3 working days |

(a) Describe how you would analyse this job order, including hardware compatibility checks, rack space planning, and pre-installation verification steps. (8 marks)

(b) Describe the complete hardware installation sequence for this server, from unboxing to powering on for the first time, with justification for the order of steps. (6 marks)

(c) Describe the software installation process, including BIOS/UEFI configuration, OS installation, RAID controller setup, NIC driver installation, and role configuration. (6 marks)

**22.** After completing the server installation, you conduct the functionality test and discover the following issues:

- The server boots but one of the two CPUs is not detected in the OS
- RAID 5 is reported as "degraded" — one drive shows a fault indicator
- The server cannot be reached from the network despite the NIC showing a link

(a) For each of the three issues, explain the most likely cause and describe the troubleshooting steps you would take to resolve it. (15 marks)

(b) Describe the complete server installation set-up report you would prepare, listing all required sections and contents. Explain what action should be taken if any component deviates from the original job order specification. (10 marks)
