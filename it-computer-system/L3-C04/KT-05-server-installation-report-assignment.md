## Tugasan / Tasks

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (10 markah / marks)

**A1.** The primary purpose of a server installation set-up report is to:

- (a) Justify the cost of the server hardware to management
- (b) Provide a formal, documented record of the server installation for audit, reference, and handover purposes
- (c) Replace the need for a job order in future server installations
- (d) Record the technician's personal performance rating

**A2.** Which of the following is NOT typically included in a server installation set-up report?

- (a) Server hardware specifications as installed
- (b) Software and licence details
- (c) Technician's personal salary information
- (d) Functionality test results and sign-off status

**A3.** A server installation report must be signed by:

- (a) The technician only
- (b) The technician and the authorised requestor or supervisor as acceptance acknowledgement
- (c) The IT vendor's representative only
- (d) The server manufacturer's authorised service agent

**A4.** When recording the RAID configuration in the server installation report, the technician should include:

- (a) Only the total storage capacity visible in the OS
- (b) RAID level, number of drives, drive capacity, controller model, and logical volume status
- (c) The brand name of the hard drives only
- (d) The RAID controller's serial number only

**A5.** A server installation report that is filed and stored correctly contributes to the organisation's:

- (a) Marketing and sales strategy
- (b) IT asset register, configuration management, and audit trail
- (c) Human resources recruitment plan
- (d) Financial investment portfolio

---

### Bahagian B: Soalan Jawapan Pendek / Short Answer (15 markah / marks)

**B1.** List FIVE (5) mandatory sections that must be present in a server installation set-up report. *(5 markah)*

**B2.** Explain THREE (3) reasons why accurate documentation in a server installation report is important for the organisation's IT operations. *(6 markah)*

**B3.** Describe the correct procedure for obtaining sign-off on a completed server installation report, and state TWO (2) consequences of submitting an incomplete or inaccurate report. *(4 markah)*

### Bahagian C: Soalan Situasi / Situational Question (15 markah / marks)

**C1.** You have successfully completed the installation and functionality testing of a new rack server. You are now required to prepare the formal server installation set-up report for handover to the IT Manager. The server details are as follows:

> **Job Order Ref:** JO-SRV-2024-011
> **Installation Date:** Current date
> **Technician:** Yourself
> **Server Make/Model:** Dell PowerEdge R550, 2U Rack
> **Serial Number:** SRV-PE550-20240611
> **Location:** Server Room B, Rack Unit 12–14
> **CPU:** 2 × Intel Xeon Silver 4314 (16-Core each)
> **RAM:** 64 GB DDR4 ECC Registered (8 × 8 GB)
> **RAID Config:** RAID 5, 4 × 2 TB SAS HDD, usable ~5.5 TB, Status: Healthy
> **NIC:** Dual-port 10GbE SFP+ (LACP bonded as team0)
> **PSU:** Dual redundant 800W (both active)
> **OS:** Windows Server 2022 Standard (Desktop Experience), fully updated
> **Roles Installed:** AD DS (Additional DC), DNS, File and Storage Services (DFS), Print and Document Services
> **Applications:** Symantec Endpoint Protection v14, Dell OMSA v10
> **IP Address:** 192.168.10.20/24, GW 192.168.10.1, DNS 192.168.10.10
> **Domain:** corp.prisma.local
> **Functionality Test Result:** PASS — all services operational, replication verified, print queues active
> **Remarks:** NIC LACP warning resolved; RAID initialisation completed at 100%; all licence keys recorded

(a) Draft the complete server installation set-up report using the information above. Your report must include all mandatory sections, be written in professional government-standard language, and be suitable for submission to the IT Manager for sign-off. *(10 markah)*

(b) After submitting the report, the IT Manager informs you that the RAID configuration details are missing from the hardware section. Explain the steps you would take to amend the report and resubmit it correctly, and state what record you should keep of the amendment. *(5 markah)*
