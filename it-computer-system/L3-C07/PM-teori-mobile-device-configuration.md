## Kaedah Pengajaran / Teaching Method (4-Step)

### 1. PERSEDIAAN (Preparation)

| Langkah / Step | Aktiviti / Activity | Masa / Duration |
|----------------|---------------------|-----------------|
| 1.1 | Sambut pelatih, ambil kehadiran dan tulis kursus, tajuk serta tarikh di papan putih | 5 min |
| 1.2 | Nyatakan objektif pembelajaran sesi tersebut | 5 min |
| 1.3 | Kaitkan tajuk dengan pengalaman kerja atau pelatihan lepas pelatih; tanya soalan pembuka minda | 5 min |
| 1.4 | Berikan gambaran keseluruhan kandungan Kertas Penerangan (KP) yang akan dibincangkan | 5 min |

### 2. PENYAMPAIAN (Presentation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 2.1 | Sampaikan kandungan teori daripada KP yang berkaitan menggunakan slaid, rajah, dan contoh nyata |
| 2.2 | Terangkan istilah utama, definisi, dan konsep dengan senario industri yang relevan |
| 2.3 | Tunjukkan rajah, gambar peranti mudah alih, dan tangkapan skrin antara muka konfigurasi |
| 2.4 | Demonstrasikan jenis-jenis peranti mudah alih, perbezaan OS Android dan iOS, serta proses konfigurasi asas melalui perbincangan dan slaid |
| 2.5 | Galakkan soalan dan jelaskan kekeliruan |
| 2.6 | Ketengahkan pertimbangan keselamatan: pengendalian peranti, keselamatan data, dan kawalan akses |

### 3. PENGGUNAAN (Application)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 3.1 | Edarkan Kertas Tugasan (KT) yang berkaitan untuk sesi tersebut |
| 3.2 | Pelatih menjawab tugasan secara individu atau berkumpulan |
| 3.3 | Pengajar memberikan bimbingan dan sokongan semasa latihan |
| 3.4 | Bincangkan jawapan dan kesilapan lazim bersama kelas |

### 4. PENGESAHAN (Confirmation)

| Langkah / Step | Aktiviti / Activity |
|----------------|---------------------|
| 4.1 | Ulas semula poin pembelajaran utama sesi tersebut |
| 4.2 | Jalankan soal jawab lisan ringkas untuk mengesahkan kefahaman pelatih |
| 4.3 | Kumpul KT yang telah dilengkapkan untuk penandaan dan maklum balas |
| 4.4 | Pratonton tajuk sesi berikutnya |
| 4.5 | Rekod kehadiran dan penyelesaian sesi |

## Perincian Kandungan KP / KP Content Detail

### KP(1/4) — Job Order Analysis and Mobile Device Specifications (4.5 jam)

**Pemetaan WA:** WA 1 — Analyse Job Order/Change Request

| Topik | Kandungan |
|-------|-----------|
| 1.1 Pesanan kerja / change request | Komponen pesanan kerja; maklumat yang diperlukan; keperluan perisian, perkakasan, dan rangkaian |
| 1.2 Jenis peranti mudah alih | Smartphone, tablet, PDA, peranti navigasi; ciri-ciri setiap jenis |
| 1.3 Spesifikasi peranti | Jenama/model, kapasiti RAM, storan, jenis paparan, kaedah input, sambungan, versi OS |
| 1.4 Semakan keserasian (compatibility check) | Semakan versi OS, keperluan aplikasi, jenis penyambung (kabel), keperluan rangkaian |
| 1.5 Perancangan konfigurasi | Menyediakan senarai semak konfigurasi berdasarkan pesanan kerja |

**Soalan Pengesahan:**
- S: Apakah lima (5) maklumat utama yang perlu terdapat dalam pesanan kerja konfigurasi peranti mudah alih?
- S: Apakah perbezaan antara smartphone dan tablet dari segi kegunaan dalam persekitaran korporat?

---

### KP(2/4) — Mobile Device Types, OS, Application Requirements and Compatibility (4.5 jam)

**Pemetaan WA:** WA 2 — Carry Out Mobile Device Configuration (bahagian teori)

| Topik | Kandungan |
|-------|-----------|
| 2.1 Sistem pengendalian mudah alih | Android (Google); iOS (Apple); ciri-ciri, kelebihan, batasan |
| 2.2 Versi OS | Kepentingan versi OS; kesan versi terhadap keserasian aplikasi; prosedur kemaskini |
| 2.3 Lesen perisian | Lesen hak milik vs lesen sumber terbuka; implikasi penggunaan korporat |
| 2.4 Keperluan aplikasi | Keperluan perkakasan minimum; keserasian OS; kebenaran (permissions) aplikasi |
| 2.5 Sumber pemasangan aplikasi | Google Play Store (Android); Apple App Store (iOS); risiko pemasangan dari sumber tidak sah |
| 2.6 Jenis penyambung | USB Type-A, USB Type-B, USB-C, Lightning, Mini USB, USB OTG; kesesuaian dengan model peranti |

**Soalan Pengesahan:**
- S: Apakah dua (2) perbezaan utama antara Android dan iOS dari segi pemasangan aplikasi?
- S: Mengapakah pemasangan aplikasi dari sumber tidak rasmi berbahaya?

---

### KP(3/4) — Mobile Device Configuration Settings, Network and Security (4.5 jam)

**Pemetaan WA:** WA 2 — Carry Out Mobile Device Configuration (bahagian teori lanjutan)

| Topik | Kandungan |
|-------|-----------|
| 3.1 Tetapan konfigurasi asas peranti | Tetapan menu peranti; bahasa, masa/zon waktu, paparan, bunyi |
| 3.2 Konfigurasi akaun | Pemasangan akaun e-mel (IMAP, POP3, Exchange); akaun Google / Apple ID |
| 3.3 Konfigurasi rangkaian Wi-Fi | SSID, jenis keselamatan (WPA2/WPA3), kata laluan, konfigurasi proksi |
| 3.4 Konfigurasi APN data mudah alih | Nama Titik Akses (APN); tetapan data operator; ujian sambungan |
| 3.5 Konfigurasi VPN | Jenis VPN (IPSec, SSL/TLS); memasang profil VPN; pengesahan sijil |
| 3.6 Tetapan keselamatan | PIN/kata laluan skrin kunci; penyulitan peranti (device encryption); MDM enrollment; dasar keselamatan korporat |
| 3.7 MDM (Mobile Device Management) | Tujuan MDM; proses pendaftaran; dasar yang boleh dikuatkuasakan melalui MDM |

**Soalan Pengesahan:**
- S: Apakah maksud APN dan mengapa ia perlu dikonfigurasi?
- S: Senaraikan tiga (3) tetapan keselamatan yang perlu dikonfigurasi pada peranti korporat.

---

### KP(4/4) — Mobile Device Troubleshooting, Testing and Commissioning (4.5 jam)

**Pemetaan WA:** WA 3 — Perform Mobile Device Troubleshoot; WA 4 — Carry Out Mobile Device Commissioning

| Topik | Kandungan |
|-------|-----------|
| 4.1 Kaedah penyelesaian masalah | Pendekatan sistematik: kenal pasti, analisa, selesaikan, sahkan; penggunaan fail log |
| 4.2 Masalah lazim konfigurasi | Wi-Fi tidak dapat disambung; ralat pengesahan (authentication error); e-mel tidak berfungsi; storan tidak mencukupi; aplikasi gagal dipasang |
| 4.3 Ujian pengesahan (Authentication test) | Ujian log masuk akaun; ujian kebenaran akses |
| 4.4 Ujian rangkaian dan komunikasi | Ujian ping; ujian muat turun/naik data; ujian e-mel; ujian VPN |
| 4.5 Ujian aplikasi | Ujian fungsional setiap aplikasi yang dipasang; semakan versi |
| 4.6 Commissioning peranti | Definisi commissioning; senarai semak commissioning; kriteria penerimaan (acceptance criteria) |
| 4.7 Dokumentasi dan laporan konfigurasi | Kandungan laporan konfigurasi; kepentingan dokumentasi; prosedur penyerahan peranti kepada pengguna |

**Soalan Pengesahan:**
- S: Apakah langkah PERTAMA dalam penyelesaian masalah apabila peranti tidak dapat menyambung ke Wi-Fi?
- S: Apakah yang dimaksudkan dengan commissioning peranti mudah alih?
