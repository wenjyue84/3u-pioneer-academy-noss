## Arahan kepada Pelatih / Instructions to Trainee

1. Ini adalah peperiksaan AMALI. Anda akan dinilai berdasarkan keupayaan anda melaksanakan konfigurasi peranti mudah alih secara menyeluruh.
2. Anda akan diberikan pesanan kerja, peranti mudah alih, dan kelengkapan yang diperlukan. Anda mesti melengkapkan keseluruhan kitaran konfigurasi.
3. Anda akan dinilai berdasarkan: **Proses** (cara anda melaksanakan tugas), **Hasil** (keputusan konfigurasi), **Sikap** (profesionalisme), **Keselamatan** (pematuhan prosedur keselamatan), dan **Alam Sekitar** (penjagaan ruang kerja).
4. Semua kerja mesti didokumentasikan dalam borang laporan konfigurasi yang disediakan.
5. Anda TIDAK dibenarkan meminta bantuan penilai kecuali dalam situasi kecemasan keselamatan.

## Tugasan / Task Description

**Senario:** Anda adalah Juruteknik Sistem Komputer Tahap 3. Anda menerima pesanan kerja berikut:

| Maklumat | Butiran |
|----------|---------|
| Nombor pesanan kerja | PA-C07-2026-001 |
| Diminta oleh | Jabatan Sumber Manusia |
| Keutamaan | Normal |
| Jenis peranti | Smartphone Android (versi OS semasa) |
| Konfigurasi akaun | E-mel korporat (IMAP/Exchange) |
| Konfigurasi rangkaian | Wi-Fi (WPA2), APN data mudah alih |
| Aplikasi yang diperlukan | E-mel, penyemak imbas korporat, antivirus mudah alih |
| Keselamatan | Kunci skrin PIN (6 digit), penyulitan peranti (device encryption) |
| Ujian diperlukan | Ujian e-mel, ujian rangkaian, ujian aplikasi |
| Tarikh siap | Hari ini |

**Anda mesti melengkapkan tugas berikut mengikut urutan:**

1. Menganalisis pesanan kerja dan menyediakan senarai semak konfigurasi (10 minit)
2. Memeriksa spesifikasi peranti dan keserasian OS (10 minit)
3. Melaksanakan konfigurasi asas peranti (tetapan, akaun, keselamatan) (40 minit)
4. Memasang dan mengkonfigurasi aplikasi yang diperlukan (30 minit)
5. Mengkonfigurasi tetapan rangkaian (Wi-Fi, APN, e-mel) (20 minit)
6. Menjalankan ujian konfigurasi dan commissioning (20 minit)
7. Melengkapkan laporan konfigurasi dan menyediakan untuk penyerahan (20 minit)

**Jumlah masa yang dibenarkan: 2 jam 30 minit**
