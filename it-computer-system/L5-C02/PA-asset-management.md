## Arahan kepada Pelatih / Instructions to Trainee

1. This is a PRACTICAL examination. You will be assessed on your ability to manage computer system assets through the complete asset management lifecycle.
2. You will be given a scenario, a simulated asset register, ITAM system access, physical assets (training units), and supporting documents. You must complete all tasks within the time allowed.
3. You will be assessed on: **Process** (how you work), **Output** (quality of deliverables), **Attitude** (professionalism and decision-making), **Safety and Compliance** (data protection, regulatory requirements), and **Environmental** compliance (e-waste handling).
4. Work independently. Do not seek assistance unless there is a safety or compliance concern.
5. All outputs must be submitted to the assessor at the end of the examination.

---

## Arahan kepada Penilai / Instructions to Assessor

- Provide each trainee with: the scenario brief, simulated asset register (50 records), ITAM system access (training instance), 5 physical training assets with tags, label printer access, simulated supporting documents (repair quotations, vendor quotations, technical assessment reports), and all required templates.
- Observe each trainee continuously throughout the examination.
- Do NOT provide guidance or assistance unless there is a safety or compliance issue.
- Score each criterion on the rubric as the trainee works and at output review.
- Total time: **4 hours**.

## Tugasan / Task Description

**Scenario:** You are the IT Asset Manager at Prisma Academy Sdn Bhd. You have been asked to complete the following asset management tasks during this assessment session.

---

### Task 1: Asset Inventory and Reconciliation (60 minutes)

You are provided with a simulated asset register (50 records) and the results of an automated network discovery scan (CSV file). The discovery scan was run on the same environment.

**Required outputs:**
1. Reconcile the physical and logical inventory — identify ghost and phantom assets
2. Update the ITAM system to correct all resolvable discrepancies
3. Produce a one-page Inventory Reconciliation Summary

---

### Task 2: Asset Status Classification (45 minutes)

From the 50-asset register, ten assets have been flagged for status review. Supporting documents (technical assessment reports, repair quotations, age data) are provided for each.

**Required outputs:**
1. Classify each of the ten assets using the standard criteria
2. Document the classification decision and supporting evidence for each asset
3. Identify any assets that qualify for End-of-Life classification and prepare a disposal trigger memo

---

### Task 3: Cost and Space Estimation (45 minutes)

The company plans to purchase 10 new laptops to replace the end-of-life assets identified in Task 2. Two vendor quotations are provided.

**Required outputs:**
1. Calculate the 4-year TCO for both vendors
2. Prepare the straight-line depreciation schedule for the recommended vendor
3. Write a one-page procurement recommendation with CBA summary

---

### Task 4: Asset Tagging (30 minutes)

Five new training assets (desktops and laptops) have just been received. They are untagged.

**Required outputs:**
1. Generate asset IDs following the organisation's tag format (3UPAM-[TYPE]-[YEAR]-[SEQ])
2. Print and affix labels to the correct location on each asset
3. Create asset records in the ITAM system for all five assets

---

### Task 5: Secure Data Destruction (30 minutes)

Two end-of-life assets have received disposal approval. Asset A contains a SATA HDD with internal data classified as "Internal". Asset B contains an NVMe SSD with data classified as "Confidential".

**Required outputs:**
1. Select the appropriate destruction method for each asset with justification
2. Execute the data destruction using the tools provided (DBAN USB for HDD; ATA Secure Erase utility for SSD)
3. Complete the Data Destruction Certificate for each asset

---

### Task 6: Asset Management Report (30 minutes)

Using data compiled from Tasks 1–5 and the summary statistics provided, prepare a one-page Management Summary Report suitable for presentation to the Operations Director.

**Required outputs:**
1. Management Summary Report (one page, A4) covering: portfolio status overview, key KPIs vs targets, top three findings, and recommendations
2. Licence compliance table for the four software products in the provided data
