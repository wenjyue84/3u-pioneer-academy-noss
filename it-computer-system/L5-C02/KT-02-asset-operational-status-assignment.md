## Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (20 marks)

**A1.** An IT asset that is functional but has not been assigned to any user and has been sitting in the IT storeroom for 3 weeks is classified as:

- (a) Active
- (b) In Repair
- (c) Idle / Unassigned
- (d) End of Life

**A2.** Which of the following is the MINIMUM number of End-of-Life criteria that must be satisfied before an asset can be formally classified as End of Life?

- (a) One
- (b) Two
- (c) Three
- (d) Four

**A3.** An asset's status is changed from "Active" to "Pending Disposal". Which of the following must be completed BEFORE this status change is recorded?

- (a) The asset has been physically destroyed
- (b) Disposal approval has been obtained from the authorising committee
- (c) The asset has been removed from the insurance schedule
- (d) The replacement asset has been ordered

**A4.** Which status transition is triggered by a missing asset report and requires a police report or internal incident report?

- (a) Active → In Repair
- (b) Any status → Lost / Stolen
- (c) Idle → End of Life
- (d) Pending Disposal → Disposed

**A5.** A laptop's repair quotation is RM 1,800. The laptop's current replacement value is RM 3,200. What is the repair-to-replacement ratio and what status classification does this suggest?

- (a) 56.3% — exceeds the 50% threshold; classify as End of Life / Uneconomical to Repair
- (b) 56.3% — below the threshold; repair and return to Active
- (c) 43.7% — classify as End of Life
- (d) 43.7% — classify as In Repair

## Bahagian B: Soalan Jawapan Pendek / Short Answer (30 marks)

**B1.** List FIVE (5) standard operational status categories used in IT asset management. For each, write a one-sentence definition. (10 marks)

**B2.** Describe THREE (3) ways in which an asset's operational status affects management decisions. For each, give a specific example. (9 marks)

**B3.** Explain what information must be recorded in the asset register when an asset's status is changed. Why is this documentation requirement important for audits? (6 marks)

**B4.** An organisation has 200 active IT assets. After a status review, 28 are reclassified as Idle. What action should the asset manager take next, before recommending new procurement? Explain why. (5 marks)

## Bahagian C: Soalan Berstruktur / Structured Question (50 marks)

**C1.** You are the IT Asset Manager at a private university in Malaysia. The university has 1,200 IT assets. During the annual status review, you receive the following information about six assets:

| Asset | Description | Evidence |
|-------|-------------|---------|
| A | Desktop PC | Purchased 2018; runs Windows 10 (Microsoft end-of-support Oct 2025); cannot run Windows 11 (fails TPM 2.0 check) |
| B | Laptop | In the IT store since March (5 months); last assigned user resigned; fully functional |
| C | Server | Hard disk failure; repair quote RM 12,000; replacement server cost RM 18,000 |
| D | Network Switch | Deployed in Server Room; last scanned by ITAM system yesterday; no faults reported |
| E | Printer | Reported missing by user; IT store has no record of it |
| F | Monitor | Physically found but asset tag is missing; serial number matches register entry for a monitor in a different department |

(a) For each of the six assets (A–F), state the appropriate operational status and the primary criterion or evidence supporting your classification. (18 marks)

(b) Describe the specific documentation that must be completed for Assets C and E. Include the form name, key fields, and who must authorise each document. (12 marks)

(c) Asset B has been idle for 5 months. The Finance department has submitted a purchase request for 2 new laptops. Explain the process the asset manager should follow before the purchase request is approved. What factors determine whether the idle laptop can be redeployed? (12 marks)

(d) Write a status transition record (as it would appear in the asset register) for Asset A, changing its status from Active to End of Life. Include all required fields. (8 marks)
