## Objektif / Objective

Design an asset tag format for a simulated organisation, produce and affix tags on a set of training assets, conduct a spot-check audit of tagging compliance, and produce a tag compliance report with corrective actions.

---

## Tempoh / Duration

5 hours

---

## Peralatan dan Bahan / Equipment and Materials

| No. | Item | Quantity |
|-----|------|----------|
| 1 | Laptop or workstation with ITAM system access | 1 |
| 2 | Label printer (Dymo, Brother, or equivalent) with barcode/QR capability | 1 (shared) |
| 3 | Label stock (polyester, adhesive-backed) | 1 roll (shared) |
| 4 | Barcode/QR scanner | 1 |
| 5 | Set of 10 training assets (desktops, laptops, monitors, printers — simulated or actual) | 10 |
| 6 | Simulated asset register with tag number fields (blank) | 1 |
| 7 | Tag Placement Guide (from KP-05) | 1 |
| 8 | Tag Compliance Audit Checklist (provided) | 1 |

---

## Langkah Keselamatan / Safety Precautions

- Do not affix tags over ventilation slots, serial number labels, or regulatory markings
- Use tamper-evident labels only on designated high-value assets as instructed
- Do not use solvents to remove existing labels without instructor approval
- Handle all assets with care; do not open cases or disconnect cables

---

## Prosedur / Procedures

| Langkah | Arahan / Instruction |
|---------|---------------------|
| 1 | Design the asset tag format for the simulated organisation "3U Pioneer Academy". Define: the organisation code (3UPA), asset type codes for each asset type present (refer to KP-05 Section 3.2), the year, and the starting sequence number (00001). Document the format in a Tag Format Specification sheet. |
| 2 | Generate asset IDs for all 10 training assets. For each asset, determine the appropriate asset type code based on the physical inspection. Assign sequential numbers. Record the mapping in a spreadsheet: Asset ID, Asset Type, Manufacturer, Model, Serial Number. |
| 3 | Configure the label printer to produce labels containing: the asset ID in human-readable text, the asset ID as a QR code, and the text "PROPERTY OF 3U PIONEER ACADEMY". Print all 10 labels and verify that each QR code is scannable before affixing. |
| 4 | Affix each label to the correct location on each asset, following the placement guide from KP-05 Section 4.1. For any asset where the standard location is obstructed, document the alternative placement and the reason in the Tag Format Specification sheet. |
| 5 | Create asset records in the ITAM system for all 10 assets. Enter: Asset ID, Asset Type, Manufacturer, Model, Serial Number, Tag Number (same as Asset ID), and Location. |
| 6 | Conduct a simulated spot-check audit. The instructor will modify 3 of the 10 assets (e.g. remove a tag, place a tag in the wrong location, enter a wrong serial number in the system). Using the barcode scanner, scan all 10 assets and compare physical findings with the ITAM register. Identify and document all discrepancies. |
| 7 | For each discrepancy identified in Step 6, complete a Non-Compliance Record in the audit checklist: describe the non-compliance type, the corrective action taken or recommended, and the resolution target date. |
| 8 | Compile the Tag Compliance Report using the structure in the Expected Outcome section. Calculate the Tag Coverage Rate, Tag Readability Rate, and Register Accuracy Rate for the 10-asset sample. |

---

## Hasil Jangkaan / Expected Outcome

1. **Tag Format Specification** — format definition, asset type codes, sample tag for each asset type
2. **Asset ID Mapping Spreadsheet** — all 10 assets with ID, type code, serial, and assigned tag
3. **Printed and affixed tags** — verified as scannable; correctly placed on all assets
4. **ITAM records** — all 10 assets created in the system with correct attributes
5. **Spot-check audit log** — all discrepancies identified and documented
6. **Non-Compliance Records** — corrective action documented for each discrepancy
7. **Tag Compliance Report** — coverage rate, readability rate, register accuracy rate; recommendations
