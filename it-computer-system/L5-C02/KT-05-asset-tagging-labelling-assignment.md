## Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (20 marks)

**A1.** Which type of asset tag is MOST appropriate for a server installed in a metal rack enclosure, where the tag must be readable without removing the server from the rack?

- (a) Standard 1D barcode label
- (b) Standard QR code label
- (c) RFID on-metal tag
- (d) Hand-written paper label

**A2.** According to best practice, at what point in the asset lifecycle should a tag be affixed to a new IT asset?

- (a) When the asset is assigned to a user
- (b) At point of receipt — before deployment
- (c) During the annual physical audit
- (d) After the asset has been in service for 30 days

**A3.** An organisation's Tag Coverage Rate is calculated as:

- (a) (Assets with valid tag / Assets deployed this year) × 100%
- (b) (Assets with valid tag / Total assets) × 100%
- (c) (Tags printed / Tags affixed) × 100%
- (d) (Assets scanned / Total assets in register) × 100%

**A4.** A tamper-evident label is found showing a "VOID" pattern on a high-value laptop. What is the FIRST action the asset manager should take?

- (a) Replace the label immediately and continue normal operations
- (b) Investigate the tampering; escalate to the security team if unauthorised access is suspected
- (c) Dispose of the laptop as it is now unusable
- (d) Update the asset register to show the laptop as "In Repair"

**A5.** Which of the following is a consequence of tagging assets AFTER deployment rather than at point of receipt?

- (a) Tags last longer because the asset is already in a stable environment
- (b) Some assets may never be tagged; the register has gaps from day one
- (c) The tag number sequence will start at a higher number
- (d) Users will be more aware of the tagging system

## Bahagian B: Soalan Jawapan Pendek / Short Answer (30 marks)

**B1.** Design an asset tag format for an organisation called "Prisma Technology Sdn Bhd". Define: the organisation code, asset type codes for at least 5 asset types, the full tag format with an example for each type. (10 marks)

**B2.** Describe the standard tag placement location for FOUR (4) different asset types. For each, explain why that location was chosen (e.g. visibility, access). (8 marks)

**B3.** An organisation conducts a monthly spot-check audit of 10% of its 500 assets. The results show: 46 out of 50 assets scanned had readable tags; 44 out of 50 had correct ITAM records.

(a) Calculate the Tag Readability Rate and the Register Accuracy Rate. (4 marks)

(b) Both rates are below the organisational targets (readability ≥ 98%; accuracy ≥ 97%). Describe the corrective actions the asset manager should implement within the next 30 days. (8 marks)

## Bahagian C: Soalan Berstruktur / Structured Question (50 marks)

**C1.** A newly established polytechnic in Malaysia has just received 200 IT assets (80 desktops, 40 laptops, 30 servers, 20 network switches, 30 printers). None of the assets have been tagged yet. The IT Director has asked you, as the IT Asset Manager, to design and implement the asset tagging programme.

(a) Write the Tag Format Specification for the polytechnic (organisation code: POLY). Define the format, asset type codes for all five asset types present, and provide one example tag for each type. (10 marks)

(b) Describe the end-to-end tagging workflow from point of receipt to deployment. For each step, state the action, the responsible party, and the document or system record produced. (15 marks)

(c) Three months after implementation, the IT Director asks for a Tag Compliance Report. Describe the data you would collect, the metrics you would calculate, and the format you would use to present the findings. (12 marks)

(d) During the quarterly spot-check, you discover that 12 of the servers have RFID tags that are unreadable. Investigation reveals the standard polyester QR/RFID tags were used on the metal server chassis. Explain the root cause of this problem and describe the corrective action. How should the tagging policy be updated to prevent recurrence? (13 marks)
