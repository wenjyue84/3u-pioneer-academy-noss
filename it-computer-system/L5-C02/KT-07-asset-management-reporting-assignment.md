## Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (20 marks)

**A1.** Which of the following is the PRIMARY audience for the Annual Asset Management Report's Executive Summary?

- (a) The IT help desk team
- (b) External auditors only
- (c) Senior management and the Board — who need a strategic overview without reading the full report
- (d) The asset tag printing vendor

**A2.** The Licence Compliance Report shows that Microsoft 365 has 120 licences purchased but 138 deployed (18 more deployed than purchased). This situation is described as:

- (a) Under-utilisation — no action required
- (b) Over-deployment — the organisation is non-compliant and at risk of a licence audit penalty
- (c) Compliant — within a 15% tolerance
- (d) A data entry error that can be ignored

**A3.** Which chart type is MOST appropriate for showing the trend of monthly repair counts over a 12-month period?

- (a) Pie chart
- (b) Line chart
- (c) Donut chart
- (d) Scatter plot

**A4.** The formula for calculating the Active Asset Utilisation KPI is:

- (a) (Active assets / Total assets ever purchased) × 100%
- (b) (Active assets / Total non-disposed assets) × 100%
- (c) (Assets in use today / Assets purchased this year) × 100%
- (d) (Active assets / Total licences) × 100%

**A5.** Which of the following statements about the Executive Summary of an asset management report is CORRECT?

- (a) It should be written first, before the rest of the report
- (b) It should repeat the full content of every section for convenience
- (c) It must be self-contained, action-oriented, and include findings with specific recommendations
- (d) It is optional for internal management reports

## Bahagian B: Soalan Jawapan Pendek / Short Answer (30 marks)

**B1.** List the ELEVEN (11) sections of a comprehensive Annual Asset Management Report. For each section, write a one-sentence description of its content. (11 marks)

**B2.** An organisation's ITAM KPIs for the quarter are as follows:

| KPI | Result | Target |
|-----|--------|--------|
| Asset Register Accuracy | 94.2% | ≥ 97% |
| Idle Asset Rate | 14.8% | ≤ 10% |
| Mean Time to Repair | 8.3 days | ≤ 5 days |
| Licence Compliance Rate | 103% (over-deployed) | 90–100% |

For each KPI that is below target, write a Finding-Impact-Recommendation statement as described in KP-07 Section 6.2. (12 marks)

**B3.** Explain why the software licence deployment count should be obtained from automated discovery data rather than from user self-reporting. What risk does self-reporting introduce? (7 marks)

## Bahagian C: Soalan Berstruktur / Structured Question (50 marks)

**C1.** You are preparing the annual IT asset management report for a manufacturing company with 650 assets. The following data is available:

**Asset Portfolio:**
- 420 Active, 65 Idle, 38 In Repair, 42 Pending Disposal, 85 Disposed (during the year)
- Total gross asset value: RM 2,850,000
- Total accumulated depreciation: RM 1,640,000
- Depreciation charge for the year: RM 380,000
- Assets disposed during the year: book value RM 125,000; proceeds received RM 48,000
- Repair costs for the year: RM 67,500 across 112 repair events
- Longest single repair: 22 days

**Software Licences (selected):**
| Product | Licences Purchased | Licences Deployed |
|---------|--------------------|-------------------|
| Windows 11 Pro | 420 | 418 |
| Microsoft 365 Business | 380 | 391 |
| AutoCAD LT | 25 | 23 |
| Adobe Acrobat Pro | 50 | 57 |

(a) Calculate the following KPIs and state whether each meets its target:
(i) Active Asset Utilisation; (ii) Idle Asset Rate; (iii) MTTR; (iv) Licence Compliance Rate for each of the four software products listed. (16 marks)

(b) Calculate: (i) Net book value of the asset portfolio at year-end; (ii) Gain or loss on disposal of the assets disposed during the year; (iii) Average repair cost per event. (9 marks)

(c) Write the Executive Summary for this report (maximum 300 words). It must be self-contained, include at least three key findings (each with impact and recommendation), and be suitable for presentation to the Board of Directors. (15 marks)

(d) The company's Finance Director asks why the ITAM report shows a different asset count from the financial fixed asset register. Explain THREE (3) reasons why the ITAM asset inventory and the financial fixed asset register may differ. How should these differences be reconciled? (10 marks)
