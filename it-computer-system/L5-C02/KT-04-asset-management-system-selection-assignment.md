## Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (20 marks)

**A1.** Which of the following is an open-source ITAM software platform that includes a built-in helpdesk module and network auto-discovery via the FusionInventory plugin?

- (a) Snipe-IT
- (b) ServiceNow ITAM
- (c) GLPI
- (d) Flexera One

**A2.** Role-Based Access Control (RBAC) in an ITAM system is important because:

- (a) It increases the system's processing speed
- (b) It ensures that only authorised personnel can view or modify specific asset data
- (c) It automatically discovers new assets on the network
- (d) It calculates asset depreciation

**A3.** Which integration between the ITAM system and another system would automatically create an asset record when a new purchase order is approved?

- (a) ITAM ↔ HR system
- (b) ITAM ↔ Procurement system
- (c) ITAM ↔ Service desk
- (d) ITAM ↔ CMDB

**A4.** During the implementation of a new ITAM system, the purpose of the User Acceptance Testing (UAT) phase is to:

- (a) Train all IT staff on how to use the system
- (b) Test all workflows and reports with key users to verify the system meets requirements before go-live
- (c) Configure the system's database and server infrastructure
- (d) Import all asset data from the old system

**A5.** A Proof of Concept (PoC) for an ITAM system should be conducted:

- (a) After signing the vendor contract
- (b) Only if the system is open-source
- (c) Before committing to a platform, using real or representative data to verify the system meets key requirements
- (d) Only for systems costing more than RM 100,000

## Bahagian B: Soalan Jawapan Pendek / Short Answer (30 marks)

**B1.** List FIVE (5) functional requirements that an organisation should define before selecting an ITAM system. For each, briefly explain why it matters. (10 marks)

**B2.** Describe the difference between agent-based and agentless asset discovery. State ONE advantage and ONE limitation of each approach. (8 marks)

**B3.** An organisation currently uses separate spreadsheets for: (i) the asset register, (ii) software licences, and (iii) vendor contracts. Explain THREE (3) problems this approach creates. How would a unified ITAM platform address each problem? (12 marks)

## Bahagian C: Soalan Berstruktur / Structured Question (50 marks)

**C1.** A Malaysian public university with 3,000 IT assets across five faculties is considering replacing its existing manual asset register (Excel-based) with an ITAM software platform. The IT Director has shortlisted two options: **Snipe-IT** (open-source, self-hosted) and **ManageEngine AssetExplorer** (commercial, cloud-hosted).

(a) For each platform, identify THREE (3) strengths and TWO (2) limitations relevant to the university's context. (20 marks)

(b) The university's IT department has 4 staff: 1 IT Manager, 2 IT Officers, and 1 System Administrator. Describe how Role-Based Access Control (RBAC) should be configured for each role. State what actions each role should be permitted to perform and what should be restricted. (12 marks)

(c) The university's Finance department requires a monthly depreciation report and a quarterly capital expenditure vs budget report. The HR department wants the ITAM system to automatically de-assign assets when an employee resigns. Describe the integrations required to meet both requirements. Include the integration method (API, CSV export, direct connector) and the data that must flow between systems. (10 marks)

(d) The university decides to implement Snipe-IT. The implementation team discovers that the existing Excel asset register contains 340 records with incomplete or inconsistent data (missing serial numbers, duplicate entries, wrong department codes). Describe the data migration strategy you would recommend. What steps must be completed before the data is imported into Snipe-IT? (8 marks)
