## Tugasan / Tasks

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (10 markah / marks)

**A1.** Apakah tujuan utama penggunaan kemas kini keselamatan (security patches) pada sistem pengendalian pelayan? / What is the main purpose of applying security patches to a server operating system?

- (a) Untuk meningkatkan kelajuan pemprosesan data / To increase data processing speed
- (b) Untuk menutup kelemahan keselamatan yang diketahui dan melindungi pelayan daripada eksploitasi / To close known security vulnerabilities and protect the server from exploitation
- (c) Untuk menambah ciri antara muka grafik baharu / To add new graphical interface features
- (d) Untuk mengoptimumkan penggunaan memori bagi aplikasi pejabat / To optimise memory usage for office applications

**A2.** Sebelum menggunakan kemas kini OS pada pelayan produksi (production server), apakah amalan terbaik yang perlu dilaksanakan terlebih dahulu? / Before applying OS updates to a production server, what best practice should be carried out first?

- (a) Mematikan semua perkhidmatan rangkaian / Shutting down all network services
- (b) Membuat sandaran (backup) sistem atau snapshot sebelum sebarang kemas kini digunakan / Creating a system backup or snapshot before any update is applied
- (c) Memaklumkan semua pengguna bahawa pelayan akan dipensiunkan / Informing all users that the server will be retired
- (d) Memadam semua fail log yang sedia ada / Deleting all existing log files

**A3.** Apakah fungsi utiliti "Event Viewer" (Windows Server) atau "journalctl" (Linux) dalam penyelenggaraan OS pelayan? / What is the function of the "Event Viewer" (Windows Server) or "journalctl" (Linux) utility in server OS maintenance?

- (a) Mengurus akaun pengguna dan kata laluan / Managing user accounts and passwords
- (b) Memformat semula cakera keras sistem / Reformatting the system hard disk
- (c) Menyemak dan menganalisis log peristiwa sistem untuk mengenal pasti ralat, amaran, dan aktiviti luar biasa / Reviewing and analysing system event logs to identify errors, warnings, and unusual activity
- (d) Mengkonfigurasi tetapan rangkaian pelayan / Configuring server network settings

**A4.** Dalam penyelenggaraan OS pelayan, apakah tujuan penyahjagalan cakera (disk defragmentation) untuk cakera keras berputar (HDD)? / In server OS maintenance, what is the purpose of disk defragmentation for a spinning hard disk drive (HDD)?

- (a) Memadamkan fail yang rosak secara kekal / Permanently deleting corrupt files
- (b) Menyusun semula data berselerak pada cakera bagi meningkatkan kelajuan capaian / Rearranging fragmented data on the disk to improve access speed
- (c) Mencipta partition baharu pada cakera / Creating new partitions on the disk
- (d) Meningkatkan kapasiti storan fizikal / Increasing physical storage capacity

**A5.** Apakah langkah yang perlu diambil selepas mengguna pakai kemas kini OS pada pelayan untuk mengesahkan kejayaan kemas kini tersebut? / What step should be taken after applying OS updates on a server to verify the update was successful?

- (a) Mematikan pelayan serta-merta / Shutting down the server immediately
- (b) Memformat semula cakera sistem / Reformatting the system disk
- (c) Menyemak log kemas kini, mengesahkan versi OS terkini, dan menguji perkhidmatan kritikal masih berfungsi / Checking update logs, verifying the current OS version, and testing that critical services are still functioning
- (d) Memadamkan semua akaun pengguna sementara / Deleting all temporary user accounts

### Bahagian C: Soalan Situasi / Situational Question (20 markah / marks)

**C1.** Anda ialah juruteknik IT yang bertanggungjawab ke atas pelayan Windows Server 2022 bernama SRV-APP-03 yang menjalankan perkhidmatan aplikasi dalaman syarikat. Semasa sesi penyelenggaraan OS berjadual, anda mendapati perkara berikut:

You are an IT technician responsible for a Windows Server 2022 server named SRV-APP-03 that runs the company's internal application services. During a scheduled OS maintenance session, you find the following:

- 47 kemas kini keselamatan belum digunakan, termasuk 3 bertanda "Kritikal" / 47 security updates have not been applied, including 3 marked "Critical"
- Ruang cakera pada pemacu C: tinggal 8% (32 GB daripada 400 GB) / Disk space on C: drive is down to 8% (32 GB of 400 GB)
- Log Peristiwa menunjukkan 12 ralat "Application Crash" dalam tempoh 7 hari lepas, semuanya berkaitan dengan perkhidmatan yang sama / Event Log shows 12 "Application Crash" errors in the past 7 days, all related to the same service
- Dua akaun pengguna tidak aktif sejak 180 hari yang lalu masih dalam keadaan aktif / Two user accounts inactive for 180 days are still enabled

**(i)** Susun keempat-empat isu di atas mengikut **keutamaan tindakan** dan berikan justifikasi ringkas untuk setiap susunan. / Arrange all four issues above according to **priority of action** and provide a brief justification for each ranking. *(8 markah)*

**(ii)** Pilih **DUA (2) isu** yang anda anggap paling kritikal dan huraikan langkah-langkah teknikal lengkap untuk menangani setiap isu tersebut pada Windows Server 2022. Sertakan langkah berjaga-jaga sebelum bertindak, prosedur pelaksanaan, dan kaedah pengesahan selepas tindakan. / Select the **TWO (2) issues** you consider most critical and describe the complete technical steps to address each on Windows Server 2022. Include precautionary steps before acting, the implementation procedure, and the verification method after the action. *(12 markah)*
