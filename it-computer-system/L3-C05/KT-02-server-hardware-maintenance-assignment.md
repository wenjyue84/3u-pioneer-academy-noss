## Tugasan / Tasks

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (10 markah / marks)

**A1.** Mengapakah juruteknik perlu memakai gelang anti-statik (ESD wrist strap) semasa menjalankan penyelenggaraan perkakasan pelayan? / Why must a technician wear an ESD wrist strap when carrying out server hardware maintenance?

- (a) Untuk melindungi kulit daripada habuk / To protect the skin from dust
- (b) Untuk mencegah nyahcas elektrostatik yang boleh merosakkan komponen sensitif / To prevent electrostatic discharge that can damage sensitive components
- (c) Untuk memudahkan pengenalpastian juruteknik di bilik pelayan / To easily identify the technician in the server room
- (d) Kerana ia diwajibkan oleh undang-undang pekerjaan sahaja / Because it is required by employment law only

**A2.** Semasa pemeriksaan perkakasan, juruteknik mendapati salah satu kipas pelayan tidak berpusing. Apakah risiko utama jika keadaan ini dibiarkan? / During hardware inspection, a technician finds one server fan is not spinning. What is the main risk if this is left unaddressed?

- (a) Pelayan akan mencetak lebih banyak ralat dalam log / The server will print more errors in the log
- (b) Pelayan akan mengalami peningkatan suhu yang boleh menyebabkan gangguan atau kerosakan komponen / The server will experience rising temperatures that can cause system failure or component damage
- (c) Kelajuan capaian rangkaian akan meningkat / Network access speed will increase
- (d) Sistem pengendalian akan dikemas kini secara automatik / The operating system will update automatically

**A3.** Apakah tujuan penggantian pasta terma (thermal paste) pada pemproses (CPU) pelayan semasa penyelenggaraan? / What is the purpose of replacing thermal paste on a server processor (CPU) during maintenance?

- (a) Untuk meningkatkan kelajuan pemproses / To increase the processor speed
- (b) Untuk menambah kapasiti memori / To increase memory capacity
- (c) Untuk memastikan pemindahan haba yang cekap antara CPU dan pendingin bagi mengelakkan kepanasan berlebihan / To ensure efficient heat transfer between the CPU and heatsink to prevent overheating
- (d) Untuk membolehkan CPU berjalan tanpa bekalan kuasa / To allow the CPU to run without a power supply

**A4.** Dalam konteks penyelenggaraan perkakasan pelayan, apakah yang dimaksudkan dengan "redundant power supply" (bekalan kuasa berlebihan)? / In the context of server hardware maintenance, what is meant by "redundant power supply"?

- (a) Bekalan kuasa tambahan yang disimpan dalam stor / Extra power supply units kept in storage
- (b) Konfigurasi di mana dua atau lebih unit bekalan kuasa dipasang; jika satu gagal, yang lain mengambil alih tanpa gangguan perkhidmatan / A configuration where two or more PSUs are installed; if one fails, the other takes over without service interruption
- (c) Bekalan kuasa yang digunakan hanya semasa ujian / Power supply used only during testing
- (d) Bekalan kuasa yang disambungkan kepada penjana luar / Power supply connected to an external generator

**A5.** Apakah langkah PERTAMA yang perlu dilakukan sebelum membersihkan komponen dalaman pelayan menggunakan udara termampat (compressed air)? / What is the FIRST step to be taken before cleaning internal server components using compressed air?

- (a) Menyambungkan pelayan kepada UPS / Connecting the server to the UPS
- (b) Mematikan pelayan dengan prosedur yang betul dan memastikan kuasa diputuskan / Shutting down the server using the correct procedure and ensuring power is disconnected
- (c) Mengemas kini perisian pemacu (driver) / Updating the device drivers
- (d) Membuka semua panel dan menanggalkan semua kabel serentak / Opening all panels and removing all cables simultaneously

### Bahagian C: Soalan Situasi / Situational Question (20 markah / marks)

**C1.** Anda menjalankan penyelenggaraan perkakasan berjadual pada pelayan SRV-DB-02 (Dell PowerEdge R540) di bilik pelayan syarikat anda. Semasa pemeriksaan, anda menemui perkara berikut:

You are carrying out scheduled hardware maintenance on server SRV-DB-02 (Dell PowerEdge R540) in your company's server room. During the inspection, you find the following:

- Satu daripada empat kipas dalaman tidak berpusing / One of four internal fans is not spinning
- Suhu CPU 1 mencatat 82°C dalam log iDRAC (ambang kritikal: 85°C) / CPU 1 temperature reads 82°C in the iDRAC log (critical threshold: 85°C)
- Dua daripada lapan slot RAM menunjukkan amaran ralat satu-bit dalam log peristiwa / Two of eight RAM slots show single-bit error warnings in the event log
- Kandungan debu yang banyak pada penapis udara dan penyejuk / Heavy dust accumulation on the air filter and heatsink

**(i)** Berdasarkan dapatan di atas, susun temuan ini mengikut **keutamaan tindakan** (dari paling kritikal ke paling rendah) dan nyatakan justifikasi bagi setiap susunan yang anda berikan. / Based on the findings above, arrange these findings according to **priority of action** (from most critical to lowest) and state the justification for each ranking. *(8 markah)*

**(ii)** Huraikan langkah-langkah teknikal lengkap untuk menangani **dua (2) isu teratas** yang anda kenal pasti dalam bahagian (i). Sertakan langkah keselamatan, prosedur kerja, dan semakan selepas setiap tindakan. / Describe the complete technical steps to address the **top two (2) issues** you identified in part (i). Include safety steps, work procedure, and post-action verification for each. *(12 markah)*
