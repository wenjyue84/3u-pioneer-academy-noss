## Tugasan / Tasks

### Bahagian A: Soalan Pelbagai Pilihan / Multiple Choice (10 markah / marks)

**A1.** Apakah tujuan utama analisis perintah kerja penyelenggaraan pelayan dijalankan sebelum memulakan kerja? / What is the primary purpose of analysing a server maintenance job order before commencing work?

- (a) Menentukan kos pembaikan peralatan / To determine the cost of repairing equipment
- (b) Memastikan skop kerja, sumber yang diperlukan, dan had masa difahami sepenuhnya / To ensure the scope of work, required resources, and time constraints are fully understood
- (c) Menyemak rekod gaji juruteknik / To check the technician's salary records
- (d) Mendapatkan kebenaran untuk membeli perkakasan baru / To obtain authorisation to purchase new hardware

**A2.** Maklumat manakah yang MESTI terdapat dalam perintah kerja penyelenggaraan pelayan? / Which information MUST be present in a server maintenance job order?

- (a) Nombor perintah kerja, nama pelayan, dan skop kerja yang ditetapkan / Job order number, server name, and defined scope of work
- (b) Nama pembekal dan harga komponen / Supplier name and component prices
- (c) Rekod prestasi peribadi juruteknik / Technician's personal performance record
- (d) Jadual cuti tahunan jabatan IT / Annual leave schedule of the IT department

**A3.** Semasa menganalisis perintah kerja, juruteknik mendapati maklumat aset pelayan tidak sepadan dengan rekod inventori. Apakah tindakan yang paling sesuai? / During job order analysis, a technician finds that the server asset details do not match the inventory record. What is the most appropriate action?

- (a) Meneruskan kerja dan mengabaikan perbezaan tersebut / Proceed with the work and ignore the discrepancy
- (b) Membuat andaian berdasarkan pengalaman terdahulu / Make assumptions based on previous experience
- (c) Melaporkan ketidaksepadanan kepada penyelia dan mendapatkan pengesahan sebelum meneruskan / Report the discrepancy to the supervisor and obtain verification before proceeding
- (d) Menggantikan maklumat inventori dengan maklumat dalam perintah kerja / Replace the inventory information with the job order details

**A4.** Apakah yang dimaksudkan dengan "tetingkap penyelenggaraan" (maintenance window) dalam konteks penyelenggaraan pelayan? / What is meant by a "maintenance window" in the context of server maintenance?

- (a) Tetingkap fizikal di bilik pelayan / A physical window in the server room
- (b) Tempoh masa yang diperuntukkan untuk menjalankan penyelenggaraan tanpa mengganggu operasi perniagaan / A time period allocated to carry out maintenance without disrupting business operations
- (c) Perisian antara muka untuk memantau pelayan / A software interface for monitoring the server
- (d) Prosedur keselamatan untuk memasuki bilik pelayan / A security procedure for entering the server room

**A5.** Mengapa permintaan perubahan (change request / CR) diperlukan untuk sesetengah aktiviti penyelenggaraan pelayan? / Why is a change request (CR) required for certain server maintenance activities?

- (a) Untuk meningkatkan gaji juruteknik / To increase the technician's salary
- (b) Untuk memastikan perubahan yang boleh memberi impak kepada sistem diluluskan, didokumentasikan, dan boleh dipulihkan sekiranya berlaku masalah / To ensure changes that may impact systems are approved, documented, and reversible if issues arise
- (c) Untuk mendapatkan kebenaran membeli alatan baru / To obtain approval to purchase new tools
- (d) Kerana semua kerja penyelenggaraan memerlukan CR tanpa pengecualian / Because all maintenance work requires a CR without exception

### Bahagian C: Soalan Situasi / Situational Question (20 markah / marks)

**C1.** Anda ialah juruteknik IT di sebuah organisasi. Anda menerima perintah kerja penyelenggaraan pelayan dengan butiran berikut:

You are an IT technician at an organisation. You receive a server maintenance job order with the following details:

- **Nombor Perintah Kerja / Job Order No.:** JO-2026-0089
- **Pelayan / Server:** SRV-FILE-01 (Dell PowerEdge R740, S/N: DL74X0012)
- **Lokasi / Location:** Bilik Pelayan / Server Room — Aras 2
- **Masalah dilaporkan / Reported issue:** Bunyi bising luar biasa dari kipas; amaran suhu dalam log sistem; kelajuan tindak balas perkongsian fail merosot 40%
- **Kategori / Category:** Penyelenggaraan Perkakasan dan OS / Hardware and OS Maintenance
- **Tetingkap penyelenggaraan / Maintenance window:** Sabtu, 28 Jun 2026, 11:00 PM – 3:00 AM
- **Keutamaan / Priority:** Tinggi / High
- **Kelulusan CR / CR Approval:** Diperlukan / Required (CR belum diraih / CR not yet raised)

**(i)** Berdasarkan perintah kerja di atas, huraikan langkah-langkah lengkap yang anda akan ambil untuk menganalisis perintah kerja ini sebelum memulakan sebarang kerja. Sertakan semakan inventori, klasifikasi tugas, penilaian risiko, dan keperluan CR. / Based on the job order above, describe the complete steps you would take to analyse this job order before commencing any work. Include inventory verification, task classification, risk assessment, and CR requirements. *(12 markah)*

**(ii)** Rekabentuk satu **rancangan kerja penyelenggaraan** (maintenance work plan) ringkas untuk perintah kerja ini. Rancangan tersebut hendaklah mengandungi sekurang-kurangnya ENAM (6) tugas yang disusun mengikut turutan pelaksanaan yang logik, lengkap dengan anggaran masa bagi setiap tugas. / Design a brief **maintenance work plan** for this job order. The plan must contain at least SIX (6) tasks arranged in logical execution order, with a time estimate for each task. *(8 markah)*
