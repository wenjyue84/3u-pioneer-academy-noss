## Arahan kepada Pelatih / Instructions to Trainee

1. This is a PRACTICAL examination. You will be assessed on your ability to perform a complete server maintenance cycle.
2. You will be given a maintenance job order, a server (or simulated server environment), and the necessary tools and materials.
3. You will be assessed on: **Process** (how you perform the work), **Output** (the result achieved), **Attitude** (professionalism and independence), **Safety** (ESD and electrical safety), and **Environmental** compliance (workspace cleanliness and waste disposal).
4. You must wear an anti-static wrist strap throughout all hardware maintenance phases.
5. All work must be documented on the provided server maintenance record form.
6. Do not proceed to the next task until the current task is completed and noted.

---

## Arahan kepada Penilai / Instructions to Assessor

- Provide each trainee with a server (or simulated equivalent), maintenance tools, and a printed maintenance job order.
- Observe each trainee continuously during the assessment.
- Do NOT assist the trainee unless there is an immediate safety hazard.
- Mark each criterion on the assessment rubric as the trainee performs the work.
- Verify the final output (server operational, maintenance record complete) at the end.
- Two assessors are recommended for groups of more than 8 trainees.

---

## Tugasan / Task Description

**Scenario:** You are a Level 3 Server Maintenance Technician. You have received the following maintenance job order:

| Field | Details |
|-------|---------|
| Job Order Number | PA-C05-2026-001 |
| Server Asset Tag | SVR-LAB-001 |
| Server Model | Tower/Rack Server (lab unit) |
| OS | Windows Server 2019 / 2022 |
| RAID Configuration | RAID 1 (2 × HDD/SSD) |
| Requested by | IT Department |
| Priority | Scheduled Preventive Maintenance |
| Scope of Work | Full hardware PM + OS patch + filesystem check + maintenance record |
| Maintenance Window | As allocated by instructor |
| Authorised by | Instructor (simulating IT Manager) |

**You must complete the following tasks in order:**

1. Analyse the job order and prepare a maintenance checklist *(15 minutes)*
2. Perform hardware maintenance — clean, inspect, and verify all hardware components *(60 minutes)*
3. Perform server OS maintenance — patching, event log review, filesystem check, service verification *(45 minutes)*
4. Complete the server maintenance record and present findings *(15 minutes)*

**Total time allowed: 2 hours 15 minutes**
