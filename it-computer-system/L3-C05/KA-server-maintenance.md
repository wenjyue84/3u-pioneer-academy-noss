## BAHAGIAN A: SOALAN PELBAGAI PILIHAN / SECTION A: MULTIPLE CHOICE (30 marks)

Answer all 15 questions. Each question carries 2 marks. Circle the correct answer.

**1.** The document that formally authorises a server maintenance task is called a:

- (a) Purchase requisition
- (b) Maintenance job order / work order
- (c) Asset disposal form
- (d) Network topology diagram

**2.** Which of the following information is typically found in a server maintenance job order?

- (a) User login credentials only
- (b) Server asset tag, scheduled maintenance date, scope of work, and authorisation signature
- (c) Software licensing keys only
- (d) Network switch port assignments

**3.** Before opening a server chassis for hardware maintenance, the FIRST action a technician must take is:

- (a) Download the latest firmware
- (b) Power off the server and disconnect all power cables
- (c) Back up server logs only
- (d) Notify the helpdesk

**4.** Electrostatic discharge (ESD) can be prevented by:

- (a) Working on a carpeted floor
- (b) Wearing an anti-static wrist strap connected to the server chassis ground
- (c) Blowing compressed air without grounding
- (d) Handling RAM by its gold contacts

**5.** Server RAM modules are typically what type of memory?

- (a) Unbuffered DDR4 DIMM
- (b) ECC (Error-Correcting Code) Registered DIMM (RDIMM)
- (c) SO-DIMM
- (d) Flash memory

**6.** A server's RAID controller cache battery (or capacitor) must be checked during hardware maintenance because:

- (a) It increases server processing speed
- (b) It protects uncommitted write-cache data during a power failure
- (c) It controls fan speed
- (d) It manages the OS boot process

**7.** Compressed air is used during server hardware maintenance to:

- (a) Cool down overheating CPUs during operation
- (b) Remove accumulated dust from heatsinks, fans, and air baffles
- (c) Inflate server rack cable management arms
- (d) Clean the server's power supply internal PCB during operation

**8.** Which of the following is the correct sequence for replacing a server hard disk drive in a RAID 5 array?

- (a) Remove all disks simultaneously, replace, then rebuild
- (b) Identify the failed disk, replace the hot-swap disk, allow RAID to rebuild automatically
- (c) Power down the server, remove all disks, replace, power on
- (d) Replace the disk and immediately format it

**9.** Server OS patch management involves:

- (a) Replacing physical hard disks on a schedule
- (b) Applying security updates, hotfixes, and service packs to keep the OS protected and stable
- (c) Upgrading server RAM
- (d) Recabling the server rack

**10.** The purpose of running `chkdsk` (Windows) or `fsck` (Linux) on a server volume is to:

- (a) Defragment the disk for faster read speeds
- (b) Check and repair filesystem errors and bad sectors
- (c) Update device drivers
- (d) Flush the DNS cache

**11.** Windows Server event logs are categorised into which three primary categories?

- (a) Debug, Warning, Fatal
- (b) Application, Security, System
- (c) Hardware, Software, Network
- (d) Critical, Major, Minor

**12.** A server's uptime can be verified using which command in Windows Server?

- (a) `ipconfig /all`
- (b) `systeminfo` (check "System Boot Time")
- (c) `netstat -an`
- (d) `sfc /scannow`

**13.** Which of the following should be recorded in a server maintenance record after completing maintenance?

- (a) Technician's personal expenses
- (b) Work performed, components replaced, test results, and technician signature
- (c) User email addresses
- (d) Software license prices

**14.** A server UPS (Uninterruptible Power Supply) should be tested during maintenance to ensure:

- (a) It can power the server indefinitely
- (b) It provides adequate runtime during a power failure and that alerts function correctly
- (c) It replaces the server's internal power supply
- (d) It connects directly to the RAID controller

**15.** After performing server OS maintenance, the technician should:

- (a) Power off the server immediately
- (b) Verify all services are running, check event logs for errors, and update the maintenance record
- (c) Reformat the server OS drive
- (d) Replace the server NIC

## BAHAGIAN B: SOALAN JAWAPAN PENDEK / SECTION B: SHORT ANSWER (30 marks)

Answer all 6 questions.

**16.** List FIVE (5) fields that must be included in a server maintenance job order. *(5 marks)*

**17.** State FOUR (4) hardware components that are typically inspected and cleaned during a server preventive maintenance (PM) session, and describe what is checked for each. *(8 marks)*

**18.** Describe the steps to safely replace a failed hard disk drive in a server running RAID 1. Include the steps taken before, during, and after the replacement. *(6 marks)*

**19.** List FOUR (4) common server OS maintenance tasks and state the purpose of each. *(4 marks)*

**20.** State THREE (3) items that must be recorded in a server maintenance record after completing a maintenance task. *(3 marks)*

**21.** Explain what "hot-swap" means in the context of server hardware maintenance and state TWO (2) components that typically support hot-swap capability. *(4 marks)*

## BAHAGIAN C: SOALAN ESEI / SECTION C: ESSAY (40 marks)

Answer all 2 questions.

**22.** You receive a server maintenance job order for a production file server with the following details:
- Server model: Dell PowerEdge R750
- OS: Windows Server 2022
- RAID: RAID 5 (6 × 3.6 TB SAS drives)
- Scheduled maintenance window: Saturday 00:00–04:00
- Reported issues: (i) RAID controller event log shows one disk "predictive failure"; (ii) Event Viewer shows repeated disk I/O errors; (iii) CPU temperature warnings in iDRAC
- Last maintenance: 8 months ago

(a) Describe how you would analyse the job order before the maintenance window begins, including what checks you would perform remotely and what materials you would prepare. *(8 marks)*

(b) During the maintenance window, describe the step-by-step procedure you would follow to: (i) replace the predictive-failure disk safely, (ii) clean the server hardware, and (iii) resolve the CPU temperature warning. *(12 marks)*

**23.** After completing the hardware maintenance on the server in Question 22, you proceed with OS maintenance.

(a) Describe the server OS maintenance procedure you would follow, covering: patch management, event log review, filesystem check, and service verification. *(10 marks)*

(b) Prepare a structured outline of the server maintenance record you would complete, listing all sections and the information that belongs in each section. *(5 marks)*

(c) State FIVE (5) actions you would take to verify that the server is fully operational before closing the maintenance job order. *(5 marks)*
