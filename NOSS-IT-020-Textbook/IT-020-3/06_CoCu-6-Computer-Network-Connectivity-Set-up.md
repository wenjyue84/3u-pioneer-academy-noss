| Type of Cable | Description |
|---------------|-------------|
| UTP (Cat5e / Cat6 / Cat6a) | Unshielded twisted pair used for Ethernet. Cat5e supports up to 1 Gbps; Cat6 and Cat6a support higher speeds and longer runs. Straight-through is used for PC to switch; crossover for like-to-like (many modern devices auto-detect). Crimping and tester are used to verify wiring. |
| Fibre | Used for long runs or high speed. Single-mode or multi-mode; connector type (e.g. LC, SC) must match the switch and transceiver. Handle with care; avoid bending beyond minimum radius. |
| Cable tester / LAN tester | Used to verify that each wire is correctly terminated and that the cable can carry signal. Essential when laying or repairing network cables. |

| Key Term | Description |
|----------|-------------|
| Configuration specification | IP scheme (static or DHCP), subnet mask, gateway, DNS; VLAN if used; cable type and length; switch port assignment. Confirm with requester before implementation. |
| Connectivity test | ping to gateway and DNS; traceroute to external host; check link status and speed on NIC and switch. Document results for the connectivity report. |
| Troubleshoot | Check cable, NIC, driver, IP config, switch port, and firewall. Use ipconfig, ping, and event log. Document steps and outcome. |
| Network connectivity report | Document specification, configuration applied, test results, and any faults or recommendations. Used for handover and asset or change records. |
