## 二、学习成果 (Learning Outcomes)

本能力单位旨在透过肌肉骨骼推拿针对常见关节及软组织问题（颈椎病、肩周炎、腰椎间盘突出症、网球肘、膝关节痛等）进行辅助性处理，疏通经气、缓解疼痛、恢复功能。完成本能力单位后，学员应能在推拿服务中心按议定的安全程序为肌骨问题客户提供完整的肌肉骨骼推拿服务，具体包括：

1. 准备肌肉骨骼推拿服务所需要求 (Prepare requirements for musculoskeletal Tuina service)
2. 执行肌肉骨骼推拿服务 (Perform musculoskeletal Tuina service)
3. 管理客户肌肉骨骼推拿服务后的状况 (Manage client's post musculoskeletal Tuina service condition)

## 四、各工作活动详细课程

### WA1：准备肌肉骨骼推拿服务需求 (40 小时)

**相关知识 (RK)：**
1. 肌骨推拿客户常见主诉特征：局部僵痛、关节活动受限、放射痛、晨僵
2. 肌骨推拿服务时长：全身辅助 60 分钟；单关节专项 20–40 分钟
3. 肌骨推拿可能反应：局部酸胀、轻度瘀青、短暂加重、疲倦、排病反应
4. 中西医结合肌骨解剖：骨、关节、肌腱、韧带、筋膜、滑囊；TCM 筋骨皮肉脉
5. 评估方法：望诊（姿势/步态）、触诊（肌张力/压痛点）、活动度 ROM 测试、特殊试验
6. 常用穴位与经络：膀胱经、胆经、督脉、阿是穴、华佗夹脊
7. 红旗征识别：夜间痛、体重骤降、外伤史、麻木无力
8. 客户贵重物品保管政策

**相关技能 (RS)：**
- i. 复核客户记录是否对应当前客户
- ii. 确认肌肉骨骼推拿服务方案已获客户同意
- iii. 确认客户偏好的压力强度
- iv. 确认客户偏好的服务时长
- v. 告知客户肌肉骨骼推拿可能反应
- vi. 准备相关介质与辅助器材（热敷袋、滚筒、推拿油等）
- vii. 检查正确、安全、舒适的客户体位（俯卧/仰卧/侧卧）
- viii. 告知客户中止服务的权利
- ix. 安全保管客户贵重物品

**态度 (Attitude)：**
- i. 在复核客户记录与方案时表现专业且圆融
- ii. 清晰简明地向客户解释信息
- iii. 尊重客户反馈与疼痛耐受度
- iv. 诚实处理客户财物

**安全 (Safety)：** 遵守 MOH T&CM 规范；OSHA 1994；PDPA 2010；红旗征立即转诊

**评估准则：**
- i. 解释并演示客户记录与肌骨推拿方案复核
- ii. 列出并解释客户偏好的压力强度与服务时长确认
- iii. 列出并解释肌骨推拿可能反应
- iv. 列出、解释并演示介质与辅助器材准备
- v. 解释并演示客户安全与舒适监控
- vi. 解释客户中止服务权利的告知
- vii. 解释客户贵重物品保管与归还政策

**Delivery Mode：** 讲授 / 小组讨论 / 视频 + 演示 / 观察 / 角色扮演 / OJT

### WA2：执行肌肉骨骼推拿服务（核心，280 小时）

**相关知识 (RK)：**
1. 肌骨推拿常用手法：㨰法、揉法、按法、拨法、弹拨、扳法（限低风险关节）、牵抖法、擦法
2. 力度、速度、节奏、深度的调控（按组织层次：皮→筋膜→肌→腱→关节囊）
3. 分部位专项手法：颈部理筋、肩部松解、腰部理筋、肘部弹拨、膝部理筋
4. 常见肌骨疾患的推拿处理：颈椎病（落枕/神经根型/椎动脉型辨证）、肩周炎（粘连期/解冻期）、腰椎间盘突出症（非急性期）、腰肌劳损、网球肘（肱骨外上髁炎）、膝关节痛（髌骨软化/退行性）
5. 经络循行与肌骨专属配穴：颈—风池/天柱；肩—肩井/肩髃/肩髎；腰—肾俞/大肠俞/委中；肘—曲池/手三里/少海；膝—犊鼻/阳陵泉/足三里
6. 服务过程中持续观察客户反应（VAS、ROM 变化、麻木放射征、面色、肌张力）
7. 可能反应识别（酸胀 vs 病理性剧痛）
8. 紧急情况识别与处置：椎动脉供血不足、晕针样反应、肌肉痉挛、骨折未愈外伤史
9. 工作区、用品与介质的感染控制 (Infection Control)

**相关技能 (RS)：**
- i. 持续观察肌肉骨骼推拿客户的反应与生理变化
- ii. 持续获取客户的反馈
- iii. 执行工作区、材料与介质的感染控制
- iv. 维护客户隐私
- v. 演示并应用肌肉骨骼推拿八种主要手法
- vi. 控制力度、速度、节奏、深度
- vii. 按部位（颈/肩/腰/肘/膝）正确施术
- viii. 识别并处置紧急情况

**态度 (Attitude)：** 专业博学；留意客户反应；尊重隐私；遵守 MOH T&CM 实务伦理

**安全 (Safety)：** 严格避开禁忌区域（颈动脉窦、腋窝臂丛、腘窝、腹股沟）；急性炎症、骨折未愈、骨质疏松、肿瘤、感染 — 绝对禁忌；腰椎扳法初级推拿师不得自行执行；推拿师身体力学

**评估准则：**
- i. 列出并解释力度、速度、节奏、深度调控
- ii. 演示颈/肩/腰/肘/膝五部位手法之差异
- iii. 解释客户反应观察
- iv. 解释并演示工作区/介质/材料的感染控制
- v. 解释并演示客户隐私维护

**Delivery Mode：** 讲授 / 视频 / 演示 / 观察 / 角色扮演 / 模拟客户 / OJT

### WA3：管理客户服务后状况 (80 小时)

**相关知识 (RK)：**
1. 功能性评估：ROM 复测、VAS 复评、特殊试验阴转、日常活动改善度
2. 离场政策：需求评估、离场后处理、离场计划、教育准备、功能性结果检查
3. 转介政策：红旗征、骨科/影像学指征、症状风险、客户请求、紧急情况、能力限制、第三方请求
4. 康复指导：居家拉伸、功能训练、姿势教育、人体工学建议
5. MOH 规范的记录管理：手写 / 电脑化、个人资料、咨询治疗信息、同意书、保密性、安全性

**相关技能 (RS)：**
- i. 获取客户服务后反馈
- ii. 比较服务后与服务前的客户状况（ROM、VAS、功能）
- iii. 评估持续性肌骨推拿方案的有效性
- iv. 提议方案调整
- v. 取得客户同意
- vi. 完成或终止肌骨推拿方案的离场处理
- vii. 给予居家功能训练与姿势建议
- viii. 检查转介政策
- ix. 转介符合条件的客户（骨科/影像学/神内）
- x. 即时记录服务后活动更新

**态度 (Attitude)：** 清晰沟通；尊重反馈；专业转介；细致系统化记录

**安全 (Safety)：** 严守 PDPA 2010；记录保密保存 7 年；红旗征零延误转诊

**评估准则：**
- i. 解释并演示肌骨推拿方案有效性监测（ROM/VAS/功能三指标）
- ii. 解释并演示方案调整
- iii. 列出并解释居家康复与姿势建议
- iv. 解释完成 / 终止方案时的离场流程
- v. 演示按 SOP 转介至骨科、影像或其他 TCM 从业人员
- vi. 解释并演示服务后活动的即时记录

**Delivery Mode：** 讲授 / 小组讨论 / 视频 + 演示 / 观察 / 角色扮演 / OJT
