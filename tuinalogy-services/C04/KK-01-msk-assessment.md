# 工作单 1：肌骨评估（视诊、触诊、活动度测试）


## 任务总览
学员在可调式推拿床、模拟客户设定下，独立完成从接待、记录复核、望诊、触诊、ROM 测试、特殊试验到方案同意书签署的全流程，并准确书写评估记录。

## 必备工具
- 可调式推拿床、椅子 / 低凳
- 量角器 (Goniometer)
- VAS 量表
- 客户档案表（肌骨专用）、同意书
- 经络挂图、骨骼模型（参考用）
- 消毒用品
- 计时器、笔、档案夹

---

## 步骤 1：接待与记录复核（10 分钟）

1. 问候客户，自我介绍推拿师姓名与资历
2. 请客户入座，核对姓名、NRIC / 识别号
3. 复核客户档案：既往病史、过敏史、上次服务记录
4. 询问今日主诉："今天想处理哪里？具体症状是什么？"
5. 记录新主诉（日期、部位、性质、持续时间、加重/缓解因素）

**要点：** 专业圆融；避免让客户重复填写已有信息。

---

## 步骤 2：望诊 / Observation（10 分钟）

### 静态望诊
1. 客户自然站立，观察：
   - 双肩高度是否对称
   - 骨盆高度、旋转
   - 脊柱是否侧弯、前凸、后凸
   - 头颈位置（前倾/侧倾）
   - 膝关节内翻/外翻
   - 足弓高度

### 动态望诊
1. 请客户原地行走 5–8 步，观察步态
2. 请客户做目标部位主动动作（如颈部旋转、肩部上举、弯腰）
3. 记录：疼痛弧、避痛姿势、代偿动作

**要点：** 望诊全程不触碰客户；记录"左右不对称"、"活动受限"等观察。

---

## 步骤 3：触诊 / Palpation（15 分钟）

1. 解释"我将触摸你的（部位），有任何疼痛请告诉我"
2. 客户俯卧或坐位，暴露目标区域（尊重隐私，以毛巾覆盖非检查区）
3. 触诊内容（分层）：
   - **皮温：** 手背轻触 — 热（炎症）/ 凉（循环差）
   - **皮肤张力：** 弹性、湿度
   - **筋膜：** 浅层滑动性
   - **肌肉：** 静息张力（正常/高张/低张）、结节、条索
   - **肌腱：** 附着点压痛（网球肘查肱骨外上髁）
   - **关节：** 肿胀、骨性标志（髌骨、肱骨大结节、棘突）
   - **穴位：** 阿是穴、反应点
4. 记录压痛点（mark 在图表）及 VAS 数值

---

## 步骤 4：活动度 ROM 测试（15 分钟）

使用量角器按下表测量，记录主动 (AROM) 与被动 (PROM)：

| 关节 | 动作 | 正常参考 | 测量方法 |
|------|------|----------|----------|
| 颈 | 屈 / 伸 | 45° / 45° | 客户坐位，量角器置耳垂 |
| 颈 | 侧屈 / 旋转 | 45° / 60° | 量角器置头顶中线 |
| 肩 | 屈 / 外展 | 180° / 180° | 量角器置肩峰 |
| 肩 | 内旋 / 外旋 | 70° / 90° | 肘 90° 屈曲位 |
| 腰 | 屈 / 伸 | 60° / 25° | 可用测量带替代 |
| 腰 | 侧屈 / 旋转 | 25° / 30° | |
| 肘 | 屈 / 伸 | 145° / 0° | 量角器置肘外侧 |
| 膝 | 屈 / 伸 | 135° / 0° | 量角器置膝外侧 |
| 踝 | 背屈 / 跖屈 | 20° / 50° | |

**关键：** 疼痛或抵抗时立即停止；记录"XX° 时疼痛出现"。

---

## 步骤 5：特殊试验 / Special Tests（15 分钟）

按主诉选择相关试验：

| 部位 | 试验 | 阳性含义 |
|------|------|----------|
| 颈 | Spurling's Test | 神经根受压 |
| 肩 | Neer's / Hawkins-Kennedy | 肩峰撞击 |
| 肩 | Drop Arm Test | 肩袖撕裂 |
| 肩 | Apley Scratch | 综合 ROM |
| 肘 | Cozen's / Mill's | 网球肘 |
| 腕 | Phalen's / Tinel's | 腕管综合征 |
| 腰 | Lasegue (SLR) | 坐骨神经根受压 |
| 腰 | Femoral Stretch | L2–L4 受累 |
| 膝 | McMurray | 半月板损伤 |
| 膝 | Valgus/Varus Stress | 侧副韧带损伤 |

**要点：** 动作轻柔、告知客户目的；一旦出现剧痛、麻木立即停止并记录。

---

## 步骤 6：方案同意与体位准备（10 分钟）

1. 综合评估结果，解释推拿建议：
   - "今天建议做 XX 方案，主要处理 XX，时长约 XX 分钟"
2. 告知可能反应：酸胀、轻度瘀青、疲倦
3. 告知中止权利："任何时候不舒服请告诉我，我们立即停止"
4. 告知贵重物品保管政策
5. 客户签署同意书
6. 安排合适体位（俯卧/仰卧/侧卧），铺巾，必要时暖和垫
7. 再次询问"现在这个姿势舒服吗？"

---

## 步骤 7：评估记录书写（15 分钟）

完整填写客户档案，含：
- 主诉 + 病史摘要
- 望诊发现
- 触诊发现（压痛点标图）
- ROM 数值表
- 特殊试验阳/阴性
- 初步判断（如"颈型颈椎病，无红旗征"）
- 今日方案 + 客户同意
- 推拿师签名、客户签名、日期时间
