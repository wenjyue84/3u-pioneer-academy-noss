# 资料单 3：服务后康复管理与功能评估


## 学习目标

1. 执行标准化的服务后功能性评估（ROM / VAS / 日常活动）
2. 设计适合客户的居家康复与姿势教育方案
3. 辨识需要转诊的红旗征并依 SOP 执行转介
4. 按 MOH 与 PDPA 规范完成服务后记录

---

## 1. 服务后功能性评估 / Post-Service Functional Assessment

### 1.1 三指标评估框架

| 指标 | 工具 | 评估方法 |
|------|------|----------|
| **ROM 活动度** | 量角器 Goniometer | 主动 ROM + 被动 ROM；与服务前对照 |
| **VAS 疼痛** | 0–10 视觉模拟量表 | 客户自评；含休息痛、活动痛 |
| **功能性动作** | 日常活动清单 | 穿衣、提物、上下楼、转颈、弯腰等 |

### 1.2 各部位重点复测项目

| 部位 | ROM 关键动作 | 功能性动作 |
|------|--------------|------------|
| 颈部 | 屈/伸/侧屈/旋转 | 转头看后视镜 |
| 肩部 | 屈/外展/内外旋 | 梳头、穿衣、背后系扣 |
| 腰部 | 屈/伸/侧屈/旋转 | 弯腰系鞋带、从椅子起立 |
| 肘部 | 屈/伸/旋前旋后 | 拧毛巾、端碗 |
| 膝部 | 屈/伸 | 上下楼梯、下蹲 |

### 1.3 评估记录要点
- 每次服务结束时复测，记录具体数值（例如"颈左旋 30° → 45°"、"VAS 7 → 4"）
- 客户自述的主观改善（如"晚上睡觉翻身不痛了"）同等重要
- 方案有效性以 3–6 次服务为一疗程周期评估

## 2. 居家康复与姿势教育 / Home Rehabilitation & Posture Education

### 2.1 通用原则
- 推拿非"一劳永逸"；居家配合动作才能维持疗效
- 教育客户识别"好酸" vs "坏痛"
- 循序渐进；每日 10–15 分钟，持之以恒

### 2.2 分部位居家动作示例

**颈部：**
- 颈部等长收缩（抵抗自己的手）
- 肩胛后缩挺胸
- 颈深屈肌训练（下颌后收 Chin Tuck）
- 避免低头看手机过久（20-20-20 法则）

**肩部：**
- 钟摆运动（弯腰放松悬臂摆动）
- 爬墙运动（逐日加高）
- 毛巾牵拉（肩内旋/外旋伸展）
- 避免提重物、反手抓取

**腰部：**
- 猫牛式 (Cat-Cow)
- 臀桥
- 死虫子 Dead Bug（核心稳定）
- 正确提物姿势（屈膝蹲下，腰背直）
- 避免久坐；每 45 分钟起立活动

**肘部：**
- 伸腕肌拉伸（肘直、腕屈，另手下压 15 秒 × 3）
- 握力球练习（疼痛缓解后）
- 避免反复拧重物

**膝部：**
- 直腿抬高（股四头肌强化）
- 靠墙静蹲（股四头肌等长）
- 腘绳肌拉伸
- 避免深蹲、跪坐、上下楼梯太频繁

### 2.3 姿势教育与人体工学
- 办公桌高度：屏幕上缘与眼平齐；肘 90°
- 枕头：颈椎生理曲度支撑（不宜过高）
- 床垫：中等硬度，支撑腰骶
- 开车：座椅靠背 100–110°；腰部加小垫

## 3. 转诊 SOP 与红旗征 / Referral SOP & Red Flags

### 3.1 绝对转诊（立即停止推拿，安排转介）

| 红旗征 | 可能提示 |
|--------|----------|
| 夜间痛、静息痛剧烈 | 肿瘤、感染 |
| 无外伤骨折史（骨质疏松者跌倒后）| 压缩性骨折 |
| 会阴麻木、大小便失禁 | 马尾综合征 |
| 进行性肌力下降、步态异常 | 脊髓压迫 |
| 不明原因体重下降 + 腰背痛 | 肿瘤转移 |
| 发热 + 脊柱痛 | 脊柱感染 |
| 突发剧烈头痛 + 颈部操作后 | 椎动脉夹层 |
| 胸痛放射至肩臂（不随活动变化）| 心源性 |

### 3.2 相对转诊（数周无改善时建议就医）
- 保守推拿 6 次以上无改善
- 客户要求影像学检查
- 超出 Level 3 推拿师能力范围
- 合并系统性疾病（糖尿病、风湿）需内科管理

### 3.3 转诊流程
1. 当面向客户解释转诊理由（不恐吓、不诊断）
2. 书面转介信：客户姓名、症状摘要、体征发现、推拿处理经过、转介建议
3. 建议转介对象：骨科专科、康复医师、神经内科、或注册中医师
4. 客户档案注明转介日期与对象
5. 必要时 1–2 周后电话关心客户就医情况

## 4. 服务后记录管理 / Post-Service Documentation

### 4.1 每次服务记录要素

| 要素 | 示例 |
|------|------|
| 日期时间 | 2026-04-17 14:00–15:00 |
| 客户主诉 | "右肩抬手疼，今天 VAS 5" |
| 评估发现 | 右肩前屈 120°，外展 90°，肩髃压痛 |
| 施术内容 | 㨰法肩周 8 分钟；点按肩井/肩髃/肩髎；扳法外展被动到 110° |
| 服务后评估 | 前屈 130°，VAS 3；客户反馈轻松 |
| 居家指导 | 钟摆运动 3×/日；毛巾牵拉 |
| 下次预约 | 3 天后 |
| 推拿师签名 | ___ |
| 客户签名 | ___ |

### 4.2 记录规范（依 MOH 与 PDPA）
- 手写或电脑化档案；纸本安全存档柜（上锁）
- 档案保存 **7 年**
- 未成年人档案保存至 **21 岁 + 7 年**
- 不得随意复制、转发；电子档案加密
- 客户有权查阅自己的档案
- 推拿师离职时档案归档案中心，不得带走

### 4.3 方案调整决策
- **有效（疗程有改善）：** 继续现方案；或减频次（巩固）
- **部分有效：** 调整手法重点；加强居家配合
- **无效 / 恶化：** 停止方案 → 重新评估或转诊
- **客户退出：** 询问原因；填写离场表；档案保留

---

## 5. 小结

服务后管理不是推拿结束后的"附赠"，而是疗效得以持续与客户安全得以保障的关键环节。每一次服务结束，推拿师都应完成"三件事"：**复测功能**、**交代居家**、**即时记录**。当红旗征出现，宁可"过度保守"转诊，也不可因 Level 3 权责外的处理而损害客户。
