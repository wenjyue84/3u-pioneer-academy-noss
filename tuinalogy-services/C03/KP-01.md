## 第一节　运动推拿概论 / Introduction to Sport Tuina

### 1.1 定义

**运动推拿 (Sport Tuina, 运动推拿)** 是 TCM 推拿系统中专门服务于运动员、运动爱好者及因运动产生肌肉/关节问题客户的疗法分支。其核心目标为：**疏通经络、调和气血、缓解运动疲劳、预防与处理运动相关肌肉骨骼问题、提升运动表现与恢复速度**。

### 1.2 运动推拿 vs 一般保健推拿

| 项目 | 一般保健推拿 | 运动推拿 |
|------|--------------|----------|
| 目的 | 放松、舒压、调理 | 提升表现、缓解运动疲劳、处理运动伤 |
| 时机 | 任何时间 | 紧扣赛季/训练周期 |
| 评估重点 | 整体亚健康 | 训练史、伤痛史、运动负荷、肌群代偿 |
| 手法侧重 | 八大手法均衡 | 推、揉、拿、抓提为主；针对性深压 |
| 时长 | 60–90 分钟 | 局部 30–45 分钟 / 全身 60 分钟以上 |
| 禁忌警觉 | 一般禁忌 | + 急性扭伤 24h 内、未愈合骨折、肌腱断裂 |

### 1.3 三种运动情境推拿 / Three Sport Contexts

| 情境 | 时机 | 目的 | 手法特征 |
|------|------|------|----------|
| **赛前热身式** (Pre-event) | 比赛/训练前 15–30 分钟 | 提升肌肉温度、活化经络、心理唤醒 | 快速、浅层、节奏感强；推法 + 拍法 + 摩法 |
| **赛后放松式** (Post-event) | 比赛/训练后 30 分钟内 | 排除乳酸、缓解 DOMS、恢复气血 | 缓慢、深层、舒缓；揉法 + 拿法 + 按法 |
| **慢性运动伤治疗式** (Maintenance/Therapeutic) | 训练周期间或恢复期 | 处理慢性肌腱炎、僵硬、瘢痕组织 | 局部深压、点按穴位、持续 5–10 分钟 |

## 第二节　常见运动项目与损伤模式 / Common Sports & Injuries

### 2.1 常见运动项目

| 项目 | 主要受力部位 | 常见伤害 |
|------|--------------|----------|
| 跑步 (Running) | 下肢、髋、踝 | 髂胫束综合征、足底筋膜炎、跟腱炎、胫骨内侧应力综合征 |
| 篮球 (Basketball) | 膝、踝、肩 | 踝关节扭伤、跳跃膝 (髌腱炎)、肩袖损伤 |
| 举重 (Weightlifting) | 腰、肩、膝 | 腰背拉伤、椎间盘问题、肩袖撕裂 |
| 武术 (Martial Arts) | 全身、关节 | 关节扭伤、肌肉拉伤、瘀伤 |
| 瑜伽 (Yoga) | 颈、腰、髋 | 过度拉伸、腰椎不稳、颈部劳损 |
| 自行车 (Cycling) | 颈、腰、膝 | 颈源性头痛、腰肌劳损、髌股综合征 |
| 游泳 (Swimming) | 肩、颈、腰 | 游泳肩 (Swimmer's Shoulder)、颈部僵硬 |

### 2.2 常见运动损伤分类

| 中文 | English | 病机 (TCM) | 常见表现 |
|------|---------|-------------|----------|
| 延迟性肌肉酸痛 | DOMS (Delayed Onset Muscle Soreness) | 气滞血瘀于肌腠 | 训练后 24–72h 出现酸胀、僵硬 |
| 肌肉拉伤 | Muscle strain | 气血瘀阻、筋脉受损 | 局部疼痛、肿胀、活动受限 |
| 肌腱炎 | Tendinitis | 筋脉劳损、湿热痹阻 | 慢性局部疼痛、动则加剧 |
| 关节扭伤 | Joint sprain | 经筋离位、气血壅滞 | 急性肿胀、活动痛、淤青 |
| 韧带拉伤 | Ligament strain | 筋脉拉伤 | 关节松动感、定位疼痛 |
| 抽筋 | Muscle cramp | 气血不足或寒邪侵袭 | 突发性肌肉强直收缩 |
| 髂胫束综合征 | ITBS | 筋膜痹阻 | 膝外侧疼痛 |
| 足底筋膜炎 | Plantar fasciitis | 肾虚、寒湿留经 | 晨起足跟刺痛 |

### 2.3 损伤分期与推拿适用性

| 分期 | 时间 | 推拿适用性 |
|------|------|-------------|
| 急性期 | 0–48 小时 | **患处禁推**；可推远端经络疏导，配合 RICE 原则 |
| 亚急性期 | 48h–2 周 | 谨慎轻揉患处周围；活血化瘀 |
| 慢性期 / 恢复期 | 2 周以上 | 深层手法处理瘢痕、粘连；配合关节松动 |

## 第三节　TCM 解剖与经络在运动推拿的应用

### 3.1 重点经络

| 经络 | 走向 | 运动推拿应用 |
|------|------|----------------|
| 足太阳膀胱经 | 头 → 背 → 腿后 → 足 | 背部痛、腘绳肌僵硬、坐骨神经痛 |
| 足少阳胆经 | 头侧 → 体侧 → 腿外 → 足 | 髂胫束综合征、肩颈 |
| 足阳明胃经 | 面 → 胸腹 → 腿前 → 足 | 股四头肌、跳跃膝、胫骨痛 |
| 足太阴脾经 | 足 → 腿内 → 胸 | 内收肌、生殖泌尿 |
| 手太阳小肠经 | 手 → 肩 → 颈 | 肩胛、颈侧 |
| 手少阳三焦经 | 手 → 肩 → 头 | 肩外侧、网球肘 |
| 任脉 / 督脉 | 身前/后正中线 | 全身气血总枢 |

### 3.2 运动推拿常用穴位

| 穴位 | 位置 | 主治 |
|------|------|------|
| 委中 (BL40) | 腘窝中央 | 腰背痛、坐骨神经痛 |
| 承山 (BL57) | 小腿后正中 | 腓肠肌抽筋、跟腱炎 |
| 阳陵泉 (GB34) | 膝下外侧 | 膝痛、筋会穴 |
| 足三里 (ST36) | 膝下 3 寸外 | 全身强壮、下肢酸软 |
| 肩井 (GB21) | 肩峰与大椎中点 | 肩颈僵硬 |
| 环跳 (GB30) | 臀部 | 臀肌、髋关节痛 |
| 风池 (GB20) | 后枕下 | 颈源性头痛 |
| 大椎 (GV14) | 第 7 颈椎下 | 颈背紧张 |

## 第四节　四诊在运动推拿评估的应用

### 4.1 望诊 (Observation)
- 体态：脊柱侧弯、骨盆倾斜、肩高低
- 皮肤：瘀斑、肿胀、红热
- 步态：跛行、避痛步态
- 神色：疲劳程度、精神状态

### 4.2 闻诊 (Listening)
- 关节弹响：摩擦音、爆裂音
- 呼吸：运动后呼吸恢复速度
- 客户语调：判断疲劳与疼痛级别

### 4.3 问诊 (Questioning) — 运动推拿专属问诊清单
1. 训练史：项目、年限、周训练量、强度
2. 伤痛史：既往手术、骨折、扭伤
3. 当前症状：部位、性质 (酸/胀/刺/麻)、诱发动作、缓解方式
4. 训练周期：休赛期 / 训练期 / 比赛期
5. 营养与睡眠状况
6. 既往推拿/物理治疗经验

### 4.4 切诊 (Palpation)
- 肌张力：触感是否结节、条索
- 痛点定位：按压痛、激痛点 (Trigger Point)
- 关节活动度：被动范围
- 脉象：紧 (寒/痛)、滑 (湿/痰)、弦 (肝郁)

## 第五节　适应症与禁忌症 / Indications & Contraindications

### 5.1 运动推拿适应症
- DOMS、肌肉酸痛、僵硬
- 慢性肌腱炎、筋膜炎
- 关节活动受限（非急性期）
- 运动疲劳综合恢复
- 赛前心理唤醒、赛后放松

### 5.2 运动推拿禁忌（含运动专属）

**绝对禁忌：**
- 急性扭伤 24 小时内（患处）
- 骨折、脱位未复位/未愈合
- 肌腱断裂、韧带完全撕裂
- 开放性伤口、皮肤感染
- 急性深静脉血栓 (DVT)
- 横纹肌溶解症 (Rhabdomyolysis) 急性期

**相对禁忌（须谨慎或咨询医师）：**
- 严重高血压、心律不齐
- 妊娠期（按 CU 内容）
- 服用抗凝血药物
- 关节明显肿胀
- 发烧、疲劳过度（过度训练综合征）

### 5.3 可能反应 (Possible Effects)
- 膀胱满感
- 全身压力建立与释放感
- 治疗后轻微镇静
- 轻度淤青（瘀阻释放）

## 第六节　服务前准备要点

### 6.1 服务前核对清单
1. 客户记录是否对应当前客户
2. 服务方案已获客户同意
3. 客户偏好压力（轻柔 vs 深压）确认
4. 服务时长确认
5. 介质材料就绪（按摩油 / 药酒 / 爽身粉 / 推拿米袋）
6. 客户体位安全舒适
7. 已告知客户中止服务的权利
8. 客户贵重物品已妥善保管
