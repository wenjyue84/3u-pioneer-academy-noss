# 资料单 KP(2/3) — 运动推拿手法应用（腰背、四肢、关节常见运动伤）

**WIM 编码：** MP-031-3:2016-C03/KP(2/3)
**NOSS：** MP-031-3:2016 推拿疗法服务 (Level 3)
**CU：** C03 运动推拿服务 / Sport Tuina Service
**纸张颜色：** ⚪ 白页 (PUTIH)
**时数：** 70 小时（WA2 RK 大部分）
**最后更新：** 2026-04-17

---

## 学习目标 / Learning Objectives

完成本资料单后，学员能够：
1. 列出并解释运动推拿八种主要手法（推、拉、按、揉、捻、摩、抓提、压法）的动作要领
2. 调控手法之力度、速度、节奏与深度以匹配赛前/赛后/慢性期场景
3. 应用手法处理腰背常见运动伤（腰肌劳损、椎旁紧张、腘绳肌僵硬）
4. 应用手法处理四肢常见运动伤（肩袖、网球肘、髂胫束、跳跃膝、跟腱炎、踝扭伤恢复期）
5. 应用手法处理关节常见运动伤（关节扭伤分期管理、活动度恢复）
6. 持续观察运动客户反应（VAS、呼吸、面色、肌张力）并即时调整
7. 识别紧急情况（晕厥、抽搐、隐性骨折征兆）并执行处置

## 第一节　运动推拿八种主要手法 / Eight Sport Tuina Techniques

### 1.1 推法 (Pushing, Tuī)

| 项目 | 内容 |
|------|------|
| 工具 | 拇指（指腹/指尖/指侧）、掌、指节、肘 |
| 力度 | 中至重压 |
| 方向 | 顺肌纤维 / 沿经络远端→近端（赛后）；近端→远端（赛前激活） |
| 速度 | 赛前快；赛后缓；慢性中速 |
| 适用 | 大肌群（背、大腿、臀）；沿膀胱经、胃经 |
| 安全 | 避开骨突；脊椎正中不直接深推；椎旁 1.5 寸以外 |

### 1.2 拉法 (Pulling)

| 项目 | 内容 |
|------|------|
| 动作 | 拉伸关节并延长肌肉/筋膜 |
| 力度 | 稳定、缓慢、轻柔；不可暴拉 |
| 适用 | 上肢牵伸（肩、肘、腕）；下肢牵伸（髋、膝、踝、足趾） |
| 时机 | 赛后 / 慢性期；赛前不长时间静态拉以免降低肌力输出 |
| 禁忌 | 关节未稳定（扭伤急性期）；脱位史 6 个月内；过度松弛 |

### 1.3 按法 (Pressing, Àn)

| 项目 | 内容 |
|------|------|
| 工具 | 拇指端、中指端、指节、掌、掌根；运动深部用肘 |
| 力度 | 起始用手与前臂自重；深入用体重转移；非肌力 |
| 持续 | 单穴 5–10 秒；激痛点持续 30–90 秒 |
| 适用 | 委中、承山、阳陵泉、肩井、环跳；激痛点缓解 |
| 安全 | 客户呼吸引导；VAS 控制 ≤ 6；过痛即减压 |

### 1.4 揉法 (Kneading, Róu)

| 项目 | 内容 |
|------|------|
| 工具 | 掌、指、指节、肘或前臂 |
| 动作 | 圆周轨迹；带动浅层组织滑动于深层骨/筋膜上 |
| 力度 | 浅 → 深渐进 |
| 适用 | DOMS 后大肌群（股四头、腘绳、腓肠、斜方）；放松式核心手法 |
| 配合 | 介质（运动按摩油 / 中药酒）以减少摩擦 |

### 1.5 捻法 (Twiddling, Niǎn)

| 项目 | 内容 |
|------|------|
| 工具 | 拇指与食指指腹相对 |
| 力度 | 轻 |
| 适用 | 指趾末端（运动员手指/脚趾）；耳穴；指/趾抽筋后舒缓 |

### 1.6 摩法 (Rubbing, Mó)

| 项目 | 内容 |
|------|------|
| 工具 | 全掌、掌根或指腹 |
| 动作 | 圆周节律 |
| 力度 | 轻至中压；皮肤有滑动感 |
| 适用 | 腹部（赛后消化恢复）；背部大面积放松；预热阶段 |

### 1.7 抓提法 (Grasping)

| 项目 | 内容 |
|------|------|
| 工具 | 五指张开 + 拇指对接 |
| 动作 | 将组织从骨上提起再释放 |
| 适用 | 颈肩斜方肌、上臂三角肌、大腿股四头；松解大肌群粘连 |

### 1.8 压法 (Deep Pressing)

| 项目 | 内容 |
|------|------|
| 工具 | 拇指、掌、指节或肘 |
| 动作 | 缓慢敏感地深压；逐层渗透 |
| 适用 | 慢性肌腱炎、瘢痕组织、深部激痛点 |
| 安全 | 必须呼吸同步；持续 ≤ 90 秒；避开骨突与神经走行 |

## 第二节　力度·速度·节奏·深度调控

| 情境 | 力度 | 速度 | 节奏 | 深度 |
|------|------|------|------|------|
| **赛前热身式** | 轻至中 | 快（每分钟 80–120 次） | 强烈节奏 | 浅至中 |
| **赛后放松式** | 中 | 慢（每分钟 40–60 次） | 缓和持续 | 中 |
| **慢性运动伤治疗式** | 中至重（局部） | 慢 | 间歇深透 | 深（局部 ≤ 5–10 分钟） |

> 共同要求六字诀：**持久、有力、均匀、柔和、深透、节律**

## 第三节　腰背常见运动伤推拿应用

### 3.1 腰肌劳损 (Lumbar Strain) — 举重/瑜伽常见

| 项目 | 内容 |
|------|------|
| TCM 病机 | 肾虚 + 气滞血瘀；寒湿留经 |
| 体位 | 俯卧位，腹下垫枕减少腰前突 |
| 手法序列 | 摩腰背预热 → 沿膀胱经推法 → 揉腰阳关、肾俞、大肠俞 → 按委中 → 抓提腰侧 → 拉法 |
| 时长 | 局部 20–30 分钟 |
| 配穴 | 肾俞 (BL23)、大肠俞 (BL25)、腰阳关 (GV3)、委中 (BL40)、阿是穴 |
| 禁忌 | 急性椎间盘突出、腰椎骨折、马尾症候群 → 转介 |

### 3.2 腘绳肌僵硬 (Hamstring Tightness) — 跑步/足球常见

| 项目 | 内容 |
|------|------|
| 体位 | 俯卧位，踝下垫枕 |
| 手法 | 沿膀胱经推法（臀 → 膕窝） → 揉股二头肌 → 按承山 → 拉法（直腿轻牵） |
| 配穴 | 承扶 (BL36)、殷门 (BL37)、委中、承山 |
| 注意 | 坐骨神经痛者深压须谨慎；放射麻 → 转介 |

### 3.3 颈肩斜方肌紧张 — 自行车/游泳常见

| 项目 | 内容 |
|------|------|
| 体位 | 坐位 / 俯卧位 |
| 手法 | 抓提斜方肌 → 揉肩井 → 按风池、天柱 → 推法沿膀胱经上段 |
| 配穴 | 肩井 (GB21)、风池 (GB20)、天柱 (BL10)、大椎 (GV14) |
| 注意 | 肩井深按勿过度（孕妇绝对禁忌） |

## 第四节　四肢常见运动伤推拿应用

### 4.1 肩袖损伤 (Rotator Cuff)

| 项目 | 内容 |
|------|------|
| 体位 | 仰卧 / 侧卧 |
| 手法 | 摩肩前 → 揉三角肌 → 按肩髃、肩髎、臑俞 → 抓提冈上肌 → 轻拉肩关节 |
| 配穴 | 肩髃 (LI15)、肩髎 (TE14)、臑俞 (SI10)、巨骨 (LI16) |
| 禁忌 | 完全撕裂（疑似 → 转介骨科） |

### 4.2 网球肘

| 项目 | 内容 |
|------|------|
| 手法 | 揉前臂伸肌群 → 按曲池、手三里 → 局部摩肱骨外上髁 → 拉腕背伸 |
| 配穴 | 曲池 (LI11)、手三里 (LI10)、合谷 (LI4) |

### 4.3 髂胫束综合征 (ITBS)

| 项目 | 内容 |
|------|------|
| 体位 | 侧卧（患侧在上） |
| 手法 | 沿胆经推（大转子 → 膝外） → 揉阔筋膜张肌 → 按风市、阳陵泉 → 抓提股外侧 |
| 配穴 | 风市 (GB31)、阳陵泉 (GB34)、膝阳关 (GB33) |

### 4.4 跳跃膝 / 髌腱炎

| 项目 | 内容 |
|------|------|
| 体位 | 仰卧，膝下垫枕 |
| 手法 | 揉股四头肌 → 按梁丘、血海、犊鼻、内外膝眼 → 摩髌周（避开髌骨直按） → 拉股四头 |
| 配穴 | 梁丘 (ST34)、血海 (SP10)、犊鼻 (ST35)、足三里 (ST36) |

### 4.5 跟腱炎

| 项目 | 内容 |
|------|------|
| 手法 | 揉小腿三头肌 → 按承山、昆仑、太溪 → 慢压跟腱两侧 → 摩足底 |
| 配穴 | 承山 (BL57)、昆仑 (BL60)、太溪 (KI3) |

### 4.6 踝扭伤恢复期 (≥ 48h, 无急性肿热)

| 项目 | 内容 |
|------|------|
| 手法 | 摩踝周 → 揉腓骨长短肌 → 按解溪、丘墟、申脉、照海 → 慢压韧带瘢痕 → 拉踝松动 |
| 配穴 | 解溪 (ST41)、丘墟 (GB40)、申脉 (BL62)、照海 (KI6) |

## 第五节　关节常见运动伤分期管理

| 分期 | 时间 | 临床表现 | 推拿原则 |
|------|------|----------|----------|
| **急性期** | 0–48 小时 | 红、肿、热、痛、活动受限 | **患处禁推**；远端疏导；RICE |
| **亚急性期** | 48h – 2 周 | 肿减轻、痛减、瘀斑显现 | 轻揉患处周围；活血化瘀 |
| **慢性 / 恢复期** | 2 周 + | 僵硬、瘢痕粘连 | 深层手法、激痛点深压、关节松动、牵伸 |

> RICE = Rest 休息 / Ice 冰敷 / Compression 加压 / Elevation 抬高

## 第六节　客户反应观察与紧急情况

### 6.1 持续监测项目

| 项目 | 正常 | 警示 |
|------|------|------|
| **VAS 疼痛** | ≤ 5/10 | ≥ 7 → 减压评估 |
| **呼吸** | 平稳深长 | 急促、屏气 → 暂停 |
| **面色** | 红润或微汗 | 苍白、冷汗 → 立即停手 |
| **肌张力** | 渐松 | 反射性紧绷 / 抽搐 → 停手 |
| **意识** | 清醒应答 | 嗜睡过度 / 言语含糊 → 警示 |

### 6.2 运动专属紧急情况

| 情况 | 识别 | 处置 |
|------|------|------|
| **运动员晕厥** | 突冷汗、面白、心慌 | 平卧抬腿、补水电解质；> 5 分钟未恢复 → 999 |
| **抽筋** | 突发肌肉强直 | 反向轻柔牵伸；按承山 / 阳陵泉；补水 |
| **隐性骨折征** | 持续骨点痛、肿不退 | 立即停手 → 转介影像学 |
| **横纹肌溶解疑似** | 深色尿、剧痛、虚弱 | 立即停手 → 急诊 |
| **过度换气** | 手脚麻、头晕 | 慢呼吸引导、口袋呼吸法 |

## 第七节　工作区与介质感染控制

- 推拿床每客一换大铺巾；面圈套布一客一换
- 推拿油倒入小杯，避免瓶口接触客户皮肤
- 介质开封后标注开封日期；运动按摩油保质期内使用
- 推拿师手部七步洗手法；指甲修剪圆润；制服每日更换
- 急救箱、AED 位置全员知晓并定期检查
