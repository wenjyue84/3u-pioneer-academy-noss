# 工作单 KK(1/3) — 运动员评估与准备

**对应理论：** KP-01 / KT-01

## 一、任务说明

学员须独立完成运动推拿服务前的全部准备工作：
1. 复核运动员客户记录与同意书
2. 进行运动专属问诊与四诊
3. 确认偏好压力、时长、重点部位
4. 准备推拿床/椅、铺巾、运动按摩介质
5. 协助客户更衣并定位体位
6. 告知运动推拿可能反应与中止权利
7. 安全保管贵重物品

## 三、安全与职业操守

- 演练前导师确认推拿床稳固、地面防滑、急救箱齐全
- 同伴互练须签署模拟同意书；异性配对须有第三方在场
- 学员着装：制服、工作鞋、修剪指甲、洗手消毒
- 客户隐私部位以毛巾遮蔽（draping）
- 运动按摩油 / 中药酒开封后须标注开封日期
- 严守 PDPA 2010：运动员训练日程 / 比赛日程为隐私

## 四、操作步骤 (Step-by-Step Procedure)

### 步骤 1：客户档案复核（5 分钟）
1. 取出运动员档案
2. 复核：上次服务摘要、当前训练周期、伤痛史、过敏史、知情同意有效期
3. 留意红旗征
4. 准备本次服务记录表

### 步骤 2：运动专属问诊（10 分钟）
1. **训练史** — 项目、年限、周训练量、强度
2. **伤痛史** — 既往手术、骨折、扭伤
3. **当前症状** — 部位、性质（酸/胀/刺/麻）、诱发动作、缓解方式
4. **训练周期** — 休赛 / 训练 / 赛季 / 赛后
5. **营养与睡眠** — 蛋白摄入、水分、睡眠时长
6. **既往推拿 / 物理治疗经验**
7. 记录 VAS 与 Borg RPE 基线值

### 步骤 3：四诊复核（5 分钟）
1. **望** — 体态、皮肤、步态、神色
2. **闻** — 关节弹响、呼吸、语调
3. **问** — 重点部位 + 疼痛诱发动作
4. **切** — 肌张力、痛点定位、关节活动度、脉象

### 步骤 4：偏好与方案确认（5 分钟）
1. 确认压力偏好（轻柔 vs 深压）
2. 确认时长（局部 30–45 / 全身 60+ 分钟）
3. 确认情境类型（赛前 / 赛后 / 慢性）
4. 告知可能反应：膀胱满感、压力释放、轻度镇静、轻度淤青
5. 告知中止服务的权利
6. 客户签署本次服务同意书

### 步骤 5：贵重物品保管（2 分钟）
1. 提供锁柜或保管袋
2. 列示物品 → 客户签署清单
3. 钥匙双联

### 步骤 6：推拿床 / 椅准备（10 分钟）
1. 调整推拿床高度（术者手肘平推拿面）
2. 检查床稳固性、面部圈清洁
3. 铺一次性大铺巾覆盖整床
4. 摆放靠枕（俯卧：胸下/踝下；仰卧：膝下）
5. 备浴巾在床尾
6. 赛前场域：长椅 + 浴巾 + 立式推拿（可选）

### 步骤 7：介质与用品摆放（5 分钟）
1. 运动按摩油倒入小杯
2. 中药酒备用（慢性期）
3. 爽身粉倒入小托盘
4. 毛巾叠好放推车上层
5. 计时器静音模式
6. 备温水杯、纸巾

### 步骤 8：客户更衣与体位定位（5 分钟）
1. 引导至更衣区
2. 提供运动短裤 / 衣袍
3. 协助客户上床
4. 按方案定位体位（俯/仰/侧/坐）
5. 适当 draping 隐私部位
6. 询问体位舒适度
