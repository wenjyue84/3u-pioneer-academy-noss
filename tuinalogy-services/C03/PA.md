# 表现评估 / Performance Assessment (PA) — C03 运动推拿服务


## 评估说明

- 本评估为 C03 综合实操考核，覆盖 KK-01、KK-02、KK-03 全部技能
- 学员独立完成 60 分钟运动推拿全流程（术前 + 服务 + 服务后）
- 由 1 名主考评估员 (PB) + 1 名观察员评估
- 模拟运动员客户由资深学员 / 标准化客户 (SP) 担任
- 满分 100 分，及格 ≥ 70 分
- 不及格者经 14 天再训练后可补考一次

## 评估目标

- 与 NOSS C03 全部 3 项工作活动评估准则对齐
- 测试技能层次 P3（独立操作）至 P4（熟练应用）
- 测试态度 A2–A3（专业、稳定、富同理心）

## 评估场地与设备

- 模拟推拿室一间（22–25°C、< 50 dB、暖色灯）
- 推拿床 + 全套用品（KK-01 §2 列示）
- 模拟运动员客户 1 名（健康成年；扮演慢性运动伤场景）
- 计时器 1 个
- VAS / Borg RPE 卡 / 量角器
- 评分表 + 录像设备
- 急救箱 + AED 位置确认

---

## 评估流程（共 ≈ 90 分钟操作 + 30 分钟评议）

### 阶段 A：术前准备（15 分钟）— 来自 KK-01
### 阶段 B：运动推拿执行（60 分钟）— 来自 KK-02
### 阶段 C：服务后管理（15 分钟）— 来自 KK-03

考试题目示例（PB 抽签决定情境）：
- 题目 1：赛前热身式 30 分钟方案
- 题目 2：赛后放松式 60 分钟方案
- 题目 3：慢性运动伤治疗式（腰肌劳损 / ITBS / 肩袖 / 跟腱炎，PB 抽签）
