# 工作单 KK(3/3) — 恢复跟踪与运动建议

**对应理论：** KP-03 / KT-03

## 一、任务说明

学员须独立完成运动推拿服务后的全部管理工作：
1. 评估运动员客户服务后状态
2. 给予离场建议与自我护理指导
3. 处理服务后不适
4. 识别红旗征并执行转介
5. 完整更新客户档案
6. 安排复诊频率

## 二、所需工具与材料

| 项目 | 数量 |
|------|------|
| 客户档案表（运动员版） | 1 |
| VAS 卡 + Borg RPE 卡 | 各 1 |
| 量角器（ROM 测量） | 1 |
| 温水 + 电解质（如需要） | 备 |
| 自我护理建议卡（中英双语） | 1 |
| 转介信模板 + 信封 | 备 |
| 中心 / 推拿师印章 | 1 |
| 复诊预约表 / 系统 | 1 |
| 急救箱位置确认 | — |

## 三、安全与职业操守

- 服务后 5–10 分钟方可起身，避免体位性低血压
- 红旗征零容忍：识别即停、即转介
- PDPA 2010：转介信仅含必要信息
- 客户档案记录须 24 h 内完成
- 涂改禁用涂改液 / 撕毁；划线 + 签名 + 日期

## 四、操作步骤

### 步骤 1：客户原位休息（5–10 分钟）
1. 协助客户保持原体位静卧
2. 盖浴巾保暖
3. 静音环境
4. 远端观察客户反应（嗜睡 / 烦躁 / 异常）

### 步骤 2：服务后评估（5 分钟）

#### 2A. 主观评估
1. **疼痛 VAS** 0–10 复测
2. **疲劳 RPE** Borg 6–20 复测
3. **情绪自评** 放松 / 平稳 / 烦躁
4. **客户主诉** 服务过程感受

#### 2B. 客观评估
1. **活动度 (ROM)** 量角器测患处
2. **肌张力** 触诊关键肌群
3. **生命体征** 脉搏、呼吸、面色

#### 2C. 服务前后对比记录

```
项目         | 术前    | 术后    | 变化
腰右痛 VAS   | 7/10   | 3/10   | -4 ✓
腰前屈 ROM   | 60°    | 80°    | +20° ✓
RPE 自评     | 14/20  | 9/20   | -5 ✓
心率 (bpm)   | 88     | 76     | -12 ✓
情绪         | 烦躁   | 平稳   | 改善 ✓
```

### 步骤 3：起身与离场（10 分钟）
1. 协助侧卧 → 坐起 → 静坐 30 秒 → 站立
2. 询问头晕、心慌
3. 引导更衣区
4. 提供温饮（200–500 ml；运动员加电解质）
5. 归还贵重物品并签收

### 步骤 4：自我护理建议指导（5 分钟）

按运动情境给予不同建议菜单：

#### 4A. 赛前推拿后
- 维持轻活动保持温度
- 避免立即剧烈热身
- 30 分钟内进入比赛 / 训练

#### 4B. 赛后推拿后
- 24 h 内不安排高强度训练
- 优质蛋白 1.2–2.0 g/kg/day
- 抗炎食物（鱼油、姜黄、深色蔬果）
- 避免酒精 24 h
- 睡眠 ≥ 8 小时
- 冷热交替浴可选

#### 4C. 慢性运动伤推拿后
- 48 h 内回训强度降至 60%
- 慢性僵硬：温敷 15 min × 2/天
- 亚急性肿胀：冷敷 10 min × 3/天
- PNF / 静态拉伸 30 秒 × 3 组，每日 1 次
- 按建议家庭自我护理

### 步骤 5：服务后不适处置

| 不适 | 处置 |
|------|------|
| 轻度淤青 | 告知正常；24 h 内冷敷 |
| 嗜睡 | 告知 24 h 内可能持续；勿驾车 |
| 局部酸胀 | 告知 12–48 h 内正常；温敷可缓解 |
| 头晕 | 静坐 → 补水 → 监测；> 10 min 不缓解 → 转介 |
| 深色尿 / 剧痛 | 红旗 → 立即急诊转介 |

### 步骤 6：红旗征识别与转介

#### 6A. 立即急诊转介
- 深色尿 + 剧烈肌痛 + 虚弱（横纹肌溶解）
- 突发胸痛 + 心悸 + 冷汗（心血管）
- 急性单侧腿肿热痛（DVT）
- 鞍区麻木 + 大小便失禁（马尾）
- 头部重击后呕吐 / 意识障碍
- 关节畸形 + 不能负重（骨折/脱位）

#### 6B. 一般转介
- 持续 4 周以上同部位疼痛未缓解 → 物理治疗 / 骨科
- 神经放射痛、麻木、肌力下降 → 神经科 / 脊椎专科
- 不明体重下降 + 夜间盗汗 → 内科
- 慢性肿胀不退 → 风湿免疫
- 心理压力 / 比赛焦虑严重 → 运动心理师

#### 6C. 转介流程演练
1. 红旗征识别 → 立即停止推拿
2. 客户安抚 + 解释必要性
3. 取得客户口头同意
4. 撰写转介信（症状、推拿史、建议）
5. 紧急时联系 999 / 客户家属
6. 完整记录于客户档案
7. 跟进结果


### 步骤 7：客户档案更新（5 分钟）
1. 服务日期 / 时间 / 时长
2. 体位 + 手法序列摘要
3. 服务前后对比表
4. 客户反馈与签名
5. 异常反应（含轻度淤青、嗜睡）
6. 转介记录（如有）
7. 推拿师签名 + 日期

### 步骤 8：复诊安排（3 分钟）
按情境推荐：
- 急性恢复期（亚急性后）：每周 2 次 × 2 周
- 慢性运动伤治疗：每周 1 次 × 4–6 周
- 维持保健：每 2–4 周 1 次
- 赛季支援：大赛前 1 周 + 赛后 24 h
- 休赛期：每月 1 次

预约方式：电话 / WhatsApp / 系统预约。

### 步骤 9：方案有效性评估（每 4 周）
- 改善 < 30% → 复核诊断 + 调整 + 评估转介
- 改善 30–完全 → 维持
- 痊愈 → 转维持保健频率
- 新红旗 → 立即转介
