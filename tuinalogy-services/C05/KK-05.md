# 工作单 5：销售营销方案

**对应理论：** KP-05 / KT-05

## 一、任务说明

完成以下三项实作：
1. 设计 1 份季度促销方案（含文案、定价、执行计划）
2. 撰写 5 篇合规社媒贴文（FB、IG、TikTok、WA、GMB）
3. 建立 CRM 会员系统并登记 10 位模拟客户

## 二、所需工具与材料

| 项目 | 数量 |
|------|------|
| 电脑 + Canva + MS Office | 1 |
| 模拟社媒账号（Sandbox） | FB、IG、TikTok、GMB 各 1 |
| WhatsApp Business API 试用 | 1 |
| CRM 软件（免费版：HubSpot / Zoho 试用） | 1 |
| 促销方案模板 | 1 |
| 客户资料样本（10 份虚构） | 1 |
| 打印机 + A4 彩色纸 | 1 |
| 文案审查清单（T&CM 禁例） | 1 |

## 三、安全与职业操守

- 社媒贴文使用 Sandbox 账号，不对公众发布
- 客户资料均为虚构，不得使用真实 IC
- 所有文案须经导师审批 T&CM 合规
- 学员不得保存客户资料至个人设备

## 四、操作步骤

### 步骤 1：季度促销方案设计（4 小时）
1. 选定主题（如"疫后复工纾压特惠"）
2. 定价：原价 RM128 → 会员 RM88 前 100 位
3. 期限：2026-05-01 至 2026-07-31
4. 渠道：FB/IG/WA Broadcast/GMB
5. 合规审查：不写"治愈""疗效保证"
6. 撰写 A4 单张海报 + 数字海报
7. 计算预算：广告费 RM 500 + 印刷 RM 200
8. KPI：新增客户 ≥ 50 人、复购 ≥ 30 人
9. 呈 Manager 批准

### 步骤 2：社媒贴文撰写（4 小时）
1. FB：健康知识贴（肩颈酸痛原因 + 图解）
2. IG：环境 + 推拿师专业介绍（含 MOH 注册号）
3. TikTok：15 秒推拿房介绍（环境 + 员工）
4. WA Broadcast：季度促销简讯（≤ 60 字）
5. GMB：服务项目 + 营业时间 + 常见问答
6. 合规审查 Checklist（见下表）
7. 经导师批准后发布 Sandbox

**文案合规审查：**

| 检查项 | ✅/❌ |
|-------|:----:|
| 无"治愈/根治"字眼 |  |
| 无"医生 / Dr."头衔 |  |
| 无比较医疗陈述 |  |
| 无未授权客户照片 |  |
| 含免责声明 |  |
| 含中心地址 + 联系 |  |
| 标注 MOH T&CM 注册号 |  |

### 步骤 3：CRM 会员系统（4 小时）
1. 注册 HubSpot/Zoho 免费账号
2. 创建字段：姓名、IC、生日、电话、首访、偏好、累积消费
3. 登记 10 位虚构客户
4. 分级：Silver / Gold / Platinum
5. 设置生日自动提醒（Email + WA）
6. 创建营销同意栏（PDPA）
7. 生成 CLV 报表（累积消费 × 复购率）
8. 每位客户标记"Opt-in / Opt-out"

## 六、常见错误与修正

| 错误 | 修正 |
|------|------|
| 写"陈师傅治好糖尿病" | 改"帮助放松肌肉，改善循环" |
| 贴客户前后照无同意 | 移除或取得书面同意 |
| 使用"Dr."自称 | 改为"师傅 / Therapist" |
| CRM 未标 Opt-in | 加入同意字段 |
| 促销无期限 | 注明起止日期 |
