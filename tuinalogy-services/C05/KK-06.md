# 工作单 6：模拟客户投诉处理

**对应理论：** KP-06 / KT-06

## 一、任务说明

完成以下三项实作：
1. 角色扮演：接收并以 LEARN 五步法处理 2 宗模拟投诉
2. 撰写 1 封书面回应信函
3. 建立投诉登记簿 + 月度汇总报表

## 二、所需工具与材料

| 项目 | 数量 |
|------|------|
| 模拟投诉案例卡（5 张） | 1 套 |

| 录像设备 | 1 |

| 电话 / WhatsApp 模拟 | 1 |

## 三、安全与职业操守

- 角色扮演中扮演客户者须签模拟同意书
- 涉及"性骚扰""受伤"情境须有导师监督
- 录像仅用于课堂复盘，演练后立即删除
- 学员禁止把案例带出课堂

## 四、操作步骤

### 步骤 1：角色扮演（2 小时）

**案例 A — 服务态度投诉（中等）**
- 客户当面投诉推拿师态度冷漠、手法太重
- 学员扮演 Manager：
  1. Listen：带客户到隔间落座，倒水
  2. Empathize：复述问题，表示理解
  3. Apologize：正式致歉
  4. Respond：提出 RM 50 抵用券 + 更换师傅
  5. Notify：填登记表 + 通知推拿师培训
- 录像 + 导师现场评分

**案例 B — 安全事件（高）**
- 客户在推拿后出现背部瘀青 + 剧痛（模拟受伤）
- 学员扮演 Manager：
  1. 立即陪同就医 + 支付医疗费
  2. 通知保险公司 + SOCSO
  3. 24 小时内上报 MOH T&CM Division
  4. 内部调查 + 面谈推拿师
  5. 填写不良事件报告
  6. 书面回应客户
- 录像 + 导师评分

### 步骤 2：书面回应信撰写（2 小时）
1. 选案例 B 撰写回应函
2. 信头：中心名称 + 地址 + MOH 注册号
3. 称谓 + 日期 + 投诉编号
4. 段落 1：感谢 + 致歉
5. 段落 2：调查结果摘要（不推诿）
6. 段落 3：补救方案（退费 + 医疗费 + 免费疗程 + 内部改善）
7. 段落 4：联系人 + 祝福语
8. Manager 签字 + 盖章
9. 邮寄挂号 + 保留签收单

### 步骤 3：投诉登记与月度汇总（2 小时）
1. 建立 Excel 登记簿（20 笔模拟数据）
2. 字段：编号、日期、渠道、客户、员工、类别、严重度、处理时长、结案方式
3. 生成月度数据透视：
   - 投诉率 = 笔数 ÷ 客流
   - 平均结案时间
   - 重复投诉率
   - 严重事件计数
4. 趋势图（折线 + 饼图）
5. 撰写 1 页月报（含改进建议）

## 六、常见错误与修正

| 错误 | 修正 |
|------|------|
| Manager 当面反驳客户 | 立即道歉 + 改用 LEARN |
| 禁语"别的客户都没事" | 换"您的感受很重要" |
| 回应信推诿"师傅手重是客户体质问题" | 去除 + 诚恳致歉 |
| 严重伤亡未 24h 上报 | 立即补报 + 书面解释 |
| 登记簿漏填严重度 | 补填 + 重新分析 |
