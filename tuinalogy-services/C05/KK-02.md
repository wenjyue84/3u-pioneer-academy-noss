# 工作单 2：员工排班与绩效

**对应理论：** KP-02 / KT-02

## 一、任务说明

完成以下三项实作：
1. 制作下月员工排班表（合规 Employment Act 1955）
2. 模拟 1 名员工半年度绩效评估
3. 模拟 EPF / SOCSO / PCB 月度申报（使用 Sandbox 平台）

## 二、所需工具与材料

| 项目 | 数量 |
|------|------|
| 电脑 + Excel | 1:2 |
| 排班模板 | 1 |
| 绩效评估表模板 | 1 |
| 模拟员工资料（8 人：4 推拿师 + 2 接待 + 1 清洁 + 1 Admin） | 1 套 |

## 三、安全与职业操守

- 所有模拟员工 IC 号使用虚构号码（000000-00-0000）
- 薪资数据仅用于课堂，不外传
- 法定申报使用 Sandbox 环境，不涉及真实缴款
- 学员签署保密协议

## 四、操作步骤

### 步骤 1：排班表制作（4 小时）
1. 列出 8 名模拟员工 + 职位 + 每周工时上限
2. 考虑每周最高 45 小时 + 每日最高 8 小时
3. 每人每周至少 1 天休息日
4. 推拿师至少保持 3 人在岗（高峰时段 4 人）
5. 接待至少 1 人全天在岗
6. 输出 4 周滚动排班表 + 发放给员工确认

### 步骤 2：绩效评估（4 小时）
1. 选定 1 名推拿师（模拟）
2. 依 KP-02 §5.1 KPI 表收集数据：月服务人次、满意度、复购率、安全事件、培训时数
3. 打分：超标 / 达标 / 需改进
4. 填写《半年度绩效评估表》：强项、待改进、下半年目标
5. 模拟 30 分钟面谈（角色扮演：Manager + 员工）
6. 员工签字 + Manager 签字 + 归档

### 步骤 3：EPF / SOCSO / PCB 申报（4 小时）
1. 登入 i-Akaun Sandbox，上传员工薪资表
2. 系统自动计算 EPF 13%/11%
3. 登入 ASSIST Sandbox 上传 SOCSO + EIS
4. 使用 LHDN PCB Calculator 计算 PCB
5. 生成缴款单 (VA) 与参考码
6. 存档 CP39、KWSP Form A、Borang 8A 截图
7. 核对总额 = 月薪扣款合计

## 六、常见错误与修正

| 错误 | 修正 |
|------|------|
| 单日排 10 小时 | 调整 ≤ 8 小时或计 OT |
| 连续 6 日无休息 | 插入至少 1 天 OFF |
| EPF 雇主忘加 | 按薪资 <RM5k 13% 计算 |
| 绩效只评打分不写理由 | 补充文字评语 + 改进计划 |
| PCB 忽略家属津贴扣减 | 参考 LHDN Schedule PCB |
