# 工作单 1：客户档案与归档系统建立

**对应理论：** KP-01 / KT-01

## 一、任务说明

在模拟办公室内建立一个完整的归档系统，包含员工、客户、公司三大类，涵盖分类、标签、机密分级与 PDPA 合规。

## 二、所需工具与材料 (TEM)

| 项目 | 数量 |
|------|------|
| 档案柜（钢制带锁） | 1 |
| A4 文件夹（多色） | 15 |
| 标签贴 | 1 卷 |
| 隔页、颜色分类板 | 若干 |
| 员工档案样本（10 份空白） | 10 |
| 客户档案样本（20 份空白） | 20 |
| 公司文件样本（5 份） | 5 |
| 电脑 + Excel 清单模板 | 1 |
| 碎纸机 | 1 |
| PDPA 知情同意书样本 | 10 |

## 三、安全与职业操守

- 演练前导师确认所有样本档案使用虚构资料，无真实 IC 号
- 档案柜须上锁并保管钥匙日志
- 碎纸演练后废纸立即回收
- 学员须签署课堂保密协议 (NDA)

## 四、操作步骤

### 步骤 1：文件盘点 (Inventory)
1. 列出中心所有现有文件类别
2. 使用 Excel 模板登记：文件名 / 数量 / 现存位置 / 状态
3. 标记是否含个人资料（PDPA 适用）

### 步骤 2：分类架构设计
1. 按员工 / 客户 / 公司三大类建立一级目录
2. 二级目录：员工（IC、合约、薪资、绩效、培训、请假）
3. 二级目录：客户（档案、治疗记录、同意书、反馈）
4. 二级目录：公司（组织架构、政策、SOP、证照、财务）

### 步骤 3：标签制作
1. 按 `[年份]-[类别码]-[流水号]-[简述]` 格式打印标签
2. 类别码：STF / CLT / FIN / OPS / LGL
3. 贴于文件夹外脊与封面

### 步骤 4：机密分级
1. 高度机密（红色）：客户病历、员工薪资
2. 内部使用（蓝色）：SOP、排班
3. 在文件夹封面贴机密等级贴纸

### 步骤 5：归档与上锁
1. 按分类将文件放入指定文件夹
2. 文件夹按流水号放入档案柜
3. 档案柜上锁 + 钥匙仅 Manager / Admin 持有
4. 电子版存入加密云端文件夹（权限分级）

### 步骤 6：归档登记簿
1. 登记簿记录：编号、标题、归档日期、存放位置、负责人
2. 每新增一档案即登记一行
3. 每周 Manager 抽查 5 笔

### 步骤 7：周期审核 + 销毁
1. 每 6 个月审核一次档案
2. 列出超过保存期（员工 7 年、客户 6 年）的文件
3. 填写《销毁申请表》Manager 批准
4. 碎纸销毁 + 登记销毁记录（日期、编号、见证人）

## 六、常见错误与修正

| 错误 | 修正 |
|------|------|
| 文件夹无标签 | 立即补贴 |
| 档案柜未上锁离场 | 立即上锁 + 警告 |
| 混合员工与客户档案 | 分别归档 |
| 客户档案含政治 / 宗教资料 | 移除非相关资料 |
| 销毁无记录 | 填写销毁表 |
