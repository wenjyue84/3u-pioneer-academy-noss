## 一、人力资源规划 / HR Planning

### 1.1 组织架构示例 (小型推拿中心)

```
中心经理 Manager
├── 行政/账务 Admin/Account (1)
├── 接待 Reception (1–2)
```

### 1.2 职务说明书 (Job Description, JD)

每个岗位须有：职称、直属上级、主要职责、任职资格、KPI、薪酬范围。JD 每 2 年检讨一次。

## 二、招聘流程 / Recruitment

| 步骤 | 内容 | 合规要点 |
|------|------|---------|
| 1 | 确认空缺（JD + 人数） | Manager 批准 |
| 2 | 发布广告（JobStreet / FB / WhatsApp） | 不得歧视种族、性别、宗教 |
| 3 | 筛选简历 | 核对 MOH T&CM 注册号（推拿师岗） |
| 4 | 面试（技术 + 行为） | 问题须与岗位相关 |
| 5 | 体检 + 无犯罪记录（推拿师） | 中心负担 |
| 6 | 发放聘书 (Letter of Offer) | 载明薪资、工时、试用期 |
| 7 | 入职手续 | EPF、SOCSO、EIS 注册；IC 副本存档 |
| 8 | 试用期 3–6 个月 | 期满评估确认 |

## 三、员工排班 / Staff Scheduling

### 3.1 法定工时 (Employment Act 1955 修订 2022)

| 项目 | 规定 |
|------|------|
| 每周最高工时 | 45 小时 |
| 每日最高工时 | 8 小时（含午休外） |
| 加班费 | 平日 1.5×、休息日 2.0×、公共假日 3.0× |
| 公共假日 | 每年至少 11 天（含 5 天强制） |
| 年假 | 服务 <2 年：8 天；2–5 年：12 天；>5 年：16 天 |
| 病假 | 未住院：14–22 天；住院：最多 60 天 |

## 四、培训与发展 / Training & Development

### 4.1 年度培训计划要素

- 技术提升：推拿进阶手法、经络穴位深化
- 安全与急救：CPR、AED、防感染
- 软技能：客户服务、投诉处理、沟通
- 法规：PDPA、T&CM Code of Ethics 更新

### 4.2 HRDF / HRD Corp Levy

- 雇主 ≥10 人须缴 1% 月薪 levy（Act 612）
- 可申报培训退款 (Claim)
- 文件要求：培训大纲、导师资质、出席表、发票

---

## 五、绩效管理 / Performance Management

### 5.1 KPI 示例 (推拿师)

| 维度 | 指标 | 目标 |
|------|------|------|
| 量 | 月服务人次 | ≥ 80 |
| 质 | 客户满意度 | ≥ 4.5/5 |
| 复购 | 会员续卡率 | ≥ 60% |
| 安全 | 零不良事件 | 100% |
| 学习 | 年培训时数 | ≥ 20 小时 |

### 5.2 评估周期

- 试用期末：确认 / 延长 / 辞退
- 半年度：中期检讨（Mid-Year Review）
- 年度：正式考核 + 调薪 + 奖金
