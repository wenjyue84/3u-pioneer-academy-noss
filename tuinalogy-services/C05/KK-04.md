## 一、任务说明

完成以下三项实作：
1. 执行一整日模拟交易的日终收银结算
2. 开立 3 份 MyInvois e-Invoice
3. 草拟月度 P&L 损益表

## 三、安全与职业操守

- 模拟现金使用玩具钞票，不涉真钞
- 模拟客户 IC 使用虚构号码
- MyInvois 仅使用 Sandbox 环境
- 学员禁止携带交易数据外传

## 四、操作步骤

### 步骤 1：模拟日常收银（3 小时）
1. 接待员使用 POS 收款，开立收据
2. 扫描付款（现金、POS 卡、QR Pay、转账）
3. 每笔登记：时间、项目、员工、金额、支付方式
4. 退款案件单独登记 + Manager 签字
5. 至少完成 20 笔模拟交易

### 步骤 2：日终结算（3 小时）
1. 打印 POS 报表
2. 清点现金（按面额分类）
3. 对账：POS 数 + 现金数 + QR + 转账 = 系统数
4. 差额处理：Manager 签字说明
5. 填写《日终收银表》
6. 现金存入夜盒 + 存款单存档
7. 系统关账

### 步骤 3：开立 e-Invoice（3 小时）
1. 登入 MyInvois Sandbox
2. 新增 3 份发票（A：单次服务、B：套餐、C：产品）
3. 填写必备 55 栏位
4. 递交 LHDN → 获 UIN 与 QR Code
5. 下载 PDF + 发送客户（模拟 Email）
6. 归档 e-Invoice 记录

### 步骤 4：月度 P&L 草拟（3 小时）
1. 汇总 30 日收入（现金 + POS + QR + 转账）
2. 分类收入：服务 / 产品 / 会员充值
3. 汇总支出：薪资 / 租金 / 水电 / 耗材 / 营销 / 其他
4. 计算：毛利 / 净利 / 净利率
5. 比较 vs 目标：超/未达标
6. 导出 PDF 呈 Manager

## 六、常见错误与修正

| 错误 | 修正 |
|------|------|
| 收据无 SSM 号 | 加印 SSM |
| e-Invoice 忘填 TIN | 补入 + 重新递交 |
| 对账差额不报 | 立即登记 + Manager 签 |
| 现金混放 | 按面额分类 + 清点表 |
| P&L 收入含未收账 | 区分实收 vs 应收 |
