# 工作单 3：中心卫生巡检

**对应理论：** KP-03 / KT-03

## 一、任务说明

完成以下三项实作：
1. 制作中心完整清洁检查表（日/周/月 频率）
2. 在模拟推拿中心执行一次完整巡检并填表
3. 为化学品储柜建立 MSDS 档与标签

## 二、所需工具与材料

| 项目 | 数量 |
|------|------|
| 模拟中心（接待、推拿房 2 间、厕所、茶水间） | 1 |
| 清洁用品（IPA 70%、漂白水、洗手液、搓手液、酒精棉） | 各 1 |
| 推拿床 + 一次性床纸 | 2 |
| 毛巾、脏衣篮 | 5 |
| 医疗锐器盒 | 1 |
| 清洁检查表模板 | 1 |
| MSDS 文件模板 | 5 |
| 化学品标签贴 | 若干 |
| PPE（手套、口罩、围裙） | 1 套/人 |
| 手机噪音 App / 温度计 | 1 |

## 三、安全与职业操守

- 操作化学品全程佩戴 PPE
- 漂白水严禁与氨水混用（会产生氯气）
- 演练后所有废物分类投弃
- 学员感冒或皮肤破损禁止接触化学品

## 四、操作步骤

### 步骤 1：制作清洁检查表（2 小时）
1. 按 KP-03 §1 列出各区域与频率
2. 整理为 Excel 表：区域 / 项目 / 频率 / 负责人 / 签字栏
3. 打印贴于各区域墙上
4. 设定每日 4 时段（08:00/12:00/16:00/20:00）巡检节点

### 步骤 2：推拿床每客消毒演练（2 小时）
1. 换一次性床纸
2. 将用过毛巾投入脏衣篮
3. 以 70% IPA 喷床面 + 头托 + 脚凳
4. 等待 30 秒风干
5. 湿纸巾重点擦拭
6. 废物分类（一般 / 锐器）
7. 填写 Room Turnover Log

### 步骤 3：现场巡检演练（2 小时）
1. 携带清洁检查表 + 手机噪音 App + 温度计
2. 按区域逐项检查：地面、桌面、床、厕所、垃圾桶
3. 测量接待区温度与噪音
4. 发现不合规立即标记（红笔圈出）
5. 通知清洁工即时整改
6. 表单签字 + 存档

### 步骤 4：MSDS 档案与化学品标签（2 小时）
1. 为 5 种化学品（IPA、漂白水、洗手液、搓手液、消毒片）编写 MSDS
2. 格式：名称、CAS 号、危害分类、急救措施、储存要求、废弃方式
3. 在化学品瓶贴 3 层标签：名称 + 浓度 + 危险符号
4. 装订 MSDS 册，放清洁间显眼位置
5. 列出紧急联系号码（999、毒物控制中心）

## 六、常见错误与修正

| 错误 | 修正 |
|------|------|
| 漂白水未稀释直接用 | 1:10 稀释 |
| IPA 靠近明火 | 远离插座 / 煮水壶 |
| MSDS 放清洁间外 | 贴清洁间显眼位置 |
| 巡检表未签字 | 立即签字补交 |
| 锐器投一般垃圾桶 | 改投锐器盒 + 登记 |
