# 工作单 1：婴幼儿评估与家长沟通（含安抚技巧）

## 一、任务说明 / Task Brief

学员需为一名 0–6 岁婴幼儿（由家长陪同）完成推拿服务前的全部准备工作，包括身份核对、健康史采集、知情同意、体位安置与安抚。

## 二、所需工具 / Required TEM

- 推拿床 / 婴儿换洗台
- 病史采集表（KK-01-FORM-A）
- 知情同意书（KK-01-FORM-B）
- 体温计、电子秤、皮肤温度计
- 婴儿油 / 滑石粉（皮肤敏感测试用）
- 玩具 / 安抚奶嘴
- 干净毛巾、一次性床单
- 洗手液、70% 酒精、一次性手套（备用）

## 四、安抚技巧速查 / Soothing Tips

| 情境 | 技巧 |
|------|------|
| 婴儿哭闹 | 家长怀抱+轻拍背；使用白噪音；嗅妈妈的衣物 |
| 幼儿抗拒 | 先示范在玩偶身上；让小儿摸推拿师的手；游戏化 |
| 家长焦虑 | 详尽解释每步；展示典籍图谱建立信任 |
| 啼哭超过 30 秒 | **立即停止**，转家长安抚后再评估是否续做 |

## 五、家长沟通话术示例

- "妈妈您好，今天宝宝看起来精神不错。我们今天来做一次小儿推拿。它就像给宝宝的经络做温柔的'梳理'，帮助气血循环。"
- "宝宝可能会觉得有点放松想睡觉，皮肤会稍微有点红，这都是正常的。"
- "如果您看到宝宝不舒服或哭得厉害，请随时叫停，没关系的。"
- "推拿不能替代医院的治疗。如果宝宝有发烧、抽搐、严重腹泻这些情况，一定要先去医院。"
