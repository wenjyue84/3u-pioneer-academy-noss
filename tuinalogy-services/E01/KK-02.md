# 工作单 2：执行常见小儿推拿处方

**实操时数：** 152 小时

## 一、任务说明 / Task Brief

学员在导师监督下，针对一名经评估合格的婴幼儿，依其辨证执行经典处方。本工作单覆盖 4 个核心处方：清天河水、推三关、退六腑、揉板门，并示范 2 个综合处方（消化不良 / 风寒感冒）。

## 二、所需工具

- 推拿床 / 婴儿换洗台 / 家长椅
- 婴儿油 / 滑石粉 / 凉水（清天河水蘸水用）/ 葱姜水（推三关蘸用）
- 干净小毛巾、一次性床单
- 计时器 / 节拍器（200 次/分参考）
- 玩具、安抚奶嘴
- 病史采集表（已完成 KK-01）
