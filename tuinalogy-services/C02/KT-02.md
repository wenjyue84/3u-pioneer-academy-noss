# 作业单 2：八大手法与全身推拿执行

**对应资料单：** KP-02

## 一、说明
本作业巩固八大手法理论。独立闭书完成。满分 100 分，及格 ≥ 70 分。

## 二、题目

### A. 配对（10 题 × 2 分 = 20 分）
将手法名称与定义配对：

| 序号 | 手法 | 定义编号 |
|---:|------|:------:|
| 1 | 推 (Tuī) |  |
| 2 | 拿 (Ná) |  |
| 3 | 按 (Àn) |  |
| 4 | 捏 (Niē) |  |
| 5 | 揉 (Róu) |  |
| 6 | 捻 (Niǎn) |  |
| 7 | 摩 (Mó) |  |
| 8 | 拍 (Pāi) |  |

定义：
A. 圆周轨迹皮肤不滑动
B. 单手或双手按方向直线推动
C. 拇食指对指搓捻指趾
D. 虚掌或空拳叩击
E. 拇指与四指相对捏拿肌腹
F. 拇指 / 掌根 / 肘垂直按压
G. 拇食指捏皮肤推进（如捏脊）
H. 全掌环转抚摩，皮肤滑动

**额外 4 分：** 写出"持久、有力、均匀、柔和、深透、节律"的口诀来源。

### B. 选择（10 题 × 3 分 = 30 分）
9. 八大手法共同要求的"六字诀"**不包含**：A) 持久　B) 有力　C) 均匀　D) 急促
10. 摩法与揉法的最大区别在于：A) 力度　B) 速度　C) 皮肤是否滑动　D) 部位
11. 拍法应使用：A) 实掌　B) 虚掌或空拳　C) 拳头硬背　D) 指尖
12. 拿法不可使用：A) 指腹　B) 指甲　C) 拇指　D) 食指
13. 按法每穴持续应：A) 1 秒　B) 3–10 秒　C) 30 秒　D) 1 分钟
14. 摩腹一般方向为：A) 顺时针　B) 逆时针　C) 双向　D) 上下
15. 全身推拿标准顺序：A) 仰 → 俯　B) 俯 → 侧 → 仰　C) 侧 → 俯 → 仰　D) 仰 → 侧 → 俯
16. 捏脊一般沿：A) 任脉　B) 督脉　C) 胆经　D) 胃经
17. 紧急情况下首先：A) 继续治疗　B) 停手并评估　C) 加重力度　D) 离开房间
18. 客户出现晕厥应：A) 让其坐起　B) 平卧并抬高下肢　C) 给水喝　D) 拍打面颊

### C. 简答（5 题 × 6 分 = 30 分）
19. 列出八大手法的力度、速度、节奏、深度调控原则。
20. 详述全身推拿俯卧位的操作顺序（至少 6 步）。
21. 写出 5 项配穴原则。
22. 列出客户反应观察的 6 项指标与正常 / 异常标准。
23. 描述晕厥的处置流程（至少 5 步）。

### D. 综合（共 20 分）
**案例：** 王女士，38 岁，主诉颈肩僵硬伴头痛，工作压力大。已确认无禁忌，要求 60 分钟全身推拿。

(a) 选择重点手法组合并说明理由（5 分）
(b) 列出针对头痛的远近配穴（5 分）
(c) 说明力度与节奏选择（5 分）
(d) 写出 3 项需特别监测的客户反应（5 分）

## 答案要点
- A: 1)B 2)E 3)F 4)G 5)A 6)C 7)H 8)D；口诀来源：传统中医推拿基本功要求
- B: 9)D 10)C 11)B 12)B 13)B 14)A 15)B 16)B 17)B 18)B
- 19) 力度由轻至重循序；速度按手法 30–200/min；节奏均匀；深度从浅至深循序
- 20) 背部督脉膀胱经 → 肩颈拿按 → 腰骶揉按 → 臀环跳 → 下肢后侧推拿揉拍 → 足底涌泉
- 21) 循经、远近、阴阳、上下、前后
- 22) VAS 0–10、呼吸平稳、面色红润、出汗微汗、肌张力放松、客户口头反馈
- 23) 停手 → 平卧 + 抬下肢 → 唤醒 → 测脉搏 → 必要时 999 → 记录
- 案例 (a) 拿肩井 + 揉风池 + 按合谷；理由：颈肩僵硬 + 头痛远近配穴
- (b) 远端：合谷、太冲；近端：风池、太阳、百会
- (c) 中至重力度（颈肩僵硬）+ 中速（90/min）；头部宜轻
- (d) 头晕（避免颈动脉受压）、面色（高压下苍白）、呼吸（紧张时急促）
