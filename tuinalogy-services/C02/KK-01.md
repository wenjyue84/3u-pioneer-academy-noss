# 工作单 1：服务前准备与客户定位

**对应理论：** KP-01 / KT-01

## 一、任务说明

学员须独立完成全身推拿服务前的全部准备工作：
1. 复核客户记录与同意书
2. 准备推拿床、铺巾与用品
3. 与客户确认偏好、时长与重点部位
4. 协助客户更衣并定位体位
5. 进行术前简短四诊复核

## 二、所需工具与材料 (TEM)

|------|------|
| 推拿床（可调高度） | 1 |

## 三、安全与职业操守

- 演练前导师确认推拿床稳固、地面防滑、急救箱齐全
- 同伴互练须签署模拟同意书；异性配对须有第三方在场
- 学员着装：制服、工作鞋、修剪指甲、洗手消毒
- 客户隐私部位以毛巾遮蔽（draping）
- 推拿油 / 介质开封后须标注开封日期

## 四、操作步骤 (Step-by-Step Procedure)

### 步骤 1：客户记录复核（5 分钟）
1. 取出客户档案（电子或纸本）
2. 复核：上次服务摘要、健康史、过敏史、知情同意有效期
3. 留意红旗征
4. 准备本次服务记录表（页眉填日期、推拿师签名）

### 步骤 2：推拿床准备（10 分钟）
1. 调整推拿床高度（推拿师自身手肘平推拿面为宜）
2. 检查床稳固性、面部圈是否清洁
3. 铺一次性大铺巾覆盖整床
4. 摆放靠枕：俯卧用（胸下、踝下）；仰卧用（膝下）
5. 备浴巾在床尾以便覆盖客户

### 步骤 3：用品摆放（5 分钟）
1. 推拿油倒入小杯（避免直接用瓶接触客户）
2. 爽身粉倒入小托盘
3. 毛巾叠好放推车上层
4. 计时器静音模式置于客户视线外
5. 确认温水杯、纸巾备齐

### 步骤 4：客户接待（5 分钟）
1. 起立微笑迎接，使用适当称谓
2. 引导至咨询桌就座
3. 简短确认偏好（KP-01 §1）：
   - 期望、过敏、压力承受、偏好/避开部位、性别偏好
4. 确认服务时长与重点部位
5. 客户签署本次服务同意书

### 步骤 5：术前四诊复核（5 分钟）
1. **望** — 面色、神色、姿势
2. **闻** — 呼吸、声音
3. **问** — 自上次服务后变化（睡眠、饮食、二便、新症状）
4. **切** — 简短脉诊 + 重点部位触诊压痛 / 张力
5. 记录于今日服务表

### 步骤 6：客户更衣与体位定位（5 分钟）
1. 引导客户至更衣区，提供衣袍
2. 提醒客户除去金属饰品、手机、贵重物
3. 客户更衣完毕回推拿室
4. 协助客户上床（俯卧 / 侧卧 / 仰卧 / 坐位 — 按顺序起步）
5. 用浴巾覆盖客户隐私部位
6. 询问体位是否舒适，靠枕是否合适

### 步骤 7：最终检查
1. 室温 22–25°C 确认
2. 噪音 < 50 dB
3. 灯光柔和暖色
4. 推拿油已加温（手心试温）
5. 客户表示准备就绪

> ✅ **完成 → 进入 KK-02 全身推拿执行**

## 六、常见错误与修正

| 错误 | 修正 |
|------|------|
| 未试推拿床稳固即铺巾 | 先摇动确认 |
| 推拿油直接瓶口接触客户 | 改用小杯分装 |
| 未询问性别偏好就开始 | 必须术前询问 |
| 客户隐私未遮蔽 | 立即用浴巾覆盖 |
| 体位转换扶持不足导致客户失衡 | 双手扶持，慢动作 |
| 同意书过期未续签 | 服务前必须更新 |
