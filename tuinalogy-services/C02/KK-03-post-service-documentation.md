# 工作单 3：服务后处置与记录

**对应理论：** KP-03 / KT-03

## 一、任务说明

完成全身推拿后，学员须独立执行：
1. 客户服务后状态评估
2. 离场流程（休息、补水、起身）
3. 给予自我护理建议（口头 + 书面）
4. 处置服务后不适
5. 必要时启动转介流程
6. 完整更新客户记录
7. 安排下次预约

## 二、所需工具

| 项目 | 数量 |
|------|------|
| 温水 / 养生茶 | 充足 |
| 客户记录表 | 1 |
| 自我护理卡（书面） | 1 |
| 转介表 + 转介信模板 | 各 1 |
| 镜子 | 1 |
| 血压计、血糖仪（备用） | 1 |
| 急救箱 | 1 |
| 推荐机构清单 | 1 |
| 预约本 / 系统 | 1 |

## 三、安全与职业操守

- 客户身体仍处于副交感优势期，须避免突然起身
- 异常生命体征 → 暂缓离场 + 评估
- 自我护理建议须以书面卡交予客户避免遗忘
- 严守 PDPA 2010；记录须立即归档不可外露

## 四、操作步骤

### 步骤 1：服务后状态评估（5 分钟）

客户仍卧床（步骤承接 KK-02 收式）。

1. **意识 / 神色** — 视诊
2. **VAS** — "现在疼痛 0–10 是几分？"（与术前比较）
3. **活动度** — 简单关节活动（如旋转颈、屈伸肘膝）
4. **情绪** — 询问 + 观察（是否有眼泪、焦虑）
5. **不适** — "现在哪里不舒服吗？"
6. 如有异常（头晕、心悸） → 测血压脉搏 → 延长休息

> ✅ 全部正常 → 进入步骤 2；有异常 → 进入步骤 7

### 步骤 2：离场流程（5–10 分钟）

1. **静卧休息 5–10 分钟** — 用浴巾覆盖，关掉强光
2. **缓慢起身**：
   - 侧卧 30 秒
   - 坐于床边 30 秒（双脚踏地）
   - 站立扶床缘 30 秒
3. **询问**："感觉如何？头晕吗？"
4. **补水** — 提供温水 / 养生茶 200–300ml
5. **整理仪容** — 提供镜子、卫生纸
6. **引导更衣** — 进入更衣区

### 步骤 3：服务后简短咨询与自我护理建议（5 分钟）

口头讲解 + 交予书面卡，重点：

| 类别 | 建议 |
|------|------|
| 饮食 | 30 分钟内不进食；当日清淡 + 多温水；避酒精咖啡 |
| 活动 | 当日避剧烈运动；推荐散步、八段锦 |
| 洗浴 | 2 小时后温水淋浴；避桑拿 |
| 保暖 | 避空调直吹；颈腰加衣 |
| 复诊 | 视目的（保健 2 周 / 慢性 1 周） |
| 异常 | 出现持续疼痛、瘀斑大、头晕 → 立即联络中心 |

### 步骤 4：处置服务后不适（如有）

| 情况 | 处置 |
|------|------|
| 肌肉酸痛 | 解释正常 24-48h 缓解；可热敷 |
| 轻微瘀斑 | 48h 后温敷；记录 |
| 嗜睡 | 静卧延长；勿驾车 |
| 情绪释放 | 安静陪伴 5-10 min；提供纸巾 |
| 头晕 | 平卧 + 测血压 + 必要时血糖 |
| 皮疹 | 清洁 + 冷敷；记录介质 |

### 步骤 5：转介（仅当指征出现时）

如存在转介指征（KP-03 §5.1）：

1. 向客户说明："建议您也咨询 XX 专业人员，理由是 ……"
2. 取得客户同意（口头 + 书面）
3. 填写转介表：日期、客户、症状摘要、推拿处置、转介理由
4. 推荐至少 2 个相关机构
5. 提供转介信（密封信封）
6. 客户记录登记
7. 7–14 天后追访结果

### 步骤 6：客户记录更新（10 分钟）

逐项填写本次服务记录（参 KP-03 §6.1）：

- [ ] 日期、时段
- [ ] 推拿师姓名 / 编号
- [ ] 服务时长
- [ ] 主诉 (术前)
- [ ] 四诊复核摘要
- [ ] 推拿模式：全身
- [ ] 体位顺序：俯 → 侧 → 仰
- [ ] 主要手法
- [ ] 重点部位 / 配穴
- [ ] 力度等级
- [ ] 客户反应 (服务中)
- [ ] 服务后评估（VAS 前后对比、活动度）
- [ ] 客户反馈 / 满意度
- [ ] 自我护理建议（标记已交付）
- [ ] 下次预约日期
- [ ] 异常事件 / 转介（如有）
- [ ] 推拿师签字

> 修改须划线 + 签名 + 日期；不可涂改液。

### 步骤 7：异常情况延长处置

如客户离场前仍有不适：
1. 延长静卧至少 30 分钟
2. 监测生命体征每 10 分钟
3. 必要时通知客户家属来接
4. 严重时拨 999 + 转介
5. 24 小时内填 Incident Report

### 步骤 8：预约与送别（3 分钟）

1. 翻预约本/系统，依建议复诊频率推荐日期
2. 客户确认后写入预约卡
3. 感谢客户："谢谢您今天的配合"
4. 提醒带走自我护理卡 / 预约卡
5. 引导至门口微笑送别

## 六、常见错误与修正

| 错误 | 修正 |
|------|------|
| 客户立即起身导致头晕 | 严格三步法 |
| 提供冰水而非温水 | 改温水 / 茶 |
| 自我护理建议仅口头无书面 | 必须书面卡 |
| 客户记录留空 / 字段缺失 | 服务后立即填写不留隔日 |
| 涂改液修改记录 | 改为划线签名日期 |
| 转介未取得同意 | 必须口头 + 书面同意 |
| 预约未与客户确认就写入 | 须客户口头同意 |
