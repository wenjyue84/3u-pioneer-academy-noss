# 表现评估 / Performance Assessment (PA)


## 评估说明

- 本评估为 C02 综合实操考核，覆盖 KK-01、KK-02、KK-03 全部技能
- 学员独立完成 60 分钟全身推拿全流程（术前 + 服务 + 服务后）
- 由 1 名主考评估员 (PB) + 1 名观察员评估
- 模拟客户由资深学员 / 标准化客户 (SP) 担任
- 满分 100 分，及格 ≥ 70 分
- 不及格者经 14 天再训练后可补考一次

## 评估目标

- 与 NOSS C02 全部 3 项工作活动评估准则对齐
- 测试技能层次 P3（独立操作）至 P4（熟练应用）
- 测试态度 A2–A3（专业、稳定、富同理心）

## 评估场地与设备

- 模拟推拿室一间（22–25°C、< 50 dB、暖色灯）
- 推拿床 + 全套用品（KK-01 §2-3 列示）
- 模拟客户 1 名（健康成年，已签同意书）
- 计时器 1 个
- 评分表 + 录像设备

---

## 自动 Fail 条件（任一即不及格，无论总分多少）

1. 推拿禁忌区域受力（孕妇腰骶、急性炎症区、骨折部位等）
2. 客户晕厥未正确处置
3. 客户严重不适未停手或减压
4. 异性推拿无第三方在场或违反同意范围
5. 客户记录涂改液 / 字段大幅缺失（< 50%）
6. 严重违反 PDPA（外泄客户资料）
7. 操作中接听私人电话 / 查看手机
8. 严重伤害客户（瘀伤大、皮肤破损）

## 情境口试题（任选 1 题，纳入 B5.3 / C4）

1. 客户在背部推拿时突然冒冷汗、面色苍白，你如何处置？
2. 客户主诉本次力度过重导致术后大瘀斑，你如何回应？
3. 客户希望你"治好"她的颈椎间盘突出，你如何回应？
4. 客户出现持续夜间疼痛 + 体重下降，你的下一步？
5. 异性客户要求推拿胸腹，你如何处理？

**评分参考：**
- 1 → 立即停手 + 平卧抬下肢 + 测脉 + 999
- 2 → 致歉 + 评估 + 48h 后温敷建议 + 下次力度调整 + 记录
- 3 → 不承诺治愈 + 推拿可缓解症状但需医师诊断 + 转介
- 4 → 红旗征 → 必须转介医师
- 5 → 拒绝胸腹推拿 + 提议同性推拿师 / 限制部位 + 第三方在场
