1. 评估客户服务后状态
2. 应用出院 / 离场政策
3. 提供专业的服务后建议（饮食、活动、洗浴、避风、复诊）

7. 遵守 MOH T&CM 伦理与 PDPA 2010

## 1. 服务后客户状态评估 (Post-service Assessment)

服务结束后立即进行简短、系统的状态评估，确保客户安全离场。

| 评估项目 | 方法 | 正常范围 | 异常处置 |
|---------|------|---------|---------|
| 意识 / 神色 | 视诊 + 简短问答 | 清晰、放松 | 嗜睡严重→延长休息 |
| 疼痛 (VAS) | 0–10 量表 | 较术前下降 ≥ 2 | 上升→评估并记录 |
| 活动度 (ROM) | 简单关节活动 | 改善 | 无改善 / 受限→记录 |
| 情绪 | 询问 + 观察 | 平静 / 愉悦 | 哭泣 / 焦虑→陪伴并记录 |
| 生命体征 | 必要时测脉、血压 | 稳定 | 异常→延后离场 / 转介 |
| 不适 | 主动询问 | 无 | 头晕、恶心→见 §4 |

### 1.1 客户反馈记录
- 喜欢 / 不喜欢的部位与手法
- 力度感受（太轻 / 适中 / 太重）
- 整体满意度（5 分制）

## 2. 出院 / 离场政策 (Discharge Policy)

### 2.1 标准离场流程

1. **休息 5–10 分钟** — 客户仍躺床上，覆盖薄被避风
2. **缓慢起身** — 由侧卧 → 坐位 → 站立，分三步进行
3. **补水** — 提供温水 / 养生茶 200–300ml（避免冷水）
4. **整理仪容** — 协助穿衣、整理头发，提供镜子
5. **服务后简短咨询** — 复述自我护理建议
6. **预约下次服务** — 视情况安排
7. **送别** — 微笑致谢，引导至门口

### 2.2 不可立即离场的情形
- 头晕、心悸未缓解
- 肌肉无力、站立不稳
- 情绪未平复
- 生命体征异常

> 如客户驾车前来，建议至少休息 15 分钟方可上路。

## 3. 服务后建议 (Post-service Advice)

### 3.1 饮食建议
- 服务后 30 分钟内不进食
- 当日饮食清淡，避免油腻、辛辣、生冷
- 多饮温水（当日 1.5–2L），帮助代谢
- 避免酒精、浓茶、咖啡（24 小时内）

### 3.2 活动建议
- 当日避免剧烈运动、重体力劳动
- 鼓励轻缓散步、八段锦、太极
- 充足睡眠（7–8 小时）

### 3.3 洗浴建议
- 服务后 2 小时内不洗澡（特别是冷水澡）
- 推荐温水澡（37–40°C），淋浴优于盆浴
- 避免桑拿、汗蒸（当日）

### 3.4 避风保暖
- 服务后毛孔开放，避免吹空调、电扇直吹
- 颈、腰、关节处加衣保暖
- 雨天出门戴帽 / 撑伞

### 3.5 复诊频率
| 目的 | 建议频率 |
|------|---------|
| 一般保健 | 每 2 周 1 次 |
| 慢性劳损调理 | 每周 1–2 次，连续 4–6 周 |
| 急性症状缓解 | 隔天 1 次，连续 3–5 次 |
| 季节调理 | 每季 3–5 次 |

> 所有建议须以书面单（Aftercare Card）交予客户。

## 4. 服务后不适处置 (Adverse Effects Management)

### 4.1 肌肉酸痛 (Soreness)
- **原因：** 推拿引发的微小肌纤维代谢
- **处置：** 24–48 小时内自行缓解；可热敷
- **持续 > 72 小时：** 联络客户随访，评估力度是否过重

### 4.2 轻微瘀斑 (Petechiae / Bruising)
- **原因：** 力度较重或客户毛细血管脆弱
- **处置：** 48 小时后温敷；记录部位
- **大面积或反复出现：** 转介医师排查凝血障碍

### 4.3 嗜睡 / 疲倦 (Drowsiness)
- **原因：** 副交感神经活化，正常反应
- **处置：** 充足休息；勿驾车或操作机械
- **超过 24 小时：** 评估补充体能

### 4.4 情绪波动 (Emotional Release)
- **原因：** 身体放松后情绪释放
- **处置：** 安静空间陪伴 5–10 分钟；提供纸巾与温水
- **严重抑郁倾向：** 转介心理咨询

### 4.5 头晕 / 恶心 (Dizziness / Nausea)
- **原因：** 血压改变、低血糖、起身过快
- **处置：** 平卧、补充糖水（如非糖尿病）；测血压
- **持续：** 转介医师

### 4.6 皮肤过敏 (Allergic Skin Reaction)
- **原因：** 推拿油 / 介质过敏
- **处置：** 立即清洁、冷敷；记录介质成分
- **严重：** 抗组胺药 / 转介医师

## 5. 转介指征与流程 (Referral)

### 5.1 转介指征 (Referral Indications)
按 NOSS 与 MOH T&CM 守则，下列情形必须转介：

1. 症状未改善（连续 3–5 次后）
2. 出现红旗征 (red flags)：
   - 不明原因体重下降
   - 持续夜间疼痛
   - 进行性神经症状（麻木加重、肌力下降）
   - 不明发热
   - 大小便失禁
3. 客户主动要求
4. 紧急情况（晕厥、胸痛等）
5. 超出推拿师能力范围
6. 客户家属 / 第三方要求

### 5.2 转介流程（按公司 SOP）
1. 向客户说明转介必要性
2. 取得客户同意
3. 填写转介表（Referral Form）
4. 推荐至少 2 个相关机构（西医 / TCM 医师 / 物理治疗）
5. 提供转介信（含病情摘要、推拿处置纪录）
6. 客户记录登记转介日期与去向
7. 7–14 天后追访结果

### 5.3 推荐机构清单（由各中心维护）
- 政府医院（Hospital Kerajaan）
- 私人诊所（Klinik Swasta）
- 注册 TCM 医师（MOH T&CM 注册名单）
- 物理治疗中心
- 心理咨询师

- 定期备份（建议每周）

## 7. MOH T&CM 伦理 (Ethics)

参照《T&CM Practitioners Code of Ethics 2007》：

1. **客户优先 (Client first)** — 不为业绩而过度推销
2. **诚实 (Honesty)** — 不夸大疗效，不承诺"治愈"
3. **保密 (Confidentiality)** — 严守 PDPA 2010
4. **能力范围 (Scope of competency)** — 超能力范围必转介
5. **不诋毁同业 (No badmouthing)** — 尊重其他从业者
6. **持续教育 (CPD)** — 每年 ≥ 20 学时
7. **拒绝歧视** — 不论种族、性别、宗教、社会阶层

## 8. 小结

服务后管理是全身推拿服务的最后但同等重要的环节。从离场流程、自我护理建议、不适处置到转介与记录更新，每一步都体现专业素养。完整的服务后管理不仅保障客户安全，也建立中心声誉与客户忠诚度。
