# 工作单 2：客户咨询与中医四诊

**对应理论：** KP-02 / KT-02

## 一、任务说明

在模拟咨询室中：
1. 完成客户期望与健康史采集；
2. 实施完整中医四诊（望、闻、问、切）；
3. 取得客户书面知情同意；
4. 将咨询信息录入客户记录。

## 二、所需工具与材料 (TEM)

| 项目 | 数量 |
|------|------|
| 病史采集表（空白） | 5 |
| 知情同意书（空白） | 5 |
| 解剖与生理图表 | 1 |
| 经络穴位人体模型 | 1 |
| 听诊器 | 1 |
| VAS 疼痛量表卡 | 5 |
| 计时器 | 1 |
| 笔 | 5 |

## 三、安全与职业操守

- 异性配对须有第三方在场
- 切诊触碰客户身体须事先征得口头同意
- 涉及隐私部位（如腹部、腰骶）一律不在 C01 实操中操作
- 全程录像须取得双方同意

## 四、操作步骤

### 步骤 1：开场与说明（5 分钟）
1. 自我介绍
2. 说明咨询目的与时长
3. 强调保密承诺
4. 取得客户口头同意开始

### 步骤 2：信息收集方法选择
1. 出示预设病史采集表
2. 解释每节内容
3. 边问边在表格上记录
4. 笔记本记录客户原话与情境

### 步骤 3：客户期望访谈
询问以下 5 项 NOSS 列明期望：
- 缓解症状？哪些症状？
- 整体疗法？身心方面？
- 改善生活质量？睡眠/活动？
- 减少西医依赖？
- 自我护理建议？

### 步骤 4：健康信息采集
| 类别 | 提问示例 |
|------|----------|
| 现病史 | "您目前哪里不适？多久了？" |
| 既往史 | "过去三年是否住院或动手术？" |
| 家族史 | "家中是否有糖尿病、心脏病？" |
| 用药史 | "目前服用任何西药或中药？" |

### 步骤 5：中医四诊操作

#### 5.1 望诊 (5 分钟)
- 观察神：眼神是否清亮？
- 观察色：面色（红/黄/白/青/黑）？
- 观察形：体型（瘦/匀称/肥胖）
- 观察态：步态、坐姿对称？
- 记录：望诊三句话总结

#### 5.2 闻诊 (3 分钟)
- 听语声：清亮 / 低弱 / 急促
- 听呼吸：均匀 / 粗短 / 喘
- 闻气味：口气、汗气（不超距）
- 记录：闻诊一句话总结

#### 5.3 问诊 (10 分钟)
按"十问"提示询问：
1. 寒热
2. 汗
3. 头身（疼痛部位、性质）
4. 二便
5. 饮食胃口
6. 胸腹（不便者跳过）
7. 耳目
8. 睡眠
9. 旧病
10. 用药

#### 5.4 切诊 (5 分钟)
- 征得口头同意
- 切寸口脉（左右各 30 秒）
- 触诊：按压肌肉张力（以肩颈为例）
- 评估关节活动度（颈部前屈/后伸/侧屈/旋转）

### 步骤 6：知情同意取得
1. 出示知情同意书
2. 朗读全文
3. 解释每条款
4. 回答客户疑问
5. 客户签字 + 日期
6. 推拿师签字 + 日期
7. 见证人签字（如适用）
8. 副本交客户，原件入档

### 步骤 7：信息录入客户记录
1. 全部信息当日（24 小时内）录入
2. 按客户记录模板填写
3. 修改方式：划线 + 签名 + 日期
4. 录入后档案上锁
