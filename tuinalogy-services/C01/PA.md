# 表现评估 / Performance Assessment (PA)


## 评估说明

- 综合实操评估，覆盖 C01 全部 4 项工作活动
- 学员一对一面对模拟客户（持牌评估员或角色扮演者）
- 全程录像作为 PB 与 PPD 复核证据
- 满分 100 分，及格 ≥ 70 分
- 不及格者可补考一次

## 评估对象

- 已完成 PM-teori、PM-amali、KK-01 至 KK-04、KA 的学员

## 评估场地与设备

| 项目 | 说明 |
|------|------|
| 模拟咨询室 | 符合 KP-01 §1 标准 |
| 模拟客户 | 持牌评估员 / 角色扮演者 |
| 客户档案夹（空白） | 1 |
| 信息表 / 同意书 / 转介表 | 各 2 |
| 解剖图、经络模型 | 各 1 |
| VAS、温度计、噪音计 | 各 1 |
| 录像设备 | 1 套 |

## 评估任务

学员须于 3 小时内独立完成以下完整流程：

### 任务 1：咨询区准备（15 分钟）
按 KK-01 检查并设置咨询区。

### 任务 2：客户接待与登记（30 分钟）
- 礼貌迎接
- 信息收集
- 身份核实
- 客户记录建立

### 任务 3：客户咨询与四诊（45 分钟）
- 期望访谈
- 健康史采集
- 中医四诊
- 知情同意取得

### 任务 4：适应症 / 禁忌评估（30 分钟）
- 分类判断
- 决策记录
- 转介流程演示（按案例需要）

### 任务 5：方案制定与口头汇报（45 分钟）
- 模式选择
- 方案撰写（11 项要素）
- 书面同意签署
- 客户记录归档
- 口头汇报方案

### 任务 6：场地清理 + 档案上锁（15 分钟）

## 关键失败 (Critical Failure) 项目

下列任一情况直接判 **不及格**，无论总分：

1. 对禁忌症客户施行推拿
2. 未取得知情同意即开始任何身体接触
3. 在演练中泄露客户隐私（如对外讲述）
4. 紧急情况未拨打 999 或离开客户
5. 异性配对违规（无第三方在场 + 触碰禁区）
6. 档案未上锁离场超过 5 分钟

### 案例 B：含注意事项
王太太，30 岁，怀孕 16 周，腰酸。预期：调整方案 + 避禁穴。

### 案例 C：含禁忌
刘女士，55 岁，左下肢骨折术后 2 周。预期：果断转介。

### 案例 D：紧急情况
赵先生，60 岁，突发胸痛 + 冷汗。预期：立即 999 + 不离开。

> 评估员每名学员随机抽取 1 个案例。
