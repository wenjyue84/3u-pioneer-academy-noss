## 学习成果

完成本资料单后，学员应能：
1. 区分推拿适应症 (Indication) 与注意事项 (Precaution)
2. 识别排除性的禁忌症 (Contraindication)
3. 理解转介政策与流程
4. 熟悉社区医疗资源以备转介

## 1. 推拿适应症 (Indications)

推拿疗法可作为以下情况的辅助/替代调理方式：

### 1.1 肌肉骨骼系统类
| 症状 | 中文 | 推拿目标 |
|------|------|---------|
| Muscle ache or pain | 肌肉酸痛 | 缓解疼痛、放松紧张 |
| Muscle stiffness | 肌肉僵硬 | 改善柔韧性 |
| Limb numbness | 肢体麻木 | 改善末梢循环 |
| Joint movement restriction | 关节活动受限 | 增加 ROM |
| Joint pain | 关节疼痛 | 缓解疼痛、消肿 |
| Sore back | 腰背酸痛 | 调理腰背筋膜 |
| Sciatica | 坐骨神经痛 | 放松梨状肌、减压 |
| Aching muscles | 肌肉酸痛 | 排除乳酸堆积 |

### 1.2 全身性
- 低能量 (Low energy) — 改善气血循环、提升精力

### 1.3 压力或情绪问题相关
| 症状 | 中文 | 推拿调理 |
|------|------|---------|
| Insomnia | 失眠 | 头部、足底放松 |
| Difficulty focusing | 注意力难集中 | 头颈推拿 |
| Headache | 头痛 | 太阳、风池等穴 |
| Tension headaches | 紧张性头痛 | 颈肩部解压 |

## 2. 推拿注意事项 (Precaution)

注意事项是指推拿可能进行但需特殊调整或推迟的情况：

| 情况 | 处理 |
|------|------|
| 饭后未满 3 小时 (Full stomach < 3 hrs) | 推迟疗程；避免腹部推拿 |
| 怀孕 (Pregnancy) | 避免腹部、腰骶部及合谷、三阴交等堕胎穴；妊娠初期 (< 12 周) 与晚期 (> 32 周) 不建议 |
| 高龄 (> 65 岁) 或骨质疏松 | 力度减轻；避免按压脊柱 |
| 高血压控制不佳 | 避免头部强力刺激 |
| 月经期 | 避免腹部及腰骶部强刺激 |

## 3. 推拿禁忌症 (Contraindication)

禁忌症是**绝对不可施行**推拿的情况，违反则可能造成严重伤害或法律责任。

### 3.1 NOSS 列明的禁忌症
| 禁忌情况 | 中文 | 风险 |
|---------|------|------|
| Open bleeding wound | 开放性出血伤口 | 感染、出血加重 |
| All kinds of fracture | 所有种类骨折 | 移位、二次伤害 |
| Areas with obvious skin problems | 皮肤明显异常区域 | 感染扩散 |
| Chest pain | 胸痛 | 可能掩盖心脏急症 |
| Breathing difficulty | 呼吸困难 | 可能为肺栓塞、哮喘急性期 |
| Swollen joints and body area | 关节及身体肿胀区域 | 加重炎症 |
| Woman's lower stomach and back areas (sensitive) | 女性下腹及背部敏感区域 | 月经紊乱、流产风险 |

### 3.2 临床建议补充禁忌
- 急性传染病期（如肺结核、麻疹）
- 恶性肿瘤局部
- 严重心脑血管疾病（不稳定心绞痛、近期中风）
- 严重出血性疾病（血友病、低血小板）
- 精神疾病急性发作期
- 醉酒或药物影响中

## 4. 适应症 vs 禁忌症 vs 注意事项 — 决策表

| 类别 | 含义 | 推拿决定 |
|------|------|---------|
| 适应症 | 推拿可有效改善 | ✅ 进行 |
| 注意事项 | 需调整方法/时机 | ⚠️ 调整后进行 |
| 禁忌症 | 绝对不可推拿 | ❌ 拒绝并转介 |

## 5. 转介政策 (Referral Policy)

### 5.1 转介指征 (Referral Indications)
按 NOSS 规定，以下情况须转介：

1. **症状风险 (Risk of presenting problem)** — 症状严重或持续恶化
2. **客户要求 (Client request)** — 客户主动要求转介
3. **紧急情况 (Emergency situation)** — 突发胸痛、晕厥、严重外伤
4. **能力限制 (Tuinalogist or centre's ability limitation)** — 推拿师或中心无法满足客户需求
5. **第三方要求 (Request from family/friends/parties)** — 家属、朋友或相关方提出

### 5.2 转介流程
```
客户出现转介指征
        ↓
向客户解释转介必要性与目的
        ↓
取得客户口头/书面同意
        ↓
填写转介表 (Referral Form)
        ↓
联系/介绍至适当机构
        ↓
记录转介详情于客户记录
        ↓
追踪转介结果（可选）
```

### 5.3 转介对象
- 西医诊所、医院（紧急或西医诊断需要）
- 中医诊所（针灸、中药调理）
- 物理治疗师 (Physiotherapist)
- 整骨/脊医 (Chiropractor)
- 心理咨询师
- 其他持牌 T&CM 从业者

### 5.4 社区资源清单 (Community Resource List)
中心应维护一份**Tuinalogy 与其他医疗机构名单**，包含：

| 项目 | 内容 |
|------|------|
| 机构名称 | 全名与简称 |
| 地址 | 完整地址 |
| 联系电话 | 主线 + 紧急 |
| 服务项目 | 专长领域 |
| 营业时间 | 包括周末与公假 |
| 联系人 | 推荐医师/接洽人 |

## 6. 安全与职业操守

- **明确告知风险** — 客户有权知晓推拿不能治愈某些情况
- **不可超越执业范围** — 不诊断疾病、不开处方、不替代医疗
- **紧急情况优先** — 立刻拨打 999 而非自行处理
- **保留书面记录** — 转介决定与客户回应须详细书面记录

## 7. 小结

正确识别适应症、注意事项与禁忌症是推拿安全性的基石。推拿师不应贪图业绩而冒险施治；遇到禁忌或能力范围外情况，须果断转介至合适医护人员，方为专业之道。
