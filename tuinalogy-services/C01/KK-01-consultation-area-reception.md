# 工作单 1：模拟咨询区设置与客户接待

**对应理论：** KP-01 / KT-01

## 一、任务说明

在模拟咨询室中：
1. 按 KP-01 §1 设置符合规范的咨询区域；
2. 完成一次完整的客户接待流程；
3. 收集客户个人资料并核实身份；
4. 建立客户记录档案。

## 二、所需工具与材料 (TEM)

| 项目 | 数量 |
|------|------|
| 模拟咨询室 | 1 间 |
| 接待桌椅 | 1 套 |
| 屏风 | 1 张 |
| 温度计 | 1 |
| 噪音计（手机 App 可代） | 1 |
| 客户信息表（空白） | 5 |
| 客户记录档案夹 | 5 |
| 身份证 / 护照（学员模拟） | 5 |
| 急救箱 + 灭火器 | 各 1 |

## 三、安全与职业操守

- 演练前由导师确认咨询室通道畅通、急救箱齐全
- 扮演客户的学员须签署模拟同意书
- 异性配对须有第三方在场
- 演练后所有模拟记录立即碎纸销毁

## 四、操作步骤 (Step-by-Step Procedure)

### 步骤 1：咨询区准备就绪检查
1. 测量室温（应在 22–25°C）
2. 测量噪音（应 < 50 dB）
3. 检查灯光：开启暖色灯并调节亮度
4. 确认屏风/门帘到位（私密性）
5. 确认防滑地板干燥；急救箱、灭火器在指定位置
6. 桌面整洁；摆放欢迎卡 + 温水

> ✅ **检查表：** 见末尾 Checklist 1

### 步骤 2：迎接客户
1. 客户进门时立即起立、微笑
2. 正面问候："欢迎光临 / Selamat datang / Welcome, [称谓]"
3. 引导至咨询桌就座
4. 奉上温水或养生茶
5. 简介中心服务 (≤ 30 秒)

### 步骤 3：使用适当称谓
- 男性：先生 / Encik / Mr.
- 女性已婚：女士 / Puan / Mrs.
- 女性未婚：小姐 / Cik / Miss
- 拥有头衔者：拿督 (Dato')、拿汀 (Datin) 等

### 步骤 4：信息收集
1. 递上信息表 + 笔
2. 简短解释每项内容
3. 客户填写时在旁待命答疑
4. 不识字客户：员工口述代填

### 步骤 5：身份核实
1. 礼貌请客户出示 IC / 护照
2. 核对姓名、IC 号码与表单一致
3. 影印或扫描存档（取得同意后）
4. 立即交还原件

### 步骤 6：建立客户记录
1. 在档案夹外贴标签：编号 + 姓名（首字母）
2. 信息表归入档案夹
3. 创建电子记录（如使用 EMR）
4. 档案放入上锁档案柜，记录编号
5. 在登记簿中记录新档建立日期

### 步骤 7：客户欢送
1. 感谢客户配合
2. 提供下次预约/咨询安排
3. 引导至门口微笑送别

## 七、常见错误与修正

| 错误 | 修正 |
|------|------|
| 客户进门不起立 | 立即起立致歉 |
| 不询问称谓直接称"你" | 改用"先生/女士" |
| 未取得同意复印 IC | 须先告知用途并获允 |
| 档案不上锁 | 立即放入锁柜 |
| 未碎纸销毁草稿 | 立即销毁并记录 |
