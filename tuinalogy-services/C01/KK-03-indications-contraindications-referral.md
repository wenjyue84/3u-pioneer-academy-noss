# 工作单 3：识别适应症/禁忌症与转介流程

**对应理论：** KP-03 / KT-03

## 一、任务说明

按导师提供的客户案例：
1. 区分适应症 / 注意事项 / 禁忌症；
2. 决定是否进行推拿、调整方案或转介；
3. 完成转介表填写（如需转介）；
4. 在客户记录中记录决定。

## 二、所需工具与材料 (TEM)

| 项目 | 数量 |
|------|------|
| 客户案例卡（10 张） | 1 套/组 |
| 转介表（空白） | 5 |
| 社区医疗机构通讯录 | 1 |
| 客户记录档案夹 | 5 |
| 决策流程图（A3 张贴） | 1 |
| 笔 | 5 |

## 三、安全与职业操守

- 演练遇紧急案例（如胸痛模拟）须演示 999 拨打
- 转介须**取得客户同意**方可转出资料
- 禁忌症客户演练强调"果断拒绝并转介"
- 不可在演练中诋毁西医或其他 T&CM 同行

## 四、操作步骤

### 步骤 1：阅读案例卡（5 分钟/案例）
导师发放案例卡，每张含：
- 客户基本资料
- 主诉
- 健康史摘要
- 四诊结果

### 步骤 2：分类判断
按 KP-03 §4 决策表分类：

| 类别 | 行动 |
|------|------|
| 仅适应症 | ✅ 进行推拿 |
| 含注意事项 | ⚠️ 调整方案 |
| 含禁忌症 | ❌ 拒绝并转介 |

### 步骤 3：决策记录
在案例卡背面填写：
- 适应症列表
- 注意事项列表
- 禁忌症列表
- 决定：进行 / 调整 / 转介
- 理由（≥ 50 字）

### 步骤 4：调整方案演练
若有"注意事项"，演示如何调整：
- 例：饭后客户 → 推迟 30 分钟 + 避腹部
- 例：孕妇 → 选择孕产推拿、避禁穴

### 步骤 5：转介流程演练
若有"禁忌"或"转介指征"，按 KP-03 §5.2 流程演练：

```
1. 向客户口头解释转介必要性
2. 询问客户首选转介方向（西医/中医/物理治疗）
3. 取得客户口头同意
4. 填写转介表（详见步骤 6）
5. 提供 1–2 个适合机构（含联系方式）
6. 在客户记录中记录转介决定与机构
7. 询问客户是否愿意推拿中心追访结果
```

### 步骤 6：填写转介表 (Referral Form)
转介表必填项：

| 字段 | 说明 |
|------|------|
| 推拿中心信息 | 名称 + 地址 + 电话 |
| 推拿师姓名 + 注册号 | 持牌人 |
| 客户基本资料 | 姓名 + IC + 联系方式 |
| 转介日期 | DD/MM/YYYY |
| 主诉 | 一段文字 |
| 评估结果 | 四诊 + 适应/禁忌 |
| 转介原因 | 紧急 / 能力限制 / 客户要求 / 其他 |
| 建议机构名称 | 西医诊所 / 医院 / 中医师 |
| 推拿师签字 | 签 + 日期 |
| 客户同意签字 | 签 + 日期 |

### 步骤 7：紧急案例处理（含 999 拨打模拟）
紧急案例（突发胸痛、呼吸困难、晕厥）：
1. 立即停止任何咨询/推拿
2. 让客户平卧或半坐
3. 拨打 999（演练用模拟号码）
4. 报告：地点 + 客户状况 + 自身联系电话
5. 不离开客户身边
6. 待救护车到达
7. 事后填写 Incident Report
