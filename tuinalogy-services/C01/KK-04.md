**CU：** C01 推拿疗法服务咨询
**对应工作活动：** WA4 — 制定推拿疗法服务方案
**对应理论：** KP-04 / KT-04
**纸张颜色：** 蓝

**最后更新：** 2026-04-17

> ⚠️ **Pregnancy Contraindication** — GB-21 (肩井/Jianjing) mentioned in this document are forbidden during pregnancy at all trimesters per T&CM Act 2013 Section 28. Do NOT apply to pregnant clients. See `_reference/pregnancy-safety-reference.md`.


## 一、任务说明

为指定客户案例：
1. 选择适合的推拿模式；
2. 撰写完整推拿服务方案（≥ 10 项要素）；
3. 取得客户书面知情同意；
4. 实施记录保密与安全维护；
5. 向客户口头汇报方案。

## 三、安全与职业操守

- 方案不可承诺"治愈"
- 收费在方案中明确列出（透明）
- 方案签署后副本须当日交客户
- 档案柜由轮值员工上锁，钥匙记录在交班簿
- 涉及未成年须监护人共同签字

## 四、操作步骤

### 步骤 1：审阅前期资料 (5 分钟)
- 重读 KK-02 病史与四诊结果
- 重读 KK-03 适应症 / 禁忌评估
- 确认无遗漏

### 步骤 2：选择推拿模式
按 KP-04 §1.6 决策表：

| 客户主诉 | 优选模式 |
|---------|---------|
| 全身疲劳 | 全身推拿 |
| 运动恢复 | 运动推拿 |
| 颈肩腰痛 | 肌骨推拿 |
| 小儿厌食 | 小儿推拿 |
| 月经调理（非经期） | 女子推拿 |

### 步骤 3：撰写方案 (30 分钟)
按以下 11 项要素撰写：

#### 方案模板
```
1. 客户基本资料
   姓名 / IC / 年龄 / 性别 / 联系方式

2. 主诉与评估摘要
   现病史 + 四诊结果 + 评估指标（VAS、ROM）

3. 适应症确认
   列明本次推拿对应症状

4. 禁忌排除
   说明已排除的 7 项 NOSS 禁忌

5. 推拿模式
   全身 / 运动 / 肌骨 / 小儿 / 女子（择一）

6. 重点部位与手法
   - 部位：[头/颈/肩/背/上肢/下肢/胸]
   - 八大手法：推/拿/按/捏/揉/捻/摩/拍 之组合
   - 经络穴位：列出 3–5 个主要

7. 时长与频率
   - 每次时长（30/45/60/90 分）
   - 总疗程次数（如 6 次）
   - 间隔（如 1 周 1 次）

8. 疗前疗后注意事项
   - 疗前：饭后 ≥ 3 小时；空腹喝水
   - 疗后：避风寒；24 小时内勿洗冷水

9. 自我护理建议
   - 饮食、作息、运动建议

10. 复诊安排
    下次预约日期 + 时间

11. 评估指标
    VAS 疼痛量表、ROM 关节活动度、客户主观满意度
```

### 步骤 4：取得书面知情同意（按 KP-04 §5）
1. 朗读同意书
2. 解释每条款
3. 客户签字 + 日期
4. 推拿师签字 + 日期
5. 副本当日交客户

### 步骤 5：实施记录保密与安全
| 措施 | 执行 |
|------|------|
| 文件归档 | 立即放入档案夹 |
| 档案柜上锁 | 轮值员工上锁 |
| 电子记录加密 | 输入 EMR + 双重认证 |
| 副本递交 | 当日 / 加密 PDF 邮件 |

### 步骤 6：向客户口头汇报方案 (5 分钟)
1. 用浅白语言概述方案
2. 强调推拿目的与预期效果（不承诺治愈）
3. 提示风险与可能短暂反应
4. 回答客户疑问
5. 确认下次预约

### 步骤 7：方案变更流程
若日后需变更：
- 新增模式或部位 → **重新签署同意书**
- 调整频率 → 客户口头同意 + 记录
- 任何变更须更新方案文件并归档

## 六、推拿服务方案样例（供参考）

> **客户：** 陈太太，42 岁，文员
> **主诉：** 颈肩僵硬 6 个月，轻度紧张性头痛
> **四诊：** 望—肩高低；问—睡眠浅；切—斜方肌张力高
> **适应症：** 肌肉僵硬、紧张性头痛
> **禁忌排除：** 无出血、骨折、皮肤问题、胸痛、呼吸困难、关节肿胀
> **模式：** 肌骨推拿
> **部位：** 颈、肩、背上部；穴位：风池、肩井、天宗
> **手法：** 揉法 + 按法 + 拿法
> **时长：** 60 分钟 / 次 × 6 次，每周 1 次
> **疗前：** 饭后 3 小时；放松着装
> **疗后：** 24 小时内勿冷水冲淋；多喝温水
> **自我护理：** 每小时起立伸展；调整电脑屏幕高度；睡眠 ≥ 7 小时
> **复诊：** 1 周后同时段
> **评估：** VAS 起始 6/10，目标 ≤ 2/10；ROM 颈侧屈起始 30°，目标 45°

## 七、常见错误与修正

| 错误 | 修正 |
|------|------|
| 承诺"3 次见效" | 改"按个体反应可能见效" |

| 同意书签字忘日期 | 立即补签 |
| 档案柜未上锁 | 立即上锁并交代轮值员工 |
