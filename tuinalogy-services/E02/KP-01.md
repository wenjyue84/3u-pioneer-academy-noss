## 一、妇女生理总论 / Overview of Women's Physiology

中医认为女性"以血为本，以肝为先天"，与男性有所不同。女性一生经历**经 (jīng / menstruation)**、**带 (dài / leucorrhoea)**、**胎 (tāi / pregnancy)**、**产 (chǎn / parturition)**、**乳 (rǔ / lactation)** 五大生理活动，皆与冲、任、督、带四脉密切相关。

| 中医观点 | 西医对应 |
|----------|----------|
| 肾藏精，主生殖 | 下丘脑—垂体—卵巢轴 (HPO axis) |
| 肝藏血，主疏泄 | 雌激素与情志调节 |
| 脾统血 | 凝血与代谢 |
| 心主血脉 | 心血管系统 |
| 冲为血海，任主胞胎 | 子宫、卵巢、输卵管 |

---

## 二、女性三大经脉 / Three Key Vessels

| 经脉 | 中文 | English | 功能 | 常用穴 |
|------|------|---------|------|--------|
| 任脉 | 任脉 | Conception Vessel (Ren) | 总任阴经；主胞胎 | 关元、气海、中极、膻中 |
| 冲脉 | 冲脉 | Penetrating Vessel (Chong) | 十二经之海；血海 | 横骨、大赫、气穴、公孙（八脉交会） |
| 带脉 | 带脉 | Belt Vessel (Dai) | 约束诸经；主带下 | 带脉穴、五枢、维道 |

**临床要点：** 任脉穴位（脐下）孕期严禁深按；冲脉、带脉调理多用于经带不调与子宫脱垂。

## 三、妇女四大生理阶段 / Four Major Stages

### 1. 经期 (Menstruation Phase)

| 项目 | 说明 |
|------|------|
| 西医 | 月经周期 21–35 天；行经期 3–7 天；经量 30–80ml |
| 中医 | 行经为肾气推动，冲任溢满下泄；肝郁则痛、脾虚则量多 |
| 推拿适应 | 经前/经期痛经、经前胀乳、情志不畅、腰酸 |
| 推拿禁区 | 腰骶强按；腹部深按；活血强刺激穴 |

### 2. 孕期 (Pregnancy)

| 阶段 | 周数 | 推拿原则 |
|------|------|----------|
| 第 1 孕期 | 0–12 周 | **最危险期**，原则上避免推拿；如必须，仅短时肩颈轻揉 |
| 第 2 孕期 | 13–27 周 | 相对安全期；左侧卧；避禁忌穴；30 分钟内 |
| 第 3 孕期 | 28+ 周 | 半坐位/侧卧；禁久仰卧（防腔静脉压迫）；20 分钟内 |

**孕期常见适应症：** 腰背痛、肩颈紧张、腿部水肿、便秘、情绪焦虑、坐骨神经痛
**孕期禁忌总则：** 禁腹部摩按、禁腰骶强力按压、禁活血通经穴、禁艾灸下腹（详见 KP-02）

### 3. 产褥期 (Postpartum / 月子期)

| 阶段 | 时间 | 推拿原则 |
|------|------|----------|
| 产后早期 | 0–14 天 | 仅轻柔肩颈与上肢；禁腹部、腰骶；剖宫产禁疤痕区 |
| 产后中期 | 15–42 天（恶露净） | 可加腰背调理；哺乳期禁乳房正上方按压 |
| 产后后期 | 6 周后 | 全面恢复；可恢复腹部、腰骶适度调理 |

**适应症：** 腰骶酸痛、肩颈紧张（哺乳姿势）、乳汁不通、产后情志失调、便秘、耻骨联合不适

### 4. 更年期 (Menopause / Perimenopause)

| 项目 | 说明 |
|------|------|
| 西医 | 通常 45–55 岁；卵巢功能衰退；雌激素下降 |
| 中医 | 肾气渐衰，天癸将竭；肝肾阴虚或心肾不交 |
| 适应症 | 失眠、烘热、烦躁、心悸、肩颈痛、骨关节酸痛 |
| 调理思路 | 滋肾、平肝、安神；常用太溪、太冲、神门、涌泉、百会、三阴交 |

## 四、妇女推拿适应症一览 / Indications

| 类别 | 具体症状 | 主要调理穴位 |
|------|----------|------------|
| 经期问题 | 痛经、PMS、经前胀乳 | 三阴交（非孕）、太冲、关元、子宫穴 |
| 孕期不适 | 腰背痛、肩颈紧、水肿 | 委中、承山（轻）、肩中俞、风池（轻） |
| 产后恢复 | 腰骶痛、乳汁不通、便秘 | 肾俞、八髎（产后 2 周后）、膻中、乳根、足三里 |
| 更年期 | 失眠、烘热、烦躁 | 神门、涌泉、太溪、太冲、安眠、百会 |
| 一般保健 | 疲劳、压力、肩颈僵 | 风池、肩井（非孕）、合谷（非孕）、足三里 |

## 五、妇女四诊 / Four Examinations

### 望 (Inspection)

- 面色（苍白主血虚；萎黄主脾虚；颧红主阴虚）
- 形体（水肿、消瘦）
- 舌象（舌质淡为血虚；舌紫暗为血瘀；舌红少苔为阴虚）
- 妊娠者观察腹部隆起情况、皮肤紫纹、下肢水肿

### 闻 (Listening / Smelling)

- 声音（低弱为气虚）
- 气味（带下异味提示湿热下注）

### 问 (Inquiry) — **妇科必问"经带胎产乳"**

| 项目 | 询问要点 |
|------|----------|
| 月经史 | 初潮、周期、经期、经量、颜色、有无血块、有无痛经 |
| 带下 | 量、色、质、味 |
| 孕产史 | G/P/A（妊娠/生产/流产次数） |
| 生育史 | 末次月经 LMP、避孕方法 |
| 哺乳 | 是否哺乳、有无乳汁不通史 |
| 现症 | 主诉持续时间、加重缓解因素 |

### 切 (Palpation)

- 寸口脉（女子尺脉常较盛；妊娠脉滑利）
- 必要时触诊（限中医诊断范围；以问诊为主）

> **隐私要点：** 问诊须在私密空间；记录依 PDPA 2010 保密；男技师询问妇科时需有第三人在场。

## 六、妇女推拿前必查事项 / Pre-Tuina Safety Check

1. 确认生理阶段（经/孕/产/更/平时）
2. 测血压（孕期高血压 ≥140/90 须转诊）
3. 询问是否有阴道出血、腹痛、发热
4. 孕期：核对孕周、产前检查情况
5. 产后：核对恶露情况、是否剖宫产、是否哺乳
6. 既往病史：高血压、糖尿病、子宫肌瘤、流产史
7. 是否签署同意书（孕妇专用同意书）

## 七、必须立即转诊征兆 / Immediate Referral Signs

| 阶段 | 警讯 | 转诊去向 |
|------|------|----------|
| 孕期 | 阴道出血、腹痛、胎动减少/消失、剧烈头痛、视物模糊 | 妇产科急诊 |
| 产后 | 持续高热、恶露恶臭/突增、剧烈腹痛、乳房红肿热痛 | 妇产科 / 急诊 |
| 经期 | 突发剧痛、晕厥、持续大量出血 | 急诊 |
| 更年期 | 异常出血、严重情绪障碍、自杀念头 | 妇产科 / 精神科 |

## 总结

妇女推拿不同于一般成人推拿，须以"经带胎产乳"五大生理为基础、以冲任带三脉为枢纽、以孕期禁忌为底线。学员应熟练掌握四诊重点、阶段判别与转诊指征，方能安全执业。
