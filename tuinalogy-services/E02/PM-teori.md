# 理论课教学计划 / Theory Lesson Plan — E02 妇女推拿服务


## 一、教学目标 / Learning Objectives

完成理论部分后，学员能够：
1. 阐述妇女四大生理阶段（经期、孕期、产后、更年期）的特点与推拿原则
2. 说明任脉、冲脉、带脉与妇女气血关系
3. 列出并解释妇女推拿适用手法与妊娠禁忌穴位
4. 辨识常见妇女不适（痛经、产后腰痛、肩颈紧张、乳汁不通、更年期失眠）的推拿调理思路
5. 描述妇女客户问诊重点、隐私保护规范与转诊指征

## 四、教学内容大纲 / Course Outline

### 单元一：KP-01 妇女生理周期与推拿（26 h）
- 1.1 妇女三大经脉：任脉（Conception Vessel）、冲脉（Penetrating Vessel）、带脉（Belt Vessel）
- 1.2 经期 / 孕期 / 产后 / 更年期生理特点
- 1.3 各阶段推拿目标与禁区
- 1.4 妇女推拿四诊重点（望、闻、问、切）

### 单元二：KP-02 妇女推拿适用手法与禁忌（32 h）
- 2.1 八大手法在妇女推拿的力度调整（推、拿、按、捏、揉、捻、摩、拍）
- 2.2 常用穴位：三阴交、关元、气海、血海、足三里、太冲
- 2.3 **妊娠绝对禁忌穴**：合谷、三阴交、肩井、至阴、昆仑
- 2.4 **妊娠相对禁忌部位**：下腹、腰骶部强力按压
- 2.5 产后恶露未净期手法选择
- 2.6 介质选用（按摩油、爽身粉、中药酒）与孕妇敏感性

### 单元三：KP-03 常见妇女不适推拿调理（28 h）
- 3.1 痛经（经前 / 经期）调理
- 3.2 产后腰痛 / 骶尾部不适
- 3.3 肩颈紧张（哺乳期常见）
- 3.4 产后乳汁不通调理
- 3.5 更年期失眠 / 心烦
- 3.6 何时必须转诊妇产科 / 西医
