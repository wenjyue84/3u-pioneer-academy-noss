# WIM Document Structure

## What is WIM?

**WIM = Written Instructional Materials** (Bahan Pengajaran Bertulis / BPB)

WIM is a competency-based instructional package prepared by instructors for use in JPK-accredited training centres (Pusat Bertauliah). It is the mandatory teaching/learning material for all NOSS-based training programs.

**WIM is NOT a textbook.** A textbook is a general reference organized by topic. WIM is structured specifically around NOSS competency units and work activities, with prescribed formats, coded documents, and color-coded paper.

## Purpose of WIM

1. Primary learning material for teaching and learning
2. Ensure learning outcomes in each Competency Unit (CU) are achieved
3. Help instructors prepare and build confidence for teaching sessions
4. Standardize training delivery across accredited centres

## WIM Document Package Structure

A complete WIM package for one NOSS program contains:

### Front Matter
1. Accredited centre logo
2. Title: "BAHAN PENGAJARAN BERTULIS" (Written Instructional Materials)
3. Program code and competency unit codes
4. Centre name and address
5. Publication edition

### Index Section
1. **Isi Kandungan** — Table of Contents
2. **Ahli Jawatankuasa Pembangunan** — Development Committee members
3. **Carta Profil Kompetensi (CPC)** — Competency Profile Chart
4. **CoCU** — Curriculum of Competency Unit
5. **Jadual Pembahagian WIM (JPW)** — WIM Distribution Schedule (theory + practical)
6. **Jadual Penetapan Peratusan Masa** — Time allocation percentages

## Two WIM Sets

### SET WIM TEORI (Theory Set)

| Component | Code (BM) | Code (EN) | Paper Color | Purpose |
|-----------|-----------|-----------|-------------|---------|
| Pelan Mengajar Teori | PM | LP | YELLOW | Theory lesson plan |
| Kertas Penerangan | KP | IS | WHITE | Information/theory content |
| Kertas Tugasan | KT | AS | PINK | Theory exercises/assignments |

### SET WIM AMALI (Practical Set)

| Component | Code (BM) | Code (EN) | Paper Color | Purpose |
|-----------|-----------|-----------|-------------|---------|
| Pelan Mengajar Amali | PM | LP | YELLOW | Practical lesson plan |
| Kertas Kerja | KK | WS | BLUE | Step-by-step practical instructions |

### Assessment Documents

| Component | Code | Paper Color | Minimum Duration |
|-----------|------|-------------|-----------------|
| Penilaian Pengetahuan (Knowledge Assessment) | KA | PINK | 1 hour |
| Penilaian Prestasi (Performance Assessment) | PA | LIGHT BLUE (Ocean Blue) | 2 hours (min 1 question) |

## Component Details

### Kertas Penerangan / Information Sheet (KP/IS) — WHITE paper
- Contains theoretical knowledge aligned with "Related Knowledge" in CoCU
- Explains "WHY" rather than "HOW"
- Must be clear, complete per work activity, current with technology
- Flexible quantity per CU (based on content depth)
- Each KP covers one or more Related Knowledge items from the CoCU

### Kertas Tugasan / Assignment Sheet (KT/AS) — PINK paper
- Exercises to test theoretical understanding
- NOT counted as coursework assessment (formative only)
- Quantity aligns with number of Information Sheets
- Uses varied question formats (MCQ, short answer, essay, matching)
- Tests comprehension of the corresponding KP

### Kertas Kerja / Work Sheet (KK/WS) — BLUE paper
- Step-by-step instructions for practical skill mastery
- References Work Activities and Related Skills from CoCU
- Includes: brief oral questioning, equipment/material lists, labeled diagrams
- Assessment checklist covers: process, output, attitude, safety, environment
- Each KK maps to one or more Work Activities

### Pelan Mengajar / Lesson Plan (PM/LP) — YELLOW paper
- Two types: Theory (for KP+KT sessions) and Practical (for KK sessions)
- Uses 4-step instructional method:
  1. **Persediaan** (Preparation) — Set context, state objectives
  2. **Penyampaian** (Presentation) — Deliver content/demonstrate
  3. **Penggunaan** (Application) — Trainee practice/exercise
  4. **Pengesahan** (Confirmation) — Verify understanding/competency

## Time Allocation Framework

| Level | Face-to-Face | Self-Learning | Assessment |
|-------|-------------|---------------|------------|
| Level 1-2 | 60-95% | 0-20% | 5-20% |
| Level 3-5 | Adjusted (less face-to-face) | Increased self-directed | 5-20% |

## NOSS Training Hour Split

| Component | Percentage |
|-----------|-----------|
| Knowledge (Theory) | 30% |
| Performance (Practical) | 70% |

This 30/70 split is the standard allocation mandated by JPK for most NOSS programs.
