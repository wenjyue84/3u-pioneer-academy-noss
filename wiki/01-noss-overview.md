# NOSS Overview

## What is NOSS?

**NOSS (National Occupational Skills Standard)** / Standard Kemahiran Pekerjaan Kebangsaan (SKPK) is a government document that outlines the minimum competencies required by a skilled worker in Malaysia for a specific occupational area and level, plus the pathway to achieve those competencies.

**Governing body:** Jabatan Pembangunan Kemahiran (JPK) / Department of Skills Development (DSD), under the Ministry of Human Resources (MOHR/KSM). The division responsible is SPKTVET (Bahagian Standard Pekerjaan & Kurikulum TVET).

## NOSS Code Format

Format: `[Section]-[Classification]-[Level]:[Year]`

| Component | Example | Meaning |
|-----------|---------|---------|
| Section letter | G, S, IT | Occupational section (G=Manufacturing, S=Services, IT=IT) |
| Classification | 452, 960, 020 | Job classification number |
| Level | 1-5 | Competency level |
| Year | 2013, 2020, 2023 | Year of approval |

Examples:
- `G452-010-3:2023` — BEV Diagnostic and Rectification, Level 3
- `S960-002-3:2020` — Aesthetic Services, Level 3
- `IT-020-3:2013` — Computer System Operation, Level 3

## Three Components of a NOSS Document

Every NOSS document is divided into 3 components:

### Component I: Standard Practice (SP)
Information about the occupational area:
- Introduction to the industry
- Occupational Structure (OS) — career path hierarchy
- Occupational Area Structure (OAS) — scope of occupational area
- Competency level definitions
- Certificate awards
- Employment prospects, upskilling opportunities
- Regulatory/statutory requirements

### Component II: Standard Content (SC)
Reference for industry employers:
- **Competency Profile Chart (CPC)** — visual map of ALL Competency Units across the level
- **Competency Profile (CP)** — detailed description of each CU including:
  - CU title and code
  - Competency Unit Descriptor
  - Work Activities
  - Performance Criteria
  - Underpinning Knowledge / Skills / Attitude

### Component III: Curriculum of Competency Unit (CoCU)
Reference for training personnel:
- Training requirements per CU
- Curriculum design details
- Assessment requirements
- Training hours allocation
- Each CoCU table contains:

| Column | Description |
|--------|-------------|
| Work Activities | Observable, measurable job functions |
| Related Knowledge | Theoretical understanding required |
| Related Skills | Practical capabilities needed |
| Attitude/Safety/Environment | Soft skills, compliance |
| Training Hours | Hours allocated (theory + practical) |
| Delivery Mode | Lecture, demo, practical, etc. |
| Assessment Criteria | Standards for evaluation |
| Tools, Equipment & Materials (TEM) | Resources needed |

## 5 Competency Levels

| Level | Title | Description |
|-------|-------|-------------|
| 1 | Semi-Skilled | Routine, predictable activities with close supervision |
| 2 | Skilled | Varied contexts, some non-routine tasks, moderate responsibility |
| 3 | Technician/Supervisor | Complex, non-standard work; high autonomy; supervises others |
| 4 | Executive/Technologist | Broad technical/professional scope; resource allocation |
| 5 | Manager/Specialist | Complex principles in wide scope; highest autonomy; analysis and planning |

## NOSS Development Methodology

- **1971-1991:** PKK (Panduan Kemahiran Kebangsaan)
- **1992-2010:** DACUM (Developing A Curriculum)
- **2011-present:** DESCUM (Developing Standards for Curriculum) — current methodology

## Key Statistics

- As of 2021: 1,987 NOSS standards across 29 occupational sectors
- NOSS documents available via MySPIKE (www.myspike.my) — RM20/year subscription
- Development involves: Standard Development Committee (JPS/SDC), Standard Technical Committee (JTS/STC), Standard Technical Evaluation Committee (JTPS/STEC)

| MSC Level 1 | SKM Tahap 1 | 1 |
| MSC Level 2 | SKM Tahap 2 | 2 |
| MSC Level 3 | SKM Tahap 3 | 3 |
| DKM | Diploma Kemahiran Malaysia | 4 |
| DLKM | Diploma Lanjutan Kemahiran Malaysia | 5 |

## Flow: NOSS to Training Delivery

```
NOSS Document (DSD publishes)
    |
    v
Training Provider (Pusat Bertauliah) obtains NOSS
    |
    v
Develop WIM (Written Instructional Materials) based on CoCU
    |
    v
Develop Assessment Questions (Soalan Penilaian) based on CoCU
    |
    v
Submit to JPK for accreditation approval
    |
    v
Deliver training using WIM
    |
    v
Assess trainees using approved assessment instruments
    |
    v
Award MSC/DKM/DLKM certificate
```
