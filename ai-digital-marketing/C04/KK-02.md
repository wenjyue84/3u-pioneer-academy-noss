## Work Activity Title

Write a Voiceover Script and Produce an AI Voiceover Audio Track for a Malaysian Marketing Campaign

---

## Learning Outcomes

By the end of this activity, trainees will have:
- Written a 30-second voiceover script (65–80 words) following the Hook-Body-CTA structure
- Generated an AI voiceover using at least one TTS tool (ElevenLabs or CapCut)
- Selected and mixed appropriate royalty-free background music
- Produced a final combined audio track (voiceover + music) exported as an MP3 or M4A file

## Safety Precautions

- Do not use ElevenLabs Voice Cloning to clone the voice of any real person without their explicit written consent
- Do not generate voiceovers making health, financial, or legal claims that are not substantiated
- All background music used must be verified as royalty-free for commercial use — check the licence of each track
- Label AI-generated voiceover as such in your submission documentation

## Campaign Brief

**Brand:** MediQuick — a Malaysian online pharmacy and health supplement delivery service
**Campaign:** "Your Health, Delivered" — awareness campaign for new customers
**Product Focus:** General health supplements and OTC medications, delivered to your door in 3 hours across Klang Valley
**Target Audience:** Working adults aged 25–45; busy professionals who value convenience
**Platform:** YouTube pre-roll ad (30 seconds, non-skippable)
**Tone:** Calm, reassuring, professional but approachable; NOT fast-talking or pressured
**Language:** English (primary); option to produce BM version as bonus task
**CTA:** "Download the MediQuick app — link in description below"

## Step-by-Step Instructions

### Step 1: Write Your Voiceover Script with AI (15 minutes)

**1a.** Open ChatGPT or Claude and enter:

```
Write a 30-second YouTube pre-roll voiceover script for MediQuick — 
a Malaysian online pharmacy delivering health supplements and OTC medications 
within 3 hours across Klang Valley.

Target audience: busy Malaysian professionals aged 25–45.
Tone: calm, reassuring, trustworthy — NOT rushed or salesy.
Language: English.
Word count: 65–80 words.

Structure:
- Hook (5 seconds): opens with a relatable scenario (not a question — a statement)
- Body (20 seconds): key benefits (convenience, speed, reliability, selection)
- CTA (5 seconds): "Download the MediQuick app — link in description below"

Format: 
- Number each line
- Add [PAUSE] where a natural breath or dramatic pause should occur
- Add [EMPHASIS: word] where a word should be stressed
```

**1b.** Review the AI output. Check:
- [ ] Word count is 65–80 words
- [ ] Hook opens with a scene or statement (not a question)
- [ ] Each sentence is under 15 words
- [ ] Tone is calm and reassuring — not rushed
- [ ] CTA is exact: "Download the MediQuick app — link in description below"
- [ ] [PAUSE] and [EMPHASIS] markers are placed logically

**1c.** Revise as needed. Read the script aloud (normal, calm pace) and time it. It should be 28–32 seconds.

Write the final approved script in your Answer Sheet.

---

### Step 2: Select Your AI Voice in ElevenLabs (10 minutes)

**2a.** Go to elevenlabs.io → Sign in (free account) → Text to Speech

**2b.** Browse available voices. For MediQuick's "calm, reassuring, professional" brand voice, look for:
- **Gender:** Male or female (your choice — note your reasoning)
- **Accent:** Neutral English or Malaysian-accented English if available
- **Qualities:** Warm, measured, clear diction — NOT fast-talking or overly enthusiastic

**2c.** Test at least 3 different voices with the same short excerpt from your script (first 2 lines only). Note each voice name and your assessment:

| Voice Name | Gender | Accent | Impression | Suitable? |
|---|---|---|---|---|
| 1. | | | | |
| 2. | | | | |
| 3. | | | | |

**2d.** Select your final voice. Record the name in your Answer Sheet.

**2e.** Settings adjustment:
- Stability: 70–80% (high stability = more consistent; lower = more expressive)
- Similarity boost: 70%
- Style exaggeration: 10–20% (low for professional/calm)

---

### Step 3: Generate the AI Voiceover (10 minutes)

**3a.** In ElevenLabs, paste your complete script into the text box.

> **Important:** Remove the [PAUSE] and [EMPHASIS] markers before generating — ElevenLabs reads punctuation and emphasis cues differently. Use commas and ellipsis (...) for pauses; capitalise words for emphasis (e.g., "GUARANTEED delivery").

**3b.** Generate the audio. Listen to the full output carefully.

**Review checklist:**
| Check | Pass? | Notes |
|---|---|---|
| Total duration is 28–32 seconds | ☐ | |
| All words are correctly pronounced | ☐ | |
| Pacing is calm — not rushed | ☐ | |
| "MediQuick" is pronounced correctly (not "MedQuick" or "MediaQuick") | ☐ | |
| "Klang Valley" is pronounced correctly | ☐ | |
| CTA is clear and distinct at the end | ☐ | |

**If any check fails:**
- Mispronounced product/brand name: Use ElevenLabs pronunciation dictionary or spell phonetically ("Klang" → "Klang"; test and adjust)
- Wrong pacing: Adjust Stability setting and regenerate
- Unnatural pauses: Add punctuation to script and regenerate

**3c.** Download the final voiceover as MP3. Name: `[YourName]-MediQuick-VO-EN.mp3`

---

### Step 4: Select Background Music (10 minutes)

**4a.** Go to pixabay.com/music

**4b.** Search for music matching MediQuick's tone. Try these search terms:
- "calm corporate"
- "reassuring gentle"
- "soft piano background"
- "professional ambient"

**4c.** For each candidate track, verify:
- [ ] Licence is "Free for commercial use" (shown on the track page)
- [ ] Music is instrumental (no vocals — vocals clash with voiceover)
- [ ] Tempo is slow to moderate (60–90 BPM)
- [ ] Duration is at least 35 seconds (to cover the voiceover with fade out)

**4d.** Select one track and download as MP3. Note the track name and artist for attribution.

Track selected: _______________________________________________
Attribution: _______________________________________________

### Step 5: Mix Voiceover and Music (15 minutes)

**Option A — Using Audacity (PC):**

1. Open Audacity → Import Audio → select your voiceover MP3
2. Import Audio (second time) → select your music MP3
3. You now have two audio tracks on separate rows
4. Select the music track → Effects → Amplify → set to approximately -18dB (makes music quieter)
5. Check the mix: voiceover should be clearly dominant; music barely audible
6. Add a fade-out to the music track in the last 3 seconds: select last 3 sec of music → Effect → Fade Out
7. File → Export → Export as MP3 → Name: `[YourName]-MediQuick-Final-Mix.mp3`

**Option B — Using CapCut (mobile/PC):**

1. New project → Import your voiceover MP3 as main audio
2. Add background sound → Import your music MP3
3. Set music volume to 15–20% using the volume slider
4. Add a fade-out to the music in the last 3 seconds
5. Export audio (or export as video if combining with a still image)

## Evaluation Criteria

| Criterion | Excellent (4) | Good (3) | Adequate (2) | Needs Work (1) |
|---|---|---|---|---|
| **Script Quality** | 65–80 words; hook-body-CTA; natural spoken English; brand tone achieved | Correct structure; good tone; minor length issue | Structure present; tone partially achieved | Incorrect structure; wrong tone; too long/short |
| **Voice Selection** | Tested 3+ voices; clear rationale; voice perfectly matches brand | 2–3 voices tested; appropriate choice | 1 voice tested; reasonable choice | No evaluation; random choice |
| **TTS Quality** | All words correctly pronounced; pacing 28–32 sec; natural delivery | Most words correct; minor mispronunciation | Understandable but some errors | Significant errors or wrong duration |
| **Audio Mix** | Voiceover dominant; music at correct level; smooth fade-out | Good balance; minor level issue | Mix present but music too loud or too quiet | No mixing; voiceover only submitted |
| **Attribution** | Track name, artist, source, and licence clearly documented | Track name and source present | Source only | No attribution |

## Reflection Questions (Soalan Refleksi)

1. Which voice did you select for MediQuick and why? What specific vocal qualities made it the best match for the brand?
2. When you listened back to the AI voiceover, were there any words or phrases that sounded unnatural or mispronounced? How did you resolve them?
3. Compare the experience of writing a spoken voiceover script to writing a social media caption. What are the three biggest differences in how you approached the writing?
4. If MediQuick wanted to produce the same ad in Bahasa Malaysia for a different audience segment, what specific adjustments would you make beyond translating the words? (Consider tone, pacing, voice choice, and cultural references.)
