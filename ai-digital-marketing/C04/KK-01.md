## Work Activity Title

Produce a 60-Second Promotional Video for a Malaysian Brand Using CapCut AI

---

## Learning Outcomes

By the end of this activity, trainees will have:
- Written a complete 60-second video script using the Hook-Body-CTA structure
- Filmed or sourced at least 5 clips of footage for the video
- Applied at least 3 CapCut AI features in the editing process
- Exported a completed 1080 × 1920 px vertical video ready for social media publishing

## Safety Precautions

- Obtain verbal consent before filming any person who appears on camera
- Do not film in restricted areas (government buildings, private property without permission)
- Do not make product claims in the video that are not substantiated — no "cures," "guarantees," or "best in Malaysia" without evidence
- Background music must be from a royalty-free source — do not use copyrighted commercial songs
- Review final video for any unintended content (background people, signage, or audio) before submission

## Campaign Brief

**Brand:** KraftBag Malaysia — a homegrown brand selling handcrafted leather goods (wallets, cardholders, bags)
**Product Featured:** "Slim Series Wallet" — ultra-slim bifold wallet in genuine leather; 8 card slots; RM 149
**Campaign Platform:** TikTok (primary) and Instagram Reels (secondary)
**Target Audience:** Malaysian men aged 22–40; gift buyers (partners, family); professionals
**Key Message:** "The last wallet you'll ever need — Malaysian craftsmanship, slim design."
**Tone:** Confident, proud of local craftsmanship; not overly salesy
**CTA:** "Shop the Slim Series — TikTok Shop link pinned above"

## Step-by-Step Instructions

### Step 1: Write Your Script with AI (15 minutes)

Open ChatGPT or Claude and enter:

```
Write a 60-second TikTok promotional video script for KraftBag Malaysia.
Product: Slim Series Wallet — genuine leather, ultra-slim, 8 card slots, RM149.
Target audience: Malaysian men aged 22–40 and gift buyers.
Tone: Confident, artisan pride, not pushy.
Language: English with occasional BM phrases for authenticity.

Format:
- HOOK (line 1 spoken + visual direction, 0–3 seconds)
- BODY (lines 2–10, each with spoken line + visual direction, 3–55 seconds)
- CTA (final line + visual direction, 55–60 seconds)

Also provide:
- TikTok caption (under 150 characters, with hook and 3 hashtags)
- 3 alternative hook lines I could test
```

Review the AI output. Edit the script so it:
- Sounds natural when read aloud (read it aloud now)
- Is approximately 130–150 words total
- Has a strong, specific hook
- Ends with the exact CTA from the brief

Write your final approved script in your Answer Sheet.

---

### Step 2: Plan and Film Your Footage (20 minutes)

Based on your script, plan what footage you need. Create a simple shot list:

| Shot # | Visual Direction (from script) | Shot Type | Duration to Film |
|---|---|---|---|
| 1 | [from your script] | | 10–15 seconds |
| 2 | | | |
| 3 | | | |
| 4 | | | |
| 5 | | | |

**Minimum footage required:**
- At least 5 separate clips (each 5–10 seconds raw)
- At least 1 close-up product shot
- At least 1 "in-use" or lifestyle shot (person holding wallet, cards being inserted, etc.)
- All shots filmed **vertically (portrait orientation, 9:16)**

**If a real product is not available:** Use a similar object or a printed product photo placed in a natural setting. Trainer may provide sample footage clips.

**Lighting check before filming:**
- Face a window or use a ring light — do not film with a bright light source behind the subject
- Film a 5-second test clip and review on phone screen before full shoot

---

### Step 3: Edit in CapCut AI (30 minutes)

**3a. Import all clips:**
- Open CapCut → New Project → Import all filmed clips
- Arrange clips in script order on the timeline

**3b. Apply Smart Cut:**
- Select all clips → AI Tools → Smart Cut
- Review trimmed version — restore any cuts that removed important footage

**3c. Add background music:**
- Tap Audio → Sounds → Search "artisan" or "confident" or use a CapCut curated track
- Select a track that matches the tone (confident, moderate pace)
- Set music volume to 20–25% (voiceover/speech must be louder)

**3d. Add Auto Captions:**
- Tap Text → Auto Captions → Generate
- Review all generated captions: correct any mispronounced words, names, or Malay terms
- Style captions: font, colour (ensure contrast against video background)

**3e. Add text overlays (key message highlights):**
- Add at least 3 text overlay moments aligned with key script lines:
  - Product name: "Slim Series Wallet" (on product close-up clip)
  - Key benefit: "8 Card Slots. Ultra Slim." (on demonstration clip)
  - CTA text: "TikTok Shop — Link Above" (on final CTA clip)

**3f. Apply Beat Sync (optional but recommended):**
- Tap Audio → Beat Sync → Auto
- This snaps your cuts to the music beats for a more professional, energetic feel

**3g. Apply Auto Enhance:**
- Select all clips → Adjust → AI Enhance or Auto
- Review result — revert individual clips if the AI colour correction looks unnatural

---

### Step 4: Final Review Before Export (10 minutes)

Watch your complete video from start to finish and complete this checklist:

| Review Item | Pass? | Notes |
|---|---|---|
| Total duration is 55–65 seconds | ☐ | |
| Hook is visible/audible in first 3 seconds | ☐ | |
| Captions are accurate (no errors in text) | ☐ | |
| Background music is not louder than speech/voiceover | ☐ | |
| All 3 text overlays are present and readable | ☐ | |
| Video ends with clear CTA text visible | ☐ | |
| No embarrassing background content (people, signage) | ☐ | |
| Video is vertical (9:16) throughout | ☐ | |

Fix any items marked as failing before export.

---

### Step 5: Export (5 minutes)

- Tap Export → Resolution: **1080p** → Frame rate: **30fps** → Export
- Save file name: `[YourName]-KraftBag-60sec-TikTok.mp4`
- Transfer to laptop / Google Drive for submission

## Evaluation Criteria

| Criterion | Excellent (4) | Good (3) | Adequate (2) | Needs Work (1) |
|---|---|---|---|---|
| **Script Quality** | Strong hook, clear problem-solution body, specific CTA; 130–150 words; sounds natural | Good structure; hook is effective; CTA present | Basic structure; hook is weak; CTA generic | No clear structure; missing hook or CTA |
| **Footage Quality** | 5+ clips; varied shot types; good lighting; no shaky footage | 4–5 clips; lighting adequate; minor quality issues | 3–4 clips; some poor lighting or shaky shots | 1–2 clips; poor quality throughout |
| **CapCut AI Use** | 3+ AI features used effectively; captions corrected; music balanced | 2–3 AI features; most captions correct | 1–2 AI features; captions not reviewed | No AI features used; or features used incorrectly |
| **Technical Specs** | 1080p, 9:16, 55–65 sec, MP4, correctly named | Correct resolution and ratio; duration slightly off | 720p or minor spec issue | Wrong format, ratio, or unusable file |
| **Overall Video Quality** | Publication-ready; compelling from first frame to CTA | Professional feel; minor edits would improve | Functional but rough; noticeable amateur elements | Incomplete or unwatchable |
