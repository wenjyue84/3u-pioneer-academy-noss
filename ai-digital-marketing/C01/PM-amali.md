|---|---|
| Komputer/laptop dengan internet | Satu per pelatih (wajib untuk setiap sesi amali) |
| Projektor dan skrin | Satu set bagi makmal |
| Akaun ChatGPT atau Claude (percuma) | Setiap pelatih perlu buka akaun sebelum Sesi A1 |
| Akaun Google (Percuma) | Untuk Google Trends, Google Docs, Google Sheets |
| Perplexity AI (percuma) | Capaian web tanpa akaun; akaun percuma diperakukan |
| KK(1/2) dan KK(2/2) | Edaran kepada setiap pelatih sebelum Sesi A2 |
| Helaian latihan (Latihan A1, CRAFT, SOSTAC, Template Persona) | Cetak sebelum sesi berkenaan |
| Senarai senario perniagaan | Disiapkan oleh pengajar (sekurang-kurangnya 4 pilihan) |
