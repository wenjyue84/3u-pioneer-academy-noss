## 4. Step-by-Step Instructions

### Method A: Meta Ads Manager (Facebook / Instagram)

**Step 1: Access Meta Ads Manager**
1. Go to `adsmanager.facebook.com`
2. Log in with your Facebook account
3. Ensure you have a Facebook Page linked to your account (required for ads)
4. Click **+ Create** to start a new campaign

**Step 2: Choose Campaign Objective**
Based on the business brief (Section 5), select the most appropriate objective:

| Business Goal | Select This Objective |
| --- | --- |
| Build brand awareness | Awareness |
| Get website visitors | Traffic |
| Collect contact details | Leads |
| Drive WhatsApp conversations | Engagement → WhatsApp |
| Online product sales | Sales |

Click **Continue** after selecting the objective.

**Step 3: Configure Campaign-Level Settings**
1. Name the campaign: `[BusinessName]_[Objective]_[Month][Year]`
   Example: `HarmonyWellness_Leads_Jul2026`
2. Toggle ON **Advantage Campaign Budget** (AI distributes budget across ad sets automatically)
3. Set daily budget: RM 30/day (minimum for meaningful results in Malaysia)
4. Leave Special Ad Categories as "None" unless the campaign involves credit, housing, or employment

**Step 4: Configure the Ad Set**
1. Name the ad set: `[AudienceType]_[Location]`
   Example: `Advantage+_KlangValley`
2. **Audience:** Select **Advantage+ Audience** (AI-powered — recommended)
   - Optional: Add a location hint (e.g., Selangor, Kuala Lumpur, Johor)
   - Optional: Add age range if there is a strict minimum (e.g., 21+ for financial services)
   - Leave interests blank — Advantage+ AI handles this
3. **Placements:** Select **Advantage+ Placements** (AI selects best placements across Facebook, Instagram, Messenger, and Audience Network)
4. **Schedule:** Set start date (today or tomorrow); leave end date blank for ongoing campaigns, or set a specific end date for promotions

**Step 5: Create the Ad**
1. Name the ad: `[AdType]_[Variant]`
   Example: `SingleImage_v1`
2. Select the Facebook Page representing the business
3. **Ad Format:** Choose Single Image (recommended for first campaigns)
4. Upload the ad creative prepared in Canva (1080 × 1080px for feed)
5. Fill in ad copy:

**AI Prompt for Ad Copy (use ChatGPT):**
```
Write a Facebook ad for [Business Name], a [business type] in [City], Malaysia.
Objective: [get leads / drive sales / build awareness].
Target audience: [demographic description].
Unique selling point: [USP].
Offer: [what the ad is promoting].
Include: primary text (125 chars), headline (40 chars), description (30 chars), CTA: [button text].
Tone: [friendly / professional / urgent].
Language: English with occasional Malay terms.
```

6. Add the **Call-to-Action button:** Select from dropdown (Sign Up, Learn More, WhatsApp, Shop Now)
7. Add the **Destination URL** (landing page built in C05/KK-01) or WhatsApp link

**Step 6: Review Ad Preview**
1. Check the preview panel on the right — verify how the ad looks on:
   - Facebook Feed (desktop)
   - Facebook Feed (mobile)
   - Instagram Feed
   - Stories
2. Confirm text is not cut off and image is not cropped incorrectly

**Step 7: Add Payment Method (for live campaigns only)**
- Go to **Billing** → **Add Payment Method**
- Malaysia-supported options: Visa/Mastercard credit or debit card, online banking via iPay88
- For training: skip this step and save as Draft

**Step 8: Pre-Launch Checklist**

Complete this checklist before publishing:

| Check | Verified? |
| --- | --- |
| Campaign objective matches business goal | ☐ |
| Campaign name follows naming convention | ☐ |
| Advantage+ Audience is enabled | ☐ |
| Daily budget is set (minimum RM 30/day) | ☐ |
| Ad image is 1080 × 1080px minimum | ☐ |
| Primary text is under 125 characters | ☐ |
| Headline is under 40 characters | ☐ |
| CTA button is correct and functional | ☐ |
| Destination URL opens correctly on mobile | ☐ |
| Ad preview reviewed on mobile feed | ☐ |

**Step 9: Publish or Save as Draft**
- Training: Click **Save Draft**
- Live deployment: Click **Publish** — campaign enters Meta's review process (usually 24 hours)

---

### Method B: TikTok Ads Manager

**Step 1:** Go to `ads.tiktok.com` → Create account → Verify email

**Step 2:** Click **Campaign** → **Create** → Select objective (e.g., Traffic, Lead Generation)

**Step 3:** At Ad Group level:
- Toggle ON **TikTok Smart+** for AI-automated targeting
- Set daily budget (minimum RM 50/day recommended)
- Set schedule: start date and optional end date

**Step 4:** At Ad level:
- Upload a vertical video (9:16 ratio, 1080 × 1920px, under 500MB)
- Add caption (up to 100 characters) — use ChatGPT for copy
- Select CTA button (Shop Now, Learn More, Sign Up)
- Add destination URL

**Step 5:** Review → Save Draft or Submit for review

## 7. Reflection Questions

1. Why is it recommended to use Advantage+ Audience (Meta) or Smart+ (TikTok) instead of manually specifying interests and demographics? What are the trade-offs of giving AI full targeting control?
2. You are setting up a campaign for a new pharmacy in Seremban targeting customers aged 40+. Which platform (Facebook or TikTok) would you choose and why? What objective would you select?
3. A client asks why their campaign has been running for 3 days but shows "In Review" status. What does this mean and what should you tell the client?
4. After your training campaign is saved as a draft, list three specific things you would do differently for a real live campaign with a RM 3,000/month budget.
