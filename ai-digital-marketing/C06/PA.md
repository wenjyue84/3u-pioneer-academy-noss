## TASK 1: Set Up a Facebook or TikTok Ad Campaign (35 marks)
**Time Allocation: 60 minutes**
**Reference: WA1 — KK-01**

Using the assigned business brief, set up a complete advertising campaign in Meta Ads Manager or TikTok Ads Manager. Save as Draft — no real spend required. You must:

1. Access the correct Ads Manager platform; create a new campaign with the objective that matches the business brief's goal (5 marks)
2. Name the campaign following the correct convention: `[BusinessName]_[Objective]_[Month][Year]` (e.g., `GlowStudio_Leads_Jul2026`) (3 marks)
3. Enable AI-powered automation at campaign level — Meta Advantage Campaign Budget or TikTok Smart+ (5 marks)
4. Configure the Ad Set: enable Advantage+ Audience (Meta) or Smart+ targeting (TikTok); add a Malaysia location hint; set daily budget at RM 30/day minimum with a written justification (6 marks)
5. Use ChatGPT to generate the ad copy following the prescribed prompt structure: primary text (max 125 chars), headline (max 40 chars), description (max 30 chars), and CTA button text (6 marks)
6. Design an ad creative in Canva at the correct specification (1080×1080px for Meta feed; 1080×1920px for TikTok); upload to the ad level with correct format (6 marks)
7. Complete the pre-launch checklist (all 10 items) and save campaign as Draft; submit screenshots of all three levels: Campaign, Ad Set, and Ad (4 marks)

---

## TASK 2: Analyse Campaign Performance Data (40 marks)
**Time Allocation: 60 minutes**
**Reference: WA2 — KK-02**

Using the simulated campaign dataset provided below, calculate all key metrics, classify against Malaysian benchmarks, and produce an AI-assisted campaign performance report.

**Simulated Dataset — Bella Beauty Salon, Shah Alam**
**Campaign:** Facebook Lead Generation — Free Facial Trial | **Period:** 1–31 July 2026

| Raw Data | Value |
|----------|-------|
| Total Ad Spend | RM 1,200 |
| Impressions | 68,000 |
| Link Clicks | 510 |
| Leads (Form Submissions) | 31 |
| Confirmed Appointments | 12 |
| Revenue from Confirmed Appointments | RM 2,400 (avg RM 200/customer) |
| Gross Margin | 55% |

You must:

1. Set up a Google Sheets analysis file titled `BellaBeauty_Campaign_Analysis_Jul2026` with columns: Metric | Formula | Value | Benchmark | Status | Action Required (4 marks)
2. Calculate all 7 required metrics using the correct formulas — CTR, CPC, CPM, CPL, Conversion Rate, ROAS, ROI — show all working (14 marks)
3. Classify each metric as Good / Average / Poor against Malaysian benchmarks (CTR: Good >2%; CPC: Good <RM 0.80; CPM: Good <RM 15; CPL: Good <RM 15; ROAS: Good >4×; Conversion Rate: Good >3%) and colour-code the cells (6 marks)
4. Use ChatGPT with the full prescribed prompt (paste all raw data + benchmarks) to generate: a 3-sentence executive summary, 3 key wins, 3 areas of concern, and 4 recommendations; document the prompt used (8 marks)
5. Review the AI output — identify and remove any hallucinated figures or claims not supported by the raw data; note what you changed and why (5 marks)
6. Identify the single most critical underperforming metric and write a root-cause analysis (50 words minimum) using the root-cause framework (3 marks)

---

## TASK 3: Design an A/B Test and Generate an AI Performance Report (25 marks)
**Time Allocation: 30 minutes**
**Reference: WA3 — Integrative**

Based on the July 2026 Bella Beauty Salon campaign analysis, design a structured A/B test for the August campaign cycle and produce a finalised client-ready performance report. You must:

1. Design a single-variable A/B test for August 2026 — specify: variable being tested (creative, headline, audience, or landing page), Version A (control — what was used in July), Version B (variant — what will be tested), success metric, and minimum test duration (6 marks)
2. Use ChatGPT to generate the "Recommendations for Next Cycle" section of the report — 4 specific, data-driven, prioritised actions; review and edit the AI output before including in the report (7 marks)
3. Produce a complete campaign performance report containing all 9 required sections: Cover Page, Executive Summary, Campaign Overview Table, Performance Summary Table, Key Wins, Areas of Concern, Creative Performance (screenshots or descriptions), ROI Analysis, and Recommendations for Next Cycle (8 marks)
4. Verify the final report: all numbers match the raw dataset; no AI-hallucinated claims remain; language is professional and accessible to a non-technical business owner; export as PDF (4 marks)
