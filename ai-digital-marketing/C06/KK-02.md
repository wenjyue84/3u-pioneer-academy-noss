## 4. Step-by-Step Instructions

### Phase 1: Metric Calculation and Classification

**Step 1: Set Up the Analysis Spreadsheet**
1. Open Google Sheets
2. Create a new spreadsheet titled: `[ClientName]_Campaign_Analysis_[Month][Year]`
3. Create columns: Metric | Value | Benchmark | Status (Good/Average/Poor) | Action Required

**Step 2: Calculate All Key Metrics**

Use the dataset provided in Section 5. Apply these formulas:

| Metric | Formula |
| --- | --- |
| CTR | = Clicks ÷ Impressions × 100 |
| CPC | = Spend ÷ Clicks |
| CPM | = Spend ÷ Impressions × 1000 |
| CPL | = Spend ÷ Leads |
| Conversion Rate | = Leads ÷ Clicks × 100 |
| ROAS | = Revenue ÷ Spend |
| ROI | = (Gross Profit − Spend) ÷ Spend × 100 |

**Step 3: Classify Each Metric Against Benchmarks**

| Metric | Good | Average | Poor |
| --- | --- | --- | --- |
| CTR | >2% | 1–2% | <1% |
| CPM | <RM 15 | RM 15–30 | >RM 30 |
| CPC | <RM 0.80 | RM 0.80–2.00 | >RM 2.00 |
| CPL | <RM 15 | RM 15–40 | >RM 40 |
| ROAS | >4× | 2–4× | <2× |
| Conversion Rate | >3% | 1–3% | <1% |

Mark each metric in the spreadsheet with colour coding: Green (Good), Yellow (Average), Red (Poor).

---

### Phase 2: AI-Assisted Analysis

**Step 4: Generate AI Insights Using ChatGPT**

Open ChatGPT and use this prompt:

```
I am a digital marketing specialist preparing a monthly campaign report for a client.

Here is the campaign data:
- Platform: Facebook Ads
- Campaign Objective: Lead Generation
- Period: [start date] to [end date]
- Total Spend: RM [X]
- Impressions: [X]
- Clicks: [X]
- Leads: [X]
- Revenue Generated: RM [X]
- CTR: [X]%
- CPL: RM [X]
- ROAS: [X]×

Malaysian industry benchmarks: CTR >2% is good; CPL <RM 15 is good; ROAS >4× is good.

Please provide:
1. A 3-sentence executive summary of campaign performance
2. Three key wins
3. Three areas of concern with specific reasons
4. Four actionable recommendations for the next campaign cycle
Tone: professional but accessible to a non-technical business owner.
```

Document the AI output and note which recommendations you agree with and any you would modify.

**Step 5: Identify the Top Optimisation Opportunity**

Based on the lowest-performing metric (coloured Red in Step 3), identify the root cause and recommended action:

| Root Cause Analysis Framework | |
| --- | --- |
| If CTR is poor → | Creative or audience mismatch — test new image/headline |
| If CPL is high → | Landing page conversion issue or audience too broad |
| If ROAS is low → | Offer not compelling enough or product price too low relative to ad cost |
| If Frequency >4 → | Audience exhausted — expand or refresh creative |
| If Conversion Rate is low → | Post-click experience (landing page) needs improvement |

---

### Phase 3: Build the Campaign Report

**Step 6: Structure the Report Document**

Create a Google Docs or Word document with this structure:

```
1. Cover Page
   - Client name, campaign period, prepared by, date

2. Executive Summary (AI-generated, human-reviewed)
   - 3 sentences: what was done, overall result, top recommendation

3. Campaign Overview Table
   - Platform, objective, total spend, period, target audience

4. Performance Summary Table
   - All metrics with benchmark comparison and status

5. Key Wins (3 bullet points)
   - What worked well and why

6. Areas of Concern (3 bullet points)
   - What underperformed and why

7. Creative Performance
   - Screenshot of best and worst-performing ad (if available)
   - CTR and spend comparison

8. ROI Analysis
   - ROAS, ROI%, CPA, break-even analysis

9. Recommendations for Next Cycle (4 actions)
   - Specific, actionable, prioritised

10. Appendix
    - Raw data table
    - AI prompts used and outputs
```

**Step 7: Generate Report Narrative with AI**

For each section, use a targeted AI prompt:

```
Write the "Key Wins" section of a campaign report.
Context: [paste relevant metrics].
Format: 3 bullet points, each starting with a bold win title followed by 1–2 sentences of explanation.
```

Repeat for Areas of Concern and Recommendations sections.

**Step 8: Human Review and Finalisation**

Before sending to the client:
- [ ] Verify all numbers against the raw data (AI sometimes recalculates incorrectly)
- [ ] Remove any AI-hallucinated claims (e.g., invented competitor comparisons)
- [ ] Ensure recommendations are specific to THIS client's business and budget
- [ ] Check language for professionalism — edit any overly casual AI phrasing
- [ ] Add client logo and branding to cover page if applicable
- [ ] Export as PDF for delivery
