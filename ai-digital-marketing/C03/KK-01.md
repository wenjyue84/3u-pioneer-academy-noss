## Work Activity Title

Generate a Set of Brand Visuals for a Malaysian Marketing Campaign Using AI Image Tools

---

## Learning Outcomes

By the end of this activity, trainees will have:
- Generated at least 6 AI images using structured prompts (3 product shots + 3 lifestyle images)
- Selected 3 final images based on quality, brand alignment, and cultural appropriateness
- Documented the prompts used and the evaluation rationale
- Prepared selected images at correct resolution for Instagram use

## Safety Precautions

- Do not generate images of real, identifiable persons without consent
- Do not generate images that could be considered offensive, stereotyping, or culturally disrespectful
- Review all AI outputs before presenting to trainer — flag any anatomical errors or distortions
- Do not use commercially generated images for actual publication without checking tool licensing terms

## Brand Brief — Campaign Context

**Brand:** Nutri Bumi — a Malaysian health supplement brand
**Product:** "Daily Greens" — a greens powder supplement (spirulina, moringa, wheatgrass blend)
**Target Audience:** Health-conscious Malaysian adults aged 28–45, M40/T20, urban
**Brand Personality:** Natural, trustworthy, clean, energetic; celebrates Malaysian wellness culture
**Brand Colours:** Forest green (#2D6A4F), cream white (#F5F0E8), warm gold (#E9C46A)
**Visual Style:** Clean product photography; natural settings; bright, natural lighting; diverse Malaysian representation

**Campaign visuals needed:**
1. Three product-focused shots (the product as hero)
2. Three lifestyle shots (people using or benefiting from the product)

---

## Step-by-Step Instructions

### Step 1: Study the Brand Brief (5 minutes)

Before generating any images, read the brand brief carefully and answer these questions in your Answer Sheet:

1. What are the three brand colours in HEX code?
2. Describe the visual style in two sentences.
3. Who is the target audience? Write a one-sentence description.
4. What feeling should the images give a viewer?

---

### Step 2: Write Product Shot Prompts (15 minutes)

Product shots focus on the product itself — clean, professional, no people.

Use this prompt structure:
```
[Product description] on [background/surface], [props/context], 
[lighting style], [colour palette description], [composition], 
product photography style, high resolution, [aspect ratio]
```

Write three distinct product shot prompts in your Answer Sheet. Each should produce a different look:
- **Prompt A:** Clean studio-style flat lay (white/cream background)
- **Prompt B:** Natural outdoor setting (greenery, natural light)
- **Prompt C:** Premium lifestyle surface (marble, wooden surface, or branded cloth)

**Example for Prompt A:**
```
A green powder supplement jar labelled "Daily Greens" on a white marble surface, 
surrounded by fresh spirulina leaves, moringa pods, and wheatgrass stalks. 
Soft studio lighting, clean white background, forest green and cream colour palette, 
top-down flat lay composition. Product photography style, 8K resolution, 1:1 aspect ratio.
```

Generate all three prompts in Lovart AI or Canva Magic Media. Save the outputs.

---

### Step 3: Write Lifestyle Shot Prompts (15 minutes)

Lifestyle shots show real people benefiting from or using the product. These require more care to ensure Malaysian representation.

Use this structure:
```
[Malaysian person description], [action/context], [setting], 
[lighting and mood], [colour palette], [composition], 
lifestyle photography, high resolution, [aspect ratio]
```

Write three distinct lifestyle shot prompts:
- **Prompt D:** Morning wellness routine (person preparing the drink at home)
- **Prompt E:** Active outdoor lifestyle (post-workout or outdoor activity)
- **Prompt F:** Workplace energy (professional setting, midday wellness break)

**Requirements for each lifestyle prompt:**
- Include a specific Malaysian representation detail (ethnicity, hijab, local setting, etc.)
- Match the brand's natural, clean visual style
- Specify lighting appropriate to the scene

Generate all three in Lovart AI or Canva Magic Media. Save the outputs.

---

### Step 4: Initial Evaluation — All 6 Images (20 minutes)

For each of the 6 generated images, complete this evaluation table in your Answer Sheet:

| Image | Prompt Used | Anatomical Errors? | Brand Colour Match? | Cultural Appropriateness | Composition Quality | Overall Rating (1–5) |
|---|---|---|---|---|---|---|
| A (Product) | | | | | | |
| B (Product) | | | | | | |
| C (Product) | | | | | | |
| D (Lifestyle) | | | | | | |
| E (Lifestyle) | | | | | | |
| F (Lifestyle) | | | | | | |

**Rating guide:**
- 5: Publication-ready, no edits needed
- 4: Minor edits needed (crop, slight colour adjustment)
- 3: Needs significant refinement or re-generation
- 2: Major quality issues; re-prompt
- 1: Unusable; fundamental errors

---

### Step 5: Re-Prompt and Refine (15 minutes)

For any image rated 3 or below, refine your prompt and regenerate. Common refinement strategies:

| Problem | Prompt Fix |
|---|---|
| Wrong background colour | "on a white background only, no props, clean studio white" |
| Anatomical errors (hands, faces) | Add: "perfect anatomy, no distortions, professional photography" |
| Missing Malaysian representation | Add specific descriptor: "Malaysian Malay woman in hijab, 30s" |
| Too dark or moody | Add: "bright, airy, well-lit, natural daylight" |
| Too generic / stock-photo feel | Add: "authentic, editorial style, not stock photo, genuine" |
| Product not prominent | Add: "product as hero, centred, in focus, foreground" |

Regenerate any images below rating 3 and re-evaluate. Update your table.

---

### Step 6: Final Selection and Preparation (10 minutes)

Select your **3 best final images** (at least 1 product shot and 1 lifestyle shot).

For each selected image:
1. Download in highest available resolution
2. Verify dimensions are at least 1080 × 1080 px
3. Note the final rating and one sentence explaining why you selected it

In Canva, crop each image to **1080 × 1080 px (Instagram square)** — this ensures correct dimensions for the platform.

## Evaluation Criteria

| Criterion | Excellent (4) | Good (3) | Adequate (2) | Needs Work (1) |
|---|---|---|---|---|
| **Prompt Quality** | All prompts use full structure; specific, detailed, culturally aware | Most prompts detailed; some structure | Basic prompts; missing key elements | Vague one-line prompts |
| **Malaysian Representation** | Lifestyle images clearly represent Malaysian audience appropriately | Some Malaysian context present | Generic; could be from any country | No local context |
| **Brand Alignment** | All selected images match brand colours, mood, and style | Most images on-brand | Partial brand alignment | Off-brand selections |
| **Evaluation Rigour** | All 6 images evaluated; refinements documented | Most evaluated; some refinement | Evaluation table incomplete | No structured evaluation |
| **Final Image Quality** | 3 strong images; correct resolution; publication-ready | 3 images selected; minor quality issues | 2 images; resolution issues | 1 or no qualifying images |

## Reflection Questions (Soalan Refleksi)

1. Which prompt type was harder to get right — product shot or lifestyle shot? What specific challenges did you face?
2. Did any AI-generated image contain anatomical errors or cultural inaccuracies? Describe what happened and how you addressed it.
3. Compare one of your initial prompts with the refined version. What specific changes did you make and what effect did they have?
4. If a client asked you to use these AI-generated lifestyle images in a paid Facebook advertisement, what legal or ethical check would you need to perform first?
