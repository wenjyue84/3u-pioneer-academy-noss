## 1. Introduction to AI Image Generation (Pengenalan kepada Penjanaan Imej AI)

### 1.1 What Is AI Image Generation?

**AI image generation (penjanaan imej AI)** is the process of using artificial intelligence models to create original visual content from text descriptions, reference images, or a combination of both. Rather than requiring photography equipment, a design studio, or years of artistic training, a digital marketer can now type a description — a **prompt (arahan teks)** — and receive a professional-quality image within seconds.

This technology has transformed the economics of visual content production. A single photoshoot for a product campaign can cost RM 3,000–15,000 in Malaysia (photographer, studio, models, post-processing). An equivalent AI-generated image can be produced for less than RM 5 in tool credits — or free, depending on the platform.

### 1.2 Historical Milestones in AI Image Generation

Understanding how this field evolved helps marketers appreciate both its capabilities and its limitations.

| Year | Milestone | Significance |
|---|---|---|
| 2014 | Generative Adversarial Network (GAN) introduced by Ian Goodfellow | First AI capable of generating photorealistic faces (StyleGAN) |
| 2021 | OpenAI releases DALL-E (v1) | First major text-to-image model accessible via API |
| 2022 | Stable Diffusion open-sourced; DALL-E 2 released; Midjourney launches | Democratisation — anyone could run AI image generation locally |
| 2022 | Google's Imagen model demonstrated | Showed photorealistic results from text; not publicly released |
| 2023 | DALL-E 3 integrated into ChatGPT; Midjourney v5/v6 launched | Dramatic quality improvement; text rendering improved |
| 2023 | Adobe Firefly released commercially | First commercially safe AI image tool (trained on licensed data) |
| 2024 | Ideogram 2.0; Flux model family by Black Forest Labs | Improved text-in-image accuracy; open weights models |
| 2025 | Lovart AI, Canva Dream Lab, Google Imagen 3 | Marketing-specific tools; integrated workflows for non-designers |
| 2026 | Real-time video generation; multi-modal AI agents | AI generates images, video, and audio from a single brief |

## 2. How Diffusion Models Work (Cara Kerja Model Difusi)

### 2.1 The Core Concept — From Noise to Image

Modern AI image generation is primarily powered by **diffusion models (model difusi)**. You do not need to understand the mathematics — but understanding the three-stage process helps you prompt more effectively and explain the technology to clients.

**Stage 1 — Encoding Your Text Prompt (Pengekodan Arahan Teks)**

When you type a prompt, a **text encoder (pengekod teks)** — typically a model like CLIP or T5 — converts your words into a numerical representation called an **embedding (pembenaman)**. This embedding captures the meaning and relationships between words. "Golden retriever puppy playing" produces a different embedding than "golden retriever adult sitting", even though both contain similar words.

**Stage 2 — Latent Space (Ruang Laten)**

Rather than working with full-size images (which would require enormous computing power), diffusion models operate in a compressed mathematical space called the **latent space (ruang laten)**. Think of this as a map of all possible images, where each point on the map represents a specific image. Related images cluster near each other — portraits of people cluster together, landscapes cluster elsewhere.

**Stage 3 — Denoising (Penyahbisingan)**

The model starts with a point in latent space filled with random noise (like TV static — hingar rawak). Guided by your text embedding, it progressively removes noise in many small steps — typically 20 to 50 steps — each step making the image clearer and more aligned with your prompt. This iterative refinement process is called **denoising (penyahbisingan)**.

### 2.2 Key Technical Concepts (Simplified)

| Concept | Malay Term | Simple Explanation |
|---|---|---|
| Latent Space | Ruang Laten | Compressed mathematical map of all possible images |
| Text Encoder | Pengekod Teks | Converts your words into numbers the AI understands |
| Embedding | Pembenaman | Numerical representation of meaning |
| Denoising | Penyahbisingan | Removing noise step-by-step to reveal the image |
| Sampling Steps | Langkah Pensampelan | Number of denoising iterations; more steps = more refined |
| CFG Scale | Skala Panduan | How strictly the AI follows your prompt vs. being creative |
| Seed | Benih | A number that locks in randomness — same seed = reproducible result |

### 2.3 Image Generation Modes

| Mode | Input | Output | Marketing Use Case |
|---|---|---|---|
| Text-to-Image (Teks-ke-Imej) | Written prompt only | New image from scratch | Product lifestyle shots, illustrations |
| Image-to-Image (Imej-ke-Imej) | Existing image + prompt | Modified version | Restyle a product photo |
| Inpainting (Pengecatan Dalam) | Image + selected area + prompt | Modified section | Replace background; remove unwanted objects |
| Outpainting (Pengembangan Imej) | Image + direction to extend | Extended image | Expand a portrait into a wide banner |
| ControlNet / Reference | Reference image + prompt | Image following same composition/pose | Consistent product angles |

## 4. Writing Effective Image Prompts (Penulisan Arahan Imej yang Berkesan)

### 4.1 The Anatomy of a Strong Image Prompt

A professional marketing prompt contains seven layers of information:

```
[Subject] + [Action/Scene] + [Style] + [Lighting] + [Colour Palette] + [Composition] + [Technical Specs]
```

**Example — Weak Prompt:**
```
A woman drinking coffee
```

**Example — Professional Marketing Prompt:**
```
A young Malaysian woman in her late 20s wearing a light blue hijab, seated at a minimalist 
café in Bangsar, holding a latte art coffee cup with both hands, smiling softly. 
Lifestyle photography style, natural window light, warm golden tones, shallow depth of field, 
bokeh background, rule-of-thirds composition. High resolution, 4:5 aspect ratio for Instagram feed.
```

### 4.2 Prompt Modifier Reference Table

| Category | Malay Term | Effective Modifiers |
|---|---|---|
| Style (Gaya) | Gaya Visual | photorealistic, editorial photography, watercolour illustration, flat design vector, cinematic, 3D render |
| Lighting (Pencahayaan) | Pencahayaan | soft natural window light, golden hour, studio strobe, dramatic rim lighting, overcast diffused |
| Colour Palette (Palet Warna) | Palet Warna | warm earth tones, pastel pink and cream, monochromatic blue, vibrant tropical colours, brand colours HEX |
| Composition (Komposisi) | Komposisi | close-up portrait, overhead flat lay, wide establishing shot, rule of thirds, centred symmetry |
| Mood (Suasana) | Suasana | energetic and youthful, calm and luxurious, playful, professional corporate, cosy and intimate |
| Technical (Teknikal) | Spesifikasi Teknikal | 8K resolution, sharp focus, DSLR quality, no watermark, product photography white background |
| Negative Prompt | Arahan Negatif | (use to exclude) blurry, watermark, extra fingers, distorted face, text, logo, dark background |

## 5. Malaysian Cultural Considerations in AI Image Prompts

### 5.1 Racial and Ethnic Representation

Malaysia is a multicultural nation with three major ethnic groups — **Malay (Melayu), Chinese (Cina), and Indian (India)** — plus indigenous communities (Bumiputera Sabah dan Sarawak). Marketing images must reflect this diversity appropriately.

| Ethnic Group | Key Visual Cues to Include | Common Mistakes to Avoid |
|---|---|---|
| Malay | Hijab (for Muslim women), songkok, baju kurung/baju Melayu | Assuming all Malay women wear hijab; depicting Malay as exclusively rural |
| Chinese Malaysian | Modern urban attire; traditional only for CNY campaigns | Using mainland Chinese stereotypes; ignoring local Malaysian Chinese context |
| Indian Malaysian | Saree, kurta for festive; modern urban for general | Using South Indian stereotypes exclusively; ignoring Tamil Malaysian context |
| Multi-ethnic | Diverse groups in professional/social settings | Excluding any ethnic group; using only Western-looking models |

### 5.2 Religious and Halal Sensitivity

Malaysia is a predominantly Muslim country (~63% of population). AI image prompts for food, lifestyle, and consumer products must observe **halal sensitivity (sensititi halal)**:

- Do not include pork products, alcohol bottles, or non-halal imagery in food marketing unless explicitly targeting non-Muslim audiences
- Avoid images of women without appropriate modesty if the target brand is Islamic/conservative
- For festive content: Ramadan/Hari Raya themes use crescent, mosque silhouettes, gold and green palettes — avoid including elements from other religions in the same composition
- Chinese New Year themes: red and gold, lanterns, mandarin oranges — appropriate for Chinese-Malaysian market

### 5.3 Local Architecture and Landmarks

Including recognisable Malaysian locations increases authenticity and local resonance:

| Location Type | Prompt Examples |
|---|---|
| Urban KL | "Petronas Twin Towers in background", "KLCC park skyline", "Bukit Bintang streetscape" |
| Heritage | "Georgetown Penang shophouse street", "Malacca riverside colonial architecture" |
| Local environments | "Malaysian hawker centre (gerai makan)", "wet market (pasar basah)", "surau/masjid exterior" |
| Nature | "Malaysian rainforest canopy", "palm oil plantation", "Cameron Highlands tea plantation" |

> **Note:** AI models in 2026 have improved but may still struggle with accurate depiction of Petronas Twin Towers or other specific landmarks. Always verify outputs and use reference images where available.

## 6. Copyright and Licensing of AI-Generated Images

### 6.1 Malaysian Copyright Act 1987 (Akta Hak Cipta 1987)

The **Copyright Act 1987 (Akta Hak Cipta 1987)** is the primary intellectual property legislation governing creative works in Malaysia. As of 2026, Malaysian law has not established definitive legislation specifically for AI-generated works, but the following principles apply:

| Legal Principle | Application to AI Images |
|---|---|
| Copyright subsists in an "author" | AI is not a legal author — the human who creates the prompt and selects the output may claim authorship |
| Work must be original and fixed | AI-generated images that result from substantial human creative input (prompting, curation, editing) are more likely to qualify |
| Duration of copyright | If human authorship is established: life of author + 50 years (Malaysia) |
| Infringement risk | If AI is trained on copyrighted works and reproduces them closely, infringement liability may arise |

### 6.2 Platform Terms of Service Comparison

| Platform | Free User Commercial Rights | Paid User Commercial Rights | Training Data Disclosure |
|---|---|---|---|
| DALL-E 3 (ChatGPT) | Limited | Full commercial rights | Web crawl + licensed data |
| Midjourney v7 | No commercial rights | Full commercial rights (Standard+) | Web crawl |
| Adobe Firefly | Limited (25 credits/month) | Full + Adobe indemnification | Licensed stock, public domain only |
| Canva AI | Limited | Commercial rights with Canva Pro | Mixed |
| Stable Diffusion (FLUX) | Depends on model licence | Depends on model licence | Varies by model |
| Ideogram | Free tier: commercial allowed | Commercial allowed | Web crawl + licensed |
| Lovart AI | Check ToS | Commercial rights | Product-specific training data |

### 6.3 Commercial Use Best Practices

| Practice | Rationale |
|---|---|
| Always read the ToS before using any tool for client work | Commercial rights vary significantly by plan tier |
| Prefer Adobe Firefly for high-stakes client campaigns | Adobe legally indemnifies commercial users against copyright claims |
| Do not generate images mimicking a specific living person's appearance | Risk of defamation, privacy violation, or right-of-publicity claims |
| Do not instruct AI to replicate a named living artist's style for commercial use | Potential copyright infringement and reputational risk |
| Document all prompts used to generate commercial images | Creates an evidence trail of human creative input |
| Do not resell AI-generated images as stock photography | Most platform ToS prohibit this |

## 7. Image Quality Assessment Checklist (Senarai Semak Penilaian Kualiti Imej)

Before publishing any AI-generated image in a marketing campaign, apply this checklist:

### 7.1 Technical Quality

| Check Item | Minimum Standard | Action if Failed |
|---|---|---|
| Resolution | 1080px minimum for social media; 300 DPI for print | Regenerate at higher resolution or upscale using AI (Topaz, Magnific) |
| Artefacts | No visible distortions, blurring, or noise | Regenerate or use inpainting to fix problem areas |
| Anatomical accuracy | Correct number of fingers (5), natural facial features | Regenerate; use image editing to fix minor issues |
| Text accuracy | Any text in image is readable and correctly spelled | Regenerate; add text as overlay in Canva/Photoshop instead |
| Aspect ratio | Correct for intended platform (see KP-03 for specs) | Crop or regenerate with correct ratio |

### 7.2 Brand and Cultural Alignment

| Check Item | Standard | Action if Failed |
|---|---|---|
| Brand colours | Within ±10% of brand palette | Adjust in Canva or Photoshop using colour grading |
| Cultural appropriateness | Suitable for Malaysian multicultural, predominantly Muslim audience | Do not publish; regenerate with corrected prompt |
| Halal compliance | No prohibited food or drink items visible | Do not publish; replace |
| Ethnic representation | Reflects target audience; avoids stereotypes | Consult with marketing manager; regenerate if needed |
| Competitor imagery | No competitor logos or branding visible | Regenerate or crop out |

### 7.3 Legal Clearance

| Check Item | Standard | Action if Failed |
|---|---|---|
| Commercial licence | Platform ToS permits commercial use for plan tier | Upgrade plan or switch to licensed tool |
| Real person likeness | No recognisable real person without consent | Regenerate with non-specific description |
| Trademarked elements | No logos, brand marks, or trademarks | Regenerate with prompt excluding trademark references |
| Artist style mimicry | Does not explicitly replicate a named living artist | Regenerate with different style reference |
