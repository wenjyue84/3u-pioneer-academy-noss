## 1. Core Graphic Design Principles (Prinsip Reka Bentuk Grafik Teras)

### 1.1 Why Design Principles Matter

Even with AI generating layouts and images, a digital marketer who understands graphic design principles can recognise good design, give better instructions to AI tools, and correct AI-generated designs that are "almost right." These six principles form the foundation of professional visual communication (komunikasi visual profesional) across all marketing channels.

### 1.2 The Six Core Principles

**Principle 1 — Visual Hierarchy (Hierarki Visual)**

Visual hierarchy guides the viewer's eye through the design in a deliberate sequence — from the most important information to the least important. It is created through differences in size, weight (boldness), colour, and position.

- Largest element = highest priority (headline, hero image, product)
- High-contrast colour draws the eye before low-contrast colour
- Top-left and centre are primary focal zones for most audiences; bottom-right is secondary

**Principle 2 — Contrast (Kontras)**

Contrast creates visual interest and ensures readability. Without sufficient contrast between text and background, designs fail on mobile screens — especially in bright outdoor Malaysian daylight.

- Minimum contrast ratio for body text: **4.5:1** (WCAG 2.1 accessibility standard)
- Dark text on light background; light text on dark background
- Never grey on white or light yellow on white

**Principle 3 — Alignment (Penjajaran)**

Alignment creates order and professionalism. Every element should align with at least one other element using an invisible grid. Misaligned elements make designs feel amateur and untrustworthy.

- Left alignment: most readable for text-heavy layouts
- Centre alignment: formal and balanced; best for posters and event announcements
- Consistent margin from edge of design (typically 5–10% of width)

**Principle 4 — Proximity (Kedekatan)**

Related elements should be grouped close together; unrelated elements should be separated. Proximity creates logical visual clusters without needing boxes or dividers.

- Product name + price + buy button = tight group
- Company tagline + logo = grouped at header or footer

**Principle 5 — White Space / Negative Space (Ruang Kosong)**

Empty space around and between elements is not wasted space — it is a design element. Generous white space signals quality, premium positioning, and makes content more readable.

- Malaysian SME social media posts frequently suffer from overcrowding
- Luxury brands (Dior, Hermès, Apple) use extremely generous white space
- Practical rule: if a design feels "too empty," it is probably correct

**Principle 6 — Repetition (Ulangan)**

Repeating visual elements — a specific colour, shape, font, or icon style — across all designs in a campaign creates cohesion and brand recognition. Viewers in a crowded social feed should recognise a brand's post before reading any text.

## 2. Typography for Marketing (Tipografi untuk Pemasaran)

### 2.1 Font Pairing Rules

Marketing designs typically use a two- to three-font hierarchy:

| Font Role | Usage | Visual Character |
|---|---|---|
| **Display / Heading Font** | Headlines, titles, banner text | Bold, distinctive; can be decorative or strong |
| **Body / Supporting Font** | Captions, descriptions, body paragraphs | Highly readable at small sizes; clean |
| **Accent Font** | Labels, CTA buttons, pull quotes | Complements display font; adds personality |

**Rules:**
- Maximum 3 fonts per design; 2 fonts is ideal
- Never pair two decorative or two script fonts together
- Ensure minimum **16px** body text for digital; **10pt** for print at reading distance

### 2.2 Recommended Fonts for Malaysian Marketing

| Category | Recommended Fonts | Best Application |
|---|---|---|
| Corporate / Professional | Montserrat, Inter, Source Sans Pro | B2B, finance, education, government |
| Friendly / Lifestyle | Poppins, Nunito, Lato | F&B, retail, beauty, youth brands |
| Luxury / Premium | Playfair Display, Cormorant Garamond | Property, fashion, high-end F&B |
| Bold / Impact | Anton, Bebas Neue, Black Han Sans | Promotions, sales banners, sports |
| Festive / Decorative | Script fonts (seasonal only) | Hari Raya, CNY, Deepavali campaigns only |

### 2.3 Multilingual Typography: English, Bahasa Malaysia, and Chinese

Malaysian marketing content frequently requires three languages in one design. This creates specific technical challenges:

| Challenge | Explanation | Solution |
|---|---|---|
| **Chinese character support** | Latin fonts (Montserrat, Poppins) contain no Chinese characters; fallback fonts display incorrectly | Use CJK-supporting fonts: Noto Sans CJK, Source Han Sans, Adobe Heiti |
| **Line height mismatch** | Chinese characters are visually taller than Latin characters at the same point size | Set line height (leading) to 1.5–1.8× for mixed-language text blocks |
| **Font weight inconsistency** | Bold Latin font paired with Regular Chinese font creates visual imbalance | Match weight across both scripts; test visually before finalising |
| **Jawi script** (رسم جاوي) | Some BM content uses Jawi (right-to-left Arabic-script Malay) | Use Jawi-compatible fonts: Scheherazade New, Amiri; set text direction RTL |
| **Font licensing for commercial use** | Some fonts are free for personal use but require a licence for commercial use | Use Google Fonts (OFL licensed) or Adobe Fonts (included in Adobe CC subscription) |

## 4. Creating Marketing Graphics with Canva AI (Mencipta Grafik Pemasaran dengan Canva AI)

### 4.1 The Five-Step Canva AI Workflow

**Step 1 — Define the Creative Brief (Taklimat Kreatif)**

Before opening Canva, clarify:
- Campaign objective (brand awareness / promotion / product launch / event)
- Key message (one sentence)
- Target audience (age, gender, platform, language preference)
- Target platforms (determines dimensions needed)
- Brand kit available? (colours, fonts, logo files)

**Step 2 — Generate Layout with Magic Design**

1. Open Canva → Create a design → Set correct dimensions for primary platform
2. In the editor, click **Magic Design** (left panel)
3. Type a design brief: e.g., *"Promotional banner for Hari Raya Sale — 50% off — gold and green tones — Malaysian lifestyle brand — Instagram portrait"*
4. Review 8–12 generated layout variants; select the closest to the brief
5. This becomes your editable starting template

**Step 3 — Apply Brand Kit and Customise**

1. Open Brand Kit panel → apply brand colours to background, text, and accents
2. Replace AI-suggested fonts with brand-approved fonts
3. Insert logo at correct position (typically top-left or bottom-right)
4. Replace placeholder images with brand photos, Lovart AI exports, or DALL-E 3 outputs

**Step 4 — Refine with AI Tools**

| Design Task | Canva AI Tool | Instruction Example |
|---|---|---|
| Rewrite headline | Magic Write | "Make this headline more urgent and benefit-focused" |
| Generate custom image | Dream Lab | Enter detailed image prompt |
| Remove product background | Background Remover | One click; refine edges manually |
| Expand design area | Magic Expand | Drag canvas border; AI fills extended area |
| Resize for all platforms | Magic Resize | Select all target platforms; review each output |

**Step 5 — Export in Correct Format**

| Export Setting | Use Case |
|---|---|
| PNG (transparent background) | Logos and graphics placed on other backgrounds |
| JPG (quality 90%+) | Photos and complex social media images |
| PDF (Print) | Flyers, brochures, posters for professional printing |
| MP4 | Animated posts, video thumbnails |
| GIF | Short looping animations |

## 5. Print vs Digital Design Considerations (Pertimbangan Reka Bentuk Cetak berbanding Digital)

### 5.1 Colour Modes (Mod Warna)

| Aspect | Digital (Screen) | Print |
|---|---|---|
| **Colour Mode** | RGB (Red, Green, Blue) | CMYK (Cyan, Magenta, Yellow, Key/Black) |
| **Colour Reference** | HEX code: e.g., #FF5733 | CMYK percentages: e.g., C:0 M:66 Y:80 K:0 |
| **Colour Gamut** | Wider — more vivid colours possible on screen | Narrower — some RGB colours cannot be reproduced in print |
| **Common Error** | Designing in RGB, then printing without converting — colours appear dull, shifted | Not requesting CMYK proof before large print run |
| **Canva Workflow** | Default is RGB; suitable for all social media exports | Use "Download → PDF Print" option; tick "CMYK" if available |

### 5.2 Resolution Standards (Piawaian Resolusi)

| Application | Required Resolution | Notes |
|---|---|---|
| Social media images | 72 DPI | Screen display only; higher DPI increases file size with no visible benefit |
| Digital advertising | 72–96 DPI | Same as social media |
| Office / home printing | 150–200 DPI | Acceptable for internal documents |
| **Professional print** (flyers, brochures) | **300 DPI minimum** | Industry standard in Malaysia for sharp print output |
| Large format (roll-up banners, billboards) | 72–150 DPI at actual print size | Viewed from distance; lower DPI acceptable |

### 5.3 Bleed Margins (Margin Pendarahan)

**Bleed (pendarahan)** is an extra printing zone beyond the final trim edge, preventing white borders after cutting.

| Specification | Malaysian Print Standard |
|---|---|
| Bleed margin | 3 mm on all four sides |
| Safe zone (no critical content) | Minimum 5 mm from final trim edge |
| Example: A5 flyer (148 × 210 mm) | Submit as 154 × 216 mm with bleed |

> **Note for Malaysian print submissions:** When submitting to local printers (e.g., Percetakan Nasional, PrintLab, T-Print), submit as high-resolution PDF with 3 mm bleed, CMYK colour mode, and fonts embedded or outlined.

## 6. File Format Guide (Panduan Format Fail)

### 6.1 Image Format Comparison Table

| Format | Best Use Case | Transparency | Compression | Platform Compatibility |
|---|---|---|---|---|
| **JPG / JPEG** | Photos; complex images; social media | No | Lossy | Universal |
| **PNG** | Logos; graphics with transparent background; screenshots | Yes | Lossless | Universal |
| **WebP** | Web images; faster page loading | Yes | Lossy or lossless | Modern browsers; not all platforms |
| **SVG** | Logos; icons; scalable graphics for web | Yes | Vector (no pixels) | Web and design tools only |
| **PDF** | Print files; multi-page documents; e-brochures | Yes (PDF 1.4+) | Lossless | Universal for documents |
| **GIF** | Short looping animations (max 256 colours) | Binary (yes/no) | Lossless limited | Universal |
| **MP4 (H.264)** | Social media video; Reels; TikTok | No | Compressed video | Universal video |

### 6.2 Format Selection Quick Reference

| Scenario | Correct Format | Reason |
|---|---|---|
| Instagram feed photo | JPG | Smallest file; natural photo quality |
| Logo on coloured background | PNG | Requires transparent background |
| Client brand logo for web use | SVG | Scales to any size without quality loss |
| Professional print flyer | PDF (CMYK, 300 DPI) | Printer-ready with bleed |
| Animated social post | GIF (short) or MP4 (longer) | GIF for <5s loops; MP4 for longer animations |
| Product image for Shopee | JPG (white background) | Platform requirement |
| Website hero image | WebP (with JPG fallback) | Fastest loading for web |

## 7. Quality Control Checklist for Marketing Graphics (Senarai Semak Kawalan Kualiti)

Apply this checklist to every marketing graphic before publishing or delivering to a client:

### 7.1 Design Quality

| Check | Standard | Pass / Fail |
|---|---|---|
| Visual hierarchy | Headline > supporting image > body text > CTA — viewer's eye flows naturally | |
| Text contrast | All text passes minimum 4.5:1 contrast ratio against background | |
| Font count | Maximum 3 fonts; all brand-approved typefaces | |
| Spelling and grammar | Proofread in all languages used (EN, BM, ZH) | |
| No placeholder content | No "Lorem ipsum," "[INSERT TEXT]," or unnamed dummy images | |
| White space | Design does not feel cluttered; key elements have breathing room | |

### 7.2 Brand Compliance

| Check | Standard | Pass / Fail |
|---|---|---|
| Brand colours | Confirmed by HEX code match, not visual estimation | |
| Logo correct | Present, correctly sized, not stretched, recoloured, or placed on busy background | |
| Imagery style | Matches brand's defined photography/illustration style | |
| Tone consistency | Copy matches brand voice (formal/friendly/playful/premium) | |

### 7.3 Technical Specifications

| Check | Standard | Pass / Fail |
|---|---|---|
| Dimensions | Correct for target platform (refer Section 3 table) | |
| File size | Within platform upload limit | |
| File format | Correct format for use case (JPG/PNG/PDF/MP4) | |
| Resolution | 72 DPI for digital; 300 DPI for print | |
| Print bleed | 3 mm bleed included if for professional printing | |
| CMYK mode | Applied if submitting to printer | |

### 7.4 Cultural and Legal Compliance

| Check | Standard | Pass / Fail |
|---|---|---|
| Cultural appropriateness | Suitable for Malaysian multicultural, predominantly Muslim context | |
| Halal compliance | No prohibited items visible in food/lifestyle images | |
| AI image artefacts | No distorted faces, extra fingers, or unreadable text in AI-generated images | |
| Image licensing | Commercial licence confirmed for all images used | |
| No real person likenesses | No recognisable individuals without written consent | |
| No trademarked elements | No competitor logos or trademarked brand marks visible | |

## 9. Review Questions (Soalan Ulangkaji)

1. A colleague's social media post has the following issues: the headline is the same size as the body text, Comic Sans is used alongside Montserrat and a script font, and every corner of the design is filled with text and graphics. Using the six design principles from Section 1, identify which principles are being violated and suggest specific corrections.
2. You are creating a Hari Raya campaign that will appear on Instagram Feed (portrait), Instagram Story, and Facebook Ad. State the exact pixel dimensions for each, and describe how you would use Canva's Magic Resize to produce all three versions from a single master design.
3. A client provides a product logo in JPG format. They want you to place the logo on a dark blue background in a promotional banner. What problem will arise, and which file format should you request and why?
4. Explain the difference between RGB and CMYK colour modes. A marketer designs a vivid teal flyer (#00CED1) in Canva and sends it for professional printing in RGB format. The printed flyers come back looking dull grey-green. What went wrong and how should this be corrected for the next print run?
5. Apply the quality control checklist (Section 7) to a scenario where you have used Lovart AI to generate a lifestyle image of a Malay mother and child for a baby product brand's Instagram post. List six specific checks you must perform and explain the reason for each check.
