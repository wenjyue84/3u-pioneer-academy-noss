### Sesi A4 — Ujian Kelajuan Halaman dan Pengoptimuman (WA1)

| Lajur | Butiran |
| --- | --- |
| **Sesi** | A4 |
| **Masa** | 2 jam |
| **Tajuk** | Google PageSpeed Insights dan CRO: Heatmap Simulation, A/B Testing Concepts |
| **Aktiviti Kerja** | WA1 |
| **Rujukan** | KK(1/2) — Langkah 8; KP(1/3) Seksyen 4 |

**Objektif Pembelajaran:**
Pada akhir sesi ini, pelatih berupaya:
1. Menjalankan ujian Google PageSpeed Insights pada landing page mereka dan mentafsir laporan
2. Mengenal pasti tiga tindakan pengoptimuman berdasarkan laporan dan melaksanakan sekurang-kurangnya satu
3. Merancang satu A/B test untuk elemen landing page mereka (tajuk atau CTA)

**Aktiviti P&P:**
- Jalankan PageSpeed Insights (20 minit): setiap pelatih menguji URL landing page mereka; ambil tangkapan skrin

- Rancang A/B test (20 minit): pelatih tulis cadangan A/B test dengan dua variasi tajuk atau CTA
- Perbincangan kelas (20 minit): kongsi cadangan A/B test; bincang mana paling kemungkinan untuk menang

**Bahan / ABBM:**
- Borang analisis PageSpeed Insights (templat untuk rekod skor sebelum dan selepas)
- Panduan tukar imej ke WebP menggunakan Canva (dicetak)
- Borang cadangan A/B Test

**Penilaian:**
- Borang analisis PageSpeed (sebelum/selepas) dikumpul
- Cadangan A/B test (2 variasi, 1 hipotesis) dikumpul
