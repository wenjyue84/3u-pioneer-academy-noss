## 1. Website Fundamentals for Business (Asas Laman Web untuk Perniagaan)

### 1.1 The Three Components of a Business Website

Every business website rests on three foundational components that must be selected and configured before any design work begins:

**Component 1 — Domain Name (Nama Domain)**

A domain name is the web address that users type to reach a website (e.g., `www.mybusiness.com.my`). In Malaysia, domain registration is governed by **MYNIC (Malaysia Network Information Centre)** for `.my` and `.com.my` domains.

| Domain Extension | Target | Typical Use | Annual Cost (MYR) |
|---|---|---|---|
| `.com.my` | Malaysian registered businesses | Malaysian SME businesses | RM 70–100/year |
| `.my` | Malaysian individuals and organisations | Personal brands; short URLs | RM 50–80/year |
| `.edu.my` | Educational institutions | Universities; schools | Restricted |
| `.gov.my` | Government agencies | Government bodies | Restricted |
| `.net.my` | Network service providers | ISPs; infrastructure | RM 70–100/year |
| `.com` | International; any entity | Startups targeting regional market | RM 40–60/year (via global registrars) |

**MYNIC Registration:** Domain names under `.my` extensions are registered exclusively through MYNIC-accredited registrars. As of 2026, accredited registrars include Exabytes, Shinjiru, Web Hosting Malaysia, and Webserver.com.my. Registering a `.com.my` requires a valid Malaysian business registration (SSM registration / Borang D or B).

**Component 2 — Web Hosting (Pengehosan Web)**

Web hosting is the server infrastructure that stores website files and makes them accessible on the internet. For Malaysian businesses, hosting server location directly affects website loading speed for local visitors.

| Hosting Type | Description | Suitable For | Monthly Cost (MYR) |
|---|---|---|---|
| Shared Hosting | Multiple websites on one server | Small SME websites; low traffic | RM 5–30/month |
| VPS (Virtual Private Server) | Dedicated virtual resources | Medium SME; growing traffic | RM 50–200/month |
| Cloud Hosting | Distributed cloud infrastructure (AWS, Google Cloud) | E-commerce; high traffic | RM 30–500+/month |
| Managed WordPress Hosting | Optimised specifically for WordPress | WordPress-based businesses | RM 30–150/month |

**Malaysian Hosting Providers:** Exabytes (largest local provider), Shinjiru, WebServer.com.my, and SiteGiant offer servers physically located in Malaysia (data centres in KL/Cyberjaya), which provides the lowest latency (~5–20 ms) for Malaysian visitors compared to international servers (~80–150 ms).

**Component 3 — CMS (Content Management System / Sistem Pengurusan Kandungan)**

A CMS allows non-technical users to create, edit, and publish website content without writing code.

| CMS | Market Share (2026) | Best For | Technical Skill Required |
|---|---|---|---|
| WordPress | ~43% of all websites | Full-featured business sites; blogs; e-commerce | Low–Medium |
| Shopify | ~4% | E-commerce focused | Low |
| Wix | ~3% | Simple SME websites | Very Low |
| Framer | ~1% (growing fast) | Design-forward; AI-powered | Low |
| Custom CMS | Variable | Enterprise with specific requirements | High |

## 3. Landing Page Design Principles (Prinsip Reka Bentuk Halaman Pendaratan)

### 3.1 What Is a Landing Page?

A **landing page (halaman pendaratan)** is a standalone web page with a single focused objective — to convert visitors into leads or customers. Unlike a homepage (which serves multiple purposes), a landing page is designed to convert one specific action: sign up, purchase, book appointment, or request a quote.

**Key distinction:**

| Homepage | Landing Page |
|---|---|
| Multiple navigation links | No navigation links (or minimal) |
| Multiple calls-to-action | Single, specific call-to-action |
| Introduces entire brand | Focuses on one offer or product |
| Serves awareness stage | Serves decision or action stage |

### 3.2 Above-the-Fold Content (Kandungan di Atas Lipatan)

"Above the fold" refers to the portion of a web page visible without scrolling. Research consistently shows that 80% of visitors spend the majority of their time above the fold. Everything critical must be visible immediately.

**Required above-the-fold elements:**

| Element | Purpose | AI Tool |
|---|---|---|
| **Headline (Tajuk Utama)** | State the core value proposition in one line | AI generates 5–10 variants to test |
| **Subheadline** | Clarify and expand the headline | AI refines based on target audience |
| **Hero Image or Video** | Visual reinforcement of the offer | Lovart AI; Canva AI; DALL-E 3 |
| **Primary CTA Button** | Clear action button — visible without scrolling | AI suggests copy variants |
| **Trust Signal** | One credibility element (logo, badge, or stat) | "As seen on," "500+ happy customers" |

### 3.3 Full Landing Page Structure

| Section | Content | AI Assistance |
|---|---|---|
| Hero | Headline + subheadline + hero image + primary CTA | AI generates headline variants |
| Problem Statement | State the pain point the audience experiences | AI drafts empathy-driven copy |
| Benefits List | 3–5 key benefits (not features) | AI converts features to benefits |
| Social Proof | Testimonials, ratings, case studies, logos | AI formats and highlights reviews |
| How It Works | 3-step process; reduces friction | AI generates clear step descriptions |
| Secondary CTA | Repeat CTA with any urgency element | AI generates urgency copy |
| FAQ | 5–8 common objections addressed | AI generates FAQs from product info |
| Footer CTA | Final capture before visitor leaves | Minimal; one clear action |

### 3.4 CTA Button Design (Reka Bentuk Butang Seruan Bertindak)

| Principle | Guideline | Example |
|---|---|---|
| **Colour** | High contrast with background; typically brand accent colour | Orange on white; red on dark blue |
| **Size** | Minimum 44 × 44 px (mobile tap target); visible immediately | 200 × 50 px typical |
| **Copy** | Action verb + specific benefit; not generic "Submit" or "Click Here" | "Get My Free Quote" / "Start Free Trial" |
| **Urgency** | Add scarcity or time element when appropriate | "Get 20% Off — Today Only" |
| **Whitespace** | Surround with sufficient whitespace to draw eye | 20+ px padding around button |
| **Placement** | Above the fold, after benefits section, and at page bottom | Minimum 3 placements on long page |

## 4. Conversion Rate Optimisation (CRO) with AI

### 4.1 What Is Conversion Rate?

**Conversion Rate (Kadar Penukaran)** = (Number of Conversions ÷ Total Visitors) × 100

Example: If a landing page receives 1,500 visitors in a month and 45 complete the contact form:
Conversion Rate = (45 ÷ 1,500) × 100 = **3%**

Industry benchmark conversion rates:
- Average landing page: 2–5%
- Well-optimised landing page: 5–15%
- Top-performing (specific niche + warm traffic): 15–40%

### 4.2 AI-Powered CRO Tools

| Tool | AI Feature | What It Measures | Cost |
|---|---|---|---|
| **Hotjar AI** | Heatmap + session recording + AI summary | Where users click, move, scroll, and abandon | Free (limited) / $32–$80/month |
| **Microsoft Clarity** | Heatmap + scroll map + session replay | Free AI-powered behaviour analytics | Free |
| **Google Optimize (via GA4)** | A/B testing integration | Which headline/CTA/image version converts better | Free |
| **Unbounce Smart Traffic** | AI directs visitors to highest-converting variant | A/B test winner selection | $74–$240/month |
| **Google PageSpeed Insights** | Core Web Vitals analysis with AI recommendations | Page load speed and performance issues | Free |

### 4.3 Heatmap Analysis (Analisis Peta Haba)

A **heatmap (peta haba)** visually shows where visitors click, move their mouse, and how far they scroll on a page. AI interprets heatmap data to identify:

- **Click heatmaps:** Elements that attract clicks (including non-clickable elements — a sign visitors expect them to be links)
- **Scroll maps:** What percentage of visitors reach each section of the page
- **Session recordings:** Individual visitor journey replays

**Common Malaysian SME landing page issues revealed by heatmaps:**
- Most visitors never scroll past the hero section → hero section not compelling enough
- Visitors click on product images but they are not linked → add image-to-product links
- Visitors abandon at the form → form is too long; reduce to name + phone + email only
- Mobile visitors tap the wrong element → CTA button too small; increase tap target

### 4.4 A/B Testing (Ujian A/B)

**A/B testing (ujian A/B)** compares two versions of a page element to determine which performs better. Only one element should be changed at a time.

| Element to Test | Version A | Version B |
|---|---|---|
| Headline | "Get Your Free Website Audit" | "Discover Why Your Website Isn't Converting" |
| CTA button colour | Blue | Orange |
| CTA button copy | "Request a Quote" | "Get My Free Quote Now" |
| Hero image | Product photo | Lifestyle customer photo |
| Form length | 5 fields | 3 fields (name, phone, email only) |

Minimum test duration: 2 weeks with at least 500 visitors per variant for statistically significant results.

### 4.5 Page Speed Optimisation (Pengoptimuman Kelajuan Halaman)

**Google PageSpeed Insights** analyses any URL and provides:
- Performance score (0–100; target 90+ for both mobile and desktop)
- Core Web Vitals measurements (see Section 7)
- Specific recommendations with estimated improvement

**Common page speed fixes:**
- Compress images (use WebP format instead of PNG/JPG)
- Enable lazy loading for images below the fold
- Remove unused CSS and JavaScript files
- Use a Content Delivery Network (CDN)
- Enable browser caching

## 6. Website Accessibility and Legal Requirements

### 6.1 WCAG 2.1 Accessibility Basics

The **Web Content Accessibility Guidelines (WCAG) 2.1** are the international standard for web accessibility (Kebolehcapaian Web). While not currently legally mandated for private businesses in Malaysia, accessibility is becoming a business expectation and is referenced in MCMC guidelines for government-linked digital content.

| WCAG Principle | Malay Term | Key Requirements |
|---|---|---|
| **Perceivable** | Boleh Dilihat | All images have alt text; captions for videos; sufficient colour contrast |
| **Operable** | Boleh Dioperasikan | All functions accessible via keyboard; no content that flashes >3 times/second |
| **Understandable** | Boleh Difahami | Clear language; error messages explain how to fix them; consistent navigation |
| **Robust** | Teguh | Compatible with assistive technologies (screen readers) |

**Minimum compliance targets:**
- Text contrast ratio minimum 4.5:1 (WCAG AA Level)
- All images have descriptive alt text
- All form fields have visible labels
- Font size minimum 16px for body text

### 6.2 Personal Data Protection Act 2010 (PDPA) — Website Requirements

The **Personal Data Protection Act 2010 (Akta Perlindungan Data Peribadi 2010)** imposes specific obligations on Malaysian businesses that collect personal data through websites:

| Requirement | Detail | Implementation |
|---|---|---|
| **Privacy Policy** | Must be published on all pages that collect personal data | Add Privacy Policy page; link in footer |
| **Explicit Consent** | Must obtain consent before collecting data via forms | Checkbox: "I agree to the [Privacy Policy]" — unchecked by default |
| **Data Minimisation** | Collect only data necessary for the stated purpose | Do not add optional fields "just in case" |
| **Data Security** | Must implement reasonable security measures | SSL certificate (HTTPS); secure form submission |
| **Right to Access** | Users may request to view their data | Provide contact email in Privacy Policy |
| **Right to Correction** | Users may request correction of inaccurate data | Establish process to handle requests |

> **Penalty for non-compliance:** Under PDPA 2010, failure to comply can result in fines up to RM 500,000 and/or imprisonment up to 3 years.

### 6.3 Cookie Consent

Websites that use tracking cookies (Google Analytics, Facebook Pixel, advertising cookies) must inform visitors and obtain consent before setting non-essential cookies. This is aligned with PDPA principles and international best practice (GDPR).

**Implementation:**
- Install a cookie consent banner (e.g., Cookiebot, CookieYes — both have free tiers)
- Categorise cookies: Essential / Analytics / Marketing
- Allow users to accept or reject non-essential categories
- Store consent records

### 6.4 Terms of Service (ToS) and Other Legal Pages

| Legal Page | Purpose | When Required |
|---|---|---|
| Privacy Policy | Explains data collection and use | Any website collecting personal data |
| Terms of Service | Governs use of website and services | E-commerce; SaaS; membership sites |
| Refund Policy | Explains return/refund process | All e-commerce websites (Consumer Protection Act 1999) |
| Disclaimer | Limits liability for advice or information | Educational; health; legal content websites |
| Cookie Policy | Details cookie usage | Any website using tracking cookies |

## 7. Technical SEO Fundamentals (Asas SEO Teknikal)

### 7.1 Page Speed and Mobile-First

Google's ranking algorithm uses **mobile-first indexing (pengindeksan mengutamakan mudah alih)** — meaning Google primarily uses the mobile version of a website for ranking decisions. In Malaysia, where over 85% of browsing is on mobile devices, this is critical.

**Key mobile-first requirements:**
- Responsive design (laman web responsif) — layout adapts to screen size
- Touch-friendly elements — minimum 44 × 44 px tap targets
- No horizontal scrolling on mobile
- Readable text without zooming — minimum 16px body font

### 7.2 Core Web Vitals (Penting Web Teras)

Google's **Core Web Vitals** are three specific page experience signals that directly affect search rankings:

| Metric | Full Name | What It Measures | Good | Needs Improvement | Poor |
|---|---|---|---|---|---|
| **LCP** | Largest Contentful Paint | Time until the largest visible content element loads | ≤ 2.5s | 2.5–4.0s | > 4.0s |
| **INP** | Interaction to Next Paint (replaced FID in 2024) | Responsiveness to user interactions (clicks, taps) | ≤ 200ms | 200–500ms | > 500ms |
| **CLS** | Cumulative Layout Shift | Visual stability — how much page content shifts during loading | ≤ 0.1 | 0.1–0.25 | > 0.25 |

**How to check Core Web Vitals:**
1. Go to [https://pagespeed.web.dev/](https://pagespeed.web.dev/)
2. Enter your website URL
3. Click Analyse — results shown for both mobile and desktop
4. Review the Core Web Vitals section and follow AI recommendations

### 7.3 Additional Technical SEO Elements

| Element | Description | Tool to Implement |
|---|---|---|
| SSL Certificate (HTTPS) | Encrypts data; required for Google ranking | Most hosting providers include free SSL (Let's Encrypt) |
| XML Sitemap | Map of all pages for Google to index | Yoast SEO (WordPress); automatic in Framer/Wix |
| Robots.txt | Instructs search crawlers which pages to index | Edit via hosting file manager or SEO plugin |
| Schema Markup | Structured data that enhances search result appearance | Google's Structured Data Markup Helper; AI can generate JSON-LD code |
| Meta Title and Description | Appears in search results; influences click-through rate | 50–60 characters for title; 150–160 for description |
| Image Alt Text | Describes images for search engines and screen readers | Add to every meaningful image; include relevant keywords |
