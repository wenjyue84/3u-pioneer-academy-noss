## 4. Step-by-Step Instructions

### Phase 1: Create or Claim the Google Business Profile

**Step 1: Access Google Business Profile**
1. Open Google Chrome
2. Go to `business.google.com`
3. Sign in with your Google account
4. Click **Add your business** (for new listing) or **Manage now** (to claim existing)

**Step 2: Enter Basic Business Information**
1. Business name: Enter the exact legal or trading name
2. Business category: Type the primary category (e.g., "Restaurant", "Hair Salon", "Accounting Firm")
   - AI tip: Search for your top competitor's category in Google Maps to identify the best-fit category
3. Location: Enter full address including postcode and state
4. Service area (if applicable): Add districts/cities the business serves
5. Phone number: Malaysian format — `+60X-XXXXXXXX`
6. Website URL: Enter the landing page URL built in KK-01

**Step 3: Verify the Business**
- For training purposes, select **Verify later** if available, or use a training address
- In real deployment: verification is done by postcard (5–7 days), phone call, or Google Search Console instant verification

---

### Phase 2: Complete All Profile Fields with AI Assistance

**Step 4: Generate Business Description Using ChatGPT**

Open ChatGPT or Gemini and enter this prompt:

```
Write a Google Business Profile description for [Business Name], a [business type]
in [City], [State], Malaysia. Primary keyword: "[target keyword]".
Unique selling points: [USP 1], [USP 2], [USP 3].
Include a call-to-action. Write in [English/Malay/mixed].
Maximum 750 characters. Professional and friendly tone.
```

Copy the output, paste into GBP → **Edit profile** → **Description**.
Review for accuracy before saving — AI may hallucinate specific claims (e.g., "award-winning") that must be removed if not true.

**Step 5: Set Business Hours**
1. Go to **Edit profile** → **Hours**
2. Set opening and closing times for each day
3. Add special hours for Malaysian public holidays (Hari Raya, CNY, Deepavali, Christmas)
4. Enable **More hours** for specific services (e.g., drive-through hours, delivery hours)

**Step 6: Add Products / Services**
1. Go to **Edit profile** → **Products** or **Services**
2. Click **+ Add product** or **+ Add service**
3. For each item, use this ChatGPT prompt for the description:
   ```
   Write a 200-character product/service description for "[Product Name]"
   offered by a [business type]. Include key benefits. No pricing.
   ```
4. Add minimum 2 products or services
5. Include a product photo (use Canva AI to create product mockup if real photos unavailable)

---

### Phase 3: Upload Photos

**Step 7: Prepare and Upload Business Photos**

GBP listings with 10+ photos receive 35% more website clicks.

| Photo Type | Quantity | Content |
| --- | --- | --- |
| Logo | 1 | Official business logo, square format |
| Cover photo | 1 | Best exterior or branded image, 16:9 ratio |
| Exterior | 1–2 | Building facade, parking, street view |
| Interior | 1–2 | Inside the premises, clean and well-lit |
| Product/Service | 2–3 | Core products or team performing services |
| Team | 1 | Team photo or owner photo (optional but builds trust) |

Upload process: **Edit profile** → **Photos** → **Add photos** → Select files

**Photo preparation with Canva AI:**
1. Go to `canva.com` → Create design → Custom size (1200 × 900px)
2. Use **Magic Write** to add business name overlay if needed
3. Use **Background Remover** to clean product photos
4. Download as JPEG (minimum 720px wide, maximum 5MB)

---

### Phase 4: Add Q&A and Publish a GBP Post

**Step 8: Pre-Populate Q&A Section**

The Q&A section allows anyone to ask questions. As the business owner, you can pre-populate common questions:

1. Go to your GBP listing on Google Maps (search your business name)
2. Scroll to **Questions & answers** section
3. Click **Ask a question** — enter the question yourself
4. Then reply to it as the business owner

**Use ChatGPT to generate 3 Q&A pairs:**
```
Generate 3 common customer questions and professional answers for a [business type]
in Malaysia. Format as Q: / A:. Keep each answer under 200 characters.
Language: English.
```

**Step 9: Create and Publish a GBP Post**

1. Go to **Edit profile** → **Add update**
2. Select post type: **What's new**
3. Use Canva to create a 1200 × 900px image with business branding
4. Use ChatGPT to write a post caption:
   ```
   Write a Google Business Profile post for [Business Name].
   Announce [promotion/new service/tip]. Include a call-to-action.
   Maximum 300 words. Friendly, local Malaysian tone.
   ```
5. Paste the caption, add the image, set a **Learn more** button linking to the website
6. Click **Publish**
