**Subject: Technical Brief for US-052: Technical Content Accuracy Auditor**

**1. Overview & Context**
This story requires creating a standalone Python tool to validate technical content against industry standards. The implementation will be housed in the `_tools/` directory and will not directly integrate with Frappe DocTypes or hooks, despite the prompt's mention of a Frappe app. The tool will read standards from a JSON file and audit input text for compliance.

**2. Files to Modify/Create**
*   **`_tools/accuracy_auditor.py`**: The primary new file for all auditing logic.
*   **`_tools/test_accuracy_auditor.py`**: A new test file for unit testing the auditor.
*   **`_reference/industry_standards_index.json`**: The data source for standards; this file will need to be created and populated.

**3. Implementation Approach**
*   In `accuracy_auditor.py`, implement the core functions: `audit_bev_standards`, `audit_aesthetic_standards`, `audit_it_standards`.
*   These functions should load and parse `_reference/industry_standards_index.json`.
*   They will need to accept text content as an input argument and use regular expressions to parse out technical claims (e.g., voltage levels, safety codes, chemical names).
*   Create a final function, `format_audit_report`, to structure the results into the list format specified in the acceptance criteria.
*   Begin development by writing a failing test in `test_accuracy_auditor.py` for the 48V BEV requirement, as noted in the story.

**4. Edge Cases & Gotchas**
*   **Parsing Fragility**: Extracting technical claims from unstructured text is error-prone. Use highly specific regex patterns and consider edge cases where units or phrasing might vary.
*   **Undefined Input Source**: The story does not specify where the content to be audited originates. Write the functions to be agnostic, simply accepting a string.
*   **Data Dependency**: The tool's effectiveness is entirely dependent on the `industry_standards_index.json` file. Ensure robust error handling for file-not-found or parsing errors.
