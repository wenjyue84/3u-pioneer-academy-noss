## Story US-001 — Enhance BEV C01 KP technical depth — HV safety procedures and PPE specifications

### What was implemented
- KP-01: Updated safety glasses spec from DIN EN166 to MS ISO 16321 / ANSI Z87.1 (Malaysian standard); added Electricity Supply Act 1990 (Act 447) to references with bilingual name
- KP-02: Added bilingual heading for Digital Multimeter section; added IEC 61010-1 / MS IEC 61010-1 standard reference to DMM spec; added OSHA 1994 (Act 514), EQA 1974 (Act 127), ESA 1990 (Act 447) to References
- KP-03: Added OSHA 1994 and ESA 1990 citations at start of safety section; added explicit PPE table with Class 0 gloves, CAT-III multimeter, MS ISO 16321 glasses; added BM term for LOTO (Kunci-Keluar/Tag-Keluar); added Malaysian regulatory references

### Patterns discovered
- diff size anti-pattern: previous attempt generated 2183 lines by rewriting entire files. Correct approach: surgical edits only (66 lines total)
- KP-01 was already mostly compliant; focused changes were just adding the missing Electricity Supply Act ref and updating safety glasses spec
- CAT-III multimeter specification is a TOOL spec (not PPE), so only relevant in KP-02 (health check) and KP-03 (maintenance) — not KP-01 (workplace prep)

### Gotchas
- Windows: must use encoding=utf-8 when opening files with Python
- Malaysian standard for safety glasses is MS ISO 16321 (not DIN EN166)
- Act numbers: OSHA = Act 514, EQA = Act 127, ESA = Act 447, Road Transport = Act 333
